# TP 2 : Intégration de Monte-Carlo pour l'Espérance

Dans de nombreux problèmes d'IA (notamment en Reinforcement Learning), il est impossible de calculer l'intégrale exacte de l'espérance car la loi n'est pas connue analytiquement ou l'espace d'intégration est trop complexe.
L'intégration de Monte-Carlo permet d'estimer l'espérance E[g(X)] en générant des échantillons aléatoires.

Ici, on cherche à estimer l'espérance de Y = X^2, où X suit une loi uniforme sur [0, 1].
Théoriquement, E[X^2] = int_0^1 x^2 dx = 1/3.

```python
import random

def g(x):
    '''Fonction dont on cherche l'espérance g(x) = x^2'''
    return x * x

def monte_carlo_expectation(n_samples):
    '''Estime E[g(X)] par Monte-Carlo, avec X ~ U([0,1])'''
    sum_g_x = 0
    for _ in range(n_samples):
        # Tirage d'un echantillon selon U([0,1])
        x = random.random()
        sum_g_x += g(x)

    return sum_g_x / n_samples

if __name__ == '__main__':
    theoretical_expectation = 1/3
    n = 500000

    estimated_expectation = monte_carlo_expectation(n)
    print(f"Esperance estimee par Monte-Carlo (n={n}) : {estimated_expectation:.5f}")
    print(f"Esperance theorique : {theoretical_expectation:.5f}")

    # Validation
    error = abs(estimated_expectation - theoretical_expectation)
    assert error < 0.01, f"L'estimation de Monte-Carlo a echoue, erreur : {error}"
    print("Validation reussie : convergence de Monte-Carlo.")
```
