# TP 4 : Illustration de l'Inégalité de Markov

L'inégalité de Markov, P(X >= a) <= E[X]/a, est une borne théorique supérieure.
Ce script Python illustre cette borne sur une variable aléatoire suivant une loi exponentielle (qui est toujours positive) et vérifie que la proportion réelle d'échantillons dépassant 'a' est effectivement bien inférieure ou égale à la borne théorique.

La loi exponentielle de paramètre lambda a pour espérance 1/lambda.
On prend lambda = 0.5, d'où E[X] = 2.

```python
import random
import math

def sample_exponential(lam):
    '''Génère un échantillon selon une loi exponentielle via la méthode de l'inverse (transformée de probabilité)'''
    u = random.random()
    # x = -ln(1-u) / lambda
    return -math.log(1.0 - u) / lam

if __name__ == '__main__':
    lam = 0.5
    theoretical_mean = 1.0 / lam

    n_samples = 100000
    samples = [sample_exponential(lam) for _ in range(n_samples)]

    # Calcul de la moyenne empirique pour confirmer
    empirical_mean = sum(samples) / n_samples
    print(f"Moyenne empirique : {empirical_mean:.4f}, Theorique : {theoretical_mean}")

    # Test de l'inegalite de Markov pour a = 5
    a = 5.0

    # Compter combien d'echantillons sont >= a
    count_exceed = sum(1 for x in samples if x >= a)
    empirical_prob = count_exceed / n_samples

    # Borne de Markov
    markov_bound = theoretical_mean / a

    print(f"Probabilite empirique P(X >= {a}) = {empirical_prob:.4f}")
    print(f"Borne de Markov (E[X]/{a}) = {markov_bound:.4f}")

    # Validation : L'inégalité doit être vérifiée empiriquement
    assert empirical_prob <= markov_bound, "Violation de l'inegalite de Markov !"
    print("Validation reussie : L'inegalite de Markov est respectee.")
```
