# TP 1 : Simulation de la Loi des Grands Nombres

Ce TP illustre le concept d'espérance en simulant des tirages aléatoires et en vérifiant la convergence de la moyenne empirique vers l'espérance théorique (Loi Forte des Grands Nombres).

Nous allons simuler des lancers de dés équilibrés à 6 faces.
- L'univers est Omega = {1, 2, 3, 4, 5, 6}
- L'espérance théorique est E[X] = 3.5

```python
import random

def simulate_dice_rolls(n_rolls):
    '''Simule n_rolls lancers de dés et renvoie la somme'''
    total_sum = 0
    for _ in range(n_rolls):
        roll = random.randint(1, 6)
        total_sum += roll
    return total_sum

def empirical_expectation(n_rolls):
    '''Calcule l'espérance empirique sur n_rolls lancers'''
    total = simulate_dice_rolls(n_rolls)
    return total / n_rolls

if __name__ == '__main__':
    theoretical_mean = 3.5

    # Test avec peu de lancers
    small_n = 10
    mean_10 = empirical_expectation(small_n)
    print(f"Moyenne empirique (10 lancers) : {mean_10}")

    # Test avec un grand nombre de lancers
    large_n = 100000
    mean_large = empirical_expectation(large_n)
    print(f"Moyenne empirique (100000 lancers) : {mean_large}")

    # Validation mathématique (avec une petite tolérance)
    tolerance = 0.05
    assert abs(mean_large - theoretical_mean) < tolerance, "L'espérance empirique ne converge pas vers l'espérance théorique !"
    print("Validation reussie : la moyenne converge vers l'esperance theorique.")
```
