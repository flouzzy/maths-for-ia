# TP 02 : Stabilité Numérique et Conditionnement des Matrices

## Objectifs du TP

Ce Travail Pratique vise à explorer le concept de conditionnement des matrices et son impact sur la stabilité numérique des solutions de systèmes linéaires. Un système linéaire, souvent représenté sous la forme `Ax = b`, est fondamental en science des données, en ingénierie et en physique. Comprendre comment de petites perturbations dans `b` (par exemple, dues à des erreurs de mesure ou d'arrondi) peuvent se traduire par de grandes erreurs dans la solution `x` est crucial pour évaluer la fiabilité des modèles numériques.

**Objectifs mathématiques :**
*   Comprendre la définition du nombre de condition d'une matrice.
*   Démontrer l'inégalité fondamentale reliant l'erreur relative sur la solution `x` à l'erreur relative sur le second membre `b` et au nombre de condition de la matrice `A` : `||δx|| / ||x|| <= cond(A) * (||δb|| / ||b||)`.
*   Distinguer les matrices "bien conditionnées" des matrices "mal conditionnées" par l'analyse de leur nombre de condition et de l'amplification des erreurs.

**Objectifs algorithmiques :**
*   Implémenter des fonctions de base pour l'algèbre linéaire (norme de vecteur/matrice, multiplication matrice-vecteur).
*   Développer un algorithme de calcul de l'inverse d'une matrice 2x2.
*   Calculer le nombre de condition d'une matrice en utilisant la norme L1.
*   Simuler l'impact de perturbations du second membre `b` sur la solution `x` pour des matrices avec différents nombres de condition.
*   Utiliser des assertions pour valider la relation théorique entre les erreurs et le nombre de condition.

## Implémentation en Python

Nous allons implémenter les fonctions nécessaires "from scratch" en utilisant des listes Python pour représenter les vecteurs et les matrices. Pour des raisons de simplicité pédagogique, le calcul de l'inverse et la résolution du système linéaire seront limités aux matrices 2x2, ce qui est suffisant pour illustrer le concept de conditionnement.

```python
import math

def norm_L1(vector_or_matrix):
    """
    Calcule la norme L1 (manhattan) d'un vecteur ou d'une matrice.
    Pour un vecteur x, ||x||_1 = sum(|x_i|).
    Pour une matrice A, ||A||_1 = max_j (sum_i |A_ij|), c'est-à-dire le maximum des sommes absolues des colonnes.
    """
    if not vector_or_matrix:
        raise ValueError("L'entrée ne doit pas être vide.")

    # Vérifie si c'est une matrice (liste de listes)
    if isinstance(vector_or_matrix[0], list):
        num_rows = len(vector_or_matrix)
        num_cols = len(vector_or_matrix[0])

        # Vérifie que la matrice est rectangulaire
        for row in vector_or_matrix:
            if len(row) != num_cols:
                raise ValueError("La matrice n'est pas rectangulaire.")

        column_sums = [0.0] * num_cols
        for row in vector_or_matrix:
            for j in range(num_cols):
                column_sums[j] += abs(row[j])
        return max(column_sums)
    else:  # C'est un vecteur (liste de nombres)
        return sum(abs(x) for x in vector_or_matrix)

def matrix_multiply_vector(matrix, vector):
    """
    Multiplie une matrice par un vecteur.
    Result = Matrix @ Vector
    """
    num_rows = len(matrix)
    num_cols = len(matrix[0])

    if num_cols != len(vector):
        raise ValueError(
            f"Le nombre de colonnes de la matrice ({num_cols}) "
            f"doit correspondre à la taille du vecteur ({len(vector)})."
        )

    result = [0.0] * num_rows
    for i in range(num_rows):
        for j in range(num_cols):
            result[i] += matrix[i][j] * vector[j]
    return result

def matrix_inverse_2x2(matrix):
    """
    Calcule l'inverse d'une matrice 2x2.
    Pour une matrice [[a, b], [c, d]], l'inverse est (1/det) * [[d, -b], [-c, a]].
    """
    if len(matrix) != 2 or len(matrix[0]) != 2:
        raise ValueError("Cette fonction ne gère que les matrices 2x2.")

    a, b = matrix[0][0], matrix[0][1]
    c, d = matrix[1][0], matrix[1][1]

    determinant = a * d - b * c
    if abs(determinant) < 1e-12: # Utilise une petite tolérance pour la singularité
        raise ValueError("La matrice est singulière (déterminant nul ou très proche de zéro) et n'a pas d'inverse.")

    inv_det = 1.0 / determinant
    return [[d * inv_det, -b * inv_det],
            [-c * inv_det, a * inv_det]]

def condition_number_2x2(matrix):
    """
    Calcule le nombre de condition L1 d'une matrice 2x2.
    cond(A) = ||A|| * ||A_inverse||.
    """
    norm_A = norm_L1(matrix)
    inv_A = matrix_inverse_2x2(matrix)
    norm_inv_A = norm_L1(inv_A)
    return norm_A * norm_inv_A

def solve_linear_system_2x2(matrix, vector):
    """
    Résout le système linéaire Ax=b pour une matrice 2x2 en utilisant l'inverse.
    x = A_inverse @ b.
    """
    inv_A = matrix_inverse_2x2(matrix)
    return matrix_multiply_vector(inv_A, vector)

# --- Démonstration Principale ---

print("--- Démonstration du Conditionnement des Matrices ---")

# 1. Définition des matrices de test
# Une matrice bien conditionnée (determinant non nul, éléments non trop petits ou grands)
A_well_conditioned = [[2.0, 1.0], [1.0, 2.0]]
# Une matrice mal conditionnée (déterminant très proche de zéro, lignes/colonnes quasi-linéairement dépendantes)
# Exemple: [[1, 1], [1, 1.0001]] dont le déterminant est 0.0001
A_ill_conditioned = [[1.0, 1.0], [1.0, 1.0001]]

# Vecteur solution réelle que nous cherchons à retrouver
x_true = [3.0, 5.0]

# 2. Calcul des seconds membres 'b' sans perturbation
b_wc = matrix_multiply_vector(A_well_conditioned, x_true)
b_ic = matrix_multiply_vector(A_ill_conditioned, x_true)

# 3. Application d'une petite perturbation au second membre 'b'
delta_b_magnitude = 1e-5 # Magnitude de la perturbation
delta_b = [delta_b_magnitude, -delta_b_magnitude] # Une petite perturbation arbitraire

b_perturbed_wc = [b_wc[i] + delta_b[i] for i in range(2)]
b_perturbed_ic = [b_ic[i] + delta_b[i] for i in range(2)]

print(f"\nMatrice bien conditionnée A_wc = {A_well_conditioned}")
print(f"Matrice mal conditionnée A_ic = {A_ill_conditioned}")
print(f"Solution réelle x_true = {x_true}")
print(f"Second membre b_wc (non perturbé) = {b_wc}")
print(f"Second membre b_ic (non perturbé) = {b_ic}")
print(f"Perturbation ajoutée à b (delta_b) = {delta_b}")

# 4. Résolution des systèmes linéaires perturbés
x_perturbed_wc = solve_linear_system_2x2(A_well_conditioned, b_perturbed_wc)
x_perturbed_ic = solve_linear_system_2x2(A_ill_conditioned, b_perturbed_ic)

# 5. Calcul des nombres de condition et des erreurs relatives
cond_A_wc = condition_number_2x2(A_well_conditioned)
cond_A_ic = condition_number_2x2(A_ill_conditioned)

# Calcul de l'erreur relative sur b
relative_error_b_wc = norm_L1(delta_b) / norm_L1(b_wc)
relative_error_b_ic = norm_L1(delta_b) / norm_L1(b_ic)

# Calcul de l'erreur sur x (delta_x)
error_x_wc = [x_perturbed_wc[i] - x_true[i] for i in range(2)]
error_x_ic = [x_perturbed_ic[i] - x_true[i] for i in range(2)]

# Calcul de l'erreur relative sur x
relative_error_x_wc = norm_L1(error_x_wc) / norm_L1(x_true)
relative_error_x_ic = norm_L1(error_x_ic)

print(f"\n--- Matrice bien conditionnée ({A_well_conditioned}) ---")
print(f"Nombre de condition L1: {cond_A_wc:.2f}")
print(f"Solution x_perturbed_wc = [{x_perturbed_wc[0]:.6f}, {x_perturbed_wc[1]:.6f}]")
print(f"Erreur relative sur b (||δb||/||b||): {relative_error_b_wc:.6f}")
print(f"Erreur relative sur x (||δx||/||x||): {relative_error_x_wc:.6f}")
print(f"Borne supérieure attendue de l'erreur relative sur x (cond(A)*||δb||/||b||): {cond_A_wc * relative_error_b_wc:.6f}")

print(f"\n--- Matrice mal conditionnée ({A_ill_conditioned}) ---")
print(f"Nombre de condition L1: {cond_A_ic:.2f}")
print(f"Solution x_perturbed_ic = [{x_perturbed_ic[0]:.6f}, {x_perturbed_ic[1]:.6f}]")
print(f"Erreur relative sur b (||δb||/||b||): {relative_error_b_ic:.6f}")
print(f"Erreur relative sur x (||δx||/||x||): {relative_error_x_ic:.6f}")
print(f"Borne supérieure attendue de l'erreur relative sur x (cond(A)*||δb||/||b||): {cond_A_ic * relative_error_b_ic:.6f}")

# --- Assertions pour valider les résultats ---

print("\n--- Validation par Assertions ---")

# Assertion 1: Vérification de l'inverse d'une matrice 2x2
test_matrix_inv = [[2.0, 1.0], [1.0, 2.0]]
expected_inv_matrix = [[2/3, -1/3], [-1/3, 2/3]]
calculated_inv_matrix = matrix_inverse_2x2(test_matrix_inv)
tolerance_inv = 1e-9

assert abs(calculated_inv_matrix[0][0] - expected_inv_matrix[0][0]) < tolerance_inv, "Erreur dans l'inverse (0,0)"
assert abs(calculated_inv_matrix[0][1] - expected_inv_matrix[0][1]) < tolerance_inv, "Erreur dans l'inverse (0,1)"
assert abs(calculated_inv_matrix[1][0] - expected_inv_matrix[1][0]) < tolerance_inv, "Erreur dans l'inverse (1,0)"
assert abs(calculated_inv_matrix[1][1] - expected_inv_matrix[1][1]) < tolerance_inv, "Erreur dans l'inverse (1,1)"
print("Assertion passée : Calcul de l'inverse 2x2 est correct.")

# Assertion 2: Vérification de la relation d'erreur pour la matrice bien conditionnée
# On utilise une petite marge (e.g., 1.05) pour tenir compte des erreurs d'arrondi et du fait que l'inégalité est une borne supérieure.
margin_factor = 1.05
assert relative_error_x_wc <= cond_A_wc * relative_error_b_wc * margin_factor, \
    f"Assertion échouée pour la matrice bien conditionnée: ||δx||/||x|| ({relative_error_x_wc:.6f}) " \
    f"> cond(A)*||δb||/||b|| ({cond_A_wc * relative_error_b_wc:.6f} * {margin_factor})"
print("Assertion passée : La stabilité numérique pour la matrice bien conditionnée est validée.")


# Assertion 3: Vérification de la relation d'erreur pour la matrice mal conditionnée
assert relative_error_x_ic <= cond_A_ic * relative_error_b_ic * margin_factor, \
    f"Assertion échouée pour la matrice mal conditionnée: ||δx||/||x|| ({relative_error_x_ic:.6f}) " \
    f"> cond(A)*||δb||/||b|| ({cond_A_ic * relative_error_b_ic:.6f} * {margin_factor})"
print("Assertion passée : La stabilité numérique pour la matrice mal conditionnée est validée.")


print("\nLe TP s'est exécuté avec succès et toutes les assertions ont été validées.")
print("Cela démontre que la matrice mal conditionnée amplifie significativement plus les erreurs de perturbation que la matrice bien conditionnée.")
