# TP 01 : Stabilité Numérique et Conditionnement des Matrices

## 1. Objectifs Pédagogiques

### 1.1. Objectif Mathématique

Ce TP vise à introduire le concept fondamental de **conditionnement d'une matrice** en algèbre linéaire numérique. Nous allons explorer comment la "sensibilité" d'un système linéaire $Ax=b$ aux perturbations de ses données d'entrée (par exemple, le vecteur $b$) est directement liée au nombre de conditionnement de la matrice $A$. Un système est dit **bien conditionné** si de petites perturbations sur les données d'entrée n'entraînent que de petites perturbations sur la solution, tandis qu'il est **mal conditionné** si de petites perturbations peuvent engendrer de très grandes variations de la solution. Cela nous permettra de mieux comprendre la notion de problèmes bien posés et mal posés dans un contexte numérique.

Plus spécifiquement, nous allons :
*   Comprendre la définition et l'interprétation du nombre de conditionnement d'une matrice.
*   Visualiser l'amplification des erreurs de données par le conditionnement.
*   Saisir l'impact de ce concept sur la fiabilité des calculs numériques.

### 1.2. Objectif Algorithmique

Sur le plan algorithmique, nous allons :
*   Utiliser des outils d'algèbre linéaire pour résoudre des systèmes d'équations.
*   Calculer le nombre de conditionnement d'une matrice.
*   Mettre en place une simulation pour perturber les données d'entrée et observer les variations des solutions.
*   Utiliser des assertions pour valider numériquement la relation entre les erreurs relatives et le nombre de conditionnement.

## 2. Implémentation en Python

Le code Python ci-dessous démontre l'impact du conditionnement d'une matrice sur la stabilité de la solution d'un système linéaire $Ax=b$. Pour les opérations d'algèbre linéaire (résolution de système, calcul de norme, calcul de conditionnement), nous utiliserons la bibliothèque `numpy` comme cela est toléré dans l'énoncé, afin de nous concentrer sur la démonstration du concept plutôt que sur l'implémentation des algorithmes d'algèbre linéaire sous-jacents.

```python
import numpy as np

def resoudre_systeme_lineaire(A, b):
    """
    Résout le système linéaire Ax = b.

    Paramètres:
    A (array numpy): La matrice des coefficients.
    b (array numpy): Le vecteur second membre.

    Retourne:
    array numpy: Le vecteur solution x, ou None en cas d'erreur.
    """
    # Assurer que la matrice est carrée
    assert A.shape[0] == A.shape[1], "La matrice A doit être carrée."
    # Assurer que les dimensions sont compatibles
    assert A.shape[0] == b.shape[0], "Les dimensions de A et b ne sont pas compatibles."

    try:
        x = np.linalg.solve(A, b)
        # Vérification mathématique : A @ x doit être proche de b
        # np.allclose compare deux tableaux pour voir s'ils sont égaux élément par élément
        # dans une tolérance donnée. C'est crucial pour la comparaison de nombres flottants.
        assert np.allclose(np.dot(A, x), b), "La solution calculée ne satisfait pas Ax = b."
        return x
    except np.linalg.LinAlgError:
        print("Erreur : La matrice est singulière ou mal conditionnée, np.linalg.solve a échoué.")
        return None

def calculer_conditionnement(A):
    """
    Calcule le nombre de conditionnement d'une matrice A.

    Paramètres:
    A (array numpy): La matrice.

    Retourne:
    float: Le nombre de conditionnement de A (par défaut en norme 2).
           Un nombre très grand indique une matrice mal conditionnée.
    """
    return np.linalg.cond(A)

def demonstrer_sensibilite_systeme(A, b, perturbation_magnitude=1e-6):
    """
    Démontre la sensibilité de la solution x à une petite perturbation de b
    pour le système Ax = b.

    Paramètres:
    A (array numpy): La matrice des coefficients.
    b (array numpy): Le vecteur second membre original.
    perturbation_magnitude (float): L'amplitude maximale de la perturbation à appliquer à b.
    """
    print(f"\n--- Démonstration pour une matrice de taille {A.shape[0]}x{A.shape[1]} ---")
    print(f"Matrice A:\n{A}")
    print(f"Vecteur b original:\n{b}")

    # 1. Résoudre le système original
    x_original = resoudre_systeme_lineaire(A, b)
    if x_original is None:
        return

    print(f"Solution x_original:\n{x_original}")

    # 2. Calculer le nombre de conditionnement
    cond_A = calculer_conditionnement(A)
    print(f"Nombre de conditionnement de A (cond(A)) : {cond_A:.2e}")

    # 3. Appliquer une petite perturbation aléatoire à b
    # Création d'un vecteur de perturbation aléatoire de même taille que b,
    # avec des valeurs entre -perturbation_magnitude et +perturbation_magnitude.
    delta_b = (np.random.rand(*b.shape) * 2 - 1) * perturbation_magnitude
    b_perturbe = b + delta_b
    print(f"Vecteur de perturbation delta_b (norme ||delta_b|| = {np.linalg.norm(delta_b):.2e}):\n{delta_b}")
    print(f"Vecteur b perturbé (b_perturbe):\n{b_perturbe}")

    # 4. Résoudre le système perturbé
    x_perturbe = resoudre_systeme_lineaire(A, b_perturbe)
    if x_perturbe is None:
        return

    print(f"Solution x_perturbe:\n{x_perturbe}")

    # 5. Analyser les erreurs
    erreur_x = x_perturbe - x_original
    norme_erreur_x = np.linalg.norm(erreur_x) # ||delta_x||
    norme_x_original = np.linalg.norm(x_original) # ||x||
    norme_b_original = np.linalg.norm(b) # ||b||

    print(f"\nNorme de la perturbation sur b (||delta_b||) : {np.linalg.norm(delta_b):.2e}")
    print(f"Norme de la perturbation sur x (||delta_x||) : {norme_erreur_x:.2e}")

    # Calcul des erreurs relatives
    erreur_relative_b = np.linalg.norm(delta_b) / norme_b_original if norme_b_original != 0 else float('inf')
    erreur_relative_x = norme_erreur_x / norme_x_original if norme_x_original != 0 else float('inf')

    print(f"Erreur relative sur b (||delta_b|| / ||b||) : {erreur_relative_b:.2e}")
    print(f"Erreur relative sur x (||delta_x|| / ||x||) : {erreur_relative_x:.2e}")

    # Vérification de la relation fondamentale du conditionnement
    # La théorie nous dit que : ||delta_x|| / ||x|| <= cond(A) * (||delta_b|| / ||b||)
    # C'est une borne supérieure. Le rapport observé (erreur_relative_x / erreur_relative_b)
    # doit être inférieur ou égal au conditionnement (à une petite tolérance près due aux
    # erreurs d'arrondi et au caractère parfois non exact de la borne dans la pratique numérique).
    produit_cond_erreur_b = cond_A * erreur_relative_b
    print(f"\nProduit cond(A) * (||delta_b|| / ||b||) : {produit_cond_erreur_b:.2e}")

    # Assertion pour valider la relation fondamentale
    # Nous ajoutons une petite tolérance multiplicative pour gérer les imprécisions numériques
    # et pour que l'assertion ne échoue pas sur des valeurs proches de la borne.
    tolerance_assertion = 1.1 # Marge de 10%

    # L'assertion vérifie que l'erreur relative sur la solution est bien bornée
    # par le produit du conditionnement et de l'erreur relative sur les données.
    # Ceci est la preuve numérique de l'amplification.
    assert erreur_relative_x <= produit_cond_erreur_b * tolerance_assertion, \
        (f"L'inégalité d'amplification de l'erreur est violée : {erreur_relative_x:.2e} > "
         f"{produit_cond_erreur_b:.2e} * {tolerance_assertion}")

    print("\n--- Analyse des résultats ---")
    if erreur_relative_b > 0:
        print(f"Ratio d'amplification observé (||delta_x||/||x||) / (||delta_b||/||b||) : {erreur_relative_x / erreur_relative_b:.2e}")
    else:
        print("Erreur relative sur b est nulle, impossible de calculer le ratio d'amplification.")
    print(f"Le nombre de conditionnement est de {cond_A:.2e}.")
    print("Si cond(A) est grand, une petite erreur relative sur b peut être amplifiée")
    print("en une grande erreur relative sur x, ce qui est validé par l'assertion.")

# --- Exemples de Matrices pour la Démonstration ---

print("=== Démonstration avec une Matrice Bien Conditionnée ===")
# Matrice A_bien_conditionnee : Diagonale dominante, déterminant non nul et assez grand.
# Son inverse est bien définie et ses éléments sont d'une magnitude similaire à A.
A_bien_conditionnee = np.array([[3.0, 1.0],
                                 [1.0, 2.0]])
b_bien_conditionne = np.array([5.0, 5.0])

demonstrer_sensibilite_systeme(A_bien_conditionnee, b_bien_conditionne, perturbation_magnitude=1e-6)

print("\n\n=== Démonstration avec une Matrice Mal Conditionnée ===")
# Matrice A_mal_conditionnee : Lignes presque linéairement dépendantes.
# Son déterminant est très proche de zéro, ce qui rend son inverse très grande.
# C'est un exemple classique de matrice de Hilbert ou proche d'une matrice singulière.
A_mal_conditionnee = np.array([[1.0, 1.000001],
                                [1.0, 1.000000]]) # Déterminant = 1*1 - 1*1.000001 = -0.000001
b_mal_conditionne = np.array([2.0, 2.0])

demonstrer_sensibilite_systeme(A_mal_conditionnee, b_mal_conditionne, perturbation_magnitude=1e-6)

print("\n\n=== Démonstration avec une Matrice Très Mal Conditionnée (encore plus proche de la singularité) ===")
# Matrice A_tres_mal_conditionnee : Encore plus proche de la singularité que la précédente.
# Le déterminant est encore plus petit, ce qui devrait augmenter le nombre de conditionnement.
A_tres_mal_conditionnee = np.array([[1.0, 1.0 + 1e-8],
                                     [1.0, 1.0]]) # Déterminant = 1*1 - 1*(1+1e-8) = -1e-8
b_tres_mal_conditionne = np.array([2.0, 2.0])

demonstrer_sensibilite_systeme(A_tres_mal_conditionnee, b_tres_mal_conditionne, perturbation_magnitude=1e-6)
