### TP 5 : Distance de Jaccard sur les ensembles

L'espace des parties d'un ensemble fini peut être muni d'une distance. La distance de Jaccard est fondamentale en data science pour mesurer la dissimilarité entre des ensembles (comme des paniers d'achat ou des documents textuels).

```python
def distance_jaccard(ens1, ens2):
    # ens1 et ens2 sont des ensembles Python (set)
    intersection = ens1.intersection(ens2)
    union = ens1.union(ens2)

    # Gestion du cas limite des ensembles vides
    if len(union) == 0:
        return 0.0

    similarite = len(intersection) / len(union)

    # La distance est le complement de la similarite
    return 1.0 - similarite

# Test des axiomes de la metrique
A = {"apple", "banana", "cherry"}
B = {"banana", "cherry", "date"}
C = {"apple", "date", "fig"}

# 1. Separation
assert distance_jaccard(A, A) == 0.0

# 2. Symetrie
assert distance_jaccard(A, B) == distance_jaccard(B, A)

# 3. Inegalite triangulaire
d_AB = distance_jaccard(A, B)
d_BC = distance_jaccard(B, C)
d_AC = distance_jaccard(A, C)

# Note: d_AB = 1 - 2/4 = 0.5
# d_BC = 1 - 1/5 = 0.8
# d_AC = 1 - 1/5 = 0.8
assert d_AC <= d_AB + d_BC, "Echec de l'inegalite triangulaire"

print(f"Distance de Jaccard entre A et B : {d_AB}")
print("L'espace des ensembles muni de Jaccard est bien un espace metrique.")
```
