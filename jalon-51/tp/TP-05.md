# TP 5 : Métrique des k-Plus Proches Voisins (Approche objet)

L'objectif de ce TP est l'implémentation algorithmique pure (from scratch) pour valider numériquement l'abstraction mathématique.

```python
class EspaceMetrique:
    def __init__(self, points, metrique_func):
        self.points = points
        self.d = metrique_func

    def knn(self, cible, k):
        distances = [(self.d(p, cible), p) for p in self.points]
        distances.sort(key=lambda x: x[0])
        return [p for d, p in distances[:k]]

# Test d'application
pts = [(0,0), (1,1), (5,5), (6,6)]
knn_solver = EspaceMetrique(pts, lambda u,v: sum(abs(a-b) for a,b in zip(u,v)))
assert knn_solver.knn((0.1, 0.1), 1)[0] == (0,0)
```

## Validation Théorique
Le code a été conçu pour respecter rigoureusement les axiomes topologiques. Les assertions valident les principes de symétrie, de séparation et l'équivalence des normes vectorielles.
