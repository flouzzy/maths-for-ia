# TP-05 : Distance de Hausdorff entre ensembles discrets


## 1. Objectif

La distance de Hausdorff permet de mesurer la distance entre deux sous-ensembles (et non des points isolés) d'un espace métrique. Elle est très utilisée en vision par ordinateur pour comparer des contours d'images. Ce TP l'implémente pour des ensembles finis de points dans le plan 2D.

## 2. Code Python

```python
import math

def distance_euclidienne(p1: tuple, p2: tuple) -> float:
    return math.sqrt((p1[0] - p2[0])**2 + (p1[1] - p2[1])**2)

def distance_point_ensemble(p: tuple, ensemble: list) -> float:
    """
    Calcule la distance minimale entre un point p et un ensemble de points.
    """
    if not ensemble:
        return float('inf')
    return min(distance_euclidienne(p, q) for q in ensemble)

def distance_hausdorff(A: list, B: list) -> float:
    """
    Calcule la distance de Hausdorff entre deux ensembles discrets A et B.
    """
    if not A or not B:
        raise ValueError("Les ensembles doivent être non vides.")

    # sup(inf(d(a,b))) pour a dans A, b dans B
    d_A_vers_B = max(distance_point_ensemble(a, B) for a in A)
    # sup(inf(d(a,b))) pour b dans B, a dans A
    d_B_vers_A = max(distance_point_ensemble(b, A) for b in B)

    return max(d_A_vers_B, d_B_vers_A)

# Validation
# Ensemble A : points sur l'axe X
A = [(0, 0), (1, 0), (2, 0)]
# Ensemble B : points très proches de A, décalés de 0.5 en Y
B = [(0, 0.5), (1, 0.5), (2, 0.5)]
# Ensemble C : un point éloigné
C = [(10, 10)]

d_AB = distance_hausdorff(A, B)
assert abs(d_AB - 0.5) < 1e-9, f"Distance A-B incorrecte: {d_AB}"

d_AC = distance_hausdorff(A, C)
# Le point de A le plus loin de C(10,10) est (0,0). d((0,0), (10,10)) = sqrt(200)
expected_AC = math.sqrt(200)
assert abs(d_AC - expected_AC) < 1e-9, f"Distance A-C incorrecte: {d_AC}"

# Vérification symétrie
assert distance_hausdorff(A, B) == distance_hausdorff(B, A)

print("TP-05 validé : Distance de Hausdorff implémentée avec succès.")
```
