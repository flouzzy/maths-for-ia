# TP 2 : Métrique Euclidienne et de Manhattan

L'objectif de ce TP est l'implémentation algorithmique pure (from scratch) pour valider numériquement l'abstraction mathématique.

```python
import math

def dist_L2(u, v):
    return math.sqrt(sum((a-b)**2 for a,b in zip(u,v)))

def dist_L1(u, v):
    return sum(abs(a-b) for a,b in zip(u,v))

assert dist_L2((0,0), (3,4)) == 5.0
assert dist_L1((0,0), (3,4)) == 7.0
```

## Validation Théorique
Le code a été conçu pour respecter rigoureusement les axiomes topologiques. Les assertions valident les principes de symétrie, de séparation et l'équivalence des normes vectorielles.
