## TP 2 : Génération de nuages de points et vérification d'équivalence

Dans ce TP, nous simulons un grand nombre de points aléatoires pour observer la relation d'équivalence entre la norme L1 et L2 en dimension n.

```python
import random

def generate_random_vector(dim, bound=10.0):
    return [random.uniform(-bound, bound) for _ in range(dim)]

def distance_l1(u, v):
    return sum(abs(x - y) for x, y in zip(u, v))

def distance_l2(u, v):
    return sum((x - y)**2 for x, y in zip(u, v)) ** 0.5

if __name__ == "__main__":
    dim = 5
    n_samples = 1000

    c1_empirique = float('inf')
    c2_empirique = 0.0

    for _ in range(n_samples):
        u = generate_random_vector(dim)
        v = generate_random_vector(dim)

        d1 = distance_l1(u, v)
        d2 = distance_l2(u, v)

        if d2 > 0:
            ratio = d1 / d2
            if ratio < c1_empirique:
                c1_empirique = ratio
            if ratio > c2_empirique:
                c2_empirique = ratio

    # Theoriquement: L2 <= L1 <= sqrt(dim) * L2
    # Donc L1/L2 est encadre par [1, sqrt(dim)]
    print(f"Dimension: {dim}")
    print(f"Borne theorique min : 1.0, observee : {c1_empirique}")
    print(f"Borne theorique max : {dim**0.5}, observee : {c2_empirique}")
```
