### TP 2 : Distance de Levenshtein (Métrique sur les chaînes de caractères)

L'espace des mots forme un espace métrique abstrait. La distance de Levenshtein (ou distance d'édition) vérifie les trois axiomes et permet de quantifier la proximité orthographique entre deux mots.

```python
def distance_levenshtein(s1, s2):
    # Initialisation de la matrice des distances
    m, n = len(s1), len(s2)
    dp = [[0 for _ in range(n + 1)] for _ in range(m + 1)]

    # Conditions aux limites (distance avec la chaine vide)
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Remplissage par programmation dynamique
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cout_substitution = 0 if s1[i - 1] == s2[j - 1] else 1

            dp[i][j] = min(
                dp[i - 1][j] + 1,               # Effacement
                dp[i][j - 1] + 1,               # Insertion
                dp[i - 1][j - 1] + cout_substitution  # Substitution
            )

    return dp[m][n]

# Tests et validation des axiomes
mot1 = "chien"
mot2 = "chat"
mot3 = "chou"

# Axiome 1: Separation
assert distance_levenshtein(mot1, mot1) == 0

# Axiome 2: Symetrie
assert distance_levenshtein(mot1, mot2) == distance_levenshtein(mot2, mot1)

# Axiome 3: Inegalite triangulaire
d_12 = distance_levenshtein(mot1, mot2)
d_23 = distance_levenshtein(mot2, mot3)
d_13 = distance_levenshtein(mot1, mot3)

assert d_13 <= d_12 + d_23, "L'inegalite triangulaire a echoue"

print(f"Distance entre {mot1} et {mot2} : {d_12}")
print("La metrique de Levenshtein est valide.")
```
