# TP-02 : K-Nearest Neighbors (K-NN) pur python


## 1. Objectif

Le Machine Learning repose sur l'évaluation des similarités. L'algorithme K-NN classe une observation en regardant la classe majoritaire de ses k plus proches voisins selon une métrique donnée. Ce TP propose d'implémenter K-NN sans aucune bibliothèque externe pour comprendre l'impact fondamental de la distance choisie.

## 2. Code Python

```python
def distance_euclidienne(x: list, y: list) -> float:
    return sum((a - b) ** 2 for a, b in zip(x, y)) ** 0.5

def knn_predict(train_X: list, train_y: list, new_x: list, k: int, metric_func=distance_euclidienne) -> int:
    """
    Prédit la classe de new_x basée sur les k plus proches voisins dans train_X.
    """
    # Calcul des distances entre new_x et tous les points d'entraînement
    distances = []
    for i, x_train in enumerate(train_X):
        d = metric_func(new_x, x_train)
        distances.append((d, train_y[i]))

    # Tri par distance croissante
    distances.sort(key=lambda item: item[0])

    # Sélection des k plus proches
    k_nearest = distances[:k]

    # Vote majoritaire
    counts = {}
    for _, classe in k_nearest:
        counts[classe] = counts.get(classe, 0) + 1

    # Trouver la classe avec le plus de votes
    prediction = max(counts.items(), key=lambda item: item[1])[0]
    return prediction

# Jeu de données jouet (2D)
X_train = [
    [1.0, 2.0], [1.5, 1.8], [2.0, 1.0], # Classe 0 (en bas à gauche)
    [8.0, 8.0], [8.5, 9.0], [9.0, 8.5]  # Classe 1 (en haut à droite)
]
y_train = [0, 0, 0, 1, 1, 1]

# Test d'un point proche de la classe 0
point_test_1 = [2.5, 2.5]
pred_1 = knn_predict(X_train, y_train, point_test_1, k=3)
assert pred_1 == 0, f"Erreur: prédit {pred_1} au lieu de 0"

# Test d'un point proche de la classe 1
point_test_2 = [7.0, 7.5]
pred_2 = knn_predict(X_train, y_train, point_test_2, k=3)
assert pred_2 == 1, f"Erreur: prédit {pred_2} au lieu de 1"

print("TP-02 validé : K-NN opérationnel.")
```
