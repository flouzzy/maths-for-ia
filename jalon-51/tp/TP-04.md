### TP 4 : Simulation de la Topologie Discrète

Ce TP illustre la topologie discrète en construisant une structure de données qui vérifie empiriquement que dans cet espace métrique particulier, l'intersection de voisinages reste isolée.

```python
def distance_discrete(x, y):
    # La metrique par excellence des espaces discretises
    if x == y:
        return 0
    else:
        return 1

def generer_boule_ouverte(espace, centre, rayon):
    # Renvoie la liste des points dans la boule ouverte B(centre, rayon)
    boule = []
    for pt in espace:
        if distance_discrete(centre, pt) < rayon:
            boule.append(pt)
    return boule

# Un espace de travail arbitraire (pouvant representer des etats disjoints)
X = ["Etat_A", "Etat_B", "Etat_C", "Etat_D"]

# Pour r = 0.5 (r <= 1), la boule ne contient que le centre
b_petite = generer_boule_ouverte(X, "Etat_B", 0.5)
assert b_petite == ["Etat_B"], "Erreur : la boule de rayon < 1 n'est pas un singleton"

# Pour r = 2.0 (r > 1), la boule contient tout l'espace
b_grande = generer_boule_ouverte(X, "Etat_B", 2.0)
assert len(b_grande) == len(X), "Erreur : la boule de rayon > 1 ne contient pas tout X"

print("La topologie discrete est validee : chaque point est son propre ouvert.")
```
