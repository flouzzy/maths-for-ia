# TP-04 : Distance cosinus pour l'analyse sémantique


## 1. Objectif

En intelligence artificielle, notamment en NLP, la norme des vecteurs (longueur du texte) est souvent moins importante que l'angle entre eux (thématique). La similarité cosinus mesure le cosinus de l'angle. Pour obtenir une véritable distance métrique (vérifiant l'inégalité triangulaire), on utilise la distance angulaire : d(u,v) = arccos(cos_sim) / PI.

## 2. Code Python

```python
import math

def dot_product(v1: list, v2: list) -> float:
    return sum(a * b for a, b in zip(v1, v2))

def norm(v: list) -> float:
    return math.sqrt(sum(a * a for a in v))

def distance_angulaire(v1: list, v2: list) -> float:
    """
    Calcule la distance angulaire normalisée [0, 1] entre deux vecteurs.
    """
    n1, n2 = norm(v1), norm(v2)
    if n1 == 0 or n2 == 0:
        raise ValueError("Les vecteurs doivent être non nuls.")

    cos_sim = dot_product(v1, v2) / (n1 * n2)
    # Prévention des erreurs de précision flottante hors du domaine [-1, 1]
    cos_sim = max(-1.0, min(1.0, cos_sim))

    # Distance angulaire normalisée par pi
    return math.acos(cos_sim) / math.pi

# Vecteurs thématiques jouets
# v1 et v2 sont très similaires (presque colinéaires)
v1 = [1.0, 2.0, 0.1]
v2 = [2.0, 4.0, 0.2]
# v3 est orthogonal à v1
v3 = [-2.0, 1.0, 0.0]

# 1. Symétrie
assert abs(distance_angulaire(v1, v3) - distance_angulaire(v3, v1)) < 1e-9

# 2. Séparation pour l'angle (v1 et v2 sont colinéaires, distance angulaire = 0)
d_12 = distance_angulaire(v1, v2)
assert d_12 < 1e-5, f"La distance angulaire de vecteurs colinéaires devrait être 0, obtenu {d_12}"

# 3. Orthogonalité
d_13 = distance_angulaire(v1, v3)
# cos_sim est proche de 0, acos(0) = pi/2, normalisé = 0.5
assert abs(d_13 - 0.5) < 1e-5

print("TP-04 validé : Distance angulaire implémentée et vérifiée.")
```
