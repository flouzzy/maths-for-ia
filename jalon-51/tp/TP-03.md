# TP-03 : Distance de Levenshtein (Édition sur les mots)


## 1. Objectif

Les espaces métriques ne se limitent pas aux vecteurs numériques. La distance de Levenshtein quantifie la différence entre deux chaînes de caractères en comptant le nombre minimal d'insertions, suppressions ou substitutions nécessaires pour passer de l'une à l'autre. Elle respecte les axiomes métriques et est centrale en bio-informatique (alignement ADN) et en NLP (correction orthographique).

## 2. Code Python

```python
def levenshtein(s1: str, s2: str) -> int:
    """
    Calcule la distance de Levenshtein entre s1 et s2 via programmation dynamique.
    """
    m, n = len(s1), len(s2)
    # Matrice des distances : dp[i][j] = distance entre s1[:i] et s2[:j]
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Initialisation
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Remplissage
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if s1[i-1] == s2[j-1] else 1
            dp[i][j] = min(
                dp[i-1][j] + 1,      # Suppression
                dp[i][j-1] + 1,      # Insertion
                dp[i-1][j-1] + cost  # Substitution
            )

    return dp[m][n]

# Tests et validations mathématiques
mot1 = "chien"
mot2 = "chiens"
mot3 = "chat"

# 1. Séparation
assert levenshtein(mot1, mot1) == 0

# 2. Symétrie
assert levenshtein(mot1, mot3) == levenshtein(mot3, mot1)

# 3. Inégalité triangulaire
d13 = levenshtein(mot1, mot3)
d12 = levenshtein(mot1, mot2)
d23 = levenshtein(mot2, mot3)
assert d13 <= d12 + d23, "L'inégalité triangulaire n'est pas respectée."

# Test de valeur connue
# "chien" -> "chat" : substituer 'i'->'a', 'e'->'t', supprimer 'n' => 3 opérations
assert levenshtein("chien", "chat") == 3

print("TP-03 validé : Distance de Levenshtein implémentée et vérifiée.")
```
