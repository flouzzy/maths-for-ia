### TP 3 : Algorithme des K-Plus Proches Voisins (k-NN) sur un espace métrique

Application directe de l'espace métrique en IA : la classification par K-NN repose entièrement sur l'évaluation des distances entre les points. Ce TP implémente la recherche des k voisins et le vote majoritaire.

```python
def distance_euclidienne(p1, p2):
    return sum((a - b) ** 2 for a, b in zip(p1, p2)) ** 0.5

def knn_classifier(train_data, train_labels, test_point, k):
    # Calcul des distances entre test_point et tous les points d'entrainement
    distances = []
    for i in range(len(train_data)):
        dist = distance_euclidienne(test_point, train_data[i])
        distances.append((dist, train_labels[i]))

    # Tri par distance croissante (le coeur de la notion topologique de voisinage)
    distances.sort(key=lambda x: x[0])

    # Extraction des k plus proches voisins
    k_voisins = distances[:k]

    # Vote majoritaire pour la classification
    compteurs = {}
    for _, label in k_voisins:
        compteurs[label] = compteurs.get(label, 0) + 1

    classe_predite = max(compteurs, key=compteurs.get)
    return classe_predite

# Jeu de donnees d'entrainement (x, y) et labels (classes 0 ou 1)
X_train = [[1, 2], [1.5, 1.8], [5, 8], [8, 8], [1, 0.6], [9, 11]]
y_train = [0, 0, 1, 1, 0, 1]

# Point a classer
nouveau_point = [2, 2]

# Prediction avec k=3
prediction = knn_classifier(X_train, y_train, nouveau_point, 3)

assert prediction == 0, "Le point [2, 2] devrait etre proche de la classe 0"
print(f"Le point {nouveau_point} a ete classe dans la categorie {prediction}")
```
