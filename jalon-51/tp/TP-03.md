## TP 3 : La distance discrète et topologie

Implémentation d'une distance discrète sur des chaînes de caractères (symboles).

```python
def distance_discrete(x, y):
    '''Distance valant 0 si x==y, 1 sinon.'''
    if x == y:
        return 0.0
    else:
        return 1.0

if __name__ == "__main__":
    mots = ["chat", "chien", "chat", "oiseau"]

    # Verification des axiomes sur tous les triplets possibles
    for x in mots:
        for y in mots:
            for z in mots:
                d_xy = distance_discrete(x, y)
                d_yz = distance_discrete(y, z)
                d_xz = distance_discrete(x, z)

                # Separation
                if d_xy == 0:
                    assert x == y

                # Symetrie
                assert d_xy == distance_discrete(y, x)

                # Triangulaire
                assert d_xz <= d_xy + d_yz

    print("Tous les axiomes de la distance discrete sont verifies sur l'ensemble de mots.")
```
