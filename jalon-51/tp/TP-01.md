# TP-01 : Implémentation des distances de Minkowski


## 1. Objectif

L'objectif de ce TP est d'implémenter de zéro la famille des distances de Minkowski sur des vecteurs de dimension n. Cette famille généralise la distance de Manhattan (p=1), la distance Euclidienne (p=2) et la distance de Tchebychev (p tend vers l'infini). Nous vérifierons algorithmiquement les axiomes de séparation, symétrie et inégalité triangulaire.

## 2. Code Python

```python
import math

def distance_minkowski(x: list, y: list, p: float) -> float:
    """
    Calcule la distance de Minkowski d'ordre p entre deux vecteurs x et y.
    Si p = float('inf'), calcule la distance de Tchebychev.
    """
    if len(x) != len(y):
        raise ValueError("Les vecteurs doivent avoir la même dimension.")

    if p == float('inf'):
        return max(abs(a - b) for a, b in zip(x, y))

    if p < 1:
        raise ValueError("L'ordre p doit être >= 1 pour définir une distance.")

    somme = sum(abs(a - b) ** p for a, b in zip(x, y))
    return somme ** (1.0 / p)

def verifier_axiomes(x: list, y: list, z: list, p: float):
    """
    Vérifie numériquement les trois axiomes d'une métrique.
    """
    tol = 1e-9

    # 1. Séparation
    d_xx = distance_minkowski(x, x, p)
    assert d_xx < tol, "Échec de la séparation (d(x,x)=0)"

    # 2. Symétrie
    d_xy = distance_minkowski(x, y, p)
    d_yx = distance_minkowski(y, x, p)
    assert abs(d_xy - d_yx) < tol, "Échec de la symétrie"

    # 3. Inégalité triangulaire
    d_xz = distance_minkowski(x, z, p)
    d_yz = distance_minkowski(y, z, p)
    assert d_xz <= d_xy + d_yz + tol, "Échec de l'inégalité triangulaire"

    return True

# Validation
x = [1.0, 5.0, -3.0]
y = [4.0, 2.0, 1.0]
z = [-1.0, 0.0, 5.0]

# Vérification pour p=1 (Manhattan)
assert verifier_axiomes(x, y, z, 1)
assert abs(distance_minkowski(x, y, 1) - (3 + 3 + 4)) < 1e-9

# Vérification pour p=2 (Euclidienne)
assert verifier_axiomes(x, y, z, 2)

# Vérification pour p=infini (Tchebychev)
assert verifier_axiomes(x, y, z, float('inf'))
assert abs(distance_minkowski(x, y, float('inf')) - max(3, 3, 4)) < 1e-9

print("TP-01 validé : Implémentation des distances de Minkowski correcte.")
```
