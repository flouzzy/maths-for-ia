# TP 02 : Implémentation du XOR avec une couche cachée (Théorème d'existence)

**Objectif :** Validation du concept : une couche cachée permet de plier l'espace et séparer les classes.

```python
def relu(x):
    return max(0, x)

def hidden_layer_predict(x1, x2):
    # Weights hand-picked to act as a logic gate solver
    # Hidden Node 1: AND gate (active if both are 1)
    h1 = relu(x1 + x2 - 1.5)
    # Hidden Node 2: OR gate (active if at least one is 1)
    h2 = relu(x1 + x2 - 0.5)

    # Output layer: OR XOR logic -> OR gate minus AND gate
    # We want +1 weight for OR, -2 weight for AND (to cancel the OR activation when both are 1)
    output_raw = h2 - 2 * h1
    return 1 if output_raw >= 0.5 else 0

def test_xor():
    assert hidden_layer_predict(0, 0) == 0
    assert hidden_layer_predict(1, 0) == 1
    assert hidden_layer_predict(0, 1) == 1
    assert hidden_layer_predict(1, 1) == 0
    print("XOR successfully solved using a hidden layer.")

test_xor()
```
