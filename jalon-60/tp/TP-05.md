# TP 05 : Échec de l'approximation par une fonction non bornée sur R

**Objectif :** Validation mathématique de l'Exo 9 montrant pourquoi le théorème ne tient que sur un sous-ensemble compact.

```python
import math

def run_unbounded_failure_test():
    # Attempting to approximate f(x) = x^2 on the whole real line R using bounded sigmoids
    # We construct a network bounded by M (sum of absolute output weights)

    N = 10 # 10 neurons
    # Let's say all output weights are maxed at an absolute value of 10 for instance
    alpha_weights = [10.0] * N

    M = sum(abs(a) for a in alpha_weights) # Total bound M = 100.0

    # The network output is G(x) = sum(alpha_i * sigmoid(w_i x + b_i))
    # Since sigmoid is in (0, 1), the absolute max output of the network anywhere in R is strictly bounded by M

    max_network_output = M

    # Choose an x far away such that x^2 is massively larger than M
    x_eval = 20.0
    f_x = x_eval ** 2 # 400.0

    # The minimum possible error at x_eval is:
    min_error_at_x = f_x - max_network_output

    assert min_error_at_x > 0, "The unbounded function must escape the network's bounded envelope"
    assert min_error_at_x == 300.0
    print(f"Unbounded failure validated. Network clamped at {max_network_output}, function reaches {f_x}. Universal approximation fails globally on R.")

run_unbounded_failure_test()
```
