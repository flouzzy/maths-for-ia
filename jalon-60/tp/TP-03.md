# TP 3 : La Malédiction de la dimension (Curse of Dimensionality)

Nous allons démontrer numériquement que le nombre de points d'échantillonnage requis pour paver un espace de dimension $D$ avec un pas fixe croît de manière exponentielle.

## Code Python Rigoureux

```python
import math

def calculate_grid_points(dimensions: int, resolution_per_dim: int) -> int:
    # Calcule le nombre de hyper-cubes nécessaires pour paver l'espace.
    return resolution_per_dim ** dimensions

def main():
    print("Démonstration mathématique : Croissance exponentielle du volume")
    resolution = 10 # 10 points par axe pour obtenir une bonne approximation

    dims = [1, 2, 3, 5, 10, 20]

    for d in dims:
        points = calculate_grid_points(d, resolution)
        print(f"Dimension {d} : {points} points requis.")

    assert calculate_grid_points(10, 10) == 10**10, "Erreur arithmétique de dimensionnalité"

    print("\nConclusion : Pour un réseau peu profond, approximer une fonction en dimension 20")
    print("demanderait un nombre absurde de neurones si l'on cherche à paver l'espace uniformément.")
    print("TP 3 Validé.")

if __name__ == "__main__":
    main()
```
