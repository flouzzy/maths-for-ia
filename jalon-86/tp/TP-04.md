# TP 4 : Le supremum d'une suite de variables aléatoires

L'objectif de ce TP est de manipuler informatiquement les concepts de mesurabilité, de loi image, de tribu engendrée ou de composition.

## Code Python `from scratch`

```python
def tp_4_supremum():
    # Simulation du théorème : sup(X_n) est une variable aléatoire.
    # On simule l'égalité ensembliste : {sup X_n > a} = Union {X_n > a}

    omega = list(range(100)) # Univers abstrait

    # Suite de variables aléatoires (ici 5 pour l'exemple)
    import random
    random.seed(42)
    variables_Xn = [lambda w, i=i: (w * i) % 30 for i in range(1, 6)]

    # Z = sup X_n
    def Z(w):
        return max(Xn(w) for Xn in variables_Xn)

    a = 15 # Seuil arbitraire

    # Calcul de {Z > a}
    evenement_Z_sup_a = set(w for w in omega if Z(w) > a)

    # Calcul de Union {X_n > a}
    union_Xn_sup_a = set()
    for Xn in variables_Xn:
        union_Xn_sup_a.update(w for w in omega if Xn(w) > a)

    # Validation
    assert evenement_Z_sup_a == union_Xn_sup_a, "L'égalité des tribus n'est pas respectée!"
    print("TP 4 : Égalité ensembliste validée. Le supremum conserve la mesurabilité.")

if __name__ == '__main__':
    tp_4_supremum()
```
