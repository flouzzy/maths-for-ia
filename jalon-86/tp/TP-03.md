# TP 3 : Mesurabilité et composition de variables aléatoires (Théorème 2)

L'objectif de ce TP est de manipuler informatiquement les concepts de mesurabilité, de loi image, de tribu engendrée ou de composition.

## Code Python `from scratch`

```python
import math

def tp_3_composition():
    # Omega continu discrétisé pour la simulation
    omega = [x/100.0 for x in range(-100, 101)] # [-1.0, 1.0]

    # X est une variable aléatoire mesurable (l'identité ici)
    def X(w):
        return w

    # g est une fonction mesurable (borélienne) : carrée
    def g(x):
        return x**2

    # Y est la composition
    def Y(w):
        return g(X(w))

    # Vérifions que l'image réciproque d'un borélien par Y est bien dans la tribu d'origine.
    # Prenons le borélien B = [0, 0.25]. L'image réciproque doit être [-0.5, 0.5]
    b_min, b_max = 0.0, 0.25

    image_reciproque_Y = [w for w in omega if b_min <= Y(w) <= b_max]
    image_reciproque_theorique = [w for w in omega if -0.5 <= X(w) <= 0.5]

    # Validation
    assert image_reciproque_Y == image_reciproque_theorique, "Le théorème de composition échoue!"
    print("TP 3 : Composition validée. Y^{-1}(B) = X^{-1}(g^{-1}(B)).")

if __name__ == '__main__':
    tp_3_composition()
```
