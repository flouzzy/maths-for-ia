# TP 3 : Théorème de la transformée inverse (Méthode de l'inverse)

Nous programmons la méthode d'inversion pour simuler une variable aléatoire exponentielle à partir d'une loi uniforme. Pour une loi exponentielle de paramètre lambda, la fonction de répartition est $F(x) = 1 - e^{-\lambda x}$ et son inverse est $F^{-1}(u) = -\ln(1-u) / \lambda$.

```python
import random
import math

def generate_exponential(lam, num_samples):
    samples = []
    for _ in range(num_samples):
        # 1. Tirage de U uniforme dans ]0, 1] (pour eviter ln(0))
        u = 1.0 - random.random()
        # 2. Application de l'inverse de la fonction de repartition
        x = -math.log(u) / lam
        samples.append(x)
    return samples

def test_inverse_transform():
    lam = 2.0
    samples = generate_exponential(lam, 10000)

    # Validation par l'esperance theorique E[X] = 1/lambda
    emp_mean = sum(samples) / len(samples)
    theoretical_mean = 1.0 / lam

    assert abs(emp_mean - theoretical_mean) < 0.05, "L'esperance empirique ne correspond pas a la theorie."
    print("TP 3 : Tests passes.")

if __name__ == "__main__":
    test_inverse_transform()
```
