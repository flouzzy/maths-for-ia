# TP 5 : Simulation du théorème de l'inversion de la fonction de répartition

L'objectif de ce TP est de manipuler informatiquement les concepts de mesurabilité, de loi image, de tribu engendrée ou de composition.

## Code Python `from scratch`

```python
import random

def tp_5_inversion():
    # Génération d'une loi complexe à partir d'une loi uniforme (U)
    # But : Créer une variable exponentielle via Y = F^{-1}(U)

    lambd = 1.5 # Paramètre de la loi exponentielle
    # La fonction de répartition inverse de l'exponentielle est : -ln(1-u)/lambda
    import math
    def F_inverse(u):
        return -math.log(1 - u) / lambd

    N = 50000
    echantillons_Y = []

    for _ in range(N):
        # Tirage dans la loi uniforme (variable mesurable de base)
        u = random.random()
        # Transformation mesurable
        y = F_inverse(u)
        echantillons_Y.append(y)

    # Validation de l'espérance théorique (1/lambda)
    esperance_theorique = 1.0 / lambd
    esperance_empirique = sum(echantillons_Y) / N

    assert abs(esperance_empirique - esperance_theorique) < 0.05, "L'espérance ne correspond pas à la loi cible."
    print(f"TP 5 : Transformation validée. Espérance théorique {esperance_theorique:.4f}, Empirique {esperance_empirique:.4f}.")

if __name__ == '__main__':
    tp_5_inversion()
```
