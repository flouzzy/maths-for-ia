# TP 5 : Mesurabilité de la fonction Sup

Nous avons démontré théoriquement que si $X$ et $Y$ sont des variables aléatoires, alors $Z = \max(X, Y)$ est aussi une variable aléatoire. Nous simulons ici sa fonction de répartition empirique.

```python
import random

def test_sup_random_variables():
    n = 10000
    # X, Y uniformes sur [0, 1]
    X = [random.uniform(0, 1) for _ in range(n)]
    Y = [random.uniform(0, 1) for _ in range(n)]

    # Variable Z = max(X, Y)
    Z = [max(X[i], Y[i]) for i in range(n)]

    # On sait par independance que F_Z(z) = P(max(X,Y) <= z)
    # = P(X <= z et Y <= z) = P(X <= z)P(Y <= z) = z^2 pour z dans [0,1]

    z_test = 0.5
    f_empirique = sum(1 for z in Z if z <= z_test) / n
    f_theorique = z_test**2 # 0.25

    assert abs(f_empirique - f_theorique) < 0.02, "La loi du Max ne correspond pas a la theorie independante."
    print("TP 5 : Tests passes.")

if __name__ == "__main__":
    test_sup_random_variables()
```
