# TP 1 : Simulation de l'image inverse et vérification de la loi empirique

L'objectif de ce TP est de manipuler informatiquement les concepts de mesurabilité, de loi image, de tribu engendrée ou de composition.

## Code Python `from scratch`

```python
import random
import math

def tp_1_loi_image():
    # 1. Définition de l'espace de probabilité abstrait Omega (univers fini)
    # Lancer de deux dés à 6 faces.
    omega = [(d1, d2) for d1 in range(1, 7) for d2 in range(1, 7)]
    prob_omega = 1.0 / len(omega)

    # 2. Définition d'une variable aléatoire X : Omega -> R
    # X = Somme des deux dés
    def X(event):
        return event[0] + event[1]

    # 3. Calcul de la loi image théorique P_X
    loi_X = {}
    for event in omega:
        val = X(event)
        loi_X[val] = loi_X.get(val, 0) + prob_omega

    # 4. Simulation empirique (Loi des grands nombres)
    N_simulations = 50000
    compteurs = {}
    for _ in range(N_simulations):
        evenement_tire = random.choice(omega)
        valeur_x = X(evenement_tire)
        compteurs[valeur_x] = compteurs.get(valeur_x, 0) + 1

    print(f"Validation TP 1:")
    for k, v in sorted(compteurs.items()):
        prob_emp = v / N_simulations
        assert abs(prob_emp - loi_X[k]) < 0.05, f"Erreur pour la valeur {k}"

    print("TP 1 : La loi empirique correspond à la loi théorique image. Validation réussie.")

if __name__ == '__main__':
    tp_1_loi_image()
```
