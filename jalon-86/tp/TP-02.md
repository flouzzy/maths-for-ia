# TP 2 : Tribu engendrée par une variable aléatoire simple

L'objectif de ce TP est de manipuler informatiquement les concepts de mesurabilité, de loi image, de tribu engendrée ou de composition.

## Code Python `from scratch`

```python
def tp_2_tribu_engendree():
    # 1. Univers : Une main de 3 cartes tirées parmi As(1), Roi(13), Dame(12), Valet(11)
    cartes = [1, 11, 12, 13]
    omega = [(c1, c2, c3) for c1 in cartes for c2 in cartes for c3 in cartes]

    # 2. Variable aléatoire X : nombre d'As dans la main
    def X(event):
        return event.count(1)

    # 3. Calcul des atomes de la tribu engendrée sigma(X)
    # Les atomes sont les ensembles de la forme X^{-1}(k)
    atomes = {}
    for event in omega:
        val = X(event)
        if val not in atomes:
            atomes[val] = []
        atomes[val].append(event)

    # 4. Validation
    # La tribu est formée par toutes les unions possibles de ces atomes.
    # Vérifions que les atomes forment bien une partition de Omega.
    total_events_in_atomes = sum(len(atome) for atome in atomes.values())
    assert total_events_in_atomes == len(omega), "Les atomes ne partitionnent pas l'univers!"

    intersection_test = set(atomes[0]).intersection(set(atomes[1]))
    assert len(intersection_test) == 0, "Les atomes ne sont pas disjoints!"

    print("TP 2 : Tribu engendrée calculée et vérifiée. Partition validée.")

if __name__ == '__main__':
    tp_2_tribu_engendree()
```
