# TP 2 : Vérification de la fonction de répartition

La fonction de répartition $F_X(x) = P(X \leq x)$ caractérise la loi. Nous allons construire la fonction de répartition empirique et vérifier ses propriétés (croissante, limite en 1).

```python
import random

def empirical_cdf(data, x):
    # Compte le nombre d'elements inferieurs ou egaux a x
    count = sum(1 for d in data if d <= x)
    return count / len(data)

def test_empirical_cdf():
    # Generation de donnees (simulation de VA uniforme)
    data = [random.uniform(-5, 5) for _ in range(1000)]

    # Proprietes de la fonction de repartition
    f_moins_10 = empirical_cdf(data, -10)
    f_plus_10 = empirical_cdf(data, 10)

    # Doit etre croissante
    f_0 = empirical_cdf(data, 0)
    f_2 = empirical_cdf(data, 2)

    assert f_moins_10 == 0.0, "La limite en -inf doit etre 0."
    assert f_plus_10 == 1.0, "La limite en +inf doit etre 1."
    assert f_0 <= f_2, "La fonction de repartition doit etre croissante."
    print("TP 2 : Tests passes.")

if __name__ == "__main__":
    test_empirical_cdf()
```
