# TP 1 : Simulation de la Loi Forte des Grands Nombres pour un dé équilibré

## Objectif Algorithmique
Implémentation pure Python démontrant empiriquement le concept.

## Code Python

```python
def simuler_de(n):
    '''Simule n lancers d'un dé à 6 faces à l'aide d'un générateur congruentiel linéaire simple.'''
    # Générateur pseudo-aléatoire LCG pour ne pas dépendre de bibliothèques externes complexes
    x = 123456789
    resultats = []
    for _ in range(n):
        x = (1103515245 * x + 12345) % (2**31)
        # Normalisation entre 1 et 6
        de = (x % 6) + 1
        resultats.append(de)
    return resultats

def moyenne_empirique(resultats):
    '''Calcule la moyenne d'une liste de résultats.'''
    somme = 0
    for val in resultats:
        somme += val
    return somme / len(resultats)

if __name__ == '__main__':
    n_lancers = 100000
    tirages = simuler_de(n_lancers)
    moyenne = moyenne_empirique(tirages)

    # L'espérance mathématique d'un dé est 3.5
    esperance = 3.5

    # On vérifie que la moyenne empirique est très proche de l'espérance
    ecart = abs(moyenne - esperance)
    print('Moyenne empirique pour', n_lancers, 'lancers :', moyenne)
    assert ecart < 0.05, 'La loi forte n\'est pas respectée dans cette simulation.'
    print('TP1 validé : La moyenne converge vers l\'espérance théorique.')
```
