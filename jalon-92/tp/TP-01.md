## Contexte Mathématique : La Loi Forte des Grands Nombres (LFGN)

Chers étudiants,

Aujourd'hui, nous allons explorer l'un des théorèmes fondamentaux de la théorie des probabilités : la Loi Forte des Grands Nombres (LFGN). Ce théorème est la pierre angulaire de nombreuses applications statistiques et de la compréhension de la convergence des moyennes empiriques.

Considérons une suite de variables aléatoires $X_1, X_2, \dots, X_n$ indépendantes et identiquement distribuées (i.i.d.), possédant une espérance finie $E[X_i] = \mu$. La moyenne empirique (ou moyenne échantillon) est définie comme :

$$ \bar{X}_n = \frac{1}{n} \sum_{i=1}^n X_i $$

La Loi Forte des Grands Nombres stipule que, sous certaines conditions (notamment l'existence de l'espérance), la moyenne empirique $\bar{X}_n$ converge presque sûrement vers l'espérance $\mu$ lorsque $n$ tend vers l'infini. En d'autres termes :

$$ \bar{X}_n \xrightarrow{p.s.} \mu \quad \text{quand} \quad n \to \infty $$

Cela signifie que la probabilité que $\bar{X}_n$ ne converge pas vers $\mu$ est nulle. C'est un résultat puissant qui justifie l'utilisation des moyennes d'échantillons pour estimer des paramètres de population.

Pour ce TP, nous allons illustrer ce concept avec une variable aléatoire de Bernoulli, qui modélise le succès ou l'échec d'une expérience unique (comme un lancer de pièce). Une variable de Bernoulli $X$ prend la valeur 1 avec une probabilité $p$ (succès) et 0 avec une probabilité $1-p$ (échec). Son espérance est simplement $E[X] = p$.

## Implémentation Python

Voici le squelette de l'implémentation que vous devrez compléter et exécuter.

```python
import random
import math

def simuler_bernoulli(p):
    """
    Simule une variable de Bernoulli.
    Retourne 1 avec probabilité p, 0 avec probabilité (1-p).

    Args:
        p (float): La probabilité de succès (doit être entre 0 et 1).

    Returns:
        int: 1 pour succès, 0 pour échec.
    """
    assert isinstance(p, (int, float)), "La probabilité p doit être un nombre."
    assert 0.0 <= p <= 1.0, "La probabilité p doit être entre 0 et 1."

    if random.random() < p:
        return 1
    else:
        return 0

def executer_simulation_lfgn(probabilite_succes, max_tirages, pas_affichage=100):
    """
    Exécute une simulation pour illustrer la LFGN avec une variable de Bernoulli.

    Args:
        probabilite_succes (float): La probabilité p de la variable de Bernoulli.
        max_tirages (int): Le nombre maximal de tirages à simuler.
        pas_affichage (int): Intervalle pour afficher les résultats intermédiaires.
    """
    assert isinstance(probabilite_succes, (int, float)), "La probabilité de succès doit être un nombre."
    assert 0.0 <= probabilite_succes <= 1.0, "La probabilité de succès doit être entre 0 et 1."
    assert isinstance(max_tirages, int), "Le nombre maximal de tirages doit être un entier."
    assert max_tirages > 0, "Le nombre maximal de tirages doit être positif."
    assert isinstance(pas_affichage, int), "Le pas d'affichage doit être un entier."
    assert pas_affichage > 0, "Le pas d'affichage doit être positif."
    assert pas_affichage <= max_tirages, "Le pas d'affichage ne peut pas être supérieur au nombre max de tirages."

    somme_resultats = 0
    print(f"Simulation de la LFGN pour p = {probabilite_succes}")
    print("-" * 50)
    print(f"{'Nombre de tirages':<20} | {'Moyenne empirique':<20} | {'Écart à p':<15}")
    print("-" * 50)

    for n in range(1, max_tirages + 1):
        resultat = simuler_bernoulli(probabilite_succes)
        somme_resultats += resultat
        moyenne_empirique = somme_resultats / n

        if n % pas_affichage == 0 or n == max_tirages:
            ecart_a_p = abs(moyenne_empirique - probabilite_succes)
            print(f"{n:<20} | {moyenne_empirique:<20.6f} | {ecart_a_p:<15.6f}")

    print("-" * 50)
    print(f"Simulation terminée. Moyenne finale après {max_tirages} tirages : {moyenne_empirique:.6f}")
    print(f"Probabilité théorique (espérance) p : {probabilite_succes:.6f}")

if __name__ == "__main__":
    # Paramètres de la simulation
    p_theorique = 0.6  # Probabilité de succès pour notre variable de Bernoulli
    nombre_max_tirages = 100000 # Nombre total de tirages pour la simulation
    intervalle_affichage = 5000 # Afficher les résultats tous les 5000 tirages

    # Exécution de la simulation
    executer_simulation_lfgn(p_theorique, nombre_max_tirages, intervalle_affichage)

    # Test des assertions (exemples de cas d'erreur)
    try:
        simuler_bernoulli(1.5)
    except AssertionError as e:
        print(f"\nTest d'assertion réussi pour simuler_bernoulli(1.5): {e}")

    try:
        executer_simulation_lfgn(0.5, 0)
    except AssertionError as e:
        print(f"Test d'assertion réussi pour executer_simulation_lfgn(0.5, 0): {e}")
```

## Analyse des Résultats Attendus

Lorsque vous exécuterez le code ci-dessus, vous observerez une série de moyennes empiriques calculées après un nombre croissant de tirages.

Initialement, pour un petit nombre de tirages, la moyenne empirique peut fluctuer considérablement et s'éloigner de la probabilité théorique `p_theorique`. C'est tout à fait normal, car l'échantillon est trop petit pour être représentatif.

Cependant, à mesure que le nombre de tirages (`n`) augmente, vous remarquerez que :
1.  La moyenne empirique tend à se stabiliser.
2.  Cette valeur stabilisée se rapproche de plus en plus de la probabilité théorique `p_theorique` (l'espérance de notre variable de Bernoulli).
3.  La colonne "Écart à p" montrera une diminution progressive, indiquant que la différence absolue entre la moyenne empirique et la probabilité théorique diminue.

Cette convergence est précisément ce que la Loi Forte des Grands Nombres prédit : la moyenne observée sur un grand nombre d'expériences indépendantes converge vers l'espérance théorique de la variable aléatoire. C'est une illustration concrète de la façon dont la régularité émerge du hasard sur le long terme.

Vous pouvez expérimenter en modifiant `p_theorique` (par exemple, 0.1 ou 0.9) et `nombre_max_tirages` pour voir comment ces paramètres influencent la vitesse et la précision de la convergence. Plus `nombre_max_tirages` est grand, plus la moyenne empirique finale sera proche de `p_theorique`.
