# TP 4 : La Convergence Presque Sûre : Une Illustration de la Loi Forte des Grands Nombres avec Bernoulli

## Contexte Mathématique : La Loi Forte des Grands Nombres

La Loi Forte des Grands Nombres (LFGN) est un théorème fondamental de la théorie des probabilités. Elle établit que, sous certaines conditions, la moyenne empirique d'une suite de variables aléatoires indépendantes et identiquement distribuées (i.i.d.) converge "presque sûrement" vers l'espérance mathématique de ces variables.

Plus précisément, si nous avons une suite de variables aléatoires `X_1, X_2, ..., X_n, ...` qui sont i.i.d. et possèdent une espérance finie `E[X]`, alors la moyenne empirique `M_n` définie par :

`M_n = (X_1 + X_2 + ... + X_n) / n`

converge presque sûrement vers `E[X]` lorsque `n` tend vers l'infini. La convergence "presque sûre" est une forme de convergence très forte, signifiant que la probabilité que `M_n` ne converge *pas* vers `E[X]` est nulle.

Pour ce TP, nous allons illustrer ce concept en utilisant une distribution de Bernoulli. Une variable de Bernoulli `X` prend la valeur 1 avec une probabilité `p` et la valeur 0 avec une probabilité `1-p`. Son espérance est `E[X] = p`. Nous simulerons une longue séquence de tirages de Bernoulli et observerons comment la moyenne des résultats se rapproche de `p`.

## Objectif du TP

L'objectif est d'implémenter en Python pur une simulation de la Loi Forte des Grands Nombres pour une suite de variables de Bernoulli. Vous devrez générer une longue séquence de tirages de Bernoulli, calculer la moyenne empirique à chaque étape `n`, et observer la convergence de cette moyenne vers l'espérance théorique `p`.

## Implémentation Python

Vous devez écrire le code Python `from scratch`, en utilisant uniquement les modules `math` et `random`. Aucune autre bibliothèque de haut niveau (comme `numpy`, `scipy`, `pandas`) n'est autorisée. Le code doit inclure des assertions pour valider les entrées.

```python
import random
import math

def simuler_bernoulli(p):
    """
    Simule un tirage d'une variable de Bernoulli.

    Args:
        p (float): La probabilité de succès (doit être entre 0 et 1).

    Returns:
        int: 1 pour un succès, 0 pour un échec.
    """
    assert isinstance(p, (int, float)), "La probabilité p doit être un nombre."
    assert 0.0 <= p <= 1.0, "La probabilité p doit être entre 0 et 1."

    if random.random() < p:
        return 1
    else:
        return 0

def simuler_lfgn_bernoulli(p, nombre_tirages):
    """
    Simule la Loi Forte des Grands Nombres pour une suite de variables de Bernoulli.

    Args:
        p (float): La probabilité de succès pour chaque tirage de Bernoulli.
        nombre_tirages (int): Le nombre total de tirages à simuler.

    Returns:
        list: Une liste des moyennes empiriques à chaque étape n.
    """
    assert isinstance(p, (int, float)), "La probabilité p doit être un nombre."
    assert 0.0 <= p <= 1.0, "La probabilité p doit être entre 0 et 1."
    assert isinstance(nombre_tirages, int), "Le nombre de tirages doit être un entier."
    assert nombre_tirages > 0, "Le nombre de tirages doit être positif."

    somme_cumulee = 0
    moyennes_empiriques = []

    for n in range(1, nombre_tirages + 1):
        resultat_tirage = simuler_bernoulli(p)
        somme_cumulee += resultat_tirage
        moyenne_actuelle = somme_cumulee / n
        moyennes_empiriques.append(moyenne_actuelle)

    return moyennes_empiriques

# --- Exécution de la simulation ---
if __name__ == "__main__":
    probabilite_p = 0.6  # Espérance théorique E[X] = p
    nombre_simulations = 10000 # Nombre de tirages pour observer la convergence

    print(f"Simulation de la LFGN pour une variable de Bernoulli avec p = {probabilite_p}")
    print(f"Nombre total de tirages : {nombre_simulations}")

    resultats_moyennes = simuler_lfgn_bernoulli(probabilite_p, nombre_simulations)

    # Affichage des premières et dernières moyennes pour observer la convergence
    print("\nPremières moyennes empiriques (début de la simulation) :")
    for i in range(min(10, len(resultats_moyennes))):
        print(f"M_{i+1} = {resultats_moyennes[i]:.4f}")

    print("\n...")

    print(f"\nDernières moyennes empiriques (fin de la simulation) :")
    for i in range(max(0, len(resultats_moyennes) - 10), len(resultats_moyennes)):
        print(f"M_{i+1} = {resultats_moyennes[i]:.4f}")

    print(f"\nMoyenne empirique finale (M_{nombre_simulations}) : {resultats_moyennes[-1]:.4f}")
    print(f"Espérance théorique (p) : {probabilite_p:.4f}")

    # Exemple d'assertion pour vérifier la convergence approximative à la fin
    # Note : La convergence est presque sûre, pas déterministe pour un nombre fini de tirages.
    # Cette assertion est illustrative et peut échouer si le nombre de tirages est trop faible
    # ou si la chance joue un rôle inhabituel.
    tolerance = 0.05
    assert abs(resultats_moyennes[-1] - probabilite_p) < tolerance, \
        f"La moyenne finale {resultats_moyennes[-1]:.4f} n'est pas assez proche de {probabilite_p:.4f}."
    print(f"\nAssertion de convergence approximative réussie (tolérance {tolerance}).")
```

## Analyse des Résultats Attendus

Lorsque vous exécutez le code avec un nombre suffisant de tirages (par exemple, 10 000 ou plus), vous devriez observer le comportement suivant :

1.  **Fluctuations Initiales :** Les premières moyennes empiriques (M_1, M_2, M_3, ...) peuvent varier considérablement. Il est tout à fait normal que M_1 soit 0 ou 1, M_2 soit 0, 0.5 ou 1, etc. La moyenne est très sensible aux premiers tirages.
2.  **Stabilisation Progressive :** Au fur et à mesure que le nombre de tirages `n` augmente, les fluctuations des moyennes empiriques devraient diminuer. La suite `M_n` devrait se stabiliser et se rapprocher de plus en plus de la valeur de `p` (l'espérance théorique).
3.  **Convergence Finale :** La dernière moyenne empirique calculée (`M_nombre_simulations`) devrait être très proche de la probabilité `p` que vous avez définie. Plus le nombre de tirages est grand, plus cette moyenne finale devrait être proche de `p`.

Ce comportement illustre directement la Loi Forte des Grands Nombres : la moyenne des observations converge vers l'espérance de la variable aléatoire sous-jacente. La convergence "presque sûre" signifie que, si nous pouvions répéter cette simulation un nombre infini de fois, la proportion de simulations où la moyenne ne converge pas vers `p` serait nulle. Pour un nombre fini de tirages, nous observons une forte tendance vers cette convergence.
