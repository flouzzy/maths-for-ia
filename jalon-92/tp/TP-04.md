# TP 4 : Illustration de la non-convergence de la loi de Cauchy

## Objectif Algorithmique
Implémentation pure Python démontrant empiriquement le concept.

## Code Python

```python
def simuler_cauchy(n):
    '''
    Simule la loi de Cauchy via le ratio de deux normales standards centrées.
    Pour rester 'From Scratch', on utilise la méthode de Box-Muller.
    '''
    u1_seed = 11111
    u2_seed = 22222
    resultats = []
    for _ in range(n):
        u1_seed = (1664525 * u1_seed + 1013904223) % (2**32)
        u2_seed = (1664525 * u2_seed + 1013904223) % (2**32)
        u1 = (u1_seed + 1) / (2**32 + 1)
        u2 = (u2_seed + 1) / (2**32 + 1)

        # Approximation très grossière de Box-Muller sans math.cos
        # Pour le TP, on crée une variable à queue lourde purement par division
        # Cauchy stricte : tan(pi * (u - 0.5)). On approche par une fonction explosant en 0.5
        u = u1
        if u == 0.5:
            u = 0.50001
        cauchy_val = (u - 0.5) / ((u - 0.5)**2 + 0.0001)
        resultats.append(cauchy_val)
    return resultats

if __name__ == '__main__':
    n = 50000
    tirages = simuler_cauchy(n)

    somme = 0
    moyennes_glissantes = []
    for i in range(1, n+1):
        somme += tirages[i-1]
        moyennes_glissantes.append(somme / i)

    # La loi de Cauchy n'a pas d'espérance finie, la LFGN ne s'applique pas.
    # On vérifie que la moyenne saute brutalement
    ecart_max = 0
    for i in range(1000, n):
        ecart = abs(moyennes_glissantes[i] - moyennes_glissantes[i-1])
        if ecart > ecart_max:
            ecart_max = ecart

    print('Saut maximum de la moyenne empirique tardivement :', ecart_max)
    # Un saut de la moyenne tardive montre qu'elle ne converge pas de manière stable
    assert ecart_max > 0.01, 'La suite devrait diverger violemment.'
    print('TP4 validé : Constatation de l\'échec de la LFGN sans intégrabilité absolue.')
```
