# TP 03 : La distribution de Cauchy et l'échec de la LFGN

La loi de Cauchy ne possède pas d'espérance. La moyenne empirique ne doit donc pas converger.

```python
import math
import random

def random_cauchy():
    # Genere une variable aleatoire suivant une loi de Cauchy standard.
    # On utilise l'inversion de la fonction de repartition.
    u = random.random()
    # F(x) = 1/2 + 1/pi * arctan(x) => x = tan(pi * (u - 1/2))
    return math.tan(math.pi * (u - 0.5))

def test_cauchy():
    n = 10000
    total = 0
    for i in range(1, n + 1):
        total += random_cauchy()

    mean = total / n
    print(f"Moyenne empirique (Cauchy) apres {n} echantillons : {mean}")

    print("TP03 Execute: Observez que la valeur de la moyenne ne se stabilise pas pres de 0.")

if __name__ == '__main__':
    test_cauchy()
```
