# TP 3 : L'Étreinte Asymptotique : Simulation de la Loi Forte des Grands Nombres avec une Variable de Bernoulli

## Contexte Mathématique : La Loi Forte des Grands Nombres (LFGN)

La Loi Forte des Grands Nombres est un théorème fondamental en théorie des probabilités qui décrit le comportement à long terme de la moyenne d'une suite de variables aléatoires. En termes simples, elle affirme que si l'on effectue un grand nombre d'expériences indépendantes et identiquement distribuées (i.i.d.), la moyenne des résultats observés (la fréquence empirique) convergera presque sûrement vers l'espérance mathématique (la moyenne théorique) de ces expériences.

Formellement, si $X_1, X_2, \dots$ sont des variables aléatoires i.i.d. avec une espérance finie $E[X_1] = \mu$, alors la moyenne empirique $\bar{X}_n = \frac{1}{n} \sum_{i=1}^n X_i$ converge presque sûrement vers $\mu$ lorsque $n \to \infty$. Cela signifie que la probabilité que $\bar{X}_n$ ne converge pas vers $\mu$ est nulle.

Pour ce TP, nous allons illustrer ce principe avec une variable de Bernoulli. Une variable de Bernoulli $X$ prend la valeur 1 avec une probabilité $p$ (succès) et la valeur 0 avec une probabilité $1-p$ (échec). Son espérance est $E[X] = 1 \cdot p + 0 \cdot (1-p) = p$. La LFGN nous dit donc que si nous répétons un grand nombre de fois une expérience de Bernoulli, la proportion de succès observés devrait se rapprocher de la probabilité théorique $p$.

## Objectif du TP

L'objectif est d'implémenter en Python une simulation de la Loi Forte des Grands Nombres en utilisant une variable de Bernoulli. Nous allons simuler un nombre croissant d'expériences de Bernoulli et observer comment la fréquence empirique des succès se rapproche de la probabilité théorique $p$ à mesure que le nombre d'expériences augmente.

Le code devra être entièrement écrit "from scratch", sans utiliser de bibliothèques de calcul scientifique de haut niveau (comme NumPy ou SciPy). Seules les bibliothèques `math` et `random` sont autorisées. Des assertions seront utilisées pour valider les entrées et les sorties des fonctions.

## Implémentation Python

```python
import random
import math

def simuler_bernoulli(probabilite_succes):
    """
    Simule une seule expérience de Bernoulli.

    Args:
        probabilite_succes (float): La probabilité d'obtenir un succès (1).
                                    Doit être entre 0 et 1 inclus.

    Returns:
        int: 1 pour un succès, 0 pour un échec.
    """
    assert 0.0 <= probabilite_succes <= 1.0, "La probabilité de succès doit être entre 0 et 1."

    if random.random() < probabilite_succes:
        return 1
    else:
        return 0

def calculer_moyenne_empirique(probabilite_succes, nombre_experiences):
    """
    Calcule la moyenne empirique (fréquence de succès) sur un nombre donné d'expériences de Bernoulli.

    Args:
        probabilite_succes (float): La probabilité d'obtenir un succès (1) pour chaque expérience.
        nombre_experiences (int): Le nombre total d'expériences à simuler.
                                  Doit être un entier positif.

    Returns:
        float: La moyenne empirique des résultats (proportion de succès).
    """
    assert nombre_experiences > 0, "Le nombre d'expériences doit être un entier positif."
    assert isinstance(nombre_experiences, int), "Le nombre d'expériences doit être un entier."

    somme_succes = 0
    for _ in range(nombre_experiences):
        somme_succes += simuler_bernoulli(probabilite_succes)

    moyenne = somme_succes / nombre_experiences
    assert 0.0 <= moyenne <= 1.0, "La moyenne empirique doit être entre 0 et 1."
    return moyenne

def main_simulation():
    """
    Fonction principale pour exécuter la simulation de la LFGN.
    """
    probabilite_theorique = 0.65 # La probabilité 'p' de notre variable de Bernoulli
    print(f"Probabilité théorique (p) : {probabilite_theorique}\n")

    # Différents nombres d'expériences pour observer la convergence
    nombres_experiences = [10, 100, 1000, 10000, 100000, 1000000]

    print("--- Simulation de la Loi Forte des Grands Nombres ---")
    for n in nombres_experiences:
        moyenne_observee = calculer_moyenne_empirique(probabilite_theorique, n)
        print(f"Pour N = {n:<7}, Moyenne empirique observée : {moyenne_observee:.6f}")
        # Vérification simple que la moyenne est dans une plage raisonnable
        assert abs(moyenne_observee - probabilite_theorique) < 0.5, \
            f"La moyenne observée {moyenne_observee} est trop éloignée de la probabilité théorique {probabilite_theorique} pour N={n}."

    print("\n--- Fin de la simulation ---")

if __name__ == "__main__":
    main_simulation()

```

## Analyse des Résultats Attendus

Lorsque vous exécuterez le code ci-dessus, vous devriez observer une tendance claire :

1.  **Petits nombres d'expériences (N faible)** : Pour un petit nombre d'expériences (par exemple, N=10 ou N=100), la moyenne empirique observée peut varier considérablement par rapport à la probabilité théorique `p` (ici 0.65). Les fluctuations aléatoires sont très présentes. Il est même possible d'obtenir des moyennes de 0.0 ou 1.0 si N est très petit.

2.  **Grands nombres d'expériences (N élevé)** : À mesure que le nombre d'expériences `N` augmente (N=10000, N=100000, N=1000000), la moyenne empirique observée devrait se rapprocher de plus en plus de la probabilité théorique `p`. L'écart entre la moyenne observée et `p` devrait diminuer progressivement.

Cette convergence est précisément ce que la Loi Forte des Grands Nombres prédit. Elle nous assure que, bien que le résultat d'une seule expérience soit incertain, la moyenne d'un très grand nombre d'expériences indépendantes est prévisible et tend vers l'espérance mathématique. C'est un principe fondamental qui sous-tend de nombreuses applications, de la statistique à l'apprentissage automatique, en passant par la physique statistique.

Vous remarquerez que même pour N=1 000 000, la moyenne observée ne sera probablement pas *exactement* égale à la probabilité théorique, mais elle en sera très proche, avec une différence souvent visible seulement à la troisième ou quatrième décimale ou au-delà. C'est la nature de la convergence "presque sûre" : la probabilité de s'en écarter significativement devient infime, mais une déviation minime reste possible.
