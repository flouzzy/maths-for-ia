# TP 01 : Implémentation de Taylor (Exponentielle)

## Objectif
Implémenter la série de Taylor pour l'exponentielle $e^x$ sans aucune librairie externe et évaluer l'erreur d'approximation en comparant avec le développement fini.

## Code Python
```python
def factorial(n: int) -> int:
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

def taylor_exp(x: float, order: int) -> float:
    \"\"\"Calcule l'approximation de e^x en 0 à l'ordre donné.\"\"\"
    result = 0.0
    for k in range(order + 1):
        result += (x ** k) / factorial(k)
    return result

def test_taylor():
    # Validation
    x_val = 1.0
    approx = taylor_exp(x_val, 10)
    # e^1 ~ 2.7182818
    assert abs(approx - 2.7182818) < 1e-6, "Erreur trop grande pour l'exponentielle."
    print("TP 01 Validé: exp(1) approx =", approx)

if __name__ == "__main__":
    test_taylor()
```
