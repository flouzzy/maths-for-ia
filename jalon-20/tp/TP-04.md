# TP 04 : Extrapolation de Richardson

## Objectif
Utiliser le développement de Taylor pour construire une approximation numérique de la dérivée qui est d'ordre supérieur (erreur en $O(h^4)$) sans dériver analytiquement, en annulant les termes d'erreur de bas degré.

## Code Python
```python
def f(x: float) -> float:
    # Fonction de test: f(x) = x^3, f'(x) = 3x^2
    return x ** 3

def diff_centree(func, x: float, h: float) -> float:
    # Erreur en O(h^2)
    return (func(x + h) - func(x - h)) / (2 * h)

def richardson_extrapolation(func, x: float, h: float) -> float:
    # Annule l'erreur en O(h^2) pour obtenir du O(h^4)
    D_h = diff_centree(func, x, h)
    D_h_half = diff_centree(func, x, h / 2)
    return (4 * D_h_half - D_h) / 3

def test_richardson():
    x_val = 2.0
    true_deriv = 12.0 # 3*(2^2)
    h = 0.5 # Un h assez grand

    approx = richardson_extrapolation(f, x_val, h)
    assert abs(approx - true_deriv) < 1e-10, "L'extrapolation de Richardson n'a pas atteint la précision attendue."
    print("TP 04 Validé: f'(2) approx =", approx)

if __name__ == "__main__":
    test_richardson()
```
