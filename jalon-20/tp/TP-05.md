# TP 05 : Validation du Reste de Lagrange

## Objectif
Pour la fonction $f(x) = \ln(1+x)$, calculer l'erreur exacte entre la valeur réelle et le polynôme de Taylor d'ordre $n$, puis vérifier numériquement qu'il existe un $c \in ]0, x[$ validant la formule de Taylor-Lagrange.

## Code Python
```python
import math

def taylor_ln_1_plus_x(x: float, order: int) -> float:
    # sum_{k=1}^n (-1)^(k-1) x^k / k
    result = 0.0
    for k in range(1, order + 1):
        result += ((-1)**(k - 1) * x**k) / k
    return result

def verif_lagrange_ln():
    x = 0.5
    order = 3

    # f(x) = ln(1+x)
    true_val = math.log(1 + x)
    poly_val = taylor_ln_1_plus_x(x, order)

    # Erreur exacte
    error = true_val - poly_val

    # Reste de Lagrange d'ordre 3 (dérivée 4ème)
    # f^(4)(c) = -6 / (1+c)^4
    # Reste = f^(4)(c)/4! * x^4 = (-6 / (1+c)^4) / 24 * x^4 = -1/4 * x^4 / (1+c)^4

    # On sait que l'erreur doit être ce reste pour un c dans ]0, x[
    # Isolons c: error = -0.25 * (x^4) / (1+c)^4
    # (1+c)^4 = -0.25 * (x^4) / error

    val = -0.25 * (x**4) / error
    assert val > 0, "L'erreur n'a pas le bon signe par rapport à la théorie."

    c = val**(0.25) - 1

    assert 0 < c < x, f"Le c calculé ({c}) n'est pas dans l'intervalle ]0, {x}["
    print(f"TP 05 Validé: Le théorème est vérifié avec c = {c:.4f} in ]0, {x}[")

if __name__ == "__main__":
    verif_lagrange_ln()
```
