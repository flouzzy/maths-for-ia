# TP 03 : Composition Numérique de DL

## Objectif
Créer une fonction capable d'évaluer le DL d'une fonction composée, spécifiquement $e^{\sin(x)}$ évalué en un point, en se basant sur les implémentations précédentes.

## Code Python
```python
def factorial(n: int) -> int:
    return 1 if n <= 1 else n * factorial(n - 1)

def taylor_sin(x: float, terms: int) -> float:
    return sum([((-1)**n * (x**(2*n+1)) / factorial(2*n+1)) for n in range(terms)])

def taylor_exp(x: float, order: int) -> float:
    return sum([(x**k / factorial(k)) for k in range(order+1)])

def compose_taylor_exp_sin(x: float, inner_terms: int, outer_order: int) -> float:
    # 1. Évaluer la fonction interne
    inner_val = taylor_sin(x, inner_terms)
    # 2. Passer le résultat à la fonction externe
    return taylor_exp(inner_val, outer_order)

def test_compose():
    x_val = 0.1
    # Vraie valeur exp(sin(0.1)) ~ exp(0.0998334) ~ 1.10498
    approx = compose_taylor_exp_sin(x_val, 3, 4)
    assert abs(approx - 1.10498) < 1e-4, "L'approximation composée est incorrecte."
    print("TP 03 Validé: exp(sin(0.1)) approx =", approx)

if __name__ == "__main__":
    test_compose()
```
