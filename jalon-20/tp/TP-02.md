# TP 02 : Taylor du Sinus

## Objectif
La série de Taylor de $\sin(x)$ est alternée et ne comporte que des termes impairs. Coder spécifiquement ce développement limité et vérifier son exactitude autour de 0.

## Code Python
```python
def factorial(n: int) -> int:
    if n <= 1: return 1
    return n * factorial(n - 1)

def taylor_sin(x: float, terms: int) -> float:
    \"\"\"
    Calcule l'approximation de sin(x).
    'terms' indique le nombre de termes non nuls à calculer.
    \"\"\"
    result = 0.0
    for n in range(terms):
        power = 2 * n + 1
        sign = (-1) ** n
        result += sign * (x ** power) / factorial(power)
    return result

def test_sin():
    # Pour x = pi/6 ~ 0.52359877, sin(pi/6) = 0.5
    x_val = 0.52359877
    approx = taylor_sin(x_val, 5) # Ordre jusqu'à 9
    assert abs(approx - 0.5) < 1e-5, "L'approximation du sinus a échoué."
    print("TP 02 Validé: sin(pi/6) approx =", approx)

if __name__ == "__main__":
    test_sin()
```
