# TP 4 : Série de Weierstrass (Continue mais non dérivable)

**Objectif :** Implémenter l'approximation de la célèbre fonction de Weierstrass et vérifier numériquement sa continuité tout en observant ses pentes extrêmes (qui violent la dérivabilité).

**Rappel théorique :**
$W(x) = \sum_{n=0}^\infty 2^{-n} \cos(3^n x)$ converge normalement sur $\mathbb{R}$. Elle est donc continue.

```python
import math

def W(x, max_n=30):
    total = 0.0
    for n in range(max_n):
        total += (2.0 ** (-n)) * math.cos((3.0 ** n) * x)
    return total

def test_continuity_empirical(x0, delta=1e-6):
    """
    Vérifie que f(x0+delta) est très proche de f(x0),
    mais que le taux d'accroissement (dérivée numérique) est potentiellement immense.
    """
    val_center = W(x0)
    val_right = W(x0 + delta)

    diff = abs(val_right - val_center)
    taux_accroissement = diff / delta

    return diff, taux_accroissement

def main():
    x0 = math.pi / 4

    # Test à différentes échelles microscopiques
    deltas = [1e-3, 1e-5, 1e-7, 1e-9]
    for d in deltas:
        diff, taux = test_continuity_empirical(x0, d)
        print(f"Delta: {d:.0e} | |f(x+d)-f(x)| = {diff:.6f} | Taux: {taux:.2f}")

        # La différence tend vers 0 (Continuité validée)
        assert diff < 1e-1, "La fonction devrait être continue"

    print("TP4 Validé : La fonction est continue (les petits écarts donnent de petites différences) mais le taux d'accroissement explose (non-dérivabilité).")

if __name__ == '__main__':
    main()
```
