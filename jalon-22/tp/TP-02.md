# TP 2 : Interversion Série-Intégrale (Méthode de Riemann)

**Objectif :** Implémenter l'intégration numérique d'une série de fonctions, et valider le théorème d'interversion de la limite (somme infinie) et de l'intégrale en Python pur.

**Rappel théorique :**
On sait par l'exercice 4 que $\int_0^1 \sum_{n=1}^\infty \frac{x^n}{n^3} dx = \sum_{n=1}^\infty \frac{1}{n^3(n+1)}$.
Nous allons calculer ces deux quantités séparément.

```python
def u_n(n, x):
    return (x**n) / (n**3)

def somme_infinie(x, max_n=100):
    total = 0.0
    for n in range(1, max_n + 1):
        total += u_n(n, x)
    return total

def integrate_rectangles(func, a, b, num_steps=10000):
    """
    Intégration numérique basique par la méthode des rectangles (point milieu).
    """
    step = (b - a) / num_steps
    total_area = 0.0
    for i in range(num_steps):
        x_mid = a + (i + 0.5) * step
        total_area += func(x_mid) * step
    return total_area

def somme_des_integrales(max_n=100):
    total = 0.0
    for n in range(1, max_n + 1):
        term = 1.0 / ((n**3) * (n + 1))
        total += term
    return total

def main():
    # 1. Calcul de l'intégrale de la somme (Interversion : intégrale à l'extérieur)
    # L'intégrande est la somme partielle d'ordre max_n
    integrale_de_la_somme = integrate_rectangles(lambda x: somme_infinie(x, max_n=50), 0, 1, num_steps=5000)

    # 2. Calcul de la somme des intégrales (Formule analytique dérivée théoriquement)
    somme_des_int = somme_des_integrales(max_n=50)

    print(f"Intégrale de la somme : {integrale_de_la_somme:.8f}")
    print(f"Somme des intégrales  : {somme_des_int:.8f}")

    # Vérification mathématique stricte
    assert abs(integrale_de_la_somme - somme_des_int) < 1e-5, "Le théorème d'interversion a échoué numériquement"
    print("TP2 Validé : Le théorème d'intégration terme à terme est vérifié.")

if __name__ == '__main__':
    main()
```
