# TP 5 : Application au traitement du signal (Série de Fourier)

**Objectif :** Synthétiser un signal carré à partir d'une série de fonctions harmoniques (Série de Fourier), et observer le phénomène de Gibbs (défaut de convergence uniforme aux points de discontinuité).

**Rappel théorique :**
Le signal carré impair $f(x)$ sur $[-\pi, \pi]$ valant $-1$ sur $]-\pi, 0[$ et $1$ sur $]0, \pi[$ a pour série de Fourier :
$S(x) = \frac{4}{\pi} \sum_{k=0}^\infty \frac{\sin((2k+1)x)}{2k+1}$.
Cette série converge simplement vers le signal carré (théorème de Dirichlet), mais la convergence n'est **pas** uniforme sur $[0, \pi]$ à cause de la discontinuité en 0.

```python
import math

def fouriers_square_wave(x, max_k):
    total = 0.0
    for k in range(max_k):
        n = 2 * k + 1
        total += math.sin(n * x) / float(n)
    return (4.0 / math.pi) * total

def get_peak_overshoot(max_k, num_points=1000):
    """
    Recherche le dépassement (overshoot) maximum près de la discontinuité en x=0.
    """
    max_val = 0.0
    # On cherche l'overshoot juste après le saut en 0
    step = (math.pi / 2.0) / num_points
    for i in range(1, num_points):
        x = i * step
        val = fouriers_square_wave(x, max_k)
        if val > max_val:
            max_val = val
    return max_val

def main():
    # Signal théorique max est 1.0.
    # Le phénomène de Gibbs prédit un dépassement d'environ 9% (soit ~1.09) qui ne disparaît jamais.

    ks = [10, 50, 100, 200]
    for k in ks:
        peak = get_peak_overshoot(k, num_points=5000)
        print(f"Max harmonique k={k:3d} : Peak = {peak:.5f}")

        # Le dépassement reste constant autour de 1.089...
        assert peak > 1.05, "Le phénomène de Gibbs devrait produire un dépassement (overshoot) constant > 1.05"

    print("TP5 Validé : Le phénomène de Gibbs empêche la convergence uniforme, le dépassement ne s'évanouit pas à l'infini.")

if __name__ == '__main__':
    main()
```
