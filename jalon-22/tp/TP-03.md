# TP 3 : La Bosse Glissante et le défaut d'interversion

**Objectif :** Recréer numériquement le contre-exemple classique (Exercice 10) démontrant l'échec de l'interversion limite/intégrale en l'absence de convergence uniforme.

**Rappel théorique :**
Soit $f_n(x) = n x e^{-n x^2}$.
Sur $[0, 1]$, la limite ponctuelle est $f(x)=0$, donc l'intégrale de la limite est $0$.
Cependant, l'intégrale de $f_n(x)$ tend vers $1/2$.
Nous allons visualiser ce phénomène d'aire constante échappant à la limite.

```python
import math

def f_n(n, x):
    return n * x * math.exp(-n * (x**2))

def integrate_simpson(func, a, b, num_intervals=10000):
    """
    Intégration numérique avec la méthode de Simpson (très précise) pure Python.
    """
    if num_intervals % 2 != 0:
        num_intervals += 1
    step = (b - a) / num_intervals

    res = func(a) + func(b)

    for i in range(1, num_intervals, 2):
        res += 4 * func(a + i * step)
    for i in range(2, num_intervals - 1, 2):
        res += 2 * func(a + i * step)

    return res * step / 3.0

def main():
    # Pour différentes valeurs de n, on calcule l'intégrale
    n_values = [10, 50, 100, 500]
    for n in n_values:
        integral_val = integrate_simpson(lambda x: f_n(n, x), 0.0, 1.0, 5000)
        max_val = f_n(n, 1.0 / math.sqrt(2 * n)) # Max theorique à 1/sqrt(2n)
        print(f"n={n:3d} | Integrale={integral_val:.6f} | Sup(f_n)={max_val:.2f}")

        # Validation que l'intégrale reste proche de 0.5 (1/2 * (1 - e^-n))
        assert abs(integral_val - 0.5) < 1e-2, "L'aire sous la bosse glissante devrait être 0.5"

    # Limite ponctuelle est nulle, l'intégrale de la limite est donc 0.0
    print("TP3 Validé : L'intégrale de la limite (0) est différente de la limite des intégrales (0.5), prouvant la nécessité de la CU.")

if __name__ == '__main__':
    main()
```
