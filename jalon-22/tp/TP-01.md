# TP 1 : Vérification empirique de la convergence uniforme

**Objectif :** Implémenter en Python pur le calcul des sommes partielles d'une série de fonctions et vérifier numériquement le critère de Cauchy uniforme (qui équivaut à la convergence uniforme).

**Rappel théorique :**
La série $\sum f_n$ converge uniformément sur $I$ si la suite des restes tend uniformément vers 0. Empiriquement, nous allons mesurer le supremum de l'écart entre $S_N(x)$ et la fonction limite $S(x)$ (ou une très grande somme partielle $S_{M}$ avec $M \gg N$).
Considérons la série géométrique $\sum x^n(1-x)$ sur $[0, 1]$ (qui ne converge pas uniformément) et sur $[0, 0.5]$ (où elle converge uniformément).

```python
import math

def f_n(n, x):
    return (x**n) * (1 - x)

def S_N(N, x):
    # Calcule la somme partielle d'ordre N manuellement
    total = 0.0
    for n in range(N + 1):
        total += f_n(n, x)
    return total

def test_uniform_convergence(interval_start, interval_end, num_points, N, M):
    """
    Mesure l'écart sup entre S_N et S_M (approximation de l'infini) sur un maillage de l'intervalle.
    """
    max_diff = 0.0
    step = (interval_end - interval_start) / (num_points - 1)

    for i in range(num_points):
        x = interval_start + i * step
        val_N = S_N(N, x)
        val_M = S_N(M, x)
        diff = abs(val_N - val_M)
        if diff > max_diff:
            max_diff = diff

    return max_diff

def main():
    # Test sur [0, 0.5] : doit converger uniformément (l'erreur max tend vers 0)
    err_05 = test_uniform_convergence(0.0, 0.5, 1000, 20, 200)
    print(f"Erreur max sur [0, 0.5] à N=20 : {err_05:.6f}")
    assert err_05 < 1e-4, "La convergence devrait être rapide et uniforme sur [0, 0.5]"

    # Test sur [0, 1.0] : ne converge pas uniformément (l'erreur max reste proche de 1)
    err_10 = test_uniform_convergence(0.0, 1.0, 1000, 20, 200)
    print(f"Erreur max sur [0, 1.0] à N=20 : {err_10:.6f}")
    assert err_10 > 0.1, "La convergence ne devrait PAS être uniforme sur [0, 1.0]"

    print("TP1 Validé : Les propriétés topologiques sont confirmées par le calcul empirique.")

if __name__ == '__main__':
    main()
```
