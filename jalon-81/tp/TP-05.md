# TP 5 : Convolution temporelle et produit spectral via Plancherel


Nous démontrons que l'opération de convolution dans le domaine temporel est strictement équivalente à une multiplication composante par composante dans le domaine spectral, une propriété fondamentale de la transformée unitaire L2.

```python
import cmath
import math

def dft(x):
    N = len(x)
    return [sum(x[n] * cmath.exp(complex(0, -2 * math.pi * k * n / N)) for n in range(N)) for k in range(N)]

def idft(X):
    N = len(X)
    return [(1/N) * sum(X[k] * cmath.exp(complex(0, 2 * math.pi * k * n / N)) for k in range(N)) for n in range(N)]

def circular_convolution(x, h):
    N = len(x)
    y = [0] * N
    for n in range(N):
        for m in range(N):
            y[n] += x[m] * h[(n - m) % N]
    return y

N = 8
# Signal et filtre
x = [1, 2, 3, 4, 0, 0, 0, 0]
h = [0.5, 0.5, 0, 0, 0, 0, 0, 0]

# 1. Convolution temporelle directe
y_temp = circular_convolution(x, h)

# 2. Convolution via le domaine spectral
X_freq = dft(x)
H_freq = dft(h)
# Multiplication spectrale
Y_freq = [X_freq[k] * H_freq[k] for k in range(N)]
# Retour en temporel
y_freq_inv = idft(Y_freq)

# Verification de l'egalite terme a terme (aux erreurs numeriques pres)
max_error = max(abs(y_temp[i] - y_freq_inv[i].real) for i in range(N))
print(f"Erreur maximale entre conv. directe et conv. spectrale : {max_error:.2e}")

assert max_error < 1e-10, "Le theoreme de convolution (Plancherel) est viole !"
```
