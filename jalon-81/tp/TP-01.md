# TP 1 : Calcul empirique de l'énergie et vérification de Plancherel

## Description
Implémentation d'une fonction de signal exponentiel et vérification de la conservation de l'énergie via l'approximation d'intégrales par la méthode des rectangles.

## Code Python
```python
def f(t):
    import math
    return math.exp(-abs(t))

def f_hat(xi):
    return 2.0 / (1.0 + xi**2)

def integrate(func, a, b, n_steps=100000):
    step = (b - a) / n_steps
    total = 0.0
    for i in range(n_steps):
        t = a + i * step + step / 2.0
        total += func(t)**2 * step
    return total

# The integral goes from -infinity to +infinity, we approximate with [-20, 20]
energy_time = integrate(f, -20, 20)
energy_freq = integrate(f_hat, -20, 20)

import math
# Verify Plancherel : ||f_hat||^2 = 2 * pi * ||f||^2
expected_freq_energy = 2 * math.pi * energy_time

assert abs(energy_freq - expected_freq_energy) < 0.1, "L'identite de Plancherel n'est pas verifiee numeriquement"
print("TP1: Identite de Plancherel verifiee avec succes.")

```
