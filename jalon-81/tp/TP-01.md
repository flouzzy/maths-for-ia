# TP 1 : Implémentation manuelle de la DFT et vérification de Parseval-Plancherel


Dans ce TP, nous allons implémenter la transformée de Fourier discrète (DFT) depuis zéro et vérifier l'égalité de Parseval, pendant discret de Plancherel, garantissant la conservation de l'énergie entre un signal 1D et son spectre.

```python
import cmath
import math

def dft(x):
    N = len(x)
    X = [0.0 + 0.0j] * N
    for k in range(N):
        sum_val = 0.0 + 0.0j
        for n in range(N):
            angle = -2 * math.pi * k * n / N
            sum_val += x[n] * cmath.exp(complex(0, angle))
        X[k] = sum_val
    return X

def signal_energy(x):
    return sum(abs(val)**2 for val in x)

# Signal test : une porte de largeur 4 dans un signal de taille 8
signal = [1, 1, 1, 1, 0, 0, 0, 0]

X_freq = dft(signal)

energy_temp = signal_energy(signal)
energy_freq = signal_energy(X_freq) / len(signal) # Facteur 1/N de Parseval discrète

print(f"Energie temporelle : {energy_temp}")
print(f"Energie frequentielle : {energy_freq}")

# Validation mathematique
assert math.isclose(energy_temp, energy_freq, rel_tol=1e-9), "Le theoreme de Parseval est viole !"
```
