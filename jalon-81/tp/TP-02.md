# TP 2 : DFT et conservation de l'énergie discrète (Théorème de Parseval discret)

## Description
Calcul de la Transformée de Fourier Discrète (DFT) sur un signal aléatoire 1D et vérification de l'équivalent discret du théorème de Plancherel/Parseval.

## Code Python
```python
def compute_dft(signal):
    import cmath
    import math
    N = len(signal)
    dft = []
    for k in range(N):
        val = 0.0 + 0.0j
        for n in range(N):
            angle = -2j * cmath.pi * k * n / N
            val += signal[n] * cmath.exp(angle)
        dft.append(val)
    return dft

def compute_energy_complex(signal_c):
    return sum(abs(x)**2 for x in signal_c)

signal = [1.2, -0.5, 3.1, 0.0, -2.1, 4.4, -1.1, 0.5]
energy_time = sum(x**2 for x in signal)

dft_signal = compute_dft(signal)
energy_freq = compute_energy_complex(dft_signal)

# In DFT, Parseval's theorem states: sum(|x_n|^2) = (1/N) * sum(|X_k|^2)
N = len(signal)
assert abs(energy_time - (energy_freq / N)) < 1e-10, "Le theoreme de Parseval discret a echoue"
print("TP2: Theoreme de Parseval discret verifie avec succes.")

```
