# TP 2 : La gaussienne comme vecteur propre


Nous vérifions ici numériquement que la fonction gaussienne est invariante (à une constante près due à la discrétisation) par transformée de Fourier.

```python
import cmath
import math

def dft(x):
    N = len(x)
    X = [0.0 + 0.0j] * N
    for k in range(N):
        for n in range(N):
            angle = -2 * math.pi * k * n / N
            X[k] += x[n] * cmath.exp(complex(0, angle))
    return X

# Creation d'une gaussienne discrete centree sur N/2
N = 16
sigma = 2.0
gauss_time = []
for n in range(N):
    val = (n - N/2)
    gauss_time.append(math.exp(- (val**2) / (2 * sigma**2)))

gauss_freq = dft(gauss_time)

# La DFT centre les basses frequences en 0 et N.
# Pour comparer visuellement la forme temporelle et frequentielle,
# on observe le module et on shift le spectre (fftshift).
spectre_module = [abs(c) for c in gauss_freq]
spectre_shift = spectre_module[N//2:] + spectre_module[:N//2]

# On normalise les deux signaux pour comparer leurs formes
max_time = max(gauss_time)
gauss_time_norm = [x/max_time for x in gauss_time]

max_freq = max(spectre_shift)
spectre_norm = [x/max_freq for x in spectre_shift]

diff_max = max(abs(gauss_time_norm[i] - spectre_norm[i]) for i in range(N))
print(f"Difference maximale de forme : {diff_max}")

# La difference doit etre tres faible, validant l'invariance de forme
assert diff_max < 0.1, "La gaussienne ne semble pas invariante par transformation !"
```
