# TP 4 : Validation numérique de l'inégalité de Wirtinger

**Objectif :** Vérifier algorithmiquement que $\|f\|_{L^2} \le \|f'\|_{L^2}$ pour une fonction d'intégrale nulle.

```python
import math

def f(t):
    return math.sin(t) + 0.5 * math.cos(2*t)

def df(t):
    return math.cos(t) - math.sin(2*t)

def L2_norm_squared(func, num_points=1000):
    dt = (2*math.pi) / num_points
    integral = 0.0
    for i in range(num_points):
        integral += (func(i*dt)**2) * dt
    return integral / (2*math.pi)

if __name__ == "__main__":
    norm_f = L2_norm_squared(f)
    norm_df = L2_norm_squared(df)

    print(f"||f||^2  = {norm_f}")
    print(f"||f'||^2 = {norm_df}")

    assert norm_f <= norm_df, "L'inegalite de Wirtinger est violee !"
    print("TP4: Inegalite de Wirtinger verifiee numeriquement.")
```
