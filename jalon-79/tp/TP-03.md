# TP 3 : Estimation de $\pi$ via les séries de Fourier

**Objectif :** Utiliser la série de Fourier et la somme de Parseval pour approcher la valeur de $\pi$.

```python
import math

# On utilise le fait que sum(1/(2n+1)^2) = pi^2 / 8
def approximate_pi(n_terms):
    S = 0.0
    for p in range(n_terms):
        S += 1.0 / ((2*p + 1)**2)

    # pi^2 / 8 = S => pi = sqrt(8 * S)
    return math.sqrt(8 * S)

if __name__ == "__main__":
    pi_approx = approximate_pi(1000)
    error = abs(math.pi - pi_approx)

    print(f"Approximation: {pi_approx}")
    print(f"Erreur: {error}")

    assert error < 0.001, "La somme de Parseval ne converge pas correctement vers Pi."
    print("TP3: Calcul de Pi via Parseval reussi.")
```
