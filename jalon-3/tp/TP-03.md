### Contexte et Rappels Théoriques

#### Les Quantificateurs

*   **Quantificateur Universel (∀ - "Pour tout")** : Affirme qu'une propriété est vraie pour *chaque* élément d'un domaine donné.
*   **Quantificateur Existentiel (∃ - "Il existe")** : Affirme qu'une propriété est vraie pour *au moins un* élément d'un domaine donné.

#### L'Ordre des Quantificateurs

L'ordre des quantificateurs est **crucial**. Changer l'ordre peut changer la signification et la valeur de vérité d'une proposition.

*   **∀x ∃y P(x, y)** : "Pour chaque `x`, il existe *au moins un* `y` (qui peut dépendre de `x`) tel que `P(x, y)` est vrai."
*   **∃y ∀x P(x, y)** : "Il existe *un unique* `y` (qui est le même pour tous les `x`) tel que pour chaque `x`, `P(x, y)` est vrai."

Ces deux propositions ne sont **pas équivalentes** en général. La seconde est beaucoup plus forte que la première. Si ∃y ∀x P(x, y) est vraie, alors ∀x ∃y P(x, y) est aussi vraie, mais l'inverse n'est pas vrai.

#### Négation des Quantificateurs

Les règles de De Morgan s'étendent aux quantificateurs :

*   **Négation d'un universel :** `¬(∀x P(x))` est équivalent à `∃x ¬P(x)`.
    *   "Il n'est pas vrai que tous les x ont la propriété P" équivaut à "Il existe au moins un x qui n'a pas la propriété P".
*   **Négation d'un existentiel :** `¬(∃x P(x))` est équivalent à `∀x ¬P(x)`.
    *   "Il n'est pas vrai qu'il existe un x qui a la propriété P" équivaut à "Tous les x n'ont pas la propriété P".

Ces règles s'appliquent de manière récursive pour les quantificateurs imbriqués. Par exemple :
`¬(∀x ∃y P(x, y))` est équivalent à `∃x ¬(∃y P(x, y))`, qui est équivalent à `∃x ∀y ¬P(x, y)`.

### Exercice Pratique : Vérification de Propriétés de Divisibilité

Nous allons explorer ces concepts en utilisant un prédicat simple de divisibilité sur un domaine fini d'entiers.

**Domaine `D` :** Un ensemble fini d'entiers positifs. Par exemple, `D = {1, 2, 3, 4, 5}`.

**Prédicat `P(x, y)` :** "`x` divise `y`" (c'est-à-dire, `y` est un multiple de `x`).
En Python, cela se traduit par `y % x == 0`.

Nous allons évaluer les propositions suivantes et leurs négations sur le domaine `D`.

1.  **Proposition A :** `∀x ∈ D, ∃y ∈ D, P(x, y)`
    *   "Pour tout `x` dans `D`, il existe un `y` dans `D` tel que `x` divise `y`."
2.  **Proposition B :** `∃y ∈ D, ∀x ∈ D, P(x, y)`
    *   "Il existe un `y` dans `D` tel que pour tout `x` dans `D`, `x` divise `y`."
3.  **Négation de A :** `¬(∀x ∈ D, ∃y ∈ D, P(x, y))` ≡ `∃x ∈ D, ∀y ∈ D, ¬P(x, y)`
    *   "Il existe un `x` dans `D` tel que pour tout `y` dans `D`, `x` ne divise pas `y`."
4.  **Négation de B :** `¬(∃y ∈ D, ∀x ∈ D, P(x, y))` ≡ `∀y ∈ D, ∃x ∈ D, ¬P(x, y)`
    *   "Pour tout `y` dans `D`, il existe un `x` dans `D` tel que `x` ne divise pas `y`."

### Implémentation en Python

Votre tâche est d'implémenter les fonctions Python qui évaluent la véracité de ces quatre propositions. Vous devez utiliser des boucles imbriquées pour simuler les quantificateurs.

```python
import math

# --- 1. Définition du domaine et du prédicat ---

DOMAIN = {1, 2, 3, 4, 5} # Notre domaine fini d'entiers

def predicate_divides(x: int, y: int) -> bool:
    """
    Prédicat P(x, y) : 'x divise y'.
    Retourne True si x divise y, False sinon.
    Gère le cas x=0 pour éviter ZeroDivisionError (bien que 0 ne soit pas dans notre DOMAIN).
    """
    if x == 0:
        return y == 0 # 0 divise seulement 0
    return y % x == 0

# --- 2. Implémentation des validateurs de propositions ---

def validate_forall_exists(domain_x: set, domain_y: set, predicate) -> bool:
    """
    Valide la proposition : ∀x ∈ domain_x, ∃y ∈ domain_y, P(x, y)
    """
    for x in domain_x:
        found_y = False
        for y in domain_y:
            if predicate(x, y):
                found_y = True
                break  # On a trouvé un y pour ce x, passons au x suivant
        if not found_y:
            # Si aucun y n'a été trouvé pour ce x, la proposition est fausse
            print(f"Contre-exemple pour ∀x ∃y P(x,y): Pour x={x}, aucun y dans {domain_y} n'est divisible par {x}.")
            return False
    return True  # Pour tous les x, un y a été trouvé

def validate_exists_forall(domain_y: set, domain_x: set, predicate) -> bool:
    """
    Valide la proposition : ∃y ∈ domain_y, ∀x ∈ domain_x, P(x, y)
    Note: L'ordre des domaines dans les arguments reflète l'ordre des quantificateurs.
    """
    for y in domain_y:
        all_x_satisfied = True
        for x in domain_x:
            if not predicate(x, y):
                all_x_satisfied = False
                break  # Ce y ne satisfait pas tous les x
        if all_x_satisfied:
            # Si ce y satisfait tous les x, la proposition est vraie
            print(f"Exemple pour ∃y ∀x P(x,y): y={y} est divisible par tous les x dans {domain_x}.")
            return True
    print(f"Contre-exemple pour ∃y ∀x P(x,y): Aucun y dans {domain_y} n'est divisible par tous les x dans {domain_x}.")
    return False  # Aucun y n'a été trouvé qui satisfait tous les x

# --- 3. Implémentation des validateurs de négations ---

def validate_exists_forall_not(domain_x: set, domain_y: set, predicate) -> bool:
    """
    Valide la proposition : ∃x ∈ domain_x, ∀y ∈ domain_y, ¬P(x, y)
    Ceci est la négation de ∀x ∃y P(x, y).
    """
    # On cherche un x tel que pour tous les y, P(x,y) est faux (i.e., x ne divise pas y)
    for x in domain_x:
        all_y_not_satisfied = True
        for y in domain_y:
            if predicate(x, y): # Si x divise y, alors ¬P(x,y) est faux pour ce y
                all_y_not_satisfied = False
                break # Ce x ne satisfait pas la condition "pour tous les y, x ne divise pas y"
        if all_y_not_satisfied:
            print(f"Exemple pour ∃x ∀y ¬P(x,y): x={x} ne divise aucun y dans {domain_y}.")
            return True
    print(f"Contre-exemple pour ∃x ∀y ¬P(x,y): Pour chaque x dans {domain_x}, il existe un y que x divise.")
    return False

def validate_forall_exists_not(domain_y: set, domain_x: set, predicate) -> bool:
    """
    Valide la proposition : ∀y ∈ domain_y, ∃x ∈ domain_x, ¬P(x, y)
    Ceci est la négation de ∃y ∀x P(x, y).
    """
    # Nous itérons sur chaque élément y pour démontrer l'existence d'un élément x tel que P(x,y) est faux (i.e., x ne divise pas y)
    for y in domain_y:
        found_x_not_satisfied = False
        for x in domain_x:
            if not predicate(x, y): # Si x ne divise pas y, alors ¬P(x,y) est vrai
                found_x_not_satisfied = True
                break # On a trouvé un x qui ne divise pas ce y, passons au y suivant
        if not found_x_not_satisfied:
            # Si pour ce y, tous les x le divisent, alors la proposition est fausse
            print(f"Contre-exemple pour ∀y ∃x ¬P(x,y): Pour y={y}, tous les x dans {domain_x} le divisent.")
            return False
    return True

# --- 4. Exécution et Assertions de Validation ---

print(f"Domaine D : {DOMAIN}\n")

# --- Proposition A : ∀x ∈ D, ∃y ∈ D, P(x, y) ---
# "Pour tout x dans D, il existe un y dans D tel que x divise y."
# Attendu : VRAI.
# Explication :
# - Pour x=1, y=1 (1 divise 1)
# - Pour x=2, y=2 (2 divise 2)
# - Pour x=3, y=3 (3 divise 3)
# - Pour x=4, y=4 (4 divise 4)
# - Pour x=5, y=5 (5 divise 5)
# Chaque nombre se divise lui-même, et il est dans le domaine.
result_A = validate_forall_exists(DOMAIN, DOMAIN, predicate_divides)
print(f"Résultat pour (A) ∀x ∃y P(x,y): {result_A}\n")
assert result_A is True, "Assertion échouée pour la Proposition A"

# --- Proposition B : ∃y ∈ D, ∀x ∈ D, P(x, y) ---
# "Il existe un y dans D tel que pour tout x dans D, x divise y."
# Attendu : FAUX.
# Explication :
# Cela signifie qu'il doit exister un y dans D qui est un multiple commun de TOUS les éléments de D.
# Le plus petit commun multiple (LCM) de {1, 2, 3, 4, 5} est 60.
# 60 n'est pas dans notre DOMAIN {1, 2, 3, 4, 5}.
result_B = validate_exists_forall(DOMAIN, DOMAIN, predicate_divides)
print(f"Résultat pour (B) ∃y ∀x P(x,y): {result_B}\n")
assert result_B is False, "Assertion échouée pour la Proposition B"

# --- Négation de A : ∃x ∈ D, ∀y ∈ D, ¬P(x, y) ---
# "Il existe un x dans D tel que pour tout y dans D, x ne divise pas y."
# Attendu : FAUX.
# Explication : C'est la négation de la Proposition A, qui est VRAIE. Donc, sa négation est FAUSSE.
# Pour chaque x dans D, on peut trouver au moins un y dans D que x divise (par exemple, x lui-même).
result_neg_A = validate_exists_forall_not(DOMAIN, DOMAIN, predicate_divides)
print(f"Résultat pour (¬A) ∃x ∀y ¬P(x,y): {result_neg_A}\n")
assert result_neg_A is False, "Assertion échouée pour la Négation de A"

# --- Négation de B : ∀y ∈ D, ∃x ∈ D, ¬P(x, y) ---
# "Pour tout y dans D, il existe un x dans D tel que x ne divise pas y."
# Attendu : VRAI.
# Explication : C'est la négation de la Proposition B, qui est FAUSSE. Donc, sa négation est VRAIE.
# Pour chaque y dans D, nous pouvons exhiber explicitement un x dans D tel que y n'est pas divisible par x.
# Par exemple, pour y=1, x=2 ne divise pas 1.
# Pour y=2, x=3 ne divise pas 2.
# Pour y=3, x=2 ne divise pas 3.
# Pour y=4, x=3 ne divise pas 4.
# Pour y=5, x=2 ne divise pas 5.
result_neg_B = validate_forall_exists_not(DOMAIN, DOMAIN, predicate_divides)
print(f"Résultat pour (¬B) ∀y ∃x ¬P(x,y): {result_neg_B}\n")
assert result_neg_B is True, "Assertion échouée pour la Négation de B"

print("Toutes les assertions ont été validées avec succès !")

```
