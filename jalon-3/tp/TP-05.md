# TP 5 : Quantification Avancée - Ordre des Quantificateurs et Négation

## Objectifs Pédagogiques

À la fin de ce TP, vous serez capable de :
1.  Comprendre la différence fondamentale entre les énoncés `∀x ∃y P(x,y)` et `∃y ∀x P(x,y)`.
2.  Implémenter des algorithmes pour vérifier la véracité de ces énoncés sur des domaines finis.
3.  Appliquer les règles de négation des quantificateurs pour construire les énoncés négatifs correspondants.
4.  Utiliser des assertions pour valider la logique de vos implémentations.
5.  Identifier des contre-exemples ou des témoins pour les énoncés quantifiés.

## Contexte et Concepts

Nous avons déjà exploré les quantificateurs universel (`∀`) et existentiel (`∃`) de manière isolée. Ce TP se concentre sur leur combinaison et l'impact de leur ordre.

Considérons un prédicat `P(x, y)` qui dépend de deux variables `x` et `y`, et deux domaines finis `X` et `Y`.

1.  **`∀x ∈ X, ∃y ∈ Y, P(x, y)`** : "Pour tout `x` dans `X`, il existe un `y` dans `Y` tel que `P(x, y)` est vrai."
    *   Pour vérifier cet énoncé, nous devons prendre chaque `x` de `X` et, pour chacun d'eux, trouver *au moins un* `y` dans `Y` qui satisfait `P(x, y)`. Si nous trouvons un `x` pour lequel *aucun* `y` ne satisfait `P(x, y)`, alors l'énoncé est faux.

2.  **`∃y ∈ Y, ∀x ∈ X, P(x, y)`** : "Il existe un `y` dans `Y` tel que pour tout `x` dans `X`, `P(x, y)` est vrai."
    *   Pour vérifier cet énoncé, nous devons trouver *au moins un* `y` dans `Y` qui satisfait `P(x, y)` pour *tous* les `x` de `X`. Si nous parcourons tous les `y` de `Y` et qu'aucun d'eux ne satisfait `P(x, y)` pour *tous* les `x`, alors l'énoncé est faux.

**Note importante :** Le second énoncé implique le premier, mais la réciproque est fausse. C'est-à-dire, si `∃y ∈ Y, ∀x ∈ X, P(x, y)` est vrai, alors `∀x ∈ X, ∃y ∈ Y, P(x, y)` est nécessairement vrai. Cependant, `∀x ∈ X, ∃y ∈ Y, P(x, y)` peut être vrai alors que `∃y ∈ Y, ∀x ∈ X, P(x, y)` est faux. C'est cette distinction que nous allons explorer.

### Négation des Énoncés Quantifiés

La négation d'énoncés avec des quantificateurs imbriqués suit les règles de De Morgan :
*   `¬(∀x P(x))` est équivalent à `∃x ¬P(x)`
*   `¬(∃x P(x))` est équivalent à `∀x ¬P(x)`

En appliquant ces règles successivement :
*   **Négation de `∀x ∈ X, ∃y ∈ Y, P(x, y)` :**
    `¬(∀x ∈ X, ∃y ∈ Y, P(x, y))` ≡ `∃x ∈ X, ¬(∃y ∈ Y, P(x, y))` ≡ `∃x ∈ X, ∀y ∈ Y, ¬P(x, y)`
    *   "Il existe un `x` dans `X` tel que pour tout `y` dans `Y`, `P(x, y)` est faux."
    *   Un tel `x` est un **contre-exemple** à l'énoncé original.

*   **Négation de `∃y ∈ Y, ∀x ∈ X, P(x, y)` :**
    `¬(∃y ∈ Y, ∀x ∈ X, P(x, y))` ≡ `∀y ∈ Y, ¬(∀x ∈ X, P(x, y))` ≡ `∀y ∈ Y, ∃x ∈ X, ¬P(x, y)`
    *   "Pour tout `y` dans `Y`, il existe un `x` dans `X` tel que `P(x, y)` est faux."
    *   Un tel `y` est un **contre-exemple** à l'énoncé original.

## Exercice Pratique

Vous allez implémenter des fonctions Python pour vérifier ces énoncés sur des domaines finis. Le prédicat `P(x, y)` que nous utiliserons sera `y % x == 0` (c'est-à-dire, `y` est un multiple de `x`). Nous assumerons que `x` est toujours un entier positif non nul pour éviter les divisions par zéro.

### Tâches

1.  Définir le prédicat `is_multiple(x, y)`.
2.  Implémenter `check_forall_exists(domain_x, domain_y, predicate)` qui retourne `(bool, witness_or_counterexample)`.
    *   Si l'énoncé est vrai, `witness_or_counterexample` sera `None`.
    *   Si l'énoncé est faux, `witness_or_counterexample` sera le `x` qui n'a pas de `y` correspondant (un contre-exemple).
3.  Implémenter `check_exists_forall(domain_x, domain_y, predicate)` qui retourne `(bool, witness_or_counterexample)`.
    *   Si l'énoncé est vrai, `witness_or_counterexample` sera le `y` qui satisfait tous les `x` (un témoin).
    *   Si l'énoncé est faux, `witness_or_counterexample` sera `None`.
4.  Implémenter les fonctions de vérification des négations, en utilisant les équivalences logiques. Ces fonctions devraient également retourner `(bool, witness_or_counterexample)`.
    *   `check_negation_forall_exists(domain_x, domain_y, predicate)` (vérifie `∃x ∀y ¬P(x,y)`)
    *   `check_negation_exists_forall(domain_x, domain_y, predicate)` (vérifie `∀y ∃x ¬P(x,y)`)
5.  Utiliser des `assert` pour valider vos implémentations avec différents jeux de données qui illustrent les cas où les énoncés sont vrais, faux, et où l'ordre des quantificateurs change le résultat.

```python
import math

# 1. Définition du prédicat P(x, y)
def is_multiple(x: int, y: int) -> bool:
    """
    Prédicat P(x, y) : Vérifie si y est un multiple de x.
    Assumons x > 0 pour éviter la division par zéro.
    """
    if x == 0:
        # Dans le contexte de "y est un multiple de x", x ne peut pas être 0.
        # Si x=0, y%x est indéfini. On peut choisir de retourner False ou lever une erreur.
        # Pour ce TP, nous allons simplement retourner False pour simplifier.
        return False
    return y % x == 0

# 2. Implémentation de ∀x ∈ X, ∃y ∈ Y, P(x, y)
def check_forall_exists(domain_x: list[int], domain_y: list[int], predicate) -> tuple[bool, int | None]:
    """
    Vérifie l'énoncé "Pour tout x dans X, il existe un y dans Y tel que P(x, y) est vrai".
    Retourne (True, None) si l'énoncé est vrai.
    Retourne (False, x_counterexample) si l'énoncé est faux, avec le x qui n'a pas de y correspondant.
    """
    for x in domain_x:
        found_y_for_x = False
        for y in domain_y:
            if predicate(x, y):
                found_y_for_x = True
                break  # On a trouvé un y pour ce x, passons au x suivant
        if not found_y_for_x:
            return False, x  # Aucun y n'a été trouvé pour ce x, l'énoncé est faux
    return True, None  # Tous les x ont trouvé un y, l'énoncé est vrai

# 3. Implémentation de ∃y ∈ Y, ∀x ∈ X, P(x, y)
def check_exists_forall(domain_x: list[int], domain_y: list[int], predicate) -> tuple[bool, int | None]:
    """
    Vérifie l'énoncé "Il existe un y dans Y tel que pour tout x dans X, P(x, y) est vrai".
    Retourne (True, y_witness) si l'énoncé est vrai, avec le y qui satisfait tous les x.
    Retourne (False, None) si l'énoncé est faux.
    """
    for y in domain_y:
        y_satisfies_all_x = True
        for x in domain_x:
            if not predicate(x, y):
                y_satisfies_all_x = False
                break  # Ce y ne satisfait pas tous les x, essayons le y suivant
        if y_satisfies_all_x:
            return True, y  # Ce y satisfait tous les x, l'énoncé est vrai
    return False, None  # Aucun y n'a satisfait tous les x, l'énoncé est faux

# 4. Implémentation des négations

# Négation de (∀x ∈ X, ∃y ∈ Y, P(x, y)) ≡ (∃x ∈ X, ∀y ∈ Y, ¬P(x, y))
def check_negation_forall_exists(domain_x: list[int], domain_y: list[int], predicate) -> tuple[bool, int | None]:
    """
    Vérifie l'énoncé "Il existe un x dans X tel que pour tout y dans Y, P(x, y) est faux".
    Retourne (True, x_witness) si l'énoncé est vrai, avec le x qui ne trouve aucun y.
    Retourne (False, None) si l'énoncé est faux.
    """
    # C'est l'exact opposé de check_forall_exists.
    # Si check_forall_exists est False, alors sa négation est True, et le contre-exemple de l'original
    # est le témoin de la négation.
    is_original_true, counter_x = check_forall_exists(domain_x, domain_y, predicate)
    return not is_original_true, counter_x

# Négation de (∃y ∈ Y, ∀x ∈ X, P(x, y)) ≡ (∀y ∈ Y, ∃x ∈ X, ¬P(x, y))
def check_negation_exists_forall(domain_x: list[int], domain_y: list[int], predicate) -> tuple[bool, int | None]:
    """
    Vérifie l'énoncé "Pour tout y dans Y, il existe un x dans X tel que P(x, y) est faux".
    Retourne (True, None) si l'énoncé est vrai.
    Retourne (False, y_counterexample) si l'énoncé est faux, avec le y qui satisfait tous les x.
    """
    # C'est l'exact opposé de check_exists_forall.
    # Si check_exists_forall est False, alors sa négation est True.
    # Si check_exists_forall est True, alors sa négation est False, et le témoin de l'original
    # est le contre-exemple de la négation.
    is_original_true, witness_y = check_exists_forall(domain_x, domain_y, predicate)
    return not is_original_true, witness_y


# --- Cas de Test et Assertions ---
print("--- Début des tests ---")

# Cas 1: Les deux énoncés sont VRAIS (∃y qui est multiple de tous les x)
# X = {1, 2, 3}, Y = {6}
# P(x,y) = y % x == 0
# Pour x=1, y=6 : 6%1=0 (Vrai)
# Pour x=2, y=6 : 6%2=0 (Vrai)
# Pour x=3, y=6 : 6%3=0 (Vrai)
domain_x_1 = [1, 2, 3]
domain_y_1 = [6]

# ∀x ∈ X, ∃y ∈ Y, P(x, y)
# Pour chaque x, y=6 fonctionne. VRAI.
result_fe_1, ce_fe_1 = check_forall_exists(domain_x_1, domain_y_1, is_multiple)
assert result_fe_1 is True, f"Cas 1 (∀x ∃y): Attendu True, obtenu {result_fe_1}"
assert ce_fe_1 is None, f"Cas 1 (∀x ∃y): Attendu None, obtenu {ce_fe_1}"
print(f"Cas 1 (∀x ∃y): {result_fe_1}, contre-exemple: {ce_fe_1}")

# ∃y ∈ Y, ∀x ∈ X, P(x, y)
# y=6 fonctionne pour tous les x. VRAI.
result_ef_1, w_ef_1 = check_exists_forall(domain_x_1, domain_y_1, is_multiple)
assert result_ef_1 is True, f"Cas 1 (∃y ∀x): Attendu True, obtenu {result_ef_1}"
assert w_ef_1 == 6, f"Cas 1 (∃y ∀x): Attendu 6, obtenu {w_ef_1}"
print(f"Cas 1 (∃y ∀x): {result_ef_1}, témoin: {w_ef_1}")

# Négations
assert check_negation_forall_exists(domain_x_1, domain_y_1, is_multiple) == (False, None)
assert check_negation_exists_forall(domain_x_1, domain_y_1, is_multiple) == (False, 6) # 6 est le contre-exemple à la négation


# Cas 2: Les deux énoncés sont FAUX
# X = {2, 3}, Y = {4, 5}
# P(x,y) = y % x == 0
# Pour x=2, y=4 fonctionne.
# Pour x=3, ni y=4 ni y=5 ne fonctionnent.
domain_x_2 = [2, 3]
domain_y_2 = [4, 5]

# ∀x ∈ X, ∃y ∈ Y, P(x, y)
# Pour x=3, aucun y ne fonctionne. FAUX.
result_fe_2, ce_fe_2 = check_forall_exists(domain_x_2, domain_y_2, is_multiple)
assert result_fe_2 is False, f"Cas 2 (∀x ∃y): Attendu False, obtenu {result_fe_2}"
assert ce_fe_2 == 3, f"Cas 2 (∀x ∃y): Attendu 3, obtenu {ce_fe_2}"
print(f"Cas 2 (∀x ∃y): {result_fe_2}, contre-exemple: {ce_fe_2}")

# ∃y ∈ Y, ∀x ∈ X, P(x, y)
# Pour y=4, x=3 ne fonctionne pas.
# Pour y=5, x=2 ne fonctionne pas. FAUX.
result_ef_2, w_ef_2 = check_exists_forall(domain_x_2, domain_y_2, is_multiple)
assert result_ef_2 is False, f"Cas 2 (∃y ∀x): Attendu False, obtenu {result_ef_2}"
assert w_ef_2 is None, f"Cas 2 (∃y ∀x): Attendu None, obtenu {w_ef_2}"
print(f"Cas 2 (∃y ∀x): {result_ef_2}, témoin: {w_ef_2}")

# Négations
assert check_negation_forall_exists(domain_x_2, domain_y_2, is_multiple) == (True, 3) # 3 est le témoin de la négation
assert check_negation_exists_forall(domain_x_2, domain_y_2, is_multiple) == (True, None)


# Cas 3: ∀x ∃y P(x,y) est VRAI, mais ∃y ∀x P(x,y) est FAUX (le cas le plus illustratif)
# X = {2, 3, 5}, Y = {10, 15}
# P(x,y) = y % x == 0
# Pour x=2, y=10 fonctionne.
# Pour x=3, y=15 fonctionne.
# Pour x=5, y=10 ou y=15 fonctionnent.
domain_x_3 = [2, 3, 5]
domain_y_3 = [10, 15]

# ∀x ∈ X, ∃y ∈ Y, P(x, y)
# Pour chaque x, on trouve un y. VRAI.
result_fe_3, ce_fe_3 = check_forall_exists(domain_x_3, domain_y_3, is_multiple)
assert result_fe_3 is True, f"Cas 3 (∀x ∃y): Attendu True, obtenu {result_fe_3}"
assert ce_fe_3 is None, f"Cas 3 (∀x ∃y): Attendu None, obtenu {ce_fe_3}"
print(f"Cas 3 (∀x ∃y): {result_fe_3}, contre-exemple: {ce_fe_3}")

# ∃y ∈ Y, ∀x ∈ X, P(x, y)
# Pour y=10: x=3 ne fonctionne pas (10%3 != 0).
# Pour y=15: x=2 ne fonctionne pas (15%2 != 0).
# Aucun y ne fonctionne pour tous les x. FAUX.
result_ef_3, w_ef_3 = check_exists_forall(domain_x_3, domain_y_3, is_multiple)
assert result_ef_3 is False, f"Cas 3 (∃y ∀x): Attendu False, obtenu {result_ef_3}"
assert w_ef_3 is None, f"Cas 3 (∃y ∀x): Attendu None, obtenu {w_ef_3}"
print(f"Cas 3 (∃y ∀x): {result_ef_3}, témoin: {w_ef_3}")

# Négations
assert check_negation_forall_exists(domain_x_3, domain_y_3, is_multiple) == (False, None)
assert check_negation_exists_forall(domain_x_3, domain_y_3, is_multiple) == (True, None)


# Cas 4: Test avec un domaine X vide (conventionnellement, ∀x P(x) est VRAI, ∃x P(x) est FAUX)
domain_x_empty = []
domain_y_any = [1, 2, 3]

# ∀x ∈ {}, ∃y ∈ Y, P(x, y)
# L'énoncé est vacuously true (vraiment par vacuité) car il n'y a aucun x pour le contredire.
result_fe_4, ce_fe_4 = check_forall_exists(domain_x_empty, domain_y_any, is_multiple)
assert result_fe_4 is True, f"Cas 4 (∀x ∃y, X vide): Attendu True, obtenu {result_fe_4}"
print(f"Cas 4 (∀x ∃y, X vide): {result_fe_4}, contre-exemple: {ce_fe_4}")

# ∃y ∈ Y, ∀x ∈ {}, P(x, y)
# Pour chaque y, l'énoncé ∀x ∈ {}, P(x,y) est vacuously true. Donc, il existe un tel y (n'importe lequel).
result_ef_4, w_ef_4 = check_exists_forall(domain_x_empty, domain_y_any, is_multiple)
assert result_ef_4 is True, f"Cas 4 (∃y ∀x, X vide): Attendu True, obtenu {result_ef_4}"
assert w_ef_4 == 1, f"Cas 4 (∃y ∀x, X vide): Attendu 1, obtenu {w_ef_4}" # Ou 2, ou 3...
print(f"Cas 4 (∃y ∀x, X vide): {result_ef_4}, témoin: {w_ef_4}")


# Cas 5: Test avec un domaine Y vide
domain_x_any = [1, 2, 3]
domain_y_empty = []

# ∀x ∈ X, ∃y ∈ {}, P(x, y)
# Pour x=1, il n'existe aucun y dans Y vide. FAUX.
result_fe_5, ce_fe_5 = check_forall_exists(domain_x_any, domain_y_empty, is_multiple)
assert result_fe_5 is False, f"Cas 5 (∀x ∃y, Y vide): Attendu False, obtenu {result_fe_5}"
assert ce_fe_5 == 1, f"Cas 5 (∀x ∃y, Y vide): Attendu 1, obtenu {ce_fe_5}"
print(f"Cas 5 (∀x ∃y, Y vide): {result_fe_5}, contre-exemple: {ce_fe_5}")

# ∃y ∈ {}, ∀x ∈ X, P(x, y)
# Il n'existe aucun y dans Y vide. FAUX.
result_ef_5, w_ef_5 = check_exists_forall(domain_x_any, domain_y_empty, is_multiple)
assert result_ef_5 is False, f"Cas 5 (∃y ∀x, Y vide): Attendu False, obtenu {result_ef_5}"
assert w_ef_5 is None, f"Cas 5 (∃y ∀x, Y vide): Attendu None, obtenu {w_ef_5}"
print(f"Cas 5 (∃y ∀x, Y vide): {result_ef_5}, témoin: {w_ef_5}")


print("--- Tous les tests passés avec succès ! ---")
```
