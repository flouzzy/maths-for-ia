### Contexte Mathématique

Nous allons travailler avec un prédicat binaire `P(x, y)` et deux domaines finis `D_x` et `D_y`.

1.  **Quantification Universelle-Existentielle : `∀x ∈ D_x, ∃y ∈ D_y, P(x, y)`**
    *   **Signification :** Pour *chaque* élément `x` du domaine `D_x`, il *existe au moins un* élément `y` dans le domaine `D_y` tel que le prédicat `P(x, y)` soit vrai.
    *   **Exemple :** Si `P(x, y)` est "x est plus petit que y", et `D_x = {1, 2, 3}`, `D_y = {2, 3, 4}`.
        *   Pour `x=1`, `y=2` (ou 3, 4) fonctionne.
        *   Pour `x=2`, `y=3` (ou 4) fonctionne.
        *   Pour `x=3`, `y=4` fonctionne.
        *   L'énoncé est VRAI.
    *   **Négation :** `¬(∀x ∈ D_x, ∃y ∈ D_y, P(x, y))` est équivalent à `∃x ∈ D_x, ∀y ∈ D_y, ¬P(x, y)`.
        *   Cela signifie qu'il existe un `x` pour lequel *aucun* `y` ne satisfait `P(x, y)`. C'est ce `x` que nous appellerons un "contre-exemple" à l'énoncé original.

2.  **Quantification Existentielle-Universelle : `∃y ∈ D_y, ∀x ∈ D_x, P(x, y)`**
    *   **Signification :** Il *existe au moins un* élément `y` dans le domaine `D_y` tel que, pour *chaque* élément `x` du domaine `D_x`, le prédicat `P(x, y)` soit vrai.
    *   **Exemple :** Si `P(x, y)` est "x est plus petit que y", et `D_x = {1, 2, 3}`, `D_y = {2, 3, 4}`.
        *   Pour `y=2` : `1<2` est vrai, mais `2<2` est faux. Donc `y=2` ne fonctionne pas pour tous les `x`.
        *   Pour `y=3` : `1<3` est vrai, `2<3` est vrai, mais `3<3` est faux. Donc `y=3` ne fonctionne pas pour tous les `x`.
        *   Pour `y=4` : `1<4` est vrai, `2<4` est vrai, `3<4` est vrai. Donc `y=4` fonctionne pour tous les `x`.
        *   L'énoncé est VRAI.
    *   **Négation :** `¬(∃y ∈ D_y, ∀x ∈ D_x, P(x, y))` est équivalent à `∀y ∈ D_y, ∃x ∈ D_x, ¬P(x, y)`.

Nous utiliserons le prédicat simple `P(x, y) := x < y` pour nos exemples, mais votre code devra être générique et accepter n'importe quel prédicat binaire.

### Exercice Pratique

Votre tâche consiste à implémenter en Python pur les fonctions de validation pour ces énoncés quantifiés et à démontrer leur fonctionnement avec des assertions.

#### Partie 1 : Implémentation des Quantificateurs

Implémentez les fonctions suivantes :

1.  `is_less_than(x, y)` : Un prédicat simple qui retourne `True` si `x < y`, `False` sinon.
2.  `check_for_all_exists(domain_x, domain_y, predicate)` : Prend en entrée deux listes/itérables représentant `D_x` et `D_y`, et une fonction `predicate(x, y)`. Elle doit retourner `True` si `∀x ∈ D_x, ∃y ∈ D_y, predicate(x, y)` est vrai, `False` sinon.
3.  `check_exists_for_all(domain_x, domain_y, predicate)` : Similaire à la précédente, mais retourne `True` si `∃y ∈ D_y, ∀x ∈ D_x, predicate(x, y)` est vrai, `False` sinon.
4.  `find_counter_example_for_all_exists(domain_x, domain_y, predicate)` : Si l'énoncé `∀x ∈ D_x, ∃y ∈ D_y, predicate(x, y)` est faux, cette fonction doit retourner *un* `x` de `D_x` qui est un contre-exemple (c'est-à-dire un `x` pour lequel il n'existe aucun `y` dans `D_y` satisfaisant le prédicat). Si l'énoncé est vrai, elle doit retourner `None`.

#### Partie 2 : Validation et Exploration

Utilisez des assertions (`assert`) pour valider le comportement de vos fonctions avec différents domaines et le prédicat `is_less_than`. Créez des scénarios où les énoncés sont vrais, faux, et où des contre-exemples peuvent être trouvés.

```python
# TP 4 : Quantification, Ordre et Négation

# --- Partie 1: Implémentation des Quantificateurs ---

def is_less_than(x, y):
    """
    Prédicat binaire: retourne True si x est strictement inférieur à y.
    """
    return x < y

def check_for_all_exists(domain_x, domain_y, predicate):
    """
    Vérifie l'énoncé : Pour tout x dans domain_x, il existe un y dans domain_y tel que predicate(x, y) est vrai.
    (∀x ∈ D_x, ∃y ∈ D_y, P(x, y))
    """
    # Pour chaque x dans le domaine D_x
    for x in domain_x:
        # Nous devons trouver au moins un y dans D_y qui satisfait le prédicat
        found_y_for_current_x = False
        for y in domain_y:
            if predicate(x, y):
                found_y_for_current_x = True
                break  # Un y a été trouvé pour ce x, passons au x suivant

        # Si aucun y n'a été trouvé pour le x actuel, l'énoncé universel est faux
        if not found_y_for_current_x:
            return False

    # Si nous avons parcouru tous les x et trouvé un y pour chacun, l'énoncé est vrai
    return True

def check_exists_for_all(domain_x, domain_y, predicate):
    """
    Vérifie l'énoncé : Il existe un y dans domain_y tel que pour tout x dans domain_x, predicate(x, y) est vrai.
    (∃y ∈ D_y, ∀x ∈ D_x, P(x, y))
    """
    # Nous cherchons un y unique dans D_y
    for y in domain_y:
        # Pour ce y, nous devons vérifier si tous les x dans D_x satisfont le prédicat
        all_x_satisfied_for_current_y = True
        for x in domain_x:
            if not predicate(x, y):
                all_x_satisfied_for_current_y = False
                break  # Ce y ne fonctionne pas pour tous les x, essayons le y suivant

        # Si tous les x ont satisfait le prédicat pour ce y, alors l'énoncé existentiel est vrai
        if all_x_satisfied_for_current_y:
            return True

    # Si aucun y n'a été trouvé qui satisfasse le prédicat pour tous les x, l'énoncé est faux
    return False

def find_counter_example_for_all_exists(domain_x, domain_y, predicate):
    """
    Si l'énoncé (∀x ∈ D_x, ∃y ∈ D_y, P(x, y)) est faux, cette fonction retourne un x
    qui est un contre-exemple (i.e., un x pour lequel il n'existe aucun y dans D_y
    satisfaisant le prédicat). Si l'énoncé est vrai, elle retourne None.
    Ceci correspond à trouver un x tel que (∀y ∈ D_y, ¬P(x, y)).
    """
    for x in domain_x:
        # Pour ce x, nous vérifions s'il existe un y qui satisfait le prédicat
        found_y_for_current_x = False
        for y in domain_y:
            if predicate(x, y):
                found_y_for_current_x = True
                break

        # Si aucun y n'a été trouvé pour ce x, alors ce x est un contre-exemple
        if not found_y_for_current_x:
            return x

    # Si aucun contre-exemple n'a été trouvé après avoir vérifié tous les x,
    # cela signifie que l'énoncé original (∀x ∃y P(x,y)) est vrai.
    return None

# --- Partie 2: Validation et Exploration avec Assertions ---

print("--- Début des tests avec assertions ---")

# Définition des domaines pour les tests
domain_A = [1, 2, 3]
domain_B = [1, 2, 3, 4]
domain_C = [1, 2]
domain_D = [4, 5]

# --- Test du prédicat is_less_than ---
assert is_less_than(1, 2) == True, "Test 1.1: 1 < 2 doit être True"
assert is_less_than(3, 2) == False, "Test 1.2: 3 < 2 doit être False"
assert is_less_than(2, 2) == False, "Test 1.3: 2 < 2 doit être False"
print("Prédicat 'is_less_than' : OK")

# --- Tests pour (∀x ∈ D_x, ∃y ∈ D_y, x < y) ---

# Cas VRAI : Pour chaque x dans A, il existe un y dans B tel que x < y
# x=1, y=2 (ou 3, 4) ; x=2, y=3 (ou 4) ; x=3, y=4
assert check_for_all_exists(domain_A, domain_B, is_less_than) == True, \
    "Test 2.1: (∀x ∈ A, ∃y ∈ B, x < y) doit être True"

# Cas FAUX : Pour x=3 dans A, il n'existe pas de y dans C tel que x < y (C={1,2})
assert check_for_all_exists(domain_A, domain_C, is_less_than) == False, \
    "Test 2.2: (∀x ∈ A, ∃y ∈ C, x < y) doit être False"

# Cas VRAI : Pour chaque x dans C, il existe un y dans B tel que x < y
# x=1, y=2 (ou 3, 4) ; x=2, y=3 (ou 4)
assert check_for_all_exists(domain_C, domain_B, is_less_than) == True, \
    "Test 2.3: (∀x ∈ C, ∃y ∈ B, x < y) doit être True"

print("Fonction 'check_for_all_exists' : OK")

# --- Tests pour (∃y ∈ D_y, ∀x ∈ D_x, x < y) ---

# Cas VRAI : Il existe y=4 dans B tel que pour tout x dans A, x < y
# (1<4, 2<4, 3<4)
assert check_exists_for_all(domain_A, domain_B, is_less_than) == True, \
    "Test 3.1: (∃y ∈ B, ∀x ∈ A, x < y) doit être True"

# Cas FAUX : Il n'existe pas de y dans C tel que pour tout x dans A, x < y
# Pour y=1, 1<1 est faux. Pour y=2, 2<2 est faux.
assert check_exists_for_all(domain_A, domain_C, is_less_than) == False, \
    "Test 3.2: (∃y ∈ C, ∀x ∈ A, x < y) doit être False"

# Cas FAUX : Il n'existe pas de y dans A tel que pour tout x dans B, x < y
# B={1,2,3,4}, A={1,2,3}. Aucun y dans A n'est plus grand que tous les x de B.
assert check_exists_for_all(domain_B, domain_A, is_less_than) == False, \
    "Test 3.3: (∃y ∈ A, ∀x ∈ B, x < y) doit être False"

# Cas VRAI : Il existe y=4 dans D tel que pour tout x dans A, x < y
# A={1,2,3}, D={4,5}. y=4 fonctionne.
assert check_exists_for_all(domain_A, domain_D, is_less_than) == True, \
    "Test 3.4: (∃y ∈ D, ∀x ∈ A, x < y) doit être True"

print("Fonction 'check_exists_for_all' : OK")

# --- Tests pour find_counter_example_for_all_exists ---

# Cas où l'énoncé est FAUX : (∀x ∈ A, ∃y ∈ C, x < y) est faux.
# Le contre-exemple attendu est x=3 (car 3 n'est pas < 1 ni < 2)
assert find_counter_example_for_all_exists(domain_A, domain_C, is_less_than) == 3, \
    "Test 4.1: Contre-exemple pour (A, C) doit être 3"

# Cas où l'énoncé est FAUX : (∀x ∈ B, ∃y ∈ A, x < y) est faux.
# B={1,2,3,4}, A={1,2,3}. x=3 n'a pas de y>3 dans A. x=4 n'a pas de y>4 dans A.
# Le premier contre-exemple trouvé devrait être 3.
assert find_counter_example_for_all_exists(domain_B, domain_A, is_less_than) == 3, \
    "Test 4.2: Contre-exemple pour (B, A) doit être 3"

# Cas où l'énoncé est VRAI : (∀x ∈ A, ∃y ∈ B, x < y) est vrai.
# Donc aucun contre-exemple ne devrait être trouvé.
assert find_counter_example_for_all_exists(domain_A, domain_B, is_less_than) is None, \
    "Test 4.3: Aucun contre-exemple pour (A, B) car l'énoncé est vrai"

print("Fonction 'find_counter_example_for_all_exists' : OK")

print("\n--- Tous les tests ont réussi ! ---")

# --- Exemples d'utilisation pour illustrer la différence ---
print("\n--- Illustration de la différence entre les ordres de quantificateurs ---")

Dx = [1, 2]
Dy = [1, 2, 3]

print(f"Domaine X: {Dx}, Domaine Y: {Dy}")

# (∀x ∈ Dx, ∃y ∈ Dy, x < y)
# Pour x=1, y=2 ou y=3 fonctionne.
# Pour x=2, y=3 fonctionne.
# -> VRAI
result_for_all_exists = check_for_all_exists(Dx, Dy, is_less_than)
print(f"(∀x ∈ Dx, ∃y ∈ Dy, x < y) : {result_for_all_exists}")

# (∃y ∈ Dy, ∀x ∈ Dx, x < y)
# Pour y=1: 1<1 est faux.
# Pour y=2: 2<2 est faux.
# Pour y=3: 1<3 et 2<3 sont vrais. -> y=3 fonctionne.
# -> VRAI
result_exists_for_all = check_exists_for_all(Dx, Dy, is_less_than)
print(f"(∃y ∈ Dy, ∀x ∈ Dx, x < y) : {result_exists_for_all}")

# Les deux sont vrais ici, ce n'est pas toujours le cas !
# Changeons les domaines pour montrer la différence plus clairement.

Dx_prime = [1, 2, 3]
Dy_prime = [1, 2, 3] # y ne peut pas être plus grand que 3

print(f"\nDomaine X': {Dx_prime}, Domaine Y': {Dy_prime}")

# (∀x ∈ Dx', ∃y ∈ Dy', x < y)
# Pour x=1, y=2 ou y=3 fonctionne.
# Pour x=2, y=3 fonctionne.
# Pour x=3, aucun y dans Dy' n'est > 3. -> FAUX
result_for_all_exists_prime = check_for_all_exists(Dx_prime, Dy_prime, is_less_than)
print(f"(∀x ∈ Dx', ∃y ∈ Dy', x < y) : {result_for_all_exists_prime}")

# (∃y ∈ Dy', ∀x ∈ Dx', x < y)
# Pour y=1: 1<1 est faux.
# Pour y=2: 2<2 est faux.
# Pour y=3: 3<3 est faux.
# -> FAUX
result_exists_for_all_prime = check_exists_for_all(Dx_prime, Dy_prime, is_less_than)
print(f"(∃y ∈ Dy', ∀x ∈ Dx', x < y) : {result_exists_for_all_prime}")

# Dans cet exemple, les deux sont faux.
# Prenons un cas où l'un est vrai et l'autre faux.
Dx_diff = [1, 2]
Dy_diff = [2, 3]

print(f"\nDomaine X_diff: {Dx_diff}, Domaine Y_diff: {Dy_diff}")

# (∀x ∈ Dx_diff, ∃y ∈ Dy_diff, x < y)
# Pour x=1, y=2 ou y=3 fonctionne.
# Pour x=2, y=3 fonctionne.
# -> VRAI
result_for_all_exists_diff = check_for_all_exists(Dx_diff, Dy_diff, is_less_than)
print(f"(∀x ∈ Dx_diff, ∃y ∈ Dy_diff, x < y) : {result_for_all_exists_diff}")

# (∃y ∈ Dy_diff, ∀x ∈ Dx_diff, x < y)
# Pour y=2: 1<2 est vrai, mais 2<2 est faux.
# Pour y=3: 1<3 est vrai, 2<3 est vrai. -> y=3 fonctionne.
# -> VRAI
result_exists_for_all_diff = check_exists_for_all(Dx_diff, Dy_diff, is_less_than)
print(f"(∃y ∈ Dy_diff, ∀x ∈ Dx_diff, x < y) : {result_exists_for_all_diff}")

# Encore les deux vrais. Il est difficile de trouver un cas simple avec < où l'un est vrai et l'autre faux.
# C'est souvent le cas quand le domaine Y est "suffisamment grand" par rapport à X.

# Considérons un prédicat différent pour illustrer la non-équivalence plus clairement
def divides(x, y):
    """Prédicat: x divise y (y est un multiple de x)"""
    return y % x == 0

Dx_div = [2, 3]
Dy_div = [6, 7, 8]

print(f"\n--- Illustration avec le prédicat 'divides' ---")
print(f"Domaine X_div: {Dx_div}, Domaine Y_div: {Dy_div}")

# (∀x ∈ Dx_div, ∃y ∈ Dy_div, divides(x, y))
# Pour x=2: y=6 ou y=8 fonctionne.
# Pour x=3: y=6 fonctionne.
# -> VRAI
result_for_all_exists_div = check_for_all_exists(Dx_div, Dy_div, divides)
print(f"(∀x ∈ Dx_div, ∃y ∈ Dy_div, divides(x, y)) : {result_for_all_exists_div}")

# (∃y ∈ Dy_div, ∀x ∈ Dx_div, divides(x, y))
# Pour y=6: 2 divise 6 (Vrai), 3 divise 6 (Vrai). -> y=6 fonctionne !
# -> VRAI
result_exists_for_all_div = check_exists_for_all(Dx_div, Dy_div, divides)
print(f"(∃y ∈ Dy_div, ∀x ∈ Dx_div, divides(x, y)) : {result_exists_for_all_div}")

# Encore les deux vrais. C'est plus subtil que juste "x < y".

# Un cas classique où l'ordre change la vérité :
# P(x,y) : "y est la mère de x"
# ∀x ∃y P(x,y) : "Toute personne a une mère" (VRAI)
# ∃y ∀x P(x,y) : "Il existe une personne qui est la mère de tout le monde" (FAUX)

# Simuler ce cas avec des nombres
def P_mother_of(child, mother):
    # Pour simuler, disons que 'mother' doit être 'child' + 100
    # Et 'child' doit être dans [1, 2] et 'mother' dans [101, 102]
    return mother == child + 100

Children = [1, 2]
Mothers = [101, 102]

print(f"\n--- Illustration avec un prédicat 'mère de' simulé ---")
print(f"Enfants (Dx): {Children}, Mères (Dy): {Mothers}")

# (∀child ∈ Children, ∃mother ∈ Mothers, P_mother_of(child, mother))
# Pour child=1, mother=101 fonctionne.
# Pour child=2, mother=102 fonctionne.
# -> VRAI
result_all_exists_mother = check_for_all_exists(Children, Mothers, P_mother_of)
print(f"(∀child, ∃mother, P_mother_of(child, mother)) : {result_all_exists_mother}")

# (∃mother ∈ Mothers, ∀child ∈ Children, P_mother_of(child, mother))
# Pour mother=101: P_mother_of(1, 101) est vrai, mais P_mother_of(2, 101) est faux (101 != 2+100).
# Pour mother=102: P_mother_of(1, 102) est faux (102 != 1+100).
# -> FAUX
result_exists_all_mother = check_exists_for_all(Children, Mothers, P_mother_of)
print(f"(∃mother, ∀child, P_mother_of(child, mother)) : {result_exists_all_mother}")

# Ici, nous avons enfin un cas où l'ordre des quantificateurs change la valeur de vérité !
# C'est l'exemple classique qui démontre la non-équivalence.

print("\n--- Fin des tests et illustrations ---")
```
