## Contexte Théorique (Rappel)

*   **Quantificateur Universel (∀) :** "Pour tout..." ou "Pour chaque...". La proposition `∀x P(x)` est vraie si et seulement si `P(x)` est vraie pour *chaque* élément `x` du domaine. Elle est fausse s'il existe au moins un `x` pour lequel `P(x)` est fausse (ce `x` est un **contre-exemple**).
*   **Quantificateur Existentiel (∃) :** "Il existe un..." ou "Il y a au moins un...". La proposition `∃x P(x)` est vraie si et seulement s'il existe au moins un `x` dans le domaine pour lequel `P(x)` est vraie (ce `x` est un **témoin**). Elle est fausse si `P(x)` est fausse pour *chaque* élément `x` du domaine.
*   **Ordre des Quantificateurs :** L'ordre est crucial !
    *   `∀x ∃y P(x,y)` : Pour chaque `x`, il existe *au moins un* `y` (qui peut dépendre de `x`) tel que `P(x,y)` est vraie.
    *   `∃y ∀x P(x,y)` : Il existe *un unique* `y` (qui ne dépend pas de `x`) tel que `P(x,y)` est vraie pour *tous* les `x`.
*   **Négation des Quantificateurs :**
    *   `¬(∀x P(x))` est équivalent à `∃x ¬P(x)`
    *   `¬(∃x P(x))` est équivalent à `∀x ¬P(x)`

## Exercice Pratique : Évaluation de Propositions Quantifiées

Votre tâche est d'implémenter en Python des fonctions qui évaluent des propositions quantifiées sur des domaines finis.

### Consignes d'Implémentation

1.  **Fonction `evaluate_for_all_exists(predicate, domain_x, domain_y)` :**
    *   Prend en entrée un `predicate` (une fonction `P(x, y)` qui retourne un booléen), un `domain_x` (liste ou ensemble d'éléments pour `x`), et un `domain_y` (liste ou ensemble d'éléments pour `y`).
    *   Évalue la proposition `∀x ∈ domain_x, ∃y ∈ domain_y tel que P(x,y)`.
    *   Retourne un tuple `(bool_result, counter_example_x_if_false)`. Si la proposition est fausse, elle doit retourner le premier `x` pour lequel aucun `y` satisfaisant `P(x,y)` n'a été trouvé. Sinon, `None`.

2.  **Fonction `evaluate_exists_for_all(predicate, domain_x, domain_y)` :**
    *   Prend les mêmes entrées que la fonction précédente.
    *   Évalue la proposition `∃y ∈ domain_y, ∀x ∈ domain_x tel que P(x,y)`.
    *   Retourne un tuple `(bool_result, witness_y_if_true)`. Si la proposition est vraie, elle doit retourner le premier `y` qui satisfait `P(x,y)` pour tous les `x`. Sinon, `None`.

3.  **Utilisation de `assert` :** Incluez des assertions pour valider le comportement de vos fonctions avec différents prédicats et domaines, en illustrant notamment :
    *   La différence entre `∀x ∃y P(x,y)` et `∃y ∀x P(x,y)`.
    *   L'équivalence entre la négation d'une proposition et la proposition avec quantificateurs inversés et prédicat nié (par exemple, `¬(∀x ∃y P(x,y))` est équivalent à `∃x ∀y ¬P(x,y)`).

### Implémentation Python

```python
import math

def evaluate_for_all_exists(predicate, domain_x, domain_y):
    """
    Évalue la proposition: Pour tout x dans domain_x, il existe un y dans domain_y tel que P(x,y).
    (∀x ∈ domain_x, ∃y ∈ domain_y tel que P(x,y))

    Args:
        predicate (callable): Une fonction P(x, y) qui retourne un booléen.
        domain_x (iterable): L'ensemble des valeurs possibles pour x.
        domain_y (iterable): L'ensemble des valeurs possibles pour y.

    Returns:
        tuple: (bool_result, counter_example_x_if_false)
               Si la proposition est fausse, retourne le premier x pour lequel aucun y n'a été trouvé.
               Sinon, retourne None pour le contre-exemple.
    """
    print(f"\nÉvaluation de '∀x ∃y P(x,y)' sur X={list(domain_x)}, Y={list(domain_y)}")
    for x in domain_x:
        found_y_for_x = False
        print(f"  Pour x = {x}:")
        for y in domain_y:
            if predicate(x, y):
                print(f"    P({x},{y}) est VRAI. (Témoin y={y} trouvé pour ce x)")
                found_y_for_x = True
                break  # Un y a été trouvé pour ce x, on passe au x suivant
            else:
                print(f"    P({x},{y}) est FAUX.")

        if not found_y_for_x:
            print(f"  AUCUN y n'a été trouvé pour x = {x}. La proposition est FAUSSE.")
            return False, x  # Contre-exemple trouvé

    print("  Pour chaque x, un y a été trouvé. La proposition est VRAIE.")
    return True, None


def evaluate_exists_for_all(predicate, domain_x, domain_y):
    """
    Évalue la proposition: Il existe un y dans domain_y tel que pour tout x dans domain_x, P(x,y).
    (∃y ∈ domain_y, ∀x ∈ domain_x tel que P(x,y))

    Args:
        predicate (callable): Une fonction P(x, y) qui retourne un booléen.
        domain_x (iterable): L'ensemble des valeurs possibles pour x.
        domain_y (iterable): L'ensemble des valeurs possibles pour y.

    Returns:
        tuple: (bool_result, witness_y_if_true)
               Si la proposition est vraie, retourne le premier y qui satisfait P(x,y) pour tous les x.
               Sinon, retourne None pour le témoin.
    """
    print(f"\nÉvaluation de '∃y ∀x P(x,y)' sur X={list(domain_x)}, Y={list(domain_y)}")
    for y in domain_y:
        all_x_satisfy_for_y = True
        print(f"  Pour y = {y}:")
        for x in domain_x:
            if not predicate(x, y):
                print(f"    P({x},{y}) est FAUX. (x={x} est un contre-exemple pour ce y)")
                all_x_satisfy_for_y = False
                break  # Ce y ne fonctionne pas pour tous les x
            else:
                print(f"    P({x},{y}) est VRAI.")

        if all_x_satisfy_for_y:
            print(f"  Ce y = {y} satisfait P(x,y) pour TOUS les x. La proposition est VRAIE.")
            return True, y  # Témoin trouvé

    print("  AUCUN y n'a été trouvé qui satisfasse P(x,y) pour tous les x. La proposition est FAUSSE.")
    return False, None


# --- Définition des domaines ---
DOMAIN_SMALL = [1, 2, 3]
DOMAIN_MEDIUM = [1, 2, 3, 4, 5]

# --- Définition des prédicats ---

# P1(x, y): x < y
def predicate_less_than(x, y):
    return x < y

# P2(x, y): x + y == 5
def predicate_sum_is_5(x, y):
    return x + y == 5

# P3(x, y): x est un diviseur de y
def predicate_x_divides_y(x, y):
    return y % x == 0

# P4(x, y): x * y == 6
def predicate_product_is_6(x, y):
    return x * y == 6

# --- Tests et Assertions ---
print("--- DÉBUT DES TESTS ---")

# --- Test 1: P(x,y) = x < y sur DOMAIN_SMALL ---
print("\n### Test 1: P(x,y) = x < y sur X=[1,2,3], Y=[1,2,3] ###")
# ∀x ∃y (x < y)
# Pour x=1, y=2 (ou 3) fonctionne.
# Pour x=2, y=3 fonctionne.
# Pour x=3, aucun y ne fonctionne. -> FAUX, contre-exemple x=3
result_1a, ce_1a = evaluate_for_all_exists(predicate_less_than, DOMAIN_SMALL, DOMAIN_SMALL)
assert result_1a is False
assert ce_1a == 3
print(f"Assertion 1a passée: ∀x ∃y (x < y) est FAUX avec contre-exemple x={ce_1a}")

# ∃y ∀x (x < y)
# Pour y=1: x=1,2,3 ne sont pas tous < 1.
# Pour y=2: x=2,3 ne sont pas tous < 2.
# Pour y=3: x=3 n'est pas < 3.
# -> FAUX, aucun y ne fonctionne.
result_1b, witness_1b = evaluate_exists_for_all(predicate_less_than, DOMAIN_SMALL, DOMAIN_SMALL)
assert result_1b is False
assert witness_1b is None
print(f"Assertion 1b passée: ∃y ∀x (x < y) est FAUX")

# --- Test 2: P(x,y) = x < y sur DOMAIN_SMALL pour x, DOMAIN_MEDIUM pour y ---
print("\n### Test 2: P(x,y) = x < y sur X=[1,2,3], Y=[1,2,3,4,5] ###")
# ∀x ∃y (x < y)
# Pour x=1, y=2 (ou 3,4,5) fonctionne.
# Pour x=2, y=3 (ou 4,5) fonctionne.
# Pour x=3, y=4 (ou 5) fonctionne.
# -> VRAI
result_2a, ce_2a = evaluate_for_all_exists(predicate_less_than, DOMAIN_SMALL, DOMAIN_MEDIUM)
assert result_2a is True
assert ce_2a is None
print(f"Assertion 2a passée: ∀x ∃y (x < y) est VRAI")

# ∃y ∀x (x < y)
# Pour y=1,2,3: ne fonctionne pas pour tous x.
# Pour y=4: x=1,2,3 sont tous < 4. -> VRAI, témoin y=4
result_2b, witness_2b = evaluate_exists_for_all(predicate_less_than, DOMAIN_SMALL, DOMAIN_MEDIUM)
assert result_2b is True
assert witness_2b == 4
print(f"Assertion 2b passée: ∃y ∀x (x < y) est VRAI avec témoin y={witness_2b}")

# --- Test 3: P(x,y) = x + y == 5 sur DOMAIN_SMALL ---
print("\n### Test 3: P(x,y) = x + y == 5 sur X=[1,2,3], Y=[1,2,3] ###")
# ∀x ∃y (x + y == 5)
# x=1, y=4 (pas dans Y)
# x=2, y=3 (dans Y)
# x=3, y=2 (dans Y)
# -> FAUX, contre-exemple x=1
result_3a, ce_3a = evaluate_for_all_exists(predicate_sum_is_5, DOMAIN_SMALL, DOMAIN_SMALL)
assert result_3a is False
assert ce_3a == 1
print(f"Assertion 3a passée: ∀x ∃y (x + y == 5) est FAUX avec contre-exemple x={ce_3a}")

# ∃y ∀x (x + y == 5)
# y=1: x+1==5 => x=4 (pas dans X)
# y=2: x+2==5 => x=3 (dans X, mais pas pour x=1,2)
# y=3: x+3==5 => x=2 (dans X, mais pas pour x=1,3)
# -> FAUX
result_3b, witness_3b = evaluate_exists_for_all(predicate_sum_is_5, DOMAIN_SMALL, DOMAIN_SMALL)
assert result_3b is False
assert witness_3b is None
print(f"Assertion 3b passée: ∃y ∀x (x + y == 5) est FAUX")

# --- Test 4: Négation des quantificateurs ---
print("\n### Test 4: Négation des quantificateurs ###")
# On va tester l'équivalence: ¬(∀x ∃y P(x,y)) <=> ∃x ∀y ¬P(x,y)
# Utilisons P(x,y) = x < y sur X=[1,2,3], Y=[1,2,3] (du Test 1a)
# Nous savons que (∀x ∃y (x < y)) est FAUX, avec contre-exemple x=3.
# Donc ¬(∀x ∃y (x < y)) devrait être VRAI.

# 1. Évaluation de ¬(∀x ∃y P(x,y))
result_neg_forall_exists, _ = evaluate_for_all_exists(predicate_less_than, DOMAIN_SMALL, DOMAIN_SMALL)
negation_result_1 = not result_neg_forall_exists
assert negation_result_1 is True
print(f"  ¬(∀x ∃y (x < y)) est {negation_result_1}")

# 2. Évaluation de ∃x ∀y ¬P(x,y)
# Où ¬P(x,y) est x >= y
def negated_predicate_less_than(x, y):
    return not predicate_less_than(x, y) # C'est-à-dire x >= y

# On cherche ∃x ∀y (x >= y)
# Pour x=1: y=1 (1>=1 Vrai), y=2 (1>=2 Faux) -> x=1 ne fonctionne pas
# Pour x=2: y=1 (2>=1 Vrai), y=2 (2>=2 Vrai), y=3 (2>=3 Faux) -> x=2 ne fonctionne pas
# Pour x=3: y=1 (3>=1 Vrai), y=2 (3>=2 Vrai), y=3 (3>=3 Vrai) -> x=3 fonctionne ! Témoin x=3
# Note: La fonction evaluate_exists_for_all est conçue pour ∃y ∀x P(x,y).
# Pour ∃x ∀y ¬P(x,y), nous devons inverser les rôles de domain_x et domain_y dans l'appel.
result_exists_forall_negated, witness_negated = evaluate_exists_for_all(negated_predicate_less_than, DOMAIN_SMALL, DOMAIN_SMALL)
# La fonction evaluate_exists_for_all renvoie (result, witness_y).
# Ici, notre "y" est en fait le "x" de la proposition ∃x ∀y ¬P(x,y).
assert result_exists_forall_negated is True
assert witness_negated == 3
print(f"  ∃x ∀y (x >= y) est {result_exists_forall_negated} avec témoin x={witness_negated}")

assert negation_result_1 == result_exists_forall_negated
print("Assertion 4 passée: ¬(∀x ∃y P(x,y)) <=> ∃x ∀y ¬P(x,y) est vérifiée.")


print("\n--- TOUS LES TESTS PASSÉS AVEC SUCCÈS ---")

```

### Explications du Code

1.  **`evaluate_for_all_exists(predicate, domain_x, domain_y)`**
    *   Cette fonction implémente la logique de `∀x ∃y P(x,y)`.
    *   Elle parcourt d'abord tous les éléments `x` du `domain_x` (boucle externe).
    *   Pour chaque `x`, elle tente de trouver un `y` dans `domain_y` qui satisfait le `predicate(x, y)` (boucle interne).
    *   Si un tel `y` est trouvé, `found_y_for_x` devient `True`, et la boucle interne est interrompue (`break`) car l'existence d'un `y` pour ce `x` est prouvée.
    *   Si, après avoir parcouru tous les `y` pour un `x` donné, aucun `y` n'a été trouvé (`not found_y_for_x`), cela signifie que la proposition `∀x ∃y P(x,y)` est fausse. Le `x` courant est alors un **contre-exemple**, et la fonction retourne `(False, x)`.
    *   Si toutes les itérations sur `x` se terminent sans trouver de contre-exemple, la proposition est vraie, et la fonction retourne `(True, None)`.

2.  **`evaluate_exists_for_all(predicate, domain_x, domain_y)`**
    *   Cette fonction implémente la logique de `∃y ∀x P(x,y)`.
    *   Elle parcourt d'abord tous les éléments `y` du `domain_y` (boucle externe).
    *   Pour chaque `y`, elle vérifie si ce `y` satisfait le `predicate(x, y)` pour *tous* les `x` dans `domain_x` (boucle interne).
    *   Si un `x` est trouvé pour lequel `predicate(x, y)` est faux, alors ce `y` ne peut pas être le témoin recherché. `all_x_satisfy_for_y` devient `False`, et la boucle interne est interrompue (`break`).
    *   Si, après avoir parcouru tous les `x` pour un `y` donné, `all_x_satisfy_for_y` est toujours `True`, cela signifie que ce `y` est un **témoin** qui satisfait `P(x,y)` pour tous les `x`. La proposition `∃y ∀x P(x,y)` est vraie, et la fonction retourne `(True, y)`.
    *   Si toutes les itérations sur `y` se terminent sans trouver de témoin, la proposition est fausse, et la fonction retourne `(False, None)`.

3.  **Prédicats et Domaines :**
    *   Des fonctions simples comme `predicate_less_than(x, y)` (`x < y`) ou `predicate_sum_is_5(x, y)` sont utilisées pour illustrer les concepts.
    *   Des listes d'entiers (`DOMAIN_SMALL`, `DOMAIN_MEDIUM`) servent de domaines finis.

4.  **Assertions (`assert`) :**
    *   Les assertions sont cruciales pour la validation. Elles vérifient que le résultat de l'évaluation (`True`/`False`) et le contre-exemple/témoin retourné sont conformes aux attentes logiques.
    *   Elles démontrent formellement que `∀x ∃y P(x,y)` et `∃y ∀x P(x,y)` ne sont pas équivalents en utilisant `predicate_less_than`.
    *   Elles valident l'équivalence de la négation : `¬(∀x ∃y P(x,y))` est testé contre `∃x ∀y ¬P(x,y)`. Pour cela, nous créons un `negated_predicate_less_than` et inversons les rôles des domaines dans l'appel à `evaluate_exists_for_all` pour correspondre à la structure `∃x ∀y`.
