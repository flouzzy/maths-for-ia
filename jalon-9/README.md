## Description
Calcul matriciel, opérations, inversibilité et représentations des applications linéaires.
Ce jalon explore le calcul matriciel, le produit de matrices, l'inversibilité, et la manière dont les matrices représentent formellement les applications linéaires entre espaces vectoriels.
