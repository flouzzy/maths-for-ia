\section{Origines et intuitions asymptotiques}

L'étude des phénomènes aléatoires, initialement circonscrite aux jeux de hasard, a pris une dimension analytique rigoureuse au tournant des XIXe et XXe siècles grâce aux travaux de mathématiciens russes tels que Pafnuty Chebyshev, Andrey Markov et Andrey Kolmogorov, ainsi que l'économiste et statisticien Eugen Slutsky. La question centrale qui animait ces chercheurs était de comprendre le comportement asymptotique des suites de variables aléatoires : lorsqu'une expérience est répétée une infinité de fois, de quelle manière la moyenne empirique converge-t-elle vers son espérance théorique ?

En mathématiques classiques, la convergence d'une suite de nombres réels est univoque et absolue. En probabilités, du fait de l'existence d'événements de mesure nulle (les fameux ensembles $\omega \in \Omega$ pour lesquels la propriété peut faire défaut sans affecter la probabilité globale), le concept de "proximité" entre variables aléatoires se décline sous plusieurs topologies distinctes. Il a fallu forger un arsenal d'outils analytiques pour mesurer si une suite de variables aléatoires $(X_n)$ s'approche d'une limite $X$ presque partout, en mesure, en moyenne ou seulement au niveau de ses répartitions (loi). Cette hiérarchie des modes de convergence permet d'isoler la nature exacte de la stabilité asymptotique d'un système.

\section{Définitions et Théorèmes Fondamentaux}

Dans ce qui suit, on considère un espace probabilisé $(\Omega, \mathcal{F}, \mathbb{P})$. Toutes les variables aléatoires considérées sont à valeurs réelles et définies sur cet espace. On s'intéresse à la convergence d'une suite $(X_n)_{n \in \mathbb{N}}$ vers une variable aléatoire $X$.

\subsection{Convergence Presque Sûre}

La convergence presque sûre est le mode de convergence le plus fort. Il stipule que la suite de fonctions $X_n(\omega)$ converge ponctuellement vers $X(\omega)$ pour presque toutes les réalisations $\omega$.

\textbf{Définition (Convergence Presque Sûre) :}
La suite $(X_n)$ converge presque sûrement vers $X$, noté $X_n \xrightarrow{p.s.} X$, si l'événement sur lequel la convergence ponctuelle a lieu possède une probabilité égale à $1$.
$$ \mathbb{P}\left( \left\{ \omega \in \Omega \mid \lim_{n \to \infty} X_n(\omega) = X(\omega) \right\} \right) = 1 $$

\textbf{Exemple Concret :}
Soit un espace $\Omega = [0, 1]$ muni de la mesure de Lebesgue $\mathbb{P}$. Définissons la variable aléatoire $X_n(\omega) = \omega^n$.
Pour tout $\omega \in [0, 1[$, on a $\lim_{n \to \infty} \omega^n = 0$.
Pour $\omega = 1$, on a $X_n(1) = 1$ pour tout $n$, donc $\lim_{n \to \infty} X_n(1) = 1$.
La limite simple est donc $X(\omega) = 0$ sur $[0, 1[$ et $X(1) = 1$.
Posons $Y = 0$ (variable aléatoire constante et égale à 0). On remarque que :
$$ \{ \omega \in [0, 1] \mid \lim_{n \to \infty} X_n(\omega) = Y(\omega) \} = [0, 1[ $$
Or, $\mathbb{P}([0, 1[) = 1$. Par conséquent, $X_n \xrightarrow{p.s.} 0$. Le singleton $\{1\}$ où la convergence fait défaut est de mesure nulle.


\textbf{Exemple Concret (Loi forte des grands nombres) :}
Considérons une suite infinie de lancers de dés équilibrés à 6 faces, où $X_i$ est le résultat du $i$-ème lancer. Les variables $X_i$ sont indépendantes et identiquement distribuées, d'espérance $\mu = 3.5$.
Définissons la moyenne empirique $S_n = \frac{1}{n} \sum_{i=1}^n X_i$.
La convergence presque sûre $S_n \xrightarrow{p.s.} 3.5$ signifie qu'en lançant les dés une infinité de fois, l'ensemble des scénarios (suites de lancers) pour lesquels la moyenne asymptotique n'est pas exactement $3.5$ est de probabilité strictement nulle. Sur le papier, une suite qui ne donnerait que des $6$ est possible (probabilité nulle mais ensemble non vide), mais elle n'apparaît "presque jamais".



\subsection{Convergence en Probabilité}

La convergence en probabilité est plus faible. Elle exige que pour tout seuil d'erreur fixé, la probabilité que l'écart entre $X_n$ et $X$ dépasse ce seuil tende vers zéro lorsque $n$ croît.

\textbf{Définition (Convergence en Probabilité) :}
La suite $(X_n)$ converge en probabilité vers $X$, noté $X_n \xrightarrow{\mathbb{P}} X$, si pour tout réel $\epsilon > 0$ :
$$ \lim_{n \to \infty} \mathbb{P}(|X_n - X| > \epsilon) = 0 $$

\textbf{Théorème (Implication p.s. $\implies$ en probabilité) :}
Si $X_n \xrightarrow{p.s.} X$, alors $X_n \xrightarrow{\mathbb{P}} X$. La réciproque est fausse en général.

\textbf{Contre-exemple (Convergence en probabilité n'implique pas presque sûre) :}
Définissons une suite d'événements sur $\Omega = [0, 1]$ muni de la mesure de Lebesgue. Considérons les intervalles mouvants ("machine à écrire") :
Pour $n \ge 1$, soit $k$ tel que $2^k \le n < 2^{k+1}$. Posons $m = n - 2^k$.
On définit l'intervalle $I_n = \left[ \frac{m}{2^k}, \frac{m+1}{2^k} \right]$.
Soit $X_n = \mathbf{1}_{I_n}$ (la fonction indicatrice de cet intervalle).
- Calculons la probabilité : $\mathbb{P}(|X_n - 0| > \epsilon) = \mathbb{P}(X_n = 1) = \text{longueur}(I_n) = \frac{1}{2^k}$.
Puisque $k \to \infty$ lorsque $n \to \infty$, la probabilité tend vers $0$. Donc $X_n \xrightarrow{\mathbb{P}} 0$.
- Cependant, pour tout $\omega \in [0, 1]$, la valeur $X_n(\omega)$ alternera entre $0$ et $1$ une infinité de fois, car pour chaque $k$, $\omega$ appartient à l'un des intervalles de la subdivision. Ainsi, $\limsup X_n(\omega) = 1$ et $\liminf X_n(\omega) = 0$. La suite ne converge ponctuellement pour \textbf{aucun} $\omega$. Donc $X_n$ ne converge pas presque sûrement.

\subsection{Convergence dans $L^p$ (en moyenne d'ordre $p$)}

Ce mode quantifie la "distance" fonctionnelle entre les variables.

\textbf{Définition (Convergence $L^p$) :}
Soit $p \ge 1$. On suppose que pour tout $n$, $\mathbb{E}[|X_n|^p] < \infty$ et $\mathbb{E}[|X|^p] < \infty$. La suite $(X_n)$ converge dans $L^p$ vers $X$, noté $X_n \xrightarrow{L^p} X$, si :
$$ \lim_{n \to \infty} \mathbb{E}[|X_n - X|^p] = 0 $$

\textbf{Exemple Concret (La "bosse" qui s'échappe) :}
Soit $X_n$ telle que $\mathbb{P}(X_n = n) = \frac{1}{n^2}$ et $\mathbb{P}(X_n = 0) = 1 - \frac{1}{n^2}$.
- Convergence en probabilité : Pour $\epsilon \in ]0, 1[$, $\mathbb{P}(|X_n - 0| > \epsilon) = \mathbb{P}(X_n = n) = \frac{1}{n^2} \to 0$. Donc $X_n \xrightarrow{\mathbb{P}} 0$.
- Convergence $L^1$ : $\mathbb{E}[|X_n - 0|] = n \cdot \frac{1}{n^2} = \frac{1}{n} \to 0$. Donc $X_n \xrightarrow{L^1} 0$.
- Convergence $L^2$ : $\mathbb{E}[|X_n - 0|^2] = n^2 \cdot \frac{1}{n^2} = 1$. Cette valeur ne tend pas vers $0$, donc $X_n$ ne converge pas vers $0$ dans $L^2$.

\subsection{Convergence en Loi (ou en Distribution)}

La convergence en loi est de nature fondamentalement différente. Elle ne compare pas les variables $X_n$ et $X$ sur le même espace d'états ponctuellement, mais se contente d'indiquer que la distribution statistique des valeurs de $X_n$ s'approche de celle de $X$.

\textbf{Définition (Convergence en Loi) :}
La suite $(X_n)$ converge en loi vers $X$, noté $X_n \xrightarrow{\mathcal{L}} X$, si pour toute fonction $f : \mathbb{R} \to \mathbb{R}$ continue et bornée :
$$ \lim_{n \to \infty} \mathbb{E}[f(X_n)] = \mathbb{E}[f(X)] $$
Ceci est équivalent à dire que la suite des fonctions de répartition $F_{X_n}(t) = \mathbb{P}(X_n \le t)$ converge vers $F_X(t) = \mathbb{P}(X \le t)$ en tout point $t$ où $F_X$ est continue.

\textbf{Exemple Concret :}
Soit $X \sim \mathcal{N}(0, 1)$ et $X_n = -X$. Évidemment, les variables sont identiques en loi pour tout $n$, donc $X_n$ converge en loi vers $X$ de manière triviale (la loi est $\mathcal{N}(0, 1)$ pour toutes).
Toutefois, $|X_n - X| = |-2X| = 2|X|$. La distance est constante et strictement positive avec probabilité 1, donc $X_n$ ne converge vers $X$ ni en probabilité, ni p.s.

\section{Démonstrations et Hiérarchie Strictes}

Le théorème suivant structure les relations d'implication entre les différents modes.

\textbf{Théorème (Hiérarchie de la Convergence) :}
1. La convergence dans $L^p$ implique la convergence en probabilité.
2. La convergence en probabilité implique la convergence en loi.

\subsection{Démonstration : $L^p \implies \text{Probabilité}$}

Nous voulons prouver que si $\lim_{n \to \infty} \mathbb{E}[|X_n - X|^p] = 0$, alors pour tout $\epsilon > 0$, $\lim_{n \to \infty} \mathbb{P}(|X_n - X| > \epsilon) = 0$.

\textbf{Preuve :}
Fixons $\epsilon > 0$. L'événement $\{|X_n - X| > \epsilon\}$ est strictement équivalent à $\{|X_n - X|^p > \epsilon^p\}$ car $x \mapsto x^p$ est strictement croissante pour $x \ge 0$ et $p \ge 1$.
Appliquons l'inégalité de Markov sur la variable aléatoire positive $Y_n = |X_n - X|^p$ et le seuil $a = \epsilon^p$ :
$$ \mathbb{P}(|X_n - X|^p > \epsilon^p) \le \frac{\mathbb{E}[|X_n - X|^p]}{\epsilon^p} $$
Par hypothèse de convergence dans $L^p$, on a $\lim_{n \to \infty} \mathbb{E}[|X_n - X|^p] = 0$.
Puisque le terme de droite tend vers $0$ (avec $\epsilon$ fixé), par encadrement, la probabilité du membre de gauche tend également vers $0$.
$$ \lim_{n \to \infty} \mathbb{P}(|X_n - X| > \epsilon) = 0 $$
La convergence en probabilité est démontrée.


\textbf{Exemple Concret (L'utilisation de Markov) :}
Soit une variable aléatoire $X_n$ telle que $X_n \sim \mathcal{U}(0, 1/n)$.
Calculons la norme $L^2$ : $\mathbb{E}[|X_n - 0|^2] = \int_0^{1/n} n x^2 dx = n [\frac{x^3}{3}]_0^{1/n} = \frac{1}{3n^2} \to 0$.
Donc $X_n \xrightarrow{L^2} 0$.
Vérifions la convergence en probabilité pour $\epsilon = 0.01$ :
$\mathbb{P}(|X_n| > 0.01) = 0$ dès que $1/n \le 0.01$ (soit $n \ge 100$).
La probabilité tend bien vers $0$, confirmant l'implication.


\subsection{Démonstration : $\text{Probabilité} \implies \text{Loi}$}

Nous voulons prouver que si $X_n \xrightarrow{\mathbb{P}} X$, alors pour toute fonction continue et bornée $f$, $\mathbb{E}[f(X_n)] \to \mathbb{E}[f(X)]$.

\textbf{Preuve :}
Soit $f$ une fonction continue et bornée, disons bornée par $M > 0$ (soit $|f(x)| \le M$ pour tout $x$).
Fixons un réel $\eta > 0$. Bien que $f$ soit continue, elle n'est pas uniformément continue sur tout $\mathbb{R}$. Mais en restreignant $X$ à un segment borné, nous pourrons contrôler les écarts.
Puisque $X$ est une variable aléatoire réelle, il existe un intervalle fini $K = [-A, A]$ tel que $\mathbb{P}(X \notin K) < \eta$.
Sur ce segment compact $K$, $f$ est uniformément continue (Théorème de Heine). Il existe donc $\delta > 0$ tel que pour tout $x \in K$ et $y \in \mathbb{R}$ vérifiant $|x - y| < \delta$, on ait $|f(x) - f(y)| < \eta$.

Décomposons l'espérance de la différence :
$$ |\mathbb{E}[f(X_n)] - \mathbb{E}[f(X)]| \le \mathbb{E}[|f(X_n) - f(X)|] $$
Introduisons les événements suivants pour partitionner $\Omega$ :
$E_1 = \{ |X_n - X| \ge \delta \}$
$E_2 = \{ |X_n - X| < \delta \} \cap \{ X \notin K \}$
$E_3 = \{ |X_n - X| < \delta \} \cap \{ X \in K \}$

Sur $E_1$, on majore brutalement par la borne : $|f(X_n) - f(X)| \le 2M$.
Sur $E_2$, on majore brutalement par $2M$.
Sur $E_3$, par uniforme continuité, $|f(X_n) - f(X)| \le \eta$.

En séparant l'espérance, on obtient :
$$ \mathbb{E}[|f(X_n) - f(X)|] \le 2M \cdot \mathbb{P}(E_1) + 2M \cdot \mathbb{P}(E_2) + \eta \cdot \mathbb{P}(E_3) $$
$$ \mathbb{E}[|f(X_n) - f(X)|] \le 2M \cdot \mathbb{P}(|X_n - X| \ge \delta) + 2M \cdot \mathbb{P}(X \notin K) + \eta \cdot 1 $$
Par hypothèse de convergence en probabilité, $\lim_{n \to \infty} \mathbb{P}(|X_n - X| \ge \delta) = 0$.
Par choix de $K$, $\mathbb{P}(X \notin K) < \eta$.
Donc, pour $n$ suffisamment grand :
$$ \mathbb{E}[|f(X_n) - f(X)|] \le 2M \cdot \eta + 2M \cdot \eta + \eta = (4M + 1)\eta $$
Puisque $\eta$ est arbitrairement petit, la limite supérieure de l'écart est nulle, ce qui prouve la convergence en loi.

\section{Applications en Physique, Logique et Intelligence Artificielle}

L'architecture conceptuelle des modes de convergence est la pierre angulaire de l'analyse asymptotique des algorithmes en IA et en physique statistique.

\subsection{Consistance des Estimateurs (Machine Learning)}
En théorie de l'apprentissage (PAC Learning), on construit des estimateurs $\hat{\theta}_n$ à partir d'un jeu de données de taille $n$. Un algorithme est dit \textbf{consistant} si l'estimateur converge en probabilité vers la vraie valeur des paramètres de la population, c'est-à-dire $\hat{\theta}_n \xrightarrow{\mathbb{P}} \theta^*$. Si la convergence a lieu presque sûrement ($\hat{\theta}_n \xrightarrow{p.s.} \theta^*$), on parle de \textbf{consistance forte}. La consistance garantit que l'accumulation de données est structurellement capable de débusquer la vérité.

\subsection{Descente de Gradient Stochastique (SGD)}
L'optimisation des réseaux de neurones profonds repose sur la minimisation d'une fonction de perte empirique via la descente de gradient stochastique. Sous des hypothèses strictes d'atténuation du pas d'apprentissage (condition de Robbins-Monro : $\sum \eta_n = \infty$ et $\sum \eta_n^2 < \infty$), on utilise des martingales pour démontrer que la suite des poids synaptiques $\theta_n$ converge \textbf{presque sûrement} vers un minimum local de la fonction d'erreur, assurant la stabilité finale du modèle d'IA malgré le bruit intrinsèque des mini-batchs.

\subsection{Théorèmes de Convergence en Loi en Physique Statistique}
En physique des particules, l'évolution macroscopique d'un gaz parfait résulte de l'agrégation de millions de variables aléatoires microscopiques. Le Théorème Central Limite (qui stipule que la moyenne de variables indépendantes et identiquement distribuées converge \textbf{en loi} vers une distribution normale) justifie mathématiquement pourquoi la distribution des vitesses des particules obéit universellement à la loi normale de Maxwell-Boltzmann, indépendamment des spécificités dynamiques sous-jacentes.


\part{Exercices d'Application et de Concours}
\subsection*{Exercice 01}

\quad $\bigstar\star\star\star\star$

\textbf{Énoncé :}
Soit une suite de variables aléatoires $X_n$ telles que $\mathbb{P}(X_n = 1) = \frac{1}{n}$ et $\mathbb{P}(X_n = 0) = 1 - \frac{1}{n}$.
Montrez que $X_n$ converge en probabilité vers la variable certaine $X = 0$.

\textbf{Correction :}
Nous devons montrer que pour tout $\epsilon > 0$, $\lim_{n \to \infty} \mathbb{P}(|X_n - 0| > \epsilon) = 0$.
Soit $\epsilon \in ]0, 1[$. Puisque $X_n$ ne prend que les valeurs $0$ et $1$, on a :
$$ \mathbb{P}(|X_n| > \epsilon) = \mathbb{P}(X_n = 1) = \frac{1}{n} $$
En passant à la limite lorsque $n \to \infty$ :
$$ \lim_{n \to \infty} \mathbb{P}(|X_n| > \epsilon) = \lim_{n \to \infty} \frac{1}{n} = 0 $$
Ainsi, $X_n \xrightarrow{\mathbb{P}} 0$.


\subsection*{Exercice 02}

\quad $\bigstar\star\star\star\star$

\textbf{Énoncé :}
Soit $X_n$ une suite de variables aléatoires suivant une loi uniforme discrète sur $\{1, 2, \dots, n\}$.
Montrez que $X_n/n$ ne converge pas en probabilité vers $0$.

\textbf{Correction :}
Soit $\epsilon = \frac{1}{2}$. On cherche la probabilité que $|X_n/n - 0| > \frac{1}{2}$.
$$ \mathbb{P}\left(\frac{X_n}{n} > \frac{1}{2}\right) = \mathbb{P}\left(X_n > \frac{n}{2}\right) $$
Puisque $X_n$ est uniforme sur $\{1, \dots, n\}$, il y a $\lfloor n/2 \rfloor$ entiers strictement supérieurs à $n/2$ dans cet ensemble (ou $\lceil n/2 \rceil$ selon la parité, dans tous les cas, environ la moitié).
$$ \mathbb{P}\left(X_n > \frac{n}{2}\right) \approx \frac{1}{2} $$
En passant à la limite :
$$ \lim_{n \to \infty} \mathbb{P}\left(\left| \frac{X_n}{n} \right| > \frac{1}{2}\right) = \frac{1}{2} \neq 0 $$
Par conséquent, $X_n/n$ ne converge pas en probabilité vers $0$.


\subsection*{Exercice 03}

\quad $\bigstar\bigstar\star\star\star$

\textbf{Énoncé :}
Pour l'exercice 1, étudiez la convergence de $X_n$ dans $L^1$ et dans $L^2$.

\textbf{Correction :}
Rappelons que $\mathbb{P}(X_n = 1) = \frac{1}{n}$ et $\mathbb{P}(X_n = 0) = 1 - \frac{1}{n}$.
\textbf{Convergence $L^1$ :}
On calcule l'espérance de l'écart :
$$ \mathbb{E}[|X_n - 0|] = 1 \cdot \mathbb{P}(X_n = 1) + 0 \cdot \mathbb{P}(X_n = 0) = \frac{1}{n} $$
Puisque $\lim_{n \to \infty} \frac{1}{n} = 0$, la suite converge dans $L^1$ vers $0$.

\textbf{Convergence $L^2$ :}
$$ \mathbb{E}[|X_n - 0|^2] = 1^2 \cdot \mathbb{P}(X_n = 1) + 0^2 \cdot \mathbb{P}(X_n = 0) = \frac{1}{n} $$
Puisque $\lim_{n \to \infty} \frac{1}{n} = 0$, la suite converge également dans $L^2$ vers $0$.


\subsection*{Exercice 04}

\quad $\bigstar\bigstar\star\star\star$

\textbf{Énoncé :}
Soit $U \sim \mathcal{U}([0,1])$. Définissons $Y_n = U^n$.
Étudiez la convergence en probabilité et presque sûre de la suite $Y_n$.

\textbf{Correction :}
\textbf{Convergence Presque Sûre :}
L'espace des réalisations est $\Omega = [0, 1]$. La variable aléatoire est $Y_n(\omega) = \omega^n$.
Pour tout $\omega \in [0, 1[$, on a $\lim_{n \to \infty} \omega^n = 0$.
Pour $\omega = 1$, $\lim_{n \to \infty} 1^n = 1$.
L'ensemble de convergence vers $0$ est $[0, 1[$. Puisque $U$ suit une loi uniforme, $\mathbb{P}(U = 1) = 0$.
Donc $\mathbb{P}\left(\lim_{n \to \infty} Y_n = 0\right) = 1$.
Ainsi, $Y_n \xrightarrow{p.s.} 0$.

\textbf{Convergence en probabilité :}
Puisque la convergence presque sûre implique la convergence en probabilité (Théorème du cours), nous pouvons conclure immédiatement que $Y_n \xrightarrow{\mathbb{P}} 0$.
(On peut aussi le vérifier à la main : $\mathbb{P}(U^n > \epsilon) = \mathbb{P}(U > \epsilon^{1/n}) = 1 - \epsilon^{1/n} \to 1 - 1 = 0$.)


\subsection*{Exercice 05}

\quad $\bigstar\bigstar\bigstar\star\star$

\textbf{Énoncé :}
Soit $X_n$ distribuée selon une loi Normale $\mathcal{N}\left(0, \frac{1}{n}\right)$.
Démontrez que $X_n$ converge en probabilité vers $0$ en utilisant l'inégalité de Bienaymé-Tchebychev.

\textbf{Correction :}
L'espérance de $X_n$ est $\mathbb{E}[X_n] = 0$ et sa variance est $\text{Var}(X_n) = \frac{1}{n}$.
Nous cherchons à évaluer $\mathbb{P}(|X_n - 0| > \epsilon)$ pour un $\epsilon > 0$ fixé.
D'après l'inégalité de Bienaymé-Tchebychev, pour toute variable aléatoire $Y$ d'espérance $\mu$ et de variance $\sigma^2$ :
$$ \mathbb{P}(|Y - \mu| \ge \epsilon) \le \frac{\sigma^2}{\epsilon^2} $$
Appliquée à $X_n$ :
$$ \mathbb{P}(|X_n| \ge \epsilon) \le \frac{1/n}{\epsilon^2} = \frac{1}{n\epsilon^2} $$
En passant à la limite quand $n \to \infty$, pour tout $\epsilon > 0$ fixe :
$$ \lim_{n \to \infty} \frac{1}{n\epsilon^2} = 0 $$
Ainsi, $\lim_{n \to \infty} \mathbb{P}(|X_n| \ge \epsilon) = 0$.
La suite converge bien en probabilité vers $0$.


\subsection*{Exercice 06}

\quad $\bigstar\bigstar\bigstar\star\star$

\textbf{Énoncé :}
Soit $Z_n$ une suite de variables aléatoires telles que $\mathbb{P}(Z_n = \sqrt{n}) = \frac{1}{n}$ et $\mathbb{P}(Z_n = 0) = 1 - \frac{1}{n}$.
Montrez que $Z_n$ converge en probabilité vers $0$, mais qu'elle ne converge pas dans $L^2$.

\textbf{Correction :}
\textbf{Convergence en Probabilité :}
Soit $\epsilon \in ]0, 1[$. Puisque $Z_n$ vaut $0$ ou $\sqrt{n}$ (avec $n \ge 1$), on a :
$$ \mathbb{P}(|Z_n - 0| > \epsilon) = \mathbb{P}(Z_n = \sqrt{n}) = \frac{1}{n} $$
Par passage à la limite, $\lim_{n \to \infty} \mathbb{P}(|Z_n| > \epsilon) = 0$. Donc $Z_n \xrightarrow{\mathbb{P}} 0$.

\textbf{Convergence $L^2$ :}
Calculons l'espérance du carré :
$$ \mathbb{E}[|Z_n - 0|^2] = (\sqrt{n})^2 \cdot \mathbb{P}(Z_n = \sqrt{n}) + 0^2 \cdot \mathbb{P}(Z_n = 0) $$
$$ \mathbb{E}[Z_n^2] = n \cdot \frac{1}{n} = 1 $$
La limite de $\mathbb{E}[|Z_n - 0|^2]$ est $1$, qui n'est pas égale à $0$. Par conséquent, $Z_n$ ne converge pas vers $0$ dans l'espace de Hilbert $L^2$.


\subsection*{Exercice 07}

\quad $\bigstar\bigstar\bigstar\bigstar\star$

\textbf{Énoncé :}
Soit $W_n$ distribuée uniformément sur $[-n, n]$. Considérons la suite normée $V_n = \frac{W_n}{n}$.
Vers quelle loi la suite $V_n$ converge-t-elle ? Démontrez-le formellement à l'aide des fonctions de répartition.

\textbf{Correction :}
Déterminons d'abord la loi de $V_n$. Pour tout $x \in [-1, 1]$, on a :
$$ F_{V_n}(x) = \mathbb{P}(V_n \le x) = \mathbb{P}\left(\frac{W_n}{n} \le x\right) = \mathbb{P}(W_n \le nx) $$
Puisque $W_n$ suit $\mathcal{U}([-n, n])$, sa densité est $\frac{1}{2n}$ sur cet intervalle.
$$ \mathbb{P}(W_n \le nx) = \int_{-n}^{nx} \frac{1}{2n} dt = \frac{nx - (-n)}{2n} = \frac{n(x+1)}{2n} = \frac{x+1}{2} $$
Ainsi, pour tout $x \in [-1, 1]$, $F_{V_n}(x) = \frac{x+1}{2}$, indépendamment de $n$.
Pour $x < -1$, $F_{V_n}(x) = 0$, et pour $x > 1$, $F_{V_n}(x) = 1$.

Puisque $F_{V_n}(x)$ est constante par rapport à $n$, la limite est exactement cette même fonction :
$$ \lim_{n \to \infty} F_{V_n}(x) = \begin{cases} 0 \& \text{si } x < -1 \\ \frac{x+1}{2} \& \text{si } -1 \le x \le 1 \\ 1 \& \text{si } x > 1 \end{cases} $$
On reconnaît la fonction de répartition d'une variable aléatoire uniforme sur $[-1, 1]$.
Ainsi, $V_n$ converge en loi vers $V \sim \mathcal{U}([-1, 1])$. En fait, toutes les $V_n$ ont exactement cette loi.


\subsection*{Exercice 08}

\quad $\bigstar\bigstar\bigstar\bigstar\star$

\textbf{Énoncé :}
Prouvez que la convergence en probabilité vers une constante implique la convergence en loi vers cette même constante. (Cas particulier du théorème du cours).

\textbf{Correction :}
Soit $X_n \xrightarrow{\mathbb{P}} c$ où $c \in \mathbb{R}$ est une constante déterministe. On veut montrer que $\lim F_{X_n}(x) = F_c(x)$ pour tout point de continuité de $F_c$.
La fonction de répartition de $c$ est la fonction indicatrice (Dirac en $c$) :
$$ F_c(x) = \begin{cases} 0 \& \text{si } x < c \\ 1 \& \text{si } x \ge c \end{cases} $$
Le seul point de discontinuité est $x = c$. Il suffit donc de vérifier la convergence pour $x < c$ et pour $x > c$.

\textbf{Cas 1 : $x < c$.} Posons $\epsilon = c - x > 0$.
$$ \mathbb{P}(X_n \le x) = \mathbb{P}(X_n - c \le x - c) = \mathbb{P}(X_n - c \le -\epsilon) \le \mathbb{P}(|X_n - c| \ge \epsilon) $$
Par hypothèse, $\mathbb{P}(|X_n - c| \ge \epsilon) \to 0$, donc $\mathbb{P}(X_n \le x) \to 0 = F_c(x)$.

\textbf{Cas 2 : $x > c$.} Posons $\epsilon = x - c > 0$.
$$ \mathbb{P}(X_n \le x) = 1 - \mathbb{P}(X_n > x) = 1 - \mathbb{P}(X_n - c > x - c) = 1 - \mathbb{P}(X_n - c > \epsilon) $$
Puisque $\mathbb{P}(X_n - c > \epsilon) \le \mathbb{P}(|X_n - c| > \epsilon) \to 0$, on a :
$$ \mathbb{P}(X_n \le x) \to 1 = F_c(x) $$
Ceci prouve la convergence en loi vers $c$.


\subsection*{Exercice 09}

\quad $\bigstar\bigstar\bigstar\bigstar\bigstar$

\textbf{Énoncé :}
Montrez que si une suite de variables aléatoires converge en probabilité, alors on peut en extraire une sous-suite qui converge presque sûrement.

\textbf{Correction :}
Soit $X_n \xrightarrow{\mathbb{P}} X$. Par définition, pour tout $\epsilon > 0$, $\mathbb{P}(|X_n - X| > \epsilon) \to 0$.
Construisons la sous-suite par extraction. Pour chaque entier $k \ge 1$, fixons $\epsilon_k = \frac{1}{2^k}$.
Puisque la probabilité tend vers zéro, il existe un rang $n_k$ (que l'on peut choisir strictement croissant : $n_1 < n_2 < \dots$) tel que :
$$ \mathbb{P}\left(|X_{n_k} - X| > \frac{1}{2^k}\right) < \frac{1}{2^k} $$
Considérons les événements $A_k = \left\{|X_{n_k} - X| > \frac{1}{2^k}\right\}$.
La somme des probabilités est une série géométrique convergente :
$$ \sum_{k=1}^\infty \mathbb{P}(A_k) < \sum_{k=1}^\infty \frac{1}{2^k} = 1 < \infty $$
D'après le premier Lemme de Borel-Cantelli, la probabilité que les $A_k$ se réalisent infiniment souvent est nulle :
$$ \mathbb{P}(\limsup A_k) = 0 $$
Ainsi, presque sûrement, seuls un nombre fini de $A_k$ se réalisent. Cela implique que pour presque tout $\omega \in \Omega$, il existe un entier $K(\omega)$ tel que pour tout $k \ge K(\omega)$ :
$$ |X_{n_k}(\omega) - X(\omega)| \le \frac{1}{2^k} $$
En passant à la limite lorsque $k \to \infty$, l'écart tend vers $0$ presque sûrement.
Donc $X_{n_k} \xrightarrow{p.s.} X$.


\subsection*{Exercice 10}

\quad $\bigstar\bigstar\bigstar\bigstar\bigstar$

\textbf{Énoncé :}
Théorème de Slutsky (Cas Particulier).
Soient $X_n \xrightarrow{\mathcal{L}} X$ (convergence en loi) et $Y_n \xrightarrow{\mathbb{P}} c$ (convergence en probabilité vers une constante $c$).
Montrez que la somme $X_n + Y_n \xrightarrow{\mathcal{L}} X + c$.

\textbf{Correction :}
Nous voulons montrer que pour toute fonction $f$ continue et bornée (et supposons-la uniformément continue, ce qui suffit par densité), $\mathbb{E}[f(X_n + Y_n)] \to \mathbb{E}[f(X + c)]$.
Décomposons la différence :
$$ |\mathbb{E}[f(X_n + Y_n)] - \mathbb{E}[f(X + c)]| \le \mathbb{E}[|f(X_n + Y_n) - f(X_n + c)|] + |\mathbb{E}[f(X_n + c)] - \mathbb{E}[f(X + c)]| $$

1. \textbf{Deuxième terme :} Puisque $X_n \xrightarrow{\mathcal{L}} X$, et que la fonction $g(x) = f(x + c)$ est continue et bornée, on a par définition de la convergence en loi :
$$ \lim_{n \to \infty} \mathbb{E}[f(X_n + c)] = \mathbb{E}[f(X + c)] $$
Donc le deuxième terme tend vers zéro.

2. \textbf{Premier terme :} Soit $M$ un majorant de $f$. Pour un $\epsilon > 0$ donné, par uniforme continuité de $f$, il existe $\delta > 0$ tel que si $|a - b| < \delta$, alors $|f(a) - f(b)| < \epsilon$.
Ici $| (X_n + Y_n) - (X_n + c) | = |Y_n - c|$.
On sépare l'espérance en conditionnant par $|Y_n - c| < \delta$ et $|Y_n - c| \ge \delta$ :
$$ \mathbb{E}[|f(X_n + Y_n) - f(X_n + c)|] \le \epsilon \cdot \mathbb{P}(|Y_n - c| < \delta) + 2M \cdot \mathbb{P}(|Y_n - c| \ge \delta) $$
Or, puisque $Y_n \xrightarrow{\mathbb{P}} c$, on sait que $\lim_{n \to \infty} \mathbb{P}(|Y_n - c| \ge \delta) = 0$.
Ainsi, en prenant la limite sup :
$$ \limsup_{n \to \infty} \mathbb{E}[|f(X_n + Y_n) - f(X_n + c)|] \le \epsilon \cdot 1 + 2M \cdot 0 = \epsilon $$
Puisque $\epsilon$ est arbitraire, ce terme tend vers $0$.

En additionnant les deux résultats, on trouve que $\lim_{n \to \infty} \mathbb{E}[f(X_n + Y_n)] = \mathbb{E}[f(X + c)]$, ce qui démontre la convergence en loi de la somme.

\subsection*{TP 01 : Simulation de la Convergence en Probabilité}

Ce TP illustre la convergence en probabilité de la moyenne empirique (Loi Faible des Grands Nombres) avec des variables de Bernoulli.

\begin{lstlisting}
import math
import random

def moyenne_empirique_bernoulli(n, p=0.5):
    # Genere n tirages et retourne la moyenne
    succes = sum(1 for _ in range(n) if random.random() < p)
    return succes / n

def simuler_convergence_probabilite(n_tirages, n_simulations, epsilon, p=0.5):
    # Estime empiriquement P(|X_n - p| > epsilon)
    depassements = 0
    for _ in range(n_simulations):
        moyenne = moyenne_empirique_bernoulli(n_tirages, p)
        if abs(moyenne - p) > epsilon:
            depassements += 1
    return depassements / n_simulations

# Test de validation (N doit etre assez grand)
N = 1000
simulations = 500
epsilon = 0.05

prob_depassement = simuler_convergence_probabilite(N, simulations, epsilon)
# Selon l inegalite de Tchebychev, la proba doit etre faible
print("Probabilite empirique de depassement :", prob_depassement)
assert prob_depassement < 0.2, "La probabilite devrait converger vers 0"
\end{lstlisting}


\subsection*{TP 02 : La variable fuyante (Pas de convergence L2)}

Nous codons la suite X_n qui vaut sqrt(n) avec probabilité 1/n, et 0 sinon.
On vérifie qu'elle converge en probabilité vers 0, mais que son espérance L2 reste à 1.

\begin{lstlisting}
import random
import math

def echantillonner_Xn(n):
    if random.random() < (1.0 / n):
        return math.sqrt(n)
    return 0.0

def estimer_L2(n, n_simulations):
    somme_carres = 0.0
    for _ in range(n_simulations):
        val = echantillonner_Xn(n)
        somme_carres += val * val
    return somme_carres / n_simulations

def estimer_proba_depassement(n, epsilon, n_simulations):
    depassements = 0
    for _ in range(n_simulations):
        val = echantillonner_Xn(n)
        if abs(val) > epsilon:
            depassements += 1
    return depassements / n_simulations

# Validation
n_grand = 1000
simulations = 5000

# Convergence en probabilite
proba = estimer_proba_depassement(n_grand, 0.1, simulations)
assert proba < 0.05, "La probabilite devrait etre proche de 1/n"

# Non convergence en L2
l2_empirique = estimer_L2(n_grand, simulations)
# L2 doit tourner autour de 1.0 (et non 0)
print("Esperance L2 empirique :", l2_empirique)
assert 0.5 < l2_empirique < 1.5, "L esperance du carre doit etre proche de 1"
\end{lstlisting}


\subsection*{TP 03 : Convergence en Loi vers l'Uniforme}

Nous allons simuler X\underline{n = W}n / n où W_n suit un uniforme discret (ou continu) sur [-n, n], et vérifier que la fonction de répartition empirique approche celle de U([-1, 1]).

\begin{lstlisting}
import random

def echantillonner_Vn(n):
    W_n = random.uniform(-n, n)
    return W_n / n

def fonction_repartition_empirique(n, point_evaluation, n_simulations):
    # Estime F_{V_n}(x)
    inferieurs = 0
    for _ in range(n_simulations):
        if echantillonner_Vn(n) <= point_evaluation:
            inferieurs += 1
    return inferieurs / n_simulations

# Pour x = 0, F(0) d'une uniforme sur [-1, 1] vaut 0.5
valeur_x = 0.0
n = 50
simulations = 2000

f_emp = fonction_repartition_empirique(n, valeur_x, simulations)
print("F_Vn(0) empirique :", f_emp)
assert 0.45 < f_emp < 0.55, "La repartition en 0 doit etre d'environ 0.5"

# Pour x = -0.5, F(-0.5) = (-0.5 + 1)/2 = 0.25
f_emp_2 = fonction_repartition_empirique(n, -0.5, simulations)
assert 0.20 < f_emp_2 < 0.30, "La repartition en -0.5 doit etre d'environ 0.25"
\end{lstlisting}


\subsection*{TP 04 : L'échec de la réciproque (Probabilité n'implique pas presque sûre)}

On code le contre-exemple de la "machine à écrire" avec les intervalles tournants.
On montre que la probabilité d'erreur à un temps n est faible, mais que chaque chemin fini toujours par faire des erreurs à l'infini (pas de convergence p.s.).

\begin{lstlisting}
import math

def intervalle_machine_a_ecrire(n):
    # Pour n>=1, trouve k tel que 2^k <= n < 2^{k+1}
    k = int(math.floor(math.log(n, 2)))
    m = n - (2**k)
    borne_inf = m / (2**k)
    borne_sup = (m + 1) / (2**k)
    return borne_inf, borne_sup

def est_dans_intervalle(omega, n):
    borne_inf, borne_sup = intervalle_machine_a_ecrire(n)
    return borne_inf <= omega < borne_sup

# On fixe un omega = 0.3
omega_fixe = 0.3
nb_erreurs = 0
# Sur 100 etapes, cet omega devrait "tomber" dans la bosse plusieurs fois.
for n in range(1, 101):
    if est_dans_intervalle(omega_fixe, n):
        nb_erreurs += 1

print("Nombre de sauts a 1 pour omega=0.3 sur 100 etapes :", nb_erreurs)
assert nb_erreurs > 3, "Il doit y avoir plusieurs pics pour un omega fixe (pas de conv p.s.)"

# En probabilite : a l'etape 64 (k=6), l'intervalle est de taille 1/64
inf, sup = intervalle_machine_a_ecrire(64)
taille = sup - inf
assert abs(taille - 1/64) < 1e-9, "L'intervalle doit etre de proba petite"
\end{lstlisting}


\subsection*{TP 05 : Convergence en L1 vs L2 pour un estimateur perturbé}

On construit une variable Y_n définie ainsi : elle vaut 0 avec proba 1 - 1/n,
et n^(2/3) avec proba 1/n.
Dans ce script on valide mathématiquement qu'elle converge dans L1 mais diverge dans L2.

\begin{lstlisting}
import random

def generer_Yn(n):
    if random.random() < 1/n:
        return n**(2/3)
    return 0.0

def estimer_L1_L2(n, n_simulations):
    somme_l1 = 0
    somme_l2 = 0
    for _ in range(n_simulations):
        val = generer_Yn(n)
        somme_l1 += abs(val)
        somme_l2 += val * val
    return somme_l1 / n_simulations, somme_l2 / n_simulations

# Validation
n = 1000
simul = 2000

# E[L1] theorique = (1/n) * n^(2/3) = n^(-1/3)
# E[L2] theorique = (1/n) * n^(4/3) = n^(1/3)

theorique_L1 = n**(-1/3)
theorique_L2 = n**(1/3)

empirique_L1, empirique_L2 = estimer_L1_L2(n, simul)

# L1 doit etre petit (tend vers 0)
print("L1 empirique :", empirique_L1)
assert empirique_L1 < 0.5, "L1 doit etre decroissant vers 0"

# L2 doit etre grand (tend vers l infini)
print("L2 empirique :", empirique_L2)
assert empirique_L2 > 5.0, "L2 diverge"
\end{lstlisting}
