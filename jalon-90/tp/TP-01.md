# TP 1 : Simulation Monte Carlo de la Convergence Presque Sûre

Objectif : Simuler des trajectoires pour visualiser la différence entre une convergence individuelle certaine et la convergence en probabilité.

```python
import random
import math

def simulate_trajectories(num_trajectories, num_steps):
    """
    Simule des variables aléatoires X_n = omega^n où omega est tiré uniformément.
    Vérifie que pour chaque trajectoire (presque sûrement), la limite est 0.
    """
    trajectories = []
    for _ in range(num_trajectories):
        omega = random.uniform(0, 1)
        path = []
        for n in range(1, num_steps + 1):
            path.append(omega ** n)
        trajectories.append(path)
    return trajectories

if __name__ == "__main__":
    paths = simulate_trajectories(100, 50)
    # Verification : l'écrasante majorité des chemins doivent terminer près de 0
    endpoints = [path[-1] for path in paths]
    assert max(endpoints) < 0.1, "La convergence vers 0 n'est pas constatée dans la simulation"
    print("Simulation réussie. Presque toutes les trajectoires convergent vers 0.")

```
