# TP 01 : Simulation de la Convergence en Probabilité (Loi Faible des Grands Nombres)

Ce TP illustre la convergence en probabilité de la moyenne empirique (Loi Faible des Grands Nombres) en utilisant des variables aléatoires de Bernoulli indépendantes.
Le code implémente de zéro la simulation probabiliste et quantifie asymptotiquement les écarts, sans aucune librairie de haut niveau.

```python
import random

def generer_bernoulli(p):
    # Generateur de Bernoulli depuis l'uniforme
    return 1 if random.random() < p else 0

def moyenne_empirique_bernoulli(n, p=0.5):
    # Genere n tirages independants et retourne leur moyenne
    succes = sum(generer_bernoulli(p) for _ in range(n))
    return succes / n

def simuler_convergence_probabilite(n_tirages, n_simulations, epsilon, p=0.5):
    # Estime empiriquement la probabilite P(|X_n - p| > epsilon)
    depassements = 0
    for _ in range(n_simulations):
        moyenne = moyenne_empirique_bernoulli(n_tirages, p)
        if abs(moyenne - p) > epsilon:
            depassements += 1
    return depassements / n_simulations

# Bloc de validation analytique (Verification des axiomes asympotiques)
p_theorique = 0.5
epsilon_marge = 0.05
n_simulations_mc = 1000

# Cas avec peu de tirages (la variance est haute, la probabilite de depassement est forte)
N_petit = 10
prob_petit = simuler_convergence_probabilite(N_petit, n_simulations_mc, epsilon_marge, p_theorique)
print("Pour n=10, proba de depassement :", prob_petit)

# Cas avec beaucoup de tirages (Convergence en probabilites enclenchee)
N_grand = 1000
prob_grand = simuler_convergence_probabilite(N_grand, n_simulations_mc, epsilon_marge, p_theorique)
print("Pour n=1000, proba de depassement :", prob_grand)

# Validation stricte des theoremes
assert prob_petit > prob_grand, "La probabilite d'erreur doit decroitre avec N"
assert prob_grand < 0.05, "La probabilite d'erreur pour N=1000 doit tendre vers 0"
```
