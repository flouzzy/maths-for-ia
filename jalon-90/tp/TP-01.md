# TP 1 : Simulation de la loi faible des grands nombres

Ce TP illustre la convergence en probabilité de la moyenne empirique (Loi Faible des Grands Nombres).

```python
import math
import random

def moyenne_empirique(n):
    # Tirage de n variables uniformes sur [0, 1]
    somme = sum(random.random() for _ in range(n))
    return somme / n

def tester_loi_faible(n_simulations, n_echantillons, epsilon):
    # La vraie espérance est 0.5
    esperance = 0.5
    compteur_hors_limite = 0

    for _ in range(n_simulations):
        moyenne = moyenne_empirique(n_echantillons)
        if abs(moyenne - esperance) > epsilon:
            compteur_hors_limite += 1

    probabilite_hors_limite = compteur_hors_limite / n_simulations
    return probabilite_hors_limite

# Vérification : Plus n_echantillons grandit, plus la probabilité s'approche de 0
prob_n10 = tester_loi_faible(1000, 10, 0.1)
prob_n100 = tester_loi_faible(1000, 100, 0.1)
prob_n1000 = tester_loi_faible(1000, 1000, 0.1)

assert prob_n10 > prob_n100, "La probabilité d'erreur devrait diminuer."
assert prob_n100 > prob_n1000, "La probabilité d'erreur devrait diminuer."
assert prob_n1000 < 0.05, "Pour n=1000, l'erreur devrait être très rare."
print("TP1: Convergence en probabilité validée.")
```
