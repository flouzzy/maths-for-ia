# TP 4 : Inégalité de Markov et de Bienaymé-Chebyshev

Ce TP vérifie empiriquement que la borne fournie par l'inégalité de Bienaymé-Chebyshev (qui sert à prouver la convergence en probabilité dans la loi faible des grands nombres) est bien respectée.

```python
import random

# On va utiliser une variable aléatoire simple : lancer d'un dé équilibré à 6 faces
# X dans {1, 2, 3, 4, 5, 6}
esperance = 3.5
# Variance = (35/12) = 2.9166...
variance = (6**2 - 1) / 12

def lancer_de():
    return random.randint(1, 6)

nb_lancers = 100000
resultats = [lancer_de() for _ in range(nb_lancers)]

def probabilite_empirique_ecart(epsilon, res, esp):
    count = 0
    for val in res:
        if abs(val - esp) >= epsilon:
            count += 1
    return count / len(res)

epsilons = [1.0, 1.5, 2.0, 2.5]
print("Vérification de l'Inégalité de Bienaymé-Chebyshev : P(|X - E| >= e) <= Var / e^2")
for eps in epsilons:
    p_empirique = probabilite_empirique_ecart(eps, resultats, esperance)
    borne_chebyshev = variance / (eps**2)
    # L'inégalité est-elle respectée ?
    respecte = p_empirique <= borne_chebyshev

    print(f"Epsilon = {eps:<3} | P_emp = {p_empirique:.4f} | Borne = {borne_chebyshev:.4f} | Respecté = {respecte}")

    # Assertions mathématiques
    assert respecte, f"Erreur de théorème : La borne de Chebyshev est violée pour epsilon={eps}"

print("Validation mathématique : Toutes les bornes théoriques sont strictement respectées, garantissant le mécanisme de la convergence en probabilité.")
```
