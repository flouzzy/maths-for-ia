# TP 02 : Divergence L1 de la bosse fuyante

Nous allons simuler l'exemple de la "bosse fuyante" : $X_n$ vaut $n^2$ avec probabilité $1/n$ et $0$ sinon.
Nous vérifierons numériquement que $X_n$ converge en probabilité vers $0$, mais que son espérance diverge.

```python
import random

def simuler_Xn(n):
    if random.random() < (1.0 / n):
        return n * n
    return 0

def estimer_esperance(n, n_simulations):
    somme = sum(simuler_Xn(n) for _ in range(n_simulations))
    return somme / n_simulations

def estimer_proba_ecart(n, epsilon, n_simulations):
    depassements = sum(1 for _ in range(n_simulations) if simuler_Xn(n) > epsilon)
    return depassements / n_simulations

n_simulations = 5000
epsilon = 0.1

n_valeurs = [10, 50, 200]

esperances = []
probas = []

for n in n_valeurs:
    esperances.append(estimer_esperance(n, n_simulations))
    probas.append(estimer_proba_ecart(n, epsilon, n_simulations))

print("Esperances (L1) :", esperances)
print("Probabilites ecart :", probas)

# Assertions : l'esperance doit croitre (divergence L1), la proba doit decroitre (convergence Proba)
assert esperances[2] > esperances[0], "L'espérance doit diverger vers l'infini"
assert probas[2] < probas[0], "La probabilité d'écart doit tendre vers 0"
```
