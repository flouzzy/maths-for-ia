# TP 02 : Absence de Convergence Presque Sûre ("La Machine à Écrire")

Ce script modélise explicitement le contre-exemple fondamental de la "machine à écrire".
Nous démontrons computationnellement que bien que la suite converge en probabilité et dans L1, pour chaque réalisation fixée, la limite supérieure vaut 1 et la limite inférieure vaut 0.

```python
import random

def evaluer_machine_a_ecrire(n, omega):
    # La variable depend de la position de omega dans la partition dyadique de niveau k
    # On trouve k tel que 2^k <= n < 2^(k+1)
    k = 0
    while (1 << (k + 1)) <= n:
        k += 1
    m = n - (1 << k)

    # L'intervalle est [m/2^k, (m+1)/2^k]
    borne_inf = m / (1 << k)
    borne_sup = (m + 1) / (1 << k)

    if borne_inf <= omega <= borne_sup:
        return 1
    return 0

def analyser_limites_ponctuelles(omega, N_max):
    # Historique de la realisation omega sur les N_max premieres variables de la suite
    trajectoire = [evaluer_machine_a_ecrire(n, omega) for n in range(1, N_max + 1)]
    # Evaluation sur le dernier bloc de 100 iterations pour la lim sup / lim inf
    dernier_segment = trajectoire[-100:] if N_max > 100 else trajectoire
    lim_sup = max(dernier_segment)
    lim_inf = min(dernier_segment)
    return lim_sup, lim_inf

# Bloc de validation mathématique
N_iterations = 2000

# Fixons un echantillon (omega arbitraire)
omega_cible = 0.42

limite_superieure, limite_inferieure = analyser_limites_ponctuelles(omega_cible, N_iterations)

print(f"Trajectoire pour omega={omega_cible} : lim_sup={limite_superieure}, lim_inf={limite_inferieure}")

# Verification stricte de l'absence de convergence p.s.
assert limite_superieure == 1, "La limite superieure doit valoir 1 car le bloc finit toujours par passer sur omega"
assert limite_inferieure == 0, "La limite inferieure doit valoir 0 car le bloc s'echappe de omega"
```
