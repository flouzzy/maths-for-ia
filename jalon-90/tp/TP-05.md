# TP 5 : Non-convergence Presque Sûre (La suite de la machine à écrire)

Nous implémentons la suite d'indicatrices glissantes (typewriter sequence) qui converge en probabilité vers 0, mais qui ne converge en aucun point presque sûrement car elle vaut 1 une infinité de fois pour tout $\omega$.

```python
import random

def typewriter_sequence(omega, n_max):
    # La suite est A_1, A_2, A_3 ...
    # n = 2^k + j - 1. A_n = ](j-1)/2^k, j/2^k]
    # On renvoie la séquence X_1(omega), ..., X_n_max(omega)
    seq = []
    k = 0
    j = 1
    for n in range(1, n_max + 1):
        # Limites de l'intervalle A_n
        borne_inf = (j - 1) / (2**k)
        borne_sup = j / (2**k)

        # X_n = Indicatrice de A_n
        val = 1 if borne_inf < omega <= borne_sup else 0
        seq.append(val)

        # Passage au sous-intervalle suivant
        j += 1
        if j > 2**k:
            # On passe à la puissance de 2 suivante (nouvelle série de balayage)
            k += 1
            j = 1
    return seq

# Choisissons un point quelconque, par exemple omega = 0.3
omega = 0.3
n_max = 50
seq = typewriter_sequence(omega, n_max)

print(f"Valeurs de la suite pour omega = {omega} sur les {n_max} premières itérations :")
print(seq)

# On compte le nombre de fois où la suite vaut 1.
# Mathématiquement, comme elle balaie [0,1] infiniment, elle doit repasser à 1 régulièrement.
nb_uns = sum(seq)
print(f"Nombre de fois où X_n(omega) = 1 : {nb_uns}")

# Validation : la suite ne se stabilise pas à 0.
# Dans les 50 premières itérations, k va jusqu'à 5 (2^5 = 32), donc la suite devrait valoir au moins 5 fois 1.
assert nb_uns >= 5, "La suite ne vaut pas 1 une infinité de fois comme prévu théoriquement."
print("Validation mathématique : La suite n'est pas stationnaire et ne converge donc pas presque sûrement, bien qu'elle converge en probabilité (la largeur des fenêtres tend vers 0).")
```
