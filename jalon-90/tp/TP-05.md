# TP 5 : Simulation du Lemme de Borel-Cantelli

Ce TP vérifie le premier lemme de Borel-Cantelli en comptant le nombre de fois qu'un événement rare se produit.

```python
import random

def simulation_borel_cantelli(n_max):
    # Les probabilités sont p_n = 1/n^2. La somme converge.
    compteur_realisations = 0
    for n in range(1, n_max + 1):
        p_n = 1.0 / (n**2)
        u = random.random()
        if u < p_n:
            compteur_realisations += 1
    return compteur_realisations

# On simule 100 fois la suite jusqu'à n=1000
nb_moyens = 0
n_simul = 100
for _ in range(n_simul):
    nb_moyens += simulation_borel_cantelli(1000)

moyenne_occurrences = nb_moyens / n_simul

# L'espérance du nombre d'événements est la somme des 1/n^2, qui vaut environ pi^2/6 ~ 1.64
assert 1.0 < moyenne_occurrences < 2.5, "Le nombre moyen d'occurrences devrait être autour de 1.64"
print("TP5: Lemme de Borel-Cantelli validé.")
```
