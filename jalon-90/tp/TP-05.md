# TP 5 : Simulation de l'Inégalité de Markov

Objectif : Implémenter numériquement le cœur de la preuve du fait que $L^1$ implique la convergence en Probabilité, en vérifiant concrètement l'inégalité.

```python
import random

def generate_variable_and_check_markov(n_samples=10000, epsilon=2.0):
    """
    On génère une variable aléatoire positive Y (ex: exponentielle)
    et on vérifie que P(Y > epsilon) <= E[Y]/epsilon.
    """
    # Generation empirique avec la méthode de l'inverse de la CDF
    # Y = -ln(U) simule une exponentielle de paramètre 1, E[Y] = 1.
    import math

    y_values = []
    for _ in range(n_samples):
        u = random.random()
        y = -math.log(u) if u > 0 else 0
        y_values.append(y)

    emp_mean = sum(y_values) / n_samples

    # Probabilité empirique que Y > epsilon
    count_excess = sum(1 for y in y_values if y > epsilon)
    prob_emp = count_excess / n_samples

    # Borne de Markov
    bound = emp_mean / epsilon

    return prob_emp, bound

if __name__ == "__main__":
    p_emp, markov_bound = generate_variable_and_check_markov()
    assert p_emp <= markov_bound, "L'inégalité de Markov a été violée numériquement !"
    print(f"Inégalité de Markov validée : P(Y>e)={p_emp:.3f} <= Borne={markov_bound:.3f}")

```
