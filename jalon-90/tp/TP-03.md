# TP 03 : Convergence en Loi vers l'Uniforme

Nous allons simuler X_n = W_n / n où W_n suit un uniforme discret (ou continu) sur [-n, n], et vérifier que la fonction de répartition empirique approche celle de U([-1, 1]).

```python
import random

def echantillonner_Vn(n):
    W_n = random.uniform(-n, n)
    return W_n / n

def fonction_repartition_empirique(n, point_evaluation, n_simulations):
    # Estime F_{V_n}(x)
    inferieurs = 0
    for _ in range(n_simulations):
        if echantillonner_Vn(n) <= point_evaluation:
            inferieurs += 1
    return inferieurs / n_simulations

# Pour x = 0, F(0) d'une uniforme sur [-1, 1] vaut 0.5
valeur_x = 0.0
n = 50
simulations = 2000

f_emp = fonction_repartition_empirique(n, valeur_x, simulations)
print("F_Vn(0) empirique :", f_emp)
assert 0.45 < f_emp < 0.55, "La repartition en 0 doit etre d'environ 0.5"

# Pour x = -0.5, F(-0.5) = (-0.5 + 1)/2 = 0.25
f_emp_2 = fonction_repartition_empirique(n, -0.5, simulations)
assert 0.20 < f_emp_2 < 0.30, "La repartition en -0.5 doit etre d'environ 0.25"
```
