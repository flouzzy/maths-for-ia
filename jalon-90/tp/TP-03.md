# TP 3 : La Loi Forte des Grands Nombres (Convergence p.s.)

Nous simulons le lancer d'une pièce biaisée (loi de Bernoulli) et suivons l'évolution de la moyenne empirique.
Nous vérifions que la moyenne empirique finit par rester confinée dans un tube très fin autour de la vraie probabilité.

```python
import random

def simuler_bernoulli(p):
    return 1 if random.random() < p else 0

p_vrai = 0.75
n_simulations = 50000
moyennes_empiriques = []
somme = 0

for i in range(1, n_simulations + 1):
    somme += simuler_bernoulli(p_vrai)
    moyennes_empiriques.append(somme / i)

# Vérification de la convergence
epsilon = 0.01

# On regarde à partir de quel rang on ne sort plus du tube (moyenne - epsilon, moyenne + epsilon)
# Théoriquement, ce rang est fini presque sûrement.
rang_entree = -1
for i in range(n_simulations - 1, -1, -1):
    if abs(moyennes_empiriques[i] - p_vrai) > epsilon:
        rang_entree = i + 1
        break

print(f"La moyenne empirique reste dans le tube de +-{epsilon} autour de {p_vrai} à partir de n = {rang_entree}")
print(f"Dernière valeur estimée : {moyennes_empiriques[-1]:.4f}")

# Mathématiquement, la moyenne empirique doit converger.
# On teste avec un epsilon un peu plus large pour éviter les fluctuations stochastiques résiduelles rares en fin de tableau
assert abs(moyennes_empiriques[-1] - p_vrai) < epsilon, "La loi forte des grands nombres n'est pas respectée à la fin de l'échantillon."
print("Validation mathématique : La séquence a bien convergé (p.s.) vers la moyenne de la loi.")
```
