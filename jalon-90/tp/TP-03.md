# TP 03 : Convergence L1 sans Convergence L2 (La bosse qui s'échappe)

L'espace L2 est strictement inclus dans L1 (sur un espace de probabilité).
Ce code construit la variable Y_n = n^(2/3) avec probabilité 1/n, et 0 sinon.
Nous allons prouver empiriquement la décroissance vers 0 de la norme L1, et la divergence vers l'infini de la norme L2.

```python
import random

def echantillon_bosse(n):
    # Generateur de la variable aleatoire pathologique
    if random.random() < (1.0 / n):
        return n**(2/3)
    return 0.0

def estimer_normes_Lp(n, n_simulations):
    somme_l1 = 0.0
    somme_l2 = 0.0
    for _ in range(n_simulations):
        y = echantillon_bosse(n)
        somme_l1 += y
        somme_l2 += y * y

    esperance_l1 = somme_l1 / n_simulations
    esperance_l2 = somme_l2 / n_simulations
    return esperance_l1, esperance_l2

# Simulation et Validation analytique
n_simulations_mc = 10000

# Calcul pour n=100
l1_100, l2_100 = estimer_normes_Lp(100, n_simulations_mc)
print(f"n=100  -> Norme L1: {l1_100:.4f}, Norme L2^2: {l2_100:.4f}")

# Calcul pour n=10000 (asymptotique)
l1_10k, l2_10k = estimer_normes_Lp(10000, n_simulations_mc)
print(f"n=10000 -> Norme L1: {l1_10k:.4f}, Norme L2^2: {l2_10k:.4f}")

# La theorie predit : L1 = n^(-1/3) (decroit) et L2^2 = n^(1/3) (croit)
assert l1_10k < l1_100, "La norme L1 doit converger vers 0 (decroissance stricte)"
assert l2_10k > l2_100, "La norme quadratique (L2) doit diverger vers l'infini"
```
