# TP 3 : Vérification empirique de l'inégalité de Markov

Ce TP vérifie numériquement que l'inégalité de Markov tient pour une variable aléatoire positive.

```python
import random

def simulation_markov(n_simulations, seuil_a):
    # On simule le carré d'une uniforme sur [0,1], espérance = 1/3
    valeurs = [random.random()**2 for _ in range(n_simulations)]
    esperance_theorique = 1.0 / 3.0

    compteur_depasse = sum(1 for v in valeurs if v >= seuil_a)
    proba_empirique = compteur_depasse / n_simulations

    borne_markov = esperance_theorique / seuil_a
    return proba_empirique, borne_markov

# Test pour différents seuils a
for a in [0.5, 0.8, 1.2]:
    p_emp, borne = simulation_markov(10000, a)
    assert p_emp <= borne, f"Inégalité violée pour a={a} : {p_emp} > {borne}"

print("TP3: Inégalité de Markov validée empiriquement.")
```
