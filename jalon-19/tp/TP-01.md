# TP 1 : Calcul numérique et symbolique du taux d'accroissement (Python Pur)

**Objectif :**
Implémenter le calcul de la dérivée numérique d'une fonction à partir de la définition formelle du taux d'accroissement (limite de Newton), sans utiliser aucun framework de calcul (ni numpy ni sympy), afin d'en éprouver les limites de stabilité numérique (Cancellation catastrophique).

**Code Python Pur From Scratch :**

```python
def f_1(x: float) -> float:
    # Fonction de test : x^3 - 2x + 1
    return x**3 - 2*x + 1

def taux_accroissement(func, a: float, h: float) -> float:
    """
    Calcule le taux d'accroissement (func(a+h) - func(a))/h.
    Conformément à la définition mathématique de la dérivée.
    """
    return (func(a + h) - func(a)) / h

def derivee_numerique(func, a: float, h_init: float = 1.0, tolerance: float = 1e-7) -> float:
    """
    Estime la limite du taux d'accroissement en faisant tendre h vers 0.
    """
    h = h_init
    derivee_precedente = taux_accroissement(func, a, h)

    for iteration in range(50):
        h = h / 2.0
        derivee_actuelle = taux_accroissement(func, a, h)

        # Validation d'arrêt basée sur la convergence de Cauchy
        if abs(derivee_actuelle - derivee_precedente) < tolerance:
            return derivee_actuelle

        derivee_precedente = derivee_actuelle

    return derivee_precedente # Retourne la meilleure estimation

# === Tests de validation mathématique ===
if __name__ == '__main__':
    point_etude = 2.0
    # La dérivée analytique de x^3 - 2x + C en x=2 est 3*(2)^2 - 2 = 10.
    valeur_theorique = 10.0
    valeur_estimee = derivee_numerique(f_1, point_etude)

    # Assertion stricte sans framework
    erreur = abs(valeur_theorique - valeur_estimee)
    assert erreur < 1e-4, f"Erreur mathématique inacceptable : {erreur}"
    print(f"Validation TP 1 réussie. Dérivée estimée : {valeur_estimee:.5f}, Théorique : {valeur_theorique}")
```
