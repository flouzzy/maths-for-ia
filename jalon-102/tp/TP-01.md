## TP-01 : Norme Euclidienne et convergence faible
Dans ce TP, nous implémentons numériquement un test de convergence coordonnée par coordonnée pour illustrer que la convergence faible équivaut à la convergence forte dans $\mathbb{R}^d$.

```python
import numpy as np

def tp01_convergence_finie():
    dim = 5
    # Suite convergeant fortement vers x_target
    x_target = np.array([1.0, -1.0, 2.0, 0.5, 0.0])

    # x_n = x_target + (1/n) * random_noise
    n_iters = 50

    x_n_list = []
    for n in range(1, n_iters + 1):
        noise = np.ones(dim) * (1.0 / n) # un bruit déterministe qui tend vers 0
        x_n_list.append(x_target + noise)

    # Vérification faible (coordonnée par coordonnée)
    # Dans R^d, une forme linéaire L(x) s'écrit dot(c, x)
    c = np.array([2.0, 0.5, -1.0, 1.0, 3.0])

    L_x_target = np.dot(c, x_target)

    for n in range(n_iters):
        L_x_n = np.dot(c, x_n_list[n])
        # Plus n est grand, plus la différence s'amenuise
        diff = abs(L_x_n - L_x_target)
        if n == n_iters - 1:
            assert diff < 1e-1, "La convergence faible a échoué"

    # Convergence forte
    forte_diff = np.linalg.norm(x_n_list[-1] - x_target)
    assert forte_diff < 1e-1, "La convergence forte a échoué"
    print("TP-01 Validé: Convergence forte et faible coïncident en dimension finie.")

if __name__ == "__main__":
    tp01_convergence_finie()
```
