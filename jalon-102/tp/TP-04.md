## TP-04 : Opérateurs compacts et topologie faible
Un opérateur $T$ est dit compact s'il transforme toute suite faiblement convergente en une suite fortement convergente. Nous allons l'illustrer avec un opérateur diagonal décroissant.

```python
import numpy as np

def tp04_operateur_compact():
    dim = 500

    # Opérateur diagonal compact (valeurs propres décroissant vers 0)
    diag = np.array([1.0 / (k + 1) for k in range(dim)])

    def T(x):
        return diag * x

    # Suite (e_n) qui converge faiblement vers 0 mais pas fortement
    def get_en(n):
        v = np.zeros(dim)
        v[n] = 1.0
        return v

    # On observe T(e_n)
    for n in [10, 100, 400]:
        e_n = get_en(n)
        T_en = T(e_n)

        # Norme forte de T(e_n)
        forte_norm = np.linalg.norm(T_en)

        if n == 400:
            assert forte_norm < 1e-2, "L'opérateur compact n'a pas transformé la convergence faible en forte"

    print("TP-04 Validé: L'opérateur diagonal décroissant transforme la suite faiblement convergente en fortement convergente.")

if __name__ == "__main__":
    tp04_operateur_compact()
```
