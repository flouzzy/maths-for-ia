## TP-05 : Régularisation de Tikhonov et compacité faible
Dans les problèmes inverses, la régularisation permet d'isoler une solution en utilisant la compacité faible de la boule de rayon $R$.

```python
import numpy as np

def tp05_tikhonov():
    dim = 100
    # Modèle linéaire y = Ax
    # On rend A mal conditionnée (compact)
    A = np.diag([1.0 / (k + 1)**2 for k in range(dim)])

    # Vraie solution
    x_true = np.ones(dim)
    y_true = A @ x_true

    # Bruit
    np.random.seed(42)
    y_noisy = y_true + 0.01 * np.random.randn(dim)

    # Fonction de coût Tikhonov : ||Ax - y||^2 + lambda ||x||^2
    lam = 0.1

    # La solution exacte régularisée est (A^T A + lambda I)^-1 A^T y
    ATA = A.T @ A
    regul = ATA + lam * np.eye(dim)
    x_est = np.linalg.solve(regul, A.T @ y_noisy)

    # Sans régularisation, l'inversion directe exploserait
    # A_inv = np.diag([(k + 1)**2 for k in range(dim)])
    # x_bad = A_inv @ y_noisy

    # L'estimation doit avoir une norme contrôlée (boule faiblement compacte)
    norm_est = np.linalg.norm(x_est)
    norm_true = np.linalg.norm(x_true)

    assert norm_est < norm_true * 1.5, "La norme a explosé, la régularisation n'a pas fonctionné"
    assert norm_est > 0, "Solution triviale"

    print("TP-05 Validé: Le terme de Tikhonov pénalise la norme et confine la solution dans un ensemble faiblement compact (une boule), garantissant la stabilité.")

if __name__ == "__main__":
    tp05_tikhonov()
```
