# TP 1 : Prolongement linéaire en dimension finie

Dans ce TP, nous allons écrire un algorithme qui, étant donné un sous-espace vectoriel de dimension 1 dans R2 et une forme linéaire sur ce sous-espace, trouve un prolongement sur R2 qui est dominé par la norme L1.

```python
def norme_l1(x, y):
    return abs(x) + abs(y)

def tp_prolongement_l1():
    # Espace M engendre par e1 = (1, 0)
    # Forme lineaire sur M : f(x, 0) = x

    # On cherche F(x, y) = ax + by tel que F(x, 0) = x => a = 1
    a = 1.0

    # On veut F(x, y) <= norme_l1(x, y)
    # On sait par l'exercice 1 que tout b dans [-1, 1] fonctionne.
    b = 0.5

    def F(x, y):
        return a * x + b * y

    # Validation par echantillonnage
    for x in range(-10, 10):
        for y in range(-10, 10):
            assert F(x, y) <= norme_l1(x, y), "Le prolongement depasse la jauge !"

    # Verification du prolongement
    assert F(5, 0) == 5.0, "Le prolongement ne coincide pas sur M"
    print("TP1: Prolongement valide.")

if __name__ == '__main__':
    tp_prolongement_l1()
```
