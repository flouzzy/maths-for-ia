# TP 5 : Calcul dual de distance

On implémente ici la formule de dualité distance/forme linéaire issue de Hahn-Banach.

```python
import math

def distance_point_droite(px, py, dx, dy):
    # Formule analytique standard de la distance d'un point (px,py) a la droite y = (dy/dx)*x
    # La droite a pour vecteur directeur (dx, dy).
    # Un vecteur normal est (-dy, dx). Sa norme euclidienne est sqrt(dx^2 + dy^2).
    # Le vecteur normal unitaire est (-dy/norme, dx/norme).

    norme_dir = math.sqrt(dx**2 + dy**2)
    nx = -dy / norme_dir
    ny = dx / norme_dir

    # La distance est le produit scalaire absolu entre (px, py) et (nx, ny)
    # ce qui correspond à l'evaluation de la forme lineaire de norme 1 qui s'annule sur la droite.

    dist = abs(px * nx + py * ny)
    return dist

def tp_dualite_distance():
    # Droite M engendree par (1, 1)
    dx, dy = 1.0, 1.0

    # Point exterieur
    px, py = 0.0, 2.0

    # Calcul de la distance
    dist = distance_point_droite(px, py, dx, dy)

    # On verifie geometriquement que la distance de (0,2) a la droite y=x est sqrt(2)
    assert abs(dist - math.sqrt(2.0)) < 1e-9, "Le calcul dual de la distance a echoue."

    print("TP5: Calcul dual de la distance via projection orthogonale valide.")

if __name__ == '__main__':
    tp_dualite_distance()
```
