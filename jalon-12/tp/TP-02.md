# TP 02 : Géométrie des Espaces de Plongement et Similarité Cosinus : Dualité et Problème Algébrique

## Objectif Mathématique
Ce Travail Pratique explore la conception théorique d'un moteur de recherche sémantique en se basant sur la **similarité cosinus** et la **géométrie des espaces de plongement (embeddings)**. Les mots, phrases ou documents sont représentés comme des vecteurs dans un espace multidimensionnel, où la proximité sémantique est traduite par la proximité géométrique des vecteurs. La similarité cosinus mesure l'angle entre deux vecteurs, un angle faible indiquant une forte similarité.

Nous aborderons la **dualité** en illustrant comment un "vecteur de requête" peut être interprété comme un élément de l'espace dual (une forme linéaire) qui projette les "vecteurs de document" sur une valeur scalaire (leur pertinence). La géométrie des espaces est mise en lumière par les opérations vectorielles fondamentales, la projection orthogonale et la reconstruction à partir de bases orthonormées.

Enfin, nous résoudrons un **problème d'algèbre de l'X** en deux parties :
1.  Démontrer la décomposition d'un vecteur en sa projection sur un autre et un résidu orthogonal, illustrant la décomposition d'un espace vectoriel en sous-espaces orthogonaux.
2.  Reconstruire un vecteur à partir de ses coordonnées dans une base orthonormée, soulignant le rôle fondamental du produit scalaire pour obtenir ces coordonnées et la facilité de manipulation dans de tels espaces.


### Formalisation Temporelle de l'Indexation
La création d'un index inversé sur $N$ documents et $W$ termes présente une complexité de construction du vocabulaire de $\mathcal{O}(W)$, tandis que le calcul de la matrice des poids est $\mathcal{O}(N \times |V|)$ où $|V|$ est le cardinal du vocabulaire unique.

## Implémentation Python Pure
```python
import math # Utilisation de math.sqrt pour les opérations numériques fondamentales.

# --- Opérations Vectorielles de Base (Implémentation From Scratch) ---

def dot_product(v1, v2):
    """
    Calcule le produit scalaire de deux vecteurs.
    Les vecteurs sont représentés par des listes de nombres.
    Précondition: Les vecteurs doivent avoir la même dimension.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la même dimension pour le produit scalaire.")

    result = 0
    for i in range(len(v1)):
        result += v1[i] * v2[i]
    return result

def vector_magnitude(v):
    """
    Calcule la magnitude (norme euclidienne L2) d'un vecteur.
    ||v|| = sqrt(v . v)
    """
    return math.sqrt(dot_product(v, v))

def scalar_multiply(scalar, vector):
    """
    Multiplie un vecteur par un scalaire.
    """
    return [scalar * x for x in vector]

def vector_add(v1, v2):
    """
    Additionne deux vecteurs.
    Précondition: Les vecteurs doivent avoir la même dimension.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la même dimension pour l l'addition.")
    return [v1[i] + v2[i] for i in range(len(v1))]

def vector_subtract(v1, v2):
    """
    Soustrait v2 de v1.
    Précondition: Les vecteurs doivent avoir la même dimension.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la même dimension pour la soustraction.")
    return [v1[i] - v2[i] for i in range(len(v1))]

def normalize_vector(v):
    """
    Normalise un vecteur pour obtenir un vecteur unitaire (de magnitude 1).
    Précondition: Le vecteur ne doit pas être le vecteur nul.
    """
    mag = vector_magnitude(v)
    if mag == 0:
        raise ValueError("Impossible de normaliser un vecteur nul.")
    return scalar_multiply(1.0 / mag, v)

# --- Similarité Cosinus pour la Recherche Sémantique ---

def cosine_similarity(v1, v2):
    """
    Calcule la similarité cosinus entre deux vecteurs.
    cos(theta) = (v1 . v2) / (||v1|| * ||v2||)
    Retourne 0.0 si l'un des vecteurs est nul.
    """
    dot_prod = dot_product(v1, v2)
    mag_v1 = vector_magnitude(v1)
    mag_v2 = vector_magnitude(v2)

    if mag_v1 == 0 or mag_v2 == 0:
        return 0.0 # La similarité est indéfinie ou considérée comme nulle si un vecteur est nul.

    return dot_prod / (mag_v1 * mag_v2)

# --- Problème d'Algèbre de l'X : Projection et Base Orthonormée ---

def project_vector(u, v):
    """
    Calcule la projection orthogonale du vecteur u sur le vecteur v.
    proj_v(u) = ((u . v) / ||v||^2) * v
    Précondition: Le vecteur v ne doit pas être le vecteur nul.
    """
    if vector_magnitude(v) == 0:
        raise ValueError("Impossible de projeter sur un vecteur nul.")

    dot_uv = dot_product(u, v)
    mag_v_squared = dot_product(v, v) # ||v||^2

    scalar = dot_uv / mag_v_squared
    return scalar_multiply(scalar, v)

def reconstruct_from_orthonormal_basis(vector, orthonormal_basis):
    """
    Reconstruit un vecteur à partir de ses coefficients par rapport à une base orthonormée.
    Pour une base orthonormée {b_i}, un vecteur v peut être exprimé comme :
    v = sum( (v . b_i) * b_i )
    Les coefficients (v . b_i) sont les coordonnées de v dans cette base.
    Précondition: 'orthonormal_basis' doit être une liste de vecteurs unitaires et mutuellement orthogonaux.
    """
    if not orthonormal_basis:
        return [0.0] * len(vector) # Retourne un vecteur nul si la base est vide.

    # Initialise le vecteur reconstruit avec des zéros, de la même dimension que le vecteur original.
    reconstructed_vector = [0.0] * len(vector)

    for b_i in orthonormal_basis:
        if len(b_i) != len(vector):
            raise ValueError("Les vecteurs de la base doivent avoir la même dimension que le vecteur à reconstruire.")

        # Le coefficient est le produit scalaire du vecteur avec le vecteur de base.
        # Ceci illustre la dualité : le vecteur de base b_i agit comme une forme linéaire f_bi(v) = v . b_i
        # qui extrait la composante de v le long de b_i.
        coefficient = dot_product(vector, b_i)

        # Multiplie le vecteur de base par son coefficient et l'ajoute au vecteur reconstruit.
        scaled_b_i = scalar_multiply(coefficient, b_i)
        reconstructed_vector = vector_add(reconstructed_vector, scaled_b_i)

    return reconstructed_vector

# --- Cas de Test et Assertions de Validation Mathématique ---

# Précision pour les comparaisons de nombres flottants
EPSILON = 1e-9

# Test 1 : Opérations Vectorielles de Base
print("--- Test 1 : Opérations Vectorielles de Base ---")
v_a = [1, 2, 3]
v_b = [4, 5, 6]
v_c = [0, 0, 0]
v_d = [1.0 / math.sqrt(2), 1.0 / math.sqrt(2)] # Vecteur unitaire

assert dot_product(v_a, v_b) == 32, "Test 1.1: Produit scalaire [1,2,3].[4,5,6] = 32"
assert dot_product(v_a, v_a) == 14, "Test 1.2: Produit scalaire de v_a avec lui-même = 14"
assert abs(vector_magnitude(v_a) - math.sqrt(14)) < EPSILON, "Test 1.3: Magnitude de v_a"
assert vector_magnitude(v_c) == 0, "Test 1.4: Magnitude du vecteur nul"
assert scalar_multiply(2, v_a) == [2, 4, 6], "Test 1.5: Multiplication scalaire 2 * [1,2,3]"
assert vector_add(v_a, v_b) == [5, 7, 9], "Test 1.6: Addition vectorielle [1,2,3] + [4,5,6]"
assert vector_subtract(v_b, v_a) == [3, 3, 3], "Test 1.7: Soustraction vectorielle [4,5,6] - [1,2,3]"
assert abs(vector_magnitude(normalize_vector(v_a)) - 1.0) < EPSILON, "Test 1.8: Normalisation de v_a"
assert abs(vector_magnitude(v_d) - 1.0) < EPSILON, "Test 1.9: Magnitude d'un vecteur unitaire"
print("Test 1 réussi.")

# Test 2 : Similarité Cosinus
print("--- Test 2 : Similarité Cosinus ---")
doc1 = [1, 1, 0] # "pomme rouge"
doc2 = [1, 0, 1] # "pomme verte"
doc3 = [0, 1, 1] # "rouge verte"
doc4 = [-1, -1, 0] # "pas pomme pas rouge" (opposé de doc1)

# Similarité entre doc1 et doc2 : (1*1 + 1*0 + 0*1) / (sqrt(2) * sqrt(2)) = 1 / 2 = 0.5
assert abs(cosine_similarity(doc1, doc2) - 0.5) < EPSILON, "Test 2.1: Cosine sim (doc1, doc2)"
# Similarité entre doc1 et doc1 : doit être 1.0
assert abs(cosine_similarity(doc1, doc1) - 1.0) < EPSILON, "Test 2.2: Cosine sim (doc1, doc1)"
# Similarité entre vecteurs orthogonaux (ex: [1,0] et [0,1]) : doit être 0.0
ortho_v1 = [1, 0]
ortho_v2 = [0, 1]
assert abs(cosine_similarity(ortho_v1, ortho_v2) - 0.0) < EPSILON, "Test 2.3: Cosine sim (orthogonaux)"
# Similarité avec un vecteur nul : doit être 0.0
assert cosine_similarity(doc1, v_c) == 0.0, "Test 2.4: Cosine sim avec vecteur nul"
# Similarité entre vecteurs opposés : doit être -1.0
assert abs(cosine_similarity(doc1, doc4) - (-1.0)) < EPSILON, "Test 2.5: Cosine sim (opposés)"
print("Test 2 réussi.")

# Test 3 : Problème d'Algèbre de l'X - Partie 1 : Projection et Orthogonalité
print("--- Test 3 : Problème d'Algèbre de l'X - Projection et Orthogonalité ---")
u_vec = [3, 4] # Vecteur à projeter
v_vec = [1, 0] # Vecteur sur lequel projeter (axe des x)
proj_u_v = project_vector(u_vec, v_vec)
# La projection de [3,4] sur [1,0] est [3,0]
assert proj_u_v == [3.0, 0.0], "Test 3.1: Projection simple de [3,4] sur [1,0]"

residual_vec = vector_subtract(u_vec, proj_u_v)
# Le résidu [0, 4] doit être orthogonal à v_vec [1, 0]
assert abs(dot_product(residual_vec, v_vec)) < EPSILON, "Test 3.2: Le résidu doit être orthogonal au vecteur de projection."

u_vec_2 = [1, 1]
v_vec_2 = [2, 0]
# proj_v2(u2) = ((u2 . v2) / ||v2||^2) * v2
# u2 . v2 = 1*2 + 1*0 = 2
# ||v2||^2 = 2*2 + 0*0 = 4
# scalaire = 2/4 = 0.5
# proj = 0.5 * [2, 0] = [1.0, 0.0]
proj_u_v_2 = project_vector(u_vec_2, v_vec_2)
assert proj_u_v_2 == [1.0, 0.0], "Test 3.3: Projection de [1,1] sur [2,0]"
residual_vec_2 = vector_subtract(u_vec_2, proj_u_v_2) # [0, 1]
assert abs(dot_product(residual_vec_2, v_vec_2)) < EPSILON, "Test 3.4: Le résidu doit être orthogonal au vecteur de projection (cas général)."
print("Test 3 réussi.")

# Test 4 : Problème d'Algèbre de l'X - Partie 2 : Reconstruction à partir d'une Base Orthonormée
print("--- Test 4 : Problème d'Algèbre de l'X - Reconstruction Base Orthonormée ---")
# Création d'une base orthonormée canonique pour R^3
e1 = [1.0, 0.0, 0.0]
e2 = [0.0, 1.0, 0.0]
e3 = [0.0, 0.0, 1.0]
ortho_basis_3d = [e1, e2, e3]

# Vérification que la base est bien orthonormée
for i in range(len(ortho_basis_3d)):
    assert abs(vector_magnitude(ortho_basis_3d[i]) - 1.0) < EPSILON, f"Test 4.1.{i}: Vecteur de base {i} n'est pas unitaire."
    for j in range(i + 1, len(ortho_basis_3d)):
        assert abs(dot_product(ortho_basis_3d[i], ortho_basis_3d[j])) < EPSILON, f"Test 4.2.{i}.{j}: Vecteurs de base {i} et {j} ne sont pas orthogonaux."

test_vector = [5, -2, 7]
reconstructed = reconstruct_from_orthonormal_basis(test_vector, ortho_basis_3d)

# Vérification que le vecteur reconstruit est approximativement égal au vecteur original
for i in range(len(test_vector)):
    assert abs(reconstructed[i] - test_vector[i]) < EPSILON, f"Test 4.3: La reconstruction a échoué à l'indice {i}."

# Autre base orthonormée (rotée) en 2D
sqrt2_inv = 1.0 / math.sqrt(2)
u1_basis = [sqrt2_inv, sqrt2_inv]
u2_basis = [-sqrt2_inv, sqrt2_inv]
ortho_basis_2d = [u1_basis, u2_basis]

# Vérification de l'orthonormalité de la base 2D
assert abs(vector_magnitude(u1_basis) - 1.0) < EPSILON, "Test 4.4: u1_basis n'est pas unitaire."
assert abs(vector_magnitude(u2_basis) - 1.0) < EPSILON, "Test 4.5: u2_basis n'est pas unitaire."
assert abs(dot_product(u1_basis, u2_basis)) < EPSILON, "Test 4.6: u1_basis et u2_basis ne sont pas orthogonaux."

test_vector_2d = [3, 4]
reconstructed_2d = reconstruct_from_orthonormal_basis(test_vector_2d, ortho_basis_2d)

for i in range(len(test_vector_2d)):
    assert abs(reconstructed_2d[i] - test_vector_2d[i]) < EPSILON, f"Test 4.7: La reconstruction 2D a échoué à l'indice {i}."
print("Test 4 réussi.")

print("\nTous les tests de validation mathématique ont réussi !")
```
