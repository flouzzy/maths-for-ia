# TP 03 : Géométrie des Espaces de Plongement et Recherche Sémantique par Similarité Cosinus

## Objectif Mathématique
Ce Travail Pratique explore la conception théorique d'un moteur de recherche sémantique en Python pur, en se concentrant sur la similarité cosinus. Il vise à illustrer la **dualité** et la **géométrie des espaces de plongement (embedding spaces)**, où les documents et les requêtes sont représentés comme des vecteurs. La similarité cosinus, mesurant l'angle entre ces vecteurs, est une manifestation directe de cette géométrie.

Nous aborderons également un problème d'**algèbre de l'X** simplifié : le raffinement itératif d'un vecteur de requête. Ce problème consiste à ajuster la direction d'un vecteur de requête dans l'espace de plongement pour maximiser sa similarité avec un ensemble de documents "positifs" tout en minimisant sa similarité avec un ensemble de documents "négatifs". Cela démontre comment des opérations algébriques (addition vectorielle, multiplication scalaire, normalisation) peuvent être utilisées pour naviguer et optimiser des positions dans un espace vectoriel, reflétant l'influence de formes linéaires (les "directions" positives/négatives) sur le vecteur de requête.


### Stabilité Numérique de la Pondération
Le lissage logarithmique de l'IDF $ \log(1 + \frac{N}{df(t)}) $ prévient formellement les singularités mathématiques. Numériquement, le calcul itératif des similarités emploie des types à virgule flottante double précision pour mitiger l'underflow et les erreurs de précision cumulative.

## Implémentation Python Pure
```python
import math

# --- Fonctions Utilitaires de Base (implémentées from scratch) ---

def tokenize(text):
    """
    Tokenise une chaîne de caractères en une liste de mots.
    Convertit en minuscules et supprime la ponctuation simple.
    """
    clean_text = ""
    for char in text:
        if 'a' <= char <= 'z' or 'A' <= char <= 'Z' or '0' <= char <= '9' or char == ' ':
            clean_text += char
        else:
            clean_text += ' ' # Remplace la ponctuation par un espace
    return [word for word in clean_text.lower().split() if word]

def count_words(tokens):
    """
    Compte la fréquence de chaque mot dans une liste de tokens.
    Retourne un dictionnaire {mot: fréquence}.
    """
    counts = {}
    for word in tokens:
        counts[word] = counts.get(word, 0) + 1
    return counts

def dot_product(vec1, vec2):
    """
    Calcule le produit scalaire de deux vecteurs.
    Les vecteurs sont représentés comme des listes de nombres.
    """
    if len(vec1) != len(vec2):
        raise ValueError("Les vecteurs doivent avoir la même dimension pour le produit scalaire.")

    result = 0
    for i in range(len(vec1)):
        result += vec1[i] * vec2[i]
    return result

def vector_magnitude(vec):
    """
    Calcule la magnitude (norme L2) d'un vecteur.
    """
    sum_sq = 0
    for x in vec:
        sum_sq += x * x
    return math.sqrt(sum_sq)

def cosine_similarity(vec1, vec2):
    """
    Calcule la similarité cosinus entre deux vecteurs.
    Retourne 0.0 si l'un des vecteurs est nul pour éviter la division par zéro.
    """
    if not vec1 or not vec2:
        return 0.0

    num = dot_product(vec1, vec2)
    den1 = vector_magnitude(vec1)
    den2 = vector_magnitude(vec2)

    if den1 == 0.0 or den2 == 0.0:
        return 0.0

    return num / (den1 * den2)

def vector_add(vec1, vec2):
    """
    Additionne deux vecteurs.
    """
    if len(vec1) != len(vec2):
        raise ValueError("Les vecteurs doivent avoir la même dimension pour l'addition.")

    result = []
    for i in range(len(vec1)):
        result.append(vec1[i] + vec2[i])
    return result

def scalar_multiply(vec, scalar):
    """
    Multiplie un vecteur par un scalaire.
    """
    result = []
    for x in vec:
        result.append(x * scalar)
    return result

def normalize_vector(vec):
    """
    Normalise un vecteur à une norme L2 de 1.
    Retourne un vecteur nul si la magnitude est 0.
    """
    mag = vector_magnitude(vec)
    if mag == 0.0:
        return [0.0] * len(vec)

    return scalar_multiply(vec, 1.0 / mag)

# --- Vectorisation TF-IDF (implémentée from scratch) ---

def compute_tf(document_tokens):
    """
    Calcule la fréquence des termes (TF) pour un document.
    Retourne un dictionnaire {mot: tf_score}.
    """
    tf = {}
    word_counts = count_words(document_tokens)
    total_words = len(document_tokens)
    if total_words == 0:
        return tf
    for word, count in word_counts.items():
        tf[word] = count / total_words
    return tf

def compute_idf(corpus_documents_tokens):
    """
    Calcule la fréquence inverse des documents (IDF) pour l'ensemble du corpus.
    Retourne un dictionnaire {mot: idf_score}.
    """
    idf = {}
    num_documents = len(corpus_documents_tokens)

    doc_freq = {}
    for doc_tokens in corpus_documents_tokens:
        unique_words_in_doc = {}
        for word in doc_tokens:
            unique_words_in_doc[word] = True
        for word in unique_words_in_doc:
            doc_freq[word] = doc_freq.get(word, 0) + 1

    for word, freq in doc_freq.items():
        idf[word] = math.log(num_documents / (1.0 + freq)) # Ajout de 1 pour lisser
    return idf

def build_vocabulary(corpus_documents_tokens):
    """
    Construit le vocabulaire global à partir de tous les documents tokenisés.
    Retourne une liste triée de mots uniques.
    """
    vocab_set = {}
    for doc_tokens in corpus_documents_tokens:
        for word in doc_tokens:
            vocab_set[word] = True
    return sorted(list(vocab_set.keys())) # Utilise sorted() qui est une fonction built-in

def compute_tfidf_vector(tf_scores, idf_scores, vocabulary):
    """
    Construit un vecteur TF-IDF pour un document donné.
    """
    vector = [0.0] * len(vocabulary)
    for i, word in enumerate(vocabulary):
        tf = tf_scores.get(word, 0.0)
        idf = idf_scores.get(word, 0.0)
        vector[i] = tf * idf
    return vector

def build_corpus_vectors(corpus):
    """
    Prétraite un corpus pour générer les vecteurs TF-IDF pour chaque document.
    Retourne une liste de vecteurs et le vocabulaire global.
    """
    tokenized_corpus = [tokenize(doc) for doc in corpus]

    vocabulary = build_vocabulary(tokenized_corpus)
    idf_scores = compute_idf(tokenized_corpus)

    document_vectors = []
    for doc_tokens in tokenized_corpus:
        tf_scores = compute_tf(doc_tokens)
        tfidf_vec = compute_tfidf_vector(tf_scores, idf_scores, vocabulary)
        document_vectors.append(tfidf_vec)

    return document_vectors, vocabulary, idf_scores

# --- Moteur de Recherche Sémantique ---

def search(query, document_vectors, vocabulary, idf_scores, top_k=3):
    """
    Effectue une recherche sémantique basée sur la similarité cosinus.
    """
    query_tokens = tokenize(query)
    query_tf = compute_tf(query_tokens)
    query_vector = compute_tfidf_vector(query_tf, idf_scores, vocabulary)

    normalized_query_vector = normalize_vector(query_vector)

    similarities = []
    for i, doc_vec in enumerate(document_vectors):
        normalized_doc_vec = normalize_vector(doc_vec)
        sim = cosine_similarity(normalized_query_vector, normalized_doc_vec)
        similarities.append((sim, i))

    # Tri par sélection pour rester "from scratch"
    n = len(similarities)
    for i in range(n):
        max_idx = i
        for j in range(i + 1, n):
            if similarities[j][0] > similarities[max_idx][0]:
                max_idx = j
        similarities[i], similarities[max_idx] = similarities[max_idx], similarities[i]

    return similarities[:top_k]

# --- Problème d'Algèbre de l'X : Raffinement de Requête ---

def refine_query_vector(initial_query_vec, pos_docs_vecs, neg_docs_vecs, learning_rate, iterations):
    """
    Raffine un vecteur de requête pour maximiser la similarité avec des documents "positifs"
    et minimiser avec des documents "négatifs".
    Illustre la manipulation géométrique dans l'espace de plongement.

    initial_query_vec: Le vecteur de requête initial.
    pos_docs_vecs: Liste de vecteurs de documents positifs.
    neg_docs_vecs: Liste de vecteurs de documents négatifs.
    learning_rate: Taux d'apprentissage pour l'ajustement.
    iterations: Nombre d'itérations pour le raffinement.
    """
    current_query_vec = list(initial_query_vec) # Copie pour ne pas modifier l'original
    current_query_vec = normalize_vector(current_query_vec)

    # Normaliser les vecteurs d'entrée pour que les ajustements soient basés sur la direction
    pos_docs_vecs_norm = [normalize_vector(v) for v in pos_docs_vecs]
    neg_docs_vecs_norm = [normalize_vector(v) for v in neg_docs_vecs]

    for _ in range(iterations):
        # Calculer la direction moyenne des documents positifs
        pos_direction = [0.0] * len(current_query_vec)
        if pos_docs_vecs_norm:
            for p_vec in pos_docs_vecs_norm:
                pos_direction = vector_add(pos_direction, p_vec)
            pos_direction = scalar_multiply(pos_direction, 1.0 / len(pos_docs_vecs_norm))

        # Calculer la direction moyenne des documents négatifs
        neg_direction = [0.0] * len(current_query_vec)
        if neg_docs_vecs_norm:
            for n_vec in neg_docs_vecs_norm:
                neg_direction = vector_add(neg_direction, n_vec)
            neg_direction = scalar_multiply(neg_direction, 1.0 / len(neg_docs_vecs_norm))

        # Le vecteur de correction pousse la requête vers les positifs et l'éloigne des négatifs.
        # Cela peut être vu comme l'application d'une forme linéaire dans l'espace dual
        # qui guide le mouvement du vecteur de requête dans l'espace original.
        correction_vector = vector_add(pos_direction, scalar_multiply(neg_direction, -1.0))

        # Appliquer la correction et normaliser le vecteur de requête
        current_query_vec = vector_add(current_query_vec, scalar_multiply(correction_vector, learning_rate))
        current_query_vec = normalize_vector(current_query_vec)

    return current_query_vec

# --- Exécution Principale et Assertions de Validation ---

if __name__ == "__main__":
    print("--- Démarrage du TP : Géométrie des Espaces de Plongement et Recherche Sémantique ---")

    # --- Section 1: Tests des fonctions utilitaires de base ---
    print("\n[TESTS] Fonctions utilitaires de base...")
    vec_a = [1, 2, 3]
    vec_b = [4, 5, 6]
    vec_c = [0, 0, 0]

    assert tokenize("Hello, world! This is a test.") == ['hello', 'world', 'this', 'is', 'a', 'test'], "Test tokenize échoué"
    assert count_words(['hello', 'world', 'hello']) == {'hello': 2, 'world': 1}, "Test count_words échoué"
    assert dot_product(vec_a, vec_b) == 32, "Test dot_product échoué" # 1*4 + 2*5 + 3*6 = 4 + 10 + 18 = 32
    assert abs(vector_magnitude(vec_a) - math.sqrt(14)) < 1e-9, "Test vector_magnitude échoué"
    assert abs(cosine_similarity(vec_a, vec_a) - 1.0) < 1e-9, "Test cosine_similarity (identique) échoué"
    assert abs(cosine_similarity(vec_a, vec_c) - 0.0) < 1e-9, "Test cosine_similarity (nul) échoué"
    assert vector_add(vec_a, vec_b) == [5, 7, 9], "Test vector_add échoué"
    assert scalar_multiply(vec_a, 2) == [2, 4, 6], "Test scalar_multiply échoué"

    norm_vec_a = normalize_vector(vec_a)
    assert abs(vector_magnitude(norm_vec_a) - 1.0) < 1e-9, "Test normalize_vector échoué"
    assert normalize_vector(vec_c) == [0.0, 0.0, 0.0], "Test normalize_vector (nul) échoué"
    print("Tests des fonctions utilitaires : OK")

    # --- Section 2: Tests de la vectorisation TF-IDF ---
    print("\n[TESTS] Vectorisation TF-IDF...")

    v_a = normalize_vector([1.0, 0.0, 0.0]) # Concept 'a'
