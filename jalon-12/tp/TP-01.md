# TP 01 : Géométrie des Espaces Vectoriels et Similarité Cosinus : Un Moteur de Recherche Sémantique Minimaliste et Problème d'Algèbre Linéaire

## Objectif Mathématique
Ce Travail Pratique (TP) explore la dualité et la géométrie des espaces de plongement (embedding spaces) à travers l'implémentation "from scratch" de la similarité cosinus. Nous modéliserons des documents textuels comme des vecteurs dans un espace de haute dimension (approche Bag-of-Words), où la direction de ces vecteurs capture leur "sens" sémantique. La similarité cosinus, mesurant l'angle entre deux vecteurs, devient alors une métrique de similarité sémantique.

Le TP illustrera les concepts fondamentaux de l'algèbre linéaire :
1.  **Espaces Vectoriels Réels :** Les documents et requêtes sont représentés comme des vecteurs dans $\mathbb{R}^n$.
2.  **Produit Scalaire (Dot Product) :** Mesure de la projection d'un vecteur sur un autre, base de la notion d'angle.
3.  **Norme Euclidienne (Magnitude) :** Longueur d'un vecteur, nécessaire pour la normalisation.
4.  **Similarité Cosinus :** Définie par $\text{cos}(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|}$, elle quantifie la similarité directionnelle entre deux vecteurs, indépendamment de leur magnitude.
5.  **Géométrie des Espaces :** L'angle entre vecteurs comme indicateur de proximité sémantique.

En complément, nous aborderons un problème d'algèbre de l'X, en l'occurrence la **projection orthogonale d'un vecteur sur un autre**. Ce concept est fondamental en géométrie euclidienne et en optimisation, et s'appuie directement sur les opérations vectorielles implémentées. La projection orthogonale d'un vecteur $\mathbf{v}$ sur un vecteur non nul $\mathbf{u}$ est donnée par $\text{proj}_{\mathbf{u}} \mathbf{v} = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|^2} \mathbf{u}$. Elle représente la composante de $\mathbf{v}$ qui est parallèle à $\mathbf{u}$.


### Analyse Algorithmique Strictement Bornée
Le calcul séquentiel de $\sum_{i=1}^d u_i v_i$ exige une complexité temporelle stricte de $\mathcal{O}(d)$, où $d = \dim(E)$. La normalisation des vecteurs maintient une empreinte spatiale de $\mathcal{O}(1)$ supplémentaire. L'efficacité en Python pur repose sur les itérateurs.

## Implémentation Python Pure
```python
# --- Partie 1 : Fonctions Mathématiques de Base (From Scratch) ---

def square_root(n, epsilon=1e-9):
    """
    Calcule la racine carrée d'un nombre non négatif en utilisant la méthode de Newton.
    Implémentation "from scratch" sans math.sqrt.
    """
    if n < 0:
        raise ValueError("Cannot compute square root of a negative number.")
    if n == 0:
        return 0.0
    x = n / 2.0  # Première estimation
    while True:
        next_x = 0.5 * (x + n / x)
        if abs(x - next_x) < epsilon:
            return next_x
        x = next_x

# Assertions pour square_root
assert abs(square_root(4) - 2.0) < 1e-7, "square_root(4) should be 2.0"
assert abs(square_root(9) - 3.0) < 1e-7, "square_root(9) should be 3.0"
assert abs(square_root(0) - 0.0) < 1e-7, "square_root(0) should be 0.0"
assert abs(square_root(25.0) - 5.0) < 1e-7, "square_root(25.0) should be 5.0"
assert abs(square_root(2) - 1.41421356237) < 1e-7, "square_root(2) should be approx 1.414"
try:
    square_root(-1)
    assert False, "square_root(-1) should raise ValueError"
except ValueError:
    assert True, "square_root(-1) correctly raised ValueError"
print("square_root assertions passed.")

def vector_add(v1, v2):
    """Additionne deux vecteurs de même dimension."""
    if len(v1) != len(v2):
        raise ValueError("Vectors must have the same dimension.")
    return [v1[i] + v2[i] for i in range(len(v1))]

def scalar_multiply(scalar, v):
    """Multiplie un vecteur par un scalaire."""
    return [scalar * x for x in v]

def dot_product(v1, v2):
    """Calcule le produit scalaire (dot product) de deux vecteurs."""
    if len(v1) != len(v2):
        raise ValueError("Vectors must have the same dimension.")
    return sum(v1[i] * v2[i] for i in range(len(v1)))

def vector_magnitude(v):
    """Calcule la norme Euclidienne (magnitude) d'un vecteur."""
    return square_root(dot_product(v, v))

def normalize_vector(v):
    """Normalise un vecteur (le transforme en vecteur unitaire)."""
    magnitude = vector_magnitude(v)
    if magnitude == 0:
        return [0.0] * len(v) # Vecteur nul reste nul
    return scalar_multiply(1.0 / magnitude, v)

# Assertions pour les opérations vectorielles
v_a = [1, 2, 3]
v_b = [4, 5, 6]
v_c = [0, 0, 0]
v_d = [3, 4]

assert vector_add(v_a, v_b) == [5, 7, 9], "vector_add failed"
assert scalar_multiply(2, v_a) == [2, 4, 6], "scalar_multiply failed"
assert dot_product(v_a, v_b) == 32, "dot_product failed" # 1*4 + 2*5 + 3*6 = 4 + 10 + 18 = 32
assert abs(vector_magnitude(v_d) - 5.0) < 1e-7, "vector_magnitude failed for [3,4]" # sqrt(3^2 + 4^2) = sqrt(9+16) = sqrt(25) = 5
normalized_v_d = normalize_vector([3, 4])
assert abs(normalized_v_d[0] - 0.6) < 1e-7 and abs(normalized_v_d[1] - 0.8) < 1e-7, "normalize_vector failed"
assert normalize_vector(v_c) == [0.0, 0.0, 0.0], "normalize_vector of zero vector failed"
try:
    dot_product(v_a, v_d)
    assert False, "dot_product with different dimensions should raise ValueError"
except ValueError:
    assert True, "dot_product with different dimensions correctly raised ValueError"
print("Vector operations assertions passed.")

def cosine_similarity(v1, v2):
    """
    Calcule la similarité cosinus entre deux vecteurs.
    Retourne 0.0 si l'un des vecteurs est nul.
    """
    if len(v1) != len(v2):
        raise ValueError("Vectors must have the same dimension.")

    dot_p = dot_product(v1, v2)
    mag_v1 = vector_magnitude(v1)
    mag_v2 = vector_magnitude(v2)

    if mag_v1 == 0 or mag_v2 == 0:
        return 0.0 # La similarité avec un vecteur nul est indéfinie ou souvent considérée comme 0.0

    return dot_p / (mag_v1 * mag_v2)

# Assertions pour cosine_similarity
v_e = [1, 0]
v_f = [0, 1]
v_g = [1, 1]
v_h = [-1, -1]

assert abs(cosine_similarity(v_e, v_e) - 1.0) < 1e-7, "Cosine similarity with itself should be 1.0"
assert abs(cosine_similarity(v_e, v_f) - 0.0) < 1e-7, "Cosine similarity of orthogonal vectors should be 0.0"
assert abs(cosine_similarity(v_g, v_h) - (-1.0)) < 1e-7, "Cosine similarity of opposite vectors should be -1.0"
assert abs(cosine_similarity(v_g, v_e) - (1.0 / square_root(2))) < 1e-7, "Cosine similarity of [1,1] and [1,0] failed"
assert abs(cosine_similarity([0,0], [1,1]) - 0.0) < 1e-7, "Cosine similarity with zero vector should be 0.0"
print("cosine_similarity assertions passed.")

# --- Partie 2 : Moteur de Recherche Sémantique Minimaliste ---

def build_vocabulary(documents):
    """
    Construit un vocabulaire unique à partir d'une liste de documents.
    Retourne un dictionnaire {mot: index}.
    """
    vocabulary = {}
    word_index = 0
    for doc in documents:
        # Simple tokenisation : divise par les espaces et convertit en minuscules
        for word in doc.lower().split():
            if word not in vocabulary:
                vocabulary[word] = word_index
                word_index += 1
    return vocabulary

def document_to_vector(document, vocabulary):
    """
    Convertit un document en un vecteur Bag-of-Words (BoW) basé sur le vocabulaire.
    Chaque élément du vecteur représente la fréquence d'un mot dans le document.
    """
    vector = [0] * len(vocabulary)
    for word in document.lower().split():
        if word in vocabulary:
            vector[vocabulary[word]] += 1
    return vector

def search_documents(query_text, documents, top_k=3):
    """
    Effectue une recherche sémantique basée sur la similarité cosinus.
    Retourne une liste de tuples (similarité, document) triée par similarité décroissante.
    """
    # 1. Construire le vocabulaire global à partir de tous les documents et de la requête
    all_texts = documents + [query_text]
    vocabulary = build_vocabulary(all_texts)

    # 2. Convertir tous les documents en vecteurs BoW
    document_vectors = []
    for doc in documents:
        document_vectors.append(document_to_vector(doc, vocabulary))

    # 3. Convertir la requête en vecteur BoW
    query_vector = document_to_vector(query_text, vocabulary)

    # 4. Calculer la similarité cosinus entre la requête et chaque document
    similarities = []
    for i, doc_vec in enumerate(document_vectors):
        sim = cosine_similarity(query_vector, doc_vec)
        similarities.append((sim, documents[i]))

    # 5. Trier par similarité et retourner les top_k résultats
    similarities.sort(key=lambda x: x[0], reverse=True)
    return similarities[:top_k]

# Assertions pour le moteur de recherche sémantique
corpus = [
    "Le chat dort sur le tapis.",
    "Le chien joue avec la balle.",
    "Un chat noir et blanc.",
    "Le tapis est doux.",
    "La balle est ronde."
]

vocab = build_vocabulary(corpus)
assert "chat" in vocab and "tapis" in vocab, "Vocabulary should contain key words"
assert len(vocab) > 5, "Vocabulary should have multiple words"

doc_vec_0 = document_to_vector(corpus[0], vocab)
assert sum(doc_vec_0) == len(corpus[0].split()), "Document vector sum should match word count"
assert doc_vec_0[vocab["chat"]] == 1, "Vector for 'chat' count failed"

# Test de recherche
query_1 = "un chat doux"
results_1 = search_documents(query_1, corpus, top_k=2)

# Vérifions que les documents contenant "chat" ou "doux" sont bien classés.
# L'ordre exact peut varier légèrement en fonction de la composition du vocabulaire
# et des mots communs, mais les documents pertinents doivent être en tête.
assert results_1[0][0] >= results_1[1][0], "Results should be sorted by similarity"
assert any("chat" in res[1].lower() for res in results_1), "Top results should contain 'chat' or related terms"
assert any("doux" in res[1].lower() or "tapis" in res[1].lower() for res in results_1), "Top results should contain 'doux' or related terms"
assert results_1[0][0] > 0.0, "Similarity should be positive for relevant documents"
print("Semantic search assertions passed.")

# --- Partie 3 : Problème d'Algèbre de l'X : Projection Orthogonale ---

def orthogonal_projection(u, v):
    """
    Calcule la projection orthogonale du vecteur v sur le vecteur u.
    proj_u(v) = (u . v / ||u||^2) * u
    """
    if len(u) != len(v):
        raise ValueError("Vectors must have the same dimension.")

    dot_uu = dot_product(u, u)
    if dot_uu == 0:
        raise ValueError("Cannot project onto a zero vector.")

    scalar_factor = dot_product(u, v) / dot_uu
    return scalar_multiply(scalar_factor, u)

# Assertions pour la projection orthogonale
u1 = [1, 0]
v1 = [2, 2]
proj1 = orthogonal_projection(u1, v1)
# La projection de [2,2] sur l'axe des x ([1,0]) est [2,0]
assert proj1 == [2.0, 0.0], "Projection of [2,2] onto [1,0] should be [2,0]"

u2 = [1, 1]
v2 = [0, 1]
proj2 = orthogonal_projection(u2, v2)
# u.v = (1*0 + 1*1) = 1
# ||u||^2 = (1*1 + 1*1) = 2
# scalar_factor = 1/2
# proj2 = 0.5 * [1,1] = [0.5, 0.5]
assert proj2 == [0.5, 0.5], "Projection of [0,1] onto [1,1] should be [0.5, 0.5]"

# Vérification d'orthogonalité : le vecteur (v - proj_u(v)) doit être orthogonal à u.
# Leur produit scalaire doit être proche de zéro.
diff_v2_proj2 = vector_add(v2, scalar_multiply(-1, proj2)) # v2 - proj2
assert abs(dot_product(diff_v2_proj2, u2)) < 1e-7, "Orthogonality check failed for proj2"

# Projection d'un vecteur sur lui-même
u3 = [3, 4]
proj3 = orthogonal_projection(u3, u3)
assert proj3 == [3.0, 4.0], "Projection of u onto u should be u"

# Projection d'un vecteur orthogonal
u4 = [1, 0]
v4 = [0, 5]
proj4 = orthogonal_projection(u4, v4)
assert proj4 == [0.0, 0.0], "Projection of orthogonal vector should be zero vector"

try:
    orthogonal_projection([0,0], [1,1])
    assert False, "Projection onto zero vector should raise ValueError"
except ValueError:
    assert True, "Projection onto zero vector correctly raised ValueError"
print("Orthogonal projection assertions passed.")

print("\nAll TP sections completed and assertions passed!")
```
