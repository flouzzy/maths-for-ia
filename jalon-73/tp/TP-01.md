# TP 1 : Calcul discret de la norme L1 et L2

Dans ce TP, nous allons simuler un espace mesuré fini discret (une liste de probabilités) et implémenter le calcul pur des normes L1 et L2.
Nous vérifierons expérimentalement l'inclusion L2 est inclus dans L1 sur un espace de mesure finie.

```python
def compute_l1_norm(values, probabilities):
    # L1 norm is the sum of absolute values weighted by probabilities
    norm_1 = sum(abs(v) * p for v, p in zip(values, probabilities))
    return norm_1

def compute_l2_norm(values, probabilities):
    # L2 norm is the square root of the sum of squared values weighted by probabilities
    variance = sum((v ** 2) * p for v, p in zip(values, probabilities))
    return variance ** 0.5

# Tests and Validation
values = [1.0, -2.0, 3.0, -4.0]
probabilities = [0.1, 0.2, 0.3, 0.4]

l1 = compute_l1_norm(values, probabilities)
l2 = compute_l2_norm(values, probabilities)

# Theoretical validation: L1 <= L2 on a probability space
assert l1 <= l2, "Error: L1 norm should be less than or equal to L2 norm on a probability space."
assert abs(l1 - 3.0) < 1e-9
assert abs(l2 - 3.1622776601683795) < 1e-9

print("TP 1 Validation Passed!")
```
