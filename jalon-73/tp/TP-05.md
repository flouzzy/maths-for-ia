# TP 5 : L'inégalité de Minkowski numérique

L'inégalité de Minkowski est l'inégalité triangulaire pour les espaces Lp.
Nous allons la vérifier numériquement sur des tableaux discrets sans utiliser Numpy.

```python
def compute_lp_norm_array(arr, p):
    return sum(abs(x) ** p for x in arr) ** (1.0 / p)

def add_arrays(arr1, arr2):
    return [a + b for a, b in zip(arr1, arr2)]

# Tests and Validation
f = [1.5, -2.5, 3.0]
g = [-0.5, 1.5, -1.0]

f_plus_g = add_arrays(f, g)

for p in [1, 2, 3, 5]:
    norm_f = compute_lp_norm_array(f, p)
    norm_g = compute_lp_norm_array(g, p)
    norm_sum = compute_lp_norm_array(f_plus_g, p)

    # Minkowski inequality: ||f + g||_p <= ||f||_p + ||g||_p
    assert norm_sum <= norm_f + norm_g + 1e-9, f"Minkowski failed for p={p}"

print("TP 5 Validation Passed!")
```
