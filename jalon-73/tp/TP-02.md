# TP 2 : Le supremum essentiel (L-infinity norm)

Nous allons coder une fonction qui calcule la norme L-infinity discrète.
La subtilité est que nous devons ignorer les valeurs qui ont une probabilité strictement égale à 0 (l'équivalent d'un ensemble de mesure nulle).

```python
def compute_linf_norm(values, probabilities):
    # Filter out values where probability is 0 (sets of measure zero)
    valid_values = [abs(v) for v, p in zip(values, probabilities) if p > 0]

    if not valid_values:
        return 0.0

    return max(valid_values)

# Tests and Validation
values = [10.0, -50.0, 1000.0]
# The value 1000 has probability 0, so it should be ignored in the essential supremum
probabilities = [0.8, 0.2, 0.0]

linf = compute_linf_norm(values, probabilities)

# The maximum absolute value is 1000, but the essential supremum is 50.
assert linf == 50.0, f"Expected 50.0, got {linf}"

print("TP 2 Validation Passed!")
```
