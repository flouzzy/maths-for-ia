# TP 3 : Approximation numérique de l'intégrale de Lebesgue pour Lp

Nous allons approximer numériquement l'intégrale d'une fonction continue sur [0, 1] en utilisant la méthode des rectangles pour calculer sa norme Lp approchée.

```python
def compute_continuous_lp_norm(func, p, a, b, num_steps=10000):
    step_size = (b - a) / num_steps
    integral_sum = 0.0

    for i in range(num_steps):
        x = a + i * step_size
        val = func(x)
        integral_sum += (abs(val) ** p) * step_size

    return integral_sum ** (1.0 / p)

# Tests and Validation
# Function f(x) = x on [0, 1]
def f(x):
    return x

# We know analytically that ||f||_p = (1 / (p + 1)) ** (1 / p)
l1_approx = compute_continuous_lp_norm(f, 1, 0.0, 1.0)
l2_approx = compute_continuous_lp_norm(f, 2, 0.0, 1.0)

# Theoretical targets
l1_target = 0.5
l2_target = (1.0 / 3.0) ** 0.5

assert abs(l1_approx - l1_target) < 1e-3, f"L1 error too high: {l1_approx}"
assert abs(l2_approx - l2_target) < 1e-3, f"L2 error too high: {l2_approx}"

print("TP 3 Validation Passed!")
```
