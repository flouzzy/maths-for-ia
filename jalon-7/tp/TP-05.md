# TP 5 : Interpolation de Lagrange et Base de l'Espace des Polynômes

## Objectif
L'objectif de ce TP est de vérifier informatiquement qu'une famille spécifique de polynômes forme une base de l'espace vectoriel $\mathbb{R}_n[X]$. Nous allons implémenter les polynômes interpolateurs de Lagrange pour un ensemble de $n+1$ points distincts et démontrer numériquement qu'ils constituent une famille libre et génératrice. Cette vérification se fera sans l'aide de bibliothèques mathématiques de haut niveau, en construisant notre propre logique d'évaluation et de combinaison linéaire.

## Implémentation en Python
```python
def evaluer_polynome_lagrange(points, i, x):
    """
    Évalue le i-ème polynôme de Lagrange L_i(X) au point x.
    points est une liste de tuples (x_k, y_k).
    """
    resultat = 1.0
    x_i = points[i][0]
    for j, (x_j, _) in enumerate(points):
        if i != j:
            resultat *= (x - x_j) / (x_i - x_j)
    return resultat

def combinaison_lineaire_lagrange(points, coefficients, x):
    """
    Évalue la combinaison linéaire somme(coeff_i * L_i(X)) au point x.
    """
    assert len(points) == len(coefficients), "Dimensions incompatibles"
    somme = 0.0
    for i, coeff in enumerate(coefficients):
        somme += coeff * evaluer_polynome_lagrange(points, i, x)
    return somme

def verifier_famille_libre_lagrange(points):
    """
    Vérifie expérimentalement que la famille est libre.
    Si somme(lambda_i * L_i) = 0 pour tout x, alors lambda_i = 0.
    En évaluant aux points x_j, on trouve directement lambda_j = 0.
    """
    n = len(points)
    # L_i(x_j) doit valoir 1 si i == j, 0 sinon
    for i in range(n):
        for j in range(n):
            valeur = evaluer_polynome_lagrange(points, i, points[j][0])
            if i == j:
                assert abs(valeur - 1.0) < 1e-9, f"L_{i}(x_{i}) n'est pas 1"
            else:
                assert abs(valeur) < 1e-9, f"L_{i}(x_{j}) n'est pas 0"
    return True

# --- Tests et Validation Mathématique ---
points_interpolation = [(1.0, 5.0), (2.0, 7.0), (4.0, 15.0)]

# 1. Vérification que la famille des polynômes de Lagrange est une base
# En dimension n=3 (polynômes de degré 2), une famille de 3 vecteurs libres est une base.
print("Vérification de la liberté de la famille de Lagrange...")
assert verifier_famille_libre_lagrange(points_interpolation)
print("La famille est libre (et donc une base de R_2[X]).")

# 2. Vérification de la propriété génératrice (Interpolation)
# On vérifie que la combinaison linéaire avec les ordonnées y_i passe par tous les points
y_coeffs = [y for _, y in points_interpolation]

print("\nVérification de l'interpolation (génération du polynôme cible)...")
for x_k, y_k in points_interpolation:
    y_calcule = combinaison_lineaire_lagrange(points_interpolation, y_coeffs, x_k)
    assert abs(y_calcule - y_k) < 1e-9, f"Échec de l'interpolation au point {x_k}"
    print(f"Point ({x_k}, {y_k}) vérifié : P({x_k}) = {y_calcule}")

print("\nTous les tests mathématiques ont réussi.")
```
