# TP-02 : Flot de gradient scalaire

Ici, on simule l'EDO $dx/dt = -\nabla L(x)$ pour une fonction de perte convexe simple $L(x) = \frac{1}{2} x^2$.
Le gradient est $\nabla L(x) = x$, donc l'EDO est $x' = -x$. C'est une équation linéaire homogène dont la solution est $x(t) = x_0 e^{-t}$.

```python
import math

def gradient_flow_step(x, lr):
    '''
    Effectue un pas de discrétisation du flot de gradient pour L(x) = 0.5 * x^2
    '''
    grad = x  # La derivee de 0.5 * x^2 est x
    return x - lr * grad

def simulate_gradient_flow():
    x = 10.0  # Point de depart
    dt = 0.01
    t_end = 5.0

    steps = int(t_end / dt)

    for _ in range(steps):
        x = gradient_flow_step(x, dt)

    # Solution analytique continue
    expected = 10.0 * math.exp(-t_end)

    error = abs(x - expected)

    # Validation
    assert error < 0.05, f"Le flot discret devie de la solution continue analytique. Erreur : {error}"
    assert x < 0.1, "La descente n'a pas converge vers 0."
    print("TP-02 validé : Le flot de gradient correspond à la dynamique continue analytique.")

if __name__ == '__main__':
    simulate_gradient_flow()
```
