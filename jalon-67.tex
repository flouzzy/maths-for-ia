\section*{Jalon 67 : Théorème de convergence monotone (Beppo Levi)}

\section{Présentation du concept clé}

Imaginez que vous construisiez une tour de blocs de glace qui fondent très lentement, mais que chaque jour vous ajoutiez une petite couche de glace supplémentaire par-dessus ($f_n \le f_{n+1}$). Vous voulez savoir quel sera le volume final de la tour ($f = \lim f_n$). Le \textbf{Théorème de Convergence Monotone} dit quelque chose de très simple et rassurant : le volume de la tour finale est exactement égal à la limite des volumes que vous avez mesurés jour après jour. En d'autres termes, pour des objets qui ne font que grandir, l'ordre dans lequel on fait les opérations (calculer le volume puis faire la limite, ou faire la limite puis calculer le volume) ne change pas le résultat.
C'est la grande force de l'intégrale de Lebesgue par rapport à celle de Riemann. Avec Riemann, on ne pouvait pas garantir que la limite d'une suite de fonctions intégrables soit encore intégrable. Avec Lebesgue et Beppo Levi, on a un outil ultra-robuste pour manipuler les limites et les sommes infinies.
Une suite de courbes qui "montent" vers une courbe plafond. L'aire sous les courbes monte elle aussi vers l'aire sous le plafond.

\section{Formalisation}

Soit $(X, \mathcal{F}, \mu)$ un espace mesuré.

\subsection{Énoncé du Théorème}

> \textbf{Théorème de Convergence Monotone (Beppo Levi) :}
> Soit $(f_n)_{n \in \mathbb{N}}$ une suite de fonctions mesurables de $X$ dans $[0, +\infty]$.
> Si la suite est \textbf{croissante} presque partout :
> $$\forall n \in \mathbb{N}, \quad f_n \le f_{n+1} \text{ p.p.}$$
> Alors la fonction limite $f = \lim_{n \to \infty} f_n$ est mesurable et :
> $$\int_X \left( \lim_{n \to \infty} f_n \right) d\mu = \lim_{n \to \infty} \int_X f_n d\mu$$

\subsection{Exemples Concrets Immédiats}

\textbf{Exemple 1 (Suite constante) :}
Soit $f_n(x) = c \ge 0$ pour tout $n$. La suite est croissante (large) et converge vers $f(x) = c$. On a bien $\int c d\mu = \lim \int c d\mu$.

\textbf{Exemple 2 (Suite de fonctions étagées sur $[0,1]$) :}
Soit $f_n(x) = 1 - \frac{1}{n}$. La suite est positive et croissante.
La limite est $f(x) = 1$. L'intégrale de Lebesgue de $f_n$ sur $[0,1]$ est $\int_0^1 (1 - 1/n) dx = 1 - 1/n$.
La limite des intégrales est $\lim (1 - 1/n) = 1$. L'intégrale de la limite est $\int_0^1 1 dx = 1$. L'égalité est vérifiée.

\textbf{Exemple 3 (Fonction tendant vers $+\infty$) :}
Soit $f_n(x) = n \cdot \chi_{[0,1]}(x)$. La suite est positive, croissante et diverge vers $+\infty$ sur $[0,1]$.
L'intégrale de $f_n$ est $n$. La limite est $+\infty$. L'intégrale de la limite (la fonction $+\infty \cdot \chi_{[0,1]}$) est $+\infty$.

\textbf{Exemple 4 (Série géométrique) :}
Soit $X = \mathbb{N}$ avec la mesure de comptage. Soit $u_n(k) = (\frac{1}{2})^n \chi_{\{0\}}(k)$.
La somme $\sum_n u_n(0) = \sum (1/2)^n = 2$.
L'intégrale de la somme est 2. La somme des intégrales est $\sum 1/2^n = 2$.

\textbf{Exemple 5 (Croissance stricte) :}
Soit $f_n(x) = x^2 - \frac{1}{n}$ pour $x \in [1,2]$. $f_n$ est croissante et $f_n(x) > 0$ sur l'intervalle.
La limite est $f(x) = x^2$. L'intégrale de $f_n$ est $[x^3/3 - x/n]_1^2 = (8/3 - 2/n) - (1/3 - 1/n) = 7/3 - 1/n$.
La limite est $7/3$, ce qui est bien $\int_1^2 x^2 dx$.

\textbf{Exemple 6 (Fonctions indicatrices emboîtées) :}
Soit $A_n = [0, 1 - 1/n]$. Les ensembles sont emboîtés $A_n \subset A_{n+1}$.
Soit $f_n = \chi_{A_n}$. La suite de fonctions croît vers $f = \chi_{[0,1[}$.
$\int f_n d\mu = \mu(A_n) = 1 - 1/n$. La limite est $1$. $\int f d\mu = \mu([0,1[) = 1$.

\textbf{Exemple 7 (Gaussienne qui s'élargit) :}
Soit $f_n(x) = e^{-x^2} \cdot \chi_{[-n,n]}(x)$. La suite est croissante.
La limite est $e^{-x^2}$ sur tout $\mathbb{R}$.
$\int f_n = \int_{-n}^n e^{-x^2} dx \to \sqrt{\pi}$, qui est bien l'intégrale sur $\mathbb{R}$ de la gaussienne.

\subsection{Corollaire (Sommation terme à terme)}

> \textbf{Théorème :} Pour toute suite de fonctions mesurables \textbf{positives} $(u_n)$ :
> $$\int_X \left( \sum_{n=0}^\infty u_n \right) d\mu = \sum_{n=0}^\infty \int_X u_n d\mu$$

\section{Démonstrations}

\subsection{Démonstration du Théorème de Beppo Levi}

1. \textbf{Existence de la limite :} Comme $(f_n(x))$ est une suite croissante de $[0, +\infty]$, elle admet toujours une limite dans $[0, +\infty]$ pour chaque $x$. On a vu (Jalon 65) que le sup (ou la limite ici) de fonctions mesurables est mesurable.
2. \textbf{Inégalité facile ($\ge$) :} Comme $f_n \le f$ pour tout $n$, par croissance de l'intégrale (Jalon 66) :
   $\int f_n \le \int f$. En prenant la limite : $\lim \int f_n \le \int f$.
3. \textbf{Inégalité difficile ($\le$) :} Soit $s$ une fonction simple telle que $0 \le s \le f$. Soit $\alpha \in ]0, 1[$.
   On définit $A_n = \{x \in X \mid f_n(x) \ge \alpha s(x) \}$.
   - Comme $f_n$ croît vers $f$ et $\alpha s < f$ (là où $s>0$), la suite d'ensembles $(A_n)$ est croissante et son union est $X$.
   - On a $\int f_n \ge \int_{A_n} f_n \ge \int_{A_n} \alpha s = \alpha \int_{A_n} s$.
   - Par continuité monotone de la mesure (Jalon 63), $\lim \int_{A_n} s = \int_X s$.
   - Donc $\lim \int f_n \ge \alpha \int_X s$.
   - En faisant tendre $\alpha \to 1$, on a $\lim \int f_n \ge \int s$.
4. \textbf{Conclusion :} Comme c'est vrai pour tout $s \le f$, alors $\lim \int f_n \ge \sup \int s = \int f$.
   Les deux inégalités prouvent l'égalité.

\section{Exercices d'Application}

\subsection{Exercice 1 : Intégrale d'une série}
\textbf{Énoncé :} Calculer $\int_0^1 \sum_{n=1}^\infty x^n dx$.
\textbf{Correction Détaillée :}
1. Les fonctions $u_n(x) = x^n$ sont mesurables et positives sur $[0, 1]$.
2. Par le corollaire du TCM, on peut intervertir somme et intégrale.
3. $I = \sum_{n=1}^\infty \int_0^1 x^n dx = \sum_{n=1}^\infty \left[ \frac{x^{n+1}}{n+1} \right]_0^1 = \sum_{n=1}^\infty \frac{1}{n+1}$.
4. Cette série est la série harmonique (moins son premier terme), elle diverge vers $+\infty$.
5. L'intégrale de la somme est donc $+\infty$.

\subsection{Exercice 2 : Niveau Avancé (Utilisation de la mesure de comptage)}
\textbf{Énoncé :} Retrouver le théorème de sommation des séries à termes positifs doubles : $\sum_{i} \sum_{j} a_{i,j} = \sum_{j} \sum_{i} a_{i,j}$.
\textbf{Correction Détaillée :}
On considère l'espace $\mathbb{N}$ muni de la mesure de comptage $\mu$. Soit $f_n(i) = \sum_{j=0}^n a_{i,j}$. La suite de fonctions $(f_n)$ est croissante car $a_{i,j} \ge 0$. Par Beppo Levi, l'intégrale de la limite est la limite des intégrales, ce qui correspond exactement à l'interversion des sommes.

\section{Application en Intelligence Artificielle}

- \textbf{Le Pont Théorique :} En IA, on manipule souvent des \textbf{Espérances de sommes infinies} ou des limites de processus. Le TCM est l'outil qui permet de passer à la limite sous l'espérance en toute sécurité.
- \textbf{Example Concret :}
    - \textbf{Processus de Poisson :} Pour calculer le nombre moyen d'événements (ex: clics sur une pub) sur un intervalle de temps, on somme les probabilités d'événements infinitésimaux. Le TCM garantit que la somme de ces moyennes locales donne bien la moyenne globale.
    - \textbf{Séries de Taylor de fonctions de perte :} Si on décompose une fonction de coût complexe en une série de fonctions positives, on peut intégrer cette série terme à terme pour obtenir une approximation de la perte attendue.
    - \textbf{Théorie des Noyaux (Kernels) :} De nombreux noyaux (comme le noyau RBF) peuvent être vus comme des sommes infinies de caractéristiques. Le TCM permet de manipuler ces représentations de dimension infinie comme si elles étaient finies lors des calculs d'intégrales de risque.

\part{Exercices d'Application et de Concours}
\subsection*{Exercice 1 : Intégrale d'une suite de fonctions puissances \quad $\bigstar\star\star\star$}

\subsubsection*{Énoncé}
Soit $f_n(x) = x^n$ sur $[0, 1[$. Montrer que $\lim_{n \to \infty} \int_0^1 f_n(x) dx = 0$ en utilisant le TCM.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item \textbf{Mesurabilité et positivité} : $f_n$ est mesurable et positive.
\item Cependant, la suite $(f_n)$ est décroissante. Mais on peut utiliser le TCM sur $1 - f_n(x)$ qui est croissante positive.
\item $\lim (1 - f_n(x)) = 1$ p.p. Donc $\int 1 dx = \lim \int (1-x^n)dx \implies 1 = 1 - \lim \int x^n dx \implies \lim \int x^n dx = 0$.
\end{itemize}

\subsection*{Exercice 2 : Application du Théorème de Convergence Monotone à une gaussienne tronquée \quad $\bigstar\bigstar\star\star$}

\subsubsection*{Énoncé}
Soit $(f_n)$ une suite de fonctions mesurables positives définies sur $\mathbb{R}$ par $f_n(x) = \chi_{[-n, n]}(x) e^{-x^2}$. Calculer la limite de l'intégrale de Lebesgue de $f_n$.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item \textbf{Mesurabilité et positivité} : Pour tout $n \in \mathbb{N}$, $f_n$ est mesurable et positive.
\item \textbf{Croissance} : Pour tout $x$, $f_n(x) \le f_{n+1}(x)$.
\item \textbf{Limite} : $\lim f_n(x) = e^{-x^2}$.
\item \textbf{Application du TCM} : Par Beppo Levi, $\lim \int f_n = \int e^{-x^2} = \sqrt{\pi}$.
\end{itemize}

\subsection*{Exercice 3 : Série de fonctions mesurables \quad $\bigstar\bigstar\bigstar\star$}

\subsubsection*{Énoncé}
Soit $u_n(x) = \frac{x}{(1+x)^n}$ sur $]0, \infty[$. Calculer $\int_0^\infty \sum u_n(x) dx$.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item $u_n$ mesurable positive. 2. Par le corollaire du TCM, $\int \sum u_n = \sum \int u_n$. 3. $\sum u_n(x) = x \frac{1}{1 - 1/(1+x)} = 1+x$ pour $x>0$. 4. L'intégrale de $1+x$ diverge vers $+\infty$.
\end{itemize}

\subsection*{Exercice 4 : Interversion limite et intégrale avec fonction indicatrice \quad $\bigstar\star\star\star$}

\subsubsection*{Énoncé}
Calculer $\lim_{n \to \infty} \int_0^n (1-\frac{x}{n})^n e^{x/2} dx$.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item Soit $f_n(x) = \chi_{[0,n]}(x) (1-x/n)^n e^{x/2}$. 2. $f_n(x)$ converge vers $e^{-x} e^{x/2} = e^{-x/2}$. 3. La suite $f_n$ est croissante en $n$. 4. Par TCM, $\int f = \int e^{-x/2} = [-2e^{-x/2}]_0^\infty = 2$.
\end{itemize}

\subsection*{Exercice 5 : Convergence monotone avec des logarithmes \quad $\bigstar\bigstar\star\star$}

\subsubsection*{Énoncé}
Montrer que $\lim_{n \to \infty} \int_1^\infty \frac{n \ln(1+x/n)}{x^3} dx = \int_1^\infty \frac{1}{x^2} dx$.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item Posons $f_n(x) = \frac{n \ln(1+x/n)}{x^3}$. 2. La suite est croissante (car $n \ln(1+x/n)$ est croissant en $n$). 3. $f_n(x) \to 1/x^2$. 4. TCM donne le résultat. Intégrale vaut 1.
\end{itemize}

\subsection*{Exercice 6 : Convergence d'intégrale fractionnaire \quad $\bigstar\bigstar\bigstar\star$}

\subsubsection*{Énoncé}
Évaluer $\lim_{n \to \infty} \int_0^\infty \frac{x^{1/n}}{1+x^2} dx$.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item $f_n(x) = x^{1/n} / (1+x^2)$. 2. Sur $[1, \infty[$, la suite est décroissante (TCM non applicable directement, utiliser convergence dominée ou astuce). 3. Cet exercice introduit la limite du TCM.
\end{itemize}

\subsection*{Exercice 7 : Convergence Monotone sur ensemble discret \quad $\bigstar\star\star\star$}

\subsubsection*{Énoncé}
On munit $\mathbb{N}$ de la mesure de comptage. Soit $f_n(k) = (1 - 1/n)^k$. Calculer $\lim \int_{\mathbb{N}} f_n$.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item Suite croissante vers 1. 2. $\int 1 = +\infty$. 3. $\int f_n = \sum_k (1-1/n)^k = \frac{1}{1-(1-1/n)} = n$. 4. $\lim n = +\infty$. Cohérent avec TCM.
\end{itemize}

\subsection*{Exercice 8 : Inégalité stricte sans croissance \quad $\bigstar\star\star$}

\subsubsection*{Énoncé}
Soit $f_n = n \chi_{]0, 1/n[}$. Montrer que $\int \lim f_n \neq \lim \int f_n$. Pourquoi TCM ne s'applique pas ?

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item 1. $\lim f_n = 0$ p.p. donc $\int \lim f_n = 0$.
\item 2. $\int f_n = n \times (1/n) = 1$.
\item 3. $0 \neq 1$. Le TCM ne s'applique pas car la suite n'est pas croissante.
\end{itemize}

\subsection*{Exercice 9 : Croissance presque partout \quad $\bigstar\bigstar\bigstar\star$}

\subsubsection*{Énoncé}
Montrer que le TCM reste vrai si la croissance $f_n \le f_{n+1}$ n'est vraie que presque partout.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item Soit $N_n$ l'ensemble de mesure nulle où $f_n > f_{n+1}$. 2. $N = \cup N_n$ est de mesure nulle. 3. Sur $X \setminus N$, la suite est croissante partout. 4. Les intégrales sur $N$ sont nulles, on applique TCM sur $X \setminus N$.
\end{itemize}

\subsection*{Exercice 10 : Extension à des fonctions à valeurs dans $[-\infty, +\infty]$ \quad $\bigstar\star\star\star$}

\subsubsection*{Énoncé}
Montrer que si $f_n$ est croissante et $f_1$ est intégrable, le TCM s'applique.

\subsubsection*{Correction Détaillée}
\begin{itemize}
\item On se ramène aux fonctions positives en considérant $g_n = f_n - f_1$. 2. $g_n \ge 0$ et $g_n \le g_{n+1}$. 3. TCM s'applique à $g_n$. 4. On conclut par linéarité en rajoutant $f_1$.
\end{itemize}

\subsection*{TP 1 : Simulation du TCM avec Riemann}

\subsubsection*{Objectif}
Implémentation algorithmique du concept correspondant.

\subsubsection*{Code Python}
\begin{lstlisting}[language=python]
import math

def f_n(n, x):
    if 0 <= x <= 1:
        return x**n
    return 0.0

def integrate(n, N_steps=1000):
    dx = 1.0 / N_steps
    return sum(f_n(n, i*dx)*dx for i in range(N_steps))

def tp1():
    for n in [1, 2, 5, 10, 50, 100]:
        print("n=", n, "int=", integrate(n))

if __name__ == '__main__':
    tp1()
\end{lstlisting}

\subsubsection*{Objectif}

import math

def f_n(n, x):
    if -n <= x <= n:
        return math.exp(-x*x)
    return 0.0

def integrate(n, dx=0.01):
    total = 0.0
    x = -n
    while x <= n:
        total += f_n(n, x) * dx
        x += dx
    return total

def tp2():
    print("sqrt(pi) =", math.sqrt(math.pi))
    for n in range(1, 10):
        print("n=", n, "int=", integrate(n))

if __name__ == '__main__':
    tp2()

\subsection*{TP 5 : Convergence monotone sur une série double (Mesure de comptage)}

\subsubsection*{Objectif}
Implémentation algorithmique du concept correspondant.

def a(i, j):
    if i == j:
        return 1.0 / (2 ** i)
    return 0.0

def partial_sum(N):
    total = 0.0
    for i in range(N):
        for j in range(N):
            total += a(i, j)
    return total

def tp5():
    for N in [1, 2, 5, 10, 20]:
        print("N=", N, "sum=", partial_sum(N))

if __name__ == '__main__':
    tp5()
\end{lstlisting}
