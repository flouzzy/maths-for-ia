# TP 5 : Application au Deep Learning (Gradient Descent with Momentum)

Le Momentum classique de Polyak peut s'interpréter comme la discrétisation d'une équation continue amortie : $y'' + c y' + \nabla f(y) = 0$.

```python
def f(x):
    return 5.0 * x**2 # Parabole convexe

def grad_f(x):
    return 10.0 * x

def momentum_step(x, velocity, lr, gamma):
    # velocity_next = gamma * velocity - lr * grad_f(x)
    # x_next = x + velocity_next
    velocity = gamma * velocity - lr * grad_f(x)
    x = x + velocity
    return x, velocity

x_no_mom = 10.0
x_mom = 10.0
v_mom = 0.0
lr = 0.01
gamma = 0.9

for _ in range(15):
    # Vanilla GD (ordre 1)
    x_no_mom = x_no_mom - lr * grad_f(x_no_mom)
    # Momentum (ordre 2 implicite)
    x_mom, v_mom = momentum_step(x_mom, v_mom, lr, gamma)

assert abs(x_mom) < abs(x_no_mom), "L'inertie n'accélère pas la convergence dans la vallée."
print("Analogie Ordre 2 (Momentum) mathématiquement vérifiée en optimisation.")
```
