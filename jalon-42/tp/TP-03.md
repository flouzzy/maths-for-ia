# TP 3 : Réponse à un forçage sinusoïdal (Résonance)

Le système subit une force externe périodique $y'' + \omega_0^2 y = F_0 \cos(\omega t)$.
Nous implémentons une intégration précise avec Runge-Kutta 4.

```python
import math

def rk4_step(t, y, v, dt, omega_0_sq, omega, F_0):
    def accel(t, y, v):
        return F_0 * math.cos(omega * t) - omega_0_sq * y

    k1_y = v
    k1_v = accel(t, y, v)

    k2_y = v + 0.5 * dt * k1_v
    k2_v = accel(t + 0.5 * dt, y + 0.5 * dt * k1_y, v + 0.5 * dt * k1_v)

    k3_y = v + 0.5 * dt * k2_v
    k3_v = accel(t + 0.5 * dt, y + 0.5 * dt * k2_y, v + 0.5 * dt * k2_v)

    k4_y = v + dt * k3_v
    k4_v = accel(t + dt, y + dt * k3_y, v + dt * k3_y)

    y_next = y + (dt / 6.0) * (k1_y + 2*k2_y + 2*k3_y + k4_y)
    v_next = v + (dt / 6.0) * (k1_v + 2*k2_v + 2*k3_v + k4_v)

    return y_next, v_next

y, v = 0.0, 0.0
# Cas de résonance pure : omega = omega_0 = 2.0
dt = 0.01
amplitude_max = 0.0
for i in range(1000):
    y, v = rk4_step(i*dt, y, v, dt, 4.0, 2.0, 1.0)
    amplitude_max = max(amplitude_max, abs(y))

assert amplitude_max > 1.0, "La résonance n'amplifie pas la position."
print("Phénomène de résonance validé avec RK4.")
```
