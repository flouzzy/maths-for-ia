# TP 2 : Simulation d'un oscillateur amorti

Nous ajoutons un terme de friction (amortissement visqueux $c y'$). L'équation devient $y'' + c y' + k y = 0$.
L'objectif est d'observer le régime pseudo-périodique.

```python
import math

def simulate_damped_oscillator(c, k, y0, v0, dt, t_max):
    assert c > 0 and k > 0, "Paramètres physiques invalides."

    t = 0.0
    y = y0
    v = v0

    y_history = []

    while t <= t_max:
        y_history.append((t, y))

        # Intégration Verlet ou Semi-implicite pour meilleure stabilité
        v_next = v + dt * (-c * v - k * y)
        y_next = y + dt * v_next

        t += dt
        v = v_next
        y = y_next

    return y_history

# Paramètres : faible amortissement, on attend des oscillations décroissantes
history = simulate_damped_oscillator(0.5, 2.0, 1.0, 0.0, 0.01, 10.0)

# Validation : L'amplitude doit diminuer
_, y_start = history[0]
_, y_end = history[-1]
assert abs(y_end) < abs(y_start), "L'amortissement ne réduit pas l'amplitude."
print("Amortissement correctement simulé.")
```
