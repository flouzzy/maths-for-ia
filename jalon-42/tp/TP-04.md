# TP 4 : Résolution de systèmes d'ordre 2 couplés

Modélisation de deux masses couplées par des ressorts. Les équations couplées se vectorisent en grandes matrices.
$M \mathbf{y}'' + K \mathbf{y} = 0$.

```python
def mat_vec_mul(M, V):
    return [sum(M[i][j]*V[j] for j in range(len(V))) for i in range(len(M))]

def vector_add(V1, V2):
    return [v1 + v2 for v1, v2 in zip(V1, V2)]

def vector_scale(scalar, V):
    return [scalar * v for v in V]

def step_coupled(Y, V, M_inv_K, dt):
    # Accel = - M_inv * K * Y
    accel = vector_scale(-1, mat_vec_mul(M_inv_K, Y))

    V_next = vector_add(V, vector_scale(dt, accel))
    Y_next = vector_add(Y, vector_scale(dt, V_next))
    return Y_next, V_next

# Configuration de deux masses (m=1) et trois ressorts (k=1)
M_inv_K = [[2.0, -1.0],
           [-1.0, 2.0]]

Y = [1.0, -1.0] # Mode antisymétrique
V = [0.0, 0.0]

for _ in range(100):
    Y, V = step_coupled(Y, V, M_inv_K, 0.05)

assert abs(Y[0] + Y[1]) < 0.01, "Le mode antisymétrique n'est pas préservé, erreur de symétrie."
print("Couplage vectoriel et modes propres validés.")
```
