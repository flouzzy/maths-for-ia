# TP 1 : Résolution numérique par la méthode d'Euler Explicite

L'objectif est d'implémenter le schéma le plus simple (Euler explicite) pour une EDO d'ordre 2, en modélisant un oscillateur harmonique sans amortissement ($y'' + \omega^2 y = 0$).

```python
import math

def solve_euler(omega_sq, t0, y0, v0, dt, num_steps):
    t_vals = [t0]
    y_vals = [y0]
    v_vals = [v0]

    t, y, v = t0, y0, v0

    for _ in range(num_steps):
        # Système d'ordre 1 : y' = v, v' = -omega_sq * y
        y_next = y + dt * v
        v_next = v + dt * (-omega_sq * y)
        t_next = t + dt

        y_vals.append(y_next)
        v_vals.append(v_next)
        t_vals.append(t_next)

        t, y, v = t_next, y_next, v_next

    return t_vals, y_vals, v_vals

# Validation mathématique (oscillateur harmonique omega = 1)
t_out, y_out, v_out = solve_euler(1.0, 0.0, 1.0, 0.0, 0.001, 1000)
assert abs(y_out[-1] - math.cos(t_out[-1])) < 0.05, "La méthode d'Euler diverge trop de la solution analytique."
print("Validation Euler OK.")
```
