# TP 5 : Méthode de Newton pour l'optimisation (Matrice Hessienne)

Ce TP propose de coder rigoureusement en Python pur les concepts d'analyse multivariée abordés.
Aucun framework de haut niveau (numpy, pytorch, etc.) n'est autorisé pour l'implémentation du noyau de calcul afin de garantir une compréhension profonde des algorithmes.

## 1. Objectif Théorique
Aller plus loin que l'ordre 1 (gradient) en implementant l'ordre 2. L'algorithme de Newton utilise l'inverse de la matrice Jacobienne du gradient (la matrice Hessienne) pour trouver directement le minimum des fonctions quadratiques.

## 2. Implémentation Python Pur

```python
# L'algorithme de Newton met a jour selon : x_{k+1} = x_k - H(x_k)^{-1} * grad(x_k)

def inverse_2x2(H):
    """Inverse analytique d'une matrice 2x2."""
    det = H[0][0]*H[1][1] - H[0][1]*H[1][0]
    if det == 0:
        raise ValueError("Matrice singuliere")
    inv = [
        [ H[1][1]/det, -H[0][1]/det],
        [-H[1][0]/det,  H[0][0]/det]
    ]
    return inv

def newton_method(grad_f, hessian_f, start_point, max_iter=10):
    current = list(start_point)
    for _ in range(max_iter):
        g = grad_f(current)
        H = hessian_f(current)
        H_inv = inverse_2x2(H)

        # Produit matrice vecteur : step = H_inv * g
        step_x = H_inv[0][0] * g[0] + H_inv[0][1] * g[1]
        step_y = H_inv[1][0] * g[0] + H_inv[1][1] * g[1]

        current[0] -= step_x
        current[1] -= step_y

    return current

# --- TEST ET VALIDATION MATHÉMATIQUE ---
# Soit f(x, y) = 3x^2 + xy + y^2 - 4x - 5y
# L'optimum est solution du systeme lineaire grad_f = 0
# grad_f = [6x + y - 4, x + 2y - 5]
# H_f = [[6, 1], [1, 2]]
def grad_f_quad(p):
    x, y = p
    return [6*x + y - 4, x + 2*y - 5]

def hessian_f_quad(p):
    return [[6.0, 1.0], [1.0, 2.0]]

start = [0.0, 0.0]
# La methode de Newton converge en UNE SEULE iteration pour une forme quadratique !
optimum = newton_method(grad_f_quad, hessian_f_quad, start, max_iter=2)

# Verifions le systeme analytique : 6x+y=4 et x+2y=5 => 11x=3 => x=3/11, y = 5-x/2 = (55-3)/22 = 26/11
expected_x = 3.0 / 11.0
expected_y = 26.0 / 11.0

assert abs(optimum[0] - expected_x) < 1e-6, "Valeur de x incorrecte pour Newton"
assert abs(optimum[1] - expected_y) < 1e-6, "Valeur de y incorrecte pour Newton"
print("TP 5 valide : La methode de Newton trouve le zero exact instantanement.")

```
