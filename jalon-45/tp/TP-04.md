# TP 4 : Régression linéaire analytique (Différentielle de la fonction de coût)

Ce TP propose de coder rigoureusement en Python pur les concepts d'analyse multivariée abordés.
Aucun framework de haut niveau (numpy, pytorch, etc.) n'est autorisé pour l'implémentation du noyau de calcul afin de garantir une compréhension profonde des algorithmes.

## 1. Objectif Théorique
Utiliser l'expression analytique du gradient de la fonction de coût quadratique (demontree dans l'exercice 6) pour effectuer une descente de gradient sur un jeu de données.

## 2. Implémentation Python Pur

```python
# Fonction de cout J(theta) = 0.5 * ||X * theta - y||^2
# Gradient analytique : grad(J) = X^T * (X * theta - y)

def matrix_vector_mult(X, v):
    return [sum(X[i][j] * v[j] for j in range(len(v))) for i in range(len(X))]

def transpose(X):
    return [[X[j][i] for j in range(len(X))] for i in range(len(X[0]))]

def vector_sub(v1, v2):
    return [x - y for x, y in zip(v1, v2)]

def gradient_cost_function(X, y, theta):
    """
    Calcule analytiquement X^T * (X * theta - y)
    """
    pred = matrix_vector_mult(X, theta)
    error = vector_sub(pred, y)
    X_t = transpose(X)
    return matrix_vector_mult(X_t, error)

def fit_linear_regression(X, y, learning_rate=0.01, epochs=500):
    p = len(X[0])
    theta = [0.0] * p # Initialisation à zero

    for _ in range(epochs):
        grad = gradient_cost_function(X, y, theta)
        theta = [theta[j] - learning_rate * grad[j] for j in range(p)]

    return theta

# --- TEST ET VALIDATION MATHÉMATIQUE ---
# Donnees simples : y = 3x_1 + 2x_2 (pas de biais pour simplifier)
X_data = [[1, 2], [2, 1], [3, 4], [4, 3]]
y_data = [7, 8, 17, 18] # (3*1+2*2=7), (3*2+2*1=8), etc.

theta_opt = fit_linear_regression(X_data, y_data)

assert abs(theta_opt[0] - 3.0) < 0.1, "Parametre theta_1 incorrect"
assert abs(theta_opt[1] - 2.0) < 0.1, "Parametre theta_2 incorrect"
print("TP 4 valide : Convergence des poids du modele affine par descente analytique.")

```
