# TP 1 : Calcul approché des dérivées partielles par différences finies

Ce TP propose de coder rigoureusement en Python pur les concepts d'analyse multivariée abordés.
Aucun framework de haut niveau (numpy, pytorch, etc.) n'est autorisé pour l'implémentation du noyau de calcul afin de garantir une compréhension profonde des algorithmes.

## 1. Objectif Théorique
Le taux d'accroissement permet d'approximer la dérivée partielle. Nous allons implémenter le calcul numérique du gradient d'une fonction scalaire.

## 2. Implémentation Python Pur

```python
def partial_derivative(f, point, i, epsilon=1e-5):
    """
    Calcule l'approximation par difference finie centrale de la derivee partielle
    de f au 'point' par rapport a la i-eme coordonnee.
    """
    p_plus = point.copy()
    p_minus = point.copy()
    p_plus[i] += epsilon
    p_minus[i] -= epsilon

    # Difference centrale pour une meilleure precision : (f(x+h) - f(x-h)) / 2h
    return (f(p_plus) - f(p_minus)) / (2 * epsilon)

def compute_gradient(f, point, epsilon=1e-5):
    """
    Calcule le vecteur gradient approche de la fonction f au point.
    """
    n = len(point)
    grad = [0.0] * n
    for i in range(n):
        grad[i] = partial_derivative(f, point, i, epsilon)
    return grad

# --- TEST ET VALIDATION MATHÉMATIQUE ---
# Soit f(x, y) = x^2 + 3xy
def f_test(p):
    x, y = p[0], p[1]
    return x**2 + 3 * x * y

# Le gradient analytique est (2x + 3y, 3x)
# Au point (1, 2), le gradient théorique est (2(1)+3(2), 3(1)) = (8, 3)

point = [1.0, 2.0]
grad_num = compute_gradient(f_test, point)

# Verifications par assertions
assert abs(grad_num[0] - 8.0) < 1e-4, "Erreur sur df/dx"
assert abs(grad_num[1] - 3.0) < 1e-4, "Erreur sur df/dy"
print("TP 1 valide : Calcul approché du gradient correct.")

```
