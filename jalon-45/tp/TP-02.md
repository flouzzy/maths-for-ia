# TP 2 : Vérification expérimentale de la différentiabilité

Ce TP propose de coder rigoureusement en Python pur les concepts d'analyse multivariée abordés.
Aucun framework de haut niveau (numpy, pytorch, etc.) n'est autorisé pour l'implémentation du noyau de calcul afin de garantir une compréhension profonde des algorithmes.

## 1. Objectif Théorique
Évaluer numériquement la limite du reste d'ordre 1 pour vérifier si l'approximation affine est valide, c'est-à-dire si le quotient ||R(h)|| / ||h|| tend vers 0.

## 2. Implémentation Python Pur

```python
import math

def euclidean_norm(v):
    return math.sqrt(sum(x*x for x in v))

def check_differentiability(f, grad_f, a, h):
    """
    Calcule le ratio |f(a+h) - (f(a) + <grad f(a), h>)| / ||h||.
    Si f est differentiable en a, ce ratio doit tendre vers 0 quand ||h|| tend vers 0.
    """
    # f(a+h)
    a_plus_h = [a[i] + h[i] for i in range(len(a))]
    val_approx = f(a_plus_h)

    # f(a)
    val_exact = f(a)

    # <grad f(a), h>
    grad = grad_f(a)
    dot_product = sum(grad[i] * h[i] for i in range(len(a)))

    # Approximation lineaire : L_a(a+h) = f(a) + df_a(h)
    linear_approx = val_exact + dot_product

    # Reste R(h)
    remainder = abs(val_approx - linear_approx)

    norm_h = euclidean_norm(h)
    if norm_h == 0:
        return 0.0

    return remainder / norm_h

# --- TEST ET VALIDATION MATHÉMATIQUE ---
def f_test(p):
    return p[0]**2 + p[1]**2

def grad_f_test(p):
    return [2*p[0], 2*p[1]]

point = [1.0, 1.0]

# On reduit progressivement la norme de h
h_large = [0.1, 0.1]
h_small = [0.001, 0.001]

ratio_large = check_differentiability(f_test, grad_f_test, point, h_large)
ratio_small = check_differentiability(f_test, grad_f_test, point, h_small)

assert ratio_small < ratio_large, "Le ratio ne decroit pas."
assert ratio_small < 1e-2, "L'approximation lineaire ne converge pas vers f."
print("TP 2 valide : Le comportement asymptotique du reste est confirme.")

```
