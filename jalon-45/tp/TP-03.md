# TP 3 : Algorithme de Descente de Gradient basique

Ce TP propose de coder rigoureusement en Python pur les concepts d'analyse multivariée abordés.
Aucun framework de haut niveau (numpy, pytorch, etc.) n'est autorisé pour l'implémentation du noyau de calcul afin de garantir une compréhension profonde des algorithmes.

## 1. Objectif Théorique
Programmer l'algorithme d'optimisation fondamental qui suit la direction opposée au gradient pour trouver le minimum d'une fonction convexe.

## 2. Implémentation Python Pur

```python
import math

def euclidean_distance(p1, p2):
    return math.sqrt(sum((x - y)**2 for x, y in zip(p1, p2)))

def gradient_descent(grad_f, start_point, learning_rate=0.1, max_iter=1000, tol=1e-6):
    """
    Trouve le minimum local d'une fonction en suivant l'oppose de son gradient.
    """
    current_point = list(start_point)
    n = len(current_point)

    for iteration in range(max_iter):
        grad = grad_f(current_point)

        # Mise a jour : p_{t+1} = p_t - eta * grad(p_t)
        next_point = [current_point[i] - learning_rate * grad[i] for i in range(n)]

        # Condition d'arret : si le deplacement est tres petit
        if euclidean_distance(current_point, next_point) < tol:
            current_point = next_point
            break

        current_point = next_point

    return current_point

# --- TEST ET VALIDATION MATHÉMATIQUE ---
# Paraboloide elliptique : f(x, y) = 2x^2 + y^2
# Le minimum theorique est evidemment en (0, 0)
def grad_f(p):
    return [4 * p[0], 2 * p[1]]

start = [5.0, -3.0]
minimum = gradient_descent(grad_f, start, learning_rate=0.1)

assert abs(minimum[0] - 0.0) < 1e-4, "Le minimum sur x est incorrect"
assert abs(minimum[1] - 0.0) < 1e-4, "Le minimum sur y est incorrect"
print("TP 3 valide : La descente de gradient converge vers le minimum analytique.")

```
