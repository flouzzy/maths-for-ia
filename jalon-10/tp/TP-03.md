# TP-03: Changements de Base et Matrices de Passage

## Introduction

Ce TP explore les concepts fondamentaux de changements de base et de matrices de passage en algèbre linéaire, des outils essentiels en mathématiques pour l'Intelligence Artificielle. Comprendre comment représenter un même vecteur dans différentes bases et comment passer d'une représentation à l'autre est crucial pour des domaines comme la vision par ordinateur, le traitement du langage naturel (avec les embeddings) et l'analyse de données (avec la PCA, par exemple, qui est une rotation de base).

L'objectif de ce TP est d'implémenter "from scratch" les opérations matricielles nécessaires, y compris l'inversion de matrice par élimination de Gauss-Jordan, pour ensuite calculer et utiliser les matrices de passage.

## Objectifs d'apprentissage

À la fin de ce TP, vous devriez être capable de :
1.  Implémenter les opérations matricielles de base (multiplication, transposition, création de matrice identité) sans utiliser de bibliothèques externes comme NumPy.
2.  Implémenter l'algorithme d'inversion de matrice par élimination de Gauss-Jordan.
3.  Calculer la matrice de passage entre deux bases données.
4.  Transformer les coordonnées d'un vecteur d'une base à une autre en utilisant la matrice de passage appropriée.
5.  Valider mathématiquement vos résultats à l'aide d'assertions.

## Prérequis

*   Connaissances de base en algèbre linéaire : vecteurs, matrices, bases, espace vectoriel, indépendance linéaire, matrice identité, matrice inverse.
*   Maîtrise du langage Python (structures de données, boucles, fonctions).

### Exercice 1.2: Inversion de Matrice par Élimination de Gauss-Jordan

Implémentez la fonction `inverse(matrix)` qui calcule l'inverse d'une matrice carrée en utilisant l'algorithme d'élimination de Gauss-Jordan.

**Rappel de l'algorithme :**
Pour inverser une matrice `A` de taille `n x n` :
1.  Créez une matrice augmentée `[A | I]`, où `I` est la matrice identité de taille `n x n`.
2.  Appliquez des opérations élémentaires sur les lignes de la matrice augmentée pour transformer la partie `A` en `I`. Les mêmes opérations sont appliquées à `I`, qui se transforme alors en `A_inv`.
3.  Les opérations sont :
    *   Échanger deux lignes.
    *   Multiplier une ligne par un scalaire non nul.
    *   Ajouter un multiple d'une ligne à une autre ligne.
4.  Gérez les cas où la matrice est singulière (non inversible).

```python
# --- Début du code à implémenter pour la Partie 1 ---

def create_identity_matrix(n):
    """
    Crée une matrice identité de taille n x n.
    """
    if not isinstance(n, int) or n <= 0:
        raise ValueError("n doit être un entier positif.")

    identity = []
    for i in range(n):
        row = [0.0] * n
        row[i] = 1.0
        identity.append(row)
    return identity

def matrix_mult(A, B):
    """
    Multiplie deux matrices A et B.
    """
    rows_A = len(A)
    cols_A = len(A[0])
    rows_B = len(B)
    cols_B = len(B[0])

    if cols_A != rows_B:
        raise ValueError("Les dimensions des matrices ne sont pas compatibles pour la multiplication.")

    result = [[0.0 for _ in range(cols_B)] for _ in range(rows_A)]

    for i in range(rows_A):
        for j in range(cols_B):
            for k in range(cols_A):
                result[i][j] += A[i][k] * B[k][j]
    return result

def matrix_vector_mult(M, v):
    """
    Multiplie une matrice M par un vecteur colonne v.
    """
    rows_M = len(M)
    cols_M = len(M[0])
    len_v = len(v)

    if cols_M != len_v:
        raise ValueError("Les dimensions de la matrice et du vecteur ne sont pas compatibles.")

    result = [0.0] * rows_M
    for i in range(rows_M):
        for j in range(cols_M):
            result[i] += M[i][j] * v[j]
    return result

def transpose(M):
    """
    Calcule la transposée d'une matrice M.
    """
    rows = len(M)
    cols = len(M[0])

    transposed = [[0.0 for _ in range(rows)] for _ in range(cols)]
    for i in range(rows):
        for j in range(cols):
            transposed[j][i] = M[i][j]
    return transposed

def is_close(a, b, tol=1e-9):
    """
    Vérifie si deux nombres flottants sont "proches".
    """
    return abs(a - b) < tol

def matrices_are_close(A, B, tol=1e-9):
    """
    Vérifie si deux matrices sont "proches" élément par élément.
    """
    if not A or not B: return False
    if len(A) != len(B) or len(A[0]) != len(B[0]): return False
    for i in range(len(A)):
        for j in range(len(A[0])):
            if not is_close(A[i][j], B[i][j], tol):
                return False
    return True

def vectors_are_close(v1, v2, tol=1e-9):
    """
    Vérifie si deux vecteurs sont "proches" élément par élément.
    """
    if len(v1) != len(v2): return False
    for i in range(len(v1)):
        if not is_close(v1[i], v2[i], tol):
            return False
    return True

def inverse(matrix):
    """
    Calcule l'inverse d'une matrice carrée en utilisant l'élimination de Gauss-Jordan.
    """
    n = len(matrix)
    if n == 0 or len(matrix[0]) != n:
        raise ValueError("La matrice doit être carrée et non vide.")

    # Créer la matrice augmentée [A | I]
    augmented_matrix = [row[:] + [1.0 if i == j else 0.0 for j in range(n)] for i, row in enumerate(matrix)]

    # Élimination avant (pour former une matrice triangulaire supérieure)
    for i in range(n):
        # Trouver la ligne pivot (pour éviter les zéros sur la diagonale et améliorer la stabilité numérique)
        pivot_row = i
        for k in range(i + 1, n):
            if abs(augmented_matrix[k][i]) > abs(augmented_matrix[pivot_row][i]):
                pivot_row = k
        augmented_matrix[i], augmented_matrix[pivot_row] = augmented_matrix[pivot_row], augmented_matrix[i]

        pivot = augmented_matrix[i][i]
        if is_close(pivot, 0):
            raise ValueError("La matrice est singulière (non inversible).")

        # Normaliser la ligne pivot pour que l'élément diagonal soit 1
        for j in range(2 * n):
            augmented_matrix[i][j] /= pivot

        # Éliminer les éléments sous le pivot
        for k in range(n):
            if k != i: # Pour toutes les autres lignes
                factor = augmented_matrix[k][i]
                for j in range(2 * n):
                    augmented_matrix[k][j] -= factor * augmented_matrix[i][j]

    # Extraire la matrice inverse
    inverse_matrix = [row[n:] for row in augmented_matrix]
    return inverse_matrix

# --- Fin du code à implémenter pour la Partie 1 ---
```

## Partie 2: Changement de Base et Matrices de Passage

Considérons l'espace vectoriel $\mathbb{R}^2$.
Nous avons deux bases :

*   **Base B** : $B = \{b_1, b_2\}$ où $b_1 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$ et $b_2 = \begin{pmatrix} 1 \\ -1 \end{pmatrix}$.
*   **Base C** : $C = \{c_1, c_2\}$ où $c_1 = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$ et $c_2 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$.

Nous pouvons représenter ces bases comme des matrices où les colonnes sont les vecteurs de base (par rapport à la base canonique $E = \{e_1, e_2\}$ où $e_1 = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$ et $e_2 = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$).

$M_B = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$ et $M_C = \begin{pmatrix} 2 & 1 \\ 1 & 1 \end{pmatrix}$

### Exercice 2.1: Calcul des Matrices de Passage

1.  Calculez la matrice de passage de la base C vers la base B, notée $P_{C \to B}$.
    *   Rappel : $P_{C \to B}$ est la matrice telle que si $[v]_C$ sont les coordonnées d'un vecteur $v$ dans la base C, alors $[v]_B = P_{C \to B} [v]_C$.
    *   Mathématiquement, $M_B \cdot P_{C \to B} = M_C$, donc $P_{C \to B} = M_B^{-1} \cdot M_C$.
2.  Calculez la matrice de passage de la base B vers la base C, notée $P_{B \to C}$.
    *   Rappel : $P_{B \to C}$ est la matrice telle que si $[v]_B$ sont les coordonnées d'un vecteur $v$ dans la base B, alors $[v]_C = P_{B \to C} [v]_B$.
    *   Mathématiquement, $M_C \cdot P_{B \to C} = M_B$, donc $P_{B \to C} = M_C^{-1} \cdot M_B$.
3.  Vérifiez que $P_{B \to C}$ est bien l'inverse de $P_{C \to B}$ (c'est-à-dire $P_{B \to C} \cdot P_{C \to B} = I$).

```python
# --- Début du code à implémenter pour la Partie 2 ---

# Définition des bases comme matrices (colonnes sont les vecteurs de base)
M_B = [[1.0, 1.0], [1.0, -1.0]]
M_C = [[2.0, 1.0], [1.0, 1.0]]

# 1. Calcul de l'inverse de M_B et M_C
M_B_inv = inverse(M_B)
M_C_inv = inverse(M_C)

# 2. Calcul de P_C_to_B (de C vers B)
# P_C_to_B = M_B_inv @ M_C
P_C_to_B = matrix_mult(M_B_inv, M_C)

# 3. Calcul de P_B_to_C (de B vers C)
# P_B_to_C = M_C_inv @ M_B
P_B_to_C = matrix_mult(M_C_inv, M_B)

```
