# TP 02 - Changements de Base et Matrices de Passage

## Introduction

Dans le domaine de l'Intelligence Artificielle, la capacité à représenter des données ou des concepts dans différentes bases est fondamentale. Que ce soit pour la réduction de dimensionnalité (comme l'Analyse en Composantes Principales - PCA), la transformation de caractéristiques, ou simplement pour mieux comprendre la géométrie des espaces vectoriels, les changements de base et les matrices de passage sont des outils mathématiques essentiels.

Ce TP a pour objectif de vous faire implémenter "from scratch", c'est-à-dire sans l'aide de bibliothèques de calcul numérique de haut niveau comme NumPy ou SciPy, les concepts clés liés aux changements de base. Vous développerez les fonctions nécessaires pour manipuler des matrices, calculer des inverses et effectuer des changements de coordonnées, en vous appuyant uniquement sur les structures de données natives de Python (listes de listes).

## Rappels Théoriques

### 1. Base d'un Espace Vectoriel

Une base $\mathcal{B} = (e_1, e_2, \dots, e_n)$ d'un espace vectoriel $V$ de dimension $n$ est un ensemble de $n$ vecteurs linéairement indépendants qui engendrent $V$. Tout vecteur $v \in V$ peut être exprimé de manière unique comme une combinaison linéaire des vecteurs de la base :
$v = x_1 e_1 + x_2 e_2 + \dots + x_n e_n$.
Les scalaires $(x_1, x_2, \dots, x_n)$ sont les coordonnées du vecteur $v$ dans la base $\mathcal{B}$, notées $v_{\mathcal{B}}$.

La base canonique (ou standard) de $\mathbb{R}^n$, notée $\mathcal{E}$, est constituée des vecteurs $e_i$ dont toutes les composantes sont nulles sauf la $i$-ème qui vaut 1. Par exemple, pour $\mathbb{R}^2$, $\mathcal{E} = ((1,0), (0,1))$.

### 2. Matrice de Passage (ou de Changement de Base)

Soient deux bases $\mathcal{B} = (b_1, \dots, b_n)$ et $\mathcal{B}' = (b'_1, \dots, b'_n)$ d'un même espace vectoriel $V$.

La **matrice de passage de $\mathcal{B}$ à $\mathcal{B}'$**, notée $P_{\mathcal{B} \to \mathcal{B}'}$ (ou parfois $P_{\mathcal{B}',\mathcal{B}}$), est la matrice dont les colonnes sont les vecteurs de la *nouvelle base* $\mathcal{B}'$ exprimés dans l'*ancienne base* $\mathcal{B}$.

Si $v_{\mathcal{B}}$ sont les coordonnées d'un vecteur $v$ dans la base $\mathcal{B}$ et $v_{\mathcal{B}'}$ ses coordonnées dans la base $\mathcal{B}'$, alors la relation entre ces coordonnées est donnée par :
$$v_{\mathcal{B}} = P_{\mathcal{B} \to \mathcal{B}'} \cdot v_{\mathcal{B}'}$$

**Propriétés importantes :**
*   La matrice de passage de $\mathcal{B}'$ à $\mathcal{B}$ est l'inverse de la matrice de passage de $\mathcal{B}$ à $\mathcal{B}'$ :
    $P_{\mathcal{B}' \to \mathcal{B}} = (P_{\mathcal{B} \to \mathcal{B}'})^{-1}$.
*   Si $\mathcal{E}$ est la base canonique, et que les vecteurs de $\mathcal{B}$ sont donnés directement par leurs coordonnées dans $\mathcal{E}$, alors la matrice dont les colonnes sont les vecteurs de $\mathcal{B}$ est $P_{\mathcal{E} \to \mathcal{B}}$.
*   Pour passer d'une base $\mathcal{B}$ à une base $\mathcal{B}'$ (toutes deux différentes de la base canonique $\mathcal{E}$), on utilise la formule :
    $P_{\mathcal{B} \to \mathcal{B}'} = P_{\mathcal{B} \to \mathcal{E}} \cdot P_{\mathcal{E} \to \mathcal{B}'} = (P_{\mathcal{E} \to \mathcal{B}})^{-1} \cdot P_{\mathcal{E} \to \mathcal{B}'}$.

### Structure de Données

Nous représenterons les matrices comme des listes de listes (liste de lignes). Par exemple, la matrice
$\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$ sera représentée par `[[1, 2], [3, 4]]`.
Les vecteurs seront représentés comme des matrices à une colonne (ex: `[[x], [y]]`).

### Exercice 1 : Opérations Matricielle de Base

Implémentez les fonctions suivantes pour manipuler des matrices.

1.  `create_matrix(rows, cols, value=0.0)`: Crée une matrice de `rows` lignes et `cols` colonnes, initialisée avec `value`.
2.  `get_dimensions(matrix)`: Retourne un tuple `(rows, cols)` des dimensions de la matrice.
3.  `matrix_multiply(A, B)`: Multiplie deux matrices `A` et `B`.
    *   **Validation :** Vérifiez que le nombre de colonnes de `A` est égal au nombre de lignes de `B`.
4.  `identity_matrix(n)`: Crée une matrice identité de taille `n x n`.
5.  `scalar_multiply(matrix, scalar)`: Multiplie chaque élément d'une matrice par un scalaire.
6.  `matrix_subtraction(A, B)`: Soustrait la matrice `B` de la matrice `A`.
    *   **Validation :** Vérifiez que les matrices ont les mêmes dimensions.
7.  `transpose_matrix(matrix)`: Transpose une matrice.
8.  `is_approximately_zero_matrix(matrix, epsilon=1e-9)`: Vérifie si tous les éléments d'une matrice sont proches de zéro. Utile pour les assertions avec des flottants.

```python
def create_matrix(rows, cols, value=0.0):
    """Crée une matrice de dimensions (rows, cols) initialisée avec value."""
    return [[value for _ in range(cols)] for _ in range(rows)]

def get_dimensions(matrix):
    """Retourne les dimensions (rows, cols) d'une matrice."""
    rows = len(matrix)
    cols = len(matrix[0]) if rows > 0 else 0
    return (rows, cols)

def matrix_multiply(A, B):
    """Multiplie deux matrices A et B."""
    rows_A, cols_A = get_dimensions(A)
    rows_B, cols_B = get_dimensions(B)

    assert cols_A == rows_B, "Le nombre de colonnes de A doit être égal au nombre de lignes de B pour la multiplication."

    C = create_matrix(rows_A, cols_B)

    for i in range(rows_A):
        for j in range(cols_B):
            for k in range(cols_A): # ou rows_B
                C[i][j] += A[i][k] * B[k][j]
    return C

def identity_matrix(n):
    """Crée une matrice identité de taille n x n."""
    I = create_matrix(n, n)
    for i in range(n):
        I[i][i] = 1.0
    return I

def scalar_multiply(matrix, scalar):
    """Multiplie chaque élément d'une matrice par un scalaire."""
    rows, cols = get_dimensions(matrix)
    result = create_matrix(rows, cols)
    for i in range(rows):
        for j in range(cols):
            result[i][j] = matrix[i][j] * scalar
    return result

def matrix_subtraction(A, B):
    """Soustrait la matrice B de la matrice A."""
    rows_A, cols_A = get_dimensions(A)
    rows_B, cols_B = get_dimensions(B)

    assert rows_A == rows_B and cols_A == cols_B, "Les matrices doivent avoir les mêmes dimensions pour la soustraction."

    C = create_matrix(rows_A, cols_A)
    for i in range(rows_A):
        for j in range(cols_A):
            C[i][j] = A[i][j] - B[i][j]
    return C

def transpose_matrix(matrix):
    """Transpose une matrice."""
    rows, cols = get_dimensions(matrix)
    transposed = create_matrix(cols, rows)
    for i in range(rows):
        for j in range(cols):
            transposed[j][i] = matrix[i][j]
    return transposed

def is_approximately_zero_matrix(matrix, epsilon=1e-9):
    """Vérifie si tous les éléments d'une matrice sont proches de zéro."""
    for row in matrix:
        for val in row:
            if abs(val) > epsilon:
                return False
    return True

# --- Assertions pour l'Exercice 1 ---
print("--- Assertions Exercice 1 ---")
A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
I2 = identity_matrix(2)

# Test matrix_multiply
C = matrix_multiply(A, B)
expected_C = [[19, 22], [43, 50]]
assert C == expected_C, f"Erreur multiplication: {C} != {expected_C}"

# Test identity_matrix
assert I2 == [[1.0, 0.0], [0.0, 1.0]], "Erreur matrice identité"

# Test scalar_multiply
scaled_A = scalar_multiply(A, 2)
expected_scaled_A = [[2, 4], [6, 8]]
assert scaled_A == expected_scaled_A, "Erreur multiplication scalaire"

# Test matrix_subtraction
sub_result = matrix_subtraction(A, A)
assert is_approximately_zero_matrix(sub_result), "Erreur soustraction de matrices"

# Test transpose_matrix
transposed_A = transpose_matrix(A)
expected_transposed_A = [[1, 3], [2, 4]]
assert transposed_A == expected_transposed_A, f"Erreur transposition: {transposed_A} != {expected_transposed_A}"

print("Toutes les assertions de l'Exercice 1 ont réussi !")
```

### Exercice 2 : Implémentation de l'Inverse d'une Matrice (Méthode de Gauss-Jordan)

L'inversion de matrice est une opération cruciale. Vous allez implémenter la méthode de Gauss-Jordan pour trouver l'inverse d'une matrice carrée.

**Principe de Gauss-Jordan :**
Pour inverser une matrice $A$, on construit une matrice augmentée $[A | I]$, où $I$ est la matrice identité de même taille que $A$. On applique ensuite des opérations élémentaires sur les lignes de cette matrice augmentée jusqu'à ce que la partie gauche devienne la matrice identité. La partie droite sera alors l'inverse de $A$, soit $[I | A^{-1}]$.

Les opérations élémentaires sur les lignes sont :
1.  Échanger deux lignes.
2.  Multiplier une ligne par un scalaire non nul.
3.  Ajouter à une ligne un multiple d'une autre ligne.

Implémentez la fonction `inverse_matrix(matrix)`.

```python
def inverse_matrix(matrix):
    """
    Calcule l'inverse d'une matrice carrée en utilisant la méthode de Gauss-Jordan.
    La matrice doit être carrée et inversible.
    """
    rows, cols = get_dimensions(matrix)
    assert rows == cols, "La matrice doit être carrée pour être inversible."
    n = rows

    # Créer la matrice augmentée [A | I]
    # Utiliser une copie profonde pour éviter les modifications inattendues de la matrice originale
    augmented_matrix = [row[:] + identity_matrix(n)[i] for i, row in enumerate(matrix)]

    for i in range(n):
        # 1. Trouver le pivot (élément non nul le plus grand en valeur absolue dans la colonne i, à partir de la ligne i)
        pivot_row = i
        for k in range(i + 1, n):
            if abs(augmented_matrix[k][i]) > abs(augmented_matrix[pivot_row][i]):
                pivot_row = k

        # Échanger la ligne actuelle (i) avec la ligne du pivot
        augmented_matrix[i], augmented_matrix[pivot_row] = augmented_matrix[pivot_row], augmented_matrix[i]

        pivot = augmented_matrix[i][i]
        assert abs(pivot) > 1e-9, "La matrice est singulière (non inversible)." # Utiliser epsilon pour les flottants

        # 2. Normaliser la ligne du pivot : diviser la ligne i par le pivot
        for j in range(2 * n):
            augmented_matrix[i][j] /= pivot

        # 3. Éliminer les autres éléments de la colonne i
        for k in range(n):
            if k != i:
                factor = augmented_matrix[k][i]
                for j in range(2 * n):
                    augmented_matrix[k][j] -= factor * augmented_matrix[i][j]

    # Extraire la matrice inverse de la partie droite de la matrice augmentée
    inverse = [row[n:] for row in augmented_matrix]
    return inverse

# --- Assertions pour l'Exercice 2 ---
print("\n--- Assertions Exercice 2 ---")
A_inv_test = [[2, 1], [3, 2]]
A_inv_expected = [[2.0, -1.0], [-3.0, 2.0]]
A_inv = inverse_matrix(A_inv_test)
for i in range(len(A_inv)):
    for j in range(len(A_inv[0])):
        assert abs(A_inv[i][j] - A_inv_expected[i][j]) < 1e-9, f"Erreur inverse 2x2: {A_inv} != {A_inv_expected}"

# Vérification avec la multiplication
product = matrix_multiply(A_inv_test, A_inv)
I_expected = identity_matrix(2)
diff_matrix = matrix_subtraction(product, I_expected)
assert is_approximately_zero_matrix(diff_matrix), "A * A_inv n'est pas la matrice identité."

# Test avec une matrice 3x3
M = [[1, 2, 3],
     [0, 1, 4],
     [5, 6, 0]]
M_inv = inverse_matrix(M)
product_M = matrix_multiply(M, M_inv)
I3_expected = identity_matrix(3)
diff_matrix_M = matrix_subtraction(product_M, I3_expected)
assert is_approximately_zero_matrix(diff_matrix_M), "M * M_inv n'est pas la matrice identité pour 3x3."

print("Toutes les assertions de l'Exercice 2 ont réussi !")
```

### Exercice 3 : Calcul des Matrices de Passage

Considérons l'espace vectoriel $\mathbb{R}^2$.
*   La base canonique est $\mathcal{E} = (e_1, e_2)$ où $e_1 = (1,0)$ et $e_2 = (0,1)$.
*   Une première base $\mathcal{B}$ est donnée par les vecteurs $b_1 = (1,1)$ et $b_2 = (-1,1)$.
*   Une deuxième base $\mathcal{B}'$ est donnée par les vecteurs $b'_1 = (2,1)$ et $b'_2 = (1,2)$.

Implémentez les calculs des matrices de passage suivantes :

1.  **$P_{\mathcal{E} \to \mathcal{B}}$** : Matrice de passage de la base canonique $\mathcal{E}$ à la base $\mathcal{B}$.
    *   Les colonnes de cette matrice sont les vecteurs de $\mathcal{B}$ exprimés dans $\mathcal{E}$.
2.  **$P_{\mathcal{B} \to \mathcal{E}}$** : Matrice de passage de la base $\mathcal{B}$ à la base canonique $\mathcal{E}$.
    *   C'est l'inverse de $P_{\mathcal{E} \to \mathcal{B}}$.
3.  **$P_{\mathcal{E} \to \mathcal{B}'}$** : Matrice de passage de la base canonique $\mathcal{E}$ à la base $\mathcal{B}'$.
4.  **$P_{\mathcal{B}' \to \mathcal{E}}$** : Matrice de passage de la base $\mathcal{B}'$ à la base canonique $\mathcal{E}$.
    *   C'est l'inverse de $P_{\mathcal{E} \to \mathcal{B}'}$.
5.  **$P_{\mathcal{B} \to \mathcal{B}'}$** : Matrice de passage de la base $\mathcal{B}$ à la base $\mathcal{B}'$.
    *   Utilisez la formule $P_{\mathcal{B} \to \mathcal{B}'} = P_{\mathcal{B} \to \mathcal{E}} \cdot P_{\mathcal{E} \to \mathcal{B}'}$.
6.  **$P_{\mathcal{B}' \to \mathcal{B}}$** : Matrice de passage de la base $\mathcal{B}'$ à la base $\mathcal{B}$.
    *   C'est l'inverse de $P_{\mathcal{B} \to \mathcal{B}'}$.

```python
# Définition des bases
# Les vecteurs sont donnés dans la base canonique sous forme de lignes.
B_vectors_rows = [[1, 1], [-1, 1]] # b1 = (1,1), b2 = (-1,1)
B_prime_vectors_rows = [[2, 1], [1, 2]] # b'1 = (2,1), b'2 = (1,2)

print("\n--- Exercice 3 : Calcul des Matrices de Passage ---")

# 1. P_E_to_B
# Les colonnes de P_E_to_B sont les vecteurs de B exprimés dans E.
# Si B_vectors_rows = [[b1x, b1y], [b2x, b2y]], alors P_E_to_B = [[b1x, b2x], [b1y, b2y]]
P_E_to_B = transpose_matrix(B_vectors_rows)
print(f"P_E_to_B (de E vers B):\n{P_E_to_B}")

# 2. P_B_to_E = (P_E_to_B)^-1
P_B_to_E = inverse_matrix(P_E_to_B)
print(f"P_B_to_E (de B vers E):\n{P_B_to_E}")

# 3. P_E_to_B_prime
P_E_to_B_prime = transpose_matrix(B_prime_vectors_rows)
print(f"P_E_to_B_prime (de E vers B'):\n{P_E_to_B_prime}")

# 4. P_B_prime_to_E = (P_E_to_B_prime)^-1
P_B_prime_to_E = inverse_matrix(P_E_to_B_prime)
print(f"P_B_prime_to_E (de B' vers E):\n{P_B_prime_to_E}")

# 5. P_B_to_B_prime = P_B_to_E * P_E_to_B_prime
P_B_to_B_prime = matrix_multiply(P_B_to_E, P_E_to_B_prime)
print(f"P_B_to_B_prime (de B vers B'):\n{P_B_to_B_prime}")

# 6. P_B_prime_to_B = (P_B_to_B_prime)^-1
P_B_prime_to_B = inverse_matrix(P_B_to_B_prime)
print(f"P_B_prime_to_B (de B' vers B):\n{P_B_prime_to_B}")

# --- Assertions pour l'Exercice 3 ---
print("\n--- Assertions Exercice 3 ---")

# P_E_to_B * P_B_to_E doit être l'identité
prod_EB_BE = matrix_multiply(P_E_to_B, P_B_to_E)
assert is_approximately_zero_matrix(matrix_subtraction(prod_EB_BE, identity_matrix(2))), \
    "P_E_to_B * P_B_to_E n'est pas l'identité."

# P_E_to_B_prime * P_B_prime_to_E doit être l'identité
prod_EBp_BpE = matrix_multiply(P_E_to_B_prime, P_B_prime_to_E)
assert is_approximately_zero_matrix(matrix_subtraction(prod_EBp_BpE, identity_matrix(2))), \
    "P_E_to_B_prime * P_B_prime_to_E n'est pas l'identité."

# P_B_to_B_prime * P_B_prime_to_B doit être l'identité
prod_BBp_BpB = matrix_multiply(P_B_to_B_prime, P_B_prime_to_B)
assert is_approximately_zero_matrix(matrix_subtraction(prod_BBp_BpB, identity_matrix(2))), \
    "P_B_to_B_prime * P_B_prime_to_B n'est pas l'identité."

print("Toutes les assertions de l'Exercice 3 ont réussi !")
```

### Exercice 4 : Changement de Coordonnées d'un Vecteur

Soit un vecteur $v$ dont les coordonnées dans la base $\mathcal{B}$ sont $v_{\mathcal{B}} = (2, 1)$.
C'est-à-dire $v = 2 \cdot b_1 + 1 \cdot b_2$.

Calculez les coordonnées de ce vecteur dans la base $\mathcal{B}'$, notées $v_{\mathcal{B}'}$.
Utilisez la formule : $v_{\mathcal{B}'} = P_{\mathcal{B}' \to \mathcal{B}} \cdot v_{\mathcal{B}}$.

```python
# Coordonnées du vecteur v dans la base B
v_B = [[2], [1]] # Représentation en colonne

print("\n--- Exercice 4 : Changement de Coordonnées ---")

# Calcul de v_B_prime
# v_B_prime = P_B_prime_to_B * v_B
v_B_prime = matrix_multiply(P_B_prime_to_B, v_B)
print(f"Coordonnées de v dans la base B' (v_B_prime):\n{v_B_prime}")

# --- Assertions pour l'Exercice 4 ---
print("\n--- Assertions Exercice 4 ---")

# Vérification : Convertir v_B en v_E, puis v_B_prime en v_E. Les résultats doivent être égaux.
# v_E_from_B = P_E_to_B * v_B
v_E_from_B = matrix_multiply(P_E_to_B, v_B)
print(f"Coordonnées de v dans la base canonique (calculé depuis B):\n{v_E_from_B}")

# v_E_from_B_prime = P_E_to_B_prime * v_B_prime
v_E_from_B_prime = matrix_multiply(P_E_to_B_prime, v_B_prime)
print(f"Coordonnées de v dans la base canonique (calculé depuis B'):\n{v_E_from_B_prime}")

# Les deux représentations dans la base canonique doivent être (approximativement) égales
diff_v_E = matrix_subtraction(v_E_from_B, v_E_from_B_prime)
assert is_approximately_zero_matrix(diff_v_E), \
    "Les coordonnées du vecteur dans la base canonique ne correspondent pas après changement de base."

print("Toutes les assertions de l'Exercice 4 ont réussi !")
```
