# TP-04: Changements de Base et Matrices de Passage

## Introduction

En algèbre linéaire, la notion de base est fondamentale pour représenter des vecteurs dans un espace vectoriel. Cependant, un même vecteur peut avoir des coordonnées différentes selon la base choisie. Les **matrices de passage** (ou matrices de transition) sont des outils cruciaux qui permettent de convertir les coordonnées d'un vecteur d'une base à une autre. Cette capacité à changer de perspective est essentielle dans de nombreux domaines de l'Intelligence Artificielle, notamment pour la transformation de caractéristiques, l'analyse en composantes principales (PCA), ou la manipulation de données dans différents systèmes de coordonnées.

Ce TP vous mettra au défi d'implémenter "from scratch" les opérations matricielles nécessaires pour comprendre et réaliser des changements de base. Vous développerez des fonctions pour la multiplication matricielle, le calcul de déterminants, et surtout, l'inversion de matrices via l'élimination de Gauss-Jordan, avant de construire les matrices de passage et de valider vos résultats.

## Objectifs du TP

À la fin de ce TP, vous devriez être capable de :
1.  Implémenter les opérations matricielles fondamentales (multiplication, addition, inversion) sans utiliser de bibliothèques externes comme NumPy.

3.  Utiliser une matrice de passage pour transformer les coordonnées d'un vecteur d'une base à une autre.
4.  Valider mathématiquement vos implémentations à l'aide d'assertions.
5.  Appréhender l'importance des changements de base en IA.

## Partie 1: Implémentation des Opérations Matricielles de Base (From Scratch)

Pour ce TP, toutes les opérations matricielles devront être codées manuellement. Nous représenterons une matrice comme une liste de listes (liste de lignes).

### 1.1. Fonctions Utilitaires

Implémentez les fonctions suivantes :

*   `create_matrix(rows, cols, value=0.0)`: Crée une matrice `rows` x `cols` remplie de `value`.
*   `get_dimensions(matrix)`: Retourne un tuple `(rows, cols)` des dimensions de la matrice.
*   `is_square(matrix)`: Retourne `True` si la matrice est carrée, `False` sinon.
*   `create_identity_matrix(n)`: Crée une matrice identité de taille `n x n`.
*   `matrix_addition(A, B)`: Calcule `A + B`. Lève une erreur si les dimensions ne correspondent pas.
*   `scalar_multiplication(scalar, A)`: Calcule `scalar * A`.
*   `matrix_multiplication(A, B)`: Calcule le produit matriciel `A * B`. Lève une erreur si les dimensions ne sont pas compatibles.
*   `transpose(A)`: Calcule la transposée de `A`.
*   `get_submatrix(matrix, row_to_remove, col_to_remove)`: Retourne la sous-matrice obtenue en supprimant une ligne et une colonne. (Utile pour le déterminant par cofacteurs, mais nous utiliserons Gauss pour l'inverse).

### 1.2. Déterminant et Inversion de Matrice (Élimination de Gauss-Jordan)

L'inversion de matrice est l'étape la plus complexe à implémenter "from scratch". Nous utiliserons l'algorithme d'élimination de Gauss-Jordan.

*   `determinant(matrix)`: Calcule le déterminant d'une matrice carrée. Pour des raisons de simplicité et de robustesse avec Gauss-Jordan, vous pouvez calculer le déterminant en même temps que la forme échelonnée (produit des pivots), ou utiliser la méthode des cofacteurs pour des petites matrices (2x2, 3x3) et lever une erreur pour des matrices plus grandes si vous ne voulez pas l'intégrer à Gauss-Jordan. **Pour ce TP, l'implémentation du déterminant via la méthode des cofacteurs est suffisante pour des matrices 2x2 et 3x3. Pour l'inverse, Gauss-Jordan est obligatoire.**

    *   **Rappel Déterminant 2x2:** `det([[a,b],[c,d]]) = ad - bc`
    *   **Rappel Déterminant 3x3:** `det(A) = a(ei - fh) - b(di - fg) + c(dh - eg)`

*   `inverse(matrix)`: Calcule l'inverse d'une matrice carrée en utilisant l'algorithme d'élimination de Gauss-Jordan.
    *   **Étapes clés de Gauss-Jordan pour l'inverse:**
        1.  Construire une matrice augmentée `[A | I]`, où `I` est la matrice identité de même taille que `A`.
        2.  Appliquer des opérations élémentaires sur les lignes (échange de lignes, multiplication d'une ligne par un scalaire non nul, addition d'un multiple d'une ligne à une autre) pour transformer la partie `A` en matrice identité.
        3.  Les mêmes opérations appliquées à `I` transformeront `I` en `A_inv`.
        4.  Si la matrice est singulière (déterminant nul, ou une ligne de zéros apparaît dans la partie `A` pendant l'élimination), lever une erreur `ValueError("Matrice singulière, pas d'inverse.")`.

```python
# Exemple de structure pour vos fonctions
def create_matrix(rows, cols, value=0.0):
    return [[value for _ in range(cols)] for _ in range(rows)]

def get_dimensions(matrix):
    rows = len(matrix)
    cols = len(matrix[0]) if rows > 0 else 0
    return rows, cols

def is_square(matrix):
    rows, cols = get_dimensions(matrix)
    return rows == cols

def create_identity_matrix(n):
    I = create_matrix(n, n)
    for i in range(n):
        I[i][i] = 1.0
    return I

def matrix_addition(A, B):
    rows_A, cols_A = get_dimensions(A)
    rows_B, cols_B = get_dimensions(B)
    if rows_A != rows_B or cols_A != cols_B:
        raise ValueError("Les matrices doivent avoir les mêmes dimensions pour l'addition.")

    C = create_matrix(rows_A, cols_A)
    for i in range(rows_A):
        for j in range(cols_A):
            C[i][j] = A[i][j] + B[i][j]
    return C

def scalar_multiplication(scalar, A):
    rows, cols = get_dimensions(A)
    C = create_matrix(rows, cols)
    for i in range(rows):
        for j in range(cols):
            C[i][j] = scalar * A[i][j]
    return C

def matrix_multiplication(A, B):
    rows_A, cols_A = get_dimensions(A)
    rows_B, cols_B = get_dimensions(B)
    if cols_A != rows_B:
        raise ValueError("Le nombre de colonnes de A doit être égal au nombre de lignes de B pour la multiplication.")

    C = create_matrix(rows_A, cols_B)
    for i in range(rows_A):
        for j in range(cols_B):
            for k in range(cols_A):
                C[i][j] += A[i][k] * B[k][j]
    return C

def transpose(A):
    rows, cols = get_dimensions(A)
    T = create_matrix(cols, rows)
    for i in range(rows):
        for j in range(cols):
            T[j][i] = A[i][j]
    return T

def get_submatrix(matrix, row_to_remove, col_to_remove):
    return [
        [matrix[i][j] for j in range(len(matrix[i])) if j != col_to_remove]
        for i in range(len(matrix)) if i != row_to_remove
    ]

def determinant(matrix):
    if not is_square(matrix):
        raise ValueError("Le déterminant n'est défini que pour les matrices carrées.")

    n = get_dimensions(matrix)[0]
    if n == 1:
        return matrix[0][0]
    if n == 2:
        return matrix[0][0] * matrix[1][1] - matrix[0][1] * matrix[1][0]

    # Pour n > 2, utilisons la méthode des cofacteurs (peut être coûteuse pour de grandes matrices)
    det_val = 0
    for j in range(n):
        sub_matrix = get_submatrix(matrix, 0, j)
        cofactor = matrix[0][j] * determinant(sub_matrix)
        if j % 2 == 1: # Signe alterné
            det_val -= cofactor
        else:
            det_val += cofactor
    return det_val

def inverse(matrix):
    if not is_square(matrix):
        raise ValueError("L'inverse n'est défini que pour les matrices carrées.")

    n = get_dimensions(matrix)[0]
    if n == 0:
        raise ValueError("Matrice vide n'a pas d'inverse.")

    # Créer la matrice augmentée [A | I]
    augmented_matrix = [row[:] + create_identity_matrix(n)[i] for i, row in enumerate(matrix)]

    # Élimination de Gauss-Jordan
    for i in range(n):
        # Trouver le pivot (élément non nul le plus grand dans la colonne actuelle)
        pivot_row = i
        for k in range(i + 1, n):
            if abs(augmented_matrix[k][i]) > abs(augmented_matrix[pivot_row][i]):
                pivot_row = k

        # Échanger la ligne actuelle avec la ligne du pivot
        augmented_matrix[i], augmented_matrix[pivot_row] = augmented_matrix[pivot_row], augmented_matrix[i]

        pivot = augmented_matrix[i][i]
        if abs(pivot) < 1e-9: # Pratiquement zéro, matrice singulière
            raise ValueError("Matrice singulière, pas d'inverse.")

        # Normaliser la ligne du pivot (rendre le pivot égal à 1)
        for j in range(2 * n):
            augmented_matrix[i][j] /= pivot

        # Éliminer les autres éléments de la colonne
        for k in range(n):
            if k != i:
                factor = augmented_matrix[k][i]
                for j in range(2 * n):
                    augmented_matrix[k][j] -= factor * augmented_matrix[i][j]

    # Extraire la matrice inverse de la partie droite de la matrice augmentée
    inverse_matrix = [row[n:] for row in augmented_matrix]
    return inverse_matrix

# Fonction d'aide pour comparer des flottants avec une tolérance
def matrices_are_close(A, B, tolerance=1e-9):
    rows_A, cols_A = get_dimensions(A)
    rows_B, cols_B = get_dimensions(B)
    if rows_A != rows_B or cols_A != cols_B:
        return False
    for i in range(rows_A):
        for j in range(cols_A):
            if abs(A[i][j] - B[i][j]) > tolerance:
                return False
    return True

# Fonction d'aide pour afficher les matrices
def print_matrix(matrix, name="Matrix"):
    print(f"{name}:")
    for row in matrix:
        print([f"{x:.4f}" for x in row])
    print()

```

## Partie 2: Changement de Base et Matrices de Passage

Maintenant que vous avez les outils matriciels, vous pouvez implémenter la logique de changement de base.

### 2.1. Définition des Bases

Une base est un ensemble de vecteurs linéairement indépendants qui engendrent un espace vectoriel. Pour un espace de dimension `n`, une base est composée de `n` vecteurs. Nous représenterons une base comme une liste de vecteurs, où chaque vecteur est une liste de flottants.

Par exemple, la base canonique (standard) de `R^2` est `[[1.0, 0.0], [0.0, 1.0]]`.

### 2.2. Calcul des Matrices de Passage

Soient deux bases `B = {b1, b2, ..., bn}` et `C = {c1, c2, ..., cn}` d'un espace vectoriel `V`.
Les vecteurs `b_i` et `c_i` sont exprimés dans la base canonique.

1.  **Matrice de la base B (dans la base canonique):** `M_B` est la matrice dont les colonnes sont les vecteurs de la base `B`.
2.  **Matrice de la base C (dans la base canonique):** `M_C` est la matrice dont les colonnes sont les vecteurs de la base `C`.

La matrice de passage de la base `B` vers la base `C`, notée `P_B_vers_C`, est donnée par :
`P_B_vers_C = M_C_inv * M_B`

La matrice de passage de la base `C` vers la base `B`, notée `P_C_vers_B`, est donnée par :
`P_C_vers_B = M_B_inv * M_C`

Implémentez la fonction suivante :

*   `find_transition_matrix(basis_from, basis_to)`: Prend deux listes de vecteurs (représentant les bases) et retourne la matrice de passage de `basis_from` vers `basis_to`.

```python
def vectors_to_matrix(vectors):
    """Convertit une liste de vecteurs (lignes) en une matrice où les vecteurs sont des colonnes."""
    if not vectors:
        raise ValueError("La liste de vecteurs ne peut pas être vide.")

    num_vectors = len(vectors)
    vector_dim = len(vectors[0])

    # Vérifier que tous les vecteurs ont la même dimension
    for vec in vectors:
        if len(vec) != vector_dim:
            raise ValueError("Tous les vecteurs doivent avoir la même dimension.")

    # Créer une matrice où chaque vecteur est une colonne
    # Transposer la liste de vecteurs pour qu'ils soient des colonnes
    # Si vectors est [[v1x, v1y], [v2x, v2y]], on veut [[v1x, v2x], [v1y, v2y]]
    matrix_cols = create_matrix(vector_dim, num_vectors)
    for i in range(vector_dim):
        for j in range(num_vectors):
            matrix_cols[i][j] = vectors[j][i]
    return matrix_cols

def find_transition_matrix(basis_from, basis_to):
    """
    Calcule la matrice de passage de la base 'basis_from' vers la base 'basis_to'.
    Les vecteurs des bases sont supposés être exprimés dans la base canonique.
    """
    # M_from est la matrice dont les colonnes sont les vecteurs de basis_from
    M_from = vectors_to_matrix(basis_from)

    # M_to est la matrice dont les colonnes sont les vecteurs de basis_to
    M_to = vectors_to_matrix(basis_to)

    # Calculer l'inverse de M_to
    M_to_inv = inverse(M_to)

    # La matrice de passage P_from_to est M_to_inv * M_from
    P_from_to = matrix_multiplication(M_to_inv, M_from)

    return P_from_to

def change_coordinates(vector_coords, transition_matrix):
    """
    Transforme les coordonnées d'un vecteur d'une base à une autre.
    vector_coords doit être une liste représentant un vecteur colonne.
    """
    # Convertir le vecteur de coordonnées en une matrice colonne
    vec_matrix = [[x] for x in vector_coords]

    # Multiplier par la matrice de transition
    new_coords_matrix = matrix_multiplication(transition_matrix, vec_matrix)

    # Reconvertir en liste de coordonnées
    return [row[0] for row in new_coords_matrix]

```

### 3.2. Validation des Changements de Base

Considérons les bases suivantes dans `R^2` :
*   Base canonique `E = {e1, e2}` où `e1 = (1,0)`, `e2 = (0,1)`
*   Base `B = {b1, b2}` où `b1 = (1,1)`, `b2 = (-1,1)`
*   Base `C = {c1, c2}` où `c1 = (2,1)`, `c2 = (1,1)`

```python
print("--- Validation des changements de base ---")

# Définition des bases (vecteurs colonnes dans la base canonique)
E_basis = [[1.0, 0.0], [0.0, 1.0]] # e1, e2
B_basis = [[1.0, 1.0], [-1.0, 1.0]] # b1, b2
C_basis = [[2.0, 1.0], [1.0, 1.0]] # c1, c2

# Matrice de passage de B vers C (P_B_vers_C)
# P_B_vers_C = M_C_inv * M_B
P_B_vers_C = find_transition_matrix(B_basis, C_basis)
print_matrix(P_B_vers_C, "P_B_vers_C (de B vers C)")
# Calcul manuel pour vérification:
# M_B = [[1, -1], [1, 1]]
# M_C = [[2, 1], [1, 1]]
# M_C_inv = [[1, -1], [-1, 2]]
# P_B_vers_C = [[1, -1], [-1, 2]] * [[1, -1], [1, 1]] = [[0, -2], [1, 3]]
P_B_vers_C_expected = [[0.0, -2.0], [1.0, 3.0]]
assert matrices_are_close(P_B_vers_C, P_B_vers_C_expected), "Erreur: P_B_vers_C incorrecte"
print("P_B_vers_C OK")

# Matrice de passage de C vers B (P_C_vers_B)
# P_C_vers_B = M_B_inv * M_C
P_C_vers_B = find_transition_matrix(C_basis, B_basis)
print_matrix(P_C_vers_B, "P_C_vers_B (de C vers B)")
# Calcul manuel pour vérification:
# M_B_inv = [[0.5, 0.5], [-0.5, 0.5]]
# P_C_vers_B = [[0.5, 0.5], [-0.5, 0.5]] * [[2, 1], [1, 1]] = [[1.5, 1], [-0.5, 0]]
P_C_vers_B_expected = [[1.5, 1.0], [-0.5, 0.0]]
assert matrices_are_close(P_C_vers_B, P_C_vers_B_expected), "Erreur: P_C_vers_B incorrecte"
print("P_C_vers_B OK")

# Vérification: P_B_vers_C * P_C_vers_B doit être l'identité
I2_check = matrix_multiplication(P_B_vers_C, P_C_vers_B)
assert matrices_are_close(I2_check, create_identity_matrix(2)), "Erreur: P_B_vers_C * P_C_vers_B != I"
print("P_B_vers_C * P_C_vers_B = I OK")

# Exemple de changement de coordonnées
# Soit un vecteur v dont les coordonnées dans la base B sont v_B = (2, 3)
v_B = [2.0, 3.0]
# Coordonnées de v dans la base C: v_C = P_B_vers_C * v_B
v_C_actual = change_coordinates(v_B, P_B_vers_C)
# Calcul manuel: v_C = [[0, -2], [1, 3]] * [[2], [3]] = [[-6], [11]]
v_C_expected = [-6.0, 11.0]
assert all(abs(a - b) < 1e-9 for a, b in zip(v_C_actual, v_C_expected)), "Erreur: Changement de coordonnées B vers C"

# Vérification inverse: v_B = P_C_vers_B * v_C
v_B_reconstructed = change_coordinates(v_C_actual, P_C_vers_B)
assert all(abs(a - b) < 1e-9 for a, b in zip(v_B_reconstructed, v_B)), "Erreur: Changement de coordonnées C vers B"
print(f"Coordonnées de v dans C: {v_C_actual} -> Coordonnées de v dans B: {v_B_reconstructed} (Attendu: {v_B}) OK")

print("\n")
```
