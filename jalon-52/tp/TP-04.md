# TP 04 : Détection numérique d'une discontinuité dans la fonction inverse

Ce script Python pur valide les concepts mathématiques topologiques vus dans ce Jalon, sans framework externe.

```python
import math

def f_circle(t):
    """ [0, 2pi[ vers S1, représenté par (cos t, sin t) """
    assert 0 <= t < 2 * math.pi, "Domaine [0, 2pi["
    return (math.cos(t), math.sin(t))

def f_circle_inverse(x, y):
    """ S1 vers [0, 2pi[ (fonction atan2 modifiée) """
    angle = math.atan2(y, x)
    if angle < 0:
        angle += 2 * math.pi
    return angle

# Montrons que f_inverse n'est pas continue en (1,0)
# Point 1 (proche de 1,0 par le bas de R2, quadrant 4)
epsilon = 1e-5
p1_x, p1_y = math.cos(2*math.pi - epsilon), math.sin(2*math.pi - epsilon)

# Point 2 (proche de 1,0 par le haut de R2, quadrant 1)
p2_x, p2_y = math.cos(epsilon), math.sin(epsilon)

# Dans R2, la distance entre P1 et P2 est infime
dist_R2 = math.hypot(p1_x - p2_x, p1_y - p2_y)
assert dist_R2 < 2 * epsilon

# Mais dans l'espace image (inverse)
t1 = f_circle_inverse(p1_x, p1_y)
t2 = f_circle_inverse(p2_x, p2_y)

dist_inverse = abs(t1 - t2)
assert dist_inverse > math.pi, "Discontinuité topologique confirmée : le saut est énorme dans l'image."
print("TP4 validé : Une bijection continue dont l'inverse est discontinue n'est pas un homéomorphisme.")
```
