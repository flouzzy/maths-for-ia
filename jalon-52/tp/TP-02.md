# TP 02 : Implémentation de l'homéomorphisme Stéréographique (S1 -> R)

Ce script Python pur valide les concepts mathématiques topologiques vus dans ce Jalon, sans framework externe.

```python
import math

def stereographic_projection(x, y):
    """
    Projette un point de la sphère S1 privée du pôle Nord (0, 1) vers la droite R.
    """
    assert abs(x**2 + y**2 - 1.0) < 1e-6, "Le point doit appartenir à S1"
    assert y != 1.0, "Le pôle Nord n'est pas dans le domaine"
    return x / (1.0 - y)

def inverse_stereographic(u):
    """
    Application réciproque continue de R vers S1.
    """
    x = (2 * u) / (u**2 + 1)
    y = (u**2 - 1) / (u**2 + 1)
    return x, y

# Validation mathématique (bijectivité)
test_u = 5.0
x, y = inverse_stereographic(test_u)
assert abs(x**2 + y**2 - 1.0) < 1e-6, "L'image réciproque doit être sur S1"
u_recovered = stereographic_projection(x, y)
assert abs(u_recovered - test_u) < 1e-6, "La composition proj(inv_proj) doit être l'identité"
print("TP2 validé : L'homéomorphisme stéréographique est bien un isomorphisme bijectif.")
```
