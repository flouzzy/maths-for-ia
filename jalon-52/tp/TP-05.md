# TP 05 : Approximation discrète d'un homéomorphisme (Cube vers Boule)

Ce script Python pur valide les concepts mathématiques topologiques vus dans ce Jalon, sans framework externe.

```python
import math

def cube_to_ball(x, y, z):
    """
    Homéomorphisme du cube unité [-1, 1]^3 vers la boule unité fermée.
    """
    norm_inf = max(abs(x), abs(y), abs(z))
    if norm_inf == 0:
        return 0.0, 0.0, 0.0

    norm_2 = math.sqrt(x**2 + y**2 + z**2)
    # Formule : f(v) = (||v||_2 / ||v||_inf) * v  -- Wait, l'exercice disait l'inverse pour la boule vers cube.
    # Appliquons Boule vers Cube comme vu en cours : v -> (||v||_2 / ||v||_inf) * v
    # Cube vers Boule (inverse) : v -> (||v||_inf / ||v||_2) * v
    scale = norm_inf / norm_2
    return (x * scale, y * scale, z * scale)

# Validation : un point sur le coin du cube (1,1,1) doit atterrir sur la frontière de la boule (norme 2 = 1)
bx, by, bz = cube_to_ball(1.0, 1.0, 1.0)
norm_euclide_boule = math.sqrt(bx**2 + by**2 + bz**2)
assert abs(norm_euclide_boule - 1.0) < 1e-6, "L'image du bord du cube n'est pas sur le bord de la sphère"

# Le centre est invariant
assert cube_to_ball(0, 0, 0) == (0.0, 0.0, 0.0)
print("TP5 validé : Transformation homéomorphe entre les différentes normes topologiques.")
```
