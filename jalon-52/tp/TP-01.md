# TP 01 : Vérification numérique de la continuité par boules (Métrique vs Topologie)

Ce script Python pur valide les concepts mathématiques topologiques vus dans ce Jalon, sans framework externe.

```python
def is_locally_continuous(f, x0, epsilon, delta, test_points):
    """
    Vérifie numériquement la condition de Cauchy-Weierstrass qui fonde
    la topologie métrique.
    Pour un epsilon donné, si |x - x0| < delta, a-t-on |f(x) - f(x0)| < epsilon ?
    """
    for x in test_points:
        if abs(x - x0) < delta:
            if abs(f(x) - f(x0)) >= epsilon:
                return False
    return True

# Fonction continue : x^2
f_continue = lambda x: x**2
# Fonction discontinue (saut) : Heaviside
f_discontinue = lambda x: 1.0 if x >= 0 else 0.0

test_points = [x/1000.0 for x in range(-1000, 1000)]

# Assertions
assert is_locally_continuous(f_continue, 0.0, 0.1, 0.01, test_points) == True, "x^2 doit être continue en 0"
assert is_locally_continuous(f_discontinue, 0.0, 0.5, 0.1, test_points) == False, "Heaviside doit être discontinue en 0"
print("TP1 validé : L'approche métrique locale corrobore les propriétés topologiques.")
```
