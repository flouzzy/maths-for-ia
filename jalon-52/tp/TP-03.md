# TP 03 : Transformation d'un intervalle ]-1, 1[ vers R

Ce script Python pur valide les concepts mathématiques topologiques vus dans ce Jalon, sans framework externe.

```python
def f_homeomorphism(x):
    """ ]-1, 1[ vers R : x / (1 - |x|) """
    assert -1 < x < 1, "Domaine invalide"
    return x / (1.0 - abs(x))

def f_inverse(y):
    """ R vers ]-1, 1[ : y / (1 + |y|) """
    return y / (1.0 + abs(y))

# Validation mathématique
val_x = 0.99
val_y = f_homeomorphism(val_x)
val_x_recovered = f_inverse(val_y)
assert abs(val_x - val_x_recovered) < 1e-6, "Rupture de bijection !"

val_y_large = 1000.0
val_x_from_large = f_inverse(val_y_large)
assert -1.0 < val_x_from_large < 1.0, "L'image inverse doit être strictement dans ]-1, 1["
print("TP3 validé : L'espace borné ]-1, 1[ est topologiquement équivalent à l'espace non borné R.")
```
