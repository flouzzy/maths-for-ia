### Approximation de l'intégrale de Lebesgue par supremum

Nous simulons le calcul de l'intégrale de $f(x) = x^2$ sur $[0, 1]$ par la définition de Lebesgue : on partitionne l'axe des ORDONNEES (valeurs), contrairement à Riemann qui partitionne l'axe des abscisses.

```python
def lebesgue_approximation_x2_sur_0_1(n_valeurs):
    # On subdivise l'espace des valeurs [0, 1] en n_valeurs intervalles
    # f(x) = x^2 va de 0 a 1.
    pas_valeur = 1.0 / n_valeurs
    integrale_approx = 0.0

    for k in range(n_valeurs):
        # Valeur en bas du rectangle horizontal : y_k
        y_k = k * pas_valeur
        y_k_plus_1 = (k + 1) * pas_valeur

        # Trouver l'ensemble A_k = {x dans [0,1] | y_k <= f(x) < y_k_plus_1}
        # f(x) = x^2, donc x = sqrt(y)
        # A_k = [sqrt(y_k), sqrt(y_k_plus_1)[

        # Mesure de Lebesgue de A_k (longueur de l'intervalle)
        borne_inf = y_k ** 0.5
        borne_sup = y_k_plus_1 ** 0.5
        mesure_A_k = borne_sup - borne_inf

        # Contribution a l'integrale (on prend la borne inf pour minorer f)
        integrale_approx = integrale_approx + (y_k * mesure_A_k)

    return integrale_approx

res = lebesgue_approximation_x2_sur_0_1(1000)
# La vraie valeur est \int_0^1 x^2 dx = 1/3 = 0.3333...
assert res <= 0.334 and res >= 0.332, "L'approximation de Lebesgue par defaut est defectueuse"
print("Validation TP2 reussie :", res)
```
