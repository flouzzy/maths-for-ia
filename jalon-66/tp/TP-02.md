# TP 02 : Approximation d'une fonction continue par des fonctions étagées inférieures

**Description :** Ce TP illustre la construction de Lebesgue : nous allons discrétiser l'axe des ordonnées en intervalles de taille $1/n$ (partition de l'image) pour minorer une fonction.

```python
def approximation_etagee_inferieure(fonction_f, borne_inf, borne_sup, n_etapes, resolution_x=1000):
    '''
    Construit une fonction simple s_n qui minore f et calcule son integrale
    par rapport a la mesure de Lebesgue sur [borne_inf, borne_sup].
    '''
    pas_x = (borne_sup - borne_inf) / resolution_x

    # On decoupe les ordonnees en bandes de hauteur 1/n_etapes
    hauteur_bande = 1.0 / n_etapes

    # Calcul des mesures des ensembles de niveaux
    mesures = {}

    x = borne_inf
    while x < borne_sup:
        y = fonction_f(x)
        # On trouve l'indice du palier inferieur
        palier_idx = int(y // hauteur_bande)
        valeur_etage = palier_idx * hauteur_bande

        # On ajoute la mesure du petit intervalle de largeur pas_x
        mesures[valeur_etage] = mesures.get(valeur_etage, 0.0) + pas_x

        x += pas_x

    integrale = 0.0
    for alpha, mesure in mesures.items():
        integrale += alpha * mesure

    return integrale

def carre(x):
    return x * x

# Integrale de x^2 sur [0, 1]. Vraie valeur : 1/3 (approx 0.3333)
int_approx = approximation_etagee_inferieure(carre, 0.0, 1.0, 10)
assert 0.2 < int_approx < 0.4, "L'approximation doit encadrer grossierement la valeur exacte 1/3"
print("TP-02 valide avec succes : ", int_approx)
```
