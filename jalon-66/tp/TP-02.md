# TP 2 : Approximation de Lebesgue : Découpage dyadique en ordonnées

Ce TP implémente en Python pur les concepts de base vus dans le cours sur l'intégrale de Lebesgue pour les fonctions simples et positives.

```python
def lebesgue_dyadic_approximation(f, x_points, n):
    """
    Approche une fonction f positive par une fonction simple s_n
    en utilisant un decoupage dyadique sur l'axe des ordonnees.
    f: callable, la fonction positive a approcher.
    x_points: list of points where to evaluate the approximation.
    n: integer, depth of the dyadic partition.
    """
    approx_values = []
    for x in x_points:
        fx = f(x)
        assert fx >= 0, "Function must be positive."
        if fx >= n:
            approx_values.append(n)
        else:
            # find k such that k/(2^n) <= fx < (k+1)/(2^n)
            k = int(fx * (2**n))
            approx_values.append(k / (2**n))
    return approx_values

def test_dyadic_approximation():
    def f(x): return x * x
    x_points = [0.0, 0.5, 1.0, 1.5, 2.0, 2.5]
    # At n=1: threshold is 1. grid is k/2. (0, 0.5)
    # f(0)=0 -> k=0 -> 0.0
    # f(0.5)=0.25 -> k=0 (0 <= 0.25 < 0.5) -> 0.0
    # f(1)=1 -> 1 >= 1 (threshold n=1) -> 1.0
    # f(1.5)=2.25 -> 2.25 >= 1 -> 1.0
    # f(2)=4 -> 4 >= 1 -> 1.0
    # f(2.5)=6.25 -> 6.25 >= 1 -> 1.0
    approx_n1 = lebesgue_dyadic_approximation(f, x_points, 1)
    assert approx_n1 == [0.0, 0.0, 1.0, 1.0, 1.0, 1.0]
    print("TP 02 passed.")

if __name__ == "__main__":
    test_dyadic_approximation()
```
