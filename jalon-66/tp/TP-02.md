# TP 2 : Intégrale d'une fonction simple sur un domaine discret

**Objectif :**
Écrire une fonction qui calcule de manière exacte l'intégrale d'une fonction simple sur un ensemble fini $X = \{0, 1, \dots, N-1\}$ muni d'une mesure discrète arbitraire.

**Implémentation :**
```python
def integral_discrete_simple(values, measure_probs):
    # values: liste des valeurs de la fonction f(x) pour x=0 à N-1
    # measure_probs: liste des mesures mu({x}) pour x=0 à N-1
    assert len(values) == len(measure_probs), "Taille incoherente"

    # 1. Trouver les valeurs distinctes (a_i)
    distinct_vals = list(set(values))

    # 2. Calculer la mesure de chaque ensemble A_i
    integral_value = 0.0
    for a in distinct_vals:
        measure_Ai = 0.0
        for i in range(len(values)):
            if values[i] == a:
                measure_Ai += measure_probs[i]

        integral_value += a * measure_Ai

    return integral_value

# Exemple
f_vals = [1.5, 2.0, 1.5, 3.0, 0.0]
mu_probs = [0.1, 0.2, 0.3, 0.1, 0.3] # Somme = 1 (mesure de proba)
res = integral_discrete_simple(f_vals, mu_probs)
print("Integrale exacte = ", res)

```
