# TP 02 : Approximation de Lebesgue d'une fonction continue

## Objectif

Implémentation de l'approximation par le bas d'une fonction continue positive par une fonction simple, en découpant l'axe des ordonnées (construction standard de Lebesgue).

## Code Python pur

```python
def lebesgue_standard_approximation(f, n, x_eval):
    """
    Evalue la fonction simple d'approximation s_n(x) pour une fonction positive f(x).
    On decoupe l'intervalle [0, n] en 2^n morceaux.
    """
    fx = f(x_eval)
    assert fx >= 0, "La fonction doit etre positive"

    if fx >= n:
        return n

    # Decoupage de [0, n] avec precision 2^-n
    precision = 2**n
    # Nombre d'intervalles k tq k/2^n <= fx < (k+1)/2^n
    k = int(fx * precision)
    return k / float(precision)

# Test sur f(x) = x^2, evaluee en x = 1.5 (fx = 2.25)
def square_func(x):
    return x * x

approx_n1 = lebesgue_standard_approximation(square_func, 1, 1.5)
approx_n2 = lebesgue_standard_approximation(square_func, 2, 1.5)
approx_n3 = lebesgue_standard_approximation(square_func, 3, 1.5)

print(f"f(1.5) = {square_func(1.5)}")
print(f"Approximation s_1 : {approx_n1}")
print(f"Approximation s_2 : {approx_n2}")
print(f"Approximation s_3 : {approx_n3}")

assert approx_n1 <= approx_n2 <= approx_n3 <= 2.25

```
