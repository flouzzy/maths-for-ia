# TP 5 : Intégration Numérique et Approximations par des Fonctions Étagées

Ce TP illustre algorithmiquement la construction de l'intégrale de Lebesgue pour les fonctions mesurables positives, en approximant une fonction par une suite croissante de fonctions étagées. L'approche est implémentée en Python pur.

## Implémentation Algorithmique

```python
# tp_05_lebesgue_integration.py

def lebesgue_integral_approximation(f, a, b, num_levels):
    """
    Approximation de l'intégrale de Lebesgue d'une fonction positive f
    sur un segment [a, b] en découpant l'axe des ordonnées.

    Paramètres:
        f (callable): La fonction mathématique (doit être positive).
        a (float): Borne inférieure du domaine d'intégration.
        b (float): Borne supérieure du domaine d'intégration.
        num_levels (int): Nombre de niveaux pour la fonction étagée.

    Retourne:
        float: L'approximation de l'intégrale de Lebesgue.
    """
    # Discrétisation fine du domaine pour évaluer la mesure (longueur)
    num_samples = 10000
    dx = (b - a) / num_samples

    # Trouver le supremum approché de f sur [a, b]
    max_val = 0.0
    for j in range(num_samples + 1):
        x = a + j * dx
        val = f(x)
        assert val >= 0, "La fonction doit être positive."
        if val > max_val:
            max_val = val

    # Découpage de l'axe des ordonnées (les "étages")
    dy = max_val / num_levels

    integral_sum = 0.0

    # Pour chaque étage, on calcule la "mesure" de l'ensemble de niveau
    for k in range(num_levels):
        y_k = k * dy
        measure_A_k = 0.0

        # Approximation de la mesure de Lebesgue de A_k = {x | f(x) >= y_k}
        for j in range(num_samples):
            x = a + j * dx
            if f(x) >= y_k and f(x) < (k + 1) * dy:
                measure_A_k += dx

        integral_sum += y_k * measure_A_k

    return integral_sum

def test_lebesgue_approximation_5():
    # Fonction de test : f(x) = 5 * x sur [0, 1]
    def f(x):
        return 5 * x

    # L'intégrale exacte est 5/2.0
    exact_integral = 5 / 2.0

    # Approximation de Lebesgue
    approx = lebesgue_integral_approximation(f, 0, 1, 100)

    # Validation mathématique (tolérance due à la discrétisation)
    error = abs(approx - exact_integral)
    assert error < 0.1, f"Erreur d'approximation trop élevée: {error}"
    print(f"Validation réussie : intégrale approchée {approx} vs exacte {exact_integral}")

if __name__ == '__main__':
    test_lebesgue_approximation_5()
```
