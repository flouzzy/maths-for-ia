## TP 5 : Inégalité de Markov Discrète

L'inégalité de Markov est un résultat direct de la théorie de la mesure. Prouvons algorithmiquement qu'elle se vérifie sur un échantillon empirique.

```python
def verifier_markov(valeurs, alpha):
    assert alpha > 0, "alpha doit etre strictement positif"

    n_total = len(valeurs)
    # L'integrale (esperance) par rapport a la mesure de proba uniforme
    moyenne = sum(valeurs) / n_total

    # Mesure de proba de l'ensemble {x | f(x) >= alpha}
    cpt_superieur = 0
    for v in valeurs:
        if v >= alpha:
            cpt_superieur += 1
    proba = cpt_superieur / n_total

    borne_markov = moyenne / alpha

    # Verifion l'inegalite de Markov : P(X >= alpha) <= E[X]/alpha
    assert proba <= borne_markov, "Violaton de l'inegalite de Markov"
    return proba, borne_markov

echantillon = [1, 2, 5, 0, 1, 3, 2, 10, 1, 4]
alpha_test = 4
p, b = verifier_markov(echantillon, alpha_test)

print(f"TP5: Inegalite verifiee. Proba={p} <= Borne Markov={b}")
```
