# TP 05 : Preuve algorithmique de l'inégalité de Markov

**Description :** Calcul du volume d'un ensemble de sur-niveau $\mu(f \ge c)$ et vérification systématique de la majoration de Markov.

```python
def verifier_inegalite_markov(echantillons, c):
    '''
    Verifie l'inegalite de Markov : mu(f >= c) <= (1/c) * int f dmu
    sur une distribution empirique (mesure uniforme de masse 1).
    '''
    N = len(echantillons)
    masse_unitaire = 1.0 / N

    integrale_f = sum(val * masse_unitaire for val in echantillons)

    # Calcul de la mesure de l'ensemble {f >= c}
    compteur_depassement = 0
    for val in echantillons:
        if val >= c:
            compteur_depassement += 1

    mu_depassement = compteur_depassement * masse_unitaire

    borne_markov = integrale_f / c

    assert mu_depassement <= borne_markov + 1e-9, "L'inegalite de Markov est violee"
    return mu_depassement, borne_markov

# Tirages simulant une variable positive
data = [0.1, 0.5, 2.0, 1.5, 5.0, 0.2, 0.8, 3.5, 1.2, 10.0]
c_val = 3.0
mu_A, borne = verifier_inegalite_markov(data, c_val)

print(f"TP-05 valide avec succes.")
print(f"Pour c = {c_val}, mesure = {mu_A}, borne theorique = {borne}")
```
