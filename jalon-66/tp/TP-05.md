# TP 5 : Convergence monotone (Introduction numérique)

**Objectif :**
Écrire une suite croissante de fonctions simples qui converge vers $f(x) = x^2$ sur $[0,1]$, et calculer la limite de leurs intégrales numériquement.

**Implémentation :**
```python
def f(x):
    return x * x

def s_n(x, n):
    # Construit la fonction simple de l'approximation de Lebesgue
    for k in range(n):
        lower = k / n
        upper = (k + 1) / n
        # Pour eviter les boucles lourdes, on fait une formule directe pour x^2
        if f(x) >= lower and f(x) < upper:
            return lower
    if f(x) >= 1.0:
        return 1.0
    return 0.0

def integral_s_n(n):
    # Integrale par somme de Riemann tres fine pour l'aire de la fonction simple
    n_steps = 1000
    dx = 1.0 / n_steps
    total = 0.0
    for i in range(n_steps):
        x = i * dx
        total += s_n(x, n) * dx
    return total

for n in [2, 5, 10, 50]:
    val = integral_s_n(n)
    print("Integrale s_{} = {}".format(n, val))

print("Valeur theorique = 0.3333...")

```
