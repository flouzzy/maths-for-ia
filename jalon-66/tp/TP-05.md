## TP 5 : Inégalité de Markov expérimentale

**Objectif :** Vérifier expérimentalement l'inégalité de Markov pour une fonction positive.

```python
def check_markov(func, domain_start, domain_end, points, t):
    step = (domain_end - domain_start) / points

    integral = 0
    for i in range(points):
        integral += func(domain_start + i * step) * step

    measure_ge_t = 0
    for i in range(points):
        if func(domain_start + i * step) >= t:
            measure_ge_t += step

    bound = integral / t

    print("Mesure {f >= t}:", measure_ge_t)
    print("Borne de Markov:", bound)

    return measure_ge_t <= bound

def h(x):
    return x * x * x + 1

if __name__ == "__main__":
    valid = check_markov(h, 0, 2, 1000, 4.0)
    assert valid == True
```
