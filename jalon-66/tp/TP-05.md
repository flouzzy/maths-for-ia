# TP 5 : Illustration de l'inégalité de Markov/Tchebychev

Ce programme vérifie empiriquement l'inégalité mu({x | f(x) >= alpha}) <= 1/alpha * integral(f) sur une fonction discrète.

```python
def test_markov(values, probs, alpha):
    # values: list of values f(x)
    # probs: list of probabilities mu(x)

    expected_value = sum([v * p for v, p in zip(values, probs)])

    # Calculate mu(A_alpha)
    prob_geq_alpha = sum([p for v, p in zip(values, probs) if v >= alpha])

    # Markov bound
    bound = expected_value / alpha

    return prob_geq_alpha <= bound, prob_geq_alpha, bound

if __name__ == "__main__":
    # A positive random variable (or measurable function on probability space)
    values = [0, 1, 2, 5, 10]
    probs = [0.1, 0.4, 0.3, 0.15, 0.05]

    # Check for various alphas
    for alpha in [1.0, 2.0, 4.0, 8.0]:
        is_valid, actual, bound = test_markov(values, probs, alpha)
        assert is_valid

    # Example for alpha = 5
    # expected = 0*0.1 + 1*0.4 + 2*0.3 + 5*0.15 + 10*0.05 = 0 + 0.4 + 0.6 + 0.75 + 0.5 = 2.25
    # prob(X >= 5) = P(X=5) + P(X=10) = 0.15 + 0.05 = 0.20
    # Bound = 2.25 / 5 = 0.45
    # 0.20 <= 0.45 (Valid)

    is_valid, actual, bound = test_markov(values, probs, 5.0)
    assert is_valid
    assert abs(actual - 0.20) < 1e-6
    assert abs(bound - 0.45) < 1e-6

    print("TP5 OK")
```
