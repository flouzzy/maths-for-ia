### Mesure de comptage et conversion en série

Démonstration par le code que l'intégrale de Lebesgue avec la mesure de comptage équivaut exactement à la sommation d'une série numérique standard.

```python
def integrale_mesure_comptage(termes_suite, N_max):
    # Mesure de comptage : chaque element a pour mesure 1
    integrale = 0.0
    for n in range(N_max):
        # f(n) * \mu({n}) = f(n) * 1
        integrale = integrale + (termes_suite(n) * 1.0)

    return integrale

# On considere la suite f(n) = (1/2)^n
def suite_geometrique(n):
    return (0.5) ** n

# Calcul sur les 50 premiers termes
res_comptage = integrale_mesure_comptage(suite_geometrique, 50)

# La limite theorique de la serie sum (1/2)^n de 0 a infini est 1 / (1 - 1/2) = 2.0
assert res_comptage <= 2.0, "L'integrale depasse la borne theorique de la serie"
assert abs(res_comptage - 2.0) < 1e-5, "La convergence est defectueuse"
print("Validation TP5 reussie : L'integrale converge vers la somme de la serie =", res_comptage)
```
