# TP 05 : Sous-additivité stricte

## Objectif

Implémentation démontrant que l'intégrale de Lebesgue respecte rigoureusement l'additivité pour des fonctions simples, en reconstruisant l'intersection des partitions.

## Code Python pur

```python
def create_fine_partition(s1_values, s1_intervals, s2_values, s2_intervals):
    """
    Cree une partition plus fine a partir de deux fonctions simples definies sur des intervalles.
    Chaque intervalle est [start, end).
    """
    fine_intervals = []

    for v1, (start1, end1) in zip(s1_values, s1_intervals):
        for v2, (start2, end2) in zip(s2_values, s2_intervals):
            # Intersection de [start1, end1) et [start2, end2)
            inter_start = max(start1, start2)
            inter_end = min(end1, end2)

            if inter_start < inter_end:
                fine_intervals.append({
                    "val_sum": v1 + v2,
                    "measure": inter_end - inter_start
                })
    return fine_intervals

# f = 2 sur [0, 4], 0 ailleurs
s1_v = [2.0]
s1_i = [(0.0, 4.0)]

# g = 3 sur [2, 5], 0 ailleurs
s2_v = [3.0]
s2_i = [(2.0, 5.0)]

# Integrales independantes
int_f = 2.0 * 4.0 # 8
int_g = 3.0 * 3.0 # 9
print(f"int f + int g = {int_f + int_g}")

# Construction partition fine pour f+g
fine_part = create_fine_partition(s1_v, s1_i, s2_v, s2_i)
int_sum = 0.0

# On ajoute l'integrale sur [0, 2] ou f=2, g=0
int_sum += 2.0 * 2.0
# On ajoute l'integrale sur l'intersection [2, 4] calculee par la fonction
for p in fine_part:
    int_sum += p["val_sum"] * p["measure"]
# On ajoute l'integrale sur [4, 5] ou f=0, g=3
int_sum += 3.0 * 1.0

print(f"int (f+g) = {int_sum}")
assert abs((int_f + int_g) - int_sum) < 1e-9

```
