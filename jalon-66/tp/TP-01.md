## TP 1 : Implémentation d'un Espace Mesuré de Base

Dans ce TP, nous allons modéliser de manière conceptuelle (et algorithmique) un espace mesuré discret. Bien que la théorie de Lebesgue brille pour les espaces continus, sa construction algébrique sur des ensembles finis permet de saisir l'intuition de la "mesure".

```python
class EspaceMesureFini:
    def __init__(self, omega):
        # omega est une liste d'elements de base
        self.omega = set(omega)

    def mesure_comptage(self, A):
        # A doit etre un sous-ensemble de omega
        ensemble_A = set(A)
        assert ensemble_A.issubset(self.omega), "A n'est pas dans l'espace mesurable"
        return len(ensemble_A)

    def mesure_dirac(self, A, a):
        ensemble_A = set(A)
        assert ensemble_A.issubset(self.omega), "A n'est pas dans l'espace mesurable"
        assert a in self.omega, "Le point de Dirac doit etre dans l'espace"
        if a in ensemble_A:
            return 1
        return 0

# Test simple
X = EspaceMesureFini([1, 2, 3, 4, 5])
assert X.mesure_comptage([2, 4]) == 2
assert X.mesure_dirac([1, 2, 3], 3) == 1
assert X.mesure_dirac([1, 2], 3) == 0
print("TP1: Tests passes")
```
