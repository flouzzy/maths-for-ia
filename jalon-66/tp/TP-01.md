# TP 1 : Implémentation d'une fonction étagée et calcul de son intégrale

Dans ce TP, nous allons modéliser une fonction étagée sur un espace discret fini et calculer son intégrale de Lebesgue par rapport à une mesure de comptage pondérée.

```python
class StepFunction:
    def __init__(self, values, measure_space):
        # values is a dict mapping from domain element to value
        # measure_space is a dict mapping from domain element to its measure
        self.values = values
        self.measure_space = measure_space

    def integral(self):
        result = 0.0
        # Determine the distinct values alpha_i
        alphas = set(self.values.values())
        for alpha in alphas:
            if alpha < 0:
                raise ValueError("Step function must be positive")
            # Calculate measure of A_i (preimage of alpha)
            measure_A_i = sum([self.measure_space[k] for k, v in self.values.items() if v == alpha])
            result += alpha * measure_A_i
        return result

if __name__ == "__main__":
    domain = [1, 2, 3, 4, 5]
    measure = {1: 0.1, 2: 0.2, 3: 0.3, 4: 0.2, 5: 0.2} # Probability measure

    # f(1)=10, f(2)=10, f(3)=20, f(4)=20, f(5)=30
    func_values = {1: 10, 2: 10, 3: 20, 4: 20, 5: 30}

    f = StepFunction(func_values, measure)
    val = f.integral()

    # Theoretical: 10*(0.1+0.2) + 20*(0.3+0.2) + 30*0.2 = 10*0.3 + 20*0.5 + 30*0.2 = 3 + 10 + 6 = 19
    assert abs(val - 19.0) < 1e-6
    print("TP1 OK")
```
