# TP 1 : Intégrale de Riemann vs Lebesgue (Approche naïve)

**Objectif :**
Implémenter une fonction Python pour approximer l'intégrale d'une fonction continue sur $[0,1]$ en utilisant des rectangles verticaux (Riemann) et des 'rectangles' horizontaux (Lebesgue, fonctions simples basées sur les ordonnées).

**Implémentation :**
```python
def f(x):
    return x * x

def riemann_integral(func, n_steps):
    dx = 1.0 / n_steps
    total = 0.0
    for i in range(n_steps):
        x = i * dx
        total += func(x) * dx
    return total

def lebesgue_integral_approx(func, n_y_steps):
    # Approximation par partitionnement de l'axe des ordonnées
    y_max = func(1.0)
    dy = y_max / n_y_steps
    total = 0.0
    n_samples = 10000

    for j in range(n_y_steps):
        y_val = j * dy
        # Mesure de l'ensemble A_j = {x | f(x) >= y_val} (Approximation par Monte Carlo/Echantillonnage)
        count_in_set = 0
        for i in range(n_samples):
            x = i / n_samples
            if func(x) >= y_val and func(x) < y_val + dy:
                count_in_set += 1

        measure = count_in_set / n_samples
        total += y_val * measure

    return total

print("Riemann (n=1000):", riemann_integral(f, 1000))
print("Lebesgue approx (n=100):", lebesgue_integral_approx(f, 100))

```
