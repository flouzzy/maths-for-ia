# TP 01 : Intégration d'une fonction simple positive

## Objectif

Calcul exact de l'intégrale d'une fonction simple en définissant les valeurs, les ensembles et une mesure donnée.

## Code Python pur

```python
def integrate_simple_function(values, measures):
    """
    Calcule l'integrale de Lebesgue d'une fonction simple positive.
    values : liste des valeurs a_i > 0 prises par la fonction.
    measures : liste des mesures mu(A_i) correspondantes.
    """
    assert len(values) == len(measures), "Tailles incompatibles"
    integral = 0.0
    for v, m in zip(values, measures):
        assert v >= 0, "Fonction positive requise"
        assert m >= 0, "Mesure positive requise"
        integral += v * m
    return integral

# Test : f(x) = 2 sur un ensemble de mesure 3, et 5 sur un ensemble de mesure 1
valeurs = [2.0, 5.0]
mesures = [3.0, 1.0]

resultat = integrate_simple_function(valeurs, mesures)
print(f"Integrale calculee : {resultat}")
assert abs(resultat - 11.0) < 1e-9

```
