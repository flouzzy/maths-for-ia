# TP 1 : Structure d'une fonction simple 1D et calcul de son intégrale

Ce TP implémente en Python pur les concepts de base vus dans le cours sur l'intégrale de Lebesgue pour les fonctions simples et positives.

```python
def calculate_simple_integral(intervals, values):
    """
    Calcule l'integrale d'une fonction simple positive sur R.
    intervals: list of tuples (a, b) representing disjoint intervals [a, b).
    values: list of floats representing the constant value of the function on each interval.
    """
    assert len(intervals) == len(values), "Mismatch between intervals and values."
    integral = 0.0
    for (a, b), val in zip(intervals, values):
        assert val >= 0, "Function must be positive."
        assert b >= a, "Invalid interval."
        length = b - a
        integral += val * length
    return integral

def test_simple_integral():
    intervals = [(0, 2), (3, 5), (6, 6.5)]
    values = [3.0, 5.0, 2.0]
    result = calculate_simple_integral(intervals, values)
    # Expected: 3*(2-0) + 5*(5-3) + 2*(6.5-6) = 6 + 10 + 1 = 17
    assert abs(result - 17.0) < 1e-9, f"Expected 17.0, got {result}"
    print("TP 01 passed.")

if __name__ == "__main__":
    test_simple_integral()
```
