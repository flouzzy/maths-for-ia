# TP 01 : Calcul de l'intégrale d'une fonction étagée sur un espace discret

**Description :** Nous allons implémenter la définition fondamentale de l'intégrale d'une fonction simple (étagée) sur un espace discret fini (la mesure de comptage), illustrant $\int s \, d\mu = \sum \alpha_i \mu(A_i)$.

```python
def integrale_simple_discrete(valeurs_et_frequences):
    '''
    Calcule l'integrale d'une fonction simple.
    valeurs_et_frequences est un dictionnaire ou la cle est la valeur alpha_i
    et la valeur est la mesure de l'ensemble de niveau mu(A_i).
    '''
    integrale = 0.0
    for alpha, mesure in valeurs_et_frequences.items():
        assert alpha >= 0, "La fonction doit etre positive"
        assert mesure >= 0, "La mesure doit etre positive"
        integrale += alpha * mesure
    return integrale

# Test : Fonction constante egale a 3 sur un ensemble de 5 elements, et 2 sur 4 elements
fonction = {3.0: 5, 2.0: 4}
resultat = integrale_simple_discrete(fonction)
assert resultat == 23.0, "Calcul incorrect (3*5 + 2*4 = 23)"
print("TP-01 valide avec succes.")
```
