### Représentation algorithmique d'une fonction simple

Ce TP implémente la définition formelle d'une fonction simple sur un univers fini et calcule son intégrale exacte, en évitant toute erreur de flottant sur les mesures par l'usage de types discrets.

```python
def integrale_simple(valeurs_ensembles, mesure_base):
    # valeurs_ensembles est une liste de tuples (a_i, A_i)
    # où a_i est la valeur constante sur l'ensemble A_i.
    # mesure_base est un dictionnaire associant chaque element de l'univers à son "poids"

    integrale_totale = 0

    for a_i, A_i in valeurs_ensembles:
        # Calcul strict de la mesure de l'ensemble A_i
        mesure_A_i = 0
        for element in A_i:
            if element in mesure_base:
                mesure_A_i = mesure_A_i + mesure_base[element]

        # Incrementation de l'integrale de Lebesgue
        integrale_totale = integrale_totale + (a_i * mesure_A_i)

    return integrale_totale

# Validation Mathematique
mesure_univers = {1: 0.2, 2: 0.3, 3: 0.5}
# s = 10 * 1_{1, 2} + 5 * 1_{3}
fonction_s = [(10, [1, 2]), (5, [3])]

resultat = integrale_simple(fonction_s, mesure_univers)
# Attendu: 10 * (0.2 + 0.3) + 5 * (0.5) = 10 * 0.5 + 2.5 = 7.5
assert abs(resultat - 7.5) <= 1e-9, "L'integrale simple est incorrecte"
print("Validation TP1 reussie :", resultat)
```
