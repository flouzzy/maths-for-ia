# TP 03 : Intégration numérique façon Lebesgue

## Objectif

Calcul de l'intégrale d'une fonction positive sur un segment par une approche de type Lebesgue : on discretise les ordonnées et on mesure la taille des ensembles de pré-images.

## Code Python pur

```python
def lebesgue_integral_1d(f, a, b, num_x_points, max_y, num_y_bins):
    """
    Calcule approximativement l'integrale de Lebesgue de f sur [a, b].
    - On echantillonne l'axe des abscisses pour estimer les mesures.
    - On decoupe l'axe des ordonnees en 'num_y_bins' jusqu'a 'max_y'.
    """
    dx = (b - a) / num_x_points
    dy = max_y / num_y_bins

    # Histogramme pour accumuler la mesure (longueur dx) pour chaque niveau y
    measures = [0.0] * num_y_bins

    for i in range(num_x_points):
        x = a + i * dx + dx / 2.0 # Point milieu
        fx = f(x)
        assert fx >= 0

        # Trouver dans quel bin y on se trouve
        if fx < max_y:
            bin_idx = int(fx / dy)
            measures[bin_idx] += dx

    # Calcul de l'integrale de la fonction simple (borne inf dy * idx)
    integral = 0.0
    for idx in range(num_y_bins):
        y_val = idx * dy
        integral += y_val * measures[idx]

    return integral

# Test : Integrale de x sur [0, 2] = 2.0
def identity(x): return x

res = lebesgue_integral_1d(identity, 0.0, 2.0, 10000, 2.5, 1000)
print(f"Integrale de x sur [0, 2] calculee : {res}")
assert abs(res - 2.0) < 0.1

```
