## TP 3 : Convergence monotone en action

**Objectif :** Visualiser algorithmiquement le théorème de convergence monotone avec une suite de fonctions simples.

```python
def fn(x, n):
    if x == 0:
        return 0
    return x - (x ** n)

def integrate_riemann_approx(func, n, steps=1000):
    total = 0
    dx = 1.0 / steps
    for i in range(steps):
        x = i * dx
        total += func(x, n) * dx
    return total

if __name__ == "__main__":
    integrals = []
    for n in range(1, 15):
        val = integrate_riemann_approx(fn, n)
        integrals.append(val)
        print("Integral of f_{n} =", val)

    diff = integrals[-1] - 0.5
    if diff < 0:
        diff = -diff
    assert diff < 0.1
```
