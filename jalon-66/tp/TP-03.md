### L'inégalité de Markov algorithmique

Nous vérifions expérimentalement l'inégalité de Markov : $\mu(\{x \mid f(x) \ge \alpha\}) \le \frac{1}{\alpha} \int f$.

```python
def verification_markov(valeurs, probabilites, alpha):
    # Calcul de l'esperance (Integrale de f dP)
    esperance = 0.0
    for i in range(len(valeurs)):
        esperance = esperance + valeurs[i] * probabilites[i]

    # Calcul de la mesure (probabilite) de l'ensemble {x | f(x) >= alpha}
    mesure_A_alpha = 0.0
    for i in range(len(valeurs)):
        if valeurs[i] >= alpha:
            mesure_A_alpha = mesure_A_alpha + probabilites[i]

    borne_markov = esperance / alpha

    return mesure_A_alpha, borne_markov

val = [0, 1, 2, 5, 10]
prob = [0.1, 0.4, 0.3, 0.15, 0.05]
# Esperance E[X] = 0 + 0.4 + 0.6 + 0.75 + 0.5 = 2.25

alpha_test = 4.0
mesure, borne = verification_markov(val, prob, alpha_test)

assert mesure <= borne, "Violaton flagrante du Theoreme de Markov"
print("Validation TP3 reussie : Mesure =", mesure, "<= Borne =", borne)
```
