# TP 3 : Calcul approché de l'intégrale de Lebesgue via supremum de suites croissantes

En utilisant la suite croissante de fonctions étagées (s_n) du TP2, nous approchons l'intégrale de f(x) = x^2 sur [0,1] par rapport à la mesure de Lebesgue.

```python
def f(x):
    return x * x

def integral_s_n(n, num_points=1000):
    # We approximate the integral of s_n on [0,1] using a fine grid
    # Since s_n is piecewise constant, a Riemann sum with a very fine grid
    # acts as the Lebesgue measure of the sets.
    dx = 1.0 / num_points
    integral = 0.0
    step = 1.0 / (2**n)

    for i in range(num_points):
        x = (i + 0.5) * dx
        val = f(x)
        if val >= n:
            s_nx = n
        else:
            k = int(val / step)
            s_nx = k * step
        integral += s_nx * dx
    return integral

if __name__ == "__main__":
    # Theoretical integral of x^2 on [0,1] is 1/3 ~ 0.333333
    int_1 = integral_s_n(1)
    int_2 = integral_s_n(2)
    int_3 = integral_s_n(3)
    int_6 = integral_s_n(6)

    assert int_1 <= int_2 <= int_3 <= int_6

    # Check convergence towards 1/3
    assert abs(int_6 - 1.0/3.0) < 0.05

    print("TP3 OK")
```
