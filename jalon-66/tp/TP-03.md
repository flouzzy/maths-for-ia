# TP 03 : Monotonie de l'intégrale

**Description :** Validation numérique stricte du théorème de monotonie : si $f \le g$, alors $\int f \, d\mu \le \int g \, d\mu$.

```python
def verifier_monotonie(f_dict, g_dict):
    '''
    Verifie la monotonie pour des fonctions discretes representees par
    des dictionnaires point -> valeur.
    L'espace est l'ensemble des cles communes, la mesure est la mesure de comptage.
    '''
    cles = set(f_dict.keys()).union(set(g_dict.keys()))

    # Validation point par point f <= g
    for k in cles:
        val_f = f_dict.get(k, 0.0)
        val_g = g_dict.get(k, 0.0)
        assert val_f <= val_g, "f n'est pas inferieure a g partout"

    # Calcul des integrales (mesure de comptage, mu({k}) = 1)
    int_f = sum(f_dict.get(k, 0.0) for k in cles)
    int_g = sum(g_dict.get(k, 0.0) for k in cles)

    assert int_f <= int_g, "Le theoreme de monotonie de l'integrale a echoue"
    return int_f, int_g

f = {1: 0.5, 2: 1.0, 3: 0.1}
g = {1: 0.8, 2: 1.0, 3: 0.2, 4: 0.5}

int_f, int_g = verifier_monotonie(f, g)
print(f"TP-03 valide avec succes. Int f = {int_f}, Int g = {int_g}")
```
