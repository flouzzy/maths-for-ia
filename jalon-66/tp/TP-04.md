# TP 4 : Additivité de l'intégrale sur des fonctions étagées

Vérification algorithmique du fait que l'intégrale de s + t est égale à l'intégrale de s plus l'intégrale de t pour des fonctions étagées.

```python
class StepFunc1D:
    def __init__(self, intervals, values):
        # intervals is a list of (start, end) representing a partition of a domain
        # values is the corresponding list of values
        self.intervals = intervals
        self.values = values

    def integral(self):
        res = 0.0
        for (start, end), val in zip(self.intervals, self.values):
            length = end - start
            res += val * length
        return res

def add_step_funcs(s, t):
    # Assumes both functions share the same partition for simplicity of the TP
    assert s.intervals == t.intervals
    new_values = [v1 + v2 for v1, v2 in zip(s.values, t.values)]
    return StepFunc1D(s.intervals, new_values)

if __name__ == "__main__":
    intervals = [(0, 0.5), (0.5, 1.0), (1.0, 2.0)]
    s = StepFunc1D(intervals, [1.0, 3.0, 0.5])
    t = StepFunc1D(intervals, [2.0, 0.0, 1.5])

    sum_st = add_step_funcs(s, t)

    int_s = s.integral()
    int_t = t.integral()
    int_sum = sum_st.integral()

    assert abs((int_s + int_t) - int_sum) < 1e-9

    print("TP4 OK")
```
