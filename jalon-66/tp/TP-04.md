# TP 04 : Vérification empirique de l'inégalité de Markov

## Objectif

Échantillonnage d'une distribution positive (via une fonction) pour estimer l'intégrale (l'espérance) et vérifier que la probabilité (la mesure normalisée) respecte la borne de Markov.

## Code Python pur

```python
def check_markov_inequality(data, t):
    """
    Verifie l'inegalite de Markov empiriquement sur une liste de donnees positives.
    data represente des evaluations de f(x). On suppose la mesure de comptage normalisee (proba uniforme).
    """
    n = len(data)
    # Calcul de l'integrale (esperance)
    expected_value = sum(data) / n

    # Calcul de la mesure de l'ensemble {f >= t}
    count_t = sum(1 for x in data if x >= t)
    prob_t = count_t / n

    # Borne de Markov
    bound = expected_value / t

    return prob_t, bound, expected_value

# Jeu de donnees : carres des nombres de 1 a 10
dataset = [x*x for x in range(1, 11)] # Valeurs de 1 a 100
t_val = 50.0

prob, bound, mean = check_markov_inequality(dataset, t_val)
print(f"Esperance : {mean}")
print(f"P(X >= {t_val}) = {prob}")
print(f"Borne de Markov : {bound}")
assert prob <= bound

```
