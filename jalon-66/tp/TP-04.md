# TP 04 : Intégrale de la fonction indicatrice des rationnels (Dirichlet empirique)

**Description :** Simulation du calcul de l'intégrale d'une fonction fortement discontinue en séparant les rationnels et irrationnels (via une approximation flottante).

```python
def integrale_dirichlet_empirique(points_echantillons):
    '''
    Evalue l'integrale de Lebesgue de la fonction indicatrice des 'rationnels'
    sur un echantillon discret en triant par la valeur prise (0 ou 1).
    '''
    # Dans la pratique, float est toujours 'rationnel' en memoire d'ordinateur.
    # Pour simuler, on decrete arbitrairement que si le carre du nombre est proche d'un entier,
    # c'est un 'rationnel typique', sinon irrationnel.

    mesure_rationnels = 0.0
    mesure_irrationnels = 0.0

    poids_point = 1.0 / len(points_echantillons)

    for x in points_echantillons:
        # Simulation d'un test d'appartenance a Q
        # Ici on simule que l'ensemble 'Q' a une mesure empirique tres faible.
        if (x * 100) % 1 == 0:
            mesure_rationnels += poids_point
        else:
            mesure_irrationnels += poids_point

    # L'integrale de Lebesgue est sum alpha_i * mu(A_i)
    integrale = 1.0 * mesure_rationnels + 0.0 * mesure_irrationnels

    return integrale

# Points equirepartis : 0.001, 0.002 ...
points = [i / 1000.0 for i in range(1000)]
res = integrale_dirichlet_empirique(points)
assert res < 1.0, "La mesure des points specifiques devrait etre petite ou ponctuelle."
print(f"TP-04 valide avec succes. L'integrale simulee vaut : {res}")
```
