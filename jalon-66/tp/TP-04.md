## TP 4 : Approximation de Fonctions par des Fonctions Simples

L'intégrale de Lebesgue pour une fonction continue se définit comme le supremum de l'intégrale des fonctions simples la minorant. Nous allons approximer empiriquement la fonction f(x) = x sur [0, 1].

```python
def approximer_identite(n_paliers):
    # On decoupe [0, 1] en n_paliers intervalles egaux
    # f(x) = x
    pas = 1.0 / n_paliers
    integrale = 0.0

    for i in range(n_paliers):
        borne_inf = i * pas
        borne_sup = (i + 1) * pas
        # La fonction simple minorante prend la valeur minimale de f sur l'intervalle
        valeur = borne_inf
        # La mesure de l'intervalle (mesure de Lebesgue 1D) est sa longueur
        mesure = borne_sup - borne_inf

        integrale += valeur * mesure

    return integrale

# L'integrale analytique de x sur [0, 1] est 0.5
n_test = 1000
approx = approximer_identite(n_test)
erreur = abs(0.5 - approx)
assert erreur < 0.01, "L'approximation est trop mauvaise"
print(f"TP4: Approximation de Riemann-Lebesgue ({n_test} paliers) = {approx:.4f}")
```
