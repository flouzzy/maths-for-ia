# TP 2 : Méthode des trapèzes pour un signal continu

Amélioration de la précision de l'intégration pour une fonction continue (triangle).

## 1. Objectif
Implémenter la méthode des trapèzes pour éviter les erreurs d'approximation des fonctions continues à forte pente.

## 2. Implémentation

```python
import math

def f_triangle(t):
    t_mod = t % (2 * math.pi)
    if t_mod <= math.pi:
        return t_mod
    else:
        return 2 * math.pi - t_mod

def fourier_trapezes(f, n, num_points=1000):
    dt = 2 * math.pi / num_points
    an = 0.0
    for k in range(num_points):
        t_left = k * dt
        t_right = (k + 1) * dt
        val_left = f(t_left) * math.cos(n * t_left)
        val_right = f(t_right) * math.cos(n * t_right)
        an += (val_left + val_right) / 2.0 * dt
    return an / math.pi

a1 = fourier_trapezes(f_triangle, 1)
# Valeur théorique pour le triangle de crête pi est -4/pi
assert abs(a1 - (-4/math.pi)) < 1e-2, "Erreur dans le calcul de a1 par trapèzes."
print("TP 2 : Trapèzes OK")
```
