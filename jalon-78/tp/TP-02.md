# Synthèse et reconstruction du signal

Maintenant que nous avons les coefficients, ce TP vise à reconstruire le signal temporel à partir de ses composantes harmoniques et à observer la convergence.

```python
import math

def reconstruct_signal(t, a, b, n_max):
    # a[0] contient la moyenne (deja multpliee par 2 en theorie, donc on divise)
    val = a[0] / 2.0
    for n in range(1, n_max + 1):
        val += a[n] * math.cos(n * t) + b[n] * math.sin(n * t)
    return val

# On reprend les coefficients theoriques du signal carre
# a_n = 0, b_n = 4/(n*pi) si n impair, 0 sinon
def theory_coeffs(n_max):
    a = [0.0] * (n_max + 1)
    b = [0.0] * (n_max + 1)
    for n in range(1, n_max + 1):
        if n % 2 != 0:
            b[n] = 4.0 / (n * math.pi)
    return a, b

n_max = 10
a_theo, b_theo = theory_coeffs(n_max)

# On evalue le signal reconstruit en t = pi/2 ou il vaut theoriquement 1
t_test = math.pi / 2.0
reconstructed_val = reconstruct_signal(t_test, a_theo, b_theo, n_max)
print(f"Valeur reconstruite (N={n_max}) en pi/2 : {reconstructed_val}")

# Validation mathematique
assert abs(reconstructed_val - 1.0) < 0.1, "La somme de Fourier converge vers 1 en ce point."
```
