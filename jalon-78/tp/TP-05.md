## TP 5 : Sommes de Fejer (Moyenne de Cesaro des sommes partielles)


Pour pallier le phenomene de Gibbs, on peut calculer les sommes de Fejer, qui sont la moyenne arithmetique des sommes partielles de Fourier. Elles convergent uniformement pour toute fonction continue.

\begin{lstlisting}[language=Python]
import math

def calculate_fejer_sums(a, b, T, t_values):
    omega = 2 * math.pi / T
    N = len(a) - 1
    fejer = []

    for t in t_values:
        total_sum = 0.0
        # On calcule S_n(t) pour n de 0 a N-1
        for n in range(N):
            sn = a[0] / 2.0
            for k in range(1, n + 1):
                sn += a[k] * math.cos(k * omega * t)
                sn += b[k] * math.sin(k * omega * t)
            total_sum += sn
        fejer.append(total_sum / N)

    return fejer

# Coefficients theoriques carre
def square_wave_coeffs(N):
    a = [0.0] * (N + 1)
    b = [0.0] * (N + 1)
    for n in range(1, N + 1):
        if n % 2 != 0:
            b[n] = 4.0 / (math.pi * n)
    return a, b

N_harmonics = 10
a_theo, b_theo = square_wave_coeffs(N_harmonics)

t_grid = [0.0, math.pi/2, math.pi - 0.1, math.pi + 0.1, 3*math.pi/2]
signal_fejer = calculate_fejer_sums(a_theo, b_theo, 2*math.pi, t_grid)

for i in range(len(t_grid)):
    print("t = {:.2f}, Fejer approx = {:.4f}".format(t_grid[i], signal_fejer[i]))
