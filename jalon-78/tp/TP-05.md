# Transformée de Fourier Discrète (TFD) 1D naive

La TFD est la version discrète en temps et en fréquence pour un signal échantillonné. Elle est la base de l'algorithme FFT. Implémentons-la de zéro avec des nombres complexes.

```python
import math

def naive_dft(x):
    N = len(x)
    X = []
    for k in range(N):
        re = 0.0
        im = 0.0
        for n in range(N):
            angle = -2.0 * math.pi * k * n / N
            re += x[n] * math.cos(angle)
            im += x[n] * math.sin(angle)
        X.append((re, im))
    return X

# Test avec une onde pure de frequence k=2
N = 16
signal = []
for n in range(N):
    # Frequence 2, amplitude 5
    signal.append(5.0 * math.cos(2.0 * math.pi * 2 * n / N))

spectrum = naive_dft(signal)

# On calcule les modules
modules = []
for k in range(N):
    re, im = spectrum[k]
    mod = math.sqrt(re**re + im**im)
    modules.append(mod)

# Le spectre d'un cosinus reel doit avoir des pics en k=2 et k=N-2
print("Module en k=2 :", modules[2])
print("Module en k=0 :", modules[0])

assert modules[2] > 10.0, "Pic attendu a la frequence k=2"
assert modules[0] < 1e-5, "Pas de composante continue"
```
