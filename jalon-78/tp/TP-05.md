# TP 5 : La racine de la FFT (Transformée Discrète Complexe)

Pour clore les séries de Fourier, on passe dans l'espace complexe discret.

## 1. Objectif
Calculer les $X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-i 2\pi k n / N}$.

## 2. Implémentation

```python
import math

def dft(x):
    N = len(x)
    X = []
    for k in range(N):
        real_part = 0.0
        imag_part = 0.0
        for n in range(N):
            angle = -2 * math.pi * k * n / N
            real_part += x[n] * math.cos(angle)
            imag_part += x[n] * math.sin(angle)
        # Représentation du nombre complexe par un tuple (Re, Im)
        X.append((real_part, imag_part))
    return X

# Un signal constant doit avoir une énergie nulle pour les k > 0
x = [1.0, 1.0, 1.0, 1.0]
X_out = dft(x)

# X[0] est la somme des éléments (4.0)
assert abs(X_out[0][0] - 4.0) < 1e-5, "Erreur sur X[0]."
# X[1] doit être nul
assert abs(X_out[1][0]) < 1e-5 and abs(X_out[1][1]) < 1e-5, "Erreur sur X[1]."

print("TP 5 : TFD complexe OK")
```
