# TP 4 : Reconstruction et phénomène de Gibbs

Nous allons sommer les premiers harmoniques pour reconstruire le signal, et mesurer l'erreur ponctuelle.

## 1. Objectif
Démontrer que la somme partielle "dépasse" (overshoot) la valeur de discontinuité.

## 2. Implémentation

```python
import math

def reconstruct_square_wave(t, harmonics):
    somme = 0
    for k in range(harmonics):
        n = 2 * k + 1
        bn = 4 / (math.pi * n)
        somme += bn * math.sin(n * t)
    return somme

# On teste proche de la discontinuité en t=0 (par ex. t=0.1)
val_10 = reconstruct_square_wave(0.1, 10)
val_50 = reconstruct_square_wave(0.05, 50)
val_100 = reconstruct_square_wave(0.015, 100)

# Le dépassement de Gibbs est d'environ 9%, donc le signal monte autour de 1.18 avant de redescendre.
assert val_50 > 1.05, "Le phénomène de Gibbs n'est pas observé."
assert val_100 > 1.05, "Le phénomène de Gibbs n'est pas observé à haute fréquence."
print("TP 4 : Reconstruction et Gibbs OK")
```
