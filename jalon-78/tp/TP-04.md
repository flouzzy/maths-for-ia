## TP 4 : Filtrage d'un signal bruite dans le domaine frequentiel


Le but est d'utiliser la transformee de Fourier pour identifier et supprimer les hautes frequences (bruit) d'un signal.

\begin{lstlisting}[language=Python]
import math
import cmath

# Fonction simple de FFT inverse (en utilisant la propriete de symetrie)
def ifft_recursive(X):
    N = len(X)
    X_conj = [x.conjugate() for x in X]
    x_rec = fft_recursive(X_conj)
    return [x.conjugate() / N for x in x_rec]

# Signal = onde lente + bruit rapide
N = 16
t = [i for i in range(N)]
clean_signal = [math.cos(2 * math.pi * 1 * i / N) for i in t]
noise = [0.5 * math.cos(2 * math.pi * 7 * i / N) for i in t] # haute frequence
noisy_signal = [clean_signal[i] + noise[i] for i in range(N)]

# 1. FFT
X = fft_recursive(noisy_signal)

# 2. Filtrage passe-bas : on met a zero les coefficients pour les hautes frequences
# Les basses frequences sont aux extremites du tableau X (bins 0, 1 et N-1)
filtered_X = []
for k in range(N):
    if k > 2 and k < N - 2:
        filtered_X.append(0j)
    else:
        filtered_X.append(X[k])

# 3. IFFT
filtered_signal = ifft_recursive(filtered_X)

for i in range(5):
    print("t={}, Original={:.3f}, Bruite={:.3f}, Filtre={:.3f}".format(
        t[i], clean_signal[i], noisy_signal[i], filtered_signal[i].real))
\end{lstlisting}
