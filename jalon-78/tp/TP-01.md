# TP 1 : Calcul par la méthode des rectangles

Ce TP implémente l'intégration numérique par la méthode des rectangles pour calculer $a_n$ et $b_n$.

## 1. Objectif
Calculer de manière brute les coefficients de la série de Fourier d'un signal donné, sans librairies.

## 2. Implémentation

```python
import math

def f(t):
    # Signal créneau simple
    return 1.0 if (t % (2 * math.pi)) < math.pi else -1.0

def fourier_rectangles(f, n, num_points=1000):
    dt = 2 * math.pi / num_points
    an, bn = 0.0, 0.0
    for k in range(num_points):
        t = k * dt
        val = f(t)
        an += val * math.cos(n * t) * dt
        bn += val * math.sin(n * t) * dt
    return an / math.pi, bn / math.pi

an, bn = fourier_rectangles(f, 1)
assert abs(an) < 1e-2, "Le coefficient a1 doit être nul pour un créneau (fonction impaire)."
assert abs(bn - (4/math.pi)) < 1e-1, "Le coefficient b1 est erroné."
print("TP 1 : Rectangles OK")
```
