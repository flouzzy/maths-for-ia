## TP 3 : Fast Fourier Transform (FFT) algorithme de base


Nous implementons ici l'algorithme recursif de Cooley-Tukey pour le calcul de la Transformee de Fourier Rapide (FFT) en 1D. Cet algorithme fonctionne pour les tailles de signaux qui sont des puissances de 2.

\begin{lstlisting}[language=Python]
import cmath
import math

def fft_recursive(x):
    N = len(x)
    if N <= 1:
        return x

    even = fft_recursive(x[0::2])
    odd =  fft_recursive(x[1::2])

    T = [cmath.exp(-2j * math.pi * k / N) * odd[k] for k in range(N // 2)]

    result = [0j] * N
    for k in range(N // 2):
        result[k] = even[k] + T[k]
        result[k + N // 2] = even[k] - T[k]

    return result

# Creation d'un signal discret (N=8) compose de deux sinusoides
N = 8
t = [i for i in range(N)]
signal = [math.cos(2 * math.pi * 1 * i / N) + math.sin(2 * math.pi * 2 * i / N) for i in t]

X = fft_recursive(signal)
for k, X_k in enumerate(X):
    # Arrondi pour eviter les petits bruits numeriques
    real_part = round(X_k.real, 4)
    imag_part = round(X_k.imag, 4)
    print("Frequence bin {}: {} + {}j".format(k, real_part, imag_part))
\end{lstlisting}
