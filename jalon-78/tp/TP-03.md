# TP 3 : Calcul vectoriel des coefficients

Introduction à la logique qui précède la Transformée de Fourier Rapide (FFT) : le calcul vectoriel.

## 1. Objectif
Utiliser des listes compréhensives pour approcher le fonctionnement des bibliothèques matricielles, et mesurer la puissance du produit scalaire (dot product).

## 2. Implémentation

```python
import math

def dot_product(v1, v2):
    return sum(x * y for x, y in zip(v1, v2))

def fourier_vector(N_points, n_freq):
    dt = 2 * math.pi / N_points
    t_vec = [k * dt for k in range(N_points)]

    # Signal f(t) = t^2 (sur 0..2pi, périodisé, donc asymétrique)
    f_vec = [t**2 for t in t_vec]

    cos_vec = [math.cos(n_freq * t) for t in t_vec]
    sin_vec = [math.sin(n_freq * t) for t in t_vec]

    an = dot_product(f_vec, cos_vec) * dt / math.pi
    bn = dot_product(f_vec, sin_vec) * dt / math.pi
    return an, bn

an, bn = fourier_vector(1000, 1)
# Pour f(t) = t^2 sur [0, 2pi], b1 théorique = -4pi
assert abs(bn - (-4 * math.pi)) < 1e-1, "Erreur dans le produit scalaire pour bn."
print("TP 3 : Vecteurs OK")
```
