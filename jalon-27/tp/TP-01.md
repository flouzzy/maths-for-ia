# TP 01 : Implémentation de la transposition et vérification de la symétrie

## Objectif Mathématique
Implémenter une fonction Python pure pour transposer une matrice et vérifier si elle est symétrique.

## Code Python Pur

```python
def transpose(A):
    rows = len(A)
    cols = len(A[0])
    return [[A[i][j] for i in range(rows)] for j in range(cols)]

def is_symmetric(A):
    rows = len(A)
    cols = len(A[0])
    if rows != cols:
        return False
    for i in range(rows):
        for j in range(cols):
            if abs(A[i][j] - A[j][i]) > 1e-9:
                return False
    return True

# Validation
A_sym = [[1, 2], [2, 3]]
assert is_symmetric(A_sym), "A_sym est symétrique"

A_not_sym = [[1, 2], [3, 4]]
assert not is_symmetric(A_not_sym), "A_not_sym n'est pas symétrique"
print("TP 01 validé.")
```
