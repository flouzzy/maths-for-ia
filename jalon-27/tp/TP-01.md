# TP 1 : Vérification expérimentale de la symétrie et de l'isométrie en Python pur

## Objectif
Ce TP vise à réimplémenter l'algèbre linéaire de base (produit scalaire, produit matriciel, transposée) sans aucun framework tel que numpy, afin de valider algorithmiquement la définition mathématique d'une matrice symétrique ($A = A^T$) et d'une matrice orthogonale ($O O^T = I$).

## Code Python from scratch

```python
# tp_01_symetrie_isometrie.py

def dot_product(u, v):
    """Produit scalaire canonique dans R^n."""
    assert len(u) == len(v), "Les vecteurs doivent avoir la meme dimension."
    return sum(ui * vi for ui, vi in zip(u, v))

def transpose(mat):
    """Transpose une matrice representee par une liste de listes."""
    return [[mat[j][i] for j in range(len(mat))] for i in range(len(mat[0]))]

def mat_mul(A, B):
    """Multiplication matricielle standard O(n^3)."""
    rows_A = len(A)
    cols_A = len(A[0])
    rows_B = len(B)
    cols_B = len(B[0])
    assert cols_A == rows_B, "Dimensions incompatibles pour la multiplication."

    C = [[0] * cols_B for _ in range(rows_A)]
    for i in range(rows_A):
        for j in range(cols_B):
            C[i][j] = sum(A[i][k] * B[k][j] for k in range(cols_A))
    return C

def is_symmetric(A, tol=1e-9):
    """Verifie si une matrice est symetrique (A = A^T)."""
    if len(A) != len(A[0]): return False
    A_T = transpose(A)
    for i in range(len(A)):
        for j in range(len(A[0])):
            if abs(A[i][j] - A_T[i][j]) > tol:
                return False
    return True

def is_orthogonal(O, tol=1e-9):
    """Verifie si une matrice est orthogonale (O^T * O = I)."""
    O_T = transpose(O)
    I_approx = mat_mul(O_T, O)
    n = len(O)
    for i in range(n):
        for j in range(n):
            expected = 1.0 if i == j else 0.0
            if abs(I_approx[i][j] - expected) > tol:
                return False
    return True

if __name__ == "__main__":
    # Test d'une matrice symétrique
    A = [
        [2.0, -1.0,  0.5],
        [-1.0, 3.0,  1.2],
        [0.5,  1.2, -4.0]
    ]
    print(f"La matrice A est-elle symetrique ? {is_symmetric(A)}")

    # Test d'une matrice orthogonale (Rotation 2D de pi/4)
    import math
    theta = math.pi / 4
    c, s = math.cos(theta), math.sin(theta)
    R = [
        [c, -s],
        [s,  c]
    ]
    print(f"La matrice de rotation R est-elle orthogonale ? {is_orthogonal(R)}")
```

## Validation Mathématique
- La transposée algorithmique consiste à échanger les indices de boucle `i` et `j`. Mathématiquement, c'est l'opération de passage à l'opérateur adjoint dans la base canonique orthonormée.
- Le test d'orthogonalité force l'évaluation de $n^2$ produits scalaires entre les colonnes de la matrice, validant que l'ensemble forme une base orthonormée (vecteurs unitaires et deux à deux orthogonaux).
