# TP 5 : Régression Ridge et Matrices de Covariance Symétriques

## Objectif
Une des applications les plus fondamentales des matrices symétriques en Intelligence Artificielle est la matrice de covariance $X^T X$. Ce TP résout un problème d'optimisation convexe (Régression Ridge) en inversant algébriquement une matrice modifiée $(X^T X + \lambda I)$.

## Code Python from scratch

```python
# tp_05_ridge_regression.py

def transpose(mat):
    return [[mat[j][i] for j in range(len(mat))] for i in range(len(mat[0]))]

def mat_mul(A, B):
    rows_A = len(A)
    cols_A = len(A[0])
    rows_B = len(B)
    cols_B = len(B[0])
    C = [[0] * cols_B for _ in range(rows_A)]
    for i in range(rows_A):
        for j in range(cols_B):
            C[i][j] = sum(A[i][k] * B[k][j] for k in range(cols_A))
    return C

def identity_matrix(n):
    return [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]

def get_minor(m,i,j):
    return [row[:j] + row[j+1:] for row in (m[:i]+m[i+1:])]

def determinant(m):
    if len(m) == 2:
        return m[0][0]*m[1][1]-m[0][1]*m[1][0]
    det = 0
    for c in range(len(m)):
        det += ((-1)**c)*m[0][c]*determinant(get_minor(m,0,c))
    return det

def inverse(m):
    det = determinant(m)
    if len(m) == 2:
        return [[m[1][1]/det, -1*m[0][1]/det],
                [-1*m[1][0]/det, m[0][0]/det]]
    cofactors = []
    for r in range(len(m)):
        cofactorRow = []
        for c in range(len(m)):
            minor = get_minor(m,r,c)
            cofactorRow.append(((-1)**(r+c)) * determinant(minor))
        cofactors.append(cofactorRow)
    cofactors = transpose(cofactors)
    for r in range(len(cofactors)):
        for c in range(len(cofactors)):
            cofactors[r][c] = cofactors[r][c]/det
    return cofactors

def ridge_regression(X, y, l2_penalty):
    """
    Resout w = (X^T X + lambda I)^{-1} X^T y.
    Ici y est une matrice colonne n x 1.
    """
    n_features = len(X[0])

    # 1. Calcul de X^T X (matrice symetrique de covariance/Gram)
    X_T = transpose(X)
    XT_X = mat_mul(X_T, X)

    # 2. Ajout de la pénalité Ridge : lambda * I
    I = identity_matrix(n_features)
    for i in range(n_features):
        XT_X[i][i] += l2_penalty

    # 3. Inversion de (X^T X + lambda I)
    inv_mat = inverse(XT_X)

    # 4. Calcul final : inv_mat * X^T * y
    XT_y = mat_mul(X_T, y)
    w = mat_mul(inv_mat, XT_y)

    return w

if __name__ == "__main__":
    # Jeu de donnees simule
    # X : 3 echantillons, 2 caracteristiques
    X = [
        [1.0, 0.5],
        [1.0, 1.5],
        [1.0, 2.5]
    ]
    # y : cibles
    y = [
        [1.2],
        [2.1],
        [3.0]
    ]

    # lambda = 0 correspond à OLS pur. lambda > 0 regularise la solution.
    w_ols = ridge_regression(X, y, 0.0)
    w_ridge = ridge_regression(X, y, 0.1)

    print("Poids sans regularisation (lambda=0) :")
    for row in w_ols: print([round(v, 4) for v in row])

    print("\nPoids avec regularisation Ridge (lambda=0.1) :")
    for row in w_ridge: print([round(v, 4) for v in row])
```

## Validation Mathématique
- La matrice initiale $X^T X$ est la matrice de Gram. Comme démontré dans l'exercice 7, elle est toujours symétrique et positive (valeurs propres $\geq 0$).
- Cependant, si les colonnes de $X$ sont colinéaires (ou si l'on a moins d'échantillons que de features), $X^T X$ n'est pas inversible (la valeur propre 0 est présente).
- L'astuce de la régularisation Ridge ($\lambda > 0$) décale le spectre matriciel : les valeurs propres de $X^T X + \lambda I_n$ sont $\lambda_i + \lambda$.
- Puisque $\lambda_i \geq 0$, le nouveau spectre est strictement minoré par $\lambda > 0$. La matrice régularisée devient symétrique définie positive et est donc inconditionnellement inversible. Le problème est "bien posé" au sens de Hadamard.
