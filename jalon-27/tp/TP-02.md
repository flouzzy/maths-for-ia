# TP 2 : Diagonalisation d'une matrice symétrique par la méthode de Jacobi

## Objectif
Le théorème spectral stipule que toute matrice symétrique réelle est diagonalisable dans une base orthonormée. L'algorithme de Jacobi construit explicitement cette base en appliquant des rotations successives de Givens pour "annuler" itérativement les coefficients hors diagonale. Ce TP implémente cet algorithme itératif en Python pur.

## Code Python from scratch

```python
# tp_02_jacobi.py
import math

def identity_matrix(n):
    return [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]

def get_max_off_diag(A):
    """Trouve l'element non diagonal de plus grande valeur absolue."""
    n = len(A)
    max_val = -1.0
    p, q = 0, 1
    for i in range(n):
        for j in range(i+1, n):
            if abs(A[i][j]) > max_val:
                max_val = abs(A[i][j])
                p, q = i, j
    return p, q, max_val

def jacobi_eigenvalue_algorithm(A, tol=1e-9, max_iter=1000):
    """
    Diagonalise une matrice symetrique A.
    Retourne (D, V) ou D contient les valeurs propres sur la diagonale,
    et V est la matrice orthogonale des vecteurs propres.
    """
    n = len(A)
    # A_copy sera transformée en D
    D = [[A[i][j] for j in range(n)] for i in range(n)]
    V = identity_matrix(n)

    for _ in range(max_iter):
        p, q, max_val = get_max_off_diag(D)
        if max_val < tol:
            break

        # Calcul de l'angle de rotation theta
        if abs(D[p][p] - D[q][q]) < 1e-15:
            theta = math.pi / 4.0 if D[p][q] > 0 else -math.pi / 4.0
        else:
            phi = 2.0 * D[p][q] / (D[p][p] - D[q][q])
            theta = 0.5 * math.atan(phi)

        c = math.cos(theta)
        s = math.sin(theta)

        # Application de la rotation pour D' = J^T * D * J
        for i in range(n):
            if i != p and i != q:
                D_ip = D[i][p]
                D_iq = D[i][q]
                D[i][p] = c * D_ip - s * D_iq
                D[p][i] = D[i][p]
                D[i][q] = s * D_ip + c * D_iq
                D[q][i] = D[i][q]

        D_pp = D[p][p]
        D_qq = D[q][q]
        D[p][p] = c*c * D_pp - 2*s*c * D[p][q] + s*s * D_qq
        D[q][q] = s*s * D_pp + 2*s*c * D[p][q] + c*c * D_qq
        D[p][q] = 0.0
        D[q][p] = 0.0

        # Mise à jour des vecteurs propres V' = V * J
        for i in range(n):
            V_ip = V[i][p]
            V_iq = V[i][q]
            V[i][p] = c * V_ip - s * V_iq
            V[i][q] = s * V_ip + c * V_iq

    eigenvalues = [D[i][i] for i in range(n)]
    return eigenvalues, V

if __name__ == "__main__":
    A_sym = [
        [4.0, 1.0, 2.0],
        [1.0, 3.0, 0.0],
        [2.0, 0.0, 5.0]
    ]
    evals, evecs = jacobi_eigenvalue_algorithm(A_sym)
    print("Valeurs propres trouvees :", [round(e, 4) for e in evals])
    # Vérification empirique V est orthogonale (cf. TP1)
```

## Validation Mathématique
- La méthode de Jacobi s'appuie sur la conservation de la trace et de la norme de Frobenius sous similarité orthogonale. Chaque rotation transfère de "l'énergie" (somme des carrés) des éléments hors diagonale vers la diagonale.
- La convergence est prouvée mathématiquement vers une matrice purement diagonale. Les colonnes de la matrice $V$ accumulée forment une base orthonormée de vecteurs propres, illustrant parfaitement le Théorème Spectral.
