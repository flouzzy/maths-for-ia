# TP 3 : Calcul itératif de la plus grande valeur propre (Méthode de la Puissance)

## Objectif
Le quotient de Rayleigh et le théorème de Courant-Fischer (voir Exercices) lient la plus grande valeur propre d'une matrice symétrique au maximum d'une fonctionnelle quadratique. L'algorithme de la méthode de la puissance itérée illustre cela en convergeant vers la direction du sous-espace propre dominant.

## Code Python from scratch

```python
# tp_03_power_iteration.py
import math

def dot_product(u, v):
    return sum(ui * vi for ui, vi in zip(u, v))

def norm(u):
    return math.sqrt(sum(ui**2 for ui in u))

def mat_vec_mul(A, v):
    return [sum(A[i][j] * v[j] for j in range(len(v))) for i in range(len(A))]

def power_iteration(A, num_iterations=1000, tol=1e-9):
    """
    Calcule la valeur propre dominante et le vecteur propre associe
    d'une matrice symetrique A.
    """
    n = len(A)
    # Vecteur initial aléatoire (non nul)
    b_k = [1.0] * n

    # Normalisation initiale
    b_k_norm = norm(b_k)
    b_k = [x / b_k_norm for x in b_k]

    eigenvalue = 0.0

    for _ in range(num_iterations):
        # Multiplier par la matrice
        b_k1 = mat_vec_mul(A, b_k)

        # Calculer le quotient de Rayleigh R_A(b_k) = <A b_k, b_k> / <b_k, b_k>
        # Puisque b_k est unitaire, le dénominateur vaut 1.
        new_eigenvalue = dot_product(b_k1, b_k)

        # Normaliser le nouveau vecteur
        b_k1_norm = norm(b_k1)
        b_k1 = [x / b_k1_norm for x in b_k1]

        # Test de convergence
        if abs(new_eigenvalue - eigenvalue) < tol:
            break

        eigenvalue = new_eigenvalue
        b_k = b_k1

    return eigenvalue, b_k

if __name__ == "__main__":
    # Matrice symétrique
    A = [
        [2.0, 1.0],
        [1.0, 3.0]
    ]
    lam, vec = power_iteration(A)
    print(f"Valeur propre dominante : {lam:.4f}")
    print(f"Vecteur propre associe : {[round(v, 4) for v in vec]}")
```

## Validation Mathématique
- Si $A$ est symétrique, elle est diagonalisable. Un vecteur arbitraire $v$ se décompose en $v = \sum c_i e_i$. En appliquant $A^k$, on obtient $A^k v = \sum c_i \lambda_i^k e_i$.
- En normalisant à chaque étape, le terme correspondant à la plus grande valeur propre (en module) domine écrasamment (car $(\lambda_i / \lambda_{\max})^k \to 0$).
- L'évaluation via `dot_product(b_k1, b_k)` est exactement le quotient de Rayleigh $R_A(v) = \langle A v, v \rangle$, qui, d'après le théorème de Courant-Fischer, maximise la forme quadratique pour le vecteur propre dominant.
