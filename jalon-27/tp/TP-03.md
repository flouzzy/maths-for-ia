# TP 03 : Calcul de la trace et démonstration d'invariance par transposition

## Objectif Mathématique
Calculer la trace et vérifier qu'elle est invariante pour une matrice et sa transposée.

## Code Python Pur

```python
def trace(A):
    return sum(A[i][i] for i in range(len(A)))

def transpose(A):
    rows, cols = len(A), len(A[0])
    return [[A[i][j] for i in range(rows)] for j in range(cols)]

# Validation
M = [[1.5, 2.0, 3.1],
     [4.0, 5.5, 6.0],
     [7.2, 8.0, 9.9]]

tr_M = trace(M)
tr_Mt = trace(transpose(M))

assert abs(tr_M - tr_Mt) < 1e-9, "Trace de M doit être égale à Trace de M^T"
assert abs(tr_M - (1.5 + 5.5 + 9.9)) < 1e-9
print("TP 03 validé.")
```
