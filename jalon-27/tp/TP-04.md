# TP 4 : Décomposition Polaire par itérations de Newton

## Objectif
Le cours a démontré (Exo 6) l'existence et l'unicité de la décomposition polaire $A = O S$ pour une matrice inversible. En pratique, on peut calculer l'isométrie $O$ (le "miroir") sans calculer explicitement la racine carrée de $A^T A$, en utilisant une méthode itérative de Newton sur l'espace matriciel.

## Code Python from scratch

```python
# tp_04_polar_decomposition.py

def transpose(mat):
    return [[mat[j][i] for j in range(len(mat))] for i in range(len(mat[0]))]

def mat_mul(A, B):
    n = len(A)
    return [[sum(A[i][k] * B[k][j] for k in range(n)) for j in range(n)] for i in range(n)]

def mat_add(A, B):
    n = len(A)
    return [[A[i][j] + B[i][j] for j in range(n)] for i in range(n)]

def mat_scale(A, scalar):
    n = len(A)
    return [[A[i][j] * scalar for j in range(n)] for i in range(n)]

def get_minor(m,i,j):
    return [row[:j] + row[j+1:] for row in (m[:i]+m[i+1:])]

def determinant(m):
    if len(m) == 2:
        return m[0][0]*m[1][1]-m[0][1]*m[1][0]
    det = 0
    for c in range(len(m)):
        det += ((-1)**c)*m[0][c]*determinant(get_minor(m,0,c))
    return det

def inverse(m):
    det = determinant(m)
    assert det != 0, "La matrice doit etre inversible."
    if len(m) == 2:
        return [[m[1][1]/det, -1*m[0][1]/det],
                [-1*m[1][0]/det, m[0][0]/det]]
    cofactors = []
    for r in range(len(m)):
        cofactorRow = []
        for c in range(len(m)):
            minor = get_minor(m,r,c)
            cofactorRow.append(((-1)**(r+c)) * determinant(minor))
        cofactors.append(cofactorRow)
    cofactors = transpose(cofactors)
    for r in range(len(cofactors)):
        for c in range(len(cofactors)):
            cofactors[r][c] = cofactors[r][c]/det
    return cofactors

def polar_decomposition(A, tol=1e-8, max_iter=100):
    """
    Calcule la decomposition polaire A = O * S a l'aide de l'iteration de Newton :
    X_{k+1} = 0.5 * (X_k + (X_k^T)^{-1})
    """
    n = len(A)
    X = [[A[i][j] for j in range(n)] for i in range(n)]

    for _ in range(max_iter):
        X_inv = inverse(X)
        X_inv_T = transpose(X_inv)

        # Prochaine itération: X_next = 0.5 * (X + X_inv_T)
        X_next = mat_scale(mat_add(X, X_inv_T), 0.5)

        # Test de convergence empirique (norme max)
        diff = max(abs(X_next[i][j] - X[i][j]) for i in range(n) for j in range(n))
        X = X_next
        if diff < tol:
            break

    # O est la matrice orthogonale limite
    O = X
    # S = O^T * A
    S = mat_mul(transpose(O), A)
    return O, S

if __name__ == "__main__":
    A = [
        [3.0, 1.0],
        [0.0, 2.0]
    ]
    O, S = polar_decomposition(A)
    print("Matrice Orthogonale O :")
    for row in O: print([round(x, 4) for x in row])
    print("Matrice Symetrique Definie Positive S :")
    for row in S: print([round(x, 4) for x in row])
```

## Validation Mathématique
- L'itération $X_{k+1} = \frac{1}{2} (X_k + (X_k^T)^{-1})$ converge quadratiquement vers la composante unitaire (orthogonale) de la décomposition polaire de la matrice initiale.
- Si $X_k$ est une matrice orthogonale, alors $X_k^T = X_k^{-1}$, ce qui donne $X_{k+1} = \frac{1}{2} (X_k + X_k) = X_k$. La matrice orthogonale est bien un point fixe de cette itération.
- Une fois $O$ obtenue, $S$ est calculée par $O^T A$, et les mathématiques garantissent que cette construction produit une matrice $S$ strictement symétrique.
