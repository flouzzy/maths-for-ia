# TP 04 : Construire une matrice symétrique par A + A^T

## Objectif Mathématique
Montrer que toute matrice carrée A peut être décomposée en une partie symétrique $S = (A+A^T)/2$.

## Code Python Pur

```python
def transpose(A):
    rows, cols = len(A), len(A[0])
    return [[A[i][j] for i in range(rows)] for j in range(cols)]

def symmetric_part(A):
    rows, cols = len(A), len(A[0])
    At = transpose(A)
    return [[(A[i][j] + At[i][j]) / 2.0 for j in range(cols)] for i in range(rows)]

def is_symmetric(A):
    rows, cols = len(A), len(A[0])
    for i in range(rows):
        for j in range(cols):
            if abs(A[i][j] - A[j][i]) > 1e-9:
                return False
    return True

# Validation
M = [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]]

S = symmetric_part(M)
assert is_symmetric(S), "La partie symétrique doit être parfaitement symétrique"
print("TP 04 validé.")
```
