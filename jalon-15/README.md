# Jalon 15 : Sous-suites, valeurs d'adhérence et preuve par séparation du théorème de Bolzano-Weierstrass

## Statut
🔥 **Enrichi** *(10 Exos + 5 TP)*

## Description
Ce jalon introduit formellement la notion de sous-suites, les valeurs d'adhérence et démontre le théorème fondamental de Bolzano-Weierstrass par la méthode de dichotomie. Ce théorème est crucial pour garantir l'existence d'un optimum dans les algorithmes d'apprentissage en Intelligence Artificielle.
