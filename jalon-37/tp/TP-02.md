# TP 2 : Implémentation Numérique de l'Intégrale de Riemann

## 1. Objectif du TP
L'objectif est d'implémenter rigoureusement les concepts formels d'intégration étudiés dans le cours, sans utiliser aucune bibliothèque externe de calcul numérique (pas de numpy ou scipy).

## 2. Implémentation Python

```python
def trapezoidal_rule(f, a, b, n):
    """
    Approximation de l'intégrale par la méthode des trapèzes.
    """
    dx = (b - a) / n
    total = 0.5 * (f(a) + f(b))

    for i in range(1, n):
        x_i = a + i * dx
        total += f(x_i)

    return total * dx

if __name__ == "__main__":
    def g(x): return x**3
    # Exacte = 1/4 = 0.25
    approx = trapezoidal_rule(g, 0, 1, 1000)
    print(f"Méthode des trapèzes : {approx}")
    assert abs(approx - 0.25) < 1e-4
```

## 3. Lien Théorique
Ce code transcrit l'approche formelle des sommes de Darboux et de Riemann en un algorithme discret, en respectant rigoureusement la définition d'une subdivision.
