# TP 1 : Implémentation Numérique de l'Intégrale de Riemann

## 1. Objectif du TP
L'objectif est d'implémenter rigoureusement les concepts formels d'intégration étudiés dans le cours, sans utiliser aucune bibliothèque externe de calcul numérique (pas de numpy ou scipy).

## 2. Implémentation Python

```python
def riemann_sum_left(f, a, b, n):
    """
    Calcule l'approximation de l'intégrale de f sur [a, b]
    par la méthode des rectangles à gauche avec n sous-intervalles.
    """
    assert b > a, "L'intervalle doit être orienté de gauche à droite."
    assert n > 0, "Le nombre de sous-intervalles doit être strictement positif."

    dx = (b - a) / n
    total = 0.0
    for i in range(n):
        x_i = a + i * dx
        total += f(x_i) * dx

    return total

if __name__ == "__main__":
    def f(x): return x**2
    # L'intégrale exacte est 1/3 ~ 0.3333...
    approx = riemann_sum_left(f, 0, 1, 1000)
    print(f"Approximation des rectangles à gauche : {approx}")
    assert abs(approx - 1/3) < 1e-2
```

## 3. Lien Théorique
Ce code transcrit l'approche formelle des sommes de Darboux et de Riemann en un algorithme discret, en respectant rigoureusement la définition d'une subdivision.
