# TP 3 : Implémentation Numérique de l'Intégrale de Riemann

## 1. Objectif du TP
L'objectif est d'implémenter rigoureusement les concepts formels d'intégration étudiés dans le cours, sans utiliser aucune bibliothèque externe de calcul numérique (pas de numpy ou scipy).

## 2. Implémentation Python

```python
def simpson_rule(f, a, b, n):
    """
    Approximation par la méthode de Simpson (n doit être pair).
    """
    if n % 2 != 0:
        n += 1

    dx = (b - a) / n
    total = f(a) + f(b)

    for i in range(1, n, 2):
        total += 4 * f(a + i * dx)

    for i in range(2, n, 2):
        total += 2 * f(a + i * dx)

    return total * dx / 3.0

if __name__ == "__main__":
    def h(x): return x**4
    # Exacte = 1/5 = 0.2
    approx = simpson_rule(h, 0, 1, 10)
    print(f"Méthode de Simpson : {approx}")
    assert abs(approx - 0.2) < 1e-6
```

## 3. Lien Théorique
Ce code transcrit l'approche formelle des sommes de Darboux et de Riemann en un algorithme discret, en respectant rigoureusement la définition d'une subdivision.
