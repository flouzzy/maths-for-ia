# TP 4 : Implémentation Numérique de l'Intégrale de Riemann

## 1. Objectif du TP
L'objectif est d'implémenter rigoureusement les concepts formels d'intégration étudiés dans le cours, sans utiliser aucune bibliothèque externe de calcul numérique (pas de numpy ou scipy).

## 2. Implémentation Python

```python
def darboux_sums(f, a, b, n):
    """
    Calcule les sommes de Darboux inférieures et supérieures pour une fonction monotone.
    """
    dx = (b - a) / n
    s_inf = 0.0
    s_sup = 0.0

    for i in range(n):
        x_left = a + i * dx
        x_right = a + (i + 1) * dx
        # Pour f croissante
        s_inf += f(x_left) * dx
        s_sup += f(x_right) * dx

    return s_inf, s_sup

if __name__ == "__main__":
    def f(x): return x**2
    inf, sup = darboux_sums(f, 0, 1, 100)
    print(f"S_inf: {inf}, S_sup: {sup}")
    assert inf <= 1/3 <= sup
```

## 3. Lien Théorique
Ce code transcrit l'approche formelle des sommes de Darboux et de Riemann en un algorithme discret, en respectant rigoureusement la définition d'une subdivision.
