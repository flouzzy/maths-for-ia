# TP 5 : Implémentation Numérique de l'Intégrale de Riemann

## 1. Objectif du TP
L'objectif est d'implémenter rigoureusement les concepts formels d'intégration étudiés dans le cours, sans utiliser aucune bibliothèque externe de calcul numérique (pas de numpy ou scipy).

## 2. Implémentation Python

```python
def compute_pi_via_integral(n):
    """
    Calcule une approximation de Pi en utilisant l'intégrale de 4/(1+x^2) de 0 à 1.
    """
    def f(x): return 4.0 / (1.0 + x*x)
    dx = 1.0 / n
    total = 0.0

    # Évaluation au point milieu
    for i in range(n):
        x_mid = (i + 0.5) * dx
        total += f(x_mid) * dx

    return total

if __name__ == "__main__":
    pi_approx = compute_pi_via_integral(1000)
    print(f"Approximation de Pi : {pi_approx}")
    assert abs(pi_approx - 3.14159) < 1e-3
```

## 3. Lien Théorique
Ce code transcrit l'approche formelle des sommes de Darboux et de Riemann en un algorithme discret, en respectant rigoureusement la définition d'une subdivision.
