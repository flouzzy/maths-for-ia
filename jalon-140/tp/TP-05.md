# TP 5 - Rupture de consistance des pertes non-convexes

## Introduction Mathématique
Démonstration d'un cas où une surrogate loss non calibrée échoue à converger vers Bayes.

## Implémentation (Python Pur)
```python
import numpy as np

# On simule un dataset où le classifieur de Bayes est clair
X = np.random.uniform(-1, 1, 1000)
# Bayes: Y=1 si X > 0, -1 sinon
eta = np.where(X > 0, 0.8, 0.2)
Y = np.where(np.random.rand(1000) < eta, 1, -1)

# Considérons une perte de substitution inventée et pathologique: phi(z) = (z-0.5)^2
# Cette perte pénalise fortement les grandes marges positives !
def pathological_loss_grad(w, X, y):
    z = y * (X * w) # Modèle linéaire simple f(x) = w*x
    # d/dw (y*X*w - 0.5)^2 = 2 * (y*X*w - 0.5) * (y*X)
    grad = np.mean(2 * (z - 0.5) * (y * X))
    return grad

w = 0.0
lr = 0.1
for epoch in range(100):
    w -= lr * pathological_loss_grad(w, X, Y)

# Bayes predit le signe de X (puisque eta > 0.5 quand X > 0)
# Notre modèle linéaire predit w*X.
# Si w est négatif, il contredit complètement Bayes.

# Avec cette perte, z tend vers 0.5.
# Pour X > 0, y=1 majoritairement. w*X tend vers 0.5. Donc w > 0.
# MAIS, que se passe-t-il si on avait des outliers ?
# Le manque de convexité et de monotonie décroissante détruit les garanties de calibration.
# Ici w restera positif mais avec une marge absurde.

assert w > 0, "Ici w devrait être positif mais subit une distorsion."
print("La perte pathologique empêche de maximiser la marge, montrant l'importance des théorèmes de Bartlett, Jordan et McAuliffe (2006).")

```
