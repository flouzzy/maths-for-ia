# TP 3 - Calibration et Inégalité de Zhang Empirique

## Introduction Mathématique
Vérification empirique de la relation entre excès de risque 0-1 et excès de risque phi.

## Implémentation (Python Pur)
```python
import numpy as np

# On simule la fonction eta(x) uniformément sur [0, 1]
eta = np.linspace(0.01, 0.99, 100)

# Risque de Bayes conditionnel C*
C_star = np.minimum(eta, 1 - eta)

# Pertes pour une prédiction v (disons v = 1 pour un x donné)
# Surrogate logistique
phi_1 = np.log2(1 + np.exp(-1))
phi_minus_1 = np.log2(1 + np.exp(1))

# Risque phi conditionnel pour v=1
C_phi_v1 = eta * phi_1 + (1 - eta) * phi_minus_1

# Infimum du risque phi conditionnel H_phi(eta) (Entropie binaire)
H_phi = -eta * np.log2(eta) - (1 - eta) * np.log2(1 - eta)

# Excès de risque phi conditionnel pour v=1
delta_C_phi = C_phi_v1 - H_phi

# Excès de risque 0-1 conditionnel pour v=1
# C(1, x) = P(Y=-1|x) = 1-eta
C_v1 = 1 - eta
delta_C = C_v1 - C_star

# Inégalité de Zhang (Transformée de calibration pour phi = log_2(1+exp(-x)))
# delta_C_phi >= (1 / (2*ln(2))) * delta_C^2
borne_inf = (1 / (2 * np.log(2))) * (delta_C ** 2)

# Assertion mathématique: La calibration doit être respectée strictement
assert np.all(delta_C_phi >= borne_inf - 1e-7), "L'inégalité de Zhang est violée !"
print("Validation empirique : L'excès de risque surrogate majore bien le carré de l'excès de risque 0-1 à constante près.")

```
