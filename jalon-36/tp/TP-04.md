# TP 4 : Reconstruction matricielle de rang k (Théorème d'Eckart-Young)

L'objectif de ce TP est d'implémenter de manière purement algorithmique (from scratch, en Python sans bibliothèques de haut niveau) des briques fondamentales liées à la SVD, pour asseoir la compréhension théorique.

```python
import math

# --- UTILS Briques d'Algèbre Linéaire ---
def transpose(mat):
    return [[mat[j][i] for j in range(len(mat))] for i in range(len(mat[0]))]

def matmul(A, B):
    m = len(A)
    n = len(B[0])
    p = len(B)
    C = [[0] * n for _ in range(m)]
    for i in range(m):
        for j in range(n):
            for k in range(p):
                C[i][j] += A[i][k] * B[k][j]
    return C

# --- IMPLEMENTATION SPECIFIQUE TP 4 ---

def reconstruct_k(U, S, V_T, k):
    m = len(U)
    n = len(V_T[0])
    A_k = [[0.0]*n for _ in range(m)]

    for i in range(m):
        for j in range(n):
            val = 0.0
            for l in range(k):
                val += U[i][l] * S[l] * V_T[l][j]
            A_k[i][j] = val
    return A_k
```
