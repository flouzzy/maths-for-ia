# TP 3 : Calcul du rang effectif par seuillage des valeurs singulières

L'objectif de ce TP est d'implémenter de manière purement algorithmique (from scratch, en Python sans bibliothèques de haut niveau) des briques fondamentales liées à la SVD, pour asseoir la compréhension théorique.

```python
import math

# --- UTILS Briques d'Algèbre Linéaire ---
def transpose(mat):
    return [[mat[j][i] for j in range(len(mat))] for i in range(len(mat[0]))]

def matmul(A, B):
    m = len(A)
    n = len(B[0])
    p = len(B)
    C = [[0] * n for _ in range(m)]
    for i in range(m):
        for j in range(n):
            for k in range(p):
                C[i][j] += A[i][k] * B[k][j]
    return C

# --- IMPLEMENTATION SPECIFIQUE TP 3 ---

def effective_rank(singular_values, epsilon=1e-7):
    # Compte le nombre de valeurs singulières strictement supérieures à epsilon
    rank = 0
    for s in singular_values:
        if s > epsilon:
            rank += 1
    return rank
```
