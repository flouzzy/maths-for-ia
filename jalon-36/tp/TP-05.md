# TP 5 : Calcul de l'erreur de compression (Norme de Frobenius)

L'objectif de ce TP est d'implémenter de manière purement algorithmique (from scratch, en Python sans bibliothèques de haut niveau) des briques fondamentales liées à la SVD, pour asseoir la compréhension théorique.

```python
import math

# --- UTILS Briques d'Algèbre Linéaire ---
def transpose(mat):
    return [[mat[j][i] for j in range(len(mat))] for i in range(len(mat[0]))]

def matmul(A, B):
    m = len(A)
    n = len(B[0])
    p = len(B)
    C = [[0] * n for _ in range(m)]
    for i in range(m):
        for j in range(n):
            for k in range(p):
                C[i][j] += A[i][k] * B[k][j]
    return C

# --- IMPLEMENTATION SPECIFIQUE TP 5 ---

def frobenius_error(singular_values, k):
    # D'après le théorème d'Eckart-Young, l'erreur est la racine de la somme des carrés
    # des valeurs singulières ignorées
    error_sq = 0.0
    for i in range(k, len(singular_values)):
        error_sq += singular_values[i] ** 2
    return math.sqrt(error_sq)
```
