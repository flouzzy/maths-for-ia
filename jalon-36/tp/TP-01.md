# TP 1 : Implémentation de l'itération de puissance pour extraire $\sigma_1$

L'objectif de ce TP est d'implémenter de manière purement algorithmique (from scratch, en Python sans bibliothèques de haut niveau) des briques fondamentales liées à la SVD, pour asseoir la compréhension théorique.

```python
import math

# --- UTILS Briques d'Algèbre Linéaire ---
def transpose(mat):
    return [[mat[j][i] for j in range(len(mat))] for i in range(len(mat[0]))]

def matmul(A, B):
    m = len(A)
    n = len(B[0])
    p = len(B)
    C = [[0] * n for _ in range(m)]
    for i in range(m):
        for j in range(n):
            for k in range(p):
                C[i][j] += A[i][k] * B[k][j]
    return C

# --- IMPLEMENTATION SPECIFIQUE TP 1 ---

def power_iteration(A, num_simulations=100):
    n = len(A)
    b_k = [1.0] * n
    for _ in range(num_simulations):
        b_k1 = [sum(A[i][j] * b_k[j] for j in range(n)) for i in range(n)]
        norm = math.sqrt(sum(x*x for x in b_k1))
        b_k = [x / norm for x in b_k1]

    Ab_k = [sum(A[i][j] * b_k[j] for j in range(n)) for i in range(n)]
    eigenvalue = sum(b_k[i] * Ab_k[i] for i in range(n))
    return b_k, eigenvalue
```
