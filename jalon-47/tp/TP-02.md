# TP 2 : Approximation numérique de la Hessienne par différences finies

Calculer une dérivée seconde analytiquement peut être fastidieux. Ce TP propose d'écrire un algorithme général pour approcher la matrice hessienne $2	imes2$.

```python
# tp2_hessian_approx.py

def compute_hessian_2d(f, x, y, epsilon=1e-4):
    """Calcule la hessienne de f(x, y) par approximation des différences finies (schéma centré)."""

    # Dérivée seconde par rapport à x
    dxx = (f(x+epsilon, y) - 2*f(x, y) + f(x-epsilon, y)) / (epsilon**2)

    # Dérivée seconde par rapport à y
    dyy = (f(x, y+epsilon) - 2*f(x, y) + f(x, y-epsilon)) / (epsilon**2)

    # Dérivée croisée xy
    dxy = (f(x+epsilon, y+epsilon) - f(x+epsilon, y-epsilon) - f(x-epsilon, y+epsilon) + f(x-epsilon, y-epsilon)) / (4*epsilon**2)

    # Matrice hessienne (symétrique par le théorème de Schwarz)
    return [[dxx, dxy], [dxy, dyy]]

if __name__ == "__main__":
    # Test avec la fonction de Rosenbrock simplifiée
    def f_rosen(x, y):
        return (1-x)**2 + 100*(y-x**2)**2

    H = compute_hessian_2d(f_rosen, 1.0, 1.0)

    # Validation par rapport aux valeurs théoriques du cours
    assert abs(H[0][0] - 802.0) < 1e-1, "H_xx incorrect"
    assert abs(H[1][1] - 200.0) < 1e-1, "H_yy incorrect"
    assert abs(H[0][1] - (-400.0)) < 1e-1, "H_xy croisée incorrecte"

    print("TP 2 validé : Approximation de la Hessienne précise.")
```
