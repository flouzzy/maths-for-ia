# TP 1 : Implémentation d'une fonction 2D et de son gradient exact

L'objectif de ce TP est d'implémenter la fonction de parabolöide elliptique classique et son gradient analytique en Python sans utiliser NumPy, puis de valider l'implémentation.

```python
# tp1_gradient_exact.py

def f(x, y):
    """Calcule f(x, y) = x^2 + 4y^2."""
    return x**2 + 4*y**2

def grad_f(x, y):
    """Calcule analytiquement le gradient de f en (x, y)."""
    return [2*x, 8*y]

if __name__ == "__main__":
    # Test au point (2, 1)
    val = f(2, 1)
    grad = grad_f(2, 1)

    # Assertions de validation
    assert val == 8, "Erreur dans le calcul de la fonction"
    assert grad == [4, 8], "Erreur dans le calcul analytique du gradient"

    print("TP 1 validé : La fonction et le gradient sont corrects.")
```
