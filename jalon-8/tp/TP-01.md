# TP 1 : Exploration du Noyau et de l'Image d'une Application Linéaire

## Objectif
Ce Travail Pratique vise à consolider la compréhension des concepts d'application linéaire, de noyau ($\ker f$), d'image ($\text{Im } f$) et du théorème du rang. Nous allons implémenter une application linéaire simple en Python, puis utiliser cette implémentation pour explorer son noyau et son image, et enfin vérifier le théorème du rang sur cet exemple. L'objectif est de traduire les définitions formelles en code fonctionnel, sans utiliser de bibliothèques mathématiques avancées.

## Implémentation Python (From Scratch)

```python
# --- Fonctions utilitaires pour les vecteurs ---

def vector_add(v1, v2):
    """
    Additionne deux vecteurs.
    Les vecteurs sont représentés comme des listes de nombres.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la même dimension pour l'addition.")
    return [v1[i] + v2[i] for i in range(len(v1))]

def scalar_mult(scalar, vec):
    """
    Multiplie un vecteur par un scalaire.
    """
    return [scalar * x for x in vec]

def is_zero_vector(vec, tolerance=1e-9):
    """
    Vérifie si un vecteur est le vecteur nul, avec une tolérance pour les flottants.
    """
    return all(abs(x) < tolerance for x in vec)

def are_vectors_equal(v1, v2, tolerance=1e-9):
    """
    Vérifie si deux vecteurs sont égaux, avec une tolérance.
    """
    if len(v1) != len(v2):
        return False
    return all(abs(v1[i] - v2[i]) < tolerance for i in range(len(v1)))

# --- Définition de l'application linéaire de l'Exercice 1 du cours ---

def f_exercise_1(vec):
    """
    Définit l'application linéaire f: R^3 -> R^2 par f(x,y,z) = (x+y, y+z).
    vec est une liste de 3 éléments [x, y, z].
    Retourne une liste de 2 éléments [x+y, y+z].
    """
    if len(vec) != 3:
        raise ValueError("L'application f_exercise_1 attend un vecteur de dimension 3.")
    x, y, z = vec
    return [x + y, y + z]

# --- Fonctions pour le noyau et l'image ---

def check_vector_in_kernel(f, vec):
    """
    Vérifie si un vecteur appartient au noyau d'une application linéaire f.
    Un vecteur v est dans ker(f) si f(v) est le vecteur nul de l'espace d'arrivée.
    """
    return is_zero_vector(f(vec))

def get_image_generators(f, basis_E):
    """
    Calcule les images des vecteurs d'une base de l'espace de départ E.
    Ces images sont des vecteurs générateurs de l'image de f.
    f: l'application linéaire.
    basis_E: une liste de vecteurs (listes de nombres) formant une base de E.
    Retourne une liste des vecteurs images.
    """
    return [f(v) for v in basis_E]

# --- Vérification de la linéarité (illustrative) ---

def check_linearity_illustrative(f, dim_E, dim_F, num_tests=5):
    """
    Vérifie de manière illustrative (non exhaustive) la linéarité de f.
    Génère des vecteurs et scalaires aléatoires pour tester l'additivité et l'homogénéité.
    """
    import random
    print(f"\n--- Vérification illustrative de la linéarité de {f.__name__} ---")
    for _ in range(num_tests):
        # Générer des vecteurs aléatoires dans E
        v1 = [random.uniform(-10, 10) for _ in range(dim_E)]
        v2 = [random.uniform(-10, 10) for _ in range(dim_E)]

        # Générer un scalaire aléatoire
        lambda_scalar = random.uniform(-10, 10)

        # Test d'additivité: f(v1 + v2) == f(v1) + f(v2)
        f_v1_plus_v2 = f(vector_add(v1, v2))
        f_v1_plus_f_v2 = vector_add(f(v1), f(v2))
        assert are_vectors_equal(f_v1_plus_v2, f_v1_plus_f_v2), \
            f"Erreur d'additivité: f({v1}+{v2})={f_v1_plus_v2} != f({v1})+f({v2})={f_v1_plus_f_v2}"

        # Test d'homogénéité: f(lambda * v1) == lambda * f(v1)
        f_lambda_v1 = f(scalar_mult(lambda_scalar, v1))
        lambda_f_v1 = scalar_mult(lambda_scalar, f(v1))
        assert are_vectors_equal(f_lambda_v1, lambda_f_v1), \
            f"Erreur d'homogénéité: f({lambda_scalar}*{v1})={f_lambda_v1} != {lambda_scalar}*f({v1})={lambda_f_v1}"

    print(f"La linéarité de {f.__name__} a été vérifiée sur {num_tests} exemples aléatoires.")


# --- Exécution et tests pour l'Exercice 1 ---

if __name__ == "__main__":
    print("--- TP 1 : Exploration du Noyau et de l'Image ---")

    # 1. Vérification illustrative de la linéarité de f_exercise_1
    check_linearity_illustrative(f_exercise_1, dim_E=3, dim_F=2)

    # 2. Exploration du Noyau de f_exercise_1
    print("\n--- Exploration du Noyau ---")
    # D'après l'analyse de l'Exercice 1 du cours, ker(f) = Vect((-1, 1, -1))
    candidate_kernel_vector = [-1, 1, -1]

    print(f"Test du vecteur {candidate_kernel_vector} pour le noyau...")
    is_in_ker = check_vector_in_kernel(f_exercise_1, candidate_kernel_vector)
    print(f"Le vecteur {candidate_kernel_vector} est dans le noyau : {is_in_ker}")
    assert is_in_ker, "Le vecteur (-1, 1, -1) devrait être dans le noyau."

    # Test d'un vecteur qui ne devrait PAS être dans le noyau
    not_in_kernel_vector = [1, 0, 0]
    print(f"Test du vecteur {not_in_kernel_vector} pour le noyau...")
    is_not_in_ker = check_vector_in_kernel(f_exercise_1, not_in_kernel_vector)
    print(f"Le vecteur {not_in_kernel_vector} est dans le noyau : {is_not_in_ker}")
    assert not is_not_in_ker, "Le vecteur (1, 0, 0) ne devrait PAS être dans le noyau."

    # 3. Exploration de l'Image de f_exercise_1
    print("\n--- Exploration de l'Image ---")
    # Base canonique de R^3
    basis_R3 = [[1, 0, 0], [0, 1, 0], [0, 0, 1]]
    print(f"Base de l'espace de départ R^3 : {basis_R3}")

    image_generators = get_image_generators(f_exercise_1, basis_R3)
    print(f"Vecteurs générateurs de l'image (images des vecteurs de base) : {image_generators}")

    # D'après l'analyse de l'Exercice 1 du cours:
    # f(1,0,0) = (1,0)
    # f(0,1,0) = (1,1)
    # f(0,0,1) = (0,1)
    # Ces vecteurs génèrent Im(f).
    # On peut vérifier que (1,0) et (0,1) forment une base de R^2.
    # (1,1) = (1,0) + (0,1), donc il est linéairement dépendant des deux autres.

    # Vérification des images calculées
    assert are_vectors_equal(f_exercise_1([1, 0, 0]), [1, 0]), "f(1,0,0) incorrect."
    assert are_vectors_equal(f_exercise_1([0, 1, 0]), [1, 1]), "f(0,1,0) incorrect."
    assert are_vectors_equal(f_exercise_1([0, 0, 1]), [0, 1]), "f(0,0,1) incorrect."

    print("\n--- Résumé et Théorème du Rang ---")
    # Dimensions déduites de l'analyse mathématique (comme dans le cours)
    dim_E = 3 # Dimension de R^3
    dim_ker_f = 1 # Dimension du noyau (Vect((-1,1,-1)))
    dim_im_f = 2  # Dimension de l'image (Vect((1,0), (0,1)) = R^2)

    print(f"Dimension de l'espace de départ E (R^3) : {dim_E}")
    print(f"Dimension du noyau de f (dim(ker f)) : {dim_ker_f}")
    print(f"Dimension de l'image de f (rg f) : {dim_im_f}")

    # Vérification du Théorème du Rang
    print(f"Vérification du Théorème du Rang : dim(E) = dim(ker f) + rg(f)")
    print(f"{dim_E} = {dim_ker_f} + {dim_im_f}")
    assert dim_E == dim_ker_f + dim_im_f, "Le Théorème du Rang n'est pas vérifié !"
    print("Le Théorème du Rang est vérifié pour cette application linéaire.")

    print("\nTP 1 terminé avec succès.")
```

## Validation Mathématique

Le code Python ci-dessus implémente l'application linéaire $f: \mathbb{R}^3 \to \mathbb{R}^2$ définie par $f(x,y,z) = (x+y, y+z)$, telle que présentée dans l'Exercice 1 du Jalon 8.

1.  **Vérification de la Linéarité (`check_linearity_illustrative`) :**
    *   La fonction `check_linearity_illustrative` teste les deux propriétés fondamentales d'une application linéaire : l'additivité ($f(u+v) = f(u) + f(v)$) et l'homogénéité ($f(\lambda u) = \lambda f(u)$).
    *   Elle génère des vecteurs et scalaires aléatoires et utilise des assertions pour s'assurer que les égalités sont respectées. Bien que non exhaustive, cette vérification renforce la confiance dans la correcte implémentation de $f$.

2.  **Exploration du Noyau (`check_vector_in_kernel`) :**
    *   **Définition :** $\ker f = \{ x \in E \mid f(x) = 0_F \}$.
    *   Pour $f(x,y,z) = (x+y, y+z)$, on cherche $(x,y,z)$ tel que $x+y=0$ et $y+z=0$.
    *   Cela implique $x = -y$ et $z = -y$.
    *   Ainsi, les vecteurs du noyau sont de la forme $(-y, y, -y) = y(-1, 1, -1)$.
    *   Le noyau est donc la droite vectorielle engendrée par le vecteur $v_k = (-1, 1, -1)$.
    *   **Dimension du noyau :** $\dim(\ker f) = 1$.
    *   Le code vérifie avec `check_vector_in_kernel(f_exercise_1, [-1, 1, -1])` que $f(-1,1,-1) = (-1+1, 1-1) = (0,0)$, confirmant que $v_k$ appartient bien au noyau. L'assertion `assert is_in_ker` valide ce point.

3.  **Exploration de l'Image (`get_image_generators`) :**
    *   **Définition :** $\text{Im } f = \{ f(x) \mid x \in E \}$. L'image est engendrée par les images des vecteurs d'une base de $E$.
    *   Nous utilisons la base canonique de $\mathbb{R}^3$: $e_1=(1,0,0)$, $e_2=(0,1,0)$, $e_3=(0,0,1)$.
    *   Le code calcule :
        *   $f(e_1) = f(1,0,0) = (1+0, 0+0) = (1,0)$
        *   $f(e_2) = f(0,1,0) = (0+1, 1+0) = (1,1)$
        *   $f(e_3) = f(0,0,1) = (0+0, 0+1) = (0,1)$
    *   Les vecteurs $(1,0)$, $(1,1)$, $(0,1)$ sont des générateurs de $\text{Im } f$.
    *   Dans $\mathbb{R}^2$, les vecteurs $(1,0)$ et $(0,1)$ sont linéairement indépendants et forment une base de $\mathbb{R}^2$. Le vecteur $(1,1)$ est une combinaison linéaire de $(1,0)$ et $(0,1)$ ($ (1,1) = 1 \cdot (1,0) + 1 \cdot (0,1) $).
    *   Donc, $\text{Im } f = \text{Vect}((1,0), (0,1)) = \mathbb{R}^2$.
    *   **Dimension de l'image (Rang) :** $\text{rg } f = \dim(\text{Im } f) = 2$.
    *   Les assertions vérifient que les images calculées par le code correspondent aux résultats attendus.

4.  **Théorème du Rang :**
    *   Le théorème du rang stipule que pour un espace vectoriel $E$ de dimension finie, $\dim E = \dim(\ker f) + \text{rg}(f)$.
    *   Dans notre cas :
        *   $\dim E = \dim(\mathbb{R}^3) = 3$.
        *   $\dim(\ker f) = 1$.
        *   $\text{rg}(f) = 2$.
    *   Le code vérifie l'égalité $3 = 1 + 2$. L'assertion `assert dim_E == dim_ker_f + dim_im_f` confirme que le théorème du rang est bien respecté pour cette application linéaire.

Ce TP démontre comment les concepts abstraits de l'algèbre linéaire peuvent être concrétisés et vérifiés par une implémentation simple en Python, renforçant ainsi la compréhension des relations entre le noyau, l'image et la dimension des espaces vectoriels.
