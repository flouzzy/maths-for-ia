# TP 2 : Noyau, Image et Théorème du Rang d'une Application Linéaire

## Objectif
L'objectif de ce Travail Pratique est d'implémenter, à partir de zéro et sans l'aide de bibliothèques de calcul numérique avancées (comme NumPy), les algorithmes permettant de déterminer le noyau (ker), l'image (Im) et de vérifier le théorème du rang pour une application linéaire donnée par sa matrice. Ce TP renforcera la compréhension des concepts fondamentaux de l'algèbre linéaire en les traduisant en code Python.

## Implémentation Python (From Scratch)

```python
import math

# Constante pour gérer les comparaisons de nombres flottants à zéro
EPSILON = 1e-9

def _is_zero(val):
    """Vérifie si une valeur flottante est approximativement zéro."""
    return abs(val) < EPSILON

def _swap_rows(matrix, r1, r2):
    """Échange deux lignes dans une matrice."""
    matrix[r1], matrix[r2] = matrix[r2], matrix[r1]

def _scale_row(matrix, r, scalar):
    """Multiplie une ligne par un scalaire."""
    if _is_zero(scalar):
        raise ValueError("Cannot scale row by zero.")
    matrix[r] = [val / scalar for val in matrix[r]]

def _add_scaled_row(matrix, r_target, r_source, scalar):
    """Ajoute un multiple scalaire d'une ligne source à une ligne cible."""
    matrix[r_target] = [matrix[r_target][i] + scalar * matrix[r_source][i] for i in range(len(matrix[r_target]))]

def gaussian_elimination(matrix_input):
    """
    Réduit une matrice à sa forme échelonnée réduite (RREF) en utilisant l'élimination de Gauss-Jordan.
    Retourne une nouvelle matrice (copie profonde), ne modifie pas l'entrée.
    """
    matrix = [list(row) for row in matrix_input] # Crée une copie profonde de la matrice
    num_rows = len(matrix)
    if num_rows == 0:
        return []
    num_cols = len(matrix[0])
    if num_cols == 0:
        return [[] for _ in range(num_rows)]

    lead = 0 # Indice de la colonne pivot
    for r in range(num_rows):
        if lead >= num_cols:
            break

        i = r
        # Trouver une ligne non nulle pour la colonne pivot actuelle
        while i < num_rows and _is_zero(matrix[i][lead]):
            i += 1

        if i < num_rows:
            _swap_rows(matrix, i, r) # Placer la ligne non nulle en position r

            # Normaliser la ligne pivot (rendre le pivot égal à 1)
            _scale_row(matrix, r, matrix[r][lead])

            # Éliminer les autres éléments de la colonne pivot
            for j in range(num_rows):
                if j != r: # Pour toutes les autres lignes
                    _add_scaled_row(matrix, j, r, -matrix[j][lead])
            lead += 1 # Passer à la colonne pivot suivante
        else:
            # Si aucune ligne non nulle n'est trouvée dans cette colonne, passer à la colonne suivante
            lead += 1
    return matrix

def get_rank(matrix_input):
    """
    Calcule le rang d'une matrice, qui est le nombre de lignes non nulles dans sa forme échelonnée.
    """
    ref_matrix = gaussian_elimination(matrix_input)
    rank = 0
    for row in ref_matrix:
        if any(not _is_zero(val) for val in row): # Si la ligne n'est pas entièrement nulle
            rank += 1
    return rank

def get_kernel_basis(matrix_input):
    """
    Trouve une base pour le noyau (espace nul) d'une application linéaire représentée par une matrice.
    """
    matrix = [list(row) for row in matrix_input] # Copie profonde
    num_rows = len(matrix)
    if num_rows == 0:
        return []
    num_cols = len(matrix[0])
    if num_cols == 0:
        return []

    ref_matrix = gaussian_elimination(matrix)

    pivot_cols = []
    for r in range(num_rows):
        for c in range(num_cols):
            if not _is_zero(ref_matrix[r][c]):
                pivot_cols.append(c)
                break

    free_cols = [c for c in range(num_cols) if c not in pivot_cols]

    kernel_basis = []

    # Pour chaque variable libre, construire un vecteur de base du noyau
    for free_col_idx in free_cols:
        solution_vector = [0.0] * num_cols
        solution_vector[free_col_idx] = 1.0 # Définir la variable libre actuelle à 1

        # Résoudre pour les variables pivots en utilisant les équations de la RREF
        for r in range(num_rows):
            pivot_col_in_row = -1
            # Trouver la colonne pivot dans cette ligne (s'il y en a une)
            for c in range(num_cols):
                if not _is_zero(ref_matrix[r][c]):
                    pivot_col_in_row = c
                    break

            if pivot_col_in_row != -1 and pivot_col_in_row in pivot_cols:
                # Cette ligne correspond à une équation pour une variable pivot
                # ref_matrix[r][pivot_col_in_row] * x[pivot_col_in_row] + sum(ref_matrix[r][c] * x[c]) = 0
                # Puisque ref_matrix[r][pivot_col_in_row] est 1 (RREF), on a:
                # x[pivot_col_in_row] = - sum(ref_matrix[r][c] * x[c] pour c != pivot_col_in_row)

                sum_other_terms = 0.0
                for c in range(num_cols):
                    if c != pivot_col_in_row:
                        sum_other_terms += ref_matrix[r][c] * solution_vector[c]

                solution_vector[pivot_col_in_row] = -sum_other_terms

        # Ajouter le vecteur solution à la base du noyau s'il n'est pas le vecteur nul
        if any(not _is_zero(val) for val in solution_vector):
            kernel_basis.append(solution_vector)

    return kernel_basis

def get_image_basis(matrix_input):
    """
    Trouve une base pour l'image (espace colonne) d'une application linéaire représentée par une matrice.
    La base est formée par les colonnes originales de la matrice qui correspondent aux colonnes pivots
    dans sa forme échelonnée réduite.
    """
    matrix = [list(row) for row in matrix_input] # Copie profonde
    num_rows = len(matrix)
    if num_rows == 0:
        return []
    num_cols = len(matrix[0])
    if num_cols == 0:
        return []

    ref_matrix = gaussian_elimination(matrix)

    pivot_cols = []
    for r in range(num_rows):
        for c in range(num_cols):
            if not _is_zero(ref_matrix[r][c]):
                pivot_cols.append(c)
                break

    # Transposer la matrice originale pour extraire facilement les colonnes
    original_columns = [[matrix_input[r][c] for r in range(num_rows)] for c in range(num_cols)]

    image_basis = []
    for col_idx in pivot_cols:
        image_basis.append(original_columns[col_idx])

    return image_basis

# --- Fonctions d'assertion pour la validation ---

def are_vectors_approximately_equal(v1, v2, tol=EPSILON):
    """Vérifie si deux vecteurs sont approximativement égaux."""
    if len(v1) != len(v2):
        return False
    return all(abs(a - b) < tol for a, b in zip(v1, v2))

def is_linearly_independent_rows(vectors):
    """Vérifie si une liste de vecteurs (représentés comme des lignes) est linéairement indépendante."""
    if not vectors:
        return True
    if not vectors[0]: # Gérer le cas de vecteurs vides (e.g., matrice vide)
        return True

    # Le rang de la matrice formée par ces vecteurs doit être égal au nombre de vecteurs
    return get_rank(vectors) == len(vectors)

def is_linearly_independent_cols(vectors):
    """Vérifie si une liste de vecteurs (représentés comme des colonnes) est linéairement indépendante."""
    if not vectors:
        return True
    if not vectors[0]: # Gérer le cas de vecteurs vides
        return True

    # Transposer les colonnes en lignes pour le calcul du rang
    num_rows_orig = len(vectors[0]) # Dimension de l'espace des vecteurs
    num_cols_orig = len(vectors)    # Nombre de vecteurs

    transposed_matrix = [[vectors[c][r] for c in range(num_cols_orig)] for r in range(num_rows_orig)]

    return get_rank(transposed_matrix) == len(vectors)
```

## Validation Mathématique
L'implémentation Python ci-dessus repose sur les principes fondamentaux de l'algèbre linéaire pour déterminer le noyau, l'image et vérifier le théorème du rang d'une application linéaire représentée par une matrice.

1.  **Forme Échelonnée Réduite (RREF) via `gaussian_elimination` :**
    *   La fonction `gaussian_elimination` applique l'algorithme de Gauss-Jordan pour transformer une matrice en sa forme échelonnée réduite. Cette forme est unique pour chaque matrice et est cruciale car elle simplifie le système d'équations linéaires $Ax=0$ et révèle la structure de l'espace vectoriel sous-jacent.
    *   Chaque ligne non nulle dans la RREF correspond à une équation linéaire indépendante.
    *   Les "pivots" (premiers éléments non nuls de chaque ligne non nulle) indiquent les variables dépendantes.

2.  **Calcul du Rang via `get_rank` :**
    *   Le rang d'une matrice est défini comme la dimension de son espace ligne (ou espace colonne).
    *   Dans la RREF, le nombre de lignes non nulles est égal au nombre de pivots, qui est lui-même égal au rang de la matrice. La fonction `get_rank` compte simplement ces lignes non nulles après l'élimination de Gauss.

3.  **Détermination du Noyau via `get_kernel_basis` :**
    *   Le noyau de l'application linéaire $f$ (représentée par la matrice $A$) est l'ensemble de tous les vecteurs $x$ tels que $f(x) = Ax = 0$.
    *   Pour trouver une base du noyau, nous résolvons le système homogène $Ax=0$. En utilisant la RREF de $A$, nous identifions les variables pivots (correspondant aux colonnes avec des pivots) et les variables libres (les autres colonnes).
    *   Pour chaque variable libre, nous construisons un vecteur de base en lui attribuant la valeur 1, en attribuant 0 aux autres variables libres, puis en résolvant les variables pivots correspondantes à l'aide des équations de la RREF.
    *   L'ensemble de ces vecteurs forme une base du noyau. La dimension du noyau est le nombre de variables libres.

4.  **Détermination de l'Image via `get_image_basis` :**
    *   L'image de l'application linéaire $f$ est l'ensemble de tous les vecteurs $y$ dans l'espace d'arrivée $F$ tels qu'il existe un $x$ dans l'espace de départ $E$ avec $y = f(x)$.
    *   L'image est l'espace vectoriel engendré par les colonnes de la matrice $A$.
    *   Une base de l'image est formée par les colonnes de la *matrice originale* $A$ qui correspondent aux colonnes pivots de sa RREF. La fonction `get_image_basis` identifie ces colonnes pivots et retourne les colonnes correspondantes de la matrice d'entrée. La dimension de l'image est le nombre de colonnes pivots.

5.  **Vérification du Théorème du Rang :**
    *   Le théorème du rang stipule que pour toute application linéaire $f: E \to F$ où $E$ est de dimension finie, on a $\dim E = \dim(\ker f) + \text{rg}(f)$.
    *   Dans notre implémentation, $\dim E$ est le nombre de colonnes de la matrice d'entrée.
    *   $\dim(\ker f)$ est la longueur de la liste retournée par `get_kernel_basis`.
    *   $\text{rg}(f)$ est la valeur retournée par `get_rank` (qui est aussi la longueur de la liste retournée par `get_image_basis`).
    *   Le code vérifie cette égalité fondamentale avec des assertions, comme démontré dans la section `if __name__ == "__main__":`.

**Exemple Concret (issu du cours) :**
Soit l'application linéaire $f : \mathbb{R}^3 \to \mathbb{R}^2$ définie par $f(x,y,z) = (x+y, y+z)$.
Sa matrice associée est $A = \begin{pmatrix} 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix}$.

*   **Dimension de l'espace de départ ($\dim E$) :** $3$ (nombre de colonnes de $A$).
*   **Calcul du Noyau :**
    *   La RREF de $A$ est $\begin{pmatrix} 1 & 0 & -1 \\ 0 & 1 & 1 \end{pmatrix}$.
    *   Les variables pivots sont $x_1$ et $x_2$ (colonnes 0 et 1). La variable libre est $x_3$ (colonne 2).
    *   En posant $x_3 = 1$, on obtient $x_1 - x_3 = 0 \implies x_1 = 1$ et $x_2 + x_3 = 0 \implies x_2 = -1$.
    *   Un vecteur de base du noyau est $(1, -1, 1)$.
    *   $\dim(\ker f) = 1$.
*   **Calcul de l'Image :**
    *   Les colonnes pivots de la RREF sont les colonnes 0 et 1.
    *   Les colonnes correspondantes de la matrice originale $A$ sont $\begin{pmatrix} 1 \\ 0 \end{pmatrix}$ et $\begin{pmatrix} 1 \\ 1 \end{pmatrix}$.
    *   Une base de l'image est $\{ (1,0), (1,1) \}$.
    *   $\text{rg}(f) = \dim(\text{Im } f) = 2$.
*   **Vérification du Théorème du Rang :**
    *   $\dim E = 3$.
    *   $\dim(\ker f) = 1$.
    *   $\text{rg}(f) = 2$.
    *   On a bien $3 = 1 + 2$, ce qui confirme le théorème du rang.

Les assertions dans le code `if __name__ == "__main__":` valident ces résultats pour cet exemple et d'autres cas (matrice de projection, matrice nulle, matrice identité), garantissant la correction mathématique de l'implémentation.
