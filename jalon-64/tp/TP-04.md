## Objectif

Bien qu'il soit impossible de construire numériquement l'ensemble paradoxal de Vitali (qui requiert l'axiome du choix infini), nous pouvons illustrer l'impact de la sous-additivité de la mesure extérieure face à des recouvrements qui manquent cruellement d'efficacité. L'objectif de ce script pure Python est de créer un recouvrement très redondant et de montrer que la somme des longueurs des composants majore lourdement la mesure de l'union globale finale.

## Code Python `from scratch`

```python
def overlap_ratio(intervals):
    '''
    Evalue la redondance (manque d'additivite spatiale) d'une famille d'intervalles
    en comparant la somme de leurs mesures intrinseques a la vraie mesure de Lebesgue de leur union.
    '''
    # Calcul naif de l'additivite : somme brute independante des chevauchements topologiques.
    naive_sum_measure = sum(interval[1] - interval[0] for interval in intervals)

    # Calcul rigoureux de la mesure de Lebesgue par fusion pour extraire la mesure reelle de l'union.
    # On reutilise ici la logique de base du sous-probleme de fusion d'intervalles (TP1).
    if not intervals:
        return 0.0, 0.0

    sorted_intervals = sorted(intervals, key=lambda x: x[0])
    merged = [list(sorted_intervals[0])]
    for current in sorted_intervals[1:]:
        last = merged[-1]
        if current[0] <= last[1]:
            last[1] = max(last[1], current[1])
        else:
            merged.append(list(current))

    actual_union_measure = sum(interval[1] - interval[0] for interval in merged)

    return naive_sum_measure, actual_union_measure

def run_tests():
    '''
    Mise en evidence de l'inegalite stricte inhérente a la sous-additivite.
    '''
    # Creation intentionnelle d'une famille fortement entrelacee sur le segment [0, 10]
    # representant l'inefficacite d'un mauvais recouvrement pour capturer l'infimum (la mesure exterieure).
    redundant_family = [
        [0.0, 5.0], [2.0, 7.0], [4.0, 9.0], [6.0, 10.0],
        [1.0, 3.0], [5.0, 8.0]
    ]

    naive_measure, true_lebesgue = overlap_ratio(redundant_family)

    # La somme des longueurs naives majore fortement la longueur de l'espace reel couvert.
    # Sum: 5 + 5 + 5 + 4 + 2 + 3 = 24.0. Union effective reelle: [0, 10] -> 10.0.
    assert naive_measure == 24.0
    assert true_lebesgue == 10.0
    assert true_lebesgue <= naive_measure

    print("TP4: Inegalite de sous-additivite verifiee formellement par difference stochastique et spatiale.")
    print(f"Somme des parties (sans Caratheodory) : {naive_measure} >= Mesure de l'Union (Lebesgue) : {true_lebesgue}")

run_tests()
```
