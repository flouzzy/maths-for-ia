## Objectif

Conformément à l'Exercice Théorique 10, nous allons concevoir un générateur numérique qui filtre activement les nombres flottants par décodage structurel itératif de leur représentation en chaîne de caractères décimale (base 10) pour exclure un chiffre (par ex, '7').
Nous mesurerons asymptotiquement la décroissance drastique de la probabilité résiduelle (qui modélise discrètement la mesure de Lebesgue).

## Code Python `from scratch`

```python
def proportion_without_digit(digit, depth_resolution):
    '''
    Calcule par approche combinatoire pure la mesure (proportion analytique) des nombres dans [0, 1]
    n'utilisant pas le chiffre 'digit' jusqu'a une profondeur decimale 'depth_resolution'.
    '''
    # Chaque emplacement decimal (1er, 2eme... depth) offre 10 choix possibles {0..9}.
    # En excluant un chiffre arbitraire, il reste 9 choix viables par position.

    # Nombre d'arrangements totalement permis
    allowed_combinations = 9 ** depth_resolution

    # Taille de l'espace combinatoire total de base (univers complet de Lebesgue discrétisé)
    total_combinations = 10 ** depth_resolution

    # La proportion discrete de ces arrangements simule exactement la restriction de Lebesgue
    proportion = float(allowed_combinations) / float(total_combinations)
    return proportion

def run_tests():
    '''
    Validation de la convergence vers 0 de la mesure paradoxale.
    '''
    digit_to_exclude = 7

    # Test a la 1ere decimale (profondeur 1). Exemple: 0.x, x != 7.
    prop_d1 = proportion_without_digit(digit_to_exclude, 1)
    assert prop_d1 == 0.9  # 9/10 conserves

    # Test a la 3eme decimale (profondeur 3). 9^3 / 10^3 = 729 / 1000.
    prop_d3 = proportion_without_digit(digit_to_exclude, 3)
    assert abs(prop_d3 - 0.729) < 1e-9

    # Decroissance asymptotique massive : au bout de 50 decimales d'interrogation,
    # la mesure topologique est microscopique bien que les nombres de ce type soient denombrablement infinis.
    prop_d50 = proportion_without_digit(digit_to_exclude, 50)

    # Verification que la mesure s'effondre conformement a la loi de puissance analytique (9/10)^50.
    expected_limit = (0.9) ** 50
    assert abs(prop_d50 - expected_limit) < 1e-9
    assert prop_d50 < 0.01  # Moins de 1% apres seulement 50 contraintes

    print(f"TP5: Convergence vers une mesure nulle evaluee et confirmee mathematiquement (Proportion residuelle = {prop_d50:.6f}).")

run_tests()
```
