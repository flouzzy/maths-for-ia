## Objectif

Nous allons modéliser par récursivité la construction géométrique d'un objet topologique pathologique : l'ensemble de Cantor. À chaque itération de la profondeur récursive, la fonction soustrait le tiers central ouvert de chaque intervalle fermé.
L'algorithme déterminera mathématiquement la mesure (somme des longueurs) des sous-intervalles restants, validant empiriquement le théorème formel démontrant que la mesure de Lebesgue totale du Cantor tend inexorablement vers 0.

## Code Python `from scratch`

```python
def cantor_step(intervals):
    '''
    Effectue une iteration de l'algorithme de Cantor :
    Prend une liste d'intervalles [a, b], et retire pour chacun
    le tiers central ouvert, retournant une nouvelle liste de deux segments.
    '''
    new_intervals = []
    for interval in intervals:
        start = interval[0]
        end = interval[1]
        length = end - start

        # Le tiers gauche : de 'start' a 'start + 1/3 de la longueur'
        left_segment = [start, start + length / 3.0]

        # Le tiers droit : de 'end - 1/3 de la longueur' a 'end'
        right_segment = [end - length / 3.0, end]

        new_intervals.append(left_segment)
        new_intervals.append(right_segment)

    return new_intervals

def compute_cantor_measure(depth):
    '''
    Applique l'algorithme du Cantor recursivement 'depth' fois
    a partir du segment topologique initial [0.0, 1.0], puis calcule sa mesure totale.
    '''
    intervals = [[0.0, 1.0]]
    for _ in range(depth):
        intervals = cantor_step(intervals)

    # Calcul formel de la mesure exterieure : somme des longueurs du recouvrement
    total_length = sum(interval[1] - interval[0] for interval in intervals)
    return total_length, len(intervals)

def run_tests():
    '''
    Test analytique des etapes de fragmentation de la mesure.
    '''
    # Cas de base : profondeur 0 (segment plein). Mesure = 1.0
    m0, n0 = compute_cantor_measure(0)
    assert abs(m0 - 1.0) < 1e-9
    assert n0 == 1

    # Profondeur 1 : Mesure de (2/3)^1 = 0.666..., 2 segments
    m1, n1 = compute_cantor_measure(1)
    assert abs(m1 - 2.0/3.0) < 1e-9
    assert n1 == 2

    # Profondeur 15 : Approximation de la poussiere infinitesimale
    m15, n15 = compute_cantor_measure(15)
    # La theorie mathematique postule que la mesure limite est 0. (2/3)^15.
    expected_m15 = (2.0 / 3.0) ** 15
    assert abs(m15 - expected_m15) < 1e-9
    assert m15 < 0.003

    print(f"TP3: Validation reussie. A l'etape 15, on observe {n15} fragments possedant une mesure de Lebesgue aggregee de {m15:.5f}")

run_tests()
```
