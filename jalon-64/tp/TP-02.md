# TP 2 : Recouvrement d'un intervalle avec Monte Carlo

## Implémentation en Python pur

```python
import random

def is_covered(x, intervals):
    for a, b in intervals:
        if a < x < b:
            return True
    return False

intervals = [(0.1, 0.3), (0.4, 0.8), (0.7, 0.9)]
N = 10000
hits = 0
for _ in range(N):
    x = random.random()
    if is_covered(x, intervals):
        hits += 1

estimated_measure = hits / N
print(f"Estimated Lebesgue measure: {estimated_measure}")
```
