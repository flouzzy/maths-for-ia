## Objectif

La mesure de Lebesgue d'un espace de dimension 2 correspond à la notion familière d'aire géométrique.
Dans ce TP, nous implémentons une méthode de Monte Carlo (intégration stochastique par rejet empirique) basée sur des tirages purement aléatoires uniformes, simulant ainsi un échantillonnage par rapport à la mesure de Lebesgue sur le carré unitaire, pour approcher la mesure (l'aire) du disque unitaire, qui est theoriquement $\pi$.

## Code Python `from scratch`

```python
import random

def estimate_pi_lebesgue_measure(num_samples):
    '''
    Estime la valeur numerique de pi en determinant stochastiquement
    la mesure de Lebesgue 2D du quart de disque unitaire.
    '''
    points_inside_circle = 0

    for _ in range(num_samples):
        # Tirage d'un point selon la distribution induite par la mesure de Lebesgue normalisee sur [0,1]x[0,1]
        x = random.random()
        y = random.random()

        # Test du critere geometrique d'appartenance au disque (distance a l'origine au carre)
        if x*x + y*y <= 1.0:
            points_inside_circle += 1

    # La proportion de points dans le cercle par rapport au total tend asymptotiquement
    # vers le rapport de leurs mesures de Lebesgue (A_disque / A_carre = (pi/4) / 1)
    lebesgue_measure_ratio = points_inside_circle / num_samples
    estimated_pi = lebesgue_measure_ratio * 4.0

    return estimated_pi

def run_tests():
    '''
    Validation de la convergence stochastique de l'estimateur de la mesure 2D.
    '''
    # Pour garantir la reproductibilite parfaite de la sequence stochastique lors des tests unitaires
    random.seed(42)

    samples = 100000
    approx_pi = estimate_pi_lebesgue_measure(samples)

    # La valeur theorique (mesure de Lebesgue du disque de rayon 1) est 3.14159...
    # Avec 100 000 iterations de Monte Carlo, l'erreur absolue standard attendue est < 0.05
    error = abs(approx_pi - 3.14159265)

    assert error < 0.05, f"L'erreur {error} est trop importante pour cet ordre de grandeur."
    print(f"TP2: Mesure 2D asymptotique validee. Estimation pour N={samples} iterations : {approx_pi:.4f}")

run_tests()
```
