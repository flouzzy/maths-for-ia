## Objectif

Dans ce premier TP d'implémentation bas niveau, nous allons coder une fonction pure Python capable de calculer la longueur exacte (la mesure 1D) d'une union arbitraire d'intervalles qui peuvent se chevaucher. L'objectif est de s'approcher de l'intuition de la $\sigma$-additivité et du processus de recouvrement en simplifiant une famille d'intervalles vers une union disjointe, dont la longueur se somme trivialement.

## Code Python `from scratch`

```python
def merge_intervals(intervals):
    '''
    Fusionne une liste d'intervalles (listes de deux reels [a, b]) en cas de chevauchement.
    Retourne une nouvelle liste d'intervalles totalement disjoints.
    '''
    if not intervals:
        return []

    # On trie les intervalles par rapport a leur borne inferieure pour faciliter la fusion spatiale
    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]
    for current in intervals[1:]:
        last_merged = merged[-1]

        # Si la borne inferieure du courant est plus petite ou egale a la borne superieure du dernier fusionne, il y a recouvrement
        if current[0] <= last_merged[1]:
            # On etend la borne superieure (la borne inferieure reste fixe car liste triee)
            last_merged[1] = max(last_merged[1], current[1])
        else:
            # S'ils sont completement disjoints, on ajoute simplement le nouvel intervalle a la liste finale
            merged.append(current)

    return merged

def calculate_lebesgue_measure(intervals):
    '''
    Calcule la longueur totale (mesure 1D) d'une union d'intervalles en les fusionnant prealablement.
    '''
    disjoint_intervals = merge_intervals(intervals)
    total_measure = 0.0
    for interval in disjoint_intervals:
        total_measure += (interval[1] - interval[0])
    return total_measure

def run_tests():
    '''
    Fonction de validation algorithmique garantissant la stabilite numerique.
    '''
    # Cas 1 : Intervalles completement disjoints. Mesure = (2-1) + (5-4) = 2.0
    test1 = [[1, 2], [4, 5]]
    assert calculate_lebesgue_measure(test1) == 2.0

    # Cas 2 : Intervalles qui se chevauchent completement. [1, 5] et [2, 4] -> Union = [1, 5], mesure = 4.0
    test2 = [[1, 5], [2, 4]]
    assert calculate_lebesgue_measure(test2) == 4.0

    # Cas 3 : Intervalles avec recouvrement partiel complexe.
    # [1, 3] U [2, 6] U [8, 10] U [15, 18] -> [1, 6] U [8, 10] U [15, 18]
    # Mesures de la decomposition disjointe : (6-1) + (10-8) + (18-15) = 5 + 2 + 3 = 10.0
    test3 = [[1, 3], [2, 6], [8, 10], [15, 18]]
    assert calculate_lebesgue_measure(test3) == 10.0

    print("TP1: Tous les tests d'union spatiale de sous-ensembles continus valides avec succes.")

run_tests()
```
