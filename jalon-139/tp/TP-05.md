# TP 5 : Simulation de la Stabilité de la Descente de Gradient Stochastique (SGD)

## Objectif
Ce TP a pour objectif de simuler la stabilité de l'algorithme SGD (Descente de Gradient Stochastique) sur deux échantillons ne différant que par un point, et de vérifier empiriquement la relation de croissance de la divergence moyenne $\mathbb{E}[\|w_T - w'_T\|_2] \le \frac{2 \alpha L T}{n}$ établie par Hardt, Recht et Singer.

---

## Code de Simulation et de Validation

```python
import numpy as np

def sgd_step(w, x, y, alpha):
    """
    Pas de gradient stochastique sous perte quadratique (w*x - y)^2.
    Gradient = 2 * (w*x - y) * x
    """
    grad = 2 * (np.dot(w, x) - y) * x
    return w - alpha * grad

# Graine
np.random.seed(42)

# Paramètres
n = 100        # Taille de l'échantillon
d = 3          # Dimension
alpha = 0.01   # Pas d'apprentissage
epochs = 5     # Nombre d'époques (T = n * epochs pas de gradient)
T = n * epochs
L = 2.0        # Constante de Lipschitz (borne sur le gradient)

# Générer S et S_mod (différant par l'indice 0)
X = np.random.uniform(-0.5, 0.5, size=(n, d))
y = np.random.uniform(-1, 1, size=n)

x_prime = np.random.uniform(-0.5, 0.5, size=d)
y_prime = np.random.uniform(-1, 1)

X_mod = X.copy()
X_mod[0] = x_prime
y_mod = y.copy()
y_mod[0] = y_prime

# Nous allons faire tourner 100 exécutions de SGD avec des graines stochastiques différentes
# (pour la sélection des indices) et moyenner la divergence finale.
num_runs = 200
divergences = []

for run in range(num_runs):
    # Les deux trajectoires partent de 0
    w = np.zeros(d)
    w_prime = np.zeros(d)
    
    # Générer une séquence aléatoire d'indices
    indices = np.random.choice(n, size=T)
    
    for idx in indices:
        # Étape pour w sur S
        w = sgd_step(w, X[idx], y[idx], alpha)
        # Étape pour w_prime sur S_mod
        w_prime = sgd_step(w_prime, X_mod[idx], y_mod[idx], alpha)
        
    divergences.append(np.linalg.norm(w - w_prime))

mean_divergence = np.mean(divergences)
theoretical_bound = (2 * alpha * L * T) / n

print("--- ANALYSE DE LA STABILITÉ DE SGD ---")
print(f"Divergence moyenne réelle E[||w_T - w'_T||_2] : {mean_divergence:.6f}")
print(f"Borne théorique supérieure de Hardt-Recht-Singer : {theoretical_bound:.6f}")

# Assertion de validation mathématique
assert mean_divergence <= theoretical_bound, "Erreur: La divergence réelle dépasse la borne théorique !"
print("=> La borne de stabilité de SGD est validée par l'assertion.")
```
