# TP 5 : Calcul de la Valeur Principale de Cauchy

## 1. Objectif du TP
Évaluer numériquement l'action de la distribution $vp(1/x)$ sur une fonction test.

## 2. Implémentation

```python
import math

def bump(x):
    if abs(x) >= 1.0:
        return 0.0
    return math.exp(-1.0 / (1.0 - x*x))

def test_func(x):
    # Une fonction test asymétrique : x * bump(x)
    return x * bump(x)

def action_vp(phi, epsilon):
    # Calcul de l'intégrale sur [-1, -epsilon] U [epsilon, 1]
    steps = 2000

    # Partie gauche [-1, -epsilon]
    h1 = (-epsilon - (-1.0)) / steps
    somme1 = 0.5 * (phi(-1.0)/(-1.0) + phi(-epsilon)/(-epsilon))
    for i in range(1, steps):
        x = -1.0 + i*h1
        somme1 += phi(x) / x
    int1 = somme1 * h1

    # Partie droite [epsilon, 1]
    h2 = (1.0 - epsilon) / steps
    somme2 = 0.5 * (phi(epsilon)/epsilon + phi(1.0)/1.0)
    for i in range(1, steps):
        x = epsilon + i*h2
        somme2 += phi(x) / x
    int2 = somme2 * h2

    return int1 + int2

if __name__ == "__main__":
    # Si on applique vp(1/x) à phi(x) = x * bump(x), le terme en x se simplifie,
    # et il reste l'intégrale de la bump sur l'union des domaines.
    # À la limite eps->0, ce doit être l'intégrale de bump(x) sur [-1, 1]

    # Intégrale de référence de la bump (issue du TP1)
    # environ 0.44399

    for eps in [0.1, 0.01, 0.001]:
        val = action_vp(test_func, eps)
        print(f"Action vp pour eps={eps}: {val}")

    assert val > 0.44, "L'action de la vp doit converger vers l'intégrale de bump(x)"
```

## 3. Analyse
La valeur principale de Cauchy permet de donner un sens à l'intégrale d'une fonction ayant une singularité en $1/x$, en exploitant la compensation symétrique autour de $0$.
