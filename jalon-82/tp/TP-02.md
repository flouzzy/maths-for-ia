# TP 2 : Le Dirac via la fonction porte

## 1. Objectif du TP
Nous approchons le Dirac $\delta_0$ par la suite de fonctions créneaux : $f_n(x) = \frac{n}{2} \mathbf{1}_{[-1/n, 1/n]}(x)$.

## 2. Implémentation

```python
import math

def bump(x):
    if abs(x) >= 1.0:
        return 0.0
    return math.exp(-1.0 / (1.0 - x*x))

def action_creneau(phi, n):
    # L'intégrale de phi sur [-1/n, 1/n] multipliée par n/2
    a = -1.0 / n
    b = 1.0 / n
    steps = 1000
    h = (b - a) / steps
    somme = 0.5 * (phi(a) + phi(b))
    for i in range(1, steps):
        somme += phi(a + i*h)
    return (n / 2.0) * (somme * h)

if __name__ == "__main__":
    phi_0 = bump(0.0)
    print("Phi(0) =", phi_0)

    for n in [10, 100, 1000, 10000]:
        val = action_creneau(bump, n)
        print(f"Action pour n={n}: {val}")

    assert abs(val - phi_0) < 1e-4, "L'action doit converger vers Phi(0)"
```

## 3. Analyse
On constate que plus l'intervalle est petit, plus la moyenne intégrale de la fonction test sur cet intervalle est proche de sa valeur au point 0, ce qui valide l'action du Dirac.
