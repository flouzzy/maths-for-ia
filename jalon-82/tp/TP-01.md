# TP 1 : Simulation numérique de fonctions tests (Bulle)

Ce TP vise à implémenter de zéro la fonction test standard (la "bulle" infiniment dérivable à support compact) étudiée dans le cours et de vérifier numériquement qu'elle est bien nulle en dehors de son domaine de définition.

```python
import math

def fonction_test_bulle(x):
    # La fonction vaut exp(-1/(1-x**2)) pour abs(x) < 1 et 0 sinon.
    if abs(x) >= 1.0:
        return 0.0
    return math.exp(-1.0 / (1.0 - x**2))

def test_fonction_bulle():
    # Validation mathematique
    # En dehors du support
    assert fonction_test_bulle(1.0) == 0.0
    assert fonction_test_bulle(1.5) == 0.0
    assert fonction_test_bulle(-2.0) == 0.0

    # A l'interieur du support, la valeur doit etre positive
    valeur_en_zero = fonction_test_bulle(0.0)
    assert valeur_en_zero == math.exp(-1.0)
    assert fonction_test_bulle(0.5) > 0.0

    print("TP1: Validation mathematique reussie.")

if __name__ == "__main__":
    test_fonction_bulle()
```
