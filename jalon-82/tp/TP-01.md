# TP 1 : Approximation numérique de l'intégrale d'une bump function

Dans ce TP, nous allons simuler numériquement la fonction test de référence et vérifier que c'est bien une fonction de $\mathcal{D}(\mathbb{R})$.

## 1. Objectif du TP
Implémenter la fonction $x \mapsto \exp(-\frac{1}{1-x^2}) \mathbf{1}_{]-1, 1[}(x)$ et calculer son intégrale sur $\mathbb{R}$.

## 2. Implémentation

```python
import math

def bump(x):
    if abs(x) >= 1.0:
        return 0.0
    return math.exp(-1.0 / (1.0 - x*x))

def integrale_trapezes(f, a, b, n):
    h = (b - a) / n
    somme = 0.5 * (f(a) + f(b))
    for i in range(1, n):
        somme += f(a + i*h)
    return somme * h

if __name__ == "__main__":
    I = integrale_trapezes(bump, -1, 1, 10000)
    print("Intégrale de la bump function:", I)
    assert 0.44 < I < 0.45, "L'intégrale est approximativement 0.44399"
```

## 3. Analyse
La fonction est bien non-nulle et son intégrale est finie et positive. Pour la transformer en une approximation de Dirac, on devra la dilater et la normaliser par cette valeur.
