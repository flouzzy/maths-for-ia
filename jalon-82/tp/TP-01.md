# TP 1 : Implémentation d'une fonction test (Cloche C-infini à support compact)

**Objectif :**
L'objectif de ce TP est de coder la fonction test classique de $D(R)$ et de vérifier numériquement ses propriétés de compacité et de régularité (continuité des dérivées aux bords du support).

**Code Python pur :**
```python
import math

def cloche_test(x):
    """
    Evalue la fonction test classique f(x) = exp(-1/(1-x^2)) pour |x| < 1, et 0 sinon.
    """
    if abs(x) >= 1.0:
        return 0.0
    return math.exp(-1.0 / (1.0 - x**2))

def derivee_cloche(x, h=1e-5):
    """
    Approximation de la derivee premiere par differences finies centrees.
    """
    return (cloche_test(x + h) - cloche_test(x - h)) / (2 * h)

def tester_proprietes():
    # 1. Verification du support compact (nullite en dehors de [-1, 1])
    assert cloche_test(1.1) == 0.0, "La fonction doit etre nulle hors de [-1, 1]"
    assert cloche_test(-2.5) == 0.0, "La fonction doit etre nulle hors de [-1, 1]"
    assert cloche_test(1.0) == 0.0, "La fonction doit etre nulle aux bords"

    # 2. Verification de la non-nullite a l'interieur
    assert cloche_test(0.0) == math.exp(-1), "Valeur incorrecte en 0"
    assert cloche_test(0.5) > 0.0, "Doit etre strictement positive a l'interieur"

    # 3. Verification numerique de la continuite de la derivee en 1
    # On s'approche de 1 par la gauche
    d_proche_bord = derivee_cloche(0.999)
    # On s'attend a ce que la derivee soit tres proche de 0
    assert abs(d_proche_bord) < 1e-2, f"La derivee doit tendre vers 0 aux bords, trouve: {d_proche_bord}"

    print("TP 1 : Toutes les assertions sont validees. La fonction test est correctement implementee.")

if __name__ == "__main__":
    tester_proprietes()

```
