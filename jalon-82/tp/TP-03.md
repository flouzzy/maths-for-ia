# TP 3 : Simulation de l'action de la dérivée d'une distribution (Prélude)

**Objectif :**
Bien que la dérivation systématique soit vue au Jalon 83, on peut déjà vérifier numériquement que l'action du Dirac sur une dérivée est cohérente.

**Code Python pur :**
```python
import math

def cloche(x):
    if abs(x) >= 1.0: return 0.0
    return math.exp(-1.0 / (1.0 - x**2))

def derivee_num(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

def dirac_action(f, a=0.0):
    """Action du Dirac translaté en a sur une fonction f."""
    return f(a)

def tester_derivee_dirac():
    # Calculons l'action de Dirac sur la derivee d'une fonction test
    action_sur_derivee = dirac_action(lambda x: derivee_num(cloche, x), 0.5)

    # La valeur theorique de la derivee en 0.5 est analytiquement :
    # d/dx exp(-1/(1-x^2)) = -2x/(1-x^2)^2 * exp(-1/(1-x^2))
    x0 = 0.5
    valeur_theorique = (-2 * x0 / (1 - x0**2)**2) * math.exp(-1.0 / (1 - x0**2))

    erreur = abs(action_sur_derivee - valeur_theorique)
    assert erreur < 1e-4, "L'action sur la derivee est incorrecte numeriquement"
    print(f"TP 3 : Validation numerique reussie. Erreur : {erreur:.2e}")

if __name__ == "__main__":
    tester_derivee_dirac()

```
