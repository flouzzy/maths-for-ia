# TP 3 : Le Dirac via la Gaussienne

## 1. Objectif du TP
Utiliser des Gaussiennes de variance tendant vers 0 pour approximer le Dirac sur une fonction test.

## 2. Implémentation

```python
import math

def bump(x):
    if abs(x) >= 1.0:
        return 0.0
    return math.exp(-1.0 / (1.0 - x*x))

def gaussienne(x, sigma):
    return (1.0 / (sigma * math.sqrt(2 * math.pi))) * math.exp(-0.5 * (x / sigma)**2)

def action_gaussienne(phi, sigma):
    a = -1.0
    b = 1.0
    steps = 5000
    h = (b - a) / steps
    somme = 0.5 * (phi(a)*gaussienne(a, sigma) + phi(b)*gaussienne(b, sigma))
    for i in range(1, steps):
        x = a + i*h
        somme += phi(x) * gaussienne(x, sigma)
    return somme * h

if __name__ == "__main__":
    phi_0 = bump(0.0)
    print("Phi(0) =", phi_0)

    for sig in [0.1, 0.05, 0.01, 0.005]:
        val = action_gaussienne(bump, sig)
        print(f"Action pour sigma={sig}: {val}")

    assert abs(val - phi_0) < 1e-2, "Convergence vers Phi(0)"
```

## 3. Analyse
La gaussienne donne une excellente approximation régulière du Dirac. On note que pour de très petites valeurs de sigma, la méthode numérique d'intégration (trapèzes) peut devenir instable si le pas `h` n'est pas assez fin pour capturer le pic très étroit.
