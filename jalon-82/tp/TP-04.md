# TP 4 : Dérivée numérique de la fonction Heaviside

## 1. Objectif du TP
Montrer que l'approximation lisse de la fonction de Heaviside a pour dérivée une approximation du Dirac.

## 2. Implémentation

```python
import math

def bump(x):
    if abs(x) >= 1.0:
        return 0.0
    return math.exp(-1.0 / (1.0 - x*x))

def heaviside_approx(x, k):
    # Approximation par la tangente hyperbolique : (1 + tanh(kx))/2
    return 0.5 * (1.0 + math.tanh(k * x))

def heaviside_deriv_approx(x, k):
    # La dérivée : k / (2 cosh^2(kx))
    return k / (2.0 * math.cosh(k * x)**2)

def action_deriv(phi, k):
    a = -1.0
    b = 1.0
    steps = 5000
    h = (b - a) / steps
    somme = 0.5 * (phi(a)*heaviside_deriv_approx(a, k) + phi(b)*heaviside_deriv_approx(b, k))
    for i in range(1, steps):
        x = a + i*h
        somme += phi(x) * heaviside_deriv_approx(x, k)
    return somme * h

if __name__ == "__main__":
    phi_0 = bump(0.0)

    for k in [10, 50, 100, 200]:
        val = action_deriv(bump, k)
        print(f"Action pour k={k}: {val}")

    assert abs(val - phi_0) < 1e-2, "La dérivée de Heaviside agit comme le Dirac"
```

## 3. Analyse
Cette simulation confirme numériquement un résultat central : la dérivée au sens des distributions de la fonction indicatrice (Heaviside) est la distribution de Dirac.
