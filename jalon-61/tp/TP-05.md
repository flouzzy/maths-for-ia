# TP 5 - Introduction algorithmique à la mesure

Au lieu d'intégrer par abscisse (Riemann), on trie les valeurs atteintes.

```python
def pseudo_lebesgue_integral(vals, dx):
    # vals est une liste de valeurs de f(x)

    # 1. Identifier les valeurs distinctes et leur "mesure" (nombre d'occurrences * dx)
    measure_dict = {}
    for v in vals:
        v_rounded = round(v, 3)
        measure_dict[v_rounded] = measure_dict.get(v_rounded, 0) + dx

    # 2. Somme de (valeur * mesure de l'ensemble où f(x) = valeur)
    integral = 0.0
    for val, measure in measure_dict.items():
        integral += val * measure

    return integral

if __name__ == "__main__":
    # Simulation d'une fonction qui vaut 2 sur 30% du domaine et 5 sur 70%
    n = 1000
    dx = 1.0 / n
    f_vals = [2.0 if i < 300 else 5.0 for i in range(n)]

    res = pseudo_lebesgue_integral(f_vals, dx)
    print("Intégrale (méthode des niveaux):", res)
    assert abs(res - (0.3*2.0 + 0.7*5.0)) < 1e-5
```
