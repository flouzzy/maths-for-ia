# TP 2 - Sommes de Darboux d'une fonction continue

Contrairement au TP 1, nous implémentons ici les sommes de Darboux pour une fonction Riemann-intégrable ($f(x) = x^2$) pour observer la convergence.

```python
def f_square(x):
    return x * x

def darboux_sums_square(n_intervals):
    a, b = 0.0, 1.0
    dx = (b - a) / n_intervals

    upper_sum = 0.0
    lower_sum = 0.0

    # f(x) = x^2 est croissante sur [0, 1]
    # donc le min est à gauche, le max est à droite
    for k in range(n_intervals):
        x_left = a + k * dx
        x_right = a + (k + 1) * dx

        lower_sum += f_square(x_left) * dx
        upper_sum += f_square(x_right) * dx

    return lower_sum, upper_sum

if __name__ == "__main__":
    n = 1000
    s, S = darboux_sums_square(n)
    print("s =", s, "S =", S)
    exact = 1.0 / 3.0
    assert abs(s - exact) < 1e-2
    assert abs(S - exact) < 1e-2
```
