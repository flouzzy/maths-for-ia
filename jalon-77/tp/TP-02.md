# TP 2 : Continuité de l'opérateur de translation dans L2

**Objectif :** Simuler numériquement l'invariance par translation et sa continuité $h \mapsto \|\tau_h f - f\|_2$ pour une fonction créneau.

```python
import math

def f_creneau(x):
    return 1.0 if 0 <= x <= 1 else 0.0

def translation_error_l2(h, num_points=10000):
    start, end = -2.0, 3.0
    dx = (end - start) / num_points
    error_sq = 0.0

    for i in range(num_points):
        x = start + i * dx
        val_f = f_creneau(x)
        val_fh = f_creneau(x - h)
        error_sq += (val_fh - val_f) ** 2 * dx

    return math.sqrt(error_sq)

if __name__ == "__main__":
    h_values = [0.5, 0.2, 0.1, 0.05, 0.01]

    for h in h_values:
        err = translation_error_l2(h)
        print("h =", h, "-> Erreur L2 =", err)
        # Pour une indicatrice, l'aire symétrique non-superposée vaut 2h, l'erreur L2 au carré est 2h (car (1-0)^2 = 1)
        expected = math.sqrt(2 * h)
        assert abs(err - expected) < 1e-2, "Echec de l'approximation de l'erreur L2"

    print("Tests continuités par translation reussis. La limite quand h->0 est bien 0.")
```
