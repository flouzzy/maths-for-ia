# TP 5 : Non-densité empirique dans l'espace uniforme

Démontrons numériquement que l'erreur supremum (norme infinie) entre une constante et une fonction à support compact reste minorée par 1.

```python
def f_constante(x):
    return 1.0

# Fonction continue a support compact [-R, R]
def phi_compact(x, R):
    if abs(x) <= R:
        return max(0.0, 1 - (x/R)**2)
    return 0.0

def erreur_supremum(f, phi, grid):
    return max(abs(f(x) - phi(x)) for x in grid)

# Grille de -10 a 10
grid = [i * 0.1 - 10 for i in range(201)]

R_values = [1, 5, 8]
for R in R_values:
    # Definir une fonction locale fixant R
    def current_phi(x):
        return phi_compact(x, R)

    err = erreur_supremum(f_constante, current_phi, grid)
    print("Erreur supremum pour R=", R, ":", err)

    # La validation verifie l'impossibilite d'approcher la norme uniforme
    assert err >= 0.99, "La fonction a support compact devrait avoir une erreur d'au moins 1 a l'infini."
```
