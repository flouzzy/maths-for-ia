# TP 5 : Lemme de Riemann-Lebesgue

**Objectif :** Illustrer l'application des méthodes de densité (via Riemann-Lebesgue) en calculant la décorrélation oscillatoire d'une fonction L1 avec un sinus à haute fréquence.

```python
import math

def f_signal(x):
    # Fonction e^(-x) sur [0, 5], 0 ailleurs. f in L1.
    if 0 <= x <= 5:
        return math.exp(-x)
    return 0.0

def compute_fourier_sin_coeff(n_freq, num_points=10000):
    start = 0.0
    end = 5.0
    dx = (end - start) / num_points
    integral = 0.0

    for i in range(num_points):
        x = start + i * dx + dx / 2
        integral += f_signal(x) * math.sin(n_freq * x) * dx

    return integral

if __name__ == "__main__":
    freqs = [1, 10, 50, 100, 500]

    for n in freqs:
        coeff = compute_fourier_sin_coeff(n)
        print("Frequence n =", n, "-> Integrale de f(x)sin(nx) =", coeff)

    coeff_500 = compute_fourier_sin_coeff(500)
    assert abs(coeff_500) < 1e-2, "Le lemme de Riemann-Lebesgue n'est pas verifie numeriquement."
    print("Test de decroissance asymptotique reussi.")
```
