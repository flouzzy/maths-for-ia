# TP 2 : Opérations sur les fonctions mesurables

Ce TP propose de manipuler programmatiquement des fonctions mesurables, des indicatrices et l'approximation étagée sans utiliser de frameworks avancés.

```python
# Stabilité par somme et produit
def add_functions(f, g):
    return lambda x: f(x) + g(x)

def mult_functions(f, g):
    return lambda x: f(x) * g(x)

def f1(x): return x ** 2
def f2(x): return 3 * x

def test_operations():
    sum_f = add_functions(f1, f2)
    prod_f = mult_functions(f1, f2)

    assert sum_f(2) == 10  # 4 + 6
    assert prod_f(2) == 24 # 4 * 6
    print("TP 2: Opérations stables OK")

if __name__ == "__main__":
    test_operations()
```
