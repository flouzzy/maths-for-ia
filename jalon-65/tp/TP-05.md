# TP 5 : Convergence d'une suite de fonctions mesurables (Supremum)

Ce TP propose de manipuler programmatiquement des fonctions mesurables, des indicatrices et l'approximation étagée sans utiliser de frameworks avancés.

```python
# Calcul du supremum ponctuel d'une suite finie de fonctions
def supremum_function(funcs):
    return lambda x: max([f(x) for f in funcs])

def test_supremum():
    f1 = lambda x: x
    f2 = lambda x: x**2
    f3 = lambda x: 10 - x

    sup_f = supremum_function([f1, f2, f3])

    # en x=2: f1(2)=2, f2(2)=4, f3(2)=8 -> max = 8
    assert sup_f(2) == 8
    # en x=4: f1(4)=4, f2(4)=16, f3(4)=6 -> max = 16
    assert sup_f(4) == 16
    print("TP 5: Supremum ponctuel OK")

if __name__ == "__main__":
    test_supremum()
```
