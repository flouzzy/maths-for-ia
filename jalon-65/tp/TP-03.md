# TP 3 : Construction de fonctions étagées

Ce TP propose de manipuler programmatiquement des fonctions mesurables, des indicatrices et l'approximation étagée sans utiliser de frameworks avancés.

```python
# Fonction étagée de la forme sum(alpha_i * 1_{A_i})
class StepFunction:
    def __init__(self, alphas, predicates):
        assert len(alphas) == len(predicates)
        self.alphas = alphas
        self.predicates = predicates

    def __call__(self, x):
        result = 0
        for alpha, pred in zip(self.alphas, self.predicates):
            if pred(x):
                result += alpha
        return result

def test_step_function():
    # Definition d'une fonction valant 10 si x < 0, 20 si 0<=x<5, 30 si x>=5
    alphas = [10, 20, 30]
    preds = [lambda x: x < 0, lambda x: 0 <= x < 5, lambda x: x >= 5]

    s = StepFunction(alphas, preds)
    assert s(-5) == 10
    assert s(2) == 20
    assert s(10) == 30
    print("TP 3: Fonctions étagées OK")

if __name__ == "__main__":
    test_step_function()
```
