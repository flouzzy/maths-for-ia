# TP 1 : Implémentation de fonctions indicatrices

Ce TP propose de manipuler programmatiquement des fonctions mesurables, des indicatrices et l'approximation étagée sans utiliser de frameworks avancés.

```python
# Implementation de la fonction indicatrice 1_A
def indicator_function(A_predicate, x):
    if A_predicate(x):
        return 1
    return 0

# Test avec un ensemble A = [2, 5]
def is_in_interval_2_5(x):
    return 2 <= x <= 5

def test_indicator():
    assert indicator_function(is_in_interval_2_5, 3) == 1
    assert indicator_function(is_in_interval_2_5, 1) == 0
    assert indicator_function(is_in_interval_2_5, 5) == 1
    print("TP 1: Fonctions indicatrices OK")

if __name__ == "__main__":
    test_indicator()
```
