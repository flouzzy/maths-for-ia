# TP 2 - Approximation de Pi par la formule de Leibniz

## 1. Objectif du TP
Implémenter l'approximation de $\pi$ via la série $4 \sum_{k=0}^\infty \frac{(-1)^k}{2k + 1}$.

## 2. Implémentation

```python
def pi_leibniz(n):
    assert n >= 0
    total = 0.0
    for k in range(n + 1):
        total += ((-1)**k) / (2 * k + 1)
    return 4 * total

import math
val = pi_leibniz(1000)
assert abs(val - math.pi) < 0.01
print("Validation réussie.")
```
