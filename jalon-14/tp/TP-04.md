# TP 4 - Approximation de racine carrée par la méthode de Héron

## 1. Objectif du TP
Implémenter la suite de Héron pour approximer $\sqrt{S}$ et évaluer la vitesse de convergence.

## 2. Implémentation

```python
def heron_sqrt(S, epsilon=1e-12):
    assert S >= 0, "S doit être positif"
    if S == 0: return 0.0

    x = S
    iterations = 0
    while True:
        iterations += 1
        x_next = 0.5 * (x + S / x)
        if abs(x_next - x) < epsilon:
            break
        x = x_next

    return x, iterations

racine, iters = heron_sqrt(2.0)
assert abs(racine * racine - 2.0) < 1e-10
print(f"Racine de 2 approximée en {iters} itérations.")
```
