# TP 5 - Suites récurrentes linéaires d'ordre 2

## 1. Objectif du TP
Étudier et implémenter le terme général d'une suite récurrente linéaire de la forme $u_{n+2} = a u_{n+1} + b u_n$.

## 2. Implémentation

```python
def suite_recurrente_ordre2(a, b, u0, u1, n):
    assert isinstance(n, int) and n >= 0

    if n == 0: return u0
    if n == 1: return u1

    prev2, prev1 = u0, u1
    for _ in range(2, n + 1):
        current = a * prev1 + b * prev2
        prev2, prev1 = prev1, current

    return prev1

# Test avec la suite de Fibonacci : u_{n+2} = u_{n+1} + u_n
# a=1, b=1, u0=0, u1=1
assert suite_recurrente_ordre2(1, 1, 0, 1, 10) == 55

# Test avec une autre suite arbitraire
# u_{n+2} = 2*u_{n+1} - u_n
# Si u0=1, u1=2, alors c'est la suite u_n = n + 1
assert suite_recurrente_ordre2(2, -1, 1, 2, 5) == 6
print("Validation réussie.")
```
