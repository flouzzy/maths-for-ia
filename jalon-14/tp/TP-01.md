# TP 1 - Convergence de la série harmonique alternée

## 1. Objectif du TP
Implémenter la série harmonique alternée et visualiser numériquement sa convergence vers $\ln(2)$.

## 2. Implémentation

```python
def harmonic_alternating_sum(n):
    assert n >= 1
    total = 0.0
    for k in range(1, n + 1):
        total += ((-1)**(k + 1)) / k
    return total

import math
val = harmonic_alternating_sum(1000)
assert abs(val - math.log(2)) < 0.01
print("Validation réussie.")
```
