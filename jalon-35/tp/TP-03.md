# TP 3 : Implémentation naïve de Bolzano-Weierstrass (Extraction)

```python
import random

# Dans le compact [0, 1], générer une suite aléatoire
suite = [random.random() for _ in range(100)]

# Extraction d'une sous-suite convergente (naïvement, on cherche des valeurs de Cauchy)
# On va chercher une sous-suite qui se concentre autour d'un point d'accumulation
extractrice = []
current_point = suite[0]
extractrice.append(0)

# Pour simplifier on crée une sous-suite monotone en cherchant des éléments de plus en plus proches d'une valeur arbitraire
point_accumulation = sum(suite) / len(suite)

epsilons = [0.1 / (i+1) for i in range(10)]
last_index = -1

for eps in epsilons:
    for i in range(last_index + 1, len(suite)):
        if abs(suite[i] - point_accumulation) < eps:
            extractrice.append(i)
            last_index = i
            break

print("Indices extraits:", extractrice)
print("Valeurs:", [suite[i] for i in extractrice])
```
