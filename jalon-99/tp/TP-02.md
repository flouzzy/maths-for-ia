# TP 2 : Projection et séparation point-convexe

## Objectif
Implémenter la séparation géométrique d'un point et d'un convexe fermé (un disque) en calculant la projection orthogonale, selon Hahn-Banach.

## Code Python

```python
import math

def distance(p1, p2):
    return math.sqrt(sum((x - y)**2 for x, y in zip(p1, p2)))

def separate_point_circle(center, radius, point):
    # Verifier si le point est dans le cercle
    dist = distance(center, point)
    if dist <= radius:
        raise ValueError("Le point est a l'interieur du convexe, separation impossible.")

    # Le point projete sur le cercle est sur le segment reliant le point au centre
    # Vecteur unitaire du point vers le centre
    ux = (center[0] - point[0]) / dist
    uy = (center[1] - point[1]) / dist

    # Le vecteur normal de l'hyperplan separateur
    w = (-ux, -uy)

    # Point milieu entre la frontiere et le point pour une marge optimale
    margin_point = (point[0] + (dist - radius)/2 * ux, point[1] + (dist - radius)/2 * uy)

    # b = w^T * margin_point
    b = w[0] * margin_point[0] + w[1] * margin_point[1]

    return w, b

def test_tp2():
    w, b = separate_point_circle((0, 0), 1, (3, 0))
    # w doit etre (1, 0), b = 2 (milieu entre x=1 et x=3)
    assert abs(w[0] - 1.0) < 1e-5 and abs(w[1]) < 1e-5
    assert abs(b - 2.0) < 1e-5
    print("TP 2 valide.")

if __name__ == "__main__":
    test_tp2()
```
