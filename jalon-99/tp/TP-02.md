\subsection*{TP 2 : Projection sur un Convexe Fermé}

On simule la projection d'un point sur le disque unité fermé en dimension 2. Cela illustre la séparation d'un point et d'un convexe fermé.

```python
def projection_disque(px, py):
    norm = (px**2 + py**2)**0.5
    if norm <= 1.0:
        return px, py
    return px / norm, py / norm

def check_separation(px, py, cx, cy):
    # Le plan separateur H = {x | <x-c, p-c> = 0} au point c
    # Verification : <p-c, p-c> > 0 (pour le point p)
    val_p = (px - cx)*(px - cx) + (py - cy)*(py - cy)
    assert val_p > 0
    # Pour un point dans le convexe (ex: origine)
    val_origine = (0 - cx)*(px - cx) + (0 - cy)*(py - cy)
    assert val_origine <= 0

px, py = 2.0, 2.0
cx, cy = projection_disque(px, py)
check_separation(px, py, cx, cy)
```
