# TP 1 : Séparation d'ensembles par un hyperplan (Hahn-Banach géométrique)

## Objectif
Implémenter la séparation stricte de deux ensembles convexes de points dans R^2 en trouvant les paramètres (w, b) de l'hyperplan affine `w^T x - b = 0`. Le code doit être écrit en Python pur sans aucun framework externe et sans symboles mathématiques de formatage.

## Code Python

```python
# tp_1_hahn_banach.py

def dot_product(v1, v2):
    return sum(x * y for x, y in zip(v1, v2))

def is_strictly_separated(A, B, w, b):
    # Verifier si l'hyperplan defini par (w, b) separe strictement A et B
    # A doit etre d'un cote (< b) et B de l'autre (> b)

    # Check A
    for a in A:
        if dot_product(w, a) >= b:
            return False

    # Check B
    for b_pt in B:
        if dot_product(w, b_pt) <= b:
            return False

    return True

def test_separation():
    # Ensemble A (ex: carre dans x < 0)
    A = [(-2, -2), (-2, 2), (-1, -1), (-1, 1)]
    # Ensemble B (ex: carre dans x > 0)
    B = [(1, -1), (1, 1), (2, -2), (2, 2)]

    # L'axe Y (x = 0) separe strictement
    w = (1, 0) # Vecteur normal (1,0)
    b = 0      # x = 0

    assert is_strictly_separated(A, B, w, b) == True, "Erreur: A et B devraient etre separes"

    # Test avec un hyperplan qui ne separe pas (x = 2)
    assert is_strictly_separated(A, B, w, 2) == False, "Erreur: A et B ne devraient pas etre separes"

    print("Tous les tests passent avec succes.")

if __name__ == "__main__":
    test_separation()
```
