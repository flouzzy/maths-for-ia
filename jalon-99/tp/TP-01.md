\subsection*{TP 1 : Algorithme du Perceptron et Séparabilité}

Ce TP illustre la séparation au sens large en dimension 2 (pour classer deux ensembles de points). L'algorithme du Perceptron converge si les données sont linéairement séparables (Hahn-Banach garantit qu'un hyperplan existe si les enveloppes convexes ne s'intersectent pas).

```python
def perceptron(points, labels, max_iter=1000):
    # points : liste de (x, y), labels : liste de 1 ou -1
    w = [0.0, 0.0]
    b = 0.0
    for _ in range(max_iter):
        errors = 0
        for i in range(len(points)):
            x, y = points[i]
            activation = w[0] * x + w[1] * y + b
            if labels[i] * activation <= 0:
                w[0] += labels[i] * x
                w[1] += labels[i] * y
                b += labels[i]
                errors += 1
        if errors == 0:
            break
    return w, b

points_train = [(1, 1), (2, 2), (-1, -1), (-2, -2)]
labels_train = [1, 1, -1, -1]

w, b = perceptron(points_train, labels_train)
assert w[0] > 0 or w[1] > 0
assert b == 0
```
