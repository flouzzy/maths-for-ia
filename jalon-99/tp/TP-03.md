\subsection*{TP 3 : La Jauge de Minkowski}

Calcul de la Jauge de Minkowski pour un rectangle ouvert R = ]-2, 2[ x ]-1, 1[. L'ouvert est convexe.

```python
def jauge_rectangle(x, y):
    # R est l'ensemble des (x,y) tq max(|x|/2, |y|) < 1
    # La jauge est l'inf des t > 0 tq (x/t, y/t) in R
    return max(abs(x) / 2.0, abs(y))

assert jauge_rectangle(0, 0) == 0
assert jauge_rectangle(2, 1) == 1
assert jauge_rectangle(4, 2) == 2
assert jauge_rectangle(1, 0.5) == 0.5

# Un point appartient au rectangle ssi sa jauge est < 1
assert jauge_rectangle(1.9, 0.9) < 1.0
assert jauge_rectangle(2.1, 1.1) > 1.0
```
