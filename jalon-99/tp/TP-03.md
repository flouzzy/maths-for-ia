# TP 3 : Jauge de Minkowski

## Objectif
Implémenter le calcul de la fonctionnelle de Minkowski (jauge) pour un carré centré à l'origine, qui est la base de la démonstration analytique de Hahn-Banach géométrique.

## Code Python

```python
def jauge_carre(point, size):
    # Le carre C est [-size, size] x [-size, size]
    # La jauge est inf {lambda > 0 | point in lambda C}
    # En norme infinie, p_C(x, y) = max(|x|, |y|) / size
    x, y = point
    return max(abs(x), abs(y)) / size

def test_jauge():
    # Point (2, 2) et carré [-1, 1]^2
    assert jauge_carre((2, 2), 1) == 2.0
    # Point (0.5, -0.5)
    assert jauge_carre((0.5, -0.5), 1) == 0.5
    # Point (0, 3) et carré [-2, 2]^2
    assert jauge_carre((0, 3), 2) == 1.5

    print("TP 3 valide : Jauge calculee correctement.")

if __name__ == "__main__":
    test_jauge()
```
