\subsection*{TP 5 : Marge de Sécurité Maximale (SVM Minimal)}

Trouver l'hyperplan optimal (marge maximale) pour séparer 4 points spécifiques en dimension 1, illustrant la 2ème forme géométrique (séparation stricte de compacts).

```python
# C1 : x = -2, x = -1
# C2 : x = 1, x = 2
# Le separateur optimal est a x = 0.

def find_margin(points_c1, points_c2):
    max_c1 = points_c1[0]
    for p in points_c1:
        if p > max_c1: max_c1 = p

    min_c2 = points_c2[0]
    for p in points_c2:
        if p < min_c2: min_c2 = p

    assert min_c2 > max_c1 # Separation possible

    alpha = (max_c1 + min_c2) / 2.0
    epsilon = (min_c2 - max_c1) / 2.0

    return alpha, epsilon

c1 = [-2, -1]
c2 = [1, 2]
alpha, eps = find_margin(c1, c2)

assert alpha == 0
assert eps == 1

# Verification inegalite : L(x) = x
for x in c1:
    assert x <= alpha - eps
for y in c2:
    assert y >= alpha + eps
```
