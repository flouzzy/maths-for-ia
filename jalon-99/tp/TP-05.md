# TP 5 : Séparation au sens large et limite

## Objectif
Implémenter un cas où deux ensembles convexes disjoints s'approchent asymptotiquement, montrant qu'une séparation stricte est impossible (Hahn-Banach forme large uniquement).

## Code Python

```python
def min_distance_asymptotic(n_max):
    # A : y >= 0 (demi plan superieur)
    # B : y <= -1/x (branche hyperbole inférieure pour x > 0)

    # Evaluons la distance entre les frontières y=0 et y=-1/x pour x croissant
    min_dist = float('inf')

    for x in range(1, n_max + 1):
        pt_a = (x, 0)
        pt_b = (x, -1.0/x)

        # Distance verticale
        dist = abs(pt_a[1] - pt_b[1])
        if dist < min_dist:
            min_dist = dist

    return min_dist

def test_asymptotic():
    d_10 = min_distance_asymptotic(10)
    d_100 = min_distance_asymptotic(100)
    d_1000 = min_distance_asymptotic(1000)

    assert d_10 == 0.1
    assert d_100 == 0.01
    assert d_1000 == 0.001

    # La distance tend vers 0, donc pas de epsilon de séparation stricte possible
    print("TP 5 valide : La distance asymptotique tend vers 0.")

if __name__ == "__main__":
    test_asymptotic()
```
