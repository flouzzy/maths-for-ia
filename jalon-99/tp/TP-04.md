# TP 4 : Marge maximale (Hard Margin)

## Objectif
Calculer de manière itérative ou analytique simple l'hyperplan optimal (marge maximale) séparant deux points, illustrant la séparation stricte de Hahn-Banach.

## Code Python

```python
def max_margin_hyperplane(pt1, pt2):
    # L'hyperplan optimal entre deux points est le plan mediateur
    # w = pt2 - pt1 (non normalise pour la direction)
    w = (pt2[0] - pt1[0], pt2[1] - pt1[1])

    # Milieu M
    m = ((pt1[0] + pt2[0]) / 2, (pt1[1] + pt2[1]) / 2)

    # b = w^T * m
    b = w[0] * m[0] + w[1] * m[1]

    return w, b

def test_margin():
    pt_a = (-1, 0)
    pt_b = (1, 0)
    w, b = max_margin_hyperplane(pt_a, pt_b)

    # w = (2, 0), m = (0, 0), b = 0 -> equation 2x = 0 -> x = 0
    assert w == (2, 0)
    assert b == 0

    print("TP 4 valide : Hyperplan mediateur calcule.")

if __name__ == "__main__":
    test_margin()
```
