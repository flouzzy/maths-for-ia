\subsection*{TP 4 : Enveloppe Convexe (Algorithme de Jarvis)}

Calcul de l'enveloppe convexe d'un nuage de points. Deux ensembles sont séparables ssi leurs enveloppes convexes sont disjointes.

```python
def cross_product(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def jarvis_march(points):
    n = len(points)
    if n < 3: return points
    hull = []
    # Point le plus a gauche
    l = 0
    for i in range(1, n):
        if points[i][0] < points[l][0]:
            l = i
    p = l
    while True:
        hull.append(points[p])
        q = (p + 1) % n
        for i in range(n):
            if cross_product(points[p], points[i], points[q]) > 0:
                q = i
        p = q
        if p == l:
            break
    return hull

nuage = [(0, 0), (1, 0), (0, 1), (0.1, 0.1)]
env = jarvis_march(nuage)
assert len(env) == 3
assert (0.1, 0.1) not in env
```
