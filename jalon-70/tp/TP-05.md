# TP 5 : Contre-exemple continu et discret non-sigma-fini

Ce TP simule l'intégration sur la diagonale par deux mesures distinctes (une de comptage, une de Lebesgue) pour observer que l'inversion d'intégration échoue si l'un n'est pas sigma-fini.

```python
# L'ensemble est la diagonale continue D = {(x,x)} pour x dans [0,1]
# Mesure mu = Lebesgue sur [0,1]
# Mesure nu = Comptage sur la section
# Mais numeriquement, on fixe une grille N

def integrate_diag_dx_dy(resolution=10):
    # dx est mesure de Lebesgue (poids = 1/resolution), dy est mesure de comptage (poids = 1 par point, s'il y a intersection)
    # L'integration interne est dy: integrale_{y} nu(D_x) dx
    resultat = 0.0
    dx = 1.0 / resolution

    # Pour chaque x dans l'intervalle
    for i in range(resolution):
        x = i / resolution

        # Section_x : combien de y tel que x=y (sur la diagonale) ?
        # La reponse est toujours exactement 1 point (y=x).
        nu_sec = 1  # Mesure de comptage

        # On integre selon dx
        resultat += nu_sec * dx

    return resultat

def integrate_diag_dy_dx(resolution=10):
    # Cette fois, dy est mesure de Lebesgue (poids = 1/resolution), dx est mesure de comptage (poids=1)
    # Dans l'exo theorique pathologique, dx etait la mesure de Lebesgue pour l'interne, mais on va l'approcher :
    # Si dy est l'integrale externe, et dx interne (Lebesgue) : la section_y a une mesure de Lebesgue de 0.
    resultat = 0.0
    dy = 1  # Mesure de comptage a l'externe

    for i in range(resolution):
        y = i / resolution

        # Section_y: l'ensemble des x tels que x=y. C'est un singleton {y}.
        # La mesure de Lebesgue dx d'un singleton est 0.
        mu_sec = 0.0

        # On integre selon dy (comptage)
        resultat += mu_sec * dy

    return resultat

if __name__ == "__main__":
    res_1 = integrate_diag_dx_dy(resolution=100)
    res_2 = integrate_diag_dy_dx(resolution=100)

    assert abs(res_1 - 1.0) < 1e-9, "L'integration selon comptage puis Lebesgue doit valoir 1.0"
    assert abs(res_2 - 0.0) < 1e-9, "L'integration selon Lebesgue puis comptage doit valoir 0.0"

    # Validation du theoreme (lechec car conditions sigma-finies absentes)
    assert res_1 != res_2, "Le theoreme de la mesure produit echoue, on a 1 != 0."

    print("Tous les tests du TP 5 sont valides.")
```
