# TP 4 : Algorithme de réduction de Gauss semi-symbolique

## Objectif Mathématique
L'objectif est d'implémenter l'extraction d'un carré parfait pour le premier terme non nul d'une forme quadratique (étape 1 de l'algorithme de Gauss). On le fera numériquement sur les coefficients de la matrice associée.

## Code Python (From Scratch)

```python
def reduire_premier_carre(A):
    '''
    Prend une matrice symétrique A (3x3).
    Si a11 != 0, extrait le carré associé à x_1.
    q(x) = a11(x1 + (a12/a11)x2 + (a13/a11)x3)^2 + Q_reste(x2, x3)
    Renvoie le coefficient a11, la forme linéaire L (liste des coefs), et la matrice du reste R (3x3).
    '''
    a11 = A[0][0]
    if a11 == 0:
        raise ValueError("L'algorithme requiert un a11 non nul pour cette passe.")

    # Forme linéaire L = [1, a12/a11, a13/a11]
    L = [1, A[0][1] / a11, A[0][2] / a11]

    # Calcul du reste. Q(x) = X^T A X - a11 * (L^T X)^2
    # R_ij = A_ij - a11 * L_i * L_j
    R = [[0]*3 for _ in range(3)]
    for i in range(3):
        for j in range(3):
            R[i][j] = A[i][j] - a11 * L[i] * L[j]

    return a11, L, R

if __name__ == '__main__':
    # q(x) = 2x^2 + 4xy - 2xz + 3y^2 + 5z^2 = 2(x + y - 0.5z)^2 + Q_reste
    A = [
        [2, 2, -1],
        [2, 3, 0],
        [-1, 0, 5]
    ]

    coef, L, R = reduire_premier_carre(A)

    assert abs(coef - 2) < 1e-9
    assert abs(L[1] - 1.0) < 1e-9    # a12/a11 = 2/2 = 1
    assert abs(L[2] - (-0.5)) < 1e-9 # a13/a11 = -1/2 = -0.5

    # R[0][:] et R[:][0] doivent être nuls car x1 est totalement éliminé
    for i in range(3):
        assert abs(R[0][i]) < 1e-9
        assert abs(R[i][0]) < 1e-9

    print("TP4 validé : L'étape de Gauss décompose et annule correctement les résidus.")
```
