# TP 2 : Multiplication matricielle et évaluation quadratique

## Objectif Mathématique
Vérifier l'équivalence fondamentale $q(X) = X^T A X$. Le TP consiste à implémenter un produit matriciel simple pour évaluer la forme quadratique via sa matrice, et comparer avec l'évaluation algébrique directe.

## Code Python (From Scratch)

```python
def eval_quadratique_algebrique(x):
    return x[0]**2 + 2*x[1]**2 + 3*x[2]**2 - 4*x[0]*x[1] + 2*x[0]*x[2] - 6*x[1]*x[2]

def produit_matriciel_vecteur(A, x):
    # Calcule Ax (vecteur colonne)
    n = len(A)
    res = [0] * n
    for i in range(n):
        for j in range(n):
            res[i] += A[i][j] * x[j]
    return res

def produit_scalaire(u, v):
    # Calcule u^T v
    return sum(u[i] * v[i] for i in range(len(u)))

def eval_quadratique_matricielle(A, x):
    # Calcule x^T (A x)
    Ax = produit_matriciel_vecteur(A, x)
    return produit_scalaire(x, Ax)

if __name__ == '__main__':
    A = [
        [1, -2, 1],
        [-2, 2, -3],
        [1, -3, 3]
    ]
    vecteurs_test = [(1,0,0), (0,1,0), (1,1,1), (-2, 3, 5)]

    for v in vecteurs_test:
        val_alg = eval_quadratique_algebrique(v)
        val_mat = eval_quadratique_matricielle(A, v)
        # Tolérance flottante pour éviter les erreurs d'arrondi
        assert abs(val_alg - val_mat) < 1e-9, f"Échec sur {v} : Alg={val_alg}, Mat={val_mat}"

    print("TP2 validé : L'évaluation X^T A X correspond à la définition algébrique.")
```
