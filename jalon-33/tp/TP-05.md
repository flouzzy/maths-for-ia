# TP 5 : Lien avec la minimisation et la Hessienne

## Objectif Mathématique
En optimisation de second ordre, la courbure d'une fonction d'erreur autour d'un minimum local est régie par la matrice Hessienne. Nous allons approximer le minimum d'une fonction en utilisant sa Hessienne (Forme Quadratique associée) via un pas de méthode de Newton pure.

## Code Python (From Scratch)

```python
# Fonction f(x, y) = x^2 + 4y^2 - 2x + 8y + 10
# Gradient = [2x - 2, 8y + 8]
# Hessienne H = [[2, 0], [0, 8]] (Définie positive)

def gradient(v):
    x, y = v
    return [2*x - 2, 8*y + 8]

def hessienne():
    return [[2, 0], [0, 8]]

def inverser_2x2(M):
    det = M[0][0]*M[1][1] - M[0][1]*M[1][0]
    return [
        [M[1][1]/det, -M[0][1]/det],
        [-M[1][0]/det, M[0][0]/det]
    ]

def multiplication_mat_vec(M, V):
    return [M[0][0]*V[0] + M[0][1]*V[1], M[1][0]*V[0] + M[1][1]*V[1]]

def newton_step(x_init):
    # Formule de Newton : x_{k+1} = x_k - H^{-1} * Grad(x_k)
    grad = gradient(x_init)
    H_inv = inverser_2x2(hessienne())

    # delta = H^{-1} * grad
    delta = multiplication_mat_vec(H_inv, grad)

    x_new = [x_init[0] - delta[0], x_init[1] - delta[1]]
    return x_new

if __name__ == '__main__':
    # Point initial quelconque
    x0 = [10.0, -15.0]

    # Pour une forme quadratique pure, la méthode de Newton converge en EXACTEMENT 1 itération.
    x_min = newton_step(x0)

    # Le minimum analytique est tel que Grad = 0 => 2x-2=0 (x=1) et 8y+8=0 (y=-1)
    assert abs(x_min[0] - 1.0) < 1e-9
    assert abs(x_min[1] - (-1.0)) < 1e-9

    print("TP5 validé : La forme quadratique hessienne dicte la convergence en 1 pas exact de Newton.")
```
