# Exercice 7 : Convergence Monotone sur ensemble discret \quad $\bigstar\star\star\star$

## Énoncé
On munit $\mathbb{N}$ de la mesure de comptage. Soit $f_n(k) = (1 - 1/n)^k$. Calculer $\lim \int_{\mathbb{N}} f_n$.

## Correction Détaillée
\begin{itemize}
\item Suite croissante vers 1. 2. $\int 1 = +\infty$. 3. $\int f_n = \sum_k (1-1/n)^k = \frac{1}{1-(1-1/n)} = n$. 4. $\lim n = +\infty$. Cohérent avec TCM.
\end{itemize}
