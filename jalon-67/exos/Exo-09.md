# Exercice 9 : Croissance presque partout \quad $\bigstar\bigstar\bigstar\star$

## Énoncé
Montrer que le TCM reste vrai si la croissance $f_n \le f_{n+1}$ n'est vraie que presque partout.

## Correction Détaillée
\begin{itemize}
\item Soit $N_n$ l'ensemble de mesure nulle où $f_n > f_{n+1}$. 2. $N = \cup N_n$ est de mesure nulle. 3. Sur $X \setminus N$, la suite est croissante partout. 4. Les intégrales sur $N$ sont nulles, on applique TCM sur $X \setminus N$.
\end{itemize}
