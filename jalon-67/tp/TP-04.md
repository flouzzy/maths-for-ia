# TP 4 : Contre-exemple (Suite non croissante)

## Objectif
Implémentation algorithmique du concept correspondant.

## Code Python
```python
def f_n(n, x):
    if 0 < x < 1.0/n:
        return n
    return 0

def integrate(n, N_steps=10000):
    dx = 1.0 / N_steps
    total = 0.0
    for i in range(N_steps):
        x = (i + 0.5) * dx
        total += f_n(n, x) * dx
    return total

def tp4():
    for n in [10, 100, 1000]:
        print("n=", n, "int=", integrate(n))

if __name__ == '__main__':
    tp4()
```
