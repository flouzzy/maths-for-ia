# TP 04 : Intégration numérique terme à terme

Le code Python pure suivant démontre algorithmiquement le concept étudié.

```python
import math

# On cherche à calculer \int_0^1 (-ln(1-x)) dx
# via la série -ln(1-x) = sum_{k=1}^N x^k / k
def term_k(x, k):
    return (x ** k) / float(k)

def integrate_term(k, a, b, num_steps=1000):
    step_size = (b - a) / num_steps
    total = 0.0
    for i in range(num_steps):
        x = a + (i + 0.5) * step_size
        total += term_k(x, k) * step_size
    return total

# Somme des intégrales
sum_of_integrals = 0.0
for k in range(1, 50):
    sum_of_integrals += integrate_term(k, 0, 0.999) # borne max approchée pour riemann

# L'intégrale théorique de -ln(1-x) sur [0,1] est 1.
print("Somme numérique (N=50) :", sum_of_integrals)
assert 0.95 < sum_of_integrals < 1.05
print("TP 4 Validé !")
```
