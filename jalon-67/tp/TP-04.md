# TP 4 : L'Espérance en théorie de la mesure algorithmique

## Description

Calcul de l'espérance mathématique d'une variable aléatoire continue approchée par une suite croissante de variables discrètes étagées.

## Code Python (Pure Algorithmie)

```python
# Approximation par fonctions etagees s_n <= f
# Soit f(x) = x**2 pour x in [0, 1]
# s_n(x) = (floor(n*x)/n)**2

import math

def s_n(x, n):
    k = math.floor(n * x)
    if k == n: # gestion du bord droit
        k = n - 1
    return (k / float(n)) ** 2

def integral_s_n(n):
    # s_n est constante sur des intervalles de largeur 1/n
    # Sa valeur sur [k/n, (k+1)/n[ est (k/n)**2
    total = 0.0
    for k in range(n):
        total += ((k / float(n)) ** 2) * (1.0 / n)
    return total

def test_etagees():
    # La vraie integrale de x**2 sur [0,1] est 1/3
    vraie_valeur = 1.0 / 3.0
    for n in [10, 100, 1000]:
        appro = integral_s_n(n)
        print("Pour n =", n, ", integrale =", appro)
        assert appro <= vraie_valeur # Car s_n <= f

    # Verification de la convergence
    assert abs(integral_s_n(1000) - vraie_valeur) < 1e-2

test_etagees()
```
