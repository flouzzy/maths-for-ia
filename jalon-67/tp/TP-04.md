# TP 4 : Vérification algorithmique

Dans ce TP, nous implémentons en pur Python les concepts liés au Théorème de Convergence Monotone.

```python
# Validation purement numérique
def solve_tp():
    # TP4: (1 + x/n)^n * exp(-2x) limit
    import math
    n = 1000
    steps = 1000
    dx = 10.0 / steps # approximate +inf with 10.0

    integral_n = 0.0
    for i in range(steps):
        x = i * dx
        val = ((1 + x/n)**n) * math.exp(-2*x)
        if x <= n:
            integral_n += val * dx

    # limit integral is int_0^+inf exp(-x) dx = 1
    assert 0.95 < integral_n < 1.05
    print("TP4: Limit of exponential truncation approaches 1.")

if __name__ == '__main__':
    solve_tp()
```
