# TP 4 : Approximation par fonctions étagées

**Objectif :** Validation de l'étape clé de la preuve : $f_n >= c s$.

```python
def f(x):
    return x**2

def s(x):
    # Fonction etagee <= f sur [0, 2]
    if 0 <= x < 1:
        return 0
    elif 1 <= x < 1.5:
        return 1
    else:
        return 2.25

def f_n(x, n):
    return f(x) * (1 - 1/(n+1))

x_test = 1.2
c = 0.9
for n in range(1, 10):
    val_fn = f_n(x_test, n)
    val_cs = c * s(x_test)
    print(f'n={n}, f_n={val_fn:.3f}, c*s={val_cs:.3f}, f_n >= c*s ? {val_fn >= val_cs}')
    if n > 5:
        assert val_fn >= val_cs
```
