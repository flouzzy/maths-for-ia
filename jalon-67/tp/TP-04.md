# TP 4 : Densité de probabilité et Espérance de variables infinies

**Objectif :** Calculer l'espérance d'une loi de Poisson de manière naïve et via Beppo Levi sur les queues de distribution.

## Code Python (Pure Python, Zéro Framework)

```python
def factoriel(n):
    if n == 0: return 1
    res = 1
    for i in range(1, n + 1):
        res *= i
    return res

def proba_poisson(k, lambda_param):
    # P(X=k) = e^-lambda * lambda^k / k!
    return (2.71828 ** (-lambda_param)) * (lambda_param ** k) / factoriel(k)

def proba_sup_ou_egal(k, lambda_param, n_max):
    # P(X >= k)
    return sum(proba_poisson(i, lambda_param) for i in range(k, n_max))

if __name__ == "__main__":
    lambda_param = 3.5
    n_max = 30 # Assez grand pour l'infini

    # Esperance standard: sum(k * P(X=k))
    esp_std = sum(k * proba_poisson(k, lambda_param) for k in range(n_max))

    # Esperance Beppo Levi: sum(P(X >= k)) pour k de 1 a l'infini
    esp_beppo = sum(proba_sup_ou_egal(k, lambda_param, n_max) for k in range(1, n_max))

    print("Esperance standard :", esp_std)
    print("Esperance (Beppo)  :", esp_beppo)

    # Assertion
    assert abs(esp_std - lambda_param) < 0.01
    assert abs(esp_beppo - lambda_param) < 0.01

```
