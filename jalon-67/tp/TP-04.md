## TP 4 : Défaut d'interversion avec la bosse glissante

Simulation du fameux contre-exemple $f_n(x) = n e^{-nx}$ où le maximum glisse vers $0$.

```python
def tp4_sliding_bump():
    steps = 10000
    upper_bound = 10.0
    dx = upper_bound / steps

    def my_exp(val):
        res = 1.0
        term = 1.0
        for i in range(1, 15):
            term = term * val / i
            res += term
        return res

    n_values = [1, 2, 5, 10, 20]

    for n in n_values:
        current_int = 0.0
        for s in range(steps):
            x = s * dx
            # n * e^(-nx)
            val = n * my_exp(-n * x)
            current_int += val * dx
        print("Integrale pour n =", n, ":", current_int)

        # On doit trouver environ 1
        diff = 1.0 - current_int
        if diff < 0: diff = -diff
        assert diff < 0.05

tp4_sliding_bump()
```
