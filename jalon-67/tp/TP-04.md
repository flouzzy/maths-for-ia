# TP 4 : Interversion somme infinie et série

## Objectif
Implémentation algorithmique sans bibliothèques externes pour valider les comportements asymptotiques étudiés.

## Implémentation

```python
def a(i, j):
    return 1.0 / (2**(i+j+2))

sum_i_first = 0
for i in range(100):
    for j in range(100):
        sum_i_first += a(i, j)

sum_j_first = 0
for j in range(100):
    for i in range(100):
        sum_j_first += a(i, j)

assert abs(sum_i_first - sum_j_first) < 1e-9
print("Egalite verifiee:", sum_i_first)
```
