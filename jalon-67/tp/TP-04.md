# TP 04 : Processus stochastique positif

Ce TP implémente de manière concrète une propriété liée au Théorème de Convergence Monotone ou à ses limites de validité.

```python
# tp_04_simulation.py

def reward_fn(t, N):
    return (1.0 / (2**t)) * (1.0 - 1.0/N)

def test_tp04():
    # Limit of sum is sum of limit
    total_val_limit_N = 0
    for t in range(1, 20):
        total_val_limit_N += (1.0 / (2**t)) # limit N->inf of reward_fn

    val_for_large_N = sum(reward_fn(t, 100) for t in range(1, 20))

    assert val_for_large_N <= total_val_limit_N, "Monotonicity failed"
    assert abs(total_val_limit_N - 1.0) < 1e-2, "Error in infinite sum"
    print("TP04: Application du corollaire aux récompenses d'un processus validée.")

if __name__ == '__main__':
    test_tp04()
```
