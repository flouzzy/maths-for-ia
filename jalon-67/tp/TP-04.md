# TP 4 : Convergence Monotone Numérique

## Objectif
Illustrer la croissance de l'intégrale d'une suite croissante de fonctions vers l'intégrale de la limite $f(x) = x^2$ sur $[0, 1]$.

## Implémentation

```python
def f_lim(x):
    return x * x

def f_n(n, x):
    # Suite de fonctions croissante vers x^2: (x - x/n)^2
    return (x - x/n) * (x - x/n)

def integrate_riemann(func, n, num_points=1000):
    dx = 1.0 / num_points
    integral = 0.0
    for i in range(num_points):
        x = i * dx
        # Passer n comme argument si necessaire
        if n is not None:
            integral += func(n, x) * dx
        else:
            integral += func(x) * dx
    return integral

def main():
    target = integrate_riemann(f_lim, None)
    print("Integrale de la limite f(x) = x^2:", target)

    for n in [2, 5, 10, 100, 1000]:
        val = integrate_riemann(f_n, n)
        print("Integrale de f_n pour n =", n, ":", val)

if __name__ == "__main__":
    main()
```
