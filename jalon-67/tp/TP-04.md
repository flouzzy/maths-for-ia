# TP 4 : Optimisation : limite des pertes empiriques

## Objectif
Montrer que la somme des pertes converge vers la perte de la limite si les modèles sont monotones.

## Implémentation en Python

```python
def simulate_tp_4():
    # TP 4: Monotonie dans la fonction de perte
    # Simulation d'un apprentissage ou la perte L_n(x) decroit,
    # donc l'amelioration f_n(x) = L_0(x) - L_n(x) croit.

    # Soit la distribution uniforme sur [0, 1]
    # L_n(x) = x^2 + (1 - x/2)^n
    # f_n(x) = (1 - x/2) - (1 - x/2)^n (fonction croissante en n)

    num_points = 1000
    dx = 1.0 / num_points

    # Calcul de la limite de l'integrale de f_n
    n_val = 500
    integral_fn = 0.0
    for i in range(num_points):
        x = i * dx
        val = (1.0 - x/2.0) - (1.0 - x/2.0)**n_val
        integral_fn += val * dx

    # Limite analytique de f_n est f(x) = 1 - x/2 (car (1-x/2)^n -> 0)
    # Integrale de f(x) = x - x^2/4 eval entre 0 et 1 = 1 - 0.25 = 0.75

    assert abs(integral_fn - 0.75) < 0.01
    return True

if __name__ == '__main__':
    simulate_tp_4()
    print('TP 4 valide.')
```
