# TP 4 : Intégrale de Gauss approchée

## Objectif
Validation numérique.

## Code Python
```python
def test_tp4():
    # (1 - x^2/n)^n approx exp(-x^2)
    def fn(n, x):
        return (1 - (x*x)/n)**n if x*x <= n else 0

    x = 1.0
    val_5 = fn(5, x)
    val_50 = fn(50, x)
    # verify increasing
    assert val_50 >= val_5
    print("TP4 OK")

test_tp4()
```
