# TP 1 : Vérification algorithmique

Dans ce TP, nous implémentons en pur Python les concepts liés au Théorème de Convergence Monotone.

```python
# Validation purement numérique
def solve_tp():
    # TP1: x^(1/n) limit integral
    n_vals = [10, 100, 1000]
    steps = 10000
    for n in n_vals:
        integral = 0.0
        dx = 1.0 / steps
        for i in range(1, steps):
            x = i * dx
            val = x**(1/n)
            integral += val * dx
        # The true limit is 1.0
        assert 0.9 < integral <= 1.0
    print("TP1: Limit of integral of x^(1/n) approaches 1 as expected.")

if __name__ == '__main__':
    solve_tp()
```
