# TP 1 : Simulation du TCM avec Riemann

## Objectif
Implémentation algorithmique du concept correspondant.

## Code Python
```python
import math

def f_n(n, x):
    if 0 <= x <= 1:
        return x**n
    return 0.0

def integrate(n, N_steps=1000):
    dx = 1.0 / N_steps
    return sum(f_n(n, i*dx)*dx for i in range(N_steps))

def tp1():
    for n in [1, 2, 5, 10, 50, 100]:
        print("n=", n, "int=", integrate(n))

if __name__ == '__main__':
    tp1()
```
