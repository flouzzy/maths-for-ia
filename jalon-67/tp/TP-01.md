# TP 01 : Simulation numérique d'une suite croissante simple

Ce TP implémente de manière concrète une propriété liée au Théorème de Convergence Monotone ou à ses limites de validité.

```python
# tp_01_simulation.py

def f_n(x, n):
    return (1 - 1.0/n) * x**2

def integrate_rectangle(func, a, b, n, steps=10000):
    dx = (b - a) / steps
    return sum(func(a + i*dx, n) * dx for i in range(steps))

def test_tp01():
    res = integrate_rectangle(f_n, 0, 1, 1000)
    expected = 1/3
    assert abs(res - expected) < 1e-2, f"Expected {expected}, got {res}"
    print("TP01: Validation numérique du TCM réussie.")

if __name__ == '__main__':
    test_tp01()
```
