# TP 1 : Vérification empirique de la linéarité positive

## Objectif
Implémentation algorithmique sans bibliothèques externes pour valider les comportements asymptotiques étudiés.

## Implémentation

```python
def f_n(x, n):
    return x ** 2 * (1 - 1/(n+1))

X = [0.1, 0.5, 0.9, 1.2, 2.5]
integral_limit = sum(x**2 for x in X)

for n in [10, 100, 1000]:
    integral_fn = sum(f_n(x, n) for x in X)
    assert integral_fn <= integral_limit
    print("n=", n, " Integral=", integral_fn)

print("Limite exacte=", integral_limit)
```
