# TP 01 : Validation simple de la suite géométrique pondérée


Ce TP valide numériquement l'interversion de la limite pour la série étudiée en exemple, $f_n(x) = \sum_{k=1}^n x^{k-1}$.

```python
def integrate(func, a, b, n_steps=1000):
    step = (b - a) / n_steps
    return sum(func(a + i * step) * step for i in range(n_steps))

def partial_sum(x, n):
    return sum(x**(k-1) for k in range(1, n+1))

def limit_func(x):
    return 1 / (1 - x)

def test_tcm_tp01():
    a, b = 0.0, 0.9  # borne superieure eloignee de 1 pour eviter la divergence
    n = 50

    int_limit = integrate(limit_func, a, b, 2000)
    int_partial = integrate(lambda x: partial_sum(x, n), a, b, 2000)

    # Validation du TCM : l'integrale de la somme partielle converge vers l'integrale de la limite
    assert abs(int_limit - int_partial) < 1e-2, f"Erreur TCM: {int_limit} != {int_partial}"
    print(f"TP 01: TCM valide. Int limit: {int_limit:.4f}, Int parielle(n=50): {int_partial:.4f}")

if __name__ == '__main__':
    test_tcm_tp01()
```
