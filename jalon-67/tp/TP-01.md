# TP 1 : Sommation numérique de la série de Riemann

## Objectif
Implémenter la sommation terme à terme de la série $1/n^s$ pour $s=2$ et observer la convergence de la somme partielle.

## Implémentation

```python
def sum_riemann(s, max_n):
    # Calcul approché de Zeta(s)
    total = 0.0
    for n in range(1, max_n + 1):
        total += 1.0 / (n ** s)
    return total

def main():
    print("Sommation de 1/n^2 (Convergence vers pi^2/6 ~ 1.64493)")
    for n in [10, 100, 1000, 10000]:
        val = sum_riemann(2, n)
        print("Pour n =", n, ", somme =", val)

if __name__ == "__main__":
    main()
```
