# TP 1 : Série harmonique divergente

## Objectif
Validation numérique.

## Code Python
```python
def test_tp1():
    # Integral of sum x^n from 0 to 1
    total = 0.0
    for n in range(1, 100):
        # integral x^n dx = 1/(n+1)
        total += 1.0 / (n + 1)
    assert total > 2.0  # Demonstrates divergence slowly
    print("TP1 OK")

test_tp1()
```
