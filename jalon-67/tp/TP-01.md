# TP 1 : Simulation numérique de la convergence monotone

## Description

Ce TP illustre algorithmiquement le théorème de Beppo-Levi en intégrant numériquement une suite de fonctions croissantes et en vérifiant la convergence de leurs intégrales.

## Code Python (Pure Algorithmie)

```python
# Validation du theoreme de convergence monotone par integration numerique
# On considere f_n(x) = (1 - (x/n))**n * x**(p-1) sur [0, n] avec p=2
# La limite est e**(-x) * x**(2-1) = x * e**(-x), dont l'integrale sur [0, +inf] vaut Gamma(2) = 1.

def f_n(x, n):
    if x >= n:
        return 0.0
    return ((1.0 - x/n) ** n) * x

def f_limite(x):
    import math
    return math.exp(-x) * x

def integrate(func, a, b, steps):
    dx = (b - a) / steps
    total = 0.0
    for i in range(steps):
        x = a + i * dx
        total += func(x) * dx
    return total

def test_beppo_levi():
    steps = 10000
    n_values = [10, 50, 100]

    print("Integration de la limite sur [0, 100]:")
    I_lim = integrate(f_limite, 0, 100, steps)
    print("I_lim =", I_lim)

    for n in n_values:
        # On integre f_n sur [0, n]
        I_n = integrate(lambda x: f_n(x, n), 0, n, steps)
        print("n =", n, " -> I_n =", I_n)
        # Assertion de croissance des integrales
        assert I_n <= I_lim + 1e-2

test_beppo_levi()
```
