# TP 1 : Convergence Monotone - Suite Géométrique

**Objectif :** Vérifions numériquement l'interversion limite / intégrale sur la série géométrique (Exemple 1).

```python
def f_n(x, n):
    return sum(x**k for k in range(n+1))

def integrate_riemann(func, a, b, n_steps=1000):
    dx = (b - a) / n_steps
    return sum(func(a + i*dx + dx/2) * dx for i in range(n_steps))

# Integrale de f_n sur [0, 0.99] pour eviter la singularite en 1
for n in [5, 10, 20]:
    integral_approx = integrate_riemann(lambda x: f_n(x, n), 0, 0.99)
    print(f'n={n}, Integrale partielle: {integral_approx:.4f}')

# Limite analytique f(x) = 1/(1-x)
integral_limit = integrate_riemann(lambda x: 1/(1-x), 0, 0.99)
print(f'Integrale de la limite: {integral_limit:.4f}')
assert abs(integral_approx - integral_limit) < 1.0, 'Erreur de convergence'
```
