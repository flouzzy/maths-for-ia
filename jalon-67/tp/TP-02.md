# TP 2 : Mise en évidence du contre-exemple de non-croissance

## Description

On montre par le code que la masse peut s'échapper à l'infini si la suite de fonctions n'est pas croissante, mettant en défaut l'interversion.

## Code Python (Pure Algorithmie)

```python
# Contre-exemple: f_n(x) = n * 1_]0, 1/n]
# La limite est 0, mais l'integrale de f_n vaut toujours 1.

def f_n(x, n):
    if 0 < x <= 1.0/n:
        return float(n)
    return 0.0

def integrate_fn(n, steps=1000):
    a = 0.0
    b = 2.0
    dx = (b - a) / steps
    total = 0.0
    for i in range(steps):
        x = a + (i + 0.5) * dx
        total += f_n(x, n) * dx
    return total

def test_mass_escape():
    # La limite theorique de l'integrale de f_n est 1
    # La fonction limite f(x) est constante egale a 0, d'integrale 0
    for n in [5, 10, 50]:
        val = integrate_fn(n, 10000 * n) # plus d'etapes pour capter le pic fin
        print("Integrale pour n=", n, " est ", val)
        # On verifie que la masse reste autour de 1, pas 0
        assert 0.95 <= val <= 1.05

test_mass_escape()
```
