# TP 2 : Indicatrice mobile (contre-exemple)

## Objectif
Validation numérique.

## Code Python
```python
def test_tp2():
    # f_n = n * I(]0, 1/n[)
    def f(n, x):
        return n if 0 < x < 1/n else 0

    # integral is always 1
    integrals = [1.0 for n in range(1, 10)]
    assert all(i == 1.0 for i in integrals)

    # point-wise limit is 0
    x = 0.5
    assert f(10, x) == 0
    print("TP2 OK")

test_tp2()
```
