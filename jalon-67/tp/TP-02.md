# TP 2 : Vérification de la limite gaussienne

## Objectif
Implémentation algorithmique du concept correspondant.

## Code Python
```python
import math

def f_n(n, x):
    if -n <= x <= n:
        return math.exp(-x*x)
    return 0.0

def integrate(n, dx=0.01):
    total = 0.0
    x = -n
    while x <= n:
        total += f_n(n, x) * dx
        x += dx
    return total

def tp2():
    print("sqrt(pi) =", math.sqrt(math.pi))
    for n in range(1, 10):
        print("n=", n, "int=", integrate(n))

if __name__ == '__main__':
    tp2()
```
