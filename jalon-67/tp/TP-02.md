# TP 02 : Simulation d'une perte de monotonie

Le code Python pure suivant démontre algorithmiquement le concept étudié.

```python
# On simule le contre-exemple f_n(x) = n * 1_{]0, 1/n]}(x)
def f_pathological(x, n):
    if 0 < x <= 1.0 / n:
        return float(n)
    return 0.0

def integrate_riemann(func, n, a, b, num_steps=10000):
    step_size = (b - a) / num_steps
    total = 0.0
    for i in range(num_steps):
        x_mid = a + (i + 0.5) * step_size
        total += func(x_mid, n) * step_size
    return total

# Calcul de la limite des intégrales
integrals = []
for n in [10, 50, 100, 200]:
    integrals.append(integrate_riemann(f_pathological, n, 0, 1))

# La limite simple f(x) = 0 pour tout x > 0
# Intégrale de f(x) est 0.

print("Les intégrales successives valent environ 1 :", integrals)
# La monotonie n'est pas vérifiée !
x_test = 0.05
assert f_pathological(x_test, 10) > f_pathological(x_test, 100), "La fonction décroît localement, Beppo Levi ne s'applique pas."
print("TP 2 Validé !")
```
