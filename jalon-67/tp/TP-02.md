# TP 02 : Observation de la fonction indicatrice mobile (Contre-exemple)


Ce TP illustre le cas où le TCM **échoue** parce que la suite de fonctions n'est pas croissante, utilisant la fonction pôle glissante : $f_n(x) = n \mathbf{1}_{[0, 1/n]}(x)$.

```python
def integrate(func, a, b, n_steps=5000):
    step = (b - a) / n_steps
    return sum(func(a + i * step) * step for i in range(n_steps))

def f_n(x, n):
    return n if 0 <= x <= 1/n else 0

def test_tcm_tp02():
    a, b = 0.0, 1.0

    # Pour n'importe quel x > 0 fixe, la limite quand n -> infini est 0
    # Donc l'integrale de la limite est 0.
    int_limit = 0.0

    # Pour un n fixe, l'integrale est toujours l'aire d'un rectangle de largeur 1/n et hauteur n
    int_n = integrate(lambda x: f_n(x, 100), a, b, 10000)

    # Validation de l'echec du TCM
    assert abs(int_n - 1.0) < 1e-1, "L'integrale de fn devrait valoir 1"
    assert int_limit != int_n, "Le TCM s'applique a tort"

    print(f"TP 02: Contre-exemple TCM valide. Limite des int = {int_n:.2f}, Int de la limite = {int_limit}")

if __name__ == '__main__':
    test_tcm_tp02()
```
