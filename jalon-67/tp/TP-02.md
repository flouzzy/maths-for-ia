
# TP 2 : Simulation de la fuite de masse

Nous modélisons le contre-exemple classique : une suite de fonctions $f_n(x) = n \cdot 1_{(0, 1/n)}(x)$ qui n'est *pas* croissante. La limite ponctuelle est 0, l'intégrale est 1. La simulation vérifie que le TCM échoue.

```python
# Validation pure Python, sans modules externes

def f_n_mass(n, x):
    # La cloche de Dirac rectangulaire de masse 1
    if 0.0 < x < 1.0 / n:
        return float(n)
    return 0.0

def integrate_mass(n_arg, a, b, num_steps=10000):
    # Intégration adaptée à la largeur du pic pour ne pas le rater
    # Le pic est entre 0 et 1/n
    width = (b - a) / num_steps
    total_area = 0.0
    for i in range(num_steps):
        x = a + i * width + (width / 2.0) # point milieu
        total_area += f_n_mass(n_arg, x) * width
    return total_area

def run_tp2():
    # Intégrales pour des n croissants
    integrals = []
    for n in [10, 100, 1000]:
        val = integrate_mass(n, 0.0, 1.0, num_steps=20000)
        integrals.append(val)

    # Toutes les intégrales doivent valoir exactement (ou presque) 1.0
    for val in integrals:
        assert 0.95 < val < 1.05, f"La masse de chaque fn est 1.0, calculée: {val}"

    # Limite ponctuelle en un x fixé (ex: x=0.5)
    limit_ponctuelle_05 = f_n_mass(1000, 0.5)
    assert limit_ponctuelle_05 == 0.0, "La fonction tend vers 0 ponctuellement"

    print("TP 2 : Le contre-exemple fonctionne. Masse constante = 1, limite = 0.")

if __name__ == "__main__":
    run_tp2()
```
