# TP 2 : Série Harmonique et Divergence

## Objectif
Implémentation algorithmique sans bibliothèques externes pour valider les comportements asymptotiques étudiés.

## Implémentation

```python
def u(n):
    return 1.0 / (n + 1)

somme = 0
for n in range(10000):
    somme += u(n)
    if n % 2000 == 0:
        print("Somme partielle", n, ":", somme)
# La limite diverge lentement, illustrant l'intégration d'une somme infinie non bornée
```
