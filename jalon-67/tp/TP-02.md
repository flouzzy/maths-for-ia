# TP 02 : Sommation de la série harmonique expérimentale

Ce TP implémente de manière concrète une propriété liée au Théorème de Convergence Monotone ou à ses limites de validité.

```python
# tp_02_simulation.py

def term_n(x, n):
    return sum(x**k for k in range(n))

def integrate_rectangle(func, a, b, n, steps=1000):
    dx = (b - a) / steps
    return sum(func(a + i*dx, n) * dx for i in range(steps))

def test_tp02():
    # Integrating from 0 to 0.5 where series converges to ln(2)
    res = integrate_rectangle(term_n, 0, 0.5, 20)
    expected = 0.693147  # ln(2)
    assert abs(res - expected) < 1e-2, "Error in TP02"
    print("TP02: Interversion série/intégrale valide (convergence finie).")

if __name__ == '__main__':
    test_tp02()
```
