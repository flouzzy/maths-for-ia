# TP 2 : Simulation de la non-applicabilité sans croissance

Ce script Python démontre numériquement le processus de convergence monotone.

```python
def f(n, x):
    # n * exp(-nx) sur [0, 1]
    import math
    if x <= 0 or x >= 1: return 0.0
    return n * math.exp(-n*x)

def riemann_sum(n, steps=10000):
    dx = 1.0 / steps
    total = 0.0
    for i in range(steps):
        x = (i + 0.5) * dx
        total += f(n, x) * dx
    return total

print("n | Intégrale de fn | f_n(0.5)")
for n in range(1, 10):
    integral = riemann_sum(n)
    val_point = f(n, 0.5)
    print(f"{n} | {integral:.5f} | {val_point:.5f}")

print("L'intégrale converge vers 1, mais la fonction limite est 0.")
print("La suite n'est pas croissante, Beppo-Levi est en defaut.")
```
