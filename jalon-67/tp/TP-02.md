# TP 2 : Simulation de la bosse glissante

## Objectif
Mettre en évidence numériquement le contre-exemple classique (la bosse glissante) où le Théorème de Convergence Monotone ne s'applique pas par défaut de croissance.

## Implémentation

```python
def f_n(n, x):
    # La bosse glissante: n * indicator_]0, 1/n[
    if 0 < x < 1.0/n:
        return n
    return 0

def riemann_integral_f_n(n, num_points=10000):
    # Approximation par somme de Riemann
    dx = 2.0 / num_points # integrer sur [0, 2]
    integral = 0.0
    for i in range(num_points):
        x = i * dx
        integral += f_n(n, x) * dx
    return integral

def main():
    print("Integrales de la bosse glissante:")
    for n in [1, 5, 10, 50, 100]:
        val = riemann_integral_f_n(n)
        print("n =", n, ", Integrale =", val)

    print("La limite des integrales reste ~1.0, bien que la limite ponctuelle soit 0.")

if __name__ == "__main__":
    main()
```
