# TP 2 : Vérification algorithmique

Dans ce TP, nous implémentons en pur Python les concepts liés au Théorème de Convergence Monotone.

```python
# Validation purement numérique
def solve_tp():
    # TP2: Series sum vs Integral interversion
    import math
    steps = 1000
    dx = 1.0 / steps

    integral_sum = 0.0
    for i in range(1, steps):
        x = i * dx
        # sum of (x/2)^n for n=0 to 50
        series_val = 0.0
        for n in range(50):
            series_val += (x/2)**n
        integral_sum += series_val * dx

    expected = 2 * math.log(2)
    assert abs(integral_sum - expected) < 0.1
    print(f"TP2: Series and Integral interversion verified. Calculated {integral_sum}, Expected {expected}")

if __name__ == '__main__':
    solve_tp()
```
