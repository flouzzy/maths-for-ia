# TP 5 : Optimisation par EM-algorithme et monotonie de la vraisemblance

## Description

Dans cet exercice, on simule l'évolution strictement croissante de la borne inférieure de la fonction de log-vraisemblance (ELBO) qui justifie l'interversion de Beppo-Levi dans le Variational Inference.

## Code Python (Pure Algorithmie)

```python
# Simulation de l'evolution monotone d'une fonction de cout (ELBO)
# L'algorithme EM genere une suite croissante de minorants

def EM_step(mu_prev, data):
    # Simplification : estimation de la moyenne d'une mixture 1D
    n = len(data)
    # E-step : calcul de la responsabilite
    resp = [1.0 if abs(x - mu_prev) < 2.0 else 0.1 for x in data]

    # M-step : mise a jour
    num = sum(r * x for r, x in zip(resp, data))
    den = sum(resp)
    mu_new = num / den

    # Approximation de l'ELBO
    elbo = sum(r * -abs(x - mu_new) for r, x in zip(resp, data))
    return mu_new, elbo

def test_EM_monotonicity():
    data = [1.2, 1.4, 1.1, 5.0, 5.2, 4.9]
    mu = 0.0 # initialisation arbitraire

    prev_elbo = -float('inf')

    print("Initial mu:", mu)
    for i in range(10):
        mu, elbo = EM_step(mu, data)
        print("Iteration", i, "mu:", mu, "ELBO:", elbo)

        # Le theoreme fondamental de l'EM garantit la croissance de l'ELBO
        assert elbo >= prev_elbo - 1e-5
        prev_elbo = elbo

test_EM_monotonicity()
```
