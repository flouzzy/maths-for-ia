# TP 5 : Vérification algorithmique

Dans ce TP, nous implémentons en pur Python les concepts liés au Théorème de Convergence Monotone.

```python
# Validation purement numérique
def solve_tp():
    # TP5: Checking properties of monotone sequences
    # Verify that a_n = x^(1/n) is strictly increasing for x in ]0, 1[
    x = 0.5
    prev = 0.0
    for n in range(1, 20):
        curr = x**(1/n)
        assert curr > prev
        prev = curr
    print("TP5: Monotonicity property strictly verified for power sequence.")

if __name__ == '__main__':
    solve_tp()
```
