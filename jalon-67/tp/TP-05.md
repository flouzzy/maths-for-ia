# TP 5 : Série de fonctions et IPP

**Objectif :** Calcul numérique de l'exercice 8 : integrale de x log(x)/(1-x)

```python
import math

def f(x):
    if x <= 0 or x >= 1: return 0.0
    return -x * math.log(x) / (1 - x)

def integrate_riemann(func, a, b, n_steps=10000):
    dx = (b - a) / n_steps
    return sum(func(a + i*dx + dx/2) * dx for i in range(n_steps))

integral_val = integrate_riemann(f, 0, 1)

# Valeur limite de la serie sum_k 1/(k+1)^2 = pi^2 / 6 - 1
limit_val = math.pi**2 / 6.0 - 1.0

print(f'Valeur integrale de Lebesgue: {integral_val:.6f}')
print(f'Valeur theoremique (Beppo Levi): {limit_val:.6f}')
assert abs(integral_val - limit_val) < 1e-2, 'Erreur integration'
```
