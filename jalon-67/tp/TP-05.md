# TP 5 : Méthode de Monte Carlo et Interversion

**Objectif :** Implémenter une approximation de type Monte-Carlo pour vérifier statistiquement l'interversion d'une limite et d'une espérance sur une suite croissante de variables aléatoires (illustrant Beppo Levi en probabilités).

```python
import random

def random_variable_sequence(n):
    # Generateur aleatoire uniforme sur [0, 1]
    u = random.random()
    # On simule une suite croissante X_n(u)
    # X_n(u) = -log(u) * (1 - e^(-n))
    import math
    return -math.log(u + 1e-10) * (1 - math.exp(-n))

def monte_carlo_expectation(n, num_samples=10000):
    total = 0.0
    for _ in range(num_samples):
        total += random_variable_sequence(n)
    return total / num_samples

def test_monte_carlo_beppo_levi():
    # E[X_n]
    E_1 = monte_carlo_expectation(1)
    E_5 = monte_carlo_expectation(5)
    E_10 = monte_carlo_expectation(10)

    # La suite des esperances doit etre croissante car la suite de V.A. est croissante
    assert E_1 <= E_5 <= E_10

    # L'esperance de la limite (X = -log(u)) qui suit une loi exponentielle
    # L'esperance theorique d'une exponentielle de parametre 1 est 1.0
    expected_limit = 1.0

    # Pour n grand, E_n doit etre proche de 1.0
    assert abs(E_10 - expected_limit) < 0.1, "L'esperance ne converge pas correctement"
    print("TP5: TCM applique a l'esperance de processus stochastiques valide.")

test_monte_carlo_beppo_levi()
```
