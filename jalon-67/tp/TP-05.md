# TP 05 : Fonction de Dirichlet approchée


Ce TP tente d'illustrer la divergence de la série harmonique tronquée en vérifiant l'ordre de grandeur de l'intégrale de la série géométrique approchant 1/(1-x) près de la singularité.

```python
import math

def integrate(func, a, b, n_steps=2000):
    step = (b - a) / n_steps
    return sum(func(a + i * step) * step for i in range(n_steps))

def f_n(x, n):
    return sum(x**k for k in range(n))

def test_tcm_tp05():
    # Sur l'intervalle [0, 1-epsilon], la croissance des integrales des polynomes
    # doit correspondre a la croissance logarithmique due au pole en 1.
    epsilon = 1e-4
    a, b = 0.0, 1.0 - epsilon

    n_val = 50
    # Integral de f_n est sum( (1-epsilon)^(k+1) / (k+1) )
    int_approx = integrate(lambda x: f_n(x, n_val), a, b, 2000)

    # La valeur exacte de l'integrale limite int_0^{1-eps} 1/(1-x) dx est -ln(eps)
    val_limite = -math.log(epsilon)

    # TCM garantit que l'integrale de f_n monte vers cette limite
    assert int_approx <= val_limite, "L'integrale approchee depasse la limite theorique !"

    print(f"TP 05: TCM près du pôle. Int(n=50)={int_approx:.4f}, Limite Theoretiqe={val_limite:.4f}")

if __name__ == '__main__':
    test_tcm_tp05()
```
