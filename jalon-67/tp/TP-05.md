# TP 05 : Échec de l'interversion sur une suite non croissante (Contre-exemple Fatou)

Ce TP implémente de manière concrète une propriété liée au Théorème de Convergence Monotone ou à ses limites de validité.

```python
# tp_05_simulation.py

def f_bump(x, n):
    if n <= x <= n+1:
        return 1.0
    return 0.0

def integrate_bump(n, steps=1000):
    # Integral on [0, 20]
    res = 0.0
    for i in range(20 * steps):
        x = i / steps
        res += f_bump(x, n) * (1/steps)
    return res

def test_tp05():
    # For n=5, integral is 1
    int_n5 = integrate_bump(5)
    assert abs(int_n5 - 1.0) < 1e-2, "Error computing bump integral"

    # Pointwise limit as n->inf is 0. Integral of limit is 0.
    # Limit of integrals is 1.
    # TCM does not apply because fn is NOT increasing!
    print("TP05: Échec du TCM justifié car absence de croissance.")

if __name__ == '__main__':
    test_tp05()
```
