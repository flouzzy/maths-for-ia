# TP 5 : Convergence monotone sur une série double (Mesure de comptage)

## Objectif
Implémentation algorithmique du concept correspondant.

## Code Python
```python
def a(i, j):
    if i == j:
        return 1.0 / (2 ** i)
    return 0.0

def partial_sum(N):
    total = 0.0
    for i in range(N):
        for j in range(N):
            total += a(i, j)
    return total

def tp5():
    for N in [1, 2, 5, 10, 20]:
        print("N=", N, "sum=", partial_sum(N))

if __name__ == '__main__':
    tp5()
```
