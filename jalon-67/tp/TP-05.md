# TP 05 : Densité et Additivité de la mesure

Le code Python pure suivant démontre algorithmiquement le concept étudié.

```python
# Discrétisation grossière d'une mesure
class Measure:
    def __init__(self, items):
        self.items = items
    def __call__(self, condition_func):
        return sum(1 for x in self.items if condition_func(x))

space = list(range(1, 101))
mu = Measure(space)

# Ensembles disjoints
A1 = lambda x: 1 <= x <= 20
A2 = lambda x: 21 <= x <= 50
A3 = lambda x: 51 <= x <= 100

union_func = lambda x: A1(x) or A2(x) or A3(x)

# Vérification empirique de mu(A U B U C) = mu(A) + mu(B) + mu(C)
mu_union = mu(union_func)
sum_mu = mu(A1) + mu(A2) + mu(A3)

assert mu_union == sum_mu, "L'additivité a échoué"
print("TP 5 Validé, l'additivité des ensembles disjoints vérifie l'intégration des indicatrices.")
```
