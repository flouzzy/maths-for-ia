# TP 5 : Algorithme d'interversion de sommes doubles positives

Ce script Python démontre numériquement le processus de convergence monotone.

```python
# Matrice double infinie (ici de grande taille) positive
# Verification empirique de Fubini pour la mesure de comptage

N_size = 100
matrix = [[0.0 for _ in range(N_size)] for _ in range(N_size)]

# a_{i,j} = 1 / (2^{i+j+2})
for i in range(N_size):
    for j in range(N_size):
        matrix[i][j] = 1.0 / (2**(i+j+2))

# Somme par lignes puis colonnes
sum_rows_first = 0.0
for i in range(N_size):
    row_sum = 0.0
    for j in range(N_size):
        row_sum += matrix[i][j]
    sum_rows_first += row_sum

# Somme par colonnes puis lignes
sum_cols_first = 0.0
for j in range(N_size):
    col_sum = 0.0
    for i in range(N_size):
        col_sum += matrix[i][j]
    sum_cols_first += col_sum

print(f"Somme (Lignes):   {sum_rows_first:.7f}")
print(f"Somme (Colonnes): {sum_cols_first:.7f}")
assert abs(sum_rows_first - sum_cols_first) < 1e-9
```
