# TP 5 : La bosse croissante et TCM

## Objectif
Montrer le cas d'une suite où la limite ponctuelle est infinie et l'intégrale diverge vers l'infini, respectant le TCM étendu à $[0, \infty]$.

## Implémentation

```python
def f_n(n, x):
    # S_n(x) = 1 sur [1, n+1], 0 ailleurs
    if 1.0 <= x <= (n + 1.0):
        return 1.0
    return 0.0

def integrate_fn(n, max_x=100):
    # integration Riemann basique
    dx = 0.1
    integral = 0.0
    # max_x definit la borne sup d'integration approchee
    num_points = int(max_x / dx)
    for i in range(num_points):
        x = i * dx
        integral += f_n(n, x) * dx
    return integral

def main():
    print("Integration de l'indicatrice sur [1, n+1]")
    for n in [5, 10, 20, 50]:
        val = integrate_fn(n, 100)
        print("n =", n, ", Integrale sur R ~", round(val, 2))

    print("La limite est infinie, comme le predisent la limite simple (indicatrice [1, inf[) et le TCM.")

if __name__ == "__main__":
    main()
```
