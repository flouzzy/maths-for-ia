# TP 5 : Monotonie empirique

## Objectif
Validation numérique.

## Code Python
```python
def test_tp5():
    # Verify integral of fn <= integral of f
    def fn(x): return x**2
    def f(x): return x**2 + 0.1

    def integrate(func):
        return sum(func(i/100)*0.01 for i in range(100))

    assert integrate(fn) <= integrate(f)
    print("TP5 OK")

test_tp5()
```
