# TP 5 : Sommation des pixels (Mesure de comptage 2D)

En traitement d'image, sommer les valeurs de tous les pixels par lignes puis par colonnes (Fubini/Beppo Levi) donne le même résultat.

\begin{lstlisting}[language=Python]
# TP5: Invariance de l'ordre de sommation par TCM discret

# Simulation d'une matrice image 3x3 positive (niveaux de gris)
image = [
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
]

# Methode 1: Somme par lignes d'abord
somme_lignes = 0
for ligne in range(3):
    somme_locale = 0
    for col in range(3):
        somme_locale += image[ligne][col]
    somme_lignes += somme_locale

# Methode 2: Somme par colonnes d'abord
somme_colonnes = 0
for col in range(3):
    somme_locale = 0
    for ligne in range(3):
        somme_locale += image[ligne][col]
    somme_colonnes += somme_locale

print("Somme Lignes :", somme_lignes)
print("Somme Colonnes :", somme_colonnes)

# Beppo Levi sur la mesure de comptage double garantit cette egalite
assert somme_lignes == somme_colonnes
assert somme_lignes == 450
\end{lstlisting}
