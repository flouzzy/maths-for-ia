## TP 3 : Interversion pour les séries (Corollaire)

Simulation de l'intégration terme à terme d'une série géométrique $x^n$.

```python
def tp3_series_interversion():
    steps = 1000
    # On evite 1 pour la singularite, on integre sur [0, 0.99]
    upper = 0.99
    dx = upper / steps

    # Calcul direct somme des integrales
    sum_integrals = 0.0
    for n in range(0, 100):
        # int x^n dx = x^(n+1)/(n+1) evalue en upper
        sum_integrals += (upper**(n+1)) / (n+1)

    # Calcul integrale de la somme x / (1-x) => correction: somme = 1/(1-x) pour n de 0 a l'infini
    # L'integrale de 1/(1-x) sur [0, R] est -ln(1-R)
    integral_of_sum = 0.0
    for s in range(steps):
        x = s * dx + dx/2 # midpoint
        val = 1.0 / (1.0 - x)
        integral_of_sum += val * dx

    print("Somme des integrales :", sum_integrals)
    print("Integrale de la somme :", integral_of_sum)

    diff = sum_integrals - integral_of_sum
    if diff < 0: diff = -diff
    assert diff < 0.01

tp3_series_interversion()
```
