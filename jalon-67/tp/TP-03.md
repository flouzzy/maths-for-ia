# TP 03 : Fonction étagée et passage à la limite

Ce TP implémente de manière concrète une propriété liée au Théorème de Convergence Monotone ou à ses limites de validité.

```python
# tp_03_simulation.py

def f_step(x, n):
    import math
    if x < 1 - 1.0/n:
        return 1.0
    return 0.0

def integrate_step(func, a, b, n, steps=1000):
    dx = (b - a) / steps
    return sum(func(a + i*dx, n) * dx for i in range(steps))

def test_tp03():
    res = integrate_step(f_step, 0, 1, 100)
    # The integral should be roughly 1 - 1/100 = 0.99
    assert abs(res - 0.99) < 1e-2, "Error in TP03"
    print("TP03: Limite d'intégrales de fonctions indicatrices réussie.")

if __name__ == '__main__':
    test_tp03()
```
