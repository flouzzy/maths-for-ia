# TP 3 : Série de fonctions positives

## Objectif
Implémentation algorithmique du concept correspondant.

## Code Python
```python
def u_n(n, x):
    return (x ** n) / (math.factorial(n)) if x > 0 else 0

def sum_u_N(N, x):
    return sum(u_n(n, x) for n in range(N))

def integrate_sum(N, x_max=5.0, dx=0.01):
    total = 0.0
    x = 0
    while x <= x_max:
        total += sum_u_N(N, x) * dx
        x += dx
    return total

def tp3():
    for N in [1, 2, 5, 10]:
        print("N=", N, "int=", integrate_sum(N))

if __name__ == '__main__':
    import math
    tp3()
```
