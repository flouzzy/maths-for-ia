# TP 3 : Vérification algorithmique

Dans ce TP, nous implémentons en pur Python les concepts liés au Théorème de Convergence Monotone.

```python
# Validation purement numérique
def solve_tp():
    # TP3: Lack of Monotonicity counter-example
    # f_n(x) = n for x in ]0, 1/n], 0 elsewhere.
    # Integral is always 1, but limit function is 0.
    for n in [10, 100, 1000]:
        val_x = 0.5 / n # inside the spike
        f_val = n
        integral = 1.0 # width 1/n * height n
        assert integral == 1.0
        # for x = 0.1, if n > 10, f_n(x) = 0
        if n > 10:
            assert (0 if 0.1 > 1/n else n) == 0
    print("TP3: Loss of mass counter-example verified without monotonicity.")

if __name__ == '__main__':
    solve_tp()
```
