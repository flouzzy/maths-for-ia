# TP 3 : Calcul d'aire croissante

## Objectif
Implémentation algorithmique sans bibliothèques externes pour valider les comportements asymptotiques étudiés.

## Implémentation

```python
import math
def rect_area(width, height):
    return width * height

def sum_rectangles(n):
    area = 0
    dx = 1.0 / n
    for i in range(n):
        x = i * dx
        area += rect_area(dx, math.exp(x))
    return area

print(sum_rectangles(10))
print(sum_rectangles(100))
print(sum_rectangles(1000))
print("Valeur limite e-1 :", math.exp(1)-1)
```
