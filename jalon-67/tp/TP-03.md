# TP 3 : Simulation numérique de la convergence monotone

L'objectif de ce TP est de vérifier par l'implémentation pure Python le comportement décrit par le théorème de convergence monotone pour une suite de fonctions positives.

```python
# Implementation d'une suite croissante de fonctions
def f(n, x):
    sum_val = 0
    for k in range(1, n + 1):
        sum_val += (x ** k) / (k + 3)
    return sum_val

def numerical_integration(n, steps=1000):
    dx = 1.0 / steps
    integral = 0
    for j in range(steps):
        x = j * dx
        integral += f(n, x) * dx
    return integral

# Verification de la croissance de l'integrale
prev_integral = -1
for n in range(1, 15):
    current = numerical_integration(n)
    assert current >= prev_integral, "Erreur: La suite des integrales doit etre croissante."
    prev_integral = current
    print(f"n = {n}, Integrale = {current:.6f}")
```
