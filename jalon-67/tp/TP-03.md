# TP 03 : Application à l'espérance discrète infinie


On modélise une variable aléatoire géométrique et on calcule son espérance directement (avec les masses de Dirac) puis via la formule $\sum P(X > k)$ démontrée par le TCM.

```python
def proba_geom(k, p):
    # P(X=k)
    return p * (1 - p)**(k - 1)

def proba_geom_sup(n, p):
    # P(X > n)
    return (1 - p)**n

def test_tcm_tp03():
    p = 0.3
    max_k = 100

    # Esperance directe (limite des integrales par rapport a la mesure de comptage)
    esp_direct = sum(k * proba_geom(k, p) for k in range(1, max_k))

    # Esperance par sommation de P(X > n) (integrale limite apres interversion TCM)
    esp_tcm = sum(proba_geom_sup(n, p) for n in range(0, max_k))

    valeur_theorique = 1 / p

    assert abs(esp_direct - valeur_theorique) < 1e-3, "Erreur dans le calcul direct"
    assert abs(esp_tcm - valeur_theorique) < 1e-3, "Erreur dans le calcul TCM"

    print(f"TP 03: Validation Espérance. Directe={esp_direct:.4f}, Formule TCM={esp_tcm:.4f}, Theo={valeur_theorique:.4f}")

if __name__ == '__main__':
    test_tcm_tp03()
```
