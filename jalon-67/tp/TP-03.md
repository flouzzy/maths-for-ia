# TP 3 : Calcul de pi^2 / 6

## Objectif
Validation numérique.

## Code Python
```python
def test_tp3():
    # sum 1/n^2
    total = 0.0
    for n in range(1, 1000):
        total += 1.0 / (n * n)
    pi_sq_6 = 3.1415926535**2 / 6
    assert abs(total - pi_sq_6) < 0.01
    print("TP3 OK")

test_tp3()
```
