# TP 3 : TCM sur une mesure discrète

**Objectif :** Illustration du corollaire d'inversion Somme/Intégrale. Calculons $\sum \int = \int \sum$ avec une grille.

```python
def u_n(x, n):
    return (x/2)**n

def sum_u_n(x, N):
    return sum(u_n(x, n) for n in range(N+1))

def integrate_discrete(func, grid):
    return sum(func(x) for x in grid)

grid = [0.1, 0.5, 0.9, 1.2]

# Somme des integrales
sum_of_integrals = sum(integrate_discrete(lambda x: u_n(x, n), grid) for n in range(50))

# Integrale de la limite (somme de la serie 1/(1 - x/2))
integral_of_sum = integrate_discrete(lambda x: 1/(1 - x/2), grid)

print(f'Somme des integrales : {sum_of_integrals:.6f}')
print(f'Integrale de la somme : {integral_of_sum:.6f}')
assert abs(sum_of_integrals - integral_of_sum) < 1e-4, 'Echec de Beppo Levi discret'
```
