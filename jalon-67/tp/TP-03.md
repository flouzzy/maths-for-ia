# TP 3 : Approximation de l'intégrale d'une série entière

## Objectif
Vérifier expérimentalement l'interversion somme-intégrale garantie par le TCM pour $1/(1-x) = \sum x^n$ sur un intervalle $[0, 0.99]$.

## Implémentation

```python
def integrate_term(n, a, b):
    # Primitive de x^n est x^(n+1)/(n+1)
    return (b**(n+1)) / (n+1) - (a**(n+1)) / (n+1)

def sum_integrals(max_n, a, b):
    total = 0.0
    for n in range(max_n + 1):
        total += integrate_term(n, a, b)
    return total

def exact_integral_log(a, b):
    import math
    # primitive de 1/(1-x) est -ln(1-x)
    return -math.log(1 - b) - (-math.log(1 - a))

def main():
    a = 0.0
    b = 0.99
    print("Integrale exacte de 1/(1-x) sur [0, 0.99] :", exact_integral_log(a, b))

    for max_n in [10, 50, 100, 500]:
        val = sum_integrals(max_n, a, b)
        print("Somme des integrales jusqu a N =", max_n, ":", val)

if __name__ == "__main__":
    main()
```
