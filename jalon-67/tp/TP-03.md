# TP 3 : Processus d'approximation par escalier

Ce script Python démontre numériquement le processus de convergence monotone.

```python
import math

def target_function(x):
    # f(x) = -ln(x) sur ]0, 1]
    if x <= 0: return 0.0
    return -math.log(x)

def approximate_step_function(x, n):
    # Construit une suite croissante de fonctions étagées
    # On découpe l'image en intervalles de taille 1/2^n
    # et on tronque à la hauteur n
    val = target_function(x)
    if val >= n:
        return float(n)
    else:
        # Troncation inférieure sur la grille
        steps = 2**n
        return math.floor(val * steps) / steps

print("x=0.5, Target: ", target_function(0.5))
for n in range(1, 6):
    print(f"n={n}, Approximation: {approximate_step_function(0.5, n)}")

# Validation d'ordre (croissance p.p.)
x_test = 0.3
for n in range(1, 5):
    assert approximate_step_function(x_test, n) <= approximate_step_function(x_test, n+1)
```
