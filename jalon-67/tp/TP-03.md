# TP 3 : Contre-exemple du théorème (fonctions non positives)

On simule le contre-exemple de l'exercice 9 où le TCM échoue car les fonctions sont négatives.

\begin{lstlisting}[language=Python]
# TP3: Contre-exemple f_n(x) = -1/n pour x dans (0, n]

def fn_neg(x, n):
    if x > 0 and x <= n:
        return -1.0 / n
    return 0.0

def integrale_fn_neg(n):
    # Calcul strict de la surface (base * hauteur)
    # Base = n, Hauteur = -1/n -> Integrale = -1
    return n * (-1.0 / n)

# Verifions pour differentes valeurs de n
for n in [10, 100, 1000]:
    integral = integrale_fn_neg(n)
    print("n=", n, " Integrale fn =", integral)
    assert integral == -1.0

# La limite des integrales est -1
# Mais la limite de f_n est 0 partout, d'integrale 0.
# Le TCM est bien mis en defaut.
\end{lstlisting}
