# TP 3 : Convergence monotone et séries entières

## Description

Application du corollaire de Beppo-Levi pour intervertir série et intégrale sur des termes positifs numériquement.

## Code Python (Pure Algorithmie)

```python
# Interversion d'integrale et serie infinie
# Calcul de l'integrale de sum(x**n) sur [0, 1] pour x in ]0, 1[

def integrate_term(n, steps=10000):
    # integrale de x**n dx sur [0, 1[
    dx = 1.0 / steps
    total = 0.0
    for i in range(steps):
        x = (i + 0.5) * dx
        total += (x ** n) * dx
    return total

def sum_integrals(max_terms):
    total = 0.0
    for n in range(max_terms):
        total += integrate_term(n)
    return total

def integrate_sum(max_terms, steps=10000):
    # integrale de la somme partielle
    dx = 1.0 / steps
    total = 0.0
    for i in range(steps):
        x = (i + 0.5) * dx
        s = sum([x**n for n in range(max_terms)])
        total += s * dx
    return total

def test_series():
    s1 = sum_integrals(20)
    s2 = integrate_sum(20)
    print("Somme des integrales :", s1)
    print("Integrale de la somme:", s2)
    assert abs(s1 - s2) < 1e-4

test_series()
```
