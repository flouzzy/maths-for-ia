## 1. Code
```python
def check_inequality():
    '''
    Vérification de (x+y)/2 >= sqrt(x*y) pour des entiers
    '''
    for x in range(100):
        for y in range(100):
            left = (x+y)/2
            right = (x*y)**0.5
            assert left >= right, f"Failed for {x}, {y}"

check_inequality()
```
