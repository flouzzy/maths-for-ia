# TP 4 : Constante d'Euler-Mascheroni par série absolue

## Objectif

Implémenter le calcul de gamma via la série absolue de l'Exercice 10 et vérifier empiriquement sa nature $O(1/n^2)$.

## Code Python
```python
def calcul_gamma_serie(N):
    import math
    somme = 0.0
    for n in range(1, N + 1):
        somme += 1.0/n - math.log(1 + 1.0/n)
    return somme

def test_gamma():
    gamma = 0.5772156649
    N = 1000
    calcul = calcul_gamma_serie(N)

    # La série est en 1/2n^2, donc le reste d'ordre N est en 1/2N.
    # On devrait être à ~0.0005 de gamma pour N=1000.
    assert abs(calcul - gamma) < 1e-3
    print(f"TP4: Gamma calculé={calcul:.5f}, Gamma réel={gamma:.5f}")
    print("Tests constante d'Euler passed.")

if __name__ == "__main__":
    test_gamma()

```
