# TP 02 : Divergence de Kullback-Leibler et asymétrie

**Objectif :** Implémenter le calcul de la divergence KL et observer son asymétrie mathématique.

```python
import math

def kl_divergence(p, q):
    """
    Calcule la divergence de Kullback-Leibler D_KL(P || Q).
    p et q sont des listes de probabilités de même taille.
    """
    assert len(p) == len(q), "Les distributions doivent avoir la même taille."

    divergence = 0.0
    for i in range(len(p)):
        if p[i] > 0:
            assert q[i] > 0, "Q(x) ne peut pas être nul si P(x) > 0 (support)."
            divergence += p[i] * math.log(p[i] / q[i]) # Log naturel par défaut

    return divergence

# --- Validation Mathématique ---

# Exemple avec P et Q
P_dist = [0.36, 0.48, 0.16]
Q_dist = [0.333, 0.333, 0.334]

# D_KL(P || Q) n'est pas égal à D_KL(Q || P)
kl_pq = kl_divergence(P_dist, Q_dist)
kl_qp = kl_divergence(Q_dist, P_dist)

print(f"D_KL(P || Q) = {kl_pq:.4f}")
print(f"D_KL(Q || P) = {kl_qp:.4f}")

assert abs(kl_pq - kl_qp) > 0.01, "La divergence KL doit être asymétrique."
assert kl_pq >= 0, "L'inégalité de Gibbs impose D_KL >= 0."

print("Validation mathématique réussie : La divergence KL est bien positive et asymétrique.")
```
