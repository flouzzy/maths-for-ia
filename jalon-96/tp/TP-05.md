# TP 05 : Perplexité et évaluation d'un Modèle de Langage "Jouet"

**Objectif :** Implémenter le calcul de la perplexité, une métrique standard en NLP dérivée de l'entropie croisée.

```python
import math

def calculate_perplexity(cross_entropy_value):
    """
    La perplexité est l'exponentielle de la Cross-Entropy.
    PP = exp(H(P, Q))
    """
    return math.exp(cross_entropy_value)

def eval_model(sequence_probs):
    """
    Évalue la Cross-Entropy moyenne sur une séquence de probabilités prédites.
    """
    n = len(sequence_probs)
    assert n > 0, "Séquence vide"

    # La Cross-Entropy moyenne empirique est -1/N sum log(Q(x_i))
    ce_empirique = -sum(math.log(q_xi) for q_xi in sequence_probs) / n
    return ce_empirique

# --- Validation ---

# Imaginons qu'un modèle évalue une phrase de 5 mots
# Il donne ces probabilités pour les mots *réellement* observés
probs_predites = [0.1, 0.5, 0.05, 0.8, 0.2]

ce_val = eval_model(probs_predites)
perplexity_val = calculate_perplexity(ce_val)

print(f"Cross-Entropy moyenne : {ce_val:.4f}")
print(f"Perplexité : {perplexity_val:.4f}")

# Un modèle parfaitement aléatoire sur un vocabulaire de taille V aurait une perplexité de V.
# Testons avec un modèle aléatoire sur un vocabulaire de 100 mots (prob = 0.01 partout)
probs_aleatoires = [0.01, 0.01, 0.01, 0.01, 0.01]
ce_alea = eval_model(probs_aleatoires)
pp_alea = calculate_perplexity(ce_alea)

print(f"\nModèle aléatoire (V=100) -> Perplexité calculée : {pp_alea:.4f}")

assert abs(pp_alea - 100.0) < 1e-5, "La perplexité d'un modèle uniforme doit valoir |V|."
print("Validation mathématique réussie : La perplexité est correctement exponentiée.")
```
