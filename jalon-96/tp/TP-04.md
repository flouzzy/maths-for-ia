# TP 04 : Entropie croisée empirique et Loi Forte des Grands Nombres

**Objectif :** Simuler l'entraînement d'un modèle et montrer que la moyenne empirique converge vers l'espérance théorique.

```python
import math
import random

# Définition de P (Distribution réelle) et Q (Modèle paramétré)
P_probs = [0.1, 0.2, 0.7]
Q_probs = [0.2, 0.2, 0.6]

def sample_from_P(n_samples):
    """Génère des échantillons selon la distribution P"""
    samples = []
    for _ in range(n_samples):
        r = random.random()
        if r < P_probs[0]:
            samples.append(0)
        elif r < P_probs[0] + P_probs[1]:
            samples.append(1)
        else:
            samples.append(2)
    return samples

# Calcul de l'entropie croisée théorique
H_PQ_theorique = -sum(P_probs[i] * math.log(Q_probs[i]) for i in range(3))

# Simulation
n = 100000
echantillons = sample_from_P(n)

# Calcul de la perte empirique
perte_empirique = 0.0
for x_i in echantillons:
    perte_empirique -= math.log(Q_probs[x_i])
perte_empirique /= n

print(f"Entropie croisée théorique H(P,Q) : {H_PQ_theorique:.6f}")
print(f"Perte empirique sur {n} échantillons : {perte_empirique:.6f}")

# Validation par la LFGN
assert abs(perte_empirique - H_PQ_theorique) < 0.01, "La moyenne empirique ne converge pas vers l'espérance !"
print("Validation mathématique réussie : Convergence par la LFGN vérifiée.")
```
