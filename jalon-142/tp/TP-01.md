### Titre : Processus de décision de Markov (Partie 1: Introduction et Itération sur la Valeur)

**Contexte :**
Dans le vaste domaine de l'intelligence artificielle et de l'apprentissage par renforcement, la prise de décision séquentielle est un défi central. Comment un agent peut-il prendre les meilleures décisions au fil du temps pour maximiser une récompense cumulée, dans un environnement incertain ? C'est précisément la question à laquelle les **Processus de Décision de Markov (PDM)**, ou *Markov Decision Processes (MDP)* en anglais, apportent une formalisation mathématique rigoureuse.

Un PDM modélise un agent qui interagit avec un environnement. L'environnement est caractérisé par un ensemble d'états. À chaque étape, l'agent observe l'état actuel, choisit une action, et l'environnement réagit en passant à un nouvel état et en fournissant une récompense. La caractéristique "Markovienne" implique que l'état futur ne dépend que de l'état et de l'action actuels, et non de l'historique des états et actions précédents.

Ce TP est le premier d'une série de cinq et vise à poser les fondations des PDM. Nous allons définir les composants clés d'un PDM et implémenter l'algorithme d'**Itération sur la Valeur (Value Iteration)** pour trouver la fonction de valeur optimale et la politique optimale associée. Cet algorithme est une méthode de programmation dynamique qui converge vers la solution optimale pour un PDM fini.

**Objectifs de l'implémentation :**
1.  Comprendre et modéliser les composants fondamentaux d'un PDM : états, actions, probabilités de transition, récompenses et facteur d'actualisation.
2.  Implémenter la structure d'un PDM en Python pur, sans l'aide de bibliothèques haut niveau (seule `numpy` est autorisée si absolument indispensable, mais nous nous en passerons pour ce premier TP pour une implémentation la plus pure possible).
3.  Développer l'algorithme d'Itération sur la Valeur pour calculer la fonction de valeur optimale $V^*(s)$ pour chaque état $s$.
4.  Dériver la politique optimale $\pi^*(s)$ à partir de la fonction de valeur optimale.
5.  Valider mathématiquement l'implémentation à l'aide d'assertions pour garantir la conformité aux propriétés des PDM (ex: somme des probabilités de transition).

### Implémentation en Pure Python

Nous allons construire notre PDM et ses algorithmes pas à pas.

#### Étape 1 : Définition des composants d'un PDM

Un PDM est défini par un tuple $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$ où :
*   $\mathcal{S}$ est l'ensemble fini des états.
*   $\mathcal{A}$ est l'ensemble fini des actions.
*   $P$ est la fonction de probabilité de transition, $P(s' | s, a)$, qui donne la probabilité d'atteindre l'état $s'$ en prenant l'action $a$ dans l'état $s$.
*   $R$ est la fonction de récompense, $R(s, a)$, qui donne la récompense immédiate perçue après avoir pris l'action $a$ dans l'état $s$. Pour simplifier ce premier TP, nous utiliserons une récompense dépendante de $(s,a)$ plutôt que $(s,a,s')$.
*   $\gamma$ est le facteur d'actualisation (discount factor), $0 \le \gamma < 1$. Il détermine l'importance des récompenses futures.

Nous allons représenter ces composants à l'aide de listes et de listes imbriquées en Python.

**Exemple de PDM : Un problème de navigation simple**

Imaginons un petit robot qui peut se déplacer dans un couloir à 3 états :
*   État 0 : Départ
*   État 1 : Milieu
*   État 2 : Arrivée (un état de récompense)

Le robot a deux actions possibles dans chaque état :
*   Action 0 : "Rester"
*   Action 1 : "Avancer"

Les transitions et récompenses sont définies comme suit :

*   **États :** `num_states = 3` (indexés de 0 à 2)
*   **Actions :** `num_actions = 2` (indexées de 0 à 1)
*   **Facteur d'actualisation :** `gamma = 0.9`

**Probabilités de transition `P[s][a][s_prime]` :**
Pour chaque état `s` et action `a`, la somme des probabilités $P(s'|s,a)$ pour tous les `s_prime` doit être égale à 1.

```python
# Définition des paramètres du PDM
num_states = 3
num_actions = 2
gamma = 0.9  # Facteur d'actualisation

# Probabilités de transition P[s][a][s_prime]
# P[état actuel][action][état suivant]
# Initialisation avec des zeros
P = [[[0.0 for _ in range(num_states)] for _ in range(num_actions)] for _ in range(num_states)]

# Définition des transitions pour notre PDM simple
# État 0 (Départ)
# Si l'agent reste (Action 0) : Reste en état 0
P[0][0][0] = 1.0
# Si l'agent avance (Action 1) : Va en état 1
P[0][1][1] = 1.0

# État 1 (Milieu)
# Si l'agent reste (Action 0) : Reste en état 1
P[1][0][1] = 1.0
# Si l'agent avance (Action 1) : Va en état 2
P[1][1][2] = 1.0

# État 2 (Arrivée / Terminal)
# Si l'agent reste (Action 0) : Reste en état 2 (état terminal/goal)
P[2][0][2] = 1.0
# Si l'agent avance (Action 1) : Reste en état 2 (état terminal/goal)
P[2][1][2] = 1.0

# Récompenses R[s][a]
# R[état actuel][action] - récompense immédiate
# Nous simplifions en R(s,a) pour ce TP
R = [[0.0 for _ in range(num_actions)] for _ in range(num_states)]

# Définition des récompenses
# État 0
R[0][0] = 0.0  # Rester à l'état 0
R[0][1] = -1.0 # Avancer de l'état 0 vers 1 (coût de déplacement)

# État 1
R[1][0] = 0.0  # Rester à l'état 1
R[1][1] = -1.0 # Avancer de l'état 1 vers 2 (coût de déplacement)

# État 2 (État d'arrivée/goal)
R[2][0] = 10.0 # Rester à l'état 2 (récompense positive pour être arrivé)
R[2][1] = 10.0 # Tenter d'avancer depuis l'état 2 (récompense positive pour être arrivé)
```

**Validation Mathématique : Assertions sur les probabilités de transition**

Il est crucial que pour chaque paire (état, action), la somme des probabilités de transition vers tous les états suivants soit égale à 1.

```python
print("Validation des probabilités de transition...")
for s in range(num_states):
    for a in range(num_actions):
        sum_probs = sum(P[s][a][s_prime] for s_prime in range(num_states))
        # Utilisation d'une petite tolérance pour les comparaisons de flottants
        assert abs(sum_probs - 1.0) < 1e-9, \
            f"Erreur de probabilité pour P[{s}][{a}]: la somme est {sum_probs}, devrait être 1.0"
print("Probabilités de transition validées avec succès !")
```

#### Étape 2 : L'Algorithme d'Itération sur la Valeur

L'Itération sur la Valeur est un algorithme qui trouve la fonction de valeur optimale $V^*(s)$, qui représente la récompense cumulée maximale attendue en partant de l'état $s$ et en agissant de manière optimale par la suite.

L'algorithme utilise l'équation de Bellman d'optimalité :
$$ V_{k+1}(s) = \max_{a} \left( R(s, a) + \gamma \sum_{s'} P(s' | s, a) V_k(s') \right) $$
où $V_k(s)$ est la fonction de valeur à l'itération $k$. L'algorithme converge lorsque la différence entre $V_{k+1}$ et $V_k$ est inférieure à un seuil $\epsilon$.

```python
def value_iteration(P, R, gamma, num_states, num_actions, epsilon=1e-6, max_iterations=1000):
    """
    Implémente l'algorithme d'Itération sur la Valeur.

    Args:
        P (list): Probabilités de transition P[s][a][s_prime].
        R (list): Récompenses R[s][a].
        gamma (float): Facteur d'actualisation.
        num_states (int): Nombre d'états.
        num_actions (int): Nombre d'actions.
        epsilon (float): Seuil de convergence.
        max_iterations (int): Nombre maximum d'itérations.

    Returns:
        list: La fonction de valeur optimale V_star.
    """
    # Initialisation de la fonction de valeur à zéro pour tous les états
    V = [0.0 for _ in range(num_states)]

    print("\nLancement de l'Itération sur la Valeur...")
    for i in range(max_iterations):
        delta = 0.0 # Pour suivre le changement maximum dans V
        V_new = [0.0 for _ in range(num_states)] # Nouvelle fonction de valeur pour cette itération

        for s in range(num_states):
            # Calculer la Q-valeur pour chaque action 'a' dans l'état 's'
            q_values_for_s = []
            for a in range(num_actions):
                # Calcul de la valeur attendue des états suivants
                expected_future_value = 0.0
                for s_prime in range(num_states):
                    expected_future_value += P[s][a][s_prime] * V[s_prime]

                # Calcul de la Q-valeur pour l'action 'a'
                q_value_sa = R[s][a] + gamma * expected_future_value
                q_values_for_s.append(q_value_sa)

            # La nouvelle valeur de l'état s est le maximum des Q-valeurs
            V_new[s] = max(q_values_for_s)

            # Mettre à jour le delta maximum
            delta = max(delta, abs(V_new[s] - V[s]))

        # Mettre à jour V pour la prochaine itération
        V = V_new[:] # Créer une copie pour éviter les références

        # Afficher la progression toutes les 100 itérations ou si la convergence est proche
        if i % 100 == 0 or delta < 2 * epsilon:
            print(f"  Itération {i+1}: Delta = {delta:.8f}")

        # Vérifier la convergence
        if delta < epsilon:
            print(f"Convergence atteinte après {i+1} itérations.")
            break
    else:
        print(f"L'Itération sur la Valeur n'a pas convergé après {max_iterations} itérations (delta = {delta:.8f}).")

    return V

# Exécution de l'algorithme d'Itération sur la Valeur
V_star = value_iteration(P, R, gamma, num_states, num_actions)

print("\nFonction de valeur optimale V*:")
for s, val in enumerate(V_star):
    print(f"  V*({s}) = {val:.4f}")

# Assertion pour vérifier que les valeurs finales ne sont pas nulles pour les états pertinents
assert V_star[2] > 0, "La valeur de l'état d'arrivée devrait être positive."
assert V_star[0] < V_star[1], "La valeur de l'état de départ devrait être inférieure à celle de l'état intermédiaire."
assert V_star[1] < V_star[2], "La valeur de l'état intermédiaire devrait être inférieure à celle de l'état d'arrivée."
```

#### Étape 3 : Extraction de la Politique Optimale

Une fois que nous avons calculé la fonction de valeur optimale $V^*(s)$, il est facile d'en déduire la politique optimale $\pi^*(s)$. La politique optimale indique quelle action prendre dans chaque état pour maximiser la récompense future.

La politique optimale pour un état $s$ est l'action $a$ qui maximise l'expression de Bellman :
$$ \pi^*(s) = \arg\max_{a} \left( R(s, a) + \gamma \sum_{s'} P(s' | s, a) V^*(s') \right) $$

```python
def extract_optimal_policy(P, R, gamma, num_states, num_actions, V_star):
    """
    Extrait la politique optimale à partir de la fonction de valeur optimale.

    Args:
        P (list): Probabilités de transition.
        R (list): Récompenses.
        gamma (float): Facteur d'actualisation.
        num_states (int): Nombre d'états.
        num_actions (int): Nombre d'actions.
        V_star (list): La fonction de valeur optimale.

    Returns:
        list: La politique optimale (action pour chaque état).
    """
    optimal_policy = [0 for _ in range(num_states)] # Initialisation

    print("\nExtraction de la politique optimale...")
    for s in range(num_states):
        q_values_for_s = []
        for a in range(num_actions):
            expected_future_value = 0.0
            for s_prime in range(num_states):
                expected_future_value += P[s][a][s_prime] * V_star[s_prime]

            q_value_sa = R[s][a] + gamma * expected_future_value
            q_values_for_s.append(q_value_sa)

        # L'action optimale est celle qui maximise la Q-valeur
        optimal_action = q_values_for_s.index(max(q_values_for_s))
        optimal_policy[s] = optimal_action

    return optimal_policy

# Extraction de la politique optimale
optimal_policy = extract_optimal_policy(P, R, gamma, num_states, num_actions, V_star)

print("\nPolitique optimale π*:")
action_map = {0: "Rester", 1: "Avancer"}
for s, action_idx in enumerate(optimal_policy):
    print(f"  En état {s}, l'action optimale est : {action_map[action_idx]}")

# Assertions pour la politique optimale de notre exemple
# Pour l'état 0, l'action optimale devrait être d'avancer (1) pour atteindre le goal
assert optimal_policy[0] == 1, f"La politique optimale pour l'état 0 devrait être 'Avancer' (1), trouvé {optimal_policy[0]}"
# Pour l'état 1, l'action optimale devrait être d'avancer (1) pour atteindre le goal
assert optimal_policy[1] == 1, f"La politique optimale pour l'état 1 devrait être 'Avancer' (1), trouvé {optimal_policy[1]}"
# Pour l'état 2 (goal), l'action optimale devrait être de rester (0) pour capitaliser sur la récompense
assert optimal_policy[2] == 0, f"La politique optimale pour l'état 2 devrait être 'Rester' (0), trouvé {optimal_policy[2]}"

print("\nLa politique optimale a été extraite et validée avec succès !")
```
