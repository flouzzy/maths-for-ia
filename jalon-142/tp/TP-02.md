### Titre : Implémentation Avancée en Python Pur

**Contexte :**
Dans ce TP, nous implémentons un aspect spécifique de l'apprentissage par renforcement en Python.

**Objectif :** Implémenter l'évaluation d'une politique (Policy Evaluation) pour un MDP fini.

### Implémentation en Pure Python

```python
import numpy as np

def policy_evaluation(P, R, pi, gamma=0.9, epsilon=1e-6):
    num_states = P.shape[0]
    V = np.zeros(num_states)

    while True:
        V_next = np.zeros(num_states)
        for s in range(num_states):
            a = pi[s]
            V_next[s] = R[s, a] + gamma * np.sum(P[s, a] * V)

        if np.max(np.abs(V_next - V)) < epsilon:
            break
        V = V_next

    return V

# Example usage
P = np.array([[[1.0, 0.0], [0.0, 1.0]], [[0.5, 0.5], [1.0, 0.0]]])
R = np.array([[10, -5], [2, 0]])
pi = np.array([0, 1])
V_pi = policy_evaluation(P, R, pi)
print("V_pi:", V_pi)
```
