### Titre : Implémentation Avancée en Python Pur

**Contexte :**
Dans ce TP, nous implémentons un aspect spécifique de l'apprentissage par renforcement en Python.

**Objectif :** Visualiser la convergence empirique de Value Iteration.

### Implémentation en Pure Python

```python
import numpy as np

def track_value_iteration(P, R, gamma=0.9, iterations=50):
    num_states, num_actions, _ = P.shape
    V = np.zeros(num_states)
    history = [V.copy()]

    for _ in range(iterations):
        V_next = np.zeros(num_states)
        for s in range(num_states):
            q_values = [R[s, a] + gamma * np.sum(P[s, a] * V) for a in range(num_actions)]
            V_next[s] = np.max(q_values)
        V = V_next
        history.append(V.copy())

    return history

P = np.array([[[1.0, 0.0], [0.5, 0.5]], [[0.5, 0.5], [1.0, 0.0]]])
R = np.array([[10, 2], [5, 10]])
history = track_value_iteration(P, R)

for i, v in enumerate(history[:5]):
    print(f"Iteration {i}: {v}")
```
