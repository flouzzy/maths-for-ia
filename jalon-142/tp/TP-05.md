### Titre : Implémentation Avancée en Python Pur

**Contexte :**
Dans ce TP, nous implémentons un aspect spécifique de l'apprentissage par renforcement en Python.

**Objectif :** Résoudre un MDP simple (Gridworld 1D) avec Value Iteration.

### Implémentation en Pure Python

```python
import numpy as np

def solve_gridworld(size=5, gamma=0.9):
    V = np.zeros(size)

    # R: 0 for all except rightmost is 1
    # Actions: 0=Left, 1=Right
    for _ in range(100):
        V_next = np.zeros(size)
        for s in range(size):
            if s == size - 1:
                V_next[s] = 1.0 + gamma * V[s] # Terminal state self-loop
                continue

            # Go left
            s_left = max(0, s - 1)
            q_left = 0.0 + gamma * V[s_left]

            # Go right
            s_right = min(size - 1, s + 1)
            r_right = 1.0 if s_right == size - 1 else 0.0
            q_right = r_right + gamma * V[s_right]

            V_next[s] = max(q_left, q_right)

        if np.max(np.abs(V_next - V)) < 1e-6:
            break
        V = V_next

    return V

V_star = solve_gridworld()
print("V* Gridworld:", V_star)
```
