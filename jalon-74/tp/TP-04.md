# TP 4 : L'inégalité triangulaire de Minkowski

## Objectif
Vérifier l'inégalité de Minkowski $\|f+g\|_p \le \|f\|_p + \|g\|_p$ sur des vecteurs.

## Code Python
```python
def norme_lp(vecteur, p):
    somme = sum((x if x >= 0 else -x) ** p for x in vecteur)
    return somme ** (1.0 / p)

def add_vecteurs(v1, v2):
    return [x + y for x, y in zip(v1, v2)]

def test_minkowski():
    v1 = [3.5, -2.1, 8.0]
    v2 = [-1.0, 5.5, 2.0]

    # Test pour plusieurs valeurs de p
    for p in [1.0, 1.5, 2.0, 5.0, 10.0]:
        v_sum = add_vecteurs(v1, v2)
        norm_sum = norme_lp(v_sum, p)
        norm_1 = norme_lp(v1, p)
        norm_2 = norme_lp(v2, p)

        assert norm_sum <= norm_1 + norm_2 + 1e-9

    print("TP 4 : Tests passes.")

if __name__ == "__main__":
    test_minkowski()
```
