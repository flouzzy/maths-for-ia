# TP 3 : Validation de l'inégalité de Hölder sur des vecteurs

## Objectif
Implémenter le produit scalaire et les normes $L^p, L^q$ pour vérifier Hölder en dimension finie.

## Code Python
```python
def produit_scalaire(v1, v2):
    return sum(x * y for x, y in zip(v1, v2))

def norme_lp(vecteur, p):
    somme = sum((x if x >= 0 else -x) ** p for x in vecteur)
    return somme ** (1.0 / p)

def test_holder():
    # p = 3, q = 1.5 (car 1/3 + 2/3 = 1)
    p = 3.0
    q = 1.5

    v1 = [1, -2, 3, 0]
    v2 = [4, 1, -1, 2]

    # Integrale de |fg| en discret
    prod_abs = sum((x if x >= 0 else -x) * (y if y >= 0 else -y) for x, y in zip(v1, v2))

    norm_p = norme_lp(v1, p)
    norm_q = norme_lp(v2, q)

    # Verification : sum |x_i y_i| <= ||x||_p ||y||_q
    assert prod_abs <= norm_p * norm_q + 1e-9
    print("TP 3 : Tests passes.")

if __name__ == "__main__":
    test_holder()
```
