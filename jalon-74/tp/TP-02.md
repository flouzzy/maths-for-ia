### TP 2 : Calcul Numerique des Normes Lp

Nous implementons une fonction Python generique pour calculer la norme p d'un vecteur discret, permettant d'observer le comportement des differentes normes (1, 2, et infini).

```python
def calcul_norme_p(vecteur, p):
    # Gestion du cas limite p = infini
    if p == "infini":
        return max(abs(x) for x in vecteur)

    # Calcul de la somme des valeurs absolues a la puissance p
    somme = sum(abs(x)**p for x in vecteur)

    # Racine p-ieme
    return somme**(1.0/p)

if __name__ == "__main__":
    v = [1, -2, 3, 0]

    norme_1 = calcul_norme_p(v, 1)
    norme_2 = calcul_norme_p(v, 2)
    norme_inf = calcul_norme_p(v, "infini")

    print("Vecteur : ", v)
    print("Norme L1 : ", norme_1)
    print("Norme L2 : ", norme_2)
    print("Norme Linf: ", norme_inf)

    # Validation des proprietes d'inclusion: Linf <= L2 <= L1
    assert norme_inf <= norme_2 <= norme_1, "L'ordre des normes Lp n'est pas respecte."
    print("Ordre decroissant des normes selon p verifie.")
```
