### TP 1 : Simulation Numerique de l'Inegalite de Jensen

Dans ce TP, nous allons verifier experimentalement l'inegalite de Jensen avec la fonction exponentielle et une distribution uniforme.

```python
import math
import random

def simulation_jensen(n_samples):
    # Generer n_samples aleatoires entre 0 et 1 (distribution uniforme)
    samples = [random.random() for _ in range(n_samples)]

    # Calcul de l'esperance de Y
    esperance_Y = sum(samples) / n_samples

    # Image de l'esperance par la fonction convexe exp(x)
    phi_esperance = math.exp(esperance_Y)

    # Calcul de l'esperance des images E[exp(Y)]
    images = [math.exp(y) for y in samples]
    esperance_phi = sum(images) / n_samples

    print("Verification de l'inegalite de Jensen: phi(E[Y]) <= E[phi(Y)]")
    print("phi(E[Y])  = ", phi_esperance)
    print("E[phi(Y)]  = ", esperance_phi)

    # Assertion mathmatique
    assert phi_esperance <= esperance_phi, "L'inegalite de Jensen n'est pas verifiee !"
    print("Inegalite verifiee avec succes.")

if __name__ == "__main__":
    simulation_jensen(10000)
```
