### TP 5 : Application de Jensen a l'Entropie Croisee (Cross-Entropy)

L'entropie croisee est fondamentale en machine learning. Nous illustrons ici que la divergence de Kullback-Leibler, deduite de l'inegalite de Jensen, est toujours positive.

```python
import math

def divergence_kl(P, Q):
    # Les vecteurs P et Q representent des distributions de probabilites discretes
    assert len(P) == len(Q)

    # Verifier que la somme fait 1 (avec tolerance flottante)
    assert abs(sum(P) - 1.0) < 1e-5
    assert abs(sum(Q) - 1.0) < 1e-5

    kl = 0.0
    for i in range(len(P)):
        if P[i] > 0 and Q[i] > 0:
            kl += P[i] * math.log(P[i] / Q[i])

    return kl

if __name__ == "__main__":
    # Distribution cible vraie
    P_true = [0.1, 0.4, 0.5]

    # Prediction modele 1 (proche)
    Q1 = [0.15, 0.35, 0.5]

    # Prediction modele 2 (eloignee)
    Q2 = [0.6, 0.2, 0.2]

    kl_1 = divergence_kl(P_true, Q1)
    kl_2 = divergence_kl(P_true, Q2)

    print("Divergence KL(P || Q1) = ", kl_1)
    print("Divergence KL(P || Q2) = ", kl_2)

    # Verification de la consequence de l'inegalite de Jensen
    assert kl_1 >= 0, "Jensen: D_KL doit etre positive"
    assert kl_2 >= 0, "Jensen: D_KL doit etre positive"
    print("La positivite basee sur Jensen est respectee.")
```
