# Produit d'espérances pour des variables continues

L'objectif est de vérifier l'identité de l'espérance du produit pour des variables indépendantes continues (lois uniformes) en écrivant un intégrateur de Monte-Carlo 2D en Python pur.

```python
import random

def integrateur_produit_esperances(n_samples):
    """
    On tire X et Y independamment selon une loi Uniforme U([0, 10]).
    On verifie que l'espérance empirique de (XY) converge vers E[X]*E[Y].
    """
    somme_X = 0
    somme_Y = 0
    somme_XY = 0

    # E[X] theoreque pour U[a,b] est (a+b)/2, donc ici 5.0

    for _ in range(n_samples):
        X = random.uniform(0, 10)
        Y = random.uniform(0, 10)

        somme_X += X
        somme_Y += Y
        somme_XY += X * Y

    esp_X = somme_X / n_samples
    esp_Y = somme_Y / n_samples
    esp_XY = somme_XY / n_samples

    produit_des_esperances = esp_X * esp_Y

    return esp_XY, produit_des_esperances

N = 200000
e_xy, p_e = integrateur_produit_esperances(N)

print(f"Esperance empirique du produit E[XY] : {e_xy:.4f}")
print(f"Produit des esperances empiriques E[X]E[Y] : {p_e:.4f}")
print(f"Valeur theorique attendue : 5.0 * 5.0 = 25.0")

# Validation de l'identite d'independance
epsilon = 0.2
assert abs(e_xy - p_e) < epsilon, "E[XY] = E[X]E[Y] n'est pas verifie pour des variables independantes."
```
