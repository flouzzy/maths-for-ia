# Covariance nulle sans indépendance : l'exemple quadratique

Ce TP illustre par le code qu'une covariance nulle n'est pas une condition suffisante pour prouver l'indépendance de deux variables aléatoires.

```python
import random
import math

def estimer_covariance_non_independante(n_samples):
    """
    X suit une loi Normale standard.
    Y = X^2 (Totale dependance deterministe).
    Calcule la covariance empirique.
    """
    somme_X = 0
    somme_Y = 0
    somme_XY = 0

    for _ in range(n_samples):
        # Generation de X selon N(0,1) via Box-Muller
        u1 = random.random()
        u2 = random.random()
        X = math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)

        # Y est totalement dependante de X
        Y = X * X

        somme_X += X
        somme_Y += Y
        somme_XY += X * Y

    esp_X = somme_X / n_samples
    esp_Y = somme_Y / n_samples
    esp_XY = somme_XY / n_samples

    covariance = esp_XY - (esp_X * esp_Y)
    return covariance

N = 500000
cov_empirique = estimer_covariance_non_independante(N)

print(f"La covariance empirique entre X et X^2 est : {cov_empirique:.4f}")
print("Bien que Y soit definie par X, leur covariance approche 0 (Theorie: E[X^3] - E[X]E[X^2] = 0 - 0 = 0).")

# Assertion de validation mathématique (convergence vers 0)
assert abs(cov_empirique) < 0.05, "La covariance devrait etre theoriquement nulle."
```
