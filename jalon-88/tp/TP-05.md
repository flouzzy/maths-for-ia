# TP 5 : Indépendance et changement de base (Rotation en Loi Normale)

## Objectif
Comme démontré dans l'exercice 9, si $X$ et $Y$ sont deux gaussiennes centrées réduites indépendantes, les variables $U = X+Y$ et $V = X-Y$ sont également indépendantes.
Nous allons générer des échantillons normaux avec la méthode de Box-Muller, calculer $U$ et $V$, et vérifier leur indépendance via le calcul de la corrélation empirique.

## Implémentation Python pur

```python
import random
import math

def box_muller():
    # Genere un couple de variables normales centrees reduites independantes.
    u1 = random.random()
    u2 = random.random()

    r = math.sqrt(-2.0 * math.log(u1))
    theta = 2.0 * math.pi * u2

    z0 = r * math.cos(theta)
    z1 = r * math.sin(theta)
    return z0, z1

def simulation_rotation_normale(nb_tirages):
    somme_U = 0
    somme_V = 0
    somme_UU = 0
    somme_VV = 0
    somme_UV = 0

    for _ in range(nb_tirages):
        x, y = box_muller()

        u = x + y
        v = x - y

        somme_U += u
        somme_V += v
        somme_UU += (u * u)
        somme_VV += (v * v)
        somme_UV += (u * v)

    esp_U = somme_U / nb_tirages
    esp_V = somme_V / nb_tirages

    var_U = (somme_UU / nb_tirages) - (esp_U**2)
    var_V = (somme_VV / nb_tirages) - (esp_V**2)

    cov_UV = (somme_UV / nb_tirages) - (esp_U * esp_V)

    corr_UV = cov_UV / math.sqrt(var_U * var_V)

    return var_U, var_V, corr_UV

nb_sim = 200000
vU, vV, cUV = simulation_rotation_normale(nb_sim)

print("Analyse de U = X+Y et V = X-Y :")
print(f"Variance de U estimee : {vU:.4f} (Theorique: 2.0)")
print(f"Variance de V estimee : {vV:.4f} (Theorique: 2.0)")
print(f"Correlation entre U et V : {cUV:.4f}")

# Assertions
assert abs(vU - 2.0) < 0.05, "La variance de U est incorrecte."
assert abs(vV - 2.0) < 0.05, "La variance de V est incorrecte."
assert abs(cUV) < 0.01, "U et V devraient etre non correles (independants)."
print("\nAssertion reussie : U et V sont decoreles (et independants etant Gaussiens).")
```
