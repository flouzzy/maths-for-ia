# TP 4 : Série absolument convergente dans $L^1$
**Objectif :** Implémenter et sommer une série de fonctions dont la série des normes $L^1$ converge, et observer sa convergence ponctuelle.

```python
# tp_04_serie_absolue.py

def u_n(n, x):
    # u_n(x) est un "pic" centré en 1/n, de hauteur n et de base 2/n^3.
    # Ainsi ||u_n||_1 = n * (2/n^3) / 2 = 1/n^2.
    # La somme des 1/n^2 converge, donc la serie converge absolument dans L1.
    center = 1.0 / n
    base_half = 1.0 / (n**3)
    if x <= center - base_half or x >= center + base_half:
        return 0.0

    # Interpolation affine simple pour former un triangle
    if x <= center:
        slope = n / base_half
        return slope * (x - (center - base_half))
    else:
        slope = -n / base_half
        return slope * (x - center) + n

def test_series_convergence():
    x_test = 0.5

    sum_val = 0.0
    for n in range(1, 100):
        sum_val += u_n(n, x_test)

    print(f"Somme au point x={x_test} pour N=100 : {sum_val}")

    # Pour x > 0, x finira par ne plus etre dans les pics (qui se concentrent pres de 0).
    # Donc la somme doit etre finie (et souvent tres petite, voir 0 si x n'est jamais dans un pic).
    assert sum_val < 1000, "La série ponctuelle semble diverger"

if __name__ == "__main__":
    test_series_convergence()
```
