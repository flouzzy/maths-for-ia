# Travail Pratique 4 : Simulation des Records

## Énoncé et Code de Simulation

```python
def test_records():
    """
    Simule la survenue de records dans une suite de variables aleatoires i.i.d.
    Illustre que la probabilite de battre un record en n est 1/n.
    """
    import random

    N = 10000
    valeurs = [random.uniform(0, 1) for _ in range(N)]

    records = 0
    max_actuel = -1.0

    for i, val in enumerate(valeurs):
        if val > max_actuel:
            records += 1
            max_actuel = val

    # L'esperance du nombre de records est la somme de 1/n jusqu'a N.
    import math
    esperance = sum(1.0/n for n in range(1, N+1))

    assert records > 0, "Il doit y avoir des records"
    print("Nombre de records:", records, "Esperance theorique:", esperance)

if __name__ == '__main__':
    test_records()
```
