# Travail Pratique 1 : Simulation du Premier Lemme

## Énoncé et Code de Simulation

```python
def test_premier_lemme():
    """
    Simule la probabilite qu'une suite d'evenements A_n avec P(A_n) = 1/n^2
    se realise. Verifie qu'au dela d'un certain N, les evenements ne se
    produisent presque plus.
    """
    import random

    N = 1000
    realisations = 0

    # On simule les 1000 premieres epreuves
    for n in range(1, N + 1):
        p = 1.0 / (n**2)
        if random.random() < p:
            realisations += 1

    # Le nombre de realisations doit rester faible meme pour un grand N
    assert realisations < 50, "Le nombre de realisations devrait etre fini et petit"
    print("Test premier lemme : nombre de realisations =", realisations)

if __name__ == '__main__':
    test_premier_lemme()
```
