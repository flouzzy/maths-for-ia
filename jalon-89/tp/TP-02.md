# Travail Pratique 2 : Simulation du Second Lemme avec Serie Harmonique

## Énoncé et Code de Simulation

```python
def test_second_lemme():
    """
    Simule la probabilite d'evenements independants avec P(A_n) = 1/n.
    Selon Borel-Cantelli, l'evenement devrait se produire une infinite de fois.
    """
    import random

    N = 10000
    realisations = 0

    for n in range(1, N + 1):
        p = 1.0 / n
        if random.random() < p:
            realisations += 1

    # La somme harmonique ln(10000) est d'environ 9.2,
    # le nombre de realisations devrait etre de cet ordre.
    assert realisations > 0, "Il doit y avoir au moins une realisation"
    print("Test second lemme : nombre de realisations =", realisations)

if __name__ == '__main__':
    test_second_lemme()
```
