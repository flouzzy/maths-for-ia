# TP 5 : Opérateur Intégral et Compacité

## Objectif
Simuler l'opérateur intégral $Tf(x) = \int K(x,y)f(y)dy$ et vérifier la bornitude.

## Code Python
```python
def K(x, y):
    # Noyau continu K(x,y) = x * y
    return x * y

def T_f(f, x, num_points=100):
    # Approximation par methode des rectangles
    dy = 1.0 / num_points
    integral = 0
    for i in range(num_points):
        y = i * dy
        integral += K(x, y) * f(y) * dy
    return integral

def test_integral_operator():
    # Pour f(x) = 1 (norme inf <= 1), verifier l'image
    f = lambda x: 1
    # Tf(x) = int_0^1 (xy) dy = x [y^2/2]_0^1 = x/2
    val = T_f(f, 1.0)
    assert abs(val - 0.5) < 1e-2, f"Erreur operateur integral: {val}"

if __name__ == "__main__":
    test_integral_operator()
    print("TP5: Operateur integral compact valide.")
```
