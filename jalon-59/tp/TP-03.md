# TP 3 : Violation de l'équicontinuité

Ce TP illustre la perte d'équicontinuité avec la suite $f_n(x) = \sin(nx)$. Le module de continuité local à l'origine explose avec $n$.

```python
import math

def f_n(x, n):
    # Calcule sin(nx).
    return math.sin(n * x)

def eval_continuity(n, delta):
    # Evalue le maximum de |f_n(x) - f_n(0)| pour x < delta.
    # Le max sera atteint soit au bord, soit au premier pic (pi/2n)
    pic_pos = math.pi / (2 * n)
    if pic_pos < delta:
        return 1.0 # Le pic est dans le voisinage
    else:
        return math.sin(n * delta) # Le max est au bord

def run_tests():
    epsilon = 0.5
    # Fixons un delta quelconque
    delta = 0.01

    # Montrons que pour ce delta, un n suffisamment grand viole l'equicontinuite
    violation_found = False
    for n in range(1, 1000):
        max_diff = eval_continuity(n, delta)
        if max_diff >= epsilon:
            violation_found = True
            break

    assert violation_found, "Une violation d'equicontinuite aurait du etre trouvee."
    print("TP 3 : Tests passes. La suite sin(nx) n'est pas equicontinue a l'origine.")

if __name__ == "__main__":
    run_tests()
```
