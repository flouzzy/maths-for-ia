# TP 3 : Convergence des dérivées

## Objectif
Illustrer par le code que la convergence uniforme de $(f_n)$ n'implique pas la convergence de $(f_n')$.

## Code Python
```python
import math

def f_n(x, n):
    return math.sin(n * x) / math.sqrt(n)

def df_n(x, n):
    # Derivation analytique : sqrt(n)*cos(n*x)
    return math.sqrt(n) * math.cos(n * x)

def test_derivative_divergence():
    n_values = [10, 100, 1000, 10000]

    for n in n_values:
        # La fonction converge uniformement vers 0
        assert abs(f_n(1.0, n)) <= 1 / math.sqrt(n)

        # Mais la derivee en 0 diverge vers l'infini
        val_d = df_n(0.0, n)
        assert abs(val_d - math.sqrt(n)) < 1e-5

if __name__ == "__main__":
    test_derivative_divergence()
    print("TP3: Divergence de la derivee illustree.")
```
