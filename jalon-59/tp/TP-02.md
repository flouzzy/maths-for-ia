# TP 2 : Convergence uniforme et théorème de Dini

Le théorème de Dini stipule que si une suite de fonctions continues sur un compact converge simplement vers une fonction continue, de manière monotone, alors la convergence est uniforme. Testons cela avec $f_n(x) = (1 - x^2)^n$ sur $[0, 1]$.

```python
import math

def f_n(x, n):
    # Calcule (1 - x^2)^n.
    return math.pow(1 - x**2, n)

def f_limite(x):
    # Limite simple sur [0, 1]. Vaut 1 si x=0, 0 sinon.
    if x == 0.0:
        return 1.0
    return 0.0

def run_tests():
    # La limite est discontinue en 0, donc Dini ne s'applique PAS.
    # Et en effet, la convergence n'est pas uniforme.

    n_test = 100
    max_diff = 0.0
    num_points = 1000
    for i in range(num_points + 1):
        x = i / num_points
        diff = abs(f_n(x, n_test) - f_limite(x))
        if diff > max_diff:
            max_diff = diff

    assert max_diff > 0.9, "La convergence ne doit pas etre uniforme car la limite n'est pas continue."
    print("TP 2 : Tests passes. L'absence de continuite de la limite interdit la CVU.")

if __name__ == "__main__":
    run_tests()
```
