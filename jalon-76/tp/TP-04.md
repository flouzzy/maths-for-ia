# TP 4 : Contre-exemple : La norme L1 n'est pas Hilbertienne

**Objectif :** Montrer numériquement que l'espace L1 ne vérifie pas l'identité du parallélogramme.

```python
def norm_l1(f, dx): return sum(abs(a) for a in f)*dx

def test_tp4():
    N = 1000
    dx = 2.0 / (N - 1)

    # f = indicatrice de [0, 1], g = indicatrice de [1, 2]
    # On simule sur une grille de 0 a 2.
    f = [1.0 if i*dx <= 1.0 else 0.0 for i in range(N)]
    g = [1.0 if i*dx > 1.0 else 0.0 for i in range(N)]

    f_plus_g = [a+b for a,b in zip(f,g)]
    f_minus_g = [a-b for a,b in zip(f,g)]

    left = norm_l1(f_plus_g, dx)**2 + norm_l1(f_minus_g, dx)**2
    right = 2 * (norm_l1(f, dx)**2 + norm_l1(g, dx)**2)

    # left = 2^2 + 2^2 = 8, right = 2*(1^2 + 1^2) = 4
    assert abs(left - 8.0) < 1e-2
    assert abs(right - 4.0) < 1e-2
    assert abs(left - right) > 1.0, "Echec: l'identite ne devrait PAS etre verifiee."
    print("TP 4 : Norme L1 rejettee (Non hilbertienne) verifiee.")

if __name__ == "__main__":
    test_tp4()
```
