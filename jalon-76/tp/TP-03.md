# TP 3 : L'Identité du Parallélogramme

**Objectif :** Vérifier que la norme L2 respecte la géométrie hilbertienne via l'identité du parallélogramme.

```python
import math

def dot_l2(f, g, dx): return sum(a*b for a,b in zip(f,g))*dx
def norm_l2(f, dx): return math.sqrt(dot_l2(f, f, dx))

def test_tp3():
    N = 1000
    dx = 2.0 / (N - 1)
    x = [i*dx for i in range(N)]

    f = [math.exp(-xi) for xi in x]
    g = [math.sin(5*xi) for xi in x]

    f_plus_g = [a+b for a,b in zip(f,g)]
    f_minus_g = [a-b for a,b in zip(f,g)]

    left = norm_l2(f_plus_g, dx)**2 + norm_l2(f_minus_g, dx)**2
    right = 2 * (norm_l2(f, dx)**2 + norm_l2(g, dx)**2)

    assert abs(left - right) < 1e-3, f"Echec: {left} != {right}"
    print("TP 3 : Identite du parallelogramme verifiee pour norme L2.")

if __name__ == "__main__":
    test_tp3()
```
