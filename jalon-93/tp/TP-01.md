# Travail Pratique 1 : Approximation empirique de la fonction caractéristique

**Objectif :** Écrire un algorithme `from scratch` pour estimer la fonction caractéristique d'un échantillon de données. En vertu de la Loi Forte des Grands Nombres, l'espérance théorique peut être approchée par la moyenne empirique complexe.

**Directives mathématiques :**
Étant donné un échantillon `X` de taille `N` et un point fréquentiel `t`, l'estimateur empirique est :
$\hat{\phi}_N(t) = \frac{1}{N} \sum_{k=1}^N e^{it X_k}$

**Code Python :**

```python
import random
import cmath
import math

def generate_normal_sample(mu, sigma, size):
    # Box-Muller transform for normal distribution
    sample = []
    for _ in range((size + 1) // 2):
        u1 = random.random()
        u2 = random.random()
        z0 = math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)
        z1 = math.sqrt(-2.0 * math.log(u1)) * math.sin(2.0 * math.pi * u2)
        sample.extend([mu + sigma * z0, mu + sigma * z1])
    return sample[:size]

def empirical_characteristic_function(sample, t):
    N = len(sample)
    if N == 0:
        return complex(0, 0)

    sum_complex = complex(0, 0)
    for x in sample:
        # e^(itx) = cos(tx) + i*sin(tx)
        theta = t * x
        sum_complex += complex(math.cos(theta), math.sin(theta))

    return sum_complex / N

def test_tp01():
    random.seed(42)
    mu, sigma = 0.0, 1.0
    N = 10000
    t = 1.0

    sample = generate_normal_sample(mu, sigma, N)
    phi_emp = empirical_characteristic_function(sample, t)

    # Valeur theorique pour N(0, 1) evaluee en t=1 : exp(-1^2/2) = exp(-0.5)
    phi_theo = math.exp(-0.5)

    # La partie imaginaire doit etre proche de 0
    assert abs(phi_emp.imag) < 0.05, "La partie imaginaire devrait etre proche de 0 pour une loi symetrique."
    assert abs(phi_emp.real - phi_theo) < 0.05, "L'approximation empirique s'ecarte trop de la valeur theorique."
    print("TP 01 : Validation de l'estimateur empirique terminee avec succes.")

if __name__ == "__main__":
    test_tp01()
```
