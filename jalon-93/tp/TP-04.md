# Travail Pratique 4 : L'inversion de Fourier (KDE fréquentiel)

**Objectif :** Reconstruire la densité de probabilité au point $x$ en utilisant l'intégrale d'inversion tronquée sur un intervalle fréquentiel $[-T, T]$.

**Directives mathématiques :**
La formule d'inversion stipule que :
$f(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{-itx} \phi(t) dt$
On approxime l'intégrale par une somme de Riemann sur $[-T, T]$ avec un pas $dt$, et en remplaçant $\phi(t)$ par son estimateur empirique $\hat{\phi}(t)$. Cela revient à un Kernel Density Estimator (KDE) avec un noyau sinc.

**Code Python :**

```python
import random
import math

def generate_normal_sample(mu, sigma, size):
    sample = []
    for _ in range((size + 1) // 2):
        u1, u2 = random.random(), random.random()
        z0 = math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)
        z1 = math.sqrt(-2.0 * math.log(u1)) * math.sin(2.0 * math.pi * u2)
        sample.extend([mu + sigma * z0, mu + sigma * z1])
    return sample[:size]

def empirical_cf(sample, t):
    real_part = sum(math.cos(t * x) for x in sample) / len(sample)
    imag_part = sum(math.sin(t * x) for x in sample) / len(sample)
    return complex(real_part, imag_part)

def invert_fourier_density(sample, x, T=10.0, num_steps=200):
    dt = 2.0 * T / num_steps
    integral = 0.0

    for i in range(num_steps):
        t = -T + i * dt
        # e^{-itx}
        inv_exp = complex(math.cos(-t * x), math.sin(-t * x))
        phi_t = empirical_cf(sample, t)

        integral += (inv_exp * phi_t).real * dt

    return integral / (2.0 * math.pi)

def test_tp04():
    random.seed(42)
    mu, sigma = 0.0, 1.0
    N = 2000
    sample = generate_normal_sample(mu, sigma, N)

    # Evaluer la densite reconstruite en x = 0
    f_0_emp = invert_fourier_density(sample, 0.0, T=5.0, num_steps=100)
    f_0_theo = 1.0 / math.sqrt(2.0 * math.pi)

    assert abs(f_0_emp - f_0_theo) < 0.05, "La reconstruction de la densite par inversion a echoue."
    print("TP 04 : Inversion de Fourier pour reconstruction de densite validee.")

if __name__ == "__main__":
    test_tp04()
```
