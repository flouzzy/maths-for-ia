# Travail Pratique 2 : Vérification de la propriété multiplicative

**Objectif :** Valider expérimentalement que la fonction caractéristique d'une somme de variables indépendantes est le produit de leurs fonctions caractéristiques respectives.

**Directives mathématiques :**
On simule deux échantillons indépendants `X` et `Y`. On construit l'échantillon somme `Z = X + Y`. On vérifie que $\hat{\phi}_Z(t) \approx \hat{\phi}_X(t) \times \hat{\phi}_Y(t)$.

**Code Python :**

```python
import random
import math

def generate_exponential_sample(lam, size):
    return [-math.log(1.0 - random.random()) / lam for _ in range(size)]

def empirical_cf(sample, t):
    N = len(sample)
    real_part = sum(math.cos(t * x) for x in sample) / N
    imag_part = sum(math.sin(t * x) for x in sample) / N
    return complex(real_part, imag_part)

def test_tp02():
    random.seed(42)
    N = 20000
    lam1, lam2 = 2.0, 3.0
    t = 1.5

    sample_x = generate_exponential_sample(lam1, N)
    sample_y = generate_exponential_sample(lam2, N)
    sample_z = [x + y for x, y in zip(sample_x, sample_y)]

    phi_x = empirical_cf(sample_x, t)
    phi_y = empirical_cf(sample_y, t)
    phi_z_emp = empirical_cf(sample_z, t)

    phi_z_prod = phi_x * phi_y

    diff_real = abs(phi_z_emp.real - phi_z_prod.real)
    diff_imag = abs(phi_z_emp.imag - phi_z_prod.imag)

    assert diff_real < 0.05, "La partie reelle du produit ne correspond pas a celle de la somme."
    assert diff_imag < 0.05, "La partie imaginaire du produit ne correspond pas a celle de la somme."
    print("TP 02 : Propriete multiplicative verifiee avec succes.")

if __name__ == "__main__":
    test_tp02()
```
