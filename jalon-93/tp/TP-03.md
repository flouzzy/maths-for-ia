# Travail Pratique 3 : Calcul des moments par dérivation discrète

**Objectif :** Utiliser la fonction caractéristique empirique pour estimer l'espérance et la variance d'une distribution en approximant les dérivées premières et secondes de $\hat{\phi}$ en 0.

**Directives mathématiques :**
On utilise des différences finies centrées :
$\hat{\phi}'(0) \approx \frac{\hat{\phi}(h) - \hat{\phi}(-h)}{2h}$
$\hat{\phi}''(0) \approx \frac{\hat{\phi}(h) - 2\hat{\phi}(0) + \hat{\phi}(-h)}{h^2}$
Puis, on en déduit les moments : $E[X] = \frac{\phi'(0)}{i}$ et $E[X^2] = -\phi''(0)$.

**Code Python :**

```python
import random
import math

def generate_uniform_sample(a, b, size):
    return [random.uniform(a, b) for _ in range(size)]

def empirical_cf(sample, t):
    N = len(sample)
    real_part = sum(math.cos(t * x) for x in sample) / N
    imag_part = sum(math.sin(t * x) for x in sample) / N
    return complex(real_part, imag_part)

def estimate_moments_via_cf(sample, h=1e-3):
    phi_h = empirical_cf(sample, h)
    phi_minus_h = empirical_cf(sample, -h)
    phi_0 = empirical_cf(sample, 0.0) # Doit etre exactement 1+0j

    # Derivée premiere (difference centree)
    d1 = (phi_h - phi_minus_h) / (2 * h)

    # Derivée seconde
    d2 = (phi_h - 2*phi_0 + phi_minus_h) / (h**2)

    # E[X] = d1 / i = -i * d1 -> partie imaginaire de d1
    # Or, d1 est purement imaginaire pour une distribution reelle, donc E[X] = d1.imag
    e_x = d1.imag

    # E[X^2] = d2 / (i^2) = -d2 -> partie reelle
    e_x2 = -d2.real

    variance = e_x2 - e_x**2
    return e_x, variance

def test_tp03():
    random.seed(42)
    a, b = 0.0, 10.0
    N = 50000
    sample = generate_uniform_sample(a, b, N)

    emp_mean, emp_var = estimate_moments_via_cf(sample, h=1e-3)

    theo_mean = (a + b) / 2.0
    theo_var = (b - a)**2 / 12.0

    assert abs(emp_mean - theo_mean) < 0.1, "L'estimation de l'esperance par CF a echoue."
    assert abs(emp_var - theo_var) < 0.5, "L'estimation de la variance par CF a echoue."
    print("TP 03 : Estimation des moments par derives de la CF reussie.")

if __name__ == "__main__":
    test_tp03()
```
