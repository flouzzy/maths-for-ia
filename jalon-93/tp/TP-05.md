# Travail Pratique 5 : MMD via Fonctions Caractéristiques

**Objectif :** Mesurer la distance entre deux distributions (une approche clé en IA générative) en calculant la distance quadratique entre leurs fonctions caractéristiques empiriques.

**Directives mathématiques :**
On définit une distance fréquentielle pondérée :
$D(X, Y) = \int_{-T}^{T} |\hat{\phi}_X(t) - \hat{\phi}_Y(t)|^2 dt$
Si les lois sont identiques, cette distance doit être proche de zéro. Si elles diffèrent (ex: moyennes différentes), elle sera significativement plus grande.

**Code Python :**

```python
import random
import math

def generate_normal_sample(mu, sigma, size):
    sample = []
    for _ in range((size + 1) // 2):
        u1, u2 = random.random(), random.random()
        z = math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)
        sample.append(mu + sigma * z)
    return sample[:size]

def empirical_cf(sample, t):
    real_part = sum(math.cos(t * x) for x in sample) / len(sample)
    imag_part = sum(math.sin(t * x) for x in sample) / len(sample)
    return complex(real_part, imag_part)

def characteristic_mmd(sample_P, sample_Q, T=5.0, num_steps=100):
    dt = 2.0 * T / num_steps
    distance_sq = 0.0

    for i in range(num_steps):
        t = -T + i * dt
        phi_P = empirical_cf(sample_P, t)
        phi_Q = empirical_cf(sample_Q, t)

        diff = phi_P - phi_Q
        # Module au carre de la difference
        mod_sq = diff.real**2 + diff.imag**2
        distance_sq += mod_sq * dt

    return distance_sq

def test_tp05():
    random.seed(42)
    N = 1000
    # Meme distribution
    sample_P1 = generate_normal_sample(0.0, 1.0, N)
    sample_Q1 = generate_normal_sample(0.0, 1.0, N)

    # Distributions differentes (shift de moyenne)
    sample_P2 = generate_normal_sample(0.0, 1.0, N)
    sample_Q2 = generate_normal_sample(1.0, 1.0, N)

    mmd_same = characteristic_mmd(sample_P1, sample_Q1)
    mmd_diff = characteristic_mmd(sample_P2, sample_Q2)

    assert mmd_same < 0.2, "La MMD entre memes distributions devrait etre tres faible."
    assert mmd_diff > 1.0, "La MMD entre distributions differentes devrait etre grande."
    print("TP 05 : Calcul de divergence frequentielle (MMD) valide.")

if __name__ == "__main__":
    test_tp05()
```
