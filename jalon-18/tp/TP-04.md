## Exercice 1 : Approximation de la Continuité Ponctuelle

**Concept Pédagogique :**

La continuité d'une fonction $f$ en un point $a$ est définie par $\lim_{x \to a} f(x) = f(a)$. La définition formelle (epsilon-delta) est la suivante :
Pour tout $\epsilon > 0$, il existe un $\delta > 0$ tel que si $|x - a| < \delta$ (et $x \neq a$), alors $|f(x) - f(a)| < \epsilon$.

En programmation numérique, il est impossible de "prouver" la continuité pour *tout* $\epsilon$ et *tout* $\delta$. Cependant, nous pouvons *tester* si cette condition est satisfaite pour des valeurs spécifiques (et petites) de $\epsilon$ et $\delta$, en échantillonnant des points autour de $a$. Si tous les points échantillonnés dans l'intervalle $(a-\delta, a+\delta)$ (excluant $a$ lui-même) respectent la condition $|f(x) - f(a)| < \epsilon$, nous pouvons considérer que la fonction est "probablement continue" en $a$ pour ces paramètres.

**Tâche :**

Écrire une fonction `est_continue_en_point(f, a, epsilon=1e-6, delta=1e-6, num_points=10)` qui tente de vérifier la continuité de `f` en `a`.

*   La fonction prendra en entrée :
    *   `f` : la fonction à tester.
    *   `a` : le point où tester la continuité.
    *   `epsilon` : la tolérance maximale pour la différence $|f(x) - f(a)|$.
    *   `delta` : la taille de l'intervalle autour de `a` à échantillonner.
    *   `num_points` : le nombre de points à échantillonner dans l'intervalle $(a-\delta, a+\delta)$.
*   Elle retournera `True` si la fonction semble continue en `a` selon les paramètres, `False` sinon.
*   Gérer les cas où `f(a)` ou `f(x)` pour un `x` proche de `a` ne sont pas définis (ex: division par zéro).

```python
import math

def est_continue_en_point(f, a, epsilon=1e-6, delta=1e-6, num_points=10):
    """
    Tente d'approximer la continuité d'une fonction f en un point 'a' en utilisant
    une approche basée sur la définition epsilon-delta pour des valeurs fixes.

    Concept pédagogique :
    Cette fonction ne *prouve* pas la continuité au sens mathématique formel,
    mais la *teste* pour des valeurs spécifiques d'epsilon et delta.
    Elle échantillonne des points autour de 'a' et vérifie si f(x) est proche de f(a).
    Si pour tous les points échantillonnés dans (a-delta, a+delta) (excluant a),
    |f(x) - f(a)| < epsilon, on considère la fonction comme "probablement continue"
    en 'a' pour ces paramètres.

    Args:
        f (callable): La fonction à tester.
        a (float): Le point où tester la continuité.
        epsilon (float): La tolérance pour la différence |f(x) - f(a)|.
        delta (float): La taille de l'intervalle autour de 'a' à échantillonner.
        num_points (int): Le nombre de points à échantillonner dans l'intervalle (a-delta, a+delta).

    Returns:
        bool: True si la fonction semble continue en 'a' selon les paramètres, False sinon.
    """

    # 1. Calculer f(a). Si f(a) n'est pas défini, la fonction ne peut pas être continue en 'a'.
    try:
        fa = f(a)
    except Exception:
        print(f"  Attention : f({a}) n'est pas défini ou provoque une erreur.")
        return False

    # 2. Échantillonner des points autour de 'a' dans l'intervalle (a - delta, a + delta).
    # On s'assure de ne pas inclure 'a' lui-même dans les points de test.
    points_test = []
    if num_points > 0 and delta > 0:
        step = (2 * delta) / (num_points + 1) # Pour avoir num_points points espacés
        for i in range(1, num_points + 1):
            x = a - delta + i * step
            # S'assurer que x n'est pas exactement 'a' pour éviter les problèmes
            # avec des fonctions définies par morceaux ou des singularités en 'a'.
            if abs(x - a) > 1e-10:
                points_test.append(x)

    if not points_test:
        # Si aucun point valide n'a pu être généré (ex: delta trop petit, num_points=0),
        # on ne peut pas tester la continuité.
        print(f"  Avertissement : Aucun point d'échantillonnage valide autour de {a}. Impossible de tester.")
        return False

    # 3. Vérifier la condition |f(x) - f(a)| < epsilon pour chaque point échantillonné.
    for x in points_test:
        try:
            fx = f(x)
            if abs(fx - fa) >= epsilon:
                # Si un seul point ne satisfait pas la condition, la fonction n'est pas continue
                # selon notre critère d'approximation.
                return False
        except Exception:
            # Si f(x) n'est pas défini pour un x proche de 'a', elle n'est pas continue.
            return False

    # Si tous les points testés satisfont la condition, la fonction est considérée comme continue.
    return True
```

## Exercice 2 : Implémentation du Théorème des Valeurs Intermédiaires (TVI) par Dichotomie

**Concept Pédagogique :**

Le **Théorème des Valeurs Intermédiaires (TVI)** est un pilier de la théorie de la continuité. Il stipule que si une fonction $f$ est **continue** sur un intervalle fermé $[a, b]$, et si $k$ est une valeur comprise entre $f(a)$ et $f(b)$ (c'est-à-dire $f(a) \le k \le f(b)$ ou $f(b) \le k \le f(a)$), alors il existe au moins un $c$ dans $[a, b]$ tel que $f(c) = k$.

L'algorithme de **dichotomie** (ou méthode de bissection) est une méthode numérique qui exploite directement ce théorème pour trouver une approximation de ce $c$. L'idée est de diviser l'intervalle de recherche par deux à chaque étape, en garantissant que la solution $c$ reste toujours dans le nouvel intervalle réduit. C'est une méthode robuste qui converge toujours, à condition que les préconditions du TVI soient respectées.

**Tâche :**

Écrire une fonction `trouver_valeur_intermediaire(f, a, b, k, tolerance=1e-7, max_iterations=100)` qui utilise la méthode de dichotomie pour trouver un `c` tel que `f(c)` est proche de `k`.

*   **Préconditions (assertions et `ValueError`) :**
    *   `a` doit être strictement inférieur à `b`.
    *   La valeur `k` doit être comprise entre `f(a)` et `f(b)`. Si cette condition n'est pas remplie, le TVI ne garantit pas l'existence d'une solution, et la fonction doit lever une `ValueError`.
    *   La fonction `f` est *supposée* continue sur `[a, b]`. L'algorithme de dichotomie ne peut pas vérifier cette condition, il l'exploite. C'est un point crucial à comprendre.
*   **Algorithme de Dichotomie :**
    1.  Initialiser `gauche = a` et `droite = b`.
    2.  Pour un nombre maximal d'itérations :
        *   Calculer le milieu `milieu = (gauche + droite) / 2`.
        *   Évaluer `f_milieu = f(milieu)`.
        *   Si `abs(f_milieu - k) < tolerance`, la solution est trouvée, retourner `milieu`.
        *   Si l'intervalle `(droite - gauche)` est déjà inférieur à `tolerance`, retourner `milieu` comme meilleure approximation.
        *   Sinon, réduire l'intervalle :
            *   Si `(f_milieu - k)` et `(f(gauche) - k)` ont le même signe (c'est-à-dire que `f(milieu)` et `f(gauche)` sont du même côté de `k`), alors la solution est dans `[milieu, droite]`. Mettre `gauche = milieu`.
            *   Sinon, la solution est dans `[gauche, milieu]`. Mettre `droite = milieu`.
    3.  Si le nombre maximal d'itérations est atteint sans trouver une solution dans la tolérance, retourner la meilleure approximation (`(gauche + droite) / 2`) et émettre un avertissement.
*   **Assertions de validation :**
    *   Après avoir trouvé `c`, vérifier qu'il est bien dans l'intervalle `[a, b]`.
    *   Vérifier que `f(c)` est proche de `k` (dans la limite de la `tolerance`).

```python
def trouver_valeur_intermediaire(f, a, b, k, tolerance=1e-7, max_iterations=100):
    """
    Applique la méthode de dichotomie (bissection) pour trouver un 'c' dans [a, b]
    tel que f(c) est proche de 'k', en se basant sur le Théorème des Valeurs Intermédiaires (TVI).

    Concept pédagogique :
    Le TVI garantit l'existence d'une solution pour f(x) = k si f est continue sur [a, b]
    et k est entre f(a) et f(b). La dichotomie est une méthode numérique qui exploite
    cette propriété d'existence pour *localiser* cette solution avec une précision arbitraire.
    À chaque étape, l'intervalle de recherche est divisé par deux, garantissant la convergence.

    Args:
        f (callable): La fonction (supposée continue) sur [a, b].
        a (float): Borne inférieure de l'intervalle.
        b (float): Borne supérieure de l'intervalle.
        k (float): La valeur intermédiaire à atteindre.
        tolerance (float): La précision souhaitée pour f(c) ≈ k et pour la taille de l'intervalle.
        max_iterations (int): Nombre maximal d'itérations pour éviter les boucles infinies.

    Returns:
        float: Une approximation de 'c' telle que f(c) ≈ k.

    Raises:
        ValueError: Si les préconditions du TVI (k entre f(a) et f(b)) ne sont pas remplies.
    """

    # --- Assertions de préconditions du TVI ---
    assert a < b, "La borne 'a' doit être strictement inférieure à la borne 'b'."

    fa = f(a)
    fb = f(b)

    # Le TVI nécessite que k soit entre f(a) et f(b).
    # On vérifie si k est encadré par fa et fb.
    # Note : On utilise une petite tolérance pour les comparaisons de flottants.
    if not ((fa - tolerance <= k <= fb + tolerance) or (fb - tolerance <= k <= fa + tolerance)):
        raise ValueError(
            f"La valeur k={k} n'est pas comprise entre f(a)={fa} et f(b)={fb}. "
            "Le Théorème des Valeurs Intermédiaires ne peut pas être appliqué directement."
        )

    # Si f(a) ou f(b) est déjà k (à la tolérance près), on peut retourner a ou b directement.
    if abs(fa - k) < tolerance:
        return a
    if abs(fb - k) < tolerance:
        return b

    # --- Algorithme de Dichotomie ---

    gauche = a
    droite = b

    # Assertion interne pour s'assurer que f(gauche)-k et f(droite)-k ont des signes opposés.
    # C'est la condition fondamentale pour que la dichotomie fonctionne correctement.
    # Si (fa - k) * (fb - k) > 0, cela signifie que fa et fb sont du même côté de k,
    # ce qui contredit la précondition du TVI (déjà vérifiée par le ValueError ci-dessus).
    # On utilise <= 0 pour inclure le cas où f(a)=k ou f(b)=k (déjà géré).
    assert (fa - k) * (fb - k) <= 0, "Erreur interne: f(a)-k et f(b)-k n'ont pas des signes opposés."

    for i in range(max_iterations):
        milieu = (gauche + droite) / 2
        f_milieu = f(milieu)

        # Si f(milieu) est suffisamment proche de k, on a trouvé notre 'c'.
        if abs(f_milieu - k) < tolerance:
            return milieu

        # Si l'intervalle de recherche est déjà très petit, on peut s'arrêter.
        if (droite - gauche) / 2 < tolerance:
            return milieu

        # La logique de la dichotomie : réduire l'intervalle.
        # On cherche à maintenir la propriété que k est entre f(gauche) et f(droite).
        # Si (f_milieu - k) et (f(gauche) - k) ont le même signe, cela signifie que
        # f(milieu) et f(gauche) sont du même côté de k. Donc, la solution doit être
        # dans l'autre moitié : [milieu, droite].
        # Sinon, la solution est dans [gauche, milieu].
        if (f_milieu - k) * (f(gauche) - k) > 0:
            gauche = milieu
        else:
            droite = milieu

    # Si le nombre maximal d'itérations est atteint, retourner la meilleure approximation.
    final_c = (gauche + droite) / 2
    print(f"  Avertissement : Nombre maximal d'itérations ({max_iterations}) atteint. "
          f"Résultat approximatif : c={final_c:.7f}, f(c)={f(final_c):.7f}")
    return final_c
```
