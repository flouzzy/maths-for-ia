## Partie 1 : Vérification Numérique Approximative de la Continuité en un Point

### Concept Théorique

Une fonction $f$ est continue en un point $x_0$ si $\lim_{x \to x_0} f(x) = f(x_0)$. Cela signifie que lorsque $x$ s'approche de $x_0$, la valeur de $f(x)$ s'approche de $f(x_0)$. La définition formelle est la définition $\epsilon-\delta$ : pour tout $\epsilon > 0$, il existe un $\delta > 0$ tel que si $|x - x_0| < \delta$, alors $|f(x) - f(x_0)| < \epsilon$.

### Implémentation Numérique

Il est difficile d'implémenter la définition $\epsilon-\delta$ de manière exhaustive sans un moteur de calcul symbolique. Nous allons plutôt implémenter une **vérification numérique approximative**. Nous allons tester si, pour un petit pas `h`, les valeurs de la fonction à `x0 - h`, `x0`, et `x0 + h` sont "suffisamment proches".

```python
import math

def is_continuous_at_point_approx(f, x0, h=1e-6, tolerance=1e-5):
    """
    Vérifie numériquement et approximativement la continuité d'une fonction f en un point x0.

    La fonction teste si f(x) est proche de f(x0) lorsque x est proche de x0.
    Ceci est une approximation numérique et ne remplace pas la définition formelle epsilon-delta.

    Args:
        f (callable): La fonction à tester.
        x0 (float): Le point où tester la continuité.
        h (float): Un petit pas pour évaluer f(x0 - h) et f(x0 + h).
        tolerance (float): La tolérance maximale pour considérer les valeurs comme "proches".

    Returns:
        bool: True si la fonction semble continue en x0 selon les paramètres donnés, False sinon.
    """
    # Étape 1 : Calculer f(x0)
    # Si f(x0) n'est pas défini (ex: division par zéro), la fonction ne peut pas être continue en x0.
    try:
        fx0 = f(x0)
    except (ValueError, ZeroDivisionError):
        # Pédagogie: Si f(x0) n'est pas défini, la fonction ne peut pas être continue en x0.
        print(f"Attention: f({x0}) n'est pas défini. La fonction ne peut pas être continue en ce point.")
        return False

    # Étape 2 : Calculer f(x0 - h) et f(x0 + h)
    # Nous vérifions les valeurs de la fonction de part et d'autre de x0.
    try:
        fx0_minus_h = f(x0 - h)
        fx0_plus_h = f(x0 + h)
    except (ValueError, ZeroDivisionError):
        # Pédagogie: Si la fonction n'est pas définie dans le voisinage de x0,
        # elle ne peut pas être continue en x0.
        print(f"Attention: f n'est pas définie dans le voisinage de {x0}. La fonction ne peut pas être continue en ce point.")
        return False

    # Étape 3 : Vérifier si les valeurs sont "suffisamment proches"
    # La condition de continuité implique que f(x) doit tendre vers f(x0).
    # Numériquement, cela signifie que |f(x) - f(x0)| doit être petit pour x proche de x0.
    # Nous utilisons la tolérance pour définir ce qui est "petit".
    is_close_left = abs(fx0_minus_h - fx0) < tolerance
    is_close_right = abs(fx0_plus_h - fx0) < tolerance

    # Pédagogie: Pour être numériquement "continue" à notre niveau d'approximation,
    # les deux côtés (gauche et droite) doivent converger vers f(x0).
    return is_close_left and is_close_right

# --- Tests pour la Partie 1 ---

# Fonction 1: f(x) = x^2 (continue partout)
def f1(x):
    return x * x

assert is_continuous_at_point_approx(f1, 0) == True, "f(x)=x^2 doit être continue en x=0"
assert is_continuous_at_point_approx(f1, 2) == True, "f(x)=x^2 doit être continue en x=2"
assert is_continuous_at_point_approx(f1, -1.5) == True, "f(x)=x^2 doit être continue en x=-1.5"

# Fonction 2: f(x) = |x| (continue partout)
def f2(x):
    return abs(x)

assert is_continuous_at_point_approx(f2, 0) == True, "f(x)=|x| doit être continue en x=0"
assert is_continuous_at_point_approx(f2, -3) == True, "f(x)=|x| doit être continue en x=-3"

# Fonction 3: Fonction par morceaux avec une discontinuité de saut en x=0
def f3(x):
    return 1 if x >= 0 else -1

assert is_continuous_at_point_approx(f3, 0) == False, "f(x) par morceaux doit être discontinue en x=0"
assert is_continuous_at_point_approx(f3, 1) == True, "f(x) par morceaux doit être continue en x=1"
assert is_continuous_at_point_approx(f3, -1) == True, "f(x) par morceaux doit être continue en x=-1"

# Fonction 4: f(x) = 1/x (discontinue en x=0)
def f4(x):
    return 1 / x

assert is_continuous_at_point_approx(f4, 1) == True, "f(x)=1/x doit être continue en x=1"
# Test pour la discontinuité en x=0. La fonction `is_continuous_at_point_approx` gère les erreurs.
assert is_continuous_at_point_approx(f4, 0) == False, "f(x)=1/x doit être discontinue en x=0 (non définie)"

# Fonction 5: f(x) = floor(x) (discontinue aux entiers)
def f5(x):
    return math.floor(x)

assert is_continuous_at_point_approx(f5, 0.5) == True, "f(x)=floor(x) doit être continue en x=0.5"
assert is_continuous_at_point_approx(f5, 1.0) == False, "f(x)=floor(x) doit être discontinue en x=1.0"
assert is_continuous_at_point_approx(f5, -2.0) == False, "f(x)=floor(x) doit être discontinue en x=-2.0"

print("Tous les tests de la Partie 1 sont passés avec succès !")
```

## Partie 2 : Théorème des Valeurs Intermédiaires (TVI) par Dichotomie

### Concept Théorique

Le **Théorème des Valeurs Intermédiaires (TVI)** est un pilier de la théorie de la continuité. Il stipule que si une fonction $f$ est **continue** sur un intervalle fermé $[a, b]$, et si $f(a)$ et $f(b)$ ont des signes opposés (c'est-à-dire $f(a) \cdot f(b) < 0$), alors il existe au moins un nombre $c$ dans l'intervalle ouvert $(a, b)$ tel que $f(c) = 0$. En d'autres termes, une fonction continue ne peut pas "sauter" une valeur ; elle doit prendre toutes les valeurs intermédiaires entre $f(a)$ et $f(b)$.

### Implémentation Numérique : Méthode de Dichotomie

La méthode de dichotomie (ou bissection) est un algorithme efficace pour trouver numériquement une racine d'une fonction (un $c$ tel que $f(c)=0$) sur un intervalle donné, **à condition que le TVI s'applique**. Elle fonctionne en réduisant de moitié l'intervalle à chaque itération, en garantissant que la racine reste toujours dans le nouvel intervalle.

```python
def find_root_bisection(f, a, b, tolerance=1e-6, max_iterations=100):
    """
    Trouve numériquement une racine de la fonction f sur l'intervalle [a, b]
    en utilisant la méthode de dichotomie (bissection).

    Ce processus repose sur le Théorème des Valeurs Intermédiaires (TVI),
    qui exige que la fonction f soit continue sur [a, b].

    Args:
        f (callable): La fonction dont on cherche une racine.
        a (float): Borne inférieure de l'intervalle.
        b (float): Borne supérieure de l'intervalle.
        tolerance (float): La précision souhaitée pour la racine.
        max_iterations (int): Nombre maximal d'itérations pour éviter les boucles infinies.

    Returns:
        float or None: La racine trouvée ou None si les conditions initiales du TVI
                       ne sont pas remplies ou si la limite d'itérations est atteinte.
    """
    # Étape 1 : Vérification des conditions initiales du TVI
    # Le TVI exige que f(a) et f(b) aient des signes opposés.
    # Si ce n'est pas le cas, le TVI ne garantit pas l'existence d'une racine dans [a, b].
    try:
        fa = f(a)
        fb = f(b)
    except (ValueError, ZeroDivisionError):
        print(f"Erreur: La fonction n'est pas définie aux bornes de l'intervalle [{a}, {b}].")
        return None

    if fa * fb > 0:
        # Pédagogie: Si f(a) et f(b) ont le même signe, le TVI ne s'applique pas directement
        # pour garantir une racine. Il pourrait y avoir des racines, mais pas garanties par le TVI,
        # ou aucune racine.
        print(f"Attention: f({a}) et f({b}) ont le même signe ({fa}, {fb}). Le TVI ne garantit pas de racine dans [{a}, {b}].")
        return None

    if fa == 0: # Cas où 'a' est déjà une racine
        return a
    if fb == 0: # Cas où 'b' est déjà une racine
        return b

    # Étape 2 : Boucle de dichotomie
    # Nous allons itérativement réduire l'intervalle [a, b] jusqu'à ce qu'il soit suffisamment petit.
    for i in range(max_iterations):
        mid = (a + b) / 2  # Calcul du milieu de l'intervalle

        # Pédagogie: Si l'intervalle est suffisamment petit, nous avons trouvé notre racine
        # avec la précision désirée.
        if abs(b - a) < tolerance:
            return mid

        try:
            f_mid = f(mid)
        except (ValueError, ZeroDivisionError):
            # Si la fonction n'est pas définie au milieu, cela indique une discontinuité
            # ou un problème de domaine, ce qui viole la condition de continuité du TVI.
            print(f"Erreur: f({mid}) n'est pas défini. La fonction pourrait être discontinue.")
            return None

        # Pédagogie: Nous vérifions le signe de f(mid) pour décider quelle moitié de l'intervalle
        # contient la racine. C'est le cœur de la méthode de dichotomie.
        if f_mid == 0: # Cas exact où le milieu est la racine
            return mid
        elif fa * f_mid < 0:
            # La racine est dans l'intervalle [a, mid]
            b = mid
            fb = f_mid # Mettre à jour fb pour la prochaine itération
        else: # f_mid * fb < 0
            # La racine est dans l'intervalle [mid, b]
            a = mid
            fa = f_mid # Mettre à jour fa pour la prochaine itération

    # Pédagogie: Si nous atteignons le nombre maximal d'itérations, cela signifie
    # que la tolérance n'a pas été atteinte dans le temps imparti.
    print(f"Avertissement: Nombre maximal d'itérations ({max_iterations}) atteint. La racine est approximée à {mid}.")
    return mid # Retourne la meilleure approximation trouvée

# --- Tests pour la Partie 2 ---

# Fonction 1: f(x) = x^3 - x - 2 (continue partout)
# Une racine est attendue entre 1 et 2 (f(1)=-2, f(2)=4)
def f_tvi_1(x):
    return x**3 - x - 2

root1 = find_root_bisection(f_tvi_1, 1, 2)
assert root1 is not None, "La racine de x^3 - x - 2 doit être trouvée"
assert abs(f_tvi_1(root1)) < 1e-5, f"La valeur de f(root1) doit être proche de 0, est {f_tvi_1(root1)}"
# La racine exacte est environ 1.521
assert abs(root1 - 1.521) < 0.01, f"La racine de x^3 - x - 2 est environ 1.521, trouvée {root1}"

# Fonction 2: f(x) = cos(x) - x (continue partout)
# Une racine est attendue entre 0 et 1 (f(0)=1, f(1)=cos(1)-1 ~ -0.46)
def f_tvi_2(x):
    return math.cos(x) - x

root2 = find_root_bisection(f_tvi_2, 0, 1)
assert root2 is not None, "La racine de cos(x) - x doit être trouvée"
assert abs(f_tvi_2(root2)) < 1e-5, f"La valeur de f(root2) doit être proche de 0, est {f_tvi_2(root2)}"
# La racine exacte est environ 0.739
assert abs(root2 - 0.739) < 0.01, f"La racine de cos(x) - x est environ 0.739, trouvée {root2}"

# Fonction 3: Cas où f(a) et f(b) ont le même signe (pas de garantie par le TVI)
def f_tvi_3(x):
    return x**2

root3 = find_root_bisection(f_tvi_3, 1, 2) # f(1)=1, f(2)=4
assert root3 is None, "Aucune racine ne doit être trouvée si f(a) et f(b) ont le même signe"

root3_bis = find_root_bisection(f_tvi_3, -1, 2) # f(-1)=1, f(2)=4. Il y a une racine en 0, mais le TVI ne la garantit pas ici.
assert root3_bis is None, "Aucune racine ne doit être trouvée si f(a) et f(b) ont le même signe, même s'il y en a une"

# Fonction 4: Fonction discontinue où le TVI ne s'applique pas
# f(x) = 1 si x >= 0, -1 si x < 0. f(-1)=-1, f(1)=1. f(a)*f(b) < 0.
# Mais il n'y a pas de racine, car la fonction "saute" la valeur 0.
def f_tvi_4(x):
    return 1 if x >= 0 else -1

root4 = find_root_bisection(f_tvi_4, -1, 1)
# Pédagogie: Ici, la méthode de dichotomie pourrait converger vers 0,
# mais f(0) est 1, pas 0. Cela illustre l'importance de la condition de continuité.
# Notre implémentation va retourner 0, car elle ne vérifie pas la continuité formellement.
# C'est une limite de l'approche purement numérique sans vérification de la continuité.
# Cependant, f(mid) sera 1 ou -1, jamais 0, donc la boucle continuera jusqu'à la tolérance.
# Le test doit donc vérifier que f(root4) n'est PAS 0.
assert root4 is not None, "La dichotomie devrait retourner une valeur même pour une fonction discontinue"
assert abs(f_tvi_4(root4)) > 1e-5, "Pour une fonction discontinue, la 'racine' trouvée ne doit pas être une vraie racine"
print(f"Pour la fonction discontinue f_tvi_4, la dichotomie a trouvé {root4} où f({root4})={f_tvi_4(root4)}. Ceci illustre la nécessité de la continuité pour le TVI.")


print("Tous les tests de la Partie 2 sont passés avec succès !")
```

## Partie 3 : Illustration du Théorème des Bornes Atteintes (TBE / EVT)

### Concept Théorique

Le **Théorème des Bornes Atteintes (TBE)**, également connu sous le nom de Théorème de Weierstrass, est un autre théorème fondamental de la continuité. Il affirme que si une fonction $f$ est **continue** sur un intervalle fermé et borné $[a, b]$, alors $f$ atteint son minimum et son maximum sur cet intervalle. C'est-à-dire qu'il existe des points $c_1, c_2 \in [a, b]$ tels que $f(c_1) \le f(x) \le f(c_2)$ pour tout $x \in [a, b]$.

### Implémentation Numérique : Échantillonnage

Pour illustrer ce théorème numériquement sans utiliser de calcul différentiel (dérivées), nous allons échantillonner la fonction sur un grand nombre de points équidistants dans l'intervalle $[a, b]$ et trouver les valeurs minimale et maximale parmi ces échantillons.

**Attention :** Cette méthode est une **illustration numérique par échantillonnage**, et non une preuve formelle. Elle ne garantit pas de trouver les extrema exacts, mais une très bonne approximation si le nombre d'échantillons est suffisant et si la fonction est "bien comportée" (ce qui est souvent le cas pour les fonctions continues).

```python
def find_extrema_numerical(f, a, b, num_samples=1000):
    """
    Illustre numériquement le Théorème des Bornes Atteintes en trouvant
    les valeurs minimale et maximale d'une fonction f sur un intervalle [a, b]
    par échantillonnage.

    Ce théorème repose sur la continuité de f sur l'intervalle fermé [a, b].

    Args:
        f (callable): La fonction à analyser.
        a (float): Borne inférieure de l'intervalle.
        b (float): Borne supérieure de l'intervalle.
        num_samples (int): Le nombre de points à échantillonner dans l'intervalle.

    Returns:
        tuple: Un tuple (min_value, max_value) ou (None, None) en cas d'erreur.
    """
    if num_samples <= 1:
        raise ValueError("num_samples doit être supérieur à 1.")
    if b < a:
        a, b = b, a # Assurer que a est la borne inférieure

    # Étape 1 : Générer des points d'échantillonnage
    # Nous créons une liste de points équidistants dans l'intervalle [a, b].
    # Pédagogie: Inclure les bornes 'a' et 'b' est crucial car le TBE s'applique
    # sur un intervalle FERMÉ, et les extrema peuvent être atteints aux bornes.
    points = [a + i * (b - a) / (num_samples - 1) for i in range(num_samples)]

    # Étape 2 : Calculer les valeurs de la fonction pour chaque point
    values = []
    for x in points:
        try:
            values.append(f(x))
        except (ValueError, ZeroDivisionError):
            # Pédagogie: Si la fonction n'est pas définie pour certains points
            # de l'intervalle, elle n'est pas continue sur [a, b], et le TBE
            # ne s'applique pas. Nous retournons None pour indiquer un problème.
            print(f"Erreur: La fonction n'est pas définie en x={x}. Le TBE ne s'applique pas.")
            return None, None

    # Étape 3 : Trouver le minimum et le maximum parmi les valeurs échantillonnées
    # Pédagogie: Pour une fonction continue, ces valeurs approcheront les vrais extrema.
    # Pour une fonction discontinue, cette méthode pourrait donner des résultats trompeurs.
    min_value = values[0]
    max_value = values[0]

    for val in values:
        if val < min_value:
            min_value = val
        if val > max_value:
            max_value = val

    return min_value, max_value

# --- Tests pour la Partie 3 ---

# Fonction 1: f(x) = x^2 sur [-1, 2] (continue)
# Min attendu: f(0)=0. Max attendu: f(2)=4.
def f_tbe_1(x):
    return x * x

min1, max1 = find_extrema_numerical(f_tbe_1, -1, 2)
assert min1 is not None and max1 is not None, "Extrema pour x^2 doivent être trouvés"
assert abs(min1 - 0) < 1e-3, f"Min de x^2 sur [-1,2] doit être 0, trouvé {min1}"
assert abs(max1 - 4) < 1e-3, f"Max de x^2 sur [-1,2] doit être 4, trouvé {max1}"

# Fonction 2: f(x) = sin(x) sur [0, pi] (continue)
# Min attendu: f(0)=0 ou f(pi)=0. Max attendu: f(pi/2)=1.
def f_tbe_2(x):
    return math.sin(x)

min2, max2 = find_extrema_numerical(f_tbe_2, 0, math.pi)
assert min2 is not None and max2 is not None, "Extrema pour sin(x) doivent être trouvés"
assert abs(min2 - 0) < 1e-3, f"Min de sin(x) sur [0,pi] doit être 0, trouvé {min2}"
assert abs(max2 - 1) < 1e-3, f"Max de sin(x) sur [0,pi] doit être 1, trouvé {max2}"

# Fonction 3: f(x) = x si x < 0.5, x+1 si x >= 0.5 sur [0, 1] (discontinue)
# Le TBE ne s'applique pas. Le max n'est pas atteint (il y a un "saut").
def f_tbe_3(x):
    return x if x < 0.5 else x + 1

min3, max3 = find_extrema_numerical(f_tbe_3, 0, 1)
assert min3 is not None and max3 is not None, "Extrema pour f_tbe_3 doivent être trouvés numériquement"
# Pédagogie: Pour cette fonction discontinue, le minimum est 0 (f(0)=0).
# Le maximum "théorique" serait proche de 2 (limite à droite de 0.5 est 1.5, f(1)=2).
# Cependant, la valeur 0.5 n'est pas atteinte par la branche inférieure, et la valeur 1.5 n'est pas atteinte par la branche supérieure.
# Notre échantillonnage trouvera f(0)=0 et f(1)=2.
assert abs(min3 - 0) < 1e-3, f"Min de f_tbe_3 sur [0,1] doit être 0, trouvé {min3}"
assert abs(max3 - 2) < 1e-3, f"Max de f_tbe_3 sur [0,1] doit être 2, trouvé {max3}"
# Note: Ce test montre que l'échantillonnage peut trouver des valeurs aux bornes,
# mais ne prouve pas que le maximum est "atteint" au sens du TBE pour une fonction discontinue.
# C'est une illustration des limites de l'approche numérique sans la garantie de continuité.

# Fonction 4: f(x) = 1/x sur [0.1, 1] (continue sur cet intervalle)
# Min attendu: f(1)=1. Max attendu: f(0.1)=10.
def f_tbe_4(x):
    return 1 / x

min4, max4 = find_extrema_numerical(f_tbe_4, 0.1, 1)
assert min4 is not None and max4 is not None, "Extrema pour 1/x sur [0.1,1] doivent être trouvés"
assert abs(min4 - 1) < 1e-3, f"Min de 1/x sur [0.1,1] doit être 1, trouvé {min4}"
assert abs(max4 - 10) < 1e-3, f"Max de 1/x sur [0.1,1] doit être 10, trouvé {max4}"

# Fonction 5: f(x) = 1/x sur [0, 1] (discontinue en 0)
# Le TBE ne s'applique pas car l'intervalle n'est pas fermé où f est continue.
min5, max5 = find_extrema_numerical(f_tbe_4, 0, 1)
assert min5 is None and max5 is None, "Extrema pour 1/x sur [0,1] ne doivent pas être trouvés (discontinuité)"

print("Tous les tests de la Partie 3 sont passés avec succès !")
```
