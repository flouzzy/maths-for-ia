## Partie 1 : Rappels Théoriques sur le Théorème des Valeurs Intermédiaires (TVI)

Le Théorème des Valeurs Intermédiaires est un pilier de l'analyse réelle. Il stipule que :

**Théorème des Valeurs Intermédiaires (TVI)**
Soit $f$ une fonction continue sur un intervalle fermé $[a, b]$. Pour tout réel $k$ compris entre $f(a)$ et $f(b)$ (c'est-à-dire $f(a) \le k \le f(b)$ ou $f(b) \le k \le f(a)$), il existe au moins un réel $c$ dans l'intervalle $[a, b]$ tel que $f(c) = k$.

Un cas particulier très utile est celui où $k=0$. Si $f(a)$ et $f(b)$ ont des signes opposés (c'est-à-dire $f(a) \cdot f(b) < 0$), alors il existe au moins un $c \in ]a, b[$ tel que $f(c) = 0$. C'est ce cas que nous allons implémenter pour trouver des racines.

**L'importance de la continuité :** La condition de continuité est cruciale. Sans elle, le théorème ne tient pas. Une fonction discontinue peut "sauter" une valeur intermédiaire sans jamais l'atteindre.

## Partie 2 : Implémentation de l'Algorithme de Dichotomie

L'algorithme de dichotomie est une méthode numérique itérative pour trouver une racine d'une fonction continue sur un intervalle donné. Il exploite directement le TVI.

### Principe de l'Algorithme de Dichotomie

1.  **Initialisation :** On part d'un intervalle $[a, b]$ tel que $f(a)$ et $f(b)$ ont des signes opposés.
2.  **Itération :**
    *   Calculer le milieu $m = (a+b)/2$.
    *   Évaluer $f(m)$.
    *   Si $f(m)$ est proche de zéro, $m$ est notre racine approximative.
    *   Sinon, si $f(a)$ et $f(m)$ ont des signes opposés, la racine se trouve dans $[a, m]$. On remplace $b$ par $m$.
    *   Sinon (si $f(b)$ et $f(m)$ ont des signes opposés), la racine se trouve dans $[m, b]$. On remplace $a$ par $m$.
3.  **Arrêt :** L'algorithme s'arrête lorsque l'intervalle $[a, b]$ devient suffisamment petit (sa longueur est inférieure à une tolérance donnée) ou après un nombre maximal d'itérations.

### Code Python de la Méthode de Dichotomie

```python
def find_root_bisection(f, a, b, tolerance=1e-6, max_iterations=100):
    """
    Implémente l'algorithme de dichotomie pour trouver une racine de la fonction f
    dans l'intervalle [a, b].

    Préconditions (vérifiées par des assertions) :
    1. L'intervalle [a, b] est valide (a < b).
    2. La fonction f est continue sur [a, b] (cette condition est supposée, non vérifiée par le code).
    3. f(a) et f(b) ont des signes opposés, garantissant l'existence d'une racine
       selon le TVI (f(a) * f(b) < 0).

    Args:
        f (callable): La fonction dont on cherche la racine. Prend un float, retourne un float.
        a (float): Borne inférieure de l'intervalle de recherche.
        b (float): Borne supérieure de l'intervalle de recherche.
        tolerance (float): La précision souhaitée pour la racine (longueur de l'intervalle final).
        max_iterations (int): Nombre maximal d'itérations pour éviter les boucles infinies.

    Returns:
        float: Une approximation de la racine de f dans [a, b].

    Raises:
        ValueError: Si les préconditions ne sont pas remplies.
    """
    # --- Assertions de validation des préconditions mathématiques ---

    # Précondition 1: L'intervalle doit être valide.
    assert a < b, "Erreur: La borne inférieure 'a' doit être strictement inférieure à la borne supérieure 'b'."

    # Évaluation des bornes. Utilisation de try-except pour gérer les cas où f n'est pas définie aux bornes.
    try:
        f_a = f(a)
        f_b = f(b)
    except Exception as e:
        raise ValueError(f"Erreur lors de l'évaluation de f aux bornes de l'intervalle: {e}")

    # Précondition 3: f(a) et f(b) doivent avoir des signes opposés.
    # C'est la condition clé du TVI pour garantir l'existence d'une racine entre a et b.
    # Si f(a) ou f(b) est déjà 0 (ou très proche), c'est une racine, on peut la retourner directement.
    if abs(f_a) < tolerance:
        return a
    if abs(f_b) < tolerance:
        return b

    # La condition f(a) * f(b) < 0 est essentielle pour l'application du TVI.
    assert f_a * f_b < 0, (
        f"Erreur: f({a})={f_a} et f({b})={f_b} n'ont pas de signes opposés. "
        "Le TVI ne garantit pas l'existence d'une racine dans cet intervalle."
    )

    # --- Initialisation de l'algorithme ---
    low = a
    high = b
    iteration_count = 0

    # --- Boucle principale de dichotomie ---
    # La boucle continue tant que l'intervalle est plus grand que la tolérance
    # et que le nombre maximal d'itérations n'est pas atteint.
    while (high - low) / 2 > tolerance and iteration_count < max_iterations:
        mid = (low + high) / 2  # Calcul du milieu de l'intervalle actuel.
        f_mid = f(mid)          # Évaluation de la fonction au milieu.

        # Si f(mid) est très proche de zéro, nous avons trouvé une racine.
        if abs(f_mid) < tolerance:
            return mid

        # Application du TVI pour réduire l'intervalle :
        # Si f(low) et f(mid) ont des signes opposés, la racine est dans [low, mid].
        # On utilise f_a (valeur de f(low)) pour éviter de réévaluer f(low) à chaque itération.
        if f_a * f_mid < 0:
            high = mid
            # f_a reste f(low) car low n'a pas changé.
        # Sinon, la racine est dans [mid, high].
        else:
            low = mid
            f_a = f_mid # Mettre à jour f_a car low a changé pour mid.

        iteration_count += 1

    # Si le nombre max d'itérations est atteint sans atteindre la tolérance,
    # ou si la tolérance est atteinte, on retourne le milieu de l'intervalle final
    # comme meilleure approximation.
    final_root_approx = (low + high) / 2

    # --- Assertion de validation du résultat ---
    # Vérifie que la valeur de la fonction à la racine trouvée est proche de zéro.
    # C'est une validation a posteriori de la qualité de l'approximation.
    try:
        # On utilise une tolérance légèrement plus large pour cette assertion finale
        # car la condition d'arrêt est sur la taille de l'intervalle, pas directement sur f(mid).
        assert abs(f(final_root_approx)) < tolerance * 10, (
            f"La valeur de f à la racine trouvée ({final_root_approx}) est {f(final_root_approx)}, "
            f"ce qui est supérieur à la tolérance * 10 ({tolerance * 10}). "
            "La convergence n'a peut-être pas été suffisante ou la fonction est très plate."
        )
    except Exception as e:
        print(f"Attention: Impossible de valider f(racine) en raison d'une erreur: {e}")

    return final_root_approx

```

### Cas de Non-Continuité : L'importance de la condition du TVI

Le TVI repose fondamentalement sur la continuité de la fonction. Si la fonction n'est pas continue, l'algorithme de dichotomie peut échouer ou retourner un résultat incorrect, même si $f(a)$ et $f(b)$ ont des signes opposés.

```python
# Fonction discontinue par morceaux
def f_discontinuous(x):
    # Cette fonction "saute" de -1 à 1 en x=0. Elle n'est pas continue en 0.
    if x < 0:
        return -1
    else:
        return 1

print("\n--- Test 4: Fonction discontinue f(x) = -1 si x<0, 1 si x>=0 sur [-1, 1] ---")
# Ici, f(-1) = -1 et f(1) = 1. Les signes sont opposés.
# Cependant, il n'y a pas de racine car la fonction "saute" de -1 à 1 en x=0.
try:
    root_disc = find_root_bisection(f_discontinuous, -1, 1)
    print(f"Racine trouvée (incorrecte) pour f_discontinuous: {root_disc}")
    print(f"Valeur de f_discontinuous({root_disc}): {f_discontinuous(root_disc)}")
    # L'assertion finale abs(f(root)) < tolerance devrait échouer ici,
    # car f_discontinuous ne prend que les valeurs -1 ou 1.
    # Cela démontre que l'algorithme a convergé vers un point où f(x) n'est pas 0.
    # C'est une preuve de l'échec du TVI sans continuité.
    assert abs(f_discontinuous(root_disc)) < 1e-5, "ATTENTION: La fonction est discontinue, le TVI ne s'applique pas. L'algorithme a trouvé un point où f(x) n'est pas zéro."
    print("Test 4 réussi (l'assertion a bien détecté le problème).")
except ValueError as e:
    print(f"Erreur lors du Test 4: {e}")
except AssertionError as e:
    print(f"Assertion échouée lors du Test 4 (comme attendu pour une fonction discontinue): {e}")

# Autre exemple de fonction discontinue (avec une asymptote)
def f_discontinuous_asymptote(x):
    if x == 0:
        # Provoque une erreur si on essaie d'évaluer f(0), rendant la fonction non définie en 0.
        raise ValueError("Division par zéro")
    return 1/x

print("\n--- Test 5: Fonction discontinue f(x) = 1/x sur [-1, 1] (avec 0 exclu) ---")
# f(-1) = -1, f(1) = 1. Signes opposés.
# Mais la fonction n'est pas continue sur [-1, 1] car elle n'est pas définie en 0.
try:
    root_asymptote = find_root_bisection(f_discontinuous_asymptote, -1, 1)
    print(f"Racine trouvée (incorrecte) pour f_discontinuous_asymptote: {root_asymptote}")
    print(f"Valeur de f_discontinuous_asymptote({root_asymptote}): {f_discontinuous_asymptote(root_asymptote)}")
    assert abs(f_discontinuous_asymptote(root_asymptote)) < 1e-5, "ATTENTION: La fonction est discontinue, le TVI ne s'applique pas."
    print("Test 5 réussi (l'assertion a bien détecté le problème).")
except ValueError as e:
    print(f"Erreur lors du Test 5: {e}")
except AssertionError as e:
    print(f"Assertion échouée lors du Test 5 (comme attendu pour une fonction discontinue): {e}")

```

### Cas où `f(a) * f(b) >= 0` : Violation de la précondition du TVI

Si $f(a)$ et $f(b)$ n'ont pas des signes opposés, le TVI ne garantit pas l'existence d'une racine. Notre assertion initiale doit le détecter.

```python
print("\n--- Test 6: f(x) = x^2 - 2 sur [1.5, 2] (f(a) et f(b) de même signe) ---")
# f(1.5) = 1.5^2 - 2 = 2.25 - 2 = 0.25
# f(2) = 2^2 - 2 = 2
# Les deux sont positifs. Pas de garantie de racine par le TVI.
try:
    root_no_sign_change = find_root_bisection(f1, 1.5, 2)
    print(f"Racine trouvée: {root_no_sign_change}")
except ValueError as e:
    print(f"Erreur attendue lors du Test 6: {e}")
except AssertionError as e:
    print(f"Assertion échouée attendue lors du Test 6: {e}")
    print("Test 6 réussi : L'assertion a correctement détecté que f(a) et f(b) n'ont pas de signes opposés.")

print("\n--- Test 7: f(x) = x^2 sur [-1, 1] (f(a) et f(b) de même signe, mais racine en 0) ---")
# f(-1) = 1, f(1) = 1. Même signe.
# Il y a une racine en x=0, mais la condition f(a)*f(b) < 0 du TVI n'est pas remplie.
# L'algorithme de dichotomie, basé sur cette condition, ne devrait pas s'exécuter.
def f_x_squared(x):
    return x**2

try:
    root_x_squared = find_root_bisection(f_x_squared, -1, 1)
    print(f"Racine trouvée: {root_x_squared}")
except ValueError as e:
    print(f"Erreur attendue lors du Test 7: {e}")
except AssertionError as e:
    print(f"Assertion échouée attendue lors du Test 7: {e}")
    print("Test 7 réussi : L'assertion a correctement détecté que f(a) et f(b) n'ont pas de signes opposés.")

```
