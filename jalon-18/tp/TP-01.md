## Partie 1 : Approximation de la Continuité en un Point

La continuité d'une fonction $f$ en un point $a$ est définie par :
$\forall \epsilon > 0, \exists \delta > 0 \text{ tel que } \forall x \text{ si } |x - a| < \delta \text{ alors } |f(x) - f(a)| < \epsilon$.
Ou de manière équivalente : $\lim_{x \to a} f(x) = f(a)$.

En pratique, il est impossible de tester "pour tout $\epsilon$" et "pour tout $x$" numériquement. Nous allons donc adopter une approche d'approximation :
1.  **Approximation de la limite :** Évaluer $f(x)$ pour des $x$ très proches de $a$ (à gauche et à droite) et vérifier si les valeurs de $f(x)$ se rapprochent d'une valeur unique.
2.  **Vérification de la continuité :** Comparer cette valeur limite approximée avec $f(a)$.

### Exercice 1.1 : Fonction d'approximation de la limite

Implémentez une fonction `approx_limit(f, a, delta_range, num_steps, tolerance)` qui tente d'estimer la limite de `f` en `a`.

*   `f`: La fonction à tester.
*   `a`: Le point autour duquel on cherche la limite.
*   `delta_range`: Une petite valeur maximale pour `delta` (ex: 0.01).
*   `num_steps`: Le nombre de points à tester de chaque côté de `a`.
*   `tolerance`: La tolérance pour considérer que les valeurs de `f(x)` convergent.

```python
import math

def approx_limit(f, a, delta_range=0.01, num_steps=100, tolerance=1e-6):
    """
    Approximation numérique de la limite d'une fonction f en un point a.

    Cette fonction évalue f(x) pour des x s'approchant de a par la gauche et par la droite.
    Elle retourne une estimation de la limite si les valeurs convergent, sinon None.

    Args:
        f (callable): La fonction dont on veut approximer la limite.
        a (float): Le point où la limite est recherchée.
        delta_range (float): La plage maximale de delta à considérer autour de 'a'.
                             Les points seront testés dans [a - delta_range, a + delta_range].
        num_steps (int): Le nombre de points à tester de chaque côté de 'a'.
        tolerance (float): La tolérance pour considérer que les valeurs de f(x) convergent
                           vers une même limite.

    Returns:
        float or None: L'estimation de la limite si elle semble exister, sinon None.
                       Retourne None si f(a) est indéfini (ex: division par zéro)
                       ou si les valeurs ne convergent pas.
    """

    # Liste pour stocker les valeurs de f(x) autour de 'a'
    f_values = []

    # Test des points à gauche de 'a'
    # On génère des deltas de plus en plus petits pour s'approcher de 'a'.
    for i in range(1, num_steps + 1):
        delta = delta_range * i / num_steps
        x_left = a - delta
        try:
            f_values.append(f(x_left))
        except (ValueError, ZeroDivisionError):
            # Gérer les cas où f(x) n'est pas défini (ex: sqrt(negatif), 1/0)
            # Ces points ne contribuent pas à la limite.
            pass

    # Test des points à droite de 'a'
    for i in range(1, num_steps + 1):
        delta = delta_range * i / num_steps
        x_right = a + delta
        try:
            f_values.append(f(x_right))
        except (ValueError, ZeroDivisionError):
            pass

    if not f_values:
        # Aucun point n'a pu être évalué, la limite est indéfinie numériquement
        return None

    # Calcul de la moyenne des valeurs pour estimer la limite.
    # C'est une heuristique simple. Une approche plus robuste impliquerait
    # de vérifier la convergence des sous-séquences ou d'utiliser des méthodes statistiques.
    estimated_limit = sum(f_values) / len(f_values)

    # Vérifier si toutes les valeurs sont "proches" de l'estimation.
    # Ceci est une approximation de la définition epsilon-delta :
    # pour un delta donné (delta_range), toutes les f(x) doivent être proches
    # de la limite estimée (dans un epsilon donné par la tolerance).
    for val in f_values:
        if abs(val - estimated_limit) > tolerance:
            # Si une valeur est trop éloignée, la limite ne semble pas exister
            # ou n'est pas unique dans cette plage (ex: discontinuité de saut).
            return None

    return estimated_limit

# --- Assertions pour approx_limit ---

# Fonction continue simple : f(x) = x^2
def f_quad(x):
    return x * x

# La limite de x^2 en 2 est 4
assert abs(approx_limit(f_quad, 2) - 4) < 1e-5, "Test 1.1.1: Limite de x^2 en 2"

# Fonction avec une discontinuité "saut" : f(x) = 1 si x >= 0, -1 si x < 0
def f_step(x):
    return 1.0 if x >= 0 else -1.0

# La limite de f_step en 0 n'existe pas (limite gauche = -1, limite droite = 1)
assert approx_limit(f_step, 0) is None, "Test 1.1.2: Limite de f_step en 0 (discontinuité de saut)"

# Fonction avec un "trou" : f(x) = (x^2 - 1) / (x - 1) pour x != 1, indéfini en x = 1
# La limite en 1 est 2 (car (x^2 - 1) / (x - 1) = x + 1 pour x != 1)
def f_hole(x):
    if x == 1:
        # Simule l'indéfinition de la fonction au point exact
        raise ZeroDivisionError("Indéfini en x=1")
    return (x * x - 1) / (x - 1)

assert abs(approx_limit(f_hole, 1) - 2) < 1e-5, "Test 1.1.3: Limite de f_hole en 1 (trou)"

# Fonction avec une asymptote verticale : f(x) = 1/x
def f_inv(x):
    return 1.0 / x

# La limite de 1/x en 0 n'existe pas (tend vers +/- infini)
assert approx_limit(f_inv, 0) is None, "Test 1.1.4: Limite de 1/x en 0 (asymptote verticale)"

print("Tous les tests pour approx_limit ont réussi !")
```

### Exercice 1.2 : Vérification de la Continuité en un Point

Implémentez une fonction `is_continuous_at_point(f, a, tolerance, delta_range, num_steps)` qui détermine si une fonction `f` est continue en un point `a`.

*   `f`: La fonction à tester.
*   `a`: Le point de test.
*   `tolerance`: La tolérance pour la comparaison entre $f(a)$ et la limite.
*   Les autres paramètres sont passés à `approx_limit`.

```python
def is_continuous_at_point(f, a, tolerance=1e-6, delta_range=0.01, num_steps=100):
    """
    Vérifie numériquement si une fonction f est continue en un point a.

    Une fonction f est continue en a si (définition formelle):
    1. f(a) est défini.
    2. La limite de f(x) quand x tend vers a existe.
    3. La limite de f(x) quand x tend vers a est égale à f(a).

    Args:
        f (callable): La fonction à tester.
        a (float): Le point où la continuité est vérifiée.
        tolerance (float): La tolérance pour la comparaison des valeurs flottantes.
        delta_range (float): Plage pour l'approximation de la limite.
        num_steps (int): Nombre de pas pour l'approximation de la limite.

    Returns:
        bool: True si la fonction est considérée continue en 'a', False sinon.
    """

    # 1. Vérifier si f(a) est défini
    try:
        f_a = f(a)
    except (ValueError, ZeroDivisionError):
        # Si f(a) n'est pas défini (ex: division par zéro, sqrt d'un négatif),
        # la fonction ne peut pas être continue en a.
        return False

    # 2. Approximer la limite de f(x) quand x tend vers a
    limit_val = approx_limit(f, a, delta_range, num_steps, tolerance)

    # Si la limite n'a pas pu être approximée (ex: discontinuité de saut, asymptote)
    if limit_val is None:
        return False

    # 3. Comparer f(a) avec la limite approximée
    # La continuité est vérifiée si la valeur de la fonction au point
    # est "suffisamment proche" de la limite des valeurs autour de ce point.
    return abs(f_a - limit_val) < tolerance

# --- Assertions pour is_continuous_at_point ---

# Fonction continue : f(x) = x^2
assert is_continuous_at_point(f_quad, 2) is True, "Test 1.2.1: x^2 est continue en 2"
assert is_continuous_at_point(f_quad, 0) is True, "Test 1.2.2: x^2 est continue en 0"

# Fonction discontinue (saut) : f_step
assert is_continuous_at_point(f_step, 0) is False, "Test 1.2.3: f_step n'est pas continue en 0"
assert is_continuous_at_point(f_step, 1) is True, "Test 1.2.4: f_step est continue en 1"
assert is_continuous_at_point(f_step, -1) is True, "Test 1.2.5: f_step est continue en -1"

# Fonction discontinue (trou) : f_hole
# f_hole est définie pour lever une erreur en x=1, donc f(1) n'est pas défini.
assert is_continuous_at_point(f_hole, 1) is False, "Test 1.2.6: f_hole n'est pas continue en 1 (trou)"
assert is_continuous_at_point(f_hole, 2) is True, "Test 1.2.7: f_hole est continue en 2"

# Fonction discontinue (asymptote) : f_inv
assert is_continuous_at_point(f_inv, 0) is False, "Test 1.2.8: f_inv n'est pas continue en 0 (asymptote)"
assert is_continuous_at_point(f_inv, 1) is True, "Test 1.2.9: f_inv est continue en 1"

# Fonction avec une racine carrée (domaine de définition)
def f_sqrt(x):
    if x < 0:
        raise ValueError("Racine carrée d'un nombre négatif")
    return math.sqrt(x)

assert is_continuous_at_point(f_sqrt, 4) is True, "Test 1.2.10: sqrt(x) est continue en 4"
assert is_continuous_at_point(f_sqrt, -1) is False, "Test 1.2.11: sqrt(x) n'est pas continue en -1 (non définie)"
# La continuité en 0 pour sqrt(x) est un cas particulier (continuité à droite).
# Notre approx_limit teste des deux côtés. Les points à gauche de 0 lèvent une erreur,
# ce qui empêche la convergence bilatérale. Donc, la fonction n'est pas continue au sens strict bilatéral.
assert is_continuous_at_point(f_sqrt, 0) is False, "Test 1.2.12: sqrt(x) n'est pas continue en 0 (pas de limite bilatérale)"


print("Tous les tests pour is_continuous_at_point ont réussi !")
```

## Partie 2 : Approximation de la Continuité sur un Intervalle

Une fonction $f$ est continue sur un intervalle fermé $[a, b]$ si elle est continue en tout point de cet intervalle (avec des notions de continuité à droite en $a$ et à gauche en $b$).
Numériquement, nous ne pouvons pas tester "tout point". Nous allons donc échantillonner l'intervalle et vérifier la continuité en un nombre suffisant de points.

### Exercice 2.1 : Vérification de la Continuité sur un Intervalle

Implémentez une fonction `is_continuous_on_interval(f, a, b, num_test_points, tolerance, delta_range, num_steps)` qui vérifie la continuité sur un intervalle `[a, b]`.

*   `f`: La fonction à tester.
*   `a`, `b`: Les bornes de l'intervalle.
*   `num_test_points`: Le nombre de points à échantillonner dans l'intervalle.
*   Les autres paramètres sont passés à `is_continuous_at_point`.

```python
def is_continuous_on_interval(f, a, b, num_test_points=50, tolerance=1e-6, delta_range=0.01, num_steps=100):
    """
    Vérifie numériquement si une fonction f est continue sur un intervalle [a, b].

    Cette fonction échantillonne l'intervalle [a, b] en 'num_test_points' points
    et vérifie la continuité en chacun de ces points en utilisant is_continuous_at_point.

    Note: C'est une approximation. Une fonction peut être discontinue entre deux points testés.
    Pour une preuve formelle, il faudrait une analyse mathématique.

    Args:
        f (callable): La fonction à tester.
        a (float): Borne inférieure de l'intervalle.
        b (float): Borne supérieure de l'intervalle.
        num_test_points (int): Nombre de points à échantillonner dans l'intervalle.
        tolerance (float): Tolérance pour la comparaison des valeurs flottantes.
        delta_range (float): Plage pour l'approximation de la limite.
        num_steps (int): Nombre de pas pour l'approximation de la limite.

    Returns:
        bool: True si la fonction est considérée continue sur l'intervalle, False sinon.
    """
    if a >= b:
        raise ValueError("La borne inférieure 'a' doit être strictement inférieure à la borne supérieure 'b'.")

    # Générer des points uniformément espacés dans l'intervalle [a, b]
    # On utilise une liste Python simple comme demandé, pas de numpy.linspace
    test_points = []
    if num_test_points == 1:
        test_points.append(a) # Ou (a+b)/2, mais pour un seul point, a est suffisant pour le test
    else:
        step_size = (b - a) / (num_test_points - 1)
        for i in range(num_test_points):
            point = a + i * step_size
            test_points.append(point)

    # Vérifier la continuité en chaque point échantillonné
    for point in test_points:
        if not is_continuous_at_point(f, point, tolerance, delta_range, num_steps):
            # Si la fonction est discontinue en un seul point, elle n'est pas continue sur l'intervalle
            return False

    return True

# --- Assertions pour is_continuous_on_interval ---

# Fonction continue : f(x) = x^2 sur [-5, 5]
assert is_continuous_on_interval(f_quad, -5, 5) is True, "Test 2.1.1: x^2 est continue sur [-5, 5]"

# Fonction discontinue (saut) : f_step sur [-1, 1]
# f_step est discontinue en 0, qui est dans [-1, 1]
assert is_continuous_on_interval(f_step, -1, 1) is False, "Test 2.1.2: f_step n'est pas continue sur [-1, 1]"
# f_step est continue sur [0.1, 1]
assert is_continuous_on_interval(f_step, 0.1, 1) is True, "Test 2.1.3: f_step est continue sur [0.1, 1]"

# Fonction discontinue (asymptote) : f_inv sur [-1, 1]
# f_inv est discontinue en 0, qui est dans [-1, 1]
assert is_continuous_on_interval(f_inv, -1, 1) is False, "Test 2.1.4: f_inv n'est pas continue sur [-1, 1]"
# f_inv est continue sur [0.1, 1]
assert is_continuous_on_interval(f_inv, 0.1, 1) is True, "Test 2.1.5: f_inv est continue sur [0.1, 1]"

# Fonction racine carrée sur [0, 10]
# Notre is_continuous_at_point considère sqrt(0) comme non continue bilatéralement.
# Donc, si 0 est inclus dans l'intervalle, cela devrait être False.
assert is_continuous_on_interval(f_sqrt, 0, 10) is False, "Test 2.1.6: sqrt(x) n'est pas continue sur [0, 10] (problème en 0)"
assert is_continuous_on_interval(f_sqrt, 0.001, 10) is True, "Test 2.1.7: sqrt(x) est continue sur [0.001, 10]"

print("Tous les tests pour is_continuous_on_interval ont réussi !")
```

## Partie 3 : Application : Théorème des Valeurs Intermédiaires (TVI) et Dichotomie

Le Théorème des Valeurs Intermédiaires (TVI) stipule que si une fonction $f$ est continue sur un intervalle fermé $[a, b]$, alors pour toute valeur $k$ comprise entre $f(a)$ et $f(b)$, il existe au moins un $c \in [a, b]$ tel que $f(c) = k$.
Un cas particulier important est la recherche de racines ($f(c) = 0$), si $f(a)$ et $f(b)$ sont de signes opposés.

L'algorithme de dichotomie (ou méthode de bissection) est une application directe du TVI pour trouver une racine d'une fonction continue.

### Exercice 3.1 : Implémentation de la Dichotomie

Implémentez une fonction `find_root_bisection(f, a, b, tolerance, max_iterations)` qui trouve une racine de `f` dans l'intervalle `[a, b]` en utilisant la méthode de dichotomie.

*   `f`: La fonction dont on cherche la racine.
*   `a`, `b`: Les bornes de l'intervalle initial.
*   `tolerance`: La précision souhaitée pour la racine.
*   `max_iterations`: Nombre maximal d'itérations pour éviter les boucles infinies.

```python
def find_root_bisection(f, a, b, tolerance=1e-6, max_iterations=1000):
    """
    Trouve une racine d'une fonction f dans l'intervalle [a, b] en utilisant
    la méthode de dichotomie (bisection).

    Préconditions (basées sur le TVI):
    1. La fonction f doit être continue sur l'intervalle [a, b].
    2. f(a) et f(b) doivent avoir des signes opposés (f(a) * f(b) < 0).

    Args:
        f (callable): La fonction dont on cherche la racine.
        a (float): Borne inférieure de l'intervalle.
        b (float): Borne supérieure de l'intervalle.
        tolerance (float): La précision souhaitée pour la racine.
        max_iterations (int): Nombre maximal d'itérations.

    Returns:
        float or None: La racine approximée si trouvée, sinon None.
                       Retourne None si les préconditions du TVI ne sont pas remplies
                       ou si la limite d'itérations est atteinte.
    """

    # Vérification des préconditions du TVI pour l'existence d'une racine.
    # L'algorithme de dichotomie repose fondamentalement sur la continuité de f
    # et le fait que f(a) et f(b) soient de signes opposés.

    try:
        f_a = f(a)
        f_b = f(b)
    except (ValueError, ZeroDivisionError):
        # Si f(a) ou f(b) n'est pas défini, on ne peut pas appliquer le TVI.
        # Cela indique une discontinuité aux bornes ou un domaine de définition non couvert.
        print(f"Erreur: f({a}) ou f({b}) n'est pas défini.")
        return None

    # Vérification du critère des signes opposés
    if f_a * f_b > 0:
        # Si f(a) et f(b) ont le même signe, le TVI ne garantit pas de racine.
        # La dichotomie ne peut pas être appliquée directement pour trouver une racine.
        print(f"Avertissement: f({a}) et f({b}) ont le même signe ({f_a}, {f_b}). Le TVI ne garantit pas de racine dans [{a}, {b}].")
        return None

    # Cas où une borne est déjà une racine
    if abs(f_a) < tolerance:
        return a
    if abs(f_b) < tolerance:
        return b

    # Algorithme de dichotomie
    for i in range(max_iterations):
        mid = (a + b) / 2.0
        try:
            f_mid = f(mid)
        except (ValueError, ZeroDivisionError):
            # Si f(mid) n'est pas défini, cela indique une discontinuité
            # ou un problème dans l'intervalle. La dichotomie échoue.
            print(f"Erreur: f({mid}) n'est pas défini pendant la dichotomie.")
            return None

        # Si le point milieu est suffisamment proche de zéro, c'est notre racine
        if abs(f_mid) < tolerance:
            return mid

        # Si l'intervalle est devenu trop petit, on a atteint la précision maximale
        if (b - a) / 2.0 < tolerance:
            return mid # Retourne le milieu comme meilleure approximation

        # Réduire l'intervalle en fonction du signe de f(mid)
        # Le TVI garantit qu'une racine se trouve dans l'intervalle où les signes sont opposés.
        if f_a * f_mid < 0:
            b = mid
            f_b = f_mid # Mettre à jour f_b pour éviter de recalculer
        else: # f_b * f_mid < 0 (cela implique f_a * f_mid > 0)
            a = mid
            f_a = f_mid # Mettre à jour f_a

    print(f"Avertissement: Nombre maximal d'itérations ({max_iterations}) atteint. La racine n'a pas été trouvée avec la tolérance {tolerance}.")
    return (a + b) / 2.0 # Retourne la meilleure approximation trouvée

# --- Assertions pour find_root_bisection ---

# Fonction continue avec une racine : f(x) = x^2 - 2 (racines +/- sqrt(2))
def f_poly(x):
    return x * x - 2

# Racine positive dans [1, 2]

assert root1 is not None and abs(f_poly(root1)) < 1e-5, "Test 3.1.1: Racine de x^2 - 2 dans [1, 2]"
assert abs(root1 - math.sqrt(2)) < 1e-5, "Test 3.1.2: Valeur de la racine de x^2 - 2"

# Racine négative dans [-2, -1]

assert root2 is not None and abs(f_poly(root2)) < 1e-5, "Test 3.1.3: Racine de x^2 - 2 dans [-2, -1]"
assert abs(root2 - (-math.sqrt(2))) < 1e-5, "Test 3.1.4: Valeur de la racine de x^2 - 2"

# Fonction sans racine dans l'intervalle où f(a) et f(b) ont le même signe
# f(x) = x^2 + 1. Pas de racine réelle.
def f_no_root(x):
    return x * x + 1

# Devrait retourner None car f(a) et f(b) ont le même signe
assert find_root_bisection(f_no_root, -1, 1) is None, "Test 3.1.5: Pas de racine pour x^2 + 1 dans [-1, 1]"

# Fonction discontinue où la dichotomie échouerait (même si f(a)*f(b) < 0)
# f_step: f(-1) = -1, f(1) = 1. f(-1)*f(1) < 0. Mais discontinue en 0.
# La dichotomie va converger vers 0, mais f(0) = 1, pas 0.
# L'algorithme de dichotomie ne vérifie pas la continuité, il suppose qu'elle est vraie.
# Si la fonction est discontinue, le résultat peut être trompeur.
# Pour l'assertion, on vérifie que la valeur retournée n'est pas une vraie racine.
```
