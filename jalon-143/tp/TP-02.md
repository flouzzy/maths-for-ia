# TP 2 : Vérification de la Forme Quadratique

## Contexte
Nous allons écrire une fonction pure Python qui évalue $x^T L x$ de manière matricielle (produit vecteur-matrice) et la comparer à l'évaluation $\sum_{\{i,j\} \in E} (x_i - x_j)^2$ pour démontrer expérimentalement leur égalité stricte.

## Code Python
```python
def mat_vec_mult(M, x):
    n = len(M)
    result = [0] * n
    for i in range(n):
        for j in range(n):
            result[i] += M[i][j] * x[j]
    return result

def dot_product(x, y):
    return sum(x_i * y_i for x_i, y_i in zip(x, y))

def compute_quadratic_form_matrix(L, x):
    # Calcule x^T * (L * x)
    Lx = mat_vec_mult(L, x)
    return dot_product(x, Lx)

def compute_quadratic_form_sum(edges, x):
    # Calcule sum((x_i - x_j)^2)
    total = 0
    for u, v in edges:
        total += (x[u] - x[v])**2
    return total

# --- VALIDATION MATHÉMATIQUE ---
def test_quadratic_forms():
    # Définition du graphe (Cycle à 4 sommets)
    n = 4
    edges = [(0, 1), (1, 2), (2, 3), (3, 0)]

    # Construction de L (hardcodée pour simplifier ou on reprend TP1)
    L = [
        [ 2, -1,  0, -1],
        [-1,  2, -1,  0],
        [ 0, -1,  2, -1],
        [-1,  0, -1,  2]
    ]

    # Vecteur x de test aléatoire
    x = [1.5, -2.0, 0.5, 3.0]

    res_matrix = compute_quadratic_form_matrix(L, x)
    res_sum = compute_quadratic_form_sum(edges, x)

    # Vérification d'égalité (avec tolérance pour flottants si besoin, ici entiers/demis donc exact)
    assert abs(res_matrix - res_sum) < 1e-9, f"Différence détectée: matrice={res_matrix}, somme={res_sum}"

    # Vérification que c'est bien semi-défini positif
    assert res_matrix >= 0, "La forme quadratique doit être positive ou nulle"

    print("Tous les tests mathématiques du TP 2 sont passés avec succès.")

test_quadratic_forms()
```
