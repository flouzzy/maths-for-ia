# TP 3 : Optimisation stochastique basique

L'objectif de ce TP est de manipuler programmatiquement les théorèmes d'intégration à paramètres avec du code Python natif.

```python
import random

def loss_func(theta, x_sample):
    '''Perte quadratique simple.'''
    return (x_sample - theta) ** 2

def grad_loss(theta, x_sample):
    return -2 * (x_sample - theta)

def sgd_step(theta, samples, lr=0.1):
    '''Descente de gradient stochastique (passant sous la somme/intégrale).'''
    grad_emp = sum(grad_loss(theta, x) for x in samples) / len(samples)
    return theta - lr * grad_emp

theta_opt = 5.0
for _ in range(100):
    echantillons = [random.gauss(3.0, 1.0) for _ in range(10)]
    theta_opt = sgd_step(theta_opt, echantillons)

assert abs(theta_opt - 3.0) < 0.5

```
