# TP 4 : Fonction d'erreur de Gauss (Erf)

L'objectif de ce TP est de manipuler programmatiquement les théorèmes d'intégration à paramètres avec du code Python natif.

```python
import math

def erf_approx(x, n=1000):
    '''Approximation numérique de la fonction erreur basée sur l'intégrale paramétrique.'''
    if x == 0: return 0.0
    h = x / n
    res = sum(math.exp(-(i*h)**2) for i in range(n)) * h
    return (2 / math.sqrt(math.pi)) * res

assert abs(erf_approx(0)) < 1e-4
# erf(1) ~ 0.8427
assert abs(erf_approx(1) - 0.8427) < 1e-2

```
