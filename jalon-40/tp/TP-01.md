# TP 1 : Calcul numérique d'intégrales par la méthode des rectangles

L'objectif de ce TP est de manipuler programmatiquement les théorèmes d'intégration à paramètres avec du code Python natif.

```python
def methode_rectangles(f, a, b, n=10000):
    '''Approximation de l'intégrale de f sur [a, b] avec n sous-intervalles.'''
    h = (b - a) / n
    integrale = sum(f(a + i * h) for i in range(n))
    return integrale * h

# Test avec fonction constante
assert abs(methode_rectangles(lambda x: 1, 0, 1) - 1.0) < 1e-3

```
