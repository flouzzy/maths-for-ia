# TP 5 : Reparameterization Trick naïf

L'objectif de ce TP est de manipuler programmatiquement les théorèmes d'intégration à paramètres avec du code Python natif.

```python
import random

def grad_sans_reparam(mu, n_samples=10000):
    '''Gradient de E_N(mu, 1)[x^2] calculé numériquement (haute variance).'''
    return sum((random.gauss(mu, 1)**2 - (mu-0.01)**2)/0.01 for _ in range(n_samples))/n_samples

def grad_avec_reparam(mu, n_samples=10000):
    '''Gradient de E_N(0, 1)[(mu + e)^2]. Interversion de l'intégrale et du gradient.'''
    # d/dmu (mu + e)^2 = 2(mu + e)
    return sum(2 * (mu + random.gauss(0, 1)) for _ in range(n_samples))/n_samples

# Le gradient exact pour E[x^2] avec x~N(mu, 1) est d/dmu (mu^2 + 1) = 2*mu
assert abs(grad_avec_reparam(3.0) - 6.0) < 0.2

```
