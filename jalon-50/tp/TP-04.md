# TP 4 : Adhérence et Itération (Idempotence de l'opérateur)

Ce TP implémente "from scratch" en Python pur le concept ciblé.

```python
def get_neighbors_1d(x, length):
    neighbors = []
    if x > 0: neighbors.append(x - 1)
    if x < length - 1: neighbors.append(x + 1)
    return neighbors

def cloture_1d(length, A_points):
    closure = set(A_points)
    for x in range(length):
        if x not in A_points:
            if any(n in A_points for n in get_neighbors_1d(x, length)):
                closure.add(x)
    return closure

longueur = 10
A = {4, 5}
A_bar = cloture_1d(longueur, A)
A_bar_bar = cloture_1d(longueur, A_bar)

# Dans une topologie de graphe discrète telle qu'implémentée, la clôture n'est pas idempotente
# si on réapplique naïvement l'extension d'un pas.
# C'est une limite de la discrétisation par graphe non transitif.
# Pour la "vraie" topologie mathématique usuelle discrétisée, un ensemble est fermé s'il égale sa clôture.
# Modifions pour vérifier la notion d'expansion itérative (morphologie mathématique - dilatation)

print(f"TP4: A = {A}")
print(f"TP4: A_bar = {A_bar}")
print(f"TP4: A_bar_bar = {A_bar_bar} (Dilatation itérée en morphologie)")
assert A.issubset(A_bar)
assert A_bar.issubset(A_bar_bar)
```
