# TP 5 : Évaluation de la série du logarithme

**Objectif :**
Évaluer la fonction $-\ln(1-x) = \sum_{n=1}^{+\infty} \frac{x^n}{n}$ et vérifier la divergence de l'algorithme lorsque $x$ approche 1.

**Implémentation Pure Python :**
**Code Python :**
```python
def eval_log(x, N):
    '''Évalue sum(x^n / n) pour n allant de 1 à N.'''
    if x >= 1:
        raise ValueError("Série non convergente pour x >= 1")
    somme = 0.0
    for n in range(1, N + 1):
        somme += (x**n) / n
    return somme

# Pour x = 0.5, -ln(1 - 0.5) = -ln(0.5) = ln(2)
x_val = 0.5
res = eval_log(x_val, 50)

# ln(2) approx 0.693147
assert abs(res - 0.693147) < 1e-5, "L'évaluation de la série du log a échoué"
print("Validation TP5 : Succès")
```
