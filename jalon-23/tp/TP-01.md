# TP 1 : Évaluation d'une série entière et borne d'erreur

**Objectif :**
Évaluer numériquement la série de l'exponentielle $\sum \frac{x^n}{n!}$ jusqu'à un certain rang, et valider la convergence de l'algorithme.

**Implémentation Pure Python :**
```python
def factorielle(n):
    if n == 0:
        return 1
    res = 1
    for i in range(1, n + 1):
        res *= i
    return res

def eval_exp(x, N):
    '''Évalue la série entière de exp(x) jusqu'au rang N inclus.'''
    somme = 0.0
    for n in range(N + 1):
        somme += (x**n) / factorielle(n)
    return somme

# Validation Mathématique
x_val = 1.0
res = eval_exp(x_val, 15)
# e approche 2.718281828
assert abs(res - 2.718281828) < 1e-7, "La convergence vers la constante d'Euler a échoué"
print("Validation TP1 : Succès")
```
