# TP-04 : Approximation des Nombres Réels et Séquences

## Introduction

Dans le TP-02, nous avons constaté l'incomplétude des nombres rationnels ($\mathbb{Q}$) : certains ensembles bornés supérieurement n'y ont pas de supremum. L'axiome de la borne supérieure garantit l'existence de ces suprema dans les nombres réels ($\mathbb{R}$). Or, beaucoup de ces suprema sont des nombres irrationnels. Ce TP se propose d'explorer comment nous pouvons "construire" ou du moins *approximer* ces nombres irrationnels à l'aide de séquences de nombres rationnels. C'est une approche intuitive pour comprendre comment les irrationnels "remplissent les trous" de la droite rationnelle.

## Prérequis Mathématiques

**Définition 1 (Suite de Cauchy)** : Une suite de nombres réels $(x_n)_{n \in \mathbb{N}}$ est dite de Cauchy si pour tout $\epsilon > 0$, il existe un entier $N$ tel que pour tous $m, n > N$, on a $|x_m - x_n| < \epsilon$. Intuitivement, les termes d'une suite de Cauchy se rapprochent arbitrairement les uns des autres à mesure que $n$ augmente.

**Définition 2 (Convergence d'une suite)** : Une suite $(x_n)_{n \in \mathbb{N}}$ converge vers une limite $L$ si pour tout $\epsilon > 0$, il existe un entier $N$ tel que pour tout $n > N$, on a $|x_n - L| < \epsilon$.

**Théorème (Complétude de $\mathbb{R}$ via suites de Cauchy)** : Dans $\mathbb{R}$, toute suite de Cauchy converge vers un nombre réel. Ce théorème est équivalent à l'axiome de la borne supérieure : si l'un est supposé, l'autre peut être prouvé. $\mathbb{Q}$ n'est pas complet car une suite de Cauchy de rationnels peut converger vers un irrationnel.

## Exercice 1 : Approximation de $\sqrt{2}$ par la méthode de Hérond'Alexandrie (Newton-Raphson)

La méthode de Hérond'Alexandrie (souvent appelée méthode de Newton-Raphson pour la recherche de racines carrées) est un algorithme itératif pour trouver des approximations de racines carrées. Pour calculer $\sqrt{K}$, la suite est définie par $x_{n+1} = \frac{1}{2} \left( x_n + \frac{K}{x_n} \right)$.

def gcd(a, b):
    a_abs = abs(a)
    b_abs = abs(b)
    while b_abs:
        a_abs, b_abs = b_abs, a_abs % b_abs
    return a_abs

class Fraction:
    def __init__(self, numerateur, denominateur):
        if denominateur == 0:
            raise ValueError("Le dénominateur ne peut pas être zéro.")
        if denominateur < 0:
            numerateur = -numerateur
            denominateur = -denominateur
        common_divisor = gcd(numerateur, denominateur)
        self.numerateur = numerateur // common_divisor
        self.denominateur = denominateur // common_divisor

    def __str__(self):
        if self.denominateur == 1:
            return str(self.numerateur)
        return f"{self.numerateur}/{self.denominateur}"

    def __repr__(self):
        return f"Fraction({self.numerateur}, {self.denominateur})"

    def __eq__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return self.numerateur == other.numerateur and self.denominateur == other.denominateur

    def __lt__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return self.numerateur * other.denominateur < other.numerateur * self.denominateur

    def __le__(self, other):
        return self < other or self == other

    def __gt__(self, other):
        return not (self <= other)

    def __ge__(self, other):
        return not (self < other)

    def __add__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur * other.denominateur + other.numerateur * self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __radd__(self, other):
        return self.__add__(other)

    def __sub__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur * other.denominateur - other.numerateur * self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rsub__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return Fraction(other, 1) - self

    def __mul__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur * other.numerateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rmul__(self, other):
        return self.__mul__(other)

    def __truediv__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        if other.numerateur == 0:
            raise ZeroDivisionError("Division par zéro.")
        return self * Fraction(other.denominateur, other.numerateur)

    def __rtruediv__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return Fraction(other, 1) / self

    def __neg__(self):
        return Fraction(-self.numerateur, self.denominateur)

    def __abs__(self):
        return Fraction(abs(self.numerateur), self.denominateur)

# La fonction `float()` est utilisée ici uniquement pour l'affichage lisible des approximations
# et non pour le calcul interne des fractions, qui reste purement rationnel.
def heron_sqrt(K, initial_guess, num_iterations):
    """
    Génère une suite d'approximations de sqrt(K) en utilisant la méthode de Hérond'Alexandrie.
    Tous les calculs sont effectués avec des objets Fraction.

    Arguments:
        K (Fraction): Le nombre dont on veut la racine carrée.
        initial_guess (Fraction): La première approximation (x_0).
        num_iterations (int): Le nombre d'itérations à effectuer.

    Retourne:
        list[Fraction]: Une liste des num_iterations + 1 approximations (incluant x_0).
    """
    if not isinstance(K, Fraction) or not isinstance(initial_guess, Fraction):
        raise TypeError("K et initial_guess doivent être des objets Fraction.")
    if K <= Fraction(0, 1):
        raise ValueError("K doit être strictement positif pour une racine carrée réelle.")
    if initial_guess <= Fraction(0, 1):
        raise ValueError("L'approximation initiale doit être strictement positive.")
    if num_iterations < 0:
        raise ValueError("Le nombre d'itérations ne peut pas être négatif.")

    approximations = [initial_guess]
    x_n = initial_guess

    for _ in range(num_iterations):
        # x_{n+1} = (x_n + K/x_n) / 2
        term_K_div_x_n = K / x_n
        sum_terms = x_n + term_K_div_x_n
        x_n_plus_1 = sum_terms / Fraction(2, 1)
        approximations.append(x_n_plus_1)
        x_n = x_n_plus_1
    return approximations

print("\n--- Analyse de la Convergence de la suite pour sqrt(2) ---")
K_val = Fraction(2, 1)
initial = Fraction(1, 1)
iterations = 10
seq_sqrt2_long = heron_sqrt(K_val, initial, iterations)

for i, approx_f in enumerate(seq_sqrt2_long):
    float_approx = approx_f.numerateur / approx_f.denominateur
    # Calcul de l'erreur quadratique: (x_n)^2 - K
    error_sq = (approx_f * approx_f) - K_val
    print(f"x_{i} = {approx_f} (float: {float_approx:.15f})")
    print(f"  (x_{i})^2 - 2 = {error_sq} (float: {error_sq.numerateur / error_sq.denominateur:.15f})")

# Vérification que la suite est une suite de Cauchy (qualitatif)
# Les termes devraient se rapprocher les uns des autres.
print("\n--- Écart entre termes consécutifs ---")
for i in range(len(seq_sqrt2_long) - 1):
    diff = abs(seq_sqrt2_long[i+1] - seq_sqrt2_long[i])
    float_diff = diff.numerateur / diff.denominateur
    print(f"|x_{i+1} - x_{i}| = {diff} (float: {float_diff:.15f})")
    # Assertons que les différences diminuent (ce n'est pas toujours vrai pour les premières itérations,
    # mais devient rapidement vrai quand on s'approche de la convergence)
    if i > 0: # À partir de la 2ème itération
        prev_diff = abs(seq_sqrt2_long[i] - seq_sqrt2_long[i-1])
        assert float_diff < prev_diff.numerateur / prev_diff.denominateur, \
            f"La différence ne diminue pas à l'itération {i} : {float_diff} vs {prev_diff.numerateur / prev_diff.denominateur}"
print("Les écarts entre termes consécutifs diminuent, illustrant la propriété de Cauchy de la suite.")

### Assertion Mathématique : Une suite de Cauchy de rationnels converge vers un irrationnel (dans $\mathbb{R}$)

1.  **Nature de la suite de Hérond'Alexandrie** : La suite $(x_n)$ générée par la méthode de Hérond'Alexandrie pour $K > 0$ est une suite de nombres rationnels si $x_0$ est rationnel. En effet, si $x_n \in \mathbb{Q}$ et $K \in \mathbb{Q}$, alors $K/x_n \in \mathbb{Q}$, donc $x_n + K/x_n \in \mathbb{Q}$, et enfin $(x_n + K/x_n)/2 \in \mathbb{Q}$. Ainsi, tous les termes $x_n$ de la suite sont des nombres rationnels.

2.  **Convergence de la suite** : Il est bien connu que la suite $(x_n)$ converge vers $\sqrt{K}$. Pour $K=2$, elle converge vers $\sqrt{2}$. La convergence est quadratique, ce qui signifie que le nombre de chiffres décimaux corrects double approximativement à chaque itération. C'est pourquoi les écarts entre termes consécutifs diminuent très rapidement, comme observé dans les impressions. Cela démontre que la suite $(x_n)$ est une **suite de Cauchy** : ses termes se resserrent indéfiniment.

3.  **$\sqrt{2}$ est irrationnel** : Comme discuté dans le TP-02, $\sqrt{2}$ n'appartient pas à $\mathbb{Q}$. La démonstration classique par l'absurde suppose $\sqrt{2} = p/q$ sous forme irréductible, puis montre que $p$ et $q$ doivent tous deux être pairs, contredisant l'irréductibilité.

4.  **Incomplétude de $\mathbb{Q}$** : Nous avons donc une suite de nombres rationnels $(x_n)$ qui est une suite de Cauchy mais qui converge vers un nombre irrationnel ($\sqrt{2}$). Ceci est la preuve formelle de l'**incomplétude de $\mathbb{Q}$**. Si $\mathbb{Q}$ était complet, toute suite de Cauchy de rationnels devrait converger vers un rationnel. Puisqu'elle converge vers un irrationnel, $\mathbb{Q}$ n'est pas complet.

5.  **Axiome de la Borne Supérieure et $\mathbb{R}$** : C'est précisément pour combler cette incomplétude que l'ensemble des nombres réels $\mathbb{R}$ est construit. Dans $\mathbb{R}$, l'axiome de la borne supérieure (ou de manière équivalente, le fait que toute suite de Cauchy de réels converge vers un réel) garantit que de telles suites convergent vers un élément *dans* l'ensemble $\mathbb{R}$, qu'il soit rationnel ou irrationnel.
