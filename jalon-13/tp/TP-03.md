# TP-03 : La Propriété d'Archimède

## Introduction

La propriété d'Archimède est un axiome fondamental qui caractérise les nombres réels et rationnels comme des corps ordonnés "archimédiens". Elle exprime intuitivement qu'il n'existe pas de nombres "infiniment grands" ou "infiniment petits" au sens où tout nombre, aussi grand soit-il, peut être dépassé par la somme répétée d'un autre nombre positif, aussi petit soit-il. Cette propriété est cruciale pour l'analyse, notamment pour la notion de convergence et la densité des rationnels dans les réels.

## Prérequis Mathématiques

**Définition 1 (Nombres Réels - Représentation pratique)** : Pour ce TP, nous utiliserons les nombres à virgule flottante (`float`) de Python pour représenter les nombres réels. Il est essentiel de noter que les `float` sont une approximation finie des nombres réels, avec des limitations de précision. Néanmoins, pour des illustrations pratiques de la propriété d'Archimède, ils sont suffisants.

**Propriété d'Archimède (pour $\mathbb{R}$)** : Pour tous nombres réels $x$ et $y$ tels que $x > 0$, il existe un entier naturel $n$ ($n \in \mathbb{N}$) tel que $n \cdot x > y$.

**Conséquences directes de la Propriété d'Archimède** :
1.  **Les entiers naturels sont non bornés supérieurement dans $\mathbb{R}$** : Si on prend $x=1$ et $y$ un réel arbitraire, il existe $n \in \mathbb{N}$ tel que $n \cdot 1 > y$. Cela signifie que pour tout réel $y$, il existe un entier naturel plus grand que $y$.
2.  **Pour tout $\epsilon > 0$, il existe un entier $n$ tel que $1/n < \epsilon$** : Si on prend $y=1$ et $x=\epsilon$ dans la propriété d'Archimède, il existe $n \in \mathbb{N}$ tel que $n \cdot \epsilon > 1$. En divisant par $n \cdot \epsilon$ (qui est positif), on obtient $1/n < \epsilon$. Cela signifie que des intervalles arbitrairement petits autour de 0 peuvent être construits en utilisant des inverses d'entiers naturels.
3.  **Pour tout $x \in \mathbb{R}$, il existe un entier $n$ tel que $n \leq x < n+1$** (partie entière).

## Exercice 1 : Vérification de la Propriété d'Archimède

### Tâche 1.1 : Fonction `verifier_archimede`

Implémentez la fonction `verifier_archimede(x, y)` qui prend deux nombres réels $x$ (strictement positif) et $y$ (arbitraire) et retourne le plus petit entier naturel $n$ tel que $n \cdot x > y$. Si $x \leq 0$, la fonction doit lever une `ValueError`.

```python
def verifier_archimede(x, y):
    """
    Vérifie la propriété d'Archimède pour x et y.
    Trouve le plus petit entier naturel n tel que n * x > y.

    Arguments:
        x (float): Un nombre réel strictement positif.
        y (float): Un nombre réel.

    Retourne:
        int: Le plus petit entier naturel n satisfaisant n * x > y.

    Lève:
        ValueError: Si x n'est pas strictement positif.
    """
    if not isinstance(x, (float, int)) or not isinstance(y, (float, int)):
        raise TypeError("x et y doivent être des nombres (float ou int).")
    if x <= 0:
        raise ValueError("Le nombre x doit être strictement positif.")

    n = 0
    # On commence la recherche à 0. n*x > y
    # Si y est négatif, n=0 ou n=1 sera souvent suffisant (0*x=0 ou 1*x=x).
    # n doit être un entier naturel, donc n >= 0.

    # Stratégie : Démarrer n=1 si y >= 0.
    # Si y < 0, n=0 peut suffire si 0 > y.
    # Si x > y, n=1 suffit.

    # Une approche simple et robuste est d'incrémenter n à partir de 0 jusqu'à ce que la condition soit remplie.
    # Puisque nous cherchons le PLUS PETIT entier n, commencer à 0 et incrémenter est correct.
    while n * x <= y:
        n += 1
    return n

# Assertions Mathématiques pour verifier_archimede
# Cas 1: x > 0, y > 0
# x=0.5, y=3.0. On cherche n tel que n * 0.5 > 3.0 => n > 6. Le plus petit n est 7.
assert verifier_archimede(0.5, 3.0) == 7, "Assertion échouée : verifier_archimede(0.5, 3.0)"
# x=10, y=3.0. On cherche n tel que n * 10 > 3.0 => n > 0.3. Le plus petit n est 1.
assert verifier_archimede(10.0, 3.0) == 1, "Assertion échouée : verifier_archimede(10.0, 3.0)"
# Cas 2: x > 0, y <= 0
# x=5.0, y=-2.0. On cherche n tel que n * 5.0 > -2.0. Pour n=0, 0 > -2.0. Le plus petit n est 0.
assert verifier_archimede(5.0, -2.0) == 0, "Assertion échouée : verifier_archimede(5.0, -2.0)"
# Cas 3: x > 0, y = 0
# x=3.0, y=0.0. On cherche n tel que n * 3.0 > 0.0. Pour n=1, 3.0 > 0.0. Le plus petit n est 1.
assert verifier_archimede(3.0, 0.0) == 1, "Assertion échouée : verifier_archimede(3.0, 0.0)"
# Cas 4: x est un entier, y est un entier
assert verifier_archimede(2, 7) == 4, "Assertion échouée : verifier_archimede(2, 7)"
# Cas 5: x et y grands
assert verifier_archimede(1e-6, 1e6) == 1000000000001, "Assertion échouée : verifier_archimede(1e-6, 1e6)"
# Cas d'erreur : x <= 0
try:
    verifier_archimede(-1.0, 5.0)
    assert False, "Assertion échouée : ValueError attendue pour x <= 0"
except ValueError:
    assert True, "ValueError correctement levée pour x <= 0"
try:
    verifier_archimede(0.0, 5.0)
    assert False, "Assertion échouée : ValueError attendue pour x <= 0"
except ValueError:
    assert True, "ValueError correctement levée pour x <= 0"

print("Toutes les assertions pour `verifier_archimede` ont réussi.")
```

### Exemples d'Illustration de la Propriété d'Archimède

```python
print("\n--- Illustrations de la Propriété d'Archimède ---")

# Illustration 1 : Les entiers naturels sont non bornés supérieurement.
# Pour tout y réel, il existe un entier n tel que n > y.
y_val = 1_000_000_000_000.0 # Un très grand nombre
n_archimede = verifier_archimede(1.0, y_val) # Ici x=1
print(f"Pour y = {y_val}, le plus petit entier n tel que n * 1.0 > y est n = {n_archimede}.")
print(f"  Cela illustre que les entiers naturels peuvent dépasser n'importe quel nombre réel y.")
assert n_archimede > y_val, "L'illustration 1 a échoué."

# Illustration 2 : Pour tout epsilon > 0, il existe n tel que 1/n < epsilon.
# Ceci implique que des nombres arbitrairement petits peuvent être formés.
def trouver_n_pour_epsilon(epsilon):
    """
    Trouve le plus petit entier naturel n tel que 1/n < epsilon.
    Ceci est équivalent à n > 1/epsilon.
    """
    if not isinstance(epsilon, (float, int)):
        raise TypeError("epsilon doit être un nombre.")
    if epsilon <= 0:
        raise ValueError("epsilon doit être strictement positif.")

    # Utiliser la propriété d'Archimède : n * epsilon > 1
    # Donc n > 1 / epsilon
    # Le plus petit entier n est floor(1/epsilon) + 1 si 1/epsilon n'est pas entier
    # ou 1/epsilon + 1 si 1/epsilon est entier
    # La fonction verifier_archimede(x=epsilon, y=1) nous donne directement n tel que n*epsilon > 1.
    return verifier_archimede(epsilon, 1.0)

epsilon_val = 1e-9 # Un très petit nombre positif
n_epsilon = trouver_n_pour_epsilon(epsilon_val)
print(f"\nPour epsilon = {epsilon_val}, le plus petit entier n tel que 1/n < epsilon est n = {n_epsilon}.")
print(f"  Vérification : 1/{n_epsilon} = {1/n_epsilon}, qui est bien < {epsilon_val}.")
assert 1 / n_epsilon < epsilon_val, "L'illustration 2 a échoué."
print(f"  Cela illustre qu'il n'y a pas de 'plus petit réel positif' (infinitésimal non nul).")


# Illustration 3 : Approximation d'un réel par des rationnels
# La propriété d'Archimède est utilisée pour montrer la densité des rationnels dans les réels.
# Pour tout réel x, il existe un entier n tel que n <= x < n+1 (fonction partie entière).
# Cela permet de borner x entre deux entiers consécutifs.
def partie_entiere(x):
    """
    Retourne l'entier n tel que n <= x < n+1.
    """
    if not isinstance(x, (float, int)):
        raise TypeError("x doit être un nombre.")

    # Pour x >= 0, la fonction int(x) fonctionne.
    # Pour x < 0, int(x) tronque vers zéro, ce qui n'est pas la partie entière (floor).
    # Exemple: int(-3.7) = -3, mais floor(-3.7) = -4.
    # Python's math.floor() existe mais nous devons l'implémenter nous-mêmes.
    if x >= 0:
        return int(x)
    else:
        # Pour les négatifs, trouver l'entier n tel que n <= x < n+1
        # Si x = -3.7, n = -4.
        # Si int(x) est -3, et x n'est pas exactement -3.0, alors n doit être int(x) - 1.
        if x == int(x):
            return int(x)
        else:
            return int(x) - 1 # floor pour les négatifs non entiers

x_val = 3.14159
n_partie_entiere = partie_entiere(x_val)
print(f"\nPour x = {x_val}, la partie entière est n = {n_partie_entiere}.")
print(f"  Vérification : {n_partie_entiere} <= {x_val} < {n_partie_entiere + 1}.")
assert n_partie_entiere <= x_val < n_partie_entiere + 1, "L'illustration 3 (positif) a échoué."

x_val_neg = -2.718
n_partie_entiere_neg = partie_entiere(x_val_neg)
print(f"Pour x = {x_val_neg}, la partie entière est n = {n_partie_entiere_neg}.")
print(f"  Vérification : {n_partie_entiere_neg} <= {x_val_neg} < {n_partie_entiere_neg + 1}.")
assert n_partie_entiere_neg <= x_val_neg < n_partie_entiere_neg + 1, "L'illustration 3 (négatif) a échoué."

print(f"  Cela illustre la propriété d'Archimède permettant de borner tout réel entre deux entiers consécutifs,")
print(f"  une étape cruciale pour la construction des rationnels et des réels.")
```

## Assertion Mathématique : La Propriété d'Archimède comme fondement.

La propriété d'Archimède n'est pas dérivable des axiomes d'un corps ordonné seul (un corps ordonné non archimédien, comme les nombres hyperréels, existe). Elle est un axiome supplémentaire nécessaire pour caractériser les réels.

Notre implémentation `verifier_archimede(x, y)` démontre empiriquement l'existence de l'entier $n$. Pour un $x > 0$ et un $y$ donnés :
1.  Si $y \leq 0$, alors pour $n=0$, $0 \cdot x = 0$. Si $0 > y$, alors $n=0$ est le plus petit entier. Si $y=0$, $0 \cdot x \not> 0$, donc $n=1$ est nécessaire (si $x>0$, $1 \cdot x > 0$). Notre boucle `while n * x <= y` capture ceci correctement.
2.  Si $y > 0$, l'existence de $n$ tel que $n \cdot x > y$ est une conséquence directe de la propriété. Le fait que `n` puisse être trouvé par incrémentation successive (même si inefficace pour de très grands nombres, c'est conceptuellement juste) confirme cette existence. La boucle terminera toujours, car si elle ne terminait pas, cela signifierait que pour tout $n$, $n \cdot x \leq y$, ce qui voudrait dire que l'ensemble $\{n \cdot x \mid n \in \mathbb{N}^*\}$ est borné supérieurement par $y$. Puisque $x > 0$, cela impliquerait que l'ensemble des entiers naturels $\mathbb{N}^*$ est borné supérieurement par $y/x$, ce qui contredit la première conséquence de la propriété d'Archimède elle-même (Les entiers naturels sont non bornés supérieurement dans $\mathbb{R}$).

Ces démonstrations par l'exemple confirment le rôle essentiel de la propriété d'Archimède : elle assure que la droite numérique n'a pas de "trous" dus à des nombres infiniment grands ou petits, et elle prépare le terrain pour la densité des rationnels dans les réels.
