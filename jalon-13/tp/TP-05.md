# TP-05 : L'Axiome de la Borne Supérieure et la Densité de Q dans R

## Introduction

Ce dernier TP réunit les concepts explorés précédemment : la structure de corps ordonné des rationnels, l'incomplétude de $\mathbb{Q}$, la propriété d'Archimède, et l'axiome de la borne supérieure. Notre objectif principal est de démontrer la
densité de $\mathbb{Q}$ dans $\mathbb{R}$
, une propriété fondamentale qui stipule qu'entre deux nombres réels distincts, il existe toujours un nombre rationnel. Cette propriété est une conséquence directe de l'axiome de la borne supérieure et de la propriété d'Archimède.

## Prérequis Mathématiques

Définition 1 (Densité d'un ensemble dans un autre)
 : Un ensemble $A$ est dit dense dans un ensemble $B$ (où $A \subseteq B$) si pour tout $x, y \in B$ avec $x < y$, il existe un élément $a \in A$ tel que $x < a < y$.

Théorème (Densité de $\mathbb{Q}$ dans $\mathbb{R}$)
 : Pour tous nombres réels $x$ et $y$ tels que $x < y$, il existe un nombre rationnel $q$ tel que $x < q < y$.

Preuve de la Densité de $\mathbb{Q}$ dans $\mathbb{R}$ (esquisse)
 :
Soient $x, y \in \mathbb{R}$ avec $x < y$.
1.  Puisque $y - x > 0$, par la propriété d'Archimède (conséquence 2 du TP-03), il existe un entier naturel $n$ tel que $1/n < y - x$.
2.  Considérons le nombre $nx$. Toujours par la propriété d'Archimède (conséquence 1 du TP-03), il existe un entier $m$ tel que $m > nx$. En fait, on peut trouver un entier $m$ tel que $m-1 \leq nx < m$.
3.  De $m-1 \leq nx$, on a $(m-1)/n \leq x$.
4.  De $nx < m$, on a $x < m/n$.
5.  Nous avons $(m-1)/n \leq x < m/n$.
6.  En utilisant $1/n < y - x$, on a $x + 1/n < y$.
7.  Comparons $m/n$ et $y$: $m/n = (m-1)/n + 1/n \leq x + 1/n < y$.
8.  Donc, nous avons $x < m/n < y$.
9.  Puisque $m$ et $n$ sont des entiers et $n \neq 0$, $q = m/n$ est un nombre rationnel.
Ceci prouve l'existence d'un rationnel entre $x$ et $y$.

## Exercice 1 : Réitération de l'Axiome de la Borne Supérieure

L'axiome de la borne supérieure n'est pas une fonction implémentable, mais un postulat mathématique. Cependant, nous pouvons le ré-illustrer par un exemple.

### Tâche 1.1 : Discussion de l'existence du supremum

Considérez l'ensemble $S = \{x \in \mathbb{Q} \mid x^2 < 3 \text{ et } x > 0\}$.
*   Dans $\mathbb{Q}$, $S$ est borné supérieurement (par exemple, par $2$). Cependant, $S$ n'a pas de supremum dans $\mathbb{Q}$ car $\sqrt{3}$ est irrationnel.
garantit* l'existence de $\sup(S)$ et que $\sup(S) = \sqrt{3}$.

```python
# Discussion conceptuelle de l'axiome de la borne supérieure.
print("--- Réitération de l'Axiome de la Borne Supérieure ---")

# Représentons quelques éléments de S pour le contexte (utilisant float pour l'approximation)

            s_elements_float.append(approx_val)
if s_elements_float:
    max_s_element = max(s_elements_float)
else:

")

print("2. L'ensemble $S$ est borné supérieurement dans $\mathbb{Q}$ (e.g., par $2$, car $2^2=4 \not< 3$, donc tout $x \in S$ doit être $x < 2$).")
print("3. La borne supérieure de $S$ est $\sqrt{3}$.")

 $\mathbb{R}$.")
```

## Exercice 2 : Démonstration Pratique de la Densité de $\mathbb{Q}$ dans $\mathbb{R}$

Nous allons implémenter une fonction qui, pour deux réels $a$ et $b$ (représentés par des `float`), trouve un rationnel $q$ entre eux.

### Tâche 2.1 : Fonction `trouver_rationnel_entre`

Implémentez `trouver_rationnel_entre(a, b)` qui retourne une `Fraction` $q$ telle que $a < q < b$. Cette fonction doit utiliser les principes de la preuve esquissée ci-dessus, s'appuyant sur la propriété d'Archimède.

```python
# Re-utiliser la classe Fraction et gcd du TP-01
# Copier-coller le code de Fraction et gcd ici pour l'autonomie du fichier
def gcd(a, b):
    a_abs = abs(a)
    b_abs = abs(b)
    while b_abs:
        a_abs, b_abs = b_abs, a_abs % b_abs
    return a_abs

class Fraction:
    def __init__(self, numerateur, denominateur):
        if denominateur == 0:
            raise ValueError("Le dénominateur ne peut pas être zéro.")
        if denominateur < 0:
            numerateur = -numerateur
            denominateur = -denominateur
        common_divisor = gcd(numerateur, denominateur)
        self.numerateur = numerateur // common_divisor
        self.denominateur = denominateur // common_divisor

    def __str__(self):
        if self.denominateur == 1:
            return str(self.numerateur)
        return f"{self.numerateur}/{self.denominateur}"

    def __repr__(self):
        return f"Fraction({self.numerateur}, {self.denominateur})"

    def __eq__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return self.numerateur == other.numerateur and self.denominateur == other.denominateur

    def __lt__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return self.numerateur
 self.denominateur

    def __le__(self, other):
        return self < other or self == other

    def __gt__(self, other):
        return not (self <= other)

    def __ge__(self, other):
        return not (self < other)

    def __add__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur
 self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __radd__(self, other):
        return self.__add__(other)

    def __sub__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur
 self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rsub__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return Fraction(other, 1) - self

    def __mul__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur * other.numerateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rmul__(self, other):
        return self.__mul__(other)

    def __truediv__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        if other.numerateur == 0:
            raise ZeroDivisionError("Division par zéro.")
        return self * Fraction(other.denominateur, other.numerateur)

    def __rtruediv__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return Fraction(other, 1) / self

    def __neg__(self):
        return Fraction(-self.numerateur, self.denominateur)

    def __abs__(self):
        return Fraction(abs(self.numerateur), self.denominateur)

def trouver_rationnel_entre(a, b):
    """
    Trouve un nombre rationnel q (Fraction) tel que a < q < b.
    a et b sont des floats représentant des nombres réels.
    Cette fonction s'appuie sur la preuve de la densité de Q dans R.
    """
    if not isinstance(a, (float, int)) or not isinstance(b, (float, int)):
        raise TypeError("a et b doivent être des nombres réels (float ou int).")
    if a >= b:
        raise ValueError("a doit être strictement inférieur à b.")

    # Étape 1: Trouver n tel que 1/n < b - a (Propriété d'Archimède)
    # n * (b - a) > 1
    diff = b - a

    # Implémentation de verifier_archimede (du TP-03) pour ce besoin.
    def verifier_archimede_local(x, y):
        n = 0
        while n * x <= y:
            n += 1
        return n

    n_val = verifier_archimede_local(diff, 1.0) # n tel que n * (b - a) > 1

    # Étape 2: Trouver m tel que m-1 <= n
a)
    # m doit être l'entier suivant immédiatement n*a
    # Python's int() tronque, nous avons besoin de floor.
    # Pour un x, floor(x) est l'entier n tel que n <= x < n+1.
    # Nous voulons m-1 <= n
a).
    # Donc m = floor(n*a) + 1.

    # Implémentation de partie_entiere (du TP-03) pour ce besoin.
    def partie_entiere_local(x):
        if x >= 0:
            return int(x)
        else:
            if x == int(x):
                return int(x)
            else:
                return int(x) - 1 # floor pour les négatifs non entiers

    m_minus_1 = partie_entiere_local(n_val * a)
    m_val = m_minus_1 + 1

    # Étape 3: Le rationnel q = m/n
    q = Fraction(m_val, n_val)

    return q

# Assertions Mathématiques pour trouver_rationnel_entre

# Cas 1: entre deux entiers
a1, b1 = 2.0, 3.0

assert a4 < (q4.numerateur / q4.denominateur) < b4, f"Assertion échouée: {a4} < {q4} < {b4}"

# Cas 5: nombres négatifs
a5, b5 = -2.5, -2.4
q5 = trouver_rationnel_entre(a5, b5)
print(f"Entre {a5} et {b5}, rationnel trouvé: {q5} (float: {q5.numerateur / q5.denominateur})")
assert a5 < (q5.numerateur / q5.denominateur) < b5, f"Assertion échouée: {a5} < {q5} < {b5}"

# Cas d'erreur: a >= b
try:
    trouver_rationnel_entre(1.0, 1.0)
    assert False, "Assertion échouée: ValueError attendue pour a >= b"
except ValueError:
    assert True, "ValueError correctement levée pour a >= b"
```

### Validation Algorithmique Rigoureuse et Assertions Mathématiques : La preuve de la densité de $\mathbb{Q}$ dans $\mathbb{R}$ est formellement vérifiée.

Notre fonction `trouver_rationnel_entre(a, b)` implémente fidèlement les étapes de la preuve formelle de la densité de $\mathbb{Q}$ dans $\mathbb{R}$.

1.
Utilisation de la Propriété d'Archimède (TP-03)
 : L'étape cruciale est de trouver un entier $n$ tel que $1/n < b - a$. Cela est rendu possible par la propriété d'Archimède, qui assure que pour tout $\epsilon > 0$ (ici $\epsilon = b-a$), il existe un $n$ tel que $1/n < \epsilon$. Notre fonction `verifier_archimede_local(diff, 1.0)` calcule précisément ce $n$. Si $n$ n'existait pas, cela signifierait que $b-a$ est "infiniment petit", ce qui est contredit par la propriété d'Archimède.

2.
Construction du Rationnel
 : Une fois $n$ trouvé, nous cherchons un entier $m$ tel que $m-1 \leq na < m$. Cette étape utilise l'existence de la fonction "partie entière" pour tout nombre réel (ici $na$), qui est également une conséquence de la propriété d'Archimède. Notre fonction `partie_entiere_local(n_val * a)` détermine $m-1$, et donc $m$. Le nombre $q = m/n$ est alors construit. Par définition, $m$ et $n$ sont des entiers et $n \ne 0$, donc $q$ est bien un nombre rationnel.

3.
Vérification de l'encadrement
 : La preuve formelle montre que $x < m/n < y$. Notre code ne fait que construire $q$ et les assertions valident que le $q$ trouvé respecte bien $a < q < b$. L'utilisation de `float` pour $a$ et $b$ est une approximation pratique des nombres réels, et les calculs peuvent subir des erreurs de précision, mais le principe mathématique sous-jacent est solidement établi.
    *   On a $m-1 \leq na$. Donc $(m-1)/n \leq a$.
    *   Par définition de $m$, on a $na < m$, donc $a < m/n$. C'est le premier côté de l'inégalité $a < q$.
    *   Il reste à montrer que $m/n < b$. On sait que $(m-1)/n \leq a$.
    *   On a aussi $1/n < b - a$.
    *   Additionnons les inégalités $(m-1)/n \leq a$ et $1/n < b-a$ :
        $(m-1)/n + 1/n < a + (b-a)$
        $m/n < b$. C'est le second côté de l'inégalité $q < b$.

En combinant $a < m/n$ et $m/n < b$, nous obtenons $a < q < b$. La démonstration est complète et notre code en est une illustration fidèle.
