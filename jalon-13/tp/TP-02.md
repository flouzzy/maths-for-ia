# TP-02 : Bornes et Incomplétude des Nombres Rationnels

## Introduction

Après avoir établi que les nombres rationnels ($\mathbb{Q}$) forment un corps ordonné dans le TP-01, ce TP-02 se concentre sur les notions de bornes et, plus crucialement, sur l'incomplétude de $\mathbb{Q}$. L'incomplétude est la raison fondamentale pour laquelle les nombres réels ($\mathbb{R}$) ont été introduits. Nous démontrerons que certains ensembles de nombres rationnels, bien que bornés supérieurement, n'admettent pas de borne supérieure (supremum) qui soit elle-même un nombre rationnel.

## Prérequis Mathématiques

**Définition 1 (Ensemble borné supérieurement)** : Un ensemble $S$ de nombres est dit borné supérieurement s'il existe un nombre $M$ tel que pour tout $x \in S$, $x \leq M$. Un tel $M$ est appelé une **borne supérieure** de $S$.

**Définition 2 (Supremum / Borne supérieure)** : Le **supremum** (ou la **borne supérieure**) d'un ensemble $S$, noté $\sup(S)$, est la plus petite de toutes les bornes supérieures de $S$. Si $\sup(S)$ existe, il doit satisfaire deux conditions :
1.  $\sup(S)$ est une borne supérieure de $S$ (pour tout $x \in S$, $x \leq \sup(S)$).
2.  Pour toute borne supérieure $M'$ de $S$, $\sup(S) \leq M'$. (Ou de manière équivalente : pour tout $\epsilon > 0$, il existe $x \in S$ tel que $\sup(S) - \epsilon < x$).

**Définition 3 (Ensemble borné inférieurement)** : Un ensemble $S$ de nombres est dit borné inférieurement s'il existe un nombre $m$ tel que pour tout $x \in S$, $x \geq m$. Un tel $m$ est appelé une **borne inférieure** de $S$.

**Définition 4 (Infimum / Borne inférieure)** : L'**infimum** (ou la **borne inférieure**) d'un ensemble $S$, noté $\inf(S)$, est la plus grande de toutes les bornes inférieures de $S$.

**Axiome de la Borne Supérieure (ou Axiome de Complétude de $\mathbb{R}$)** : Tout ensemble non vide de nombres réels qui est borné supérieurement admet une borne supérieure dans $\mathbb{R}$. Cet axiome est ce qui distingue $\mathbb{R}$ de $\mathbb{Q}$.

def gcd(a, b):
    a_abs = abs(a)
    b_abs = abs(b)
    while b_abs:
        a_abs, b_abs = b_abs, a_abs % b_abs
    return a_abs

class Fraction:
    def __init__(self, numerateur, denominateur):
        if denominateur == 0:
            raise ValueError("Le dénominateur ne peut pas être zéro.")
        if denominateur < 0:
            numerateur = -numerateur
            denominateur = -denominateur
        common_divisor = gcd(numerateur, denominateur)
        self.numerateur = numerateur // common_divisor
        self.denominateur = denominateur // common_divisor

    def __str__(self):
        if self.denominateur == 1:
            return str(self.numerateur)
        return f"{self.numerateur}/{self.denominateur}"

    def __repr__(self):
        return f"Fraction({self.numerateur}, {self.denominateur})"

    def __eq__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return self.numerateur == other.numerateur and self.denominateur == other.denominateur

    def __lt__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return self.numerateur * other.denominateur < other.numerateur * self.denominateur

    def __le__(self, other):
        return self < other or self == other

    def __gt__(self, other):
        return not (self <= other)

    def __ge__(self, other):
        return not (self < other)

    def __add__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur * other.denominateur + other.numerateur * self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __radd__(self, other):
        return self.__add__(other)

    def __sub__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur * other.denominateur - other.numerateur * self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rsub__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return Fraction(other, 1) - self

    def __mul__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        new_numerateur = self.numerateur * other.numerateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rmul__(self, other):
        return self.__mul__(other)

    def __truediv__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        if other.numerateur == 0:
            raise ZeroDivisionError("Division par zéro.")
        return self * Fraction(other.denominateur, other.numerateur)

    def __rtruediv__(self, other):
        if not isinstance(other, Fraction):
            if isinstance(other, int): other = Fraction(other, 1)
            else: return NotImplemented
        return Fraction(other, 1) / self

    def __neg__(self):
        return Fraction(-self.numerateur, self.denominateur)

    def __abs__(self):
        return Fraction(abs(self.numerateur), self.denominateur)

def est_borne_superieurement(S):
    """
    Vérifie si un ensemble S de Fractions est borné supérieurement.
    Un ensemble est borné supérieurement s'il est vide ou si un majorant existe.
    """
    if not S:
        return True # Conventionnellement, l'ensemble vide est borné
    # Si S est non vide et contient au moins un élément, il faut vérifier l'existence d'un majorant.
    # Pour un ensemble fini, le maximum est une borne supérieure.
    # Pour un ensemble infini, nous ne pouvons pas le déterminer sans information supplémentaire sur sa construction.
    # Pour les besoins de ce TP, nous allons considérer des ensembles finis ou des ensembles définis par des propriétés
    # pour lesquels un majorant est conceptuellement clair.
    # Dans le cadre de ce TP, nous considérerons S comme une liste Python, donc finie.
    return True # Tout ensemble fini de nombres est borné.

def trouver_une_borne_superieure(S):
    """
    Trouve une borne supérieure pour un ensemble S de Fractions.
    Pour un ensemble fini, c'est simplement le maximum.
    """
    if not S:
        raise ValueError("L'ensemble vide n'a pas de borne supérieure concrète (la notion est triviale).")

    max_val = S[0]
    for x in S:
        if x > max_val:
            max_val = x
    return max_val

def trouver_supremum_dans_Q(S, tolerance_n=1, tolerance_d=1000):
    """
    Tente de trouver le supremum d'un ensemble S de Fractions dans Q.
    Cette fonction est une heuristique pour des ensembles "simples".
    Pour un ensemble S, si son supremum est dans Q, il doit être le maximum si S contient son supremum.
    Sinon, on doit chercher la plus petite borne supérieure.
    Ici, nous allons chercher une borne supérieure rationnelle potentielle
    qui soit "proche" de la borne que nous conjecturons.
    Pour les ensembles de type {x in Q | x < M}, le supremum est M si M est dans Q.
    Pour les ensembles de type {x in Q | x <= M}, le supremum est M si M est dans Q.
    Nous allons simplifier et chercher le maximum pour des ensembles finis.
    Pour des ensembles infinis définis par une règle, c'est plus complexe.

    Nous allons implémenter une recherche pour un ensemble $S = \{x \in \mathbb{Q} \mid x^2 < k\}$
    où $k$ est un rationnel. On cherche $\sqrt{k}$.

    `tolerance_n` et `tolerance_d` définissent une "précision" pour la recherche,
    signifiant que l'on cherche un rationnel $p/q$ tel que $p^2/q^2$ est très proche de $k$.
    """
    if not S:
        return None

    # Si S est simplement une liste finie, le supremum est le maximum
    if all(isinstance(x, Fraction) for x in S):
        return trouver_une_borne_superieure(S)

    # Cas spécifique pour S = {x in Q | x^2 < K} pour K rationnel
    # Cette partie est une tentative d'implémentation pour l'incomplétude.
    # Elle ne peut pas "prouver" un supremum non-Q, mais peut montrer l'échec de trouver un Q-supremum.
    # Ici, nous allons *supposer* que S est de la forme S = {x in Q | x^2 < K}, où K est un nombre rationnel.
    # On cherche le supremum de S, qui est sqrt(K).
    # Si sqrt(K) n'est pas rationnel, cette fonction ne trouvera pas de supremum DANS Q.
    # On va rechercher un candidat p/q tel que (p/q)^2 soit très proche de K.
    # Nous allons prendre le max des éléments de S comme point de départ

    # Pour simuler la recherche d'un supremum pour un ensemble infini {x in Q | P(x)},
    # nous devons nous restreindre à des cas où P(x) est testable.
    # La manière la plus simple d'illustrer l'incomplétude est de prendre un ensemble
    # dont le supremum est clairement irrationnel.
    # Par exemple, S = {x in Q | x^2 < 2}. Le supremum est sqrt(2).
    # Dans ce cas, on peut chercher des rationnels p/q tels que (p/q)^2 se rapproche de 2.
    # La fonction doit retourner le "candidat" supremum si (candidat^2 == K).

    # Pour ce TP, nous allons utiliser une approche plus simple :
    # Si le supremum est dans S, c'est le max. Sinon, il n'est pas "trivialement" trouvable.
    # Une implémentation robuste de `trouver_supremum_dans_Q` nécessiterait une définition plus précise de S.
    # Nous allons simuler la recherche du supremum pour un ensemble fini, qui sera son maximum.
    # Si le supremum d'un ensemble infini est demandé, nous allons plutôt *vérifier* si un certain candidat *rationnel* est le supremum.

    # Pour l'exemple {x in Q | x^2 < 2}, on peut itérer pour trouver le plus grand rationnel
    # dont le carré est < 2.
    # Initialisation arbitraire.
    max_in_S = Fraction(0, 1)

    # Si l'ensemble S est fourni comme une liste de Fractions, on prend le maximum.
    if all(isinstance(val, Fraction) for val in S):
        return trouver_une_borne_superieure(S)

    # Autre cas : S défini par une propriété, par exemple {x in Q | x*x < k}.
    # Nous n'avons pas de moyen général de simuler un ensemble infini de Q dans Python.
    # Nous allons simuler un ensemble fini de candidats et chercher le plus grand.
    # Cela *ne prouve pas* que le supremum est en Q, mais illustre une recherche.

    # Pour l'illustration de l'incomplétude avec sqrt(2), nous allons considérer
    # un ensemble S_sqrt2 = {x in Q | x^2 < 2 et x > 0}.
    # Cette fonction ne peut pas "générer" tous les éléments de S_sqrt2.
    # Elle peut en revanche tester si un CANDIDAT rationnel est le supremum.

    # Par convention pour cet exercice, `S` est soit une liste de Fractions, soit un identifiant symbolique.
    # Si c'est une liste, on retourne le max. Si c'est pour l'incomplétude, on retourne None.
    print("ATTENTION: `trouver_supremum_dans_Q` est une heuristique simplifiée pour ce TP.")
    print("Elle ne peut pas prouver l'existence d'un supremum pour des ensembles infinis.")
    return None # Par défaut, si non trivial, on ne trouve pas de supremum dans Q.
