# TP-01 : Construction et Ordre des Nombres Rationnels

## Introduction

Ce premier Travail Pratique a pour objectif de construire une représentation logicielle des nombres rationnels ($\mathbb{Q}$) et d'implémenter leurs opérations arithmétiques ainsi que leur relation d'ordre. Les nombres rationnels constituent un *corps ordonné*, une structure fondamentale en mathématiques, mais ils ne sont pas "complets" au sens de l'axiome de la borne supérieure, une lacune que les nombres réels ($\mathbb{R}$) viennent combler. En travaillant "à la main" sur cette construction, nous apprécierons mieux les propriétés qui distinguent $\mathbb{Q}$ de $\mathbb{R}$.

## Prérequis Mathématiques

**Définition 1 (Nombre Rationnel)** : Un nombre rationnel $q$ est un nombre qui peut s'écrire sous la forme $\frac{a}{b}$, où $a$ est un entier relatif ($a \in \mathbb{Z}$) et $b$ est un entier naturel non nul ($b \in \mathbb{N}^*$). L'ensemble des nombres rationnels est noté $\mathbb{Q}$.

**Définition 2 (Corps Ordonné)** : Un ensemble $K$ muni de deux lois de composition internes $(+, \times)$ et d'une relation d'ordre binaire $\leq$ est un corps ordonné si :
1.  $(K, +, \times)$ est un corps (il satisfait les axiomes de groupe abélien pour l'addition, de groupe abélien pour la multiplication sur $K \setminus \{0\}$, et la distributivité de la multiplication sur l'addition).
2.  La relation $\leq$ est une relation d'ordre total.
3.  La relation d'ordre est compatible avec les opérations :
    *   Si $x, y, z \in K$ et $x \leq y$, alors $x + z \leq y + z$.
    *   Si $x, y, z \in K$ et $x \leq y$ et $z > 0$, alors $x \times z \leq y \times z$.

## Exercice 1 : Implémentation de la Classe `Fraction`

Nous allons implémenter une classe `Fraction` en Python. Chaque fraction sera stockée sous forme réduite, ce qui signifie que le numérateur et le dénominateur seront divisés par leur plus grand commun diviseur (PGCD). Le dénominateur sera toujours positif.

### Tâche 1.1 : Fonction `gcd` (PGCD)

Implémentez la fonction `gcd(a, b)` qui calcule le Plus Grand Commun Diviseur de deux entiers $a$ et $b$ en utilisant l'algorithme d'Euclide. Cette fonction doit gérer correctement les nombres négatifs.

**Algorithme d'Euclide** : Pour trouver le PGCD de deux entiers positifs $a$ et $b$ ($a > b$), on utilise la propriété $\text{pgcd}(a, b) = \text{pgcd}(b, a \pmod b)$. Le processus se répète jusqu'à ce que le reste soit 0. Le PGCD est alors le dernier reste non nul. Pour les entiers négatifs, on prend la valeur absolue.

```python
def gcd(a, b):
    """
    Calcule le Plus Grand Commun Diviseur (PGCD) de deux entiers a et b
    en utilisant l'algorithme d'Euclide.
    Gère les nombres négatifs en prenant leur valeur absolue pour le calcul.
    Le PGCD sera toujours non négatif.
    """
    a_abs = abs(a)
    b_abs = abs(b)
    while b_abs:
        a_abs, b_abs = b_abs, a_abs % b_abs
    return a_abs

# Assertions Mathématiques pour gcd
# PGCD(a, 0) = |a|
assert gcd(5, 0) == 5, "Assertion échouée : gcd(5, 0) doit être 5"
assert gcd(-5, 0) == 5, "Assertion échouée : gcd(-5, 0) doit être 5"
# PGCD(0, 0) = 0 (conventionnellement)
assert gcd(0, 0) == 0, "Assertion échouée : gcd(0, 0) doit être 0"
# PGCD(a, b) = PGCD(b, a)
assert gcd(12, 18) == gcd(18, 12), "Assertion échouée : PGCD doit être commutatif"
# PGCD de nombres positifs
assert gcd(12, 18) == 6, "Assertion échouée : PGCD(12, 18) doit être 6"
assert gcd(17, 5) == 1, "Assertion échouée : PGCD(17, 5) doit être 1 (premiers entre eux)"
# PGCD avec nombres négatifs
assert gcd(-12, 18) == 6, "Assertion échouée : PGCD(-12, 18) doit être 6"
assert gcd(12, -18) == 6, "Assertion échouée : PGCD(12, -18) doit être 6"
assert gcd(-12, -18) == 6, "Assertion échouée : PGCD(-12, -18) doit être 6"
print("Toutes les assertions pour `gcd` ont réussi.")
```

### Tâche 1.2 : Classe `Fraction` et Normalisation

Créez la classe `Fraction`. Le constructeur doit prendre un numérateur et un dénominateur. Il doit :
1.  Vérifier que le dénominateur n'est pas nul.
2.  Normaliser la fraction : réduire numérateur et dénominateur par leur PGCD, et s'assurer que le dénominateur est toujours positif.

```python
class Fraction:
    """
    Représente un nombre rationnel sous forme de fraction irréductible.
    Le dénominateur est toujours positif.
    """
    def __init__(self, numerateur, denominateur):
        if denominateur == 0:
            raise ValueError("Le dénominateur ne peut pas être zéro.")

        # Assurer que le dénominateur est positif en transférant le signe au numérateur si nécessaire
        if denominateur < 0:
            numerateur = -numerateur
            denominateur = -denominateur

        common_divisor = gcd(numerateur, denominateur)
        self.numerateur = numerateur // common_divisor
        self.denominateur = denominateur // common_divisor

    def __str__(self):
        """Représentation string pour l'affichage."""
        if self.denominateur == 1:
            return str(self.numerateur)
        return f"{self.numerateur}/{self.denominateur}"

    def __repr__(self):
        """Représentation canonique pour le débogage."""
        return f"Fraction({self.numerateur}, {self.denominateur})"

    # --- Opérateurs de comparaison (pour l'ordre total) ---
    def __eq__(self, other):
        """Vérifie l'égalité de deux fractions."""
        if not isinstance(other, Fraction):
            # Tente de convertir `other` en Fraction pour la comparaison si c'est un entier
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented # ou False, selon le comportement désiré
        return self.numerateur == other.numerateur and self.denominateur == other.denominateur

    def __lt__(self, other):
        """Vérifie si self est strictement inférieur à other."""
        if not isinstance(other, Fraction):
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented
        # Pour comparer a/b et c/d, on compare ad et bc (avec b, d > 0)
        return self.numerateur * other.denominateur < other.numerateur * self.denominateur

    def __le__(self, other):
        """Vérifie si self est inférieur ou égal à other."""
        return self < other or self == other

    def __gt__(self, other):
        """Vérifie si self est strictement supérieur à other."""
        return not (self <= other)

    def __ge__(self, other):
        """Vérifie si self est supérieur ou égal à other."""
        return not (self < other)

    # --- Opérateurs arithmétiques (pour la structure de corps) ---
    def __add__(self, other):
        """Additionne deux fractions ou une fraction et un entier."""
        if not isinstance(other, Fraction):
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented
        new_numerateur = self.numerateur * other.denominateur + other.numerateur * self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __radd__(self, other):
        """Gère l'addition réflexive (e.g., 5 + Fraction(1,2))."""
        return self.__add__(other)

    def __sub__(self, other):
        """Soustrait deux fractions ou une fraction et un entier."""
        if not isinstance(other, Fraction):
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented
        new_numerateur = self.numerateur * other.denominateur - other.numerateur * self.denominateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rsub__(self, other):
        """Gère la soustraction réflexive (e.g., 5 - Fraction(1,2))."""
        if not isinstance(other, Fraction):
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented
        return Fraction(other, 1) - self # Convertir other en Fraction et soustraire

    def __mul__(self, other):
        """Multiplie deux fractions ou une fraction et un entier."""
        if not isinstance(other, Fraction):
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented
        new_numerateur = self.numerateur * other.numerateur
        new_denominateur = self.denominateur * other.denominateur
        return Fraction(new_numerateur, new_denominateur)

    def __rmul__(self, other):
        """Gère la multiplication réflexive."""
        return self.__mul__(other)

    def __truediv__(self, other):
        """Divise deux fractions ou une fraction et un entier."""
        if not isinstance(other, Fraction):
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented
        if other.numerateur == 0:
            raise ZeroDivisionError("Division par zéro.")
        # La division par c/d est équivalente à la multiplication par d/c
        return self * Fraction(other.denominateur, other.numerateur)

    def __rtruediv__(self, other):
        """Gère la division réflexive (e.g., 5 / Fraction(1,2))."""
        if not isinstance(other, Fraction):
            if isinstance(other, int):
                other = Fraction(other, 1)
            else:
                return NotImplemented
        return Fraction(other, 1) / self

    def __neg__(self):
        """Opposé d'une fraction."""
        return Fraction(-self.numerateur, self.denominateur)

    def __abs__(self):
        """Valeur absolue d'une fraction."""
        return Fraction(abs(self.numerateur), self.denominateur)
```

### Assertion Mathématique : $(\mathbb{Q}, +, \times, \leq)$ est un corps ordonné.

Nous avons implémenté les opérations d'addition, de multiplication, de soustraction, de division, ainsi que les opérateurs de comparaison ($<, \leq, =, \geq, >$) pour notre classe `Fraction`. Les assertions ci-dessus vérifient la correction de ces implémentations individuelles.
Considérons maintenant pourquoi l'ensemble de ces fractions, avec ces opérations et cet ordre, constitue un corps ordonné.

1.  **$(\mathbb{Q}, +, \times)$ est un corps** :
    *   **Addition** :
        *   **Associativité** : $(x+y)+z = x+(y+z)$. (Les entiers sont associatifs, la construction via les dénominateurs communs préserve cette propriété).
        *   **Commutativité** : $x+y = y+x$. (Idem).
        *   **Élément neutre** : La fraction $0/1$ (soit `Fraction(0, 1)`) est l'élément neutre de l'addition, car $x + 0/1 = x$.
        *   **Opposé** : Chaque fraction $a/b$ a un opposé $(-a)/b$ (implémenté par `__neg__`) tel que $a/b + (-a)/b = 0/1$.
    *   **Multiplication** :
        *   **Associativité** : $(x \times y) \times z = x \times (y \times z)$. (Idem).
        *   **Commutativité** : $x \times y = y \times x$. (Idem).
        *   **Élément neutre** : La fraction $1/1$ (soit `Fraction(1, 1)`) est l'élément neutre de la multiplication, car $x \times 1/1 = x$.
        *   **Inverse** : Chaque fraction $a/b \neq 0/1$ a un inverse $b/a$ (utilisé dans `__truediv__`) tel que $a/b \times b/a = 1/1$.
    *   **Distributivité** : $x \times (y+z) = (x \times y) + (x \times z)$. Cette propriété découle directement de la distributivité des entiers et de la définition de nos opérations sur les fractions.

2.  **$\leq$ est un ordre total sur $\mathbb{Q}$** :
    *   **Réflexivité** : $x \leq x$ (implémenté par `__le__` et `__eq__`).
    *   **Antisymétrie** : Si $x \leq y$ et $y \leq x$, alors $x=y$ (implémenté par `__le__` et `__eq__`).
    *   **Transitivité** : Si $x \leq y$ et $y \leq z$, alors $x \leq z$. La comparaison $a/b < c/d \iff ad < bc$ maintient cette propriété due à la transitivité de $<$ sur les entiers.
    *   **Totalité** : Pour tout $x, y \in \mathbb{Q}$, soit $x \leq y$ soit $y \leq x$. Cela est vrai pour notre implémentation car $ad < bc$, $ad = bc$, ou $ad > bc$ sont les seules possibilités pour les entiers $ad$ et $bc$.

3.  **Compatibilité de l'ordre avec les opérations** :
    *   **Addition** : Si $x \leq y$, alors $x+z \leq y+z$.
        Soit $x = a/b$, $y = c/d$, $z = e/f$. Si $ad \leq bc$, nous voulons montrer que $af/bf + be/bf \leq cf/df + de/df$, i.e. $(af+be)/(bf) \leq (cf+de)/(df)$. En multipliant les numérateurs par les dénominateurs respectifs on compare $(af+be)df$ et $(cf+de)bf$. Cela découle des propriétés des entiers et du fait que les dénominateurs sont positifs.
    *   **Multiplication** : Si $x \leq y$ et $z > 0$, alors $x \times z \leq y \times z$.
        Si $a/b \leq c/d$ et $e/f > 0$ (donc $e > 0, f > 0$), nous voulons montrer que $(a/b)(e/f) \leq (c/d)(e/f)$, i.e. $ae/bf \leq ce/df$. Puisque $e, f, b, d$ sont positifs, on compare $aedf$ et $bcef$. Si $ad \leq bc$, alors $ad \cdot ef \leq bc \cdot ef$. Puisque $e, f > 0$, $ef > 0$. Donc $aedf \leq bcef$.

En conclusion, notre implémentation de la classe `Fraction` respecte bien les axiomes d'un corps ordonné, ce qui fait de l'ensemble des instances de `Fraction` (conceptuellement, $\mathbb{Q}$) un corps ordonné.
