## Travail Pratique 2/5 : Démonstration des Théorèmes de Glivenko-Cantelli Généralisés

**Jalon 141 : Théorèmes de Glivenko-Cantelli généralisés pour les classes de fonctions VC**

### Introduction

Le théorème classique de Glivenko-Cantelli stipule que la fonction de répartition empirique converge uniformément vers la vraie fonction de répartition. Les théorèmes de Glivenko-Cantelli généralisés étendent cette idée à des classes de fonctions plus larges que les simples fonctions indicatrices d'intervalles (qui définissent la fonction de répartition). Ils affirment que, sous certaines conditions de "complexité" de la classe de fonctions (notamment d'être une classe VC), la convergence uniforme des moyennes empiriques vers les vraies espérances est garantie.

Plus formellement, pour une classe de fonctions $\mathcal{F}$ et une distribution de probabilité $P$, on s'intéresse à la convergence de $\sup_{f \in \mathcal{F}} |E_n[f] - E[f]| \xrightarrow{p} 0$, où $E_n[f]$ est l'espérance empirique de $f$ basée sur $n$ échantillons i.i.d. de $P$, et $E[f]$ est la vraie espérance de $f$ sous $P$.

Ce TP vise à implémenter et à observer cette convergence en Python pur, en construisant nos outils de base.

### Objectifs du TP

1.  **Implémenter** les calculs d'espérance empirique et de "vraie" espérance (par approximation Monte Carlo).
2.  **Définir** une classe de fonctions simple qui est connue pour être une classe VC.
3.  **Simuler** le processus de convergence de Glivenko-Cantelli généralisé en observant la décroissance du "sup" des différences.
4.  **Valider** les implémentations avec des assertions mathématiques.

### Prérequis

*   Connaissances de base en probabilités et statistiques (espérance, variables aléatoires i.i.d.).
*   Compréhension du concept de convergence uniforme.
*   Notions intuitives sur la complexité des classes de fonctions (sans nécessairement connaître la définition formelle de la dimension VC).

### Partie 1 : Espérance Empirique vs. Vraie Espérance

Avant de nous attaquer à une classe de fonctions, commençons par une seule fonction. Nous allons implémenter des fonctions pour calculer l'espérance empirique à partir d'un échantillon et une approximation de la vraie espérance par Monte Carlo (car le calcul analytique peut être complexe).

#### 1.1. Implémentation

```python
import random
import math

# --- Fonctions utilitaires de base ---

def mean(data):
    """Calcule la moyenne d'une liste de nombres."""
    if not data:
        return 0.0
    return sum(data) / len(data)

# --- Espérance ---

def empirical_expectation(func, data_sample):
    """
    Calcule l'espérance empirique d'une fonction sur un échantillon de données.
    E_n[f] = (1/n) * sum(f(x_i))
    """
    if not data_sample:
        return 0.0
    return mean([func(x) for x in data_sample])

def true_expectation_monte_carlo_proxy(func, distribution_sampler, num_samples_for_proxy):
    """
    Approximation de la vraie espérance E[f(X)] par Monte Carlo.
    Nous utilisons un très grand nombre d'échantillons pour obtenir une valeur de référence.
    """
    samples = [distribution_sampler() for _ in range(num_samples_for_proxy)]
    return empirical_expectation(func, samples)

# --- Distribution de test : Uniforme(0,1) ---

def uniform_0_1_sampler():
    """Génère un échantillon de la distribution Uniforme(0,1)."""
    return random.uniform(0, 1)

# --- Fonction de test : f(x) = x ---

def identity_function(x):
    """La fonction identité f(x) = x."""
    return x

# --- Fonction de test : f(x) = x^2 ---

def square_function(x):
    """La fonction carré f(x) = x^2."""
    return x * x
```

#### 1.2. Validation Mathématique (Assertions)

Nous allons vérifier que l'espérance empirique se rapproche de la vraie espérance pour une fonction simple et une distribution connue.

```python
# --- Validation de la Partie 1 ---
print("--- Validation Partie 1 : Espérance Empirique vs. Vraie Espérance ---")

# Paramètres de validation
num_true_samples = 1_000_000 # Très grand nombre pour la proxy de la vraie espérance
num_empirical_samples = 10_000 # Nombre d'échantillons pour l'espérance empirique
tolerance = 0.01 # Tolérance pour les assertions

# 1. Validation de la fonction mean
assert mean([1, 2, 3]) == 2.0, "mean([1,2,3]) should be 2.0"
assert mean([]) == 0.0, "mean([]) should be 0.0"
print("Assertion 'mean' passée.")

# 2. Vraie espérance de f(x)=x pour X ~ U(0,1) est 0.5
true_exp_identity = true_expectation_monte_carlo_proxy(identity_function, uniform_0_1_sampler, num_true_samples)
print(f"Vraie espérance (proxy) de f(x)=x pour U(0,1): {true_exp_identity:.4f}")
assert abs(true_exp_identity - 0.5) < 0.005, "True expectation of identity function on U(0,1) should be close to 0.5"
print("Assertion 'true_expectation_monte_carlo_proxy' pour f(x)=x passée.")

# 3. Vraie espérance de f(x)=x^2 pour X ~ U(0,1) est 1/3
true_exp_square = true_expectation_monte_carlo_proxy(square_function, uniform_0_1_sampler, num_true_samples)
print(f"Vraie espérance (proxy) de f(x)=x^2 pour U(0,1): {true_exp_square:.4f}")
assert abs(true_exp_square - (1/3)) < 0.005, "True expectation of square function on U(0,1) should be close to 1/3"
print("Assertion 'true_expectation_monte_carlo_proxy' pour f(x)=x^2 passée.")

# 4. Convergence de l'espérance empirique pour f(x)=x
sample_data_identity = [uniform_0_1_sampler() for _ in range(num_empirical_samples)]
emp_exp_identity = empirical_expectation(identity_function, sample_data_identity)
print(f"Espérance empirique de f(x)=x avec {num_empirical_samples} échantillons: {emp_exp_identity:.4f}")
assert abs(emp_exp_identity - true_exp_identity) < tolerance, \
    f"Empirical expectation for identity function should be close to true expectation (diff: {abs(emp_exp_identity - true_exp_identity):.4f})"
print("Assertion 'empirical_expectation' pour f(x)=x passée.")

print("\nToutes les assertions de la Partie 1 ont été passées avec succès.")
```

### Partie 2 : Définition d'une Classe de Fonctions VC

Pour illustrer les théorèmes de Glivenko-Cantelli généralisés, nous avons besoin d'une classe de fonctions $\mathcal{F}$ qui soit une classe VC. Un exemple simple et classique est la classe des fonctions indicatrices d'intervalles de la forme $(-\infty, t]$ sur $\mathbb{R}$. Cette classe a une dimension VC de 1.

Nous allons générer un ensemble discret de telles fonctions pour notre simulation.

#### 2.1. Implémentation

```python
# --- Classe de fonctions VC : Fonctions indicatrices d'intervalles ---

def indicator_function_le(threshold):
    """
    Retourne une fonction indicatrice I(x <= threshold).
    Cette fonction retourne 1 si x <= threshold, 0 sinon.
    """
    def func(x):
        return 1.0 if x <= threshold else 0.0
    return func

def generate_vc_class_functions(min_threshold, max_threshold, num_functions):
    """
    Génère une liste de fonctions indicatrices I(x <= t) pour des seuils t espacés.
    """
    if num_functions <= 0:
        return []

    thresholds = [min_threshold + i * (max_threshold - min_threshold) / (num_functions - 1)
                  for i in range(num_functions)]

    # Assurer que min_threshold et max_threshold sont inclus si num_functions > 1
    if num_functions == 1:
        thresholds = [(min_threshold + max_threshold) / 2] # Un seul seuil au milieu

    return [indicator_function_le(t) for t in thresholds]
```

#### 2.2. Validation Mathématique (Assertions)

Vérifions le comportement de nos fonctions indicatrices.

```python

assert f_indicator_0_5(0.5) == 1.0, "I(x <= 0.5) for x=0.5 should be 1.0"

# Vérifier que les fonctions sont bien des indicatrices

assert vc_class_test[-1](1.1) == 0.0 # Le dernier seuil est 1.0, donc 1.1 > 1.0
print("Assertion 'generate_vc_class_functions' passée.")

print("\nToutes les assertions de la Partie 2 ont été passées avec succès.")
```

### Partie 3 : Simulation de la Convergence de Glivenko-Cantelli Généralisée

Nous allons maintenant combiner les éléments précédents pour simuler la convergence. Pour chaque taille d'échantillon `n`, nous allons :
1.  Générer un échantillon de taille `n`.
2.  Pour chaque fonction `f` de notre classe VC :
    *   Calculer son espérance empirique `E_n[f]`.
    *   Calculer sa vraie espérance `E[f]` (une fois, via proxy Monte Carlo).
    *   Calculer la différence absolue `|E_n[f] - E[f]|`.
3.  Trouver le maximum de ces différences sur toute la classe de fonctions : `sup_{f in F} |E_n[f] - E[f]|`.
4.  Observer comment ce `sup` évolue avec `n`.

#### 3.1. Implémentation

```python
# --- Simulation de Glivenko-Cantelli Généralisé ---

def simulate_generalized_glivenko_cantelli(
    distribution_sampler,
    vc_class_functions,
    sample_sizes,
    num_true_expectation_samples_for_proxy
):
    """
    Simule la convergence de Glivenko-Cantelli généralisée pour une classe de fonctions VC.

    Args:
        distribution_sampler: Une fonction sans argument qui retourne un échantillon de la distribution.
        vc_class_functions: Une liste de fonctions de la classe VC.
        sample_sizes: Une liste de tailles d'échantillon (n) à tester.
        num_true_expectation_samples_for_proxy: Nombre d'échantillons pour calculer la proxy de la vraie espérance.

    Returns:
        Une liste de tuples (n, sup_diff) montrant la convergence.
    """

    print(f"\nCalcul des vraies espérances (proxy) pour {len(vc_class_functions)} fonctions...")
    # Calculer les vraies espérances une seule fois pour toutes les fonctions
    # C'est une optimisation cruciale pour éviter de recalculer la proxy à chaque itération.
    true_expectations = {}
    for i, func in enumerate(vc_class_functions):
        # Pour les fonctions indicatrices I(x <= t) sur U(0,1), E[f] = P(X <= t) = t
        # Nous pouvons utiliser cette propriété pour une vraie espérance analytique si la distribution est U(0,1)
        # Sinon, nous utilisons la proxy Monte Carlo.
        if distribution_sampler == uniform_0_1_sampler and hasattr(func, '__closure__') and func.__closure__ is not None:
            # Tente de récupérer le seuil 't' de la fonction indicatrice
            # C'est un peu "magique" mais permet d'utiliser la vraie valeur analytique
            # pour cet exemple spécifique.
            threshold_cell = func.__closure__[0]
            true_expectations[func] = threshold_cell.cell_contents
        else:
            true_expectations[func] = true_expectation_monte_carlo_proxy(
                func, distribution_sampler, num_true_expectation_samples_for_proxy
            )
        if (i + 1) % (len(vc_class_functions) // 10 or 1) == 0:
            print(f"  {i+1}/{len(vc_class_functions)} calculées...")
    print("Vraies espérances calculées.")

    results = []
    for n in sorted(sample_sizes):
        print(f"\nSimulating for n = {n} samples...")
        # Générer un échantillon de taille n
        data_sample = [distribution_sampler() for _ in range(n)]

        max_diff_for_n = 0.0
        for func in vc_class_functions:
            emp_exp_f = empirical_expectation(func, data_sample)
            true_exp_f = true_expectations[func]
            diff = abs(emp_exp_f - true_exp_f)
            max_diff_for_n = max(max_diff_for_n, diff)

        results.append((n, max_diff_for_n))
        print(f"  Max difference for n={n}: {max_diff_for_n:.6f}")

    return results

# --- Paramètres de la simulation ---
DISTRIBUTION_SAMPLER = uniform_0_1_sampler
MIN_THRESHOLD = 0.0
MAX_THRESHOLD = 1.0
NUM_VC_FUNCTIONS = 100 # Nombre de fonctions indicatrices dans notre classe F
SAMPLE_SIZES = [10, 50, 100, 200, 500, 1000, 2000, 5000, 10000]
NUM_TRUE_EXPECTATION_SAMPLES = 1_000_000 # Pour la proxy des vraies espérances

# Générer la classe de fonctions VC
vc_functions = generate_vc_class_functions(MIN_THRESHOLD, MAX_THRESHOLD, NUM_VC_FUNCTIONS)

# Lancer la simulation
glivenko_cantelli_results = simulate_generalized_glivenko_cantelli(
    DISTRIBUTION_SAMPLER,
    vc_functions,
    SAMPLE_SIZES,
    NUM_TRUE_EXPECTATION_SAMPLES
)

# Afficher les résultats
print("\n--- Résultats de la Simulation Glivenko-Cantelli Généralisée ---")
print("Taille d'échantillon (n) | Sup |E_n[f] - E[f]|")
print("-------------------------------------------------")
for n, sup_diff in glivenko_cantelli_results:
    print(f"{n:<20} | {sup_diff:.6f}")
```

#### 3.2. Validation Mathématique (Assertions)

L'assertion principale ici est que le `sup_diff` doit décroître à mesure que `n` augmente. Ce n'est pas une décroissance monotone garantie à chaque étape à cause de la nature stochastique de l'échantillonnage, mais la tendance générale doit être à la baisse.

```python
# --- Validation de la Partie 3 ---
print("\n--- Validation Partie 3 : Simulation Glivenko-Cantelli Généralisée ---")

# 1. Vérifier que la liste des résultats n'est pas vide
assert glivenko_cantelli_results, "Les résultats de la simulation ne devraient pas être vides."
print("Assertion 'résultats non vides' passée.")

# 2. Vérifier la tendance générale à la décroissance du sup_diff
# Nous ne pouvons pas garantir une décroissance stricte à chaque étape,
# mais la dernière valeur devrait être significativement plus petite que la première.
if len(glivenko_cantelli_results) > 1:
    first_sup_diff = glivenko_cantelli_results[0][1]
    last_sup_diff = glivenko_cantelli_results[-1][1]
    print(f"Premier sup_diff: {first_sup_diff:.6f}, Dernier sup_diff: {last_sup_diff:.6f}")

    # Le dernier sup_diff devrait être au moins 5 fois plus petit que le premier (arbitraire mais raisonnable)
    # ou au moins inférieur à une petite tolérance si le premier était déjà petit.
    if first_sup_diff > 0.01: # Seulement si la première valeur est suffisamment grande pour montrer une décroissance
        assert last_sup_diff < first_sup_diff / 2, \
            f"Le dernier sup_diff ({last_sup_diff:.6f}) ne semble pas avoir suffisamment diminué par rapport au premier ({first_sup_diff:.6f})."
    else:
        assert last_sup_diff < 0.01, f"Le dernier sup_diff ({last_sup_diff:.6f}) devrait être très petit."
    print("Assertion 'tendance de décroissance du sup_diff' passée.")
else:
    print("Pas assez de points de données pour valider la tendance de décroissance.")

print("\nToutes les assertions de la Partie 3 ont été passées avec succès.")
```

### Conclusion et Discussion

Ce TP vous a permis d'implémenter les mécanismes fondamentaux pour comprendre les théorèmes de Glivenko-Cantelli généralisés. Vous avez observé comment, pour une classe de fonctions "pas trop complexe" (ici, une classe VC d'indicatrices), l'écart maximal entre l'espérance empirique et la vraie espérance sur l'ensemble de la classe tend à diminuer à mesure que la taille de l'échantillon augmente.

**Points clés à retenir :**

*   **Convergence Uniforme :** Le point crucial n'est pas seulement que `E_n[f]` converge vers `E[f]` pour une *seule* fonction `f` (ce qui est garanti par la loi des grands nombres), mais que cette convergence est *uniforme* sur *toute une classe* de fonctions.
*   **Rôle des Classes VC :** La propriété d'être une classe VC est une condition suffisante (et souvent nécessaire) pour garantir cette convergence uniforme. Elle limite la "capacité" ou la "complexité" de la classe de fonctions, empêchant des fonctions trop "pathologiques" qui pourraient "s'adapter" trop bien à l'échantillon et ne pas converger uniformément.
*   **Implications :** Ces théorèmes sont fondamentaux en théorie de l'apprentissage statistique (Statistical Learning Theory). Ils justifient pourquoi des algorithmes d'apprentissage peuvent généraliser à partir d'un ensemble d'entraînement à des données non vues, pourvu que la classe d'hypothèses (la classe de fonctions que l'algorithme peut apprendre) ne soit pas trop complexe.

**Limitations de la simulation :**

*   **Discrétisation de la Classe :** Nous avons utilisé un nombre fini de fonctions indicatrices. En réalité, la classe $\mathcal{F}$ est infinie. Cependant, pour une classe VC, il est souvent possible de montrer que la "pire" fonction est bien représentée par un échantillon discret suffisamment dense.
*   **Proxy de la Vraie Espérance :** La "vraie" espérance est elle-même une approximation Monte Carlo. Pour des distributions et fonctions plus complexes, cela reste la méthode la plus pratique. Pour des cas simples comme `I(x <= t)` sur `U(0,1)`, `E[f] = t`, ce qui a été utilisé pour une meilleure précision.
*   **Pas une Preuve Formelle :** La simulation démontre la *tendance* de la convergence, mais ne constitue pas une preuve mathématique formelle du théorème.

Ce TP vous donne une base solide pour explorer des concepts plus avancés en théorie de l'apprentissage et en statistique non-paramétrique.
