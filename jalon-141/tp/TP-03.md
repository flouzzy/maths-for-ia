## Travail Pratique 3/5 : Convergence Uniforme pour une Classe de Fonctions VC Simples

**Jalon 141 :** Théorèmes de Glivenko-Cantelli généralisés pour les classes de fonctions VC
**Objectif du TP :** Implémenter et observer la convergence uniforme d'un processus empirique vers son espérance vraie pour une classe de fonctions de Vapnik-Chervonenkis (VC) simple, en utilisant uniquement du Python pur.

### Introduction

Les Théorèmes de Glivenko-Cantelli (GC) sont fondamentaux en théorie de l'apprentissage statistique. Ils affirment que la fonction de répartition empirique converge uniformément vers la vraie fonction de répartition. Les versions *généralisées* de ces théorèmes étendent cette idée à des classes de fonctions plus complexes que les simples fonctions indicatrices d'ensembles. La notion de **classe VC** (Vapnik-Chervonenkis) est cruciale ici, car elle caractérise les classes de fonctions "pas trop complexes" pour lesquelles cette convergence uniforme est garantie.

Dans ce TP, nous allons :
1.  Définir une distribution de données simple.
2.  Construire une classe de fonctions indicatrices (qui est une classe VC de dimension 1).
3.  Calculer l'espérance empirique et l'espérance vraie pour chaque fonction de la classe.
4.  Observer la convergence uniforme en calculant le supremum de la différence absolue entre les espérances empiriques et vraies, et en montrant qu'il diminue à mesure que la taille de l'échantillon augmente.

Nous utiliserons uniquement des fonctionnalités Python de base, sans bibliothèques de calcul numérique comme NumPy ou SciPy pour les opérations fondamentales (bien que `random` soit acceptable pour la génération de nombres aléatoires).

### Partie 1 : Les Briques Fondamentales

Nous allons commencer par définir notre distribution de données, notre classe de fonctions et les méthodes pour calculer les espérances.

#### 1.1. Génération de Données

Nous allons simuler des données issues d'une distribution uniforme sur `[0, 1]`.

```python
import random

def generate_data(sample_size: int) -> list[float]:
    """
    Génère un échantillon de données i.i.d. suivant une distribution uniforme U[0, 1].

    Args:
        sample_size (int): La taille de l'échantillon à générer.

    Returns:
        list[float]: Une liste de nombres flottants représentant l'échantillon.
    """
    assert isinstance(sample_size, int) and sample_size > 0, \
        "La taille de l'échantillon doit être un entier positif."

    data = [random.uniform(0, 1) for _ in range(sample_size)]
    return data

# Exemple d'utilisation et assertion
sample_data = generate_data(100)
assert len(sample_data) == 100, "La taille de l'échantillon généré est incorrecte."
assert all(0 <= x <= 1 for x in sample_data), "Les données doivent être dans l'intervalle [0, 1]."
print(f"Exemple de données générées (premiers 5 éléments) : {sample_data[:5]}")
```

#### 1.2. Définition d'une Classe de Fonctions VC Simples

Nous allons utiliser une classe de fonctions indicatrices de la forme `f_theta(x) = 1 si x >= theta, 0 sinon`. Cette classe est une classe VC de dimension 1.

```python
def create_threshold_function(theta: float):
    """
    Crée une fonction de seuil f_theta(x) = 1 si x >= theta, 0 sinon.

    Args:
        theta (float): Le seuil pour la fonction.

    Returns:
        function: La fonction de seuil f_theta.
    """
    assert isinstance(theta, (int, float)) and 0 <= theta <= 1, \
        "Le seuil theta doit être un nombre flottant entre 0 et 1."

    def f_theta(x: float) -> int:
        """
        Fonction indicatrice : 1 si x >= theta, 0 sinon.
        """
        assert isinstance(x, (int, float)), "L'entrée x doit être un nombre."
        return 1 if x >= theta else 0
    return f_theta

def generate_vc_function_class(num_functions: int) -> list[tuple[float, callable]]:
    """
    Génère une classe de fonctions de seuil avec des thetas uniformément espacés.

    Args:
        num_functions (int): Le nombre de fonctions à générer dans la classe.

    Returns:
        list[tuple[float, callable]]: Une liste de tuples (theta, fonction)
                                      représentant la classe de fonctions.
    """
    assert isinstance(num_functions, int) and num_functions > 0, \
        "Le nombre de fonctions doit être un entier positif."

    function_class = []
    for i in range(num_functions):
        theta = i / (num_functions - 1) if num_functions > 1 else 0.5
        func = create_threshold_function(theta)
        function_class.append((theta, func))
    return function_class

# Exemple d'utilisation et assertion
vc_class = generate_vc_function_class(10)
assert len(vc_class) == 10, "La classe de fonctions n'a pas le bon nombre de fonctions."
assert isinstance(vc_class[0][0], float), "Le seuil doit être un flottant."
assert callable(vc_class[0][1]), "L'élément doit être une fonction appelable."
print(f"\nExemple de classe VC (premières 2 fonctions) :")
for theta, func in vc_class[:2]:
    print(f"  - f_{theta:.2f}(0.1) = {func(0.1)}, f_{theta:.2f}(0.9) = {func(0.9)}")
```

#### 1.3. Calcul de l'Espérance Empirique

L'espérance empirique `E_n[f]` d'une fonction `f` sur un échantillon `X = {x_1, ..., x_n}` est simplement la moyenne des valeurs de `f(x_i)` : `(1/n) * sum(f(x_i))`.

```python
def empirical_expectation(data: list[float], func: callable) -> float:
    """
    Calcule l'espérance empirique d'une fonction sur un échantillon de données.

    Args:
        data (list[float]): L'échantillon de données.
        func (callable): La fonction pour laquelle calculer l'espérance.

    Returns:
        float: L'espérance empirique.
    """
    assert isinstance(data, list) and len(data) > 0, \
        "Les données doivent être une liste non vide."
    assert callable(func), "L'argument func doit être une fonction appelable."

    sum_fx = 0.0
    for x in data:
        sum_fx += func(x)
    return sum_fx / len(data)

# Exemple d'utilisation et assertion
test_data = [0.1, 0.5, 0.9]
f_0_5 = create_threshold_function(0.5)
emp_exp = empirical_expectation(test_data, f_0_5)
assert isinstance(emp_exp, float), "L'espérance empirique doit être un flottant."
assert 0 <= emp_exp <= 1, "Pour une fonction indicatrice, l'espérance doit être entre 0 et 1."
print(f"\nEspérance empirique de f_0.5 sur [0.1, 0.5, 0.9] : {emp_exp}") # Devrait être (0+1+1)/3 = 0.66...
```

#### 1.4. Calcul de l'Espérance Vraie

Pour notre distribution `U[0, 1]` et nos fonctions de seuil `f_theta(x) = 1 si x >= theta`, l'espérance vraie `E[f_theta(X)]` est la probabilité que `X >= theta`. Pour `X ~ U[0, 1]`, cette probabilité est `1 - theta`. C'est un avantage majeur pour ce TP, car nous pouvons calculer l'espérance vraie *analytiquement* sans avoir besoin d'une simulation très coûteuse.

```python
def true_expectation(theta: float) -> float:
    """
    Calcule l'espérance vraie de la fonction f_theta pour X ~ U[0, 1].
    E[f_theta(X)] = P(X >= theta) = 1 - theta.

    Args:
        theta (float): Le seuil de la fonction.

    Returns:
        float: L'espérance vraie.
    """
    assert isinstance(theta, (int, float)) and 0 <= theta <= 1, \
        "Le seuil theta doit être un nombre flottant entre 0 et 1."
    return 1.0 - theta

# Exemple d'utilisation et assertion
true_exp_0_5 = true_expectation(0.5)
assert isinstance(true_exp_0_5, float), "L'espérance vraie doit être un flottant."
assert 0 <= true_exp_0_5 <= 1, "L'espérance vraie doit être entre 0 et 1."
print(f"Espérance vraie de f_0.5 pour U[0,1] : {true_exp_0_5}") # Devrait être 0.5
```

### Partie 2 : Démonstration de la Convergence Uniforme

Maintenant, nous allons combiner ces éléments pour observer la convergence uniforme. L'idée est de calculer `sup_f | E_n[f] - E[f] |` pour différentes tailles d'échantillon `n` et de voir comment cette valeur diminue.

#### 2.1. Calcul du Supremum de la Différence

```python
def calculate_supremum_difference(
    data: list[float],
    vc_class: list[tuple[float, callable]]
) -> float:
    """
    Calcule le supremum de la différence absolue entre l'espérance empirique
    et l'espérance vraie pour toutes les fonctions dans la classe VC.

    Args:
        data (list[float]): L'échantillon de données.
        vc_class (list[tuple[float, callable]]): La classe de fonctions VC.

    Returns:
        float: Le supremum de |E_n[f] - E[f]| sur toutes les fonctions f.
    """
    assert isinstance(data, list) and len(data) > 0, \
        "Les données doivent être une liste non vide."
    assert isinstance(vc_class, list) and len(vc_class) > 0, \
        "La classe VC doit être une liste non vide de fonctions."

    max_diff = 0.0
    for theta, func in vc_class:
        emp_exp = empirical_expectation(data, func)
        true_exp = true_expectation(theta)
        diff = abs(emp_exp - true_exp)
        if diff > max_diff:
            max_diff = diff
    return max_diff

# Exemple d'utilisation et assertion
sample_data_100 = generate_data(100)
vc_class_50 = generate_vc_function_class(50)
sup_diff_100 = calculate_supremum_difference(sample_data_100, vc_class_50)

assert isinstance(sup_diff_100, float), "Le supremum de la différence doit être un flottant."
assert sup_diff_100 >= 0, "Le supremum de la différence ne peut pas être négatif."
assert sup_diff_100 <= 1, "Pour des fonctions indicatrices, la différence max est 1."
print(f"\nSupremum de la différence pour un échantillon de taille 100 : {sup_diff_100:.4f}")
```

#### 2.2. Observation de la Convergence avec la Taille de l'Échantillon

Nous allons maintenant exécuter la simulation pour différentes tailles d'échantillon et observer la tendance du supremum de la différence.

```python
def observe_uniform_convergence(
    sample_sizes: list[int],
    num_vc_functions: int = 100,
    num_trials_per_size: int = 5
) -> dict[int, float]:
    """
    Observe la convergence uniforme en calculant le supremum de la différence
    pour différentes tailles d'échantillon et en moyennant sur plusieurs essais.

    Args:
        sample_sizes (list[int]): Une liste de tailles d'échantillon à tester.
        num_vc_functions (int): Le nombre de fonctions dans la classe VC.
        num_trials_per_size (int): Le nombre d'essais pour chaque taille d'échantillon
                                   afin de lisser les fluctuations stochastiques.

    Returns:
        dict[int, float]: Un dictionnaire mappant la taille de l'échantillon
                          au supremum moyen de la différence.
    """
    assert isinstance(sample_sizes, list) and all(isinstance(s, int) and s > 0 for s in sample_sizes), \
        "Les tailles d'échantillon doivent être une liste d'entiers positifs."
    assert isinstance(num_vc_functions, int) and num_vc_functions > 0, \
        "Le nombre de fonctions VC doit être un entier positif."
    assert isinstance(num_trials_per_size, int) and num_trials_per_size > 0, \
        "Le nombre d'essais doit être un entier positif."

    vc_class = generate_vc_function_class(num_vc_functions)
    results = {}

    print(f"\n--- Observation de la Convergence Uniforme (Classe VC de {num_vc_functions} fonctions) ---")
    for n in sorted(sample_sizes):
        print(f"  Taille d'échantillon n = {n}...")
        sum_sup_diff = 0.0
        for _ in range(num_trials_per_size):
            data = generate_data(n)
            sup_diff = calculate_supremum_difference(data, vc_class)
            sum_sup_diff += sup_diff
        avg_sup_diff = sum_sup_diff / num_trials_per_size
        results[n] = avg_sup_diff
        print(f"    Supremum moyen de la différence : {avg_sup_diff:.6f}")

    return results

# Définir les tailles d'échantillon à tester
sample_sizes_to_test = [50, 100, 200, 500, 1000, 2000, 5000]
convergence_results = observe_uniform_convergence(sample_sizes_to_test, num_vc_functions=100, num_trials_per_size=10)

# Afficher les résultats finaux
print("\n--- Résultats de la Convergence Uniforme ---")
previous_sup_diff = float('inf')
for n in sorted(convergence_results.keys()):
    sup_diff = convergence_results[n]
    print(f"n = {n:<5} : sup_f |E_n[f] - E[f]| = {sup_diff:.6f}")
    # Assertion pour valider la tendance décroissante (avec une petite tolérance)
    # On s'attend à une décroissance, mais la stochasticité peut causer de légères augmentations ponctuelles.
    # Pour un TP, on peut être un peu plus souple ou s'attendre à une décroissance "en moyenne".
    # Ici, nous allons juste vérifier que ce n'est pas une augmentation *majeure*.
    # Pour une validation plus robuste, il faudrait des tests statistiques.
    if n > sample_sizes_to_test[0]:
        assert sup_diff <= previous_sup_diff * 1.2, \
            f"Le supremum de la différence n'a pas diminué comme attendu pour n={n} (était {previous_sup_diff:.4f}, est {sup_diff:.4f})."
    previous_sup_diff = sup_diff

print("\nLes assertions de validation mathématique ont été passées avec succès.")
print("L'observation montre que le supremum de la différence diminue à mesure que la taille de l'échantillon augmente,")
print("ce qui est la manifestation de la convergence uniforme des processus empiriques pour cette classe VC.")
```

### Partie 3 : Discussion et Implications

Ce que nous avons observé est une démonstration concrète du principe des théorèmes de Glivenko-Cantelli généralisés.

*   **Classe VC :** La classe de fonctions `f_theta(x) = 1 if x >= theta` est une classe VC de dimension 1. Cela signifie qu'elle ne peut "shatter" (séparer toutes les configurations possibles) que des ensembles d'un seul point. Pour des ensembles de deux points, par exemple `x1 < x2`, on ne peut pas obtenir la séparation `(f(x1)=0, f(x2)=1)` car si `f(x2)=1`, alors `theta <= x2`, et si `f(x1)=0`, alors `theta > x1`. Donc `x1 < theta <= x2` est possible. Mais on ne peut pas avoir `(f(x1)=1, f(x2)=0)` car si `f(x1)=1`, alors `theta <= x1`, ce qui implique `theta <= x2`, donc `f(x2)` devrait être 1. La capacité de "shattering" est limitée, ce qui est la signature d'une classe VC de faible dimension.

*   **Convergence Uniforme :** Le fait que `sup_f |E_n[f] - E[f]|` tende vers zéro lorsque `n` tend vers l'infini est la clé. Cela signifie que l'estimation empirique de l'espérance est bonne *simultanément* pour *toutes* les fonctions de la classe, et pas seulement pour une fonction spécifique. C'est cette propriété qui est essentielle pour la généralisation en apprentissage automatique (par exemple, pour garantir qu'un classifieur appris sur un échantillon se comportera bien sur de nouvelles données).

*   **"Pure Python from scratch" :** En construisant ces éléments de base, nous avons une compréhension plus profonde de ce qui se passe sous le capot des bibliothèques de haut niveau. Chaque calcul de moyenne, chaque génération de nombre aléatoire, est explicite.

Ce TP a permis d'implémenter et de visualiser un aspect fondamental des Théorèmes de Glivenko-Cantelli généralisés : la convergence uniforme des processus empiriques pour une classe de fonctions VC. Nous avons vu que pour une classe de fonctions de complexité limitée (caractérisée par sa dimension VC finie), les moyennes calculées sur un échantillon de données se rapprochent uniformément des vraies espérances à mesure que la taille de l'échantillon augmente. Cette compréhension est cruciale pour la théorie de l'apprentissage statistique et la conception d'algorithmes robustes.
