# TP 4 : Démonstration de la Pulvérisation (Shattering)

Code algorithmique cherchant à vérifier si un ensemble d'intervalles pulvérise 2 points donnés.

```python
def check_shattering_intervals(points):
    '''
    Vérifie si la classe { [a, b] } pulvérise les points donnés.
    points : liste triée de nombres
    '''
    n = len(points)
    # L'ensemble des parties attendues
    expected_subsets = 2**n

    # On génère tous les intervalles possibles (on prend les milieux entre points + extremites)
    # Pour s'assurer de couvrir tous les cas, on crée des bornes a et b
    bounds = [points[0] - 1] + [ (points[i]+points[i+1])/2 for i in range(n-1) ] + [points[-1] + 1]

    achieved_subsets = set()
    for a in bounds:
        for b in bounds:
            if a <= b:
                subset = tuple(p for p in points if a <= p <= b)
                achieved_subsets.add(subset)

    return len(achieved_subsets) == expected_subsets

# Test 2 points
assert check_shattering_intervals([1, 2]) == True, "2 points doivent être pulvérisés par un intervalle."

# Test 3 points
assert check_shattering_intervals([1, 2, 3]) == False, "3 points ne peuvent pas être pulvérisés. Subset {1, 3} est impossible."
print("Validation TP4 passée.")
```
