### Introduction Théorique Rapide

**Rappel : Le Théorème de Glivenko-Cantelli (Classique)**
Pour une suite de variables aléatoires i.i.d. $X_1, \dots, X_n$ issues d'une distribution $F$, la fonction de répartition empirique $F_n(x) = \frac{1}{n} \sum_{i=1}^n \mathbf{1}_{X_i \le x}$ converge uniformément vers la vraie fonction de répartition $F(x)$ presque sûrement :
$$ \sup_{x \in \mathbb{R}} |F_n(x) - F(x)| \xrightarrow{n \to \infty} 0 \quad \text{p.s.} $$

**Généralisation : Classes de Fonctions VC**
Le théorème de Glivenko-Cantelli généralisé étend cette idée à des classes de fonctions $\mathcal{F}$ plus complexes que les simples fonctions indicatrices d'intervalles $(-\infty, x]$. Si $\mathcal{F}$ est une classe de fonctions "suffisamment simple" (par exemple, une classe de Vapnik-Chervonenkis ou VC), alors la convergence uniforme des moyennes empiriques vers les vraies espérances est garantie :
$$ \sup_{f \in \mathcal{F}} \left| \frac{1}{n} \sum_{i=1}^n f(X_i) - E[f(X)] \right| \xrightarrow{n \to \infty} 0 \quad \text{p.s.} $$
La **dimension VC** est une mesure de la complexité d'une classe de fonctions (ou de sets). Une classe de sets $\mathcal{C}$ a une dimension VC $d$ si elle peut "briser" (shatter) $d$ points mais pas $d+1$. Pour une classe de fonctions, on peut souvent la relier à la dimension VC de ses sous-graphes ou de ses ensembles de niveau.

Dans ce TP, nous allons nous concentrer sur une classe de fonctions indicatrices d'intervalles sur $\mathbb{R}$, qui est une classe VC de dimension 2.

### Partie 1 : Préparation - Génération de Données et Calcul d'Espérance Vraie

Pour démontrer la convergence, nous avons besoin d'une distribution de référence et d'un moyen de calculer l'espérance $E[f(X)]$ pour une fonction $f$. Nous utiliserons une distribution uniforme sur $[0,1]$ pour simplifier le calcul de l'intégrale.

#### 1.1 Génération de Données Aléatoires

Nous allons implémenter une fonction pour générer des échantillons i.i.d. à partir d'une distribution uniforme sur un intervalle donné.

```python
import random
import math

def generate_uniform_data(n_samples, lower_bound=0.0, upper_bound=1.0):
    """
    Génère un échantillon de n_samples points i.i.d. à partir d'une distribution
    uniforme sur l'intervalle [lower_bound, upper_bound].
    """
    if not (isinstance(n_samples, int) and n_samples > 0):
        raise ValueError("n_samples doit être un entier positif.")
    if not (isinstance(lower_bound, (int, float)) and isinstance(upper_bound, (int, float))):
        raise ValueError("Les bornes doivent être numériques.")
    if lower_bound >= upper_bound:
        raise ValueError("lower_bound doit être strictement inférieur à upper_bound.")

    return [random.uniform(lower_bound, upper_bound) for _ in range(n_samples)]

# --- Assertions de validation ---
# Test de base
sample_size = 100
data_sample = generate_uniform_data(sample_size)
assert len(data_sample) == sample_size, "La taille de l'échantillon ne correspond pas."
assert all(0 <= x <= 1 for x in data_sample), "Les points ne sont pas dans l'intervalle [0,1]."

# Test avec des bornes différentes
data_sample_custom = generate_uniform_data(50, -5, 5)
assert len(data_sample_custom) == 50
assert all(-5 <= x <= 5 for x in data_sample_custom)

print("Partie 1.1 : Génération de données validée avec succès.")
```

#### 1.2 Calcul de l'Espérance Vraie (Intégration Numérique)

Pour une variable aléatoire $X \sim U(a,b)$, l'espérance d'une fonction $f(X)$ est $E[f(X)] = \int_a^b f(x) \frac{1}{b-a} dx$.
Puisque nous sommes en "pure Python", nous allons implémenter une intégration numérique simple (méthode des trapèzes ou du point milieu) pour calculer cette intégrale.

```python
def integrate_func_uniform(func, lower_bound=0.0, upper_bound=1.0, num_steps=10000):
    """
    Calcule l'intégrale d'une fonction sur [lower_bound, upper_bound]
    en utilisant la méthode du point milieu (Riemann sum).
    Ceci représente E[f(X)] pour X ~ U(lower_bound, upper_bound).
    """
    if not callable(func):
        raise ValueError("func doit être une fonction.")
    if not (isinstance(num_steps, int) and num_steps > 0):
        raise ValueError("num_steps doit être un entier positif.")
    if lower_bound >= upper_bound:
        raise ValueError("lower_bound doit être strictement inférieur à upper_bound.")

    step_size = (upper_bound - lower_bound) / num_steps
    integral_sum = 0.0
    for i in range(num_steps):
        # Utilisation du point milieu pour une meilleure précision
        x = lower_bound + (i + 0.5) * step_size
        integral_sum += func(x) * step_size

    # Pour une distribution uniforme, E[f(X)] = (1/(b-a)) * integral(f(x) dx)
    # Notre intégrale_sum est déjà integral(f(x) dx)
    # Donc, E[f(X)] = integral_sum / (upper_bound - lower_bound)
    # Mais comme nous avons déjà multiplié par step_size = (upper_bound - lower_bound) / num_steps
    # et que nous voulons l'intégrale, le résultat est déjà correct pour integral(f(x) dx)
    # Si nous voulions E[f(X)] pour U(a,b), il faudrait diviser par (b-a).
    # Pour ce TP, nous allons considérer que notre fonction retourne l'intégrale de f(x) dx
    # et nous diviserons par (b-a) explicitement si nécessaire pour E[f(X)].
    # Pour la distribution U(0,1), (b-a)=1, donc l'intégrale est l'espérance.
    return integral_sum

# --- Assertions de validation ---
# Test avec une fonction simple f(x) = x sur [0,1]
# E[X] pour X ~ U(0,1) est 0.5
def identity_func(x):
    return x

true_exp_identity = integrate_func_uniform(identity_func, 0, 1)
assert abs(true_exp_identity - 0.5) < 1e-3, f"E[X] attendu 0.5, obtenu {true_exp_identity}"

# Test avec f(x) = 1 sur [0,1]
# E[1] = 1
def one_func(x):
    return 1

true_exp_one = integrate_func_uniform(one_func, 0, 1)
assert abs(true_exp_one - 1.0) < 1e-3, f"E[1] attendu 1.0, obtenu {true_exp_one}"

# Test avec f(x) = x^2 sur [0,1]
# E[X^2] = integral(x^2 dx) from 0 to 1 = [x^3/3] from 0 to 1 = 1/3
def square_func(x):
    return x * x

true_exp_square = integrate_func_uniform(square_func, 0, 1)
assert abs(true_exp_square - (1/3)) < 1e-3, f"E[X^2] attendu 1/3, obtenu {true_exp_square}"

print("Partie 1.2 : Calcul de l'espérance vraie (intégration numérique) validée avec succès.")
```

### Partie 2 : Classe de Fonctions VC et Espérance Empirique

Nous allons maintenant définir notre classe de fonctions VC et la manière de calculer l'espérance empirique.

#### 2.1 Définition d'une Classe de Fonctions VC (Indicatrices d'Intervalles)

La classe des fonctions indicatrices d'intervalles $I_{[a,b]}(x)$ sur $\mathbb{R}$ est une classe VC de dimension 2.
Une fonction $f(x) = I_{[a,b]}(x)$ retourne 1 si $x \in [a,b]$ et 0 sinon.

```python
def indicator_interval_function(a, b):
    """
    Retourne une fonction indicatrice pour l'intervalle [a, b].
    Cette fonction est un élément de notre classe de fonctions VC.
    """
    if not (isinstance(a, (int, float)) and isinstance(b, (int, float))):
        raise ValueError("Les bornes de l'intervalle doivent être numériques.")
    if a > b:
        # Assurer que a <= b pour un intervalle valide
        a, b = b, a

    def func(x):
        return 1 if a <= x <= b else 0
    return func

def generate_vc_function_class(num_functions, lower_bound=0.0, upper_bound=1.0):
    """
    Génère une liste de num_functions fonctions indicatrices d'intervalles
    avec des bornes aléatoires dans [lower_bound, upper_bound].
    """
    if not (isinstance(num_functions, int) and num_functions > 0):
        raise ValueError("num_functions doit être un entier positif.")

    func_class = []
    for _ in range(num_functions):
        a = random.uniform(lower_bound, upper_bound)
        b = random.uniform(lower_bound, upper_bound)
        func_class.append(indicator_interval_function(a, b))
    return func_class

# --- Assertions de validation ---
# Test d'une fonction indicatrice
f_test = indicator_interval_function(0.2, 0.7)
assert f_test(0.1) == 0, "f_test(0.1) devrait être 0"
assert f_test(0.5) == 1, "f_test(0.5) devrait être 1"
assert f_test(0.8) == 0, "f_test(0.8) devrait être 0"
assert f_test(0.2) == 1, "f_test(0.2) devrait être 1 (borne incluse)"

# Test de génération de classe
vc_class_example = generate_vc_function_class(5)
assert len(vc_class_example) == 5, "La classe devrait contenir 5 fonctions."
assert callable(vc_class_example[0]), "Les éléments de la classe doivent être des fonctions."

print("Partie 2.1 : Classe de fonctions VC (indicatrices d'intervalles) validée avec succès.")
```

#### 2.2 Calcul de l'Espérance Empirique

L'espérance empirique pour une fonction $f$ et un échantillon de données $X_1, \dots, X_n$ est simplement la moyenne des valeurs de $f$ sur l'échantillon :
$$ E_n[f] = \frac{1}{n} \sum_{i=1}^n f(X_i) $$

```python
def calculate_empirical_expectation(data, func):
    """
    Calcule l'espérance empirique d'une fonction sur un échantillon de données.
    """
    if not data:
        return 0.0 # Gérer le cas d'un échantillon vide
    if not callable(func):
        raise ValueError("func doit être une fonction.")

    return sum(func(x) for x in data) / len(data)

# --- Assertions de validation ---
# Test avec des données et une fonction simple
test_data = [0.1, 0.3, 0.5, 0.7, 0.9]
f_interval = indicator_interval_function(0.2, 0.8) # 0.3, 0.5, 0.7 sont dans l'intervalle
emp_exp_test = calculate_empirical_expectation(test_data, f_interval)
# (0 + 1 + 1 + 1 + 0) / 5 = 3/5 = 0.6
assert abs(emp_exp_test - 0.6) < 1e-9, f"Espérance empirique attendue 0.6, obtenue {emp_exp_test}"

# Test avec une fonction constante
f_one = one_func # définie précédemment
emp_exp_one = calculate_empirical_expectation(test_data, f_one)
assert abs(emp_exp_one - 1.0) < 1e-9, f"Espérance empirique attendue 1.0, obtenue {emp_exp_one}"

# Test avec un échantillon vide
assert calculate_empirical_expectation([], f_one) == 0.0, "L'espérance empirique d'un échantillon vide doit être 0."

print("Partie 2.2 : Calcul de l'espérance empirique validée avec succès.")
```

### Partie 3 : Démonstration du Théorème de Glivenko-Cantelli Généralisé

Nous allons maintenant assembler les pièces pour démontrer la convergence uniforme. L'idée est de calculer le supremum de la différence $|E_n[f] - E[f]|$ sur une classe de fonctions pour différentes tailles d'échantillon $n$. Nous devrions observer que ce supremum diminue à mesure que $n$ augmente.

#### 3.1 Mesure du Supremum de la Différence

```python
def calculate_uniform_supremum_difference(data, func_class, dist_lower_bound, dist_upper_bound, num_integration_steps=10000):
    """
    Calcule le supremum de la différence absolue entre l'espérance empirique
    et l'espérance vraie sur une classe de fonctions donnée.
    """
    if not data:
        return 0.0 # Si pas de données, la différence est 0 (ou infinie, mais pour la convergence, on suppose n>0)
    if not func_class:
        return 0.0 # Si pas de fonctions, la différence est 0

    max_diff = 0.0
    for func in func_class:
        emp_exp = calculate_empirical_expectation(data, func)
        # L'espérance vraie pour U(a,b) est integral(f(x) dx) / (b-a)
        true_integral = integrate_func_uniform(func, dist_lower_bound, dist_upper_bound, num_integration_steps)
        true_exp = true_integral / (dist_upper_bound - dist_lower_bound)

        diff = abs(emp_exp - true_exp)
        if diff > max_diff:
            max_diff = diff
    return max_diff

# --- Assertions de validation ---
# Pour un petit échantillon, la différence devrait être significative
test_data_small = generate_uniform_data(10, 0, 1)
test_func_class = generate_vc_function_class(20, 0, 1) # 20 fonctions aléatoires
sup_diff_small_n = calculate_uniform_supremum_difference(test_data_small, test_func_class, 0, 1)
assert sup_diff_small_n >= 0, "Le supremum de la différence ne peut pas être négatif."
# On ne peut pas affirmer une valeur exacte, mais elle devrait être non nulle
assert sup_diff_small_n > 0.01, f"Supremum trop petit pour n=10: {sup_diff_small_n}"

# Si la classe de fonctions est vide, le supremum est 0
assert calculate_uniform_supremum_difference(test_data_small, [], 0, 1) == 0.0

print("Partie 3.1 : Mesure du supremum de la différence validée avec succès.")
```

#### 3.2 Simulation et Observation de la Convergence

Nous allons maintenant exécuter la simulation pour différentes tailles d'échantillon et observer la diminution du supremum.

```python
# Paramètres de la simulation
DIST_LOWER_BOUND = 0.0
DIST_UPPER_BOUND = 1.0
NUM_VC_FUNCTIONS = 100 # Nombre de fonctions dans notre classe VC pour la simulation
NUM_INTEGRATION_STEPS = 50000 # Précision pour le calcul de l'espérance vraie

# Tailles d'échantillon à tester
sample_sizes = [10, 50, 100, 200, 500, 1000, 2000, 5000]

print("\n--- Démonstration du Théorème de Glivenko-Cantelli Généralisé ---")
print(f"Distribution : Uniforme sur [{DIST_LOWER_BOUND}, {DIST_UPPER_BOUND}]")
print(f"Classe de fonctions : {NUM_VC_FUNCTIONS} fonctions indicatrices d'intervalles aléatoires.")

# Générer la classe de fonctions VC une seule fois
vc_function_class = generate_vc_function_class(NUM_VC_FUNCTIONS, DIST_LOWER_BOUND, DIST_UPPER_BOUND)

supremum_differences = []
previous_sup_diff = float('inf')

for n in sample_sizes:
    print(f"\nCalcul pour n = {n}...")
    data = generate_uniform_data(n, DIST_LOWER_BOUND, DIST_UPPER_BOUND)

    current_sup_diff = calculate_uniform_supremum_difference(
        data, vc_function_class, DIST_LOWER_BOUND, DIST_UPPER_BOUND, NUM_INTEGRATION_STEPS
    )
    supremum_differences.append(current_sup_diff)

    print(f"  Supremum de |E_n[f] - E[f]| sur la classe : {current_sup_diff:.6f}")

    # --- Assertions de validation de la convergence ---
    # Le supremum devrait généralement diminuer ou rester stable (non-croissant)
    # avec l'augmentation de n. Il peut y avoir des fluctuations mineures
    # dues au caractère aléatoire de l'échantillon, mais la tendance générale doit être à la baisse.
    if n > sample_sizes[0]:
        # On s'attend à ce que la différence diminue, ou au moins ne croisse pas trop fortement
        # Nous utilisons une tolérance pour les petites fluctuations aléatoires
        assert current_sup_diff <= previous_sup_diff * 1.2, \
               f"Le supremum a augmenté de manière inattendue de {previous_sup_diff:.6f} à {current_sup_diff:.6f} pour n={n}."

    previous_sup_diff = current_sup_diff

# --- Assertion finale ---
# Pour le plus grand n, le supremum devrait être très petit
final_sup_diff = supremum_differences[-1]
assert final_sup_diff < 0.05, f"Le supremum final ({final_sup_diff:.6f}) n'est pas suffisamment petit pour n={sample_sizes[-1]}."

print("\n--- Résumé des résultats ---")
for i, n in enumerate(sample_sizes):
    print(f"n = {n:<5} : Supremum Différence = {supremum_differences[i]:.6f}")

print("\nPartie 3.2 : Démonstration de la convergence validée avec succès.")
print("Le supremum de la différence diminue bien avec l'augmentation de la taille de l'échantillon,")
print("démontrant ainsi le principe du Théorème de Glivenko-Cantelli Généralisé pour cette classe VC.")
```
