# TP 1 : Calcul de la fonction de répartition empirique
**Objectif :** Implémenter en Python pur la fonction de répartition empirique et la comparer à une distribution connue.

**Code Python :**
```python
import math

def empirical_cdf(sample, t):
    \"\"\"
    Calcule la fonction de répartition empirique F_n(t) pour un échantillon donné.
    \"\"\"
    n = len(sample)
    if n == 0:
        return 0.0
    count = sum(1 for x in sample if x <= t)
    return count / float(n)

# Test de validation mathématique
def test_empirical_cdf():
    sample = [1.2, 3.4, 1.2, 5.0, 2.8]

    assert math.isclose(empirical_cdf(sample, 1.0), 0.0), "Erreur en t=1.0"
    assert math.isclose(empirical_cdf(sample, 1.5), 0.4), "Erreur en t=1.5"
    assert math.isclose(empirical_cdf(sample, 2.8), 0.6), "Erreur en t=2.8"
    assert math.isclose(empirical_cdf(sample, 3.5), 0.8), "Erreur en t=3.5"
    assert math.isclose(empirical_cdf(sample, 6.0), 1.0), "Erreur en t=6.0"

    print("Tous les tests mathématiques pour la CDF empirique sont passés.")

if __name__ == "__main__":
    test_empirical_cdf()
```
