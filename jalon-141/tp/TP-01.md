### Titre : Introduction aux Concepts Fondamentaux : Moyennes Empiriques et Classes de Sets VC

**Contexte :**
Les Théorèmes de Glivenko-Cantelli (GC) sont des résultats fondamentaux en théorie des probabilités et en statistique. Le théorème original stipule que la fonction de répartition empirique converge uniformément vers la vraie fonction de répartition. Les versions *généralisées* étendent cette convergence uniforme à des classes de fonctions plus complexes, et la condition clé pour qu'une telle convergence ait lieu est souvent liée à la "complexité" de cette classe de fonctions, mesurée par sa **dimension VC (Vapnik-Chervonenkis)**.

Dans ce TP, nous allons implémenter en "pure Python from scratch" les concepts suivants :
1.  La simulation de données et le calcul de moyennes empiriques.
2.  La notion de "shattering" (brisure) de points par une classe de sets.
3.  Le calcul de la dimension VC pour des classes de sets simples.

Ces implémentations nous permettront de poser les bases pour comprendre comment la complexité d'une classe (de sets ou de fonctions) influence la convergence uniforme.

### Exercice 1 : Moyennes Empiriques et Espérance

**Contexte Théorique :**
L'espérance $E[X]$ d'une variable aléatoire $X$ est sa valeur moyenne "vraie". En pratique, nous n'avons accès qu'à un échantillon de données $X_1, X_2, \dots, X_n$. La **moyenne empirique** $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$ est une estimation de $E[X]$. La Loi des Grands Nombres nous assure que $\bar{X}_n$ converge vers $E[X]$ lorsque $n \to \infty$.

**Votre tâche :**
1.  Implémenter une fonction pour générer des nombres aléatoires uniformément distribués (nous utiliserons le module `random` de la bibliothèque standard Python, qui est considéré comme "from scratch" dans ce contexte, car il ne s'agit pas d'un framework scientifique de haut niveau).
2.  Implémenter une fonction pour calculer la moyenne empirique d'une liste de nombres.
3.  Comparer la moyenne empirique à l'espérance théorique pour une distribution uniforme.

```python
import random
import math

# --- Exercice 1: Moyennes Empiriques et Espérance ---

print("--- Exercice 1: Moyennes Empiriques et Espérance ---")

def generate_uniform_data(low: float, high: float, n: int) -> list[float]:
    """
    Génère une liste de n nombres aléatoires uniformément distribués
    entre low (inclus) et high (exclus).
    """
    if n <= 0:
        return []
    if low >= high:
        raise ValueError("low doit être inférieur à high")

    data = []
    for _ in range(n):
        # random.random() génère un float dans [0.0, 1.0)
        data.append(low + (high - low) * random.random())
    return data

def calculate_empirical_mean(data: list[float]) -> float:
    """
    Calcule la moyenne empirique d'une liste de nombres.
    """
    if not data:
        return 0.0
    return sum(data) / len(data)

def calculate_true_mean_uniform(low: float, high: float) -> float:
    """
    Calcule l'espérance théorique pour une distribution uniforme U(low, high).
    L'espérance d'une U(a, b) est (a + b) / 2.
    """
    return (low + high) / 2.0

# --- Tests et Assertions pour l'Exercice 1 ---
low_bound = 0.0
high_bound = 10.0
true_mean = calculate_true_mean_uniform(low_bound, high_bound)
print(f"Espérance théorique pour U({low_bound}, {high_bound}): {true_mean:.4f}")

# Test avec un petit échantillon
sample_size_small = 10
data_small = generate_uniform_data(low_bound, high_bound, sample_size_small)
empirical_mean_small = calculate_empirical_mean(data_small)
print(f"Moyenne empirique (n={sample_size_small}): {empirical_mean_small:.4f}")
# Assertion: La moyenne empirique doit être dans les bornes
assert low_bound <= empirical_mean_small <= high_bound, \
    f"La moyenne empirique ({empirical_mean_small}) doit être entre {low_bound} et {high_bound}."

# Test avec un grand échantillon pour observer la convergence
sample_size_large = 100000
data_large = generate_uniform_data(low_bound, high_bound, sample_size_large)
empirical_mean_large = calculate_empirical_mean(data_large)
print(f"Moyenne empirique (n={sample_size_large}): {empirical_mean_large:.4f}")

# Assertion: Pour un grand échantillon, la moyenne empirique doit être proche de l'espérance théorique.
tolerance = 0.05 # Une tolérance raisonnable pour la convergence
assert abs(empirical_mean_large - true_mean) < tolerance, \
    f"La moyenne empirique ({empirical_mean_large}) ne converge pas assez vers l'espérance ({true_mean})."
print(f"Assertion réussie : La moyenne empirique pour n={sample_size_large} est proche de l'espérance théorique (différence: {abs(empirical_mean_large - true_mean):.4f}).")

print("\n")
```

### Exercice 2 : Shattering et Dimension VC pour des Classes de Sets

**Contexte Théorique :**
La **dimension VC** d'une classe de sets $\mathcal{C}$ est le plus grand nombre $d$ tel qu'il existe un ensemble de $d$ points qui peut être "shattered" (brisé) par $\mathcal{C}$.
Un ensemble de $d$ points $x_1, \dots, x_d$ est **shattered** par une classe de sets $\mathcal{C}$ si, pour chaque sous-ensemble possible de ces $d$ points, il existe un set $C \in \mathcal{C}$ qui contient exactement les points de ce sous-ensemble et aucun des autres points. En d'autres termes, pour chaque partition binaire possible des $d$ points (chaque point est soit "dans le set", soit "hors du set"), il existe un set $C \in \mathcal{C}$ qui réalise cette partition. Il y a $2^d$ partitions binaires possibles pour $d$ points.

**Votre tâche :**
1.  Implémenter une fonction qui vérifie si un set donné (par exemple, un intervalle `[a, b]`) contient un point.
2.  Implémenter une fonction `can_shatter_points` qui, pour une classe de sets donnée et un ensemble de points, détermine si ces points peuvent être brisés.
3.  Implémenter une fonction `calculate_vc_dimension` qui estime la dimension VC d'une classe de sets en testant itérativement le "shattering" pour un nombre croissant de points.

Nous allons travailler avec des points sur une ligne réelle (1D) et deux classes de sets simples :
*   **Classe d'intervalles** : $\mathcal{C}_1 = \{[a, b] : a, b \in \mathbb{R}, a \le b\}$.
*   **Classe de demi-droites** : $\mathcal{C}_2 = \{(-\infty, a] : a \in \mathbb{R}\}$.

```python
import itertools

# --- Exercice 2: Shattering et Dimension VC pour des Classes de Sets ---

print("--- Exercice 2: Shattering et Dimension VC pour des Classes de Sets ---")

# --- Fonctions utilitaires pour les sets ---

def is_in_interval(point: float, interval: tuple[float, float]) -> bool:
    """
    Vérifie si un point est dans un intervalle [a, b].
    """
    a, b = interval
    return a <= point <= b

def is_in_half_line(point: float, half_line_bound: float) -> bool:
    """
    Vérifie si un point est dans une demi-droite (-inf, a].
    """
    return point <= half_line_bound

# --- Fonctions pour le Shattering ---

def generate_all_dichotomies(num_points: int) -> list[tuple[int, ...]]:
    """
    Génère toutes les 2^num_points dichotomies possibles pour num_points.
    Une dichotomie est une tuple de 0s et 1s, où 1 signifie "dans le set" et 0 "hors du set".
    Ex: pour 2 points, [(0,0), (0,1), (1,0), (1,1)]
    """
    return list(itertools.product([0, 1], repeat=num_points))

def can_shatter_intervals(points: list[float], target_dichotomy: tuple[int, ...]) -> bool:
    """
    Vérifie si la classe des intervalles peut réaliser une dichotomie spécifique
    sur un ensemble de points.

    Pour une classe d'intervalles, une dichotomie (0,1,0) pour des points triés
    (p1, p2, p3) n'est pas possible, car un intervalle ne peut pas "sauter" un point.
    Les points labellisés '1' doivent être contigus.
    """
    if not points:
        return True # Aucun point à briser

    # Tri des points pour faciliter la logique des intervalles
    sorted_points_with_indices = sorted([(p, i) for i, p in enumerate(points)])

    # Récupérer les labels correspondant aux points triés
    sorted_labels = [target_dichotomy[idx] for _, idx in sorted_points_with_indices]

    # Vérifier si les points labellisés '1' sont contigus
    first_one = -1
    last_one = -1

    for i, label in enumerate(sorted_labels):
        if label == 1:
            if first_one == -1:
                first_one = i
            last_one = i

    # Si aucun '1', c'est possible (intervalle vide ou très petit)
    if first_one == -1:
        return True

    # Vérifier que tous les points entre first_one et last_one sont aussi des '1'
    for i in range(first_one, last_one + 1):
        if sorted_labels[i] == 0:
            return False # Non contigu, donc pas un intervalle

    # Si tous les '1' sont contigus, un intervalle peut être construit
    # Par exemple, [sorted_points_with_indices[first_one][0], sorted_points_with_indices[last_one][0]]
    return True


def can_shatter_half_lines(points: list[float], target_dichotomy: tuple[int, ...]) -> bool:
    """
    Vérifie si la classe des demi-droites (-inf, a] peut réaliser une dichotomie spécifique
    sur un ensemble de points.

    Pour une classe de demi-droites (-inf, a], si les points sont triés (p1, p2, p3),
    une dichotomie (0,1,1) n'est pas possible car si p1 est 0, alors p2 et p3 doivent aussi être 0.
    Les labels doivent être non-décroissants (0,0,0), (0,0,1), (0,1,1), (1,1,1).
    """
    if not points:
        return True

    # Tri des points pour faciliter la logique des demi-droites
    sorted_points_with_indices = sorted([(p, i) for i, p in enumerate(points)])

    # Récupérer les labels correspondant aux points triés
    sorted_labels = [target_dichotomy[idx] for _, idx in sorted_points_with_indices]

    # Vérifier que les labels sont non-décroissants
    for i in range(len(sorted_labels) - 1):
        if sorted_labels[i] > sorted_labels[i+1]:
            return False # Ex: (1,0) est impossible pour une demi-droite
    return True


def check_if_points_can_be_shattered(points: list[float], class_shattering_func) -> bool:
    """
    Vérifie si un ensemble de points peut être brisé par une classe de sets donnée.
    `class_shattering_func` est une fonction comme `can_shatter_intervals` ou `can_shatter_half_lines`.
    """
    num_points = len(points)
    all_dichotomies = generate_all_dichotomies(num_points)

    for dichotomy in all_dichotomies:
        # Si la classe ne peut pas réaliser cette dichotomie, les points ne sont pas brisés
        if not class_shattering_func(points, dichotomy):
            return False

    # Si toutes les dichotomies peuvent être réalisées, les points sont brisés
    return True

def calculate_vc_dimension(class_shattering_func, max_points_to_test: int = 5) -> int:
    """
    Calcule la dimension VC d'une classe de sets en testant itérativement
    le shattering pour un nombre croissant de points.

    Note: Pour des classes de sets simples sur R^1, tester des points consécutifs
    comme [1.0, 2.0, ..., k.0] est suffisant pour trouver la VC dimension.
    Pour des classes plus complexes ou des dimensions plus élevées, il faudrait
    tester toutes les combinaisons possibles de k points, ce qui est beaucoup plus coûteux.
    """
    vc_dim = 0
    for k in range(1, max_points_to_test + 1):
        # On utilise des points distincts et ordonnés pour faciliter la logique
        test_points = [float(i) for i in range(1, k + 1)]

        print(f"  Test de shattering pour {k} points: {test_points}")
        if check_if_points_can_be_shattered(test_points, class_shattering_func):
            vc_dim = k
            print(f"  -> {k} points PEUVENT être brisés.")
        else:
            print(f"  -> {k} points NE PEUVENT PAS être brisés.")
            break # La VC dimension est k-1

    return vc_dim

# --- Tests et Assertions pour l'Exercice 2 ---

print("\n--- Test de la classe d'intervalles ---")
# VC dimension des intervalles sur R^1 est 2.
# 1 point: [1.0] -> (0), (1) -> Shattered
# 2 points: [1.0, 2.0] -> (0,0), (0,1), (1,0), (1,1) -> Shattered
# 3 points: [1.0, 2.0, 3.0] -> (0,1,0) impossible -> Not shattered
vc_intervals = calculate_vc_dimension(can_shatter_intervals)
print(f"Dimension VC estimée pour la classe d'intervalles: {vc_intervals}")
assert vc_intervals == 2, f"La dimension VC des intervalles devrait être 2, mais est {vc_intervals}."
print("Assertion réussie : Dimension VC pour les intervalles est correcte.")

print("\n--- Test de la classe de demi-droites (-inf, a] ---")
# VC dimension des demi-droites sur R^1 est 1.
# 1 point: [1.0] -> (0), (1) -> Shattered
# 2 points: [1.0, 2.0] -> (1,0) impossible -> Not shattered
vc_halflines = calculate_vc_dimension(can_shatter_half_lines)
print(f"Dimension VC estimée pour la classe de demi-droites: {vc_halflines}")
assert vc_halflines == 1, f"La dimension VC des demi-droites devrait être 1, mais est {vc_halflines}."
print("Assertion réussie : Dimension VC pour les demi-droites est correcte.")

print("\n")
```

### Réponses et Discussion (Exercice 3)

1.  **Interprétation de la Dimension VC :**
    *   **Dimension VC de 2 pour la classe des intervalles :** Cela signifie que la classe des intervalles peut "briser" (shatter) au moins un ensemble de 2 points. C'est-à-dire, pour 2 points distincts sur la ligne réelle, on peut toujours trouver un intervalle qui les inclut tous les deux, aucun des deux, seulement le premier, ou seulement le second. Cependant, elle ne peut pas briser *tout* ensemble de 3 points. Par exemple, si on prend 3 points $p_1 < p_2 < p_3$, un intervalle ne peut pas labelliser $(0, 1, 0)$ (seul le point du milieu est inclus). La classe d'intervalles a une capacité limitée à séparer des points non contigus.
    *   **Dimension VC de 1 pour la classe des demi-droites :** Cela signifie que la classe des demi-droites $(-\infty, a]$ peut briser au moins un ensemble de 1 point. Pour un point $p_1$, on peut trouver une demi-droite qui l'inclut (ex: $(-\infty, p_1]$) ou qui ne l'inclut pas (ex: $(-\infty, p_1-1]$). Cependant, elle ne peut pas briser tout ensemble de 2 points. Si on prend 2 points $p_1 < p_2$, une demi-droite ne peut pas labelliser $(1, 0)$ (le premier point est inclus, le second non), car si $p_1$ est inclus, alors $p_2$ (qui est plus grand) doit aussi être inclus si $a \ge p_1$. La classe de demi-droites est encore plus restrictive que celle des intervalles.
    *   **Lien avec la "capacité" d'un modèle :** La dimension VC est une mesure de la "complexité" ou de la "capacité" d'une classe de fonctions (ou de sets) à s'adapter à des données. Une dimension VC élevée indique une classe très flexible, capable de créer de nombreuses séparations différentes, et donc potentiellement de "mémoriser" les données d'entraînement (sur-apprentissage). Une dimension VC faible indique une classe plus rigide, moins sujette au sur-apprentissage mais potentiellement moins expressive. Les théorèmes de Glivenko-Cantelli généralisés montrent que pour qu'une convergence uniforme ait lieu (c'est-à-dire que la performance sur l'échantillon d'entraînement soit une bonne estimation de la performance sur de nouvelles données), la classe de fonctions ne doit pas être "trop complexe", ce qui est souvent formalisé par une dimension VC finie.

2.  **Limites de l'approche "from scratch" :**
    *   **Complexité pour des classes complexes ou dimensions supérieures :**
        *   **Génération de sets :** Pour des classes de sets plus complexes (ex: polygones, cercles en 2D), la fonction `class_shattering_func` deviendrait extrêmement difficile à implémenter. Il faudrait un algorithme pour "trouver" un set qui réalise une dichotomie donnée, ce qui peut être un problème d'optimisation non trivial.
        *   **Choix des points :** Notre `calculate_vc_dimension` teste des points consécutifs `[1.0, 2.0, ..., k.0]`. Pour des classes plus complexes, il n'est pas garanti que ces points soient représentatifs. Il faudrait tester *toutes les combinaisons* de $k$ points distincts, ce qui est combinatoirement explosif.
        *   **Performance :** Même pour des classes simples, la génération de toutes les $2^k$ dichotomies et la vérification pour chaque dichotomie devient très lente pour $k$ élevé.
    *   **Simplification par des bibliothèques :**
        *   **NumPy :** Offrirait des opérations vectorisées pour manipuler les points et les dichotomies, rendant le code plus concis et beaucoup plus rapide. Par exemple, pour vérifier si un point est dans un intervalle, on pourrait utiliser des masques booléens sur des tableaux NumPy.
        *   **SciPy :** Pourrait fournir des outils d'optimisation pour trouver un set qui réalise une dichotomie, ou des fonctions pour générer des points de manière plus sophistiquée.
        *   **Bibliothèques de géométrie :** Pour des sets en 2D ou plus, des bibliothèques de géométrie computationnelle (comme `shapely` ou `scipy.spatial`) seraient indispensables pour gérer les formes et les relations point-dans-forme.
        *   **Génération de nombres aléatoires :** `numpy.random` est beaucoup plus performant et offre une plus grande variété de distributions.
