# TP 2 : Le Théorème Fondamental via la Méthode des Trapèzes

**Objectif :** Valider le Théorème Fondamental en utilisant une méthode d'intégration géométrique d'ordre supérieur : l'interpolation linéaire par les trapèzes.

## 1. Code Python Pur

```python
import math

def f(t: float) -> float:
    \"\"\"Fonction à intégrer : f(t) = sin(t).\"\"\"
    return math.sin(t)

def methode_trapezes(func, a: float, b: float, n: int) -> float:
    \"\"\"Calcule l'intégrale de func de a à b via la méthode des trapèzes.\"\"\"
    if n <= 0: raise ValueError("n doit être > 0")
    if a == b: return 0.0
    largeur = (b - a) / n
    somme = 0.5 * (func(a) + func(b))
    for i in range(1, n):
        somme += func(a + i * largeur)
    return somme * largeur

def Phi(x: float) -> float:
    \"\"\"Fonction intégrale de 0 à x.\"\"\"
    return methode_trapezes(f, 0.0, x, 5000)

def derivee_numerique(func, x: float, h: float = 1e-5) -> float:
    return (func(x + h) - func(x - h)) / (2 * h)

def test_tfa_trapezes():
    points = [math.pi/4, math.pi/2, math.pi]
    for x in points:
        assert abs(f(x) - derivee_numerique(Phi, x)) < 1e-4
    print("TP2 validé : Phi'(x) est bien égal à f(x) via les trapèzes.")

if __name__ == '__main__':
    test_tfa_trapezes()
```

## 2. Exégèse du Code
Ici, au lieu d'approximer la fonction par des segments constants horizontaux, nous la relions par des segments obliques (trapèzes). C'est le fondement de la méthode de Newton-Cotes d'ordre 1. Le théorème fondamental résiste parfaitement à ce changement de schéma numérique.
