# TP 1 : Implémentation du Théorème Fondamental via la Méthode des Rectangles

**Objectif :** Vérifier numériquement le Théorème Fondamental de l'Analyse en approximant la dérivée de la fonction intégrale $\Phi(x) = \int_a^x f(t) \, dt$ en utilisant la méthode d'intégration par les rectangles (point milieu).

## 1. Code Python Pur

```python
def f(t: float) -> float:
    \"\"\"Fonction à intégrer : f(t) = t^2.\"\"\"
    return t**2

def methode_rectangles(func, a: float, b: float, n: int) -> float:
    \"\"\"Calcule l'intégrale de func de a à b via n rectangles (point milieu).\"\"\"
    if n <= 0: raise ValueError("n doit être > 0")
    if a == b: return 0.0
    largeur = (b - a) / n
    return sum(func(a + (i + 0.5) * largeur) * largeur for i in range(n))

def Phi(x: float) -> float:
    \"\"\"Fonction intégrale de 0 à x.\"\"\"
    return methode_rectangles(f, 0.0, x, 5000)

def derivee_numerique(func, x: float, h: float = 1e-5) -> float:
    \"\"\"Approximation de la dérivée par différences centrales.\"\"\"
    return (func(x + h) - func(x - h)) / (2 * h)

def test_tfa():
    points = [1.0, 2.0, 3.5]
    for x in points:
        assert abs(f(x) - derivee_numerique(Phi, x)) < 1e-4
    print("TP1 validé : Phi'(x) est bien égal à f(x) via les rectangles.")

if __name__ == '__main__':
    test_tfa()
```

## 2. Exégèse du Code
Ce premier TP pose les bases. Nous utilisons l'approximation de Riemann la plus intuitive, celle des rectangles, et nous évaluons au point milieu pour annuler l'erreur du premier ordre. Le code vérifie empiriquement que la dérivée numérique de cette aire cumulée retombe exactement sur la valeur de la fonction de départ.
