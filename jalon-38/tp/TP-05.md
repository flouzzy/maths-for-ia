# TP 5 : L'Intégration comme Accumulation de Gradients

**Objectif :** Illustrer le concept fondamental du Machine Learning où le changement total (mise à jour des poids) est l'intégrale discrète des changements instantanés (gradients).

## 1. Code Python Pur

```python
def vraie_perte(w: float) -> float:
    \"\"\"La Loss (L) qu'on cherche à minimiser: L(w) = w^2.\"\"\"
    return w**2

def gradient_perte(w: float) -> float:
    \"\"\"La dérivée de la perte (gradient): dL/dw = 2w.\"\"\"
    return 2 * w

def simulation_training():
    w_initial = 10.0
    w_final = 0.0 # Point minimum ciblé

    # Par le TFA, le changement total de la Loss doit être égal
    # à l'intégrale de son gradient le long du chemin des poids.
    changement_theorique = vraie_perte(w_final) - vraie_perte(w_initial)

    # Intégrons numériquement le gradient de w_initial à w_final
    n_etapes = 1000
    dw = (w_final - w_initial) / n_etapes
    integrale_gradient = 0.0

    for i in range(n_etapes):
        w_actuel = w_initial + (i + 0.5) * dw
        # L'intégrale est la somme des f(x)*dx
        integrale_gradient += gradient_perte(w_actuel) * dw

    assert abs(changement_theorique - integrale_gradient) < 1e-4
    print(f"Delta Loss Théorique : {changement_theorique}")
    print(f"Intégrale des Gradients : {integrale_gradient:.5f}")
    print("TP5 validé : En IA, la descente de gradient est une application numérique du TFA.")

if __name__ == '__main__':
    simulation_training()
```

## 2. Exégèse du Code
En Deep Learning, lorsque nous utilisons l'optimiseur SGD, nous calculons des gradients locaux. La modification totale de la fonction de coût d'un poids $A$ à un poids $B$ équivaut mathématiquement, d'après le second théorème fondamental de l'analyse, à l'intégrale du gradient entre ces deux poids. C'est ce qui justifie formellement la descente de gradient continue (Gradient Flow).
