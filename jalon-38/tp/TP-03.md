# TP 3 : La Méthode de Simpson (Interpolation Quadratique)

**Objectif :** Atteindre une précision machine optimale sur l'intégrale pour vérifier le TFA avec une fonction fortement non-linéaire (exponentielle).

## 1. Code Python Pur

```python
import math

def f(t: float) -> float:
    \"\"\"Fonction à intégrer : f(t) = exp(-t).\"\"\"
    return math.exp(-t)

def methode_simpson(func, a: float, b: float, n: int) -> float:
    \"\"\"Intégration numérique selon la méthode de Simpson (n doit être pair).\"\"\"
    if n % 2 != 0: n += 1
    if a == b: return 0.0
    h = (b - a) / n
    somme_paires = sum(func(a + 2 * i * h) for i in range(1, n // 2))
    somme_impaires = sum(func(a + (2 * i - 1) * h) for i in range(1, n // 2 + 1))
    return (h / 3) * (func(a) + func(b) + 2 * somme_paires + 4 * somme_impaires)

def Phi(x: float) -> float:
    return methode_simpson(f, 0.0, x, 1000)

def derivee_numerique(func, x: float, h: float = 1e-6) -> float:
    return (func(x + h) - func(x - h)) / (2 * h)

def test_tfa_simpson():
    for x in [0.5, 1.0, 2.0]:
        assert abs(f(x) - derivee_numerique(Phi, x)) < 1e-5
    print("TP3 validé : Simpson confirme le Théorème Fondamental.")

if __name__ == '__main__':
    test_tfa_simpson()
```

## 2. Exégèse du Code
La méthode de Simpson interpole la courbe par des arcs de parabole, ce qui est extrêmement précis (erreur en $O(h^4)$). Ce TP montre que même avec un schéma mathématiquement plus complexe pour calculer l'aire, la fonction primitive définie ainsi respecte universellement le principe de dérivation inverse.
