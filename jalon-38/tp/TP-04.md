# TP 4 : Limites du TFA avec les Fonctions Discontinues

**Objectif :** Montrer empiriquement que si la fonction initiale n'est pas continue, sa fonction intégrale (primitive) perd sa propriété de dérivabilité en ce point de discontinuité.

## 1. Code Python Pur

```python
def f_discontinue(t: float) -> float:
    \"\"\"Fonction échelon : vaut 1 si t >= 0, sinon -1.\"\"\"
    return 1.0 if t >= 0 else -1.0

def methode_rectangles(func, a: float, b: float, n: int) -> float:
    if a == b: return 0.0
    largeur = (b - a) / n
    return sum(func(a + (i + 0.5) * largeur) * largeur for i in range(n))

def Phi(x: float) -> float:
    \"\"\"Intégration depuis a = -2.\"\"\"
    return methode_rectangles(f_discontinue, -2.0, x, 5000)

def derivee_numerique(func, x: float, h: float = 1e-5) -> float:
    return (func(x + h) - func(x - h)) / (2 * h)

def test_limites_tfa():
    # En x = 1 (où f est continue), le TFA fonctionne
    assert abs(f_discontinue(1.0) - derivee_numerique(Phi, 1.0)) < 1e-3

    # En x = 0, la dérivée numérique dépend de h et du schéma. La fonction Phi est anguleuse.
    derivee_zero = derivee_numerique(Phi, 0.0)
    print(f"La valeur de f(0) est {f_discontinue(0.0)}.")
    print(f"La 'dérivée' évaluée numériquement en 0 donne {derivee_zero:.5f}.")
    print("TP4 validé : Le TFA ne garantit pas la dérivabilité si f est discontinue.")

if __name__ == '__main__':
    test_limites_tfa()
```

## 2. Exégèse du Code
L'hypothèse reine du TFA est la continuité de la fonction à intégrer. Nous encodons ici une fonction échelon (signe). La fonction `Phi` correspondante sera géométriquement la valeur absolue, continue mais pointue en 0. La différence finie centrée en 0 tentera de faire la moyenne des deux pentes, renvoyant 0, ce qui contredit la vraie fonction échelon qui vaut 1 en zéro. Le théorème s'effondre logiquement.
