### 3. Contexte Théorique Bref Rappel

Un **espace de Hilbert** est un espace vectoriel complet muni d'un produit scalaire. C'est la généralisation des espaces euclidiens de dimension finie aux dimensions infinies.

*   **Produit Scalaire (ou Produit Intérieur)**: Une fonction `(u, v) -> <u, v>` qui associe à deux vecteurs `u` et `v` un scalaire. Il satisfait des propriétés de linéarité, symétrie et de positivité. Pour des vecteurs réels `u = (u1, ..., un)` et `v = (v1, ..., vn)`, le produit scalaire standard est `sum(ui * vi)`.
*   **Norme**: La norme d'un vecteur `u`, notée `||u||`, est définie par `sqrt(<u, u>)`. Elle représente la "longueur" du vecteur.
*   **Orthogonalité**: Deux vecteurs `u` et `v` sont orthogonaux si leur produit scalaire est nul : `<u, v> = 0`.
*   **Base Orthonormale (BON)**: Un ensemble de vecteurs `{e1, e2, ..., en}` forme une BON si tous les vecteurs sont mutuellement orthogonaux (`<ei, ej> = 0` pour `i != j`) et si chaque vecteur est de norme 1 (`||ei|| = 1`).
*   **Décomposition sur une BON**: Tout vecteur `v` dans un espace de Hilbert de dimension finie peut être exprimé comme une combinaison linéaire de ses vecteurs de base : `v = c1*e1 + c2*e2 + ... + cn*en`. Les coefficients `ci` sont obtenus par `ci = <v, ei>`. Cette opération permet de "numériser" l'élément `v` par la suite de ses coefficients `(c1, ..., cn)`.
*   **Identité de Parseval**: Pour tout vecteur `v` et toute BON `{e1, ..., en}`, la norme de `v` au carré est égale à la somme des carrés des coefficients de sa décomposition : `||v||^2 = sum(ci^2) = sum(<v, ei>^2)`. Cela signifie que la "quantité" d'information (énergie) est préservée entre la représentation du vecteur lui-même et sa représentation par ses coefficients dans la base.
*   **Procédé d'Orthogonalisation de Gram-Schmidt**: Cet algorithme permet de transformer un ensemble de vecteurs linéairement indépendants `{v1, ..., vk}` en un ensemble de vecteurs orthonormaux `{u1, ..., uk}` qui engendrent le même sous-espace.

#### Mission 1: Outils Fondamentaux (Produit Scalaire et Norme)

Implémentez les fonctions Python pour le produit scalaire et la norme d'un vecteur.

```python
import math

# Une petite tolerance pour les comparaisons de nombres flotants
# dans les assertions.
TOLERANCE = 1e-9

def dot_product(v1, v2):
    """
    Calcule le produit scalaire (produit interne) de deux vecteurs.
    Les vecteurs sont représentés par des listes de nombres.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la meme dimension.")

    # Implémentation "from scratch" sans sum() ni list comprehension pour illustrer
    result = 0.0
    for i in range(len(v1)):
        result += v1[i] * v2[i]
    return result

def vector_norm(v):
    """
    Calcule la norme euclidienne (longueur) d'un vecteur.
    """
    # La norme est la racine carree du produit scalaire du vecteur avec lui-meme.
    return math.sqrt(dot_product(v, v))

def scale_vector(v, scalar):
    """
    Multiplie un vecteur par un scalaire.
    """
    scaled_v = []
    for x in v:
        scaled_v.append(x * scalar)
    return scaled_v

def subtract_vectors(v1, v2):
    """
    Soustrait deux vecteurs element par element.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la meme dimension.")
    sub_v = []
    for i in range(len(v1)):
        sub_v.append(v1[i] - v2[i])
    return sub_v

# --- Assertions pour valider les fonctions ---
# Test du produit scalaire
v_a = [1.0, 2.0, 3.0]
v_b = [4.0, 5.0, 6.0]
expected_dot_ab = 1.0*4.0 + 2.0*5.0 + 3.0*6.0 # 4 + 10 + 18 = 32
assert abs(dot_product(v_a, v_b) - expected_dot_ab) < TOLERANCE, "Test dot_product simple echoue"

v_c = [0.0, 0.0, 0.0]
assert abs(dot_product(v_a, v_c)) < TOLERANCE, "Test dot_product avec vecteur nul echoue"

# Test de la norme
v_d = [3.0, 4.0]
expected_norm_d = math.sqrt(3.0*3.0 + 4.0*4.0) # sqrt(9 + 16) = sqrt(25) = 5
assert abs(vector_norm(v_d) - expected_norm_d) < TOLERANCE, "Test vector_norm simple echoue"

v_e = [1.0, 0.0, 0.0]
assert abs(vector_norm(v_e) - 1.0) < TOLERANCE, "Test vector_norm pour vecteur unitaire echoue"

# Test de scale_vector
v_f = [1.0, 2.0]
scaled_f = scale_vector(v_f, 2.0)
assert scaled_f == [2.0, 4.0], "Test scale_vector echoue"

# Test de subtract_vectors
v_g = [5.0, 2.0]
v_h = [1.0, 1.0]
sub_gh = subtract_vectors(v_g, v_h)
assert sub_gh == [4.0, 1.0], "Test subtract_vectors echoue"

print("Mission 1: Toutes les assertions ont ete validees avec succes!")
```

#### Mission 2: Décomposition sur une Base Orthonormale

Dans cette mission, vous allez décomposer un vecteur `v` sur une base orthonormale donnée. Pour l'exemple, nous utiliserons une base orthonormale canonique dans `R^3`.

```python
# Utilisation des fonctions de la Mission 1
# dot_product, vector_norm, scale_vector, subtract_vectors sont disponibles ici

def get_canonical_basis(dimension):
    """
    Genere la base canonique orthonormale pour un espace de dimension donnee.
    Ex: pour dimension=3, retourne [[1,0,0], [0,1,0], [0,0,1]]
    """
    basis = []
    for i in range(dimension):
        e_i = [0.0] * dimension
        e_i[i] = 1.0
        basis.append(e_i)
    return basis

def decompose_on_orthonormal_basis(v, basis):
    """
    Decompose un vecteur v sur une base orthonormale.
    Retourne la liste des coefficients ci.
    """
    coefficients = []
    for e_i in basis:
        # Les coefficients ci sont calcules par le produit scalaire de v avec chaque vecteur de base.
        ci = dot_product(v, e_i)
        coefficients.append(ci)
    return coefficients

def reconstruct_vector_from_basis(coefficients, basis):
    """
    Reconstruit un vecteur a partir de ses coefficients et de la base.
    """
    if not coefficients:
        if not basis:
            return []
        return [0.0] * len(basis[0]) # retourne un vecteur nul si aucun coefficient et une base non vide

    reconstructed_v = [0.0] * len(basis[0])
    for i in range(len(coefficients)):
        scaled_e_i = scale_vector(basis[i], coefficients[i])
        for j in range(len(reconstructed_v)):
            reconstructed_v[j] += scaled_e_i[j]
    return reconstructed_v

# --- Assertions pour valider les fonctions ---
dimension_3 = 3
canonical_basis_3d = get_canonical_basis(dimension_3)

# Verifier que la base canonique est orthonormale
for i in range(dimension_3):
    assert abs(vector_norm(canonical_basis_3d[i]) - 1.0) < TOLERANCE, \
        f"Erreur: Le vecteur de base {i} n'est pas normalise."
    for j in range(i + 1, dimension_3):
        assert abs(dot_product(canonical_basis_3d[i], canonical_basis_3d[j])) < TOLERANCE, \
            f"Erreur: Les vecteurs de base {i} et {j} ne sont pas orthogonaux."

# Test de decomposition et reconstruction
v_test = [5.0, -2.0, 7.0]
coeffs_v_test = decompose_on_orthonormal_basis(v_test, canonical_basis_3d)
expected_coeffs_v_test = [5.0, -2.0, 7.0] # Pour la base canonique, les coefficients sont les composantes du vecteur
assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(coeffs_v_test, expected_coeffs_v_test)), \
    "Test decompose_on_orthonormal_basis echoue"

reconstructed_v_test = reconstruct_vector_from_basis(coeffs_v_test, canonical_basis_3d)
assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(reconstructed_v_test, v_test)), \
    "Test reconstruct_vector_from_basis echoue"

# Test avec un autre vecteur et une base non canonique (mais qui doit etre orthonormale)
# Exemple de base orthonormale pour R2 (rotation de la base canonique)
basis_r2 = [
    [1.0 / math.sqrt(2.0), 1.0 / math.sqrt(2.0)],
    [-1.0 / math.sqrt(2.0), 1.0 / math.sqrt(2.0)]
]
v_r2 = [3.0, 4.0]
coeffs_r2 = decompose_on_orthonormal_basis(v_r2, basis_r2)
# c1 = <[3,4], [1/sqrt(2), 1/sqrt(2)]> = (3+4)/sqrt(2) = 7/sqrt(2)
# c2 = <[3,4], [-1/sqrt(2), 1/sqrt(2)]> = (-3+4)/sqrt(2) = 1/sqrt(2)
expected_coeffs_r2_c1 = 7.0 / math.sqrt(2.0)
expected_coeffs_r2_c2 = 1.0 / math.sqrt(2.0)

assert abs(coeffs_r2[0] - expected_coeffs_r2_c1) < TOLERANCE, "Test coeffs_r2 c1 echoue"
assert abs(coeffs_r2[1] - expected_coeffs_r2_c2) < TOLERANCE, "Test coeffs_r2 c2 echoue"

reconstructed_v_r2 = reconstruct_vector_from_basis(coeffs_r2, basis_r2)
assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(reconstructed_v_r2, v_r2)), \
    "Test reconstruct_vector_from_basis avec base non canonique echoue"

print("Mission 2: Toutes les assertions ont ete validees avec succes!")
```

#### Mission 3: Validation de l'Identité de Parseval

Utilisez les fonctions précédentes pour valider l'identité de Parseval.

```python
# Utilisation des fonctions des Missions 1 et 2
# dot_product, vector_norm, decompose_on_orthonormal_basis sont disponibles ici

def check_parseval_identity(v, basis):
    """
    Verifie l'identite de Parseval pour un vecteur v et une base orthonormale.
    Retourne True si l'identite est verifiee (a TOLERANCE pres), False sinon.
    """
    # Calculer ||v||^2
    norm_v_squared = dot_product(v, v) # C'est la meme chose que vector_norm(v)**2

    # Calculer sum(ci^2)
    coefficients = decompose_on_orthonormal_basis(v, basis)
    sum_coeffs_squared = 0.0
    for ci in coefficients:
        sum_coeffs_squared += ci * ci

    # Comparer les deux valeurs
    return abs(norm_v_squared - sum_coeffs_squared) < TOLERANCE

# --- Assertions pour valider la fonction ---
# Cas 1: Base canonique 3D
v_parseval_1 = [1.0, 2.0, 3.0]
basis_parseval_1 = get_canonical_basis(3) # Utilise la fonction de la Mission 2
assert check_parseval_identity(v_parseval_1, basis_parseval_1), "Parseval echoue pour base canonique"

# Cas 2: Base non canonique 2D
v_parseval_2 = [3.0, 4.0]
basis_parseval_2 = [
    [1.0 / math.sqrt(2.0), 1.0 / math.sqrt(2.0)],
    [-1.0 / math.sqrt(2.0), 1.0 / math.sqrt(2.0)]
]
assert check_parseval_identity(v_parseval_2, basis_parseval_2), "Parseval echoue pour base non canonique"

# Cas 3: Vecteur nul
v_parseval_3 = [0.0, 0.0, 0.0]
assert check_parseval_identity(v_parseval_3, basis_parseval_1), "Parseval echoue pour vecteur nul"

# Cas 4: Vecteur de norme 1
v_parseval_4 = [1.0, 0.0, 0.0]
assert check_parseval_identity(v_parseval_4, basis_parseval_1), "Parseval echoue pour vecteur unitaire"

print("Mission 3: Toutes les assertions ont ete validees avec succes!")
```

#### Mission 4: Implémentation du Procédé d'Orthogonalisation de Gram-Schmidt

Implémentez l'algorithme de Gram-Schmidt pour transformer un ensemble de vecteurs linéairement indépendants en une base orthonormale.

```python
# Utilisation des fonctions des Missions 1
# dot_product, vector_norm, scale_vector, subtract_vectors sont disponibles ici

def gram_schmidt_orthogonalization(vectors):
    """
    Applique le procede de Gram-Schmidt a un ensemble de vecteurs
    pour produire une base orthonormale.

    Args:
        vectors: Une liste de vecteurs (listes de nombres) qui sont lineairement independants.
                 Tous les vecteurs doivent avoir la meme dimension.

    Returns:
        Une liste de vecteurs formant une base orthonormale.
    """
    if not vectors:
        return []

    # Verifier que tous les vecteurs ont la meme dimension
    dimension = len(vectors[0])
    for v in vectors:
        if len(v) != dimension:
            raise ValueError("Tous les vecteurs doivent avoir la meme dimension.")

    orthonormal_basis = []
    for v_i in vectors:
        u_i = list(v_i) # Copie du vecteur original

        # Soustraire les projections sur les vecteurs deja orthogonalises
        for u_j in orthonormal_basis:
            # Projection de v_i sur u_j: <v_i, u_j> * u_j
            projection_scalar = dot_product(v_i, u_j)
            projected_vector = scale_vector(u_j, projection_scalar)
            u_i = subtract_vectors(u_i, projected_vector)

        # Normaliser le vecteur obtenu
        norm_u_i = vector_norm(u_i)

        # Gerer le cas ou le vecteur est nul (ce qui indiquerait une dependance lineaire)
        if norm_u_i < TOLERANCE:
            raise ValueError("Les vecteurs d'entree ne sont pas lineairement independants.")

        u_i_normalized = scale_vector(u_i, 1.0 / norm_u_i)
        orthonormal_basis.append(u_i_normalized)

    return orthonormal_basis

def is_orthonormal_basis(basis, tolerance=TOLERANCE):
    """
    Verifie si une liste de vecteurs forme une base orthonormale.
    """
    if not basis:
        return True

    # Verifier si les vecteurs ont une dimension coherente
    if not all(len(v) == len(basis[0]) for v in basis):
        return False

    for i in range(len(basis)):
        # Verifier la normalisation
        if abs(vector_norm(basis[i]) - 1.0) >= tolerance:
            return False

        # Verifier l'orthogonalite
        for j in range(i + 1, len(basis)):
            if abs(dot_product(basis[i], basis[j])) >= tolerance:
                return False
    return True

# --- Assertions pour valider la fonction ---
# Cas 1: Vecteurs de base non orthogonaux en R2
v1_gs = [1.0, 1.0]
v2_gs = [2.0, 0.0]
vectors_gs_1 = [v1_gs, v2_gs]
bon_gs_1 = gram_schmidt_orthogonalization(vectors_gs_1)

# Verification des proprietes de la BON resultante
assert is_orthonormal_basis(bon_gs_1), "Gram-Schmidt echoue pour R2 - la base n'est pas orthonormale"

# Attendu pour bon_gs_1:
# u1 = v1 / ||v1|| = [1,1] / sqrt(2) = [1/sqrt(2), 1/sqrt(2)]
# u2_prime = v2 - <v2, u1>u1 = [2,0] - ([2,0].[1/sqrt(2), 1/sqrt(2)]) * [1/sqrt(2), 1/sqrt(2)]
#           = [2,0] - (2/sqrt(2)) * [1/sqrt(2), 1/sqrt(2)]
#           = [2,0] - [1,1] = [1,-1]
# u2 = u2_prime / ||u2_prime|| = [1,-1] / sqrt(2) = [1/sqrt(2), -1/sqrt(2)]

expected_u1 = [1.0 / math.sqrt(2.0), 1.0 / math.sqrt(2.0)]
expected_u2 = [1.0 / math.sqrt(2.0), -1.0 / math.sqrt(2.0)]

assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(bon_gs_1[0], expected_u1)), \
    "Premier vecteur de la BON de Gram-Schmidt incorrect"
assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(bon_gs_1[1], expected_u2)), \
    "Deuxieme vecteur de la BON de Gram-Schmidt incorrect"


# Cas 2: Vecteurs de base non orthogonaux en R3
v3_gs = [1.0, 1.0, 0.0]
v4_gs = [1.0, 0.0, 0.0]
v5_gs = [0.0, 0.0, 1.0]
vectors_gs_2 = [v3_gs, v4_gs, v5_gs]
bon_gs_2 = gram_schmidt_orthogonalization(vectors_gs_2)

assert is_orthonormal_basis(bon_gs_2), "Gram-Schmidt echoue pour R3 - la base n'est pas orthonormale"

# Test de robustesse (vecteurs deja orthogonaux)
v6_gs = [1.0, 0.0, 0.0]
v7_gs = [0.0, 1.0, 0.0]
v8_gs = [0.0, 0.0, 1.0]
vectors_gs_3 = [v6_gs, v7_gs, v8_gs]
bon_gs_3 = gram_schmidt_orthogonalization(vectors_gs_3)

assert is_orthonormal_basis(bon_gs_3), "Gram-Schmidt echoue pour base canonique d'entree"
assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(bon_gs_3[0], v6_gs)), "Vecteur 1 inchangé echoue"
assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(bon_gs_3[1], v7_gs)), "Vecteur 2 inchangé echoue"
assert all(abs(c1 - c2) < TOLERANCE for c1, c2 in zip(bon_gs_3[2], v8_gs)), "Vecteur 3 inchangé echoue"

# Test de cas d'erreur: vecteurs lineairement dependants
v_dep1 = [1.0, 2.0]
v_dep2 = [2.0, 4.0] # 2 * v_dep1
vectors_dependent = [v_dep1, v_dep2]
try:
    gram_schmidt_orthogonalization(vectors_dependent)
    assert False, "Gram-Schmidt n'a pas detecte la dependance lineaire."
except ValueError as e:
    assert "lineairement independants" in str(e), "Message d'erreur de dependance lineaire incorrect."

print("Mission 4: Toutes les assertions ont ete validees avec succes!")
```
