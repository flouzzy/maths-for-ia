## Introduction

Les espaces de Hilbert sont des espaces vectoriels munis d'un produit scalaire complets. Ils constituent un cadre fondamental en mathématiques pures et appliquées, notamment en analyse fonctionnelle, en mécanique quantique ou en traitement du signal. La notion de base orthonormée est cruciale car elle permet de représenter de manière unique et "numérisable" tout élément de l'espace, un peu comme les coordonnées cartésiennes dans R^n.

Ce TP vous guidera à travers l'implémentation de concepts clés des bases hilbertiennes dans un contexte de dimension finie, en utilisant Python pur, sans aucune bibliothèque externe de calcul numérique (comme NumPy). Cela vous permettra de saisir en profondeur les mécanismes sous-jacents et l'importance des assertions pour valider la correction mathématique de votre code.

```python
import math
import random

# Constante de tolerance pour les comparaisons de nombres flottants
EPSILON = 1e-9

class Vecteur:
    """
    Represente un vecteur en dimension finie.
    Les vecteurs sont traites comme immutables apres creation pour les operations
    (chaque operation retourne un nouveau vecteur).
    """
    def __init__(self, elements):
        if not isinstance(elements, list) or not all(isinstance(x, (int, float)) for x in elements):
            raise ValueError("Les elements du vecteur doivent etre une liste de nombres.")
        self.elements = [float(x) for x in elements]

    def __len__(self):
        """Retourne la dimension du vecteur."""
        return len(self.elements)

    def __getitem__(self, index):
        """Permet l'acces aux elements par indice (ex: v[0])."""
        return self.elements[index]

    def __str__(self):
        """Representation textuelle conviviale du vecteur."""
        return f"Vecteur({[round(x, 4) for x in self.elements]})"

    def __repr__(self):
        """Representation formelle du vecteur, utile pour le debug."""
        return f"Vecteur({self.elements})"

    def __add__(self, other):
        """Definit l'operation d'addition de vecteurs (v1 + v2)."""
        if not isinstance(other, Vecteur) or len(self) != len(other):
            raise ValueError("Les vecteurs doivent avoir la meme dimension pour l'addition.")
        return Vecteur([self.elements[i] + other.elements[i] for i in range(len(self))])

    def __sub__(self, other):
        """Definit l'operation de soustraction de vecteurs (v1 - v2)."""
        if not isinstance(other, Vecteur) or len(self) != len(other):
            raise ValueError("Les vecteurs doivent avoir la meme dimension pour la soustraction.")
        return Vecteur([self.elements[i] - other.elements[i] for i in range(len(self))])

    def __mul__(self, scalar):
        """Definit la multiplication par un scalaire (vecteur * scalaire)."""
        if not isinstance(scalar, (int, float)):
            raise ValueError("Le multiplicateur doit etre un scalaire.")
        return Vecteur([x * scalar for x in self.elements])

    def __rmul__(self, scalar):
        """Definit la multiplication par un scalaire dans le sens inverse (scalaire * vecteur)."""
        return self.__mul__(scalar)

    def __eq__(self, other):
        """Definit l'egalite entre vecteurs, tenant compte de la precision flottante."""
        if not isinstance(other, Vecteur) or len(self) != len(other):
            return False
        return all(abs(self.elements[i] - other.elements[i]) < EPSILON for i in range(len(self)))

    def est_proche(self, other, tolerance=EPSILON):
        """Verifie si deux vecteurs sont "presque" egaux."""
        if not isinstance(other, Vecteur) or len(self) != len(other):
            return False
        return all(abs(self.elements[i] - other.elements[i]) < tolerance for i in range(len(self)))

def produit_scalaire(v1, v2):
    """
    Calcule le produit scalaire de deux vecteurs.
    Dans un espace euclidien, c'est la somme des produits des composantes correspondantes.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la meme dimension pour le produit scalaire.")
    return sum(v1[i] * v2[i] for i in range(len(v1)))

def norme(v):
    """
    Calcule la norme euclidienne (L2) d'un vecteur.
    C'est la racine carree du produit scalaire du vecteur avec lui-meme.
    """
    return math.sqrt(produit_scalaire(v, v))

def distance(v1, v2):
    """
    Calcule la distance euclidienne entre deux vecteurs.
    C'est la norme de leur difference.
    """
    if len(v1) != len(v2):
        raise ValueError("Les vecteurs doivent avoir la meme dimension pour calculer la distance.")
    diff_vec = v1 - v2
    return norme(diff_vec)

```

## Partie 2 : Orthogonalisation de Gram-Schmidt

Le procédé de Gram-Schmidt est un algorithme qui prend un ensemble fini de vecteurs linéairement indépendants dans un espace de Hilbert et retourne un ensemble orthogonal de vecteurs qui engendrent le même sous-espace. Si en plus on normalise chaque vecteur, on obtient une base orthonormée.

### Exercice 2.1 : Implémentation de Gram-Schmidt

Implémentez la fonction `orthogonaliser_gram_schmidt` qui prend en entrée une liste de `Vecteur` et retourne une liste de `Vecteur` formant une base orthonormée.

```python
def orthogonaliser_gram_schmidt(vecteurs):
    """
    Applique le procede d'orthogonalisation de Gram-Schmidt a une liste de vecteurs
    lineairement independants pour produire une base orthonormee.
    """
    if not vecteurs:
        return []

    dimension = len(vecteurs[0])
    # Verifier que tous les vecteurs ont la meme dimension
    if not all(len(v) == dimension for v in vecteurs):
        raise ValueError("Tous les vecteurs doivent avoir la meme dimension.")

    base_orthonormee = []

    for v in vecteurs:
        u = v # Initialiser u avec le vecteur courant

        # Soustraire les projections sur les vecteurs deja orthogonalises
        # u = v - sum_{e_j in base_orthonormee} (<v, e_j> * e_j)
        for e in base_orthonormee:
            projection = produit_scalaire(v, e) * e
            u = u - projection

        # Normaliser le vecteur obtenu
        norme_u = norme(u)
        if norme_u < EPSILON:
            # Le vecteur u est proche du vecteur nul, ce qui signifie qu'il
            # est lineairement dependant des vecteurs precedents de la base.
            raise ValueError(f"Les vecteurs fournis ne sont pas lineairement independants. Vecteur: {v} est dependant.")

        e_i = u * (1.0 / norme_u) # Normalisation: e_i = u / ||u||
        base_orthonormee.append(e_i)

    return base_orthonormee

        assert abs(n - 1.0) < EPSILON, f"Assertion normalisation echouee pour e{i+1}: norme = {n}"
        print(f"  ||e{i+1}|| = {round(n, 4)} (OK)")
```

## Partie 3 : Décomposition sur une Base Orthonormée et Identité de Parseval

Une fois que nous avons une base orthonormée `(e1, e2, ..., en)` pour un espace de Hilbert, tout vecteur `v` dans cet espace peut être représenté comme une combinaison linéaire de ces vecteurs de base : `v = c1*e1 + c2*e2 + ... + cn*en`. Les coefficients `ci` sont appelés coefficients de Fourier et sont obtenus par projection : `ci = <v, ei>`.

L'identité de Parseval stipule que la norme au carré d'un vecteur est égale à la somme des carrés des modules de ses coefficients de Fourier : `||v||^2 = sum(|ci|^2)`. Cette identité est fondamentale car elle lie la "taille" du vecteur dans l'espace original à la "taille" de sa représentation numérique.

### Exercice 3.1 : Projection, Reconstruction et Vérification de Parseval

Implémentez les fonctions `projeter_sur_base_orthonormee`, `reconstruire_vecteur_depuis_base` et `verifier_identite_de_parseval`. Utilisez les assertions pour valider la correction de ces fonctions.

```python
def projeter_sur_base_orthonormee(vecteur, base_orthonormee):
    """
    Calcule les coefficients du vecteur dans la base orthonormee.
    Ces coefficients sont aussi appeles coefficients de Fourier.
    Chaque coefficient c_i est obtenu par le produit scalaire du vecteur
    avec le i-eme vecteur de la base: c_i = <vecteur, e_i>.
    """
    dimension_v = len(vecteur)
    if not base_orthonormee:
        return []

    dimension_base = len(base_orthonormee[0])
    if dimension_v != dimension_base:
        raise ValueError("Le vecteur et les vecteurs de la base doivent avoir la meme dimension.")

    coefficients = []
    for e_i in base_orthonormee:
        coeff = produit_scalaire(vecteur, e_i)
        coefficients.append(coeff)
    return coefficients

def reconstruire_vecteur_depuis_base(coefficients, base_orthonormee):
    """
    Reconstruit un vecteur a partir de ses coefficients et d'une base orthonormee.
    Le vecteur reconstruit est la somme ponderee: v_reconstruit = sum(c_i * e_i).
    """
    if not coefficients or not base_orthonormee:
        if base_orthonormee: # Si la base existe mais pas les coeffs
            return Vecteur([0.0] * len(base_orthonormee[0]))
        return Vecteur([]) # Si ni coeffs ni base (cas d'un espace de dim 0)

    if len(coefficients) != len(base_orthonormee):
        raise ValueError("Le nombre de coefficients doit correspondre au nombre de vecteurs dans la base.")

    dim = len(base_orthonormee[0])
    vecteur_reconstruit = Vecteur([0.0] * dim) # Initialisation avec un vecteur nul

    for i in range(len(coefficients)):
        vecteur_reconstruit = vecteur_reconstruit + (coefficients[i] * base_orthonormee[i])

    return vecteur_reconstruit

def verifier_identite_de_parseval(vecteur, coefficients):
    """
    Verifie l'identite de Parseval: ||v||^2 = sum(|c_i|^2).
    Retourne True si l'identite est verifiee a EPSILON pres, False sinon.
    """
    norme_carre_vecteur = norme(vecteur)**2
    somme_coeffs_carre = sum(c**2 for c in coefficients)

    return abs(norme_carre_vecteur - somme_coeffs_carre) < EPSILON

print("--- Partie 3: Decomposition sur une Base Orthonormee et Identite de Parseval ---")

# Utilisation de la base orthonormee generee par Gram-Schmidt precedemment
# (base_orthonormee_gs de la Partie 2)
v_original = Vecteur([2, 3, 5])
print(f"Vecteur original a decomposer: {v_original}")

# 1. Projeter le vecteur sur la base orthonormee pour obtenir les coefficients
coeffs = projeter_sur_base_orthonormee(v_original, base_orthonormee_gs)
print(f"Coefficients de Fourier (projections) du vecteur sur la base: {[round(c, 4) for c in coeffs]}")

# 2. Reconstruire le vecteur a partir des coefficients et de la base
v_reconstruit = reconstruire_vecteur_depuis_base(coeffs, base_orthonormee_gs)
print(f"Vecteur reconstruit depuis la base: {v_reconstruit}")

# Assertions
# Verification de la reconstruction: La distance entre le vecteur original
# et le vecteur reconstruit doit etre proche de zero.
dist_reconstruction = distance(v_original, v_reconstruit)
assert dist_reconstruction < EPSILON, f"Assertion reconstruction echouee: distance = {dist_reconstruction}"
print(f"Distance entre vecteur original et reconstruit: {dist_reconstruction:.6f} (attendue ~0) -> OK")

# Verification de l'identite de Parseval
parseval_ok = verifier_identite_de_parseval(v_original, coeffs)
assert parseval_ok, "Assertion Identite de Parseval echouee."
print(f"Identite de Parseval verifiee: {parseval_ok}")
print(f"  Norme carre du vecteur original: {norme(v_original)**2:.6f}")
print(f"  Somme des carres des coefficients: {sum(c**2 for c in coeffs):.6f}")

print("Tous les tests de la Partie 3 ont reussi avec succes.")
```
