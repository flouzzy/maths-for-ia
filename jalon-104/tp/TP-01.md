## Introduction

Dans le monde de l'ingénierie et de la science des données, les "espaces de Hilbert" sont des fondations mathématiques puissantes. Ce sont des espaces vectoriels complets munis d'un produit scalaire, permettant de définir des notions de distance et d'angle, essentielles pour de nombreuses applications allant du traitement du signal à la mécanique quantique, en passant par l'apprentissage automatique.

Ce Travail Pratique (TP) vise à explorer concrètement la numérisation des éléments d'un espace de Hilbert de dimension finie. Pour cela, nous allons nous appuyer sur le concept fondamental de "base orthonormée". Une base orthonormée nous permet de représenter n'importe quel élément de l'espace comme une combinaison linéaire unique de vecteurs de base, transformant ainsi des objets complexes (comme des fonctions) en des listes de coefficients numériques, facilitant leur traitement algorithmique.

Nous aborderons trois concepts clés :
1.  **Le produit scalaire et la norme** : Les outils qui définissent la géométrie de notre espace.
2.  **Le procédé d'orthonormalisation de Gram-Schmidt** : Une méthode algorithmique pour construire des bases orthonormées à partir d'une famille de vecteurs.
3.  **La décomposition sur une base orthonormée et l'identité de Parseval** : Comment représenter un vecteur par ses coefficients et la relation fondamentale entre la norme du vecteur et la somme des carrés de ses coefficients.

## Partie 1 : Vecteurs, Produit Scalaire et Norme

Dans un espace vectoriel réel de dimension finie (comme `R^n`), un vecteur peut être représenté par une liste de nombres. Le produit scalaire est une opération qui prend deux vecteurs et retourne un scalaire, généralisant la notion de projection. La norme d'un vecteur, dérivée du produit scalaire, représente sa "longueur".

### 1.1 Définitions et Implémentations Python

Commençons par définir les opérations de base sur les vecteurs.

```python
import math

# Constante pour les comparaisons de nombres flottants
EPSILON = 1e-9

def are_close(a, b, tol=EPSILON):
    """Vérifie si deux nombres flottants sont suffisamment proches."""
    return abs(a - b) < tol

def vector_add(v1, v2):
    """
    Additionne deux vecteurs.
    Ex: vector_add([1, 2], [3, 4]) -> [4, 6]
    """
    assert len(v1) == len(v2), "Les vecteurs doivent avoir la même dimension pour l'addition."
    return [v1[i] + v2[i] for i in range(len(v1))]

def scalar_multiply(scalar, v):
    """
    Multiplie un vecteur par un scalaire.
    Ex: scalar_multiply(2, [1, 2]) -> [2, 4]
    """
    return [scalar * x for x in v]

def dot_product(v1, v2):
    """
    Calcule le produit scalaire (produit interne) de deux vecteurs.
    Ex: dot_product([1, 2], [3, 4]) -> 1*3 + 2*4 = 11
    """
    assert len(v1) == len(v2), "Les vecteurs doivent avoir la même dimension pour le produit scalaire."
    return sum(v1[i] * v2[i] for i in range(len(v1)))

def vector_norm(v):
    """
    Calcule la norme euclidienne (longueur) d'un vecteur.
    Ex: vector_norm([3, 4]) -> sqrt(3^2 + 4^2) = 5.0
    """
    return math.sqrt(dot_product(v, v))

def normalize_vector(v):
    """
    Normalise un vecteur (le transforme en un vecteur unitaire).
    Un vecteur unitaire a une norme de 1.
    Ex: normalize_vector([3, 4]) -> [0.6, 0.8]
    """
    norm = vector_norm(v)
    assert norm > EPSILON, "Impossible de normaliser un vecteur nul."
    return scalar_multiply(1.0 / norm, v)

```

## Partie 2 : Procédé d'Orthonormalisation de Gram-Schmidt

Une "base orthonormée" est un ensemble de vecteurs mutuellement orthogonaux (leur produit scalaire est nul) et unitaires (leur norme est 1). Ces bases sont extrêmement utiles car elles simplifient grandement les calculs. Le procédé de Gram-Schmidt permet de transformer n'importe quelle base (ou plus généralement, un ensemble de vecteurs linéairement indépendants) en une base orthonormée.

Le procédé fonctionne comme suit :
1.  On prend le premier vecteur et on le normalise pour obtenir le premier vecteur de la base orthonormée.
2.  Pour chaque vecteur suivant, on soustrait ses projections sur tous les vecteurs orthonormés déjà construits. Cela rend le vecteur résultant orthogonal aux précédents.
3.  On normalise ce nouveau vecteur pour qu'il soit unitaire.

### 2.1 Implémentation de Gram-Schmidt

```python
def gram_schmidt(vectors):
    """
    Applique le procédé d'orthonormalisation de Gram-Schmidt à une liste de vecteurs.
    Les vecteurs d'entrée doivent être linéairement indépendants pour former une base complète.
    Retourne une liste de vecteurs formant une base orthonormée.
    """
    if not vectors:
        return []

    orthonormal_basis = []

    for v_in in vectors:
        v_current = list(v_in) # Copie du vecteur pour éviter les modifications in-place

        # Soustraire la projection de v_current sur chaque vecteur de base déjà orthonormalisé
        for u in orthonormal_basis:
            projection_scalar = dot_product(v_current, u)
            v_current = vector_add(v_current, scalar_multiply(-projection_scalar, u))

        # Vérifier si le vecteur résultant est significativement non-nul
        norm_v_current = vector_norm(v_current)
        if norm_v_current < EPSILON:
            # Le vecteur est linéairement dépendant des précédents, ou nul.
            # Pour une base complète, cela signifie que le vecteur d'entrée n'ajoute pas de nouvelle dimension.
            # Nous le sautons, mais dans d'autres contextes, cela pourrait être une erreur.
            print(f"Avertissement: Vecteur d'entrée '{v_in}' proche de zéro après orthogonalisation. Indique une dépendance linéaire avec les vecteurs précédents.")
            continue # Passe au vecteur suivant si le vecteur est nul après projection

        # Normaliser le vecteur pour qu'il soit unitaire
        u_new = normalize_vector(v_current)
        orthonormal_basis.append(u_new)

    return orthonormal_basis

```

## Partie 3 : Décomposition sur une Base Orthonormée et Identité de Parseval

Maintenant que nous savons construire une base orthonormée, nous pouvons utiliser cette base pour "numériser" n'importe quel vecteur de l'espace. La décomposition consiste à trouver les coefficients uniques qui permettent d'exprimer le vecteur comme une combinaison linéaire des vecteurs de base. Pour une base orthonormée `(u_1, u_2, ..., u_n)`, les coefficients sont simplement les produits scalaires du vecteur avec chaque vecteur de base : `c_i = <v, u_i>`.

L'**Identité de Parseval** est un théorème fondamental qui stipule que la norme au carré d'un vecteur est égale à la somme des carrés de ses coefficients de décomposition sur une base orthonormée. Cela signifie que la "longueur" d'un vecteur est préservée que l'on travaille avec le vecteur lui-même ou avec sa représentation par ses coefficients.

### 3.1 Implémentation de la Décomposition

```python
def decompose_on_basis(vector, orthonormal_basis):
    """
    Décompose un vecteur sur une base orthonormée.
    Retourne une liste des coefficients.
    """
    coeffs = []
    for u in orthonormal_basis:
        coeffs.append(dot_product(vector, u))
    return coeffs

def reconstruct_from_coeffs(coeffs, orthonormal_basis):
    """
    Reconstruit un vecteur à partir de ses coefficients et de la base orthonormée.
    """
    assert len(coeffs) == len(orthonormal_basis), "Le nombre de coefficients doit correspondre au nombre de vecteurs de base."
    if not coeffs:
        return []

    # Initialise un vecteur nul de la bonne dimension
    # Supposons que tous les vecteurs de la base ont la même dimension
    dim = len(orthonormal_basis[0])
    reconstructed_vec = [0.0] * dim

    for i in range(len(coeffs)):
        reconstructed_vec = vector_add(reconstructed_vec, scalar_multiply(coeffs[i], orthonormal_basis[i]))

    return reconstructed_vec

def check_parseval_identity(original_vector, coeffs):
    """
    Vérifie l'identité de Parseval.
    La norme au carré du vecteur original doit être égale à la somme des carrés des coefficients.
    """
    norm_squared_original = dot_product(original_vector, original_vector) # Ou vector_norm(original_vector)**2
    coeffs_squared_sum = sum(c*c for c in coeffs)

    return are_close(norm_squared_original, coeffs_squared_sum)

```
