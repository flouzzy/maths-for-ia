# TP 04 : Calcul de l'Indice de Jaccard

## Objectif Mathématique

Ce Travail Pratique vise à implémenter et à comprendre l'**Indice de Jaccard**, également connu sous le nom de Coefficient de Similarité de Jaccard. Cet indice est une mesure statistique utilisée pour évaluer la similarité entre deux ensembles d'échantillons et est largement utilisé en science des données, en bio-informatique, en traitement du langage naturel et dans de nombreux autres domaines.

Mathématiquement, l'Indice de Jaccard entre deux ensembles $A$ et $B$ est défini comme le rapport de la taille de leur intersection à la taille de leur union.

$$ J(A, B) = \frac{|A \cap B|}{|A \cup B|} $$

où :
*   $|A \cap B|$ représente la cardinalité (le nombre d'éléments) de l'intersection des ensembles $A$ et $B$. L'intersection contient les éléments communs aux deux ensembles.
*   $|A \cup B|$ représente la cardinalité de l'union des ensembles $A$ et $B$. L'union contient tous les éléments présents dans $A$, dans $B$, ou dans les deux, sans répétition.

La valeur de l'Indice de Jaccard est toujours un nombre réel compris entre 0 et 1, inclusivement : $0 \le J(A, B) \le 1$.
*   Une valeur de 1 indique que les deux ensembles sont identiques (ils contiennent exactement les mêmes éléments).
*   Une valeur de 0 indique que les deux ensembles sont disjoints (ils n'ont aucun élément en commun).
*   Une valeur intermédiaire reflète le degré de chevauchement entre les deux ensembles.

Le complément de l'Indice de Jaccard est la **Distance de Jaccard**, définie comme $D_J(A, B) = 1 - J(A, B)$. Elle mesure la dissemblance entre les ensembles.

## Implémentation en Python Pur

L'implémentation ci-dessous utilise les types `set` natifs de Python, qui sont optimisés pour les opérations ensemblistes comme l'intersection et l'union. Les fonctions sont conçues pour être robustes et gérer les cas limites, comme les ensembles vides.

```python
import collections

def jaccard_index(set_a: collections.abc.Iterable, set_b: collections.abc.Iterable) -> float:
    """
    Calcule l'Indice de Jaccard (ou Coefficient de Similarité de Jaccard) entre deux ensembles.

    L'Indice de Jaccard est défini comme le rapport de la taille de l'intersection
    des ensembles à la taille de leur union.

    J(A, B) = |A intersect B| / |A union B|

    Args:
        set_a (collections.abc.Iterable): Le premier ensemble d'éléments.
                                          Peut être une liste, un tuple, un set, etc.
        set_b (collections.abc.Iterable): Le second ensemble d'éléments.
                                          Peut être une liste, un tuple, un set, etc.

    Returns:
        float: La valeur de l'Indice de Jaccard, comprise entre 0.0 et 1.0.
               Retourne 1.0 si les deux ensembles sont vides (car ils sont parfaitement similaires).
               Retourne 0.0 si l'un des ensembles est vide et l'autre non (car ils n'ont rien en commun).
    """
    # Convertir les itérables en ensembles pour des opérations ensemblistes efficaces.
    # Cela gère également les doublons si les entrées sont des listes.
    s_a = set(set_a)
    s_b = set(set_b)

    # Calculer l'intersection des deux ensembles
    intersection = s_a.intersection(s_b)
    cardinality_intersection = len(intersection)

    # Calculer l'union des deux ensembles
    union = s_a.union(s_b)
    cardinality_union = len(union)

    # Gérer le cas où l'union est vide.
    # Si l'union est vide, cela signifie que les deux ensembles sont vides.
    # Dans ce cas, ils sont considérés comme parfaitement similaires, d'où un Jaccard de 1.0.
    if cardinality_union == 0:
        return 1.0

    # Calculer l'Indice de Jaccard
    jaccard = cardinality_intersection / cardinality_union

    return jaccard

def jaccard_distance(set_a: collections.abc.Iterable, set_b: collections.abc.Iterable) -> float:
    """
    Calcule la Distance de Jaccard entre deux ensembles.

    La Distance de Jaccard est définie comme 1 - J(A, B), où J(A, B) est l'Indice de Jaccard.

    Args:
        set_a (collections.abc.Iterable): Le premier ensemble d'éléments.
        set_b (collections.abc.Iterable): Le second ensemble d'éléments.

    Returns:
        float: La valeur de la Distance de Jaccard, comprise entre 0.0 et 1.0.
    """
    return 1.0 - jaccard_index(set_a, set_b)

```

## Validation et Assertions

Nous allons maintenant valider l'implémentation `jaccard_index` en utilisant des assertions pour vérifier les propriétés mathématiques fondamentales de l'Indice de Jaccard.

```python
# --- Cas de test et validations formelles ---

# 1. Ensembles identiques : J(A, A) = 1
A = {1, 2, 3}
B = {1, 2, 3}
assert jaccard_index(A, B) == 1.0, "Assertion échouée : Jaccard de deux ensembles identiques doit être 1."
print(f"Jaccard({A}, {B}) = {jaccard_index(A, B)} (Attendu: 1.0)")

# 2. Ensembles disjoints : J(A, B) = 0 si A intersect B = vide
C = {4, 5, 6}
assert jaccard_index(A, C) == 0.0, "Assertion échouée : Jaccard de deux ensembles disjoints doit être 0."
print(f"Jaccard({A}, {C}) = {jaccard_index(A, C)} (Attendu: 0.0)")

# 3. Ensembles partiellement chevauchants
D = {3, 4, 5}
# A = {1, 2, 3}, D = {3, 4, 5}
# Intersection = {3}, Cardinalité = 1
# Union = {1, 2, 3, 4, 5}, Cardinalité = 5
# Jaccard = 1/5 = 0.2
assert jaccard_index(A, D) == 0.2, "Assertion échouée : Jaccard pour ensembles partiellement chevauchants incorrect."
print(f"Jaccard({A}, {D}) = {jaccard_index(A, D)} (Attendu: 0.2)")

# 4. Un ensemble vide et un ensemble non vide : J(A, {}) = 0 si A non vide
E = set()
assert jaccard_index(A, E) == 0.0, "Assertion échouée : Jaccard entre un ensemble non vide et un ensemble vide doit être 0."
print(f"Jaccard({A}, {E}) = {jaccard_index(A, E)} (Attendu: 0.0)")

# 5. Deux ensembles vides : J({}, {}) = 1 (par convention, car ils sont parfaitement similaires)
assert jaccard_index(E, E) == 1.0, "Assertion échouée : Jaccard de deux ensembles vides doit être 1."
print(f"Jaccard({E}, {E}) = {jaccard_index(E, E)} (Attendu: 1.0)")

# 6. Propriété de symétrie : J(A, B) = J(B, A)
F = {1, 5, 7}
G = {1, 2, 5, 8}
j_fg = jaccard_index(F, G)
j_gf = jaccard_index(G, F)
assert j_fg == j_gf, "Assertion échouée : La propriété de symétrie J(A,B) = J(B,A) n'est pas respectée."
print(f"Jaccard({F}, {G}) = {j_fg}, Jaccard({G}, {F}) = {j_gf} (Attendu: égalité)")

# 7. Bornes de l'indice de Jaccard : 0 <= J(A, B) <= 1
# Nous avons déjà testé les cas 0 et 1. Vérifions qu'il ne dépasse pas ces bornes.
H = {1, 2, 3, 4, 5}
I = {3, 4, 5, 6, 7}
j_hi = jaccard_index(H, I)
assert 0 <= j_hi <= 1, "Assertion échouée : L'Indice de Jaccard doit être entre 0 et 1."
print(f"Jaccard({H}, {I}) = {j_hi} (Attendu: entre 0 et 1)")

# 8. Test avec des listes en entrée (vérifie la conversion en set)
list_a = [1, 2, 2, 3]
list_b = [2, 3, 3, 4]
# Après conversion en sets: s_a = {1, 2, 3}, s_b = {2, 3, 4}
# Intersection = {2, 3}, Cardinalité = 2
# Union = {1, 2, 3, 4}, Cardinalité = 4
# Jaccard = 2/4 = 0.5
assert jaccard_index(list_a, list_b) == 0.5, "Assertion échouée : Jaccard avec listes en entrée incorrect."
print(f"Jaccard({list_a}, {list_b}) = {jaccard_index(list_a, list_b)} (Attendu: 0.5)")

# 9. Validation de la Distance de Jaccard
# D_J(A, B) = 1 - J(A, B)
distance_ad = jaccard_distance(A, D)
assert distance_ad == (1 - jaccard_index(A, D)), "Assertion échouée : La Distance de Jaccard est incorrecte."
print(f"Distance de Jaccard({A}, {D}) = {distance_ad} (Attendu: {1 - jaccard_index(A, D)})")

print("\nToutes les assertions mathématiques ont été vérifiées avec succès.")

```

## Analyse de Complexité

L'analyse de complexité de l'implémentation de l'Indice de Jaccard repose principalement sur les opérations ensemblistes de Python. Soient $N_A = |A|$ et $N_B = |B|$ les cardinalités des ensembles d'entrée.

### Complexité Temporelle

1.  **Conversion en `set` :**
    *   `s_a = set(set_a)` : La conversion d'un itérable de $N_A$ éléments en un `set` prend en moyenne $O(N_A)$ temps. Dans le pire des cas (collisions de hachage fréquentes), cela peut être $O(N_A^2)$, mais c'est rare avec de bons algorithmes de hachage.
    *   `s_b = set(set_b)` : Similairement, $O(N_B)$ temps.
    *   Coût total pour la conversion : $O(N_A + N_B)$.

2.  **Opération d'intersection (`intersection`) :**
    *   `s_a.intersection(s_b)` : Cette opération itère sur les éléments du plus petit ensemble et vérifie leur présence dans le plus grand ensemble (qui est un `set` et permet des recherches en $O(1)$ en moyenne).
    *   La complexité moyenne est $O(\min(N_A, N_B))$.

3.  **Opération d'union (`union`) :**
    *   `s_a.union(s_b)` : Cette opération construit un nouvel ensemble contenant tous les éléments des deux ensembles. Elle itère sur tous les éléments des deux ensembles et les ajoute au nouvel ensemble.
    *   La complexité moyenne est $O(N_A + N_B)$.

4.  **Calcul des cardinalités (`len`) et division :**
    *   Ces opérations sont $O(1)$ car les `set` en Python stockent leur taille.

En combinant ces étapes, la complexité temporelle dominante est celle de la conversion en `set` et des opérations d'union/intersection.
La complexité temporelle totale moyenne est donc $O(N_A + N_B)$.

### Complexité Spatiale

1.  **Stockage des ensembles convertis (`s_a`, `s_b`) :**
    *   `s_a` occupe $O(N_A)$ espace.
    *   `s_b` occupe $O(N_B)$ espace.

2.  **Stockage de l'intersection (`intersection`) :**
    *   L'ensemble `intersection` peut contenir au maximum $\min(N_A, N_B)$ éléments.
    *   Espace occupé : $O(\min(N_A, N_B))$.

3.  **Stockage de l'union (`union`) :**
    *   L'ensemble `union` peut contenir au maximum $N_A + N_B$ éléments (si les ensembles sont disjoints).
    *   Espace occupé : $O(N_A + N_B)$.

La complexité spatiale totale est dominée par le stockage de l'union et des ensembles d'entrée.
La complexité spatiale totale moyenne est donc $O(N_A + N_B)$.

Ces complexités sont optimales pour ce type de problème, car il est nécessaire de "toucher" chaque élément des deux ensembles au moins une fois pour calculer l'union et l'intersection. L'utilisation des `set` natifs de Python garantit cette efficacité grâce à l'implémentation sous-jacente des tables de hachage.
