# TP 4 : Relations Binaires et Fonctions Ensemblistes

## Objectif Mathématique
Ce TP vise à implémenter la représentation et la manipulation de relations binaires, ainsi qu'à déterminer si une relation donnée est une fonction. En théorie des ensembles (ZFC), une relation binaire $R$ entre deux ensembles $A$ et $B$ est définie comme un sous-ensemble du produit cartésien $A \times B$. Une fonction $f: A \to B$ est un type spécial de relation qui satisfait deux conditions : la totalité (chaque élément de $A$ a une image) et l'unicité (chaque élément de $A$ a exactement une image). Nous allons implémenter le calcul du domaine et de l'image d'une relation, et vérifier ces propriétés pour identifier une fonction.

## Implémentation Python
```python
from typing import Any, List, Tuple

# --- Fonctions utilitaires pour manipuler les listes comme des ensembles ---
def _to_set_list(collection: List[Any]) -> List[Any]:
    """
    Convertit une liste en une "liste-ensemble" : contient uniquement des éléments uniques,
    triés pour une comparaison cohérente. Cela simule un ensemble mathématique
    en utilisant une liste Python.

    Args:
        collection: La liste d'éléments à convertir.

    Returns:
        Une nouvelle liste contenant les éléments uniques de la collection, triés.
    """
    # Utilise le type `set` intégré de Python pour un filtrage efficace des éléments uniques,
    # puis reconvertit en liste et trie pour garantir un ordre cohérent lors de la comparaison.
    unique_elements = list(set(collection))
    unique_elements.sort()
    return unique_elements

def _are_equal_sets_list(list1: List[Any], list2: List[Any]) -> bool:
    """
    Vérifie si deux listes représentent le même ensemble mathématique (ignorant l'ordre et les doublons).

    Args:
        list1: La première liste (représentant un ensemble).
        list2: La deuxième liste (représentant un ensemble).

    Returns:
        True si les deux listes représentent le même ensemble, False sinon.
    """
    return _to_set_list(list1) == _to_set_list(list2)

def _is_subset(subset_candidate: List[Any], superset_candidate: List[Any]) -> bool:
    """
    Vérifie si une liste (représentant un ensemble) est un sous-ensemble d'une autre.

    Args:
        subset_candidate: La liste potentiellement sous-ensemble.
        superset_candidate: La liste potentiellement sur-ensemble.

    Returns:
        True si subset_candidate est un sous-ensemble de superset_candidate, False sinon.
    """
    set_subset = set(subset_candidate)
    set_superset = set(superset_candidate)
    return set_subset.issubset(set_superset)


# --- Fonctions principales pour les Relations et Fonctions ---

def domain(relation: List[Tuple[Any, Any]]) -> List[Any]:
    """
    Calcule le domaine d'une relation binaire.
    Le domaine d'une relation R est l'ensemble de tous les premiers éléments des paires ordonnées de R.
    Formellement, pour R ⊆ A × B, Dom(R) = {a ∈ A | ∃ b ∈ B tel que (a,b) ∈ R}.

    Args:
        relation: Une liste de tuples, où chaque tuple (a, b) représente une paire ordonnée
                  dans la relation. Les listes sont utilisées pour représenter des ensembles
                  selon les contraintes du TP.

    Returns:
        Une liste d'éléments uniques représentant le domaine de la relation.

    Raises:
        TypeError: Si 'relation' n'est pas une liste.
        ValueError: Si un élément de 'relation' n'est pas un tuple de 2 éléments.
    """
    if not isinstance(relation, list):
        raise TypeError("La relation doit être une liste de tuples.")

    first_elements = []
    for pair in relation:
        if not isinstance(pair, tuple) or len(pair) != 2:
            raise ValueError(f"Chaque élément de la relation doit être un tuple de 2: {pair} n'est pas valide.")
        first_elements.append(pair[0])

    return _to_set_list(first_elements)

def image(relation: List[Tuple[Any, Any]]) -> List[Any]:
    """
    Calcule l'image (ou la portée/range) d'une relation binaire.
    L'image d'une relation R est l'ensemble de tous les seconds éléments des paires ordonnées de R.
    Formellement, pour R ⊆ A × B, Im(R) = {b ∈ B | ∃ a ∈ A tel que (a,b) ∈ R}.

    Args:
        relation: Une liste de tuples, où chaque tuple (a, b) représente une paire ordonnée
                  dans la relation.

    Returns:
        Une liste d'éléments uniques représentant l'image de la relation.

    Raises:
        TypeError: Si 'relation' n'est pas une liste.
        ValueError: Si un élément de 'relation' n'est pas un tuple de 2 éléments.
    """
    if not isinstance(relation, list):
        raise TypeError("La relation doit être une liste de tuples.")

    second_elements = []
    for pair in relation:
        if not isinstance(pair, tuple) or len(pair) != 2:
            raise ValueError(f"Chaque élément de la relation doit être un tuple de 2: {pair} n'est pas valide.")
        second_elements.append(pair[1])

    return _to_set_list(second_elements)

def is_function(
    relation: List[Tuple[Any, Any]],
    domain_set_A: List[Any],
    codomain_set_B: List[Any]
) -> bool:
    """
    Détermine si une relation binaire R est une fonction de l'ensemble A vers l'ensemble B.
    Une relation R ⊆ A × B est une fonction f: A → B si et seulement si deux conditions sont remplies :
    1.  **Totalité (Existence)**: Chaque élément de l'ensemble de départ A est le premier élément d'exactement une paire dans R.
        Formellement, pour tout a ∈ A, il existe un b ∈ B tel que (a,b) ∈ R.
        Cela implique que le domaine de R est égal à A.
    2.  **Unicité**: Pour tout a ∈ A, si (a,b1) ∈ R et (a,b2) ∈ R, alors b1 = b2.
        Cela signifie qu'aucun élément de A n'est le premier élément de plus d'une paire dans R.

    Args:
        relation: La relation binaire, représentée comme une liste de paires ordonnées (tuples).
        domain_set_A: L'ensemble de départ (domaine mathématique) A, représenté comme une liste.
        codomain_set_B: L'ensemble d'arrivée (codomaine) B, représenté comme une liste.

    Returns:
        True si la relation est une fonction de A vers B, False sinon.

    Raises:
        TypeError: Si 'relation', 'domain_set_A' ou 'codomain_set_B' ne sont pas des listes.
    """
    if not isinstance(relation, list) or not isinstance(domain_set_A, list) or not isinstance(codomain_set_B, list):
        raise TypeError("Les arguments relation, domain_set_A et codomain_set_B doivent être des listes.")

    # Convertit les entrées en "listes-ensembles" pour une comparaison cohérente et l'unicité.
    A_set = _to_set_list(domain_set_A)
    B_set = _to_set_list(codomain_set_B)

    # Si l'ensemble de départ A est vide, la seule fonction possible est la relation vide.
    if not A_set:
        return not relation # Si A est vide, la relation doit aussi être vide pour être une fonction.

    # Pré-vérification: Toutes les paires de la relation doivent être dans A x B.
    # C'est-à-dire, le premier élément de chaque paire doit être dans A, et le second dans B.
    for pair in relation:
        if not isinstance(pair, tuple) or len(pair) != 2:
            raise ValueError(f"Chaque élément de la relation doit être un tuple de 2: {pair} n'est pas valide.")
        x, y = pair
        if x not in A_set or y not in B_set:
            # La relation contient des paires dont les éléments sont en dehors de A ou B.
            # Ainsi, elle ne peut pas être une fonction de A vers B.
            return False

    # Condition 1: Totalité (Existence)
    # Chaque élément de A doit être le premier élément d'au moins une paire dans R.
    # Ceci est équivalent à vérifier que le domaine de la relation est égal à l'ensemble A.
    if not _are_equal_sets_list(domain(relation), A_set):
        return False

    # Condition 2: Unicité
    # Aucun élément de A ne peut être mappé à plus d'un élément de B.
    # Nous vérifions cela en gardant une trace des premiers éléments déjà vus.
    seen_first_elements = set()
    for pair in relation:
        x_val = pair[0]
        if x_val in seen_first_elements:
            # Trouvé un premier élément qui apparaît plus d'une fois, viole l'unicité.
            return False
        seen_first_elements.add(x_val)

    # Si les deux conditions passent, c'est une fonction.
    return True
