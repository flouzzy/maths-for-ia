# TP 4 : Relations Binaires et Fonctions Ensemblistes

## Objectif Mathématique
Ce TP vise à implémenter la représentation et la manipulation de relations binaires, ainsi qu'à déterminer si une relation donnée est une fonction. En théorie des ensembles (ZFC), une relation binaire $R$ entre deux ensembles $A$ et $B$ est définie comme un sous-ensemble du produit cartésien $A \times B$. Une fonction $f: A \to B$ est un type spécial de relation qui satisfait deux conditions : la totalité (chaque élément de $A$ a une image) et l'unicité (chaque élément de $A$ a exactement une image). Nous allons implémenter le calcul du domaine et de l'image d'une relation, et vérifier ces propriétés pour identifier une fonction.

from typing import Any, List, Tuple

# --- Fonctions utilitaires pour manipuler les listes comme des ensembles ---
def _to_set_list(collection: List[Any]) -> List[Any]:
    unique_elements = []
    for item in collection:
        if item not in unique_elements:
            unique_elements.append(item)
    return unique_elements

def _are_equal_sets_list(list1: List[Any], list2: List[Any]) -> bool:
    if len(list1) != len(list2):
        return False
    for item in list1:
        if item not in list2:
            return False
    return True
