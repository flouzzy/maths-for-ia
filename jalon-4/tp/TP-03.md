# TP 3 : Produit Cartésien de deux Ensembles

## Objectif Mathématique
Le produit cartésien de deux ensembles $A$ et $B$, noté $A \times B$, est l'ensemble de toutes les paires ordonnées $(a, b)$ telles que $a$ appartient à $A$ et $b$ appartient à $B$.
Formellement, il est défini comme :
$A \times B = \{ (a,b) \mid a \in A \text{ et } b \in B \}$

La cardinalité du produit cartésien de deux ensembles finis est le produit de leurs cardinalités : $|A \times B| = |A| \times |B|$.

L'objectif de ce TP est d'implémenter une fonction Python qui calcule le produit cartésien de deux listes. Ces listes sont traitées comme des représentations d'ensembles, ce qui implique que leurs éléments doivent être uniques pour une conformité mathématique stricte. La fonction retournera une liste de tuples représentant les paires ordonnées du produit cartésien.

## Implémentation Python
```python
from typing import Any, List, Tuple

def cartesian_product(set_A: List[Any], set_B: List[Any]) -> List[Tuple[Any, Any]]:
    """
    Calcule le produit cartésien de deux ensembles représentés par des listes.

    Le produit cartésien A x B est l'ensemble de toutes les paires ordonnées (a, b)
    telles que a appartient à A et b appartient à B.

    Les listes d'entrée `set_A` et `set_B` sont traitées comme des ensembles.
    Pour une conformité stricte avec la définition des ensembles en mathématiques,
    il est recommandé que les listes d'entrée contiennent des éléments uniques.
    Si des doublons sont présents dans les listes d'entrée, la fonction les
    traitera comme des éléments distincts lors de la formation des paires, ce qui
    reflétera un "produit de listes" plutôt qu'un "produit d'ensembles" strict.

    Args:
        set_A: Une liste d'éléments représentant l'ensemble A.
        set_B: Une liste d'éléments représentant l'ensemble B.

    Returns:
        Une liste de tuples, où chaque tuple `(a, b)` représente une paire ordonnée
        du produit cartésien A x B. L'ordre des tuples dans la liste résultante
        peut varier, mais l'ensemble des tuples doit être le même.

    Examples:
        >>> cartesian_product([1, 2], ['a', 'b'])
        [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]
    """
    result: List[Tuple[Any, Any]] = []
    for element_a in set_A:
        for element_b in set_B:
            result.append((element_a, element_b))
    return result

# --- Fonctions auxiliaires pour les tests (non une partie de l'implémentation du TP) ---

def _to_set_list(input_list: List[Any]) -> List[Any]:
    """
    Convertit une liste en une liste "semblable à un ensemble", supprimant les doublons
    tout en préservant l'ordre de la première apparition.
    Utile pour préparer des entrées de test qui représentent strictement des ensembles.
    """
    seen = set()
    result = []
    for item in input_list:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result
