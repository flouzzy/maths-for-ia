# TP 2 : Génération de l'Ensemble des Parties (Puissance)

## Objectif Mathématique
Ce TP vise à implémenter la fonction qui génère l'ensemble des parties $\mathcal{P}(E)$ pour un ensemble fini $E$.
L'ensemble des parties d'un ensemble $E$, noté $\mathcal{P}(E)$ (ou $2^E$), est l'ensemble de tous les sous-ensembles possibles de $E$, y compris l'ensemble vide $\emptyset$ et l'ensemble $E$ lui-même.
Si un ensemble $E$ a $n$ éléments (c'est-à-dire, $|E|=n$), alors son ensemble des parties $\mathcal{P}(E)$ contiendra $2^n$ sous-ensembles (c'est-à-dire, $|\mathcal{P}(E)|=2^n$).
Par exemple, si $E = \{a, b\}$, alors $\mathcal{P}(E) = \{\emptyset, \{a\}, \{b\}, \{a, b\}\}$.

L'implémentation utilisera une approche basée sur la manipulation de bits pour générer systématiquement tous les $2^n$ sous-ensembles. Chaque entier de $0$ à $2^n-1$ peut être vu comme un "masque" de bits, où le $j$-ième bit indique si le $j$-ième élément de l'ensemble original doit être inclus dans le sous-ensemble courant.

## Implémentation Python
```python
from typing import Any, List, Set

def generate_power_set(elements: List[Any]) -> List[List[Any]]:
    """
    Génère l'ensemble des parties (power set) d'un ensemble donné.

    L'ensemble des parties d'un ensemble E est l'ensemble de tous les sous-ensembles
    possibles de E, y compris l'ensemble vide et l'ensemble E lui-même.
    Si |E| = n, alors |P(E)| = 2^n.

    L'implémentation traite la liste d'entrée comme une représentation d'un ensemble
    mathématique, éliminant d'abord les doublons et triant les éléments pour
    assurer une génération canonique et reproductible des sous-ensembles.

    Args:
        elements: Une liste d'éléments représentant l'ensemble d'entrée E.
                  Les doublons seront ignorés, et l'ordre des éléments sera
                  standardisé (trié) pour la génération des sous-ensembles.
                  Les éléments doivent être hashables (pour `set`) et comparables
                  (pour `sorted`).

    Returns:
        Une liste de listes, où chaque liste interne est un sous-ensemble de E.
        Les sous-ensembles sont eux-mêmes triés pour la cohérence, et l'ordre
        des sous-ensembles dans la liste résultante est déterminé par l'algorithme
        de manipulation de bits, puis par un tri final pour la cohérence des tests.

    Exemple:
        >>> generate_power_set([1, 2])
        [[], [1], [2], [1, 2]]
    """
    # Éliminer les doublons et trier les éléments pour obtenir une représentation
    # canonique de l'ensemble, ce qui garantit un comportement prévisible
    # des assertions et correspond mieux à la notion mathématique d'ensemble.
    # Les éléments doivent être hashables pour `set()` et comparables pour `sorted()`.
    try:
        unique_sorted_elements: List[Any] = sorted(list(set(elements)))
    except TypeError as e:
        raise TypeError(f"Les éléments de l'ensemble doivent être hashables et comparables: {e}")

    n: int = len(unique_sorted_elements)

    # Le nombre total de sous-ensembles est 2^n
    num_subsets: int = 1 << n  # Équivalent à 2**n, utilisant l'opérateur de décalage de bits

    power_set: List[List[Any]] = []

    # Itérer de 0 à 2^n - 1. Chaque entier 'i' représente un masque de bits
    # qui correspond à un sous-ensemble unique.
    for i in range(num_subsets):
        current_subset: List[Any] = []
        # Pour chaque bit dans 'i' (de 0 à n-1)
        for j in range(n):
            # Si le j-ième bit de 'i' est défini (c'est-à-dire 1)
            if (i >> j) & 1:
                # Ajouter le j-ième élément de l'ensemble unique et trié
                # au sous-ensemble courant.
                current_subset.append(unique_sorted_elements[j])

        # Ajouter le sous-ensemble généré à la liste de tous les sous-ensembles
        power_set.append(current_subset)

    # Pour garantir un ordre reproductible des sous-ensembles pour les assertions
    # et une présentation cohérente, nous trions la liste finale des sous-ensembles.
    # Le tri se fait d'abord par la taille du sous-ensemble, puis lexicographiquement
    # par le contenu (représenté comme un tuple).
    power_set.sort(key=lambda s: (len(s), tuple(s)))

    return power_set

# --- Assertions de validation (tests unitaires mathématiques) ---

# Fonction utilitaire pour comparer les ensembles de listes de manière agnostique à l'ordre
def assert_power_sets_equal(actual: List[List[Any]], expected: List[List[Any]], message: str = "") -> None:
    """
    Vérifie si deux listes de listes (représentant des ensembles de sous-ensembles)
    sont équivalentes, indépendamment de l'ordre des sous-ensembles ou des éléments
    à l'intérieur de chaque sous-ensemble.

    Args:
        actual: La liste de listes obtenue de la fonction `generate_power_set`.
        expected: La liste de listes attendue.
        message: Un message optionnel à afficher en cas d'échec.
    """
    # Convertir chaque sous-ensemble en un tuple trié pour la comparaison canonique.
    # Convertir l'ensemble de sous-ensembles en un set de tuples triés pour ignorer l'ordre global.
    normalized_actual: Set[tuple[Any, ...]] = {tuple(sorted(sub)) for sub in actual}
    normalized_expected: Set[tuple[Any, ...]] = {tuple(sorted(sub)) for sub in expected}

    assert normalized_actual == normalized_expected, message + f"\nAttendu (normalisé): {normalized_expected}\nObtenu (normalisé): {normalized_actual}"

    # Vérifier aussi la taille pour s'assurer qu'il n'y a pas de doublons inattendus ou manquants
    assert len(actual) == len(expected), f"Nombre de sous-ensembles incorrect. Attendu: {len(expected)}, Obtenu: {len(actual)}"
