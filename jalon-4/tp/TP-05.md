# TP 05 : Différence symétrique et propriétés algébriques

## Objectif Mathématique
Ce Travail Pratique (TP) explore la **différence symétrique** de deux ensembles, une opération fondamentale en théorie des ensembles avec des propriétés algébriques riches. Nous allons implémenter cette opération et d'autres opérations ensemblistes de base (union, intersection, différence) en Python pur, puis valider formellement leurs propriétés mathématiques à l'aide d'assertions.

La différence symétrique de deux ensembles $A$ et $B$, notée $A \Delta B$, est l'ensemble des éléments qui appartiennent à $A$ ou à $B$, mais pas aux deux simultanément. Elle peut être définie de deux manières équivalentes :
1.  $A \Delta B = (A \setminus B) \cup (B \setminus A)$
2.  $A \Delta B = (A \cup B) \setminus (A \cap B)$

Ces définitions mettent en lumière le caractère "exclusif" de l'appartenance à l'un ou l'autre ensemble.

Les propriétés algébriques de la différence symétrique sont particulièrement intéressantes :
*   **Commutativité** : $A \Delta B = B \Delta A$
*   **Associativité** : $(A \Delta B) \Delta C = A \Delta (B \Delta C)$
*   **Élément neutre** : $A \Delta \emptyset = A$, où $\emptyset$ est l'ensemble vide.
*   **Élément inverse** : $A \Delta A = \emptyset$, chaque ensemble est son propre inverse pour la différence symétrique.
*   **Distributivité de l'intersection sur la différence symétrique** : $A \cap (B \Delta C) = (A \cap B) \Delta (A \cap C)$. Cette propriété est cruciale car elle montre que l'ensemble des parties d'un ensemble universel $U$, $\mathcal{P}(U)$, muni de la différence symétrique ($\Delta$) et de l'intersection ($\cap$), forme un anneau de Boole.

Nous allons implémenter ces opérations en utilisant des listes Python pour représenter les ensembles, en veillant à ce que les résultats soient des listes d'éléments uniques et triés pour une représentation canonique des ensembles.

## Implémentation en Python Pur
L'implémentation ci-dessous utilise des listes pour représenter les ensembles. Pour garantir l'unicité des éléments et faciliter les comparaisons, toutes les fonctions normalisent leurs entrées et produisent des sorties sous forme de listes triées d'éléments uniques. Les opérations `union`, `intersection`, et `difference` sont implémentées en utilisant une approche de fusion similaire à celle utilisée dans l'algorithme de tri fusion, ce qui est efficace pour des listes triées.

```python
import itertools

def _normalize_set_input(s_list):
    """
    Normalise une liste pour qu'elle représente un ensemble :
    éléments uniques et triés.
    Utilise le type `set` de Python pour l'unicité, puis trie la liste résultante.
    """
    if not isinstance(s_list, list):
        raise TypeError("L'entrée doit être une liste.")
    return sorted(list(set(s_list)))

def union(A, B):
    """
    Calcule l'union de deux ensembles A et B.
    A et B sont des listes d'éléments.
    Retourne une nouvelle liste représentant l'union, avec des éléments uniques et triés.
    Complexité temporelle: O(N log N + M log M) pour la normalisation, puis O(N+M) pour la fusion.
    """
    A_norm = _normalize_set_input(A)
    B_norm = _normalize_set_input(B)

    result = []
    ptr_a, ptr_b = 0, 0

    while ptr_a < len(A_norm) and ptr_b < len(B_norm):
        if A_norm[ptr_a] < B_norm[ptr_b]:
            result.append(A_norm[ptr_a])
            ptr_a += 1
        elif B_norm[ptr_b] < A_norm[ptr_a]:
            result.append(B_norm[ptr_b])
            ptr_b += 1
        else: # Les éléments sont égaux, ajouter un et avancer les deux pointeurs
            result.append(A_norm[ptr_a])
            ptr_a += 1
            ptr_b += 1

    # Ajouter les éléments restants de A (s'il y en a)
    while ptr_a < len(A_norm):
        result.append(A_norm[ptr_a])
        ptr_a += 1

    # Ajouter les éléments restants de B (s'il y en a)
    while ptr_b < len(B_norm):
        result.append(B_norm[ptr_b])
        ptr_b += 1

    return result

def intersection(A, B):
    """
    Calcule l'intersection de deux ensembles A et B.
    A et B sont des listes d'éléments.
    Retourne une nouvelle liste représentant l'intersection, avec des éléments uniques et triés.
    Complexité temporelle: O(N log N + M log M) pour la normalisation, puis O(N+M) pour la fusion.
    """
    A_norm = _normalize_set_input(A)
    B_norm = _normalize_set_input(B)

    result = []
    ptr_a, ptr_b = 0, 0

    while ptr_a < len(A_norm) and ptr_b < len(B_norm):
        if A_norm[ptr_a] < B_norm[ptr_b]:
            ptr_a += 1
        elif B_norm[ptr_b] < A_norm[ptr_a]:
            ptr_b += 1
        else: # Les éléments sont égaux, ajouter au résultat et avancer les deux pointeurs
            result.append(A_norm[ptr_a])
            ptr_a += 1
            ptr_b += 1

    return result

def difference(A, B):
    """
    Calcule la différence ensembliste A \ B (éléments dans A mais pas dans B).
    A et B sont des listes d'éléments.
    Retourne une nouvelle liste représentant la différence, avec des éléments uniques et triés.
    Complexité temporelle: O(N log N + M log M) pour la normalisation, puis O(N+M) pour la fusion.
    """
    A_norm = _normalize_set_input(A)
    B_norm = _normalize_set_input(B)

    result = []
    ptr_a, ptr_b = 0, 0

    while ptr_a < len(A_norm) and ptr_b < len(B_norm):
        if A_norm[ptr_a] < B_norm[ptr_b]:
            result.append(A_norm[ptr_a])
            ptr_a += 1
        elif B_norm[ptr_b] < A_norm[ptr_a]:
            ptr_b += 1 # Élément dans B mais pas dans A, ignorer l'élément de B
        else: # Les éléments sont égaux, ignorer les deux (l'élément est dans B, donc pas dans A \ B)
            ptr_a += 1
            ptr_b += 1

    # Ajouter les éléments restants de A (s'il y en a), car ils ne peuvent pas être dans B
    while ptr_a < len(A_norm):
        result.append(A_norm[ptr_a])
        ptr_a += 1

    return result

def symmetric_difference(A, B):
    """
    Calcule la différence symétrique de deux ensembles A et B.
    A et B sont des listes d'éléments.
    Retourne une nouvelle liste représentant la différence symétrique, avec des éléments uniques et triés.
    Implémentée en utilisant la définition: (A \ B) U (B \ A).
    Complexité temporelle: O(N log N + M log M) pour la normalisation et les opérations sous-jacentes.
    """
    diff_ab = difference(A, B)
    diff_ba = difference(B, A)
    return union(diff_ab, diff_ba)

```

## Validation et Assertions
Nous allons maintenant valider les propriétés mathématiques de la différence symétrique à l'aide d'exemples concrets et d'assertions.

```python
# Définition des ensembles de test
A = [1, 2, 3, 4]
B = [3, 4, 5, 6]
C = [2, 4, 6, 8]
empty_set = []
print(f"Ensemble A: {A}")
print(f"Ensemble B: {B}")
print(f"Ensemble C: {C}")
print(f"Ensemble vide: {empty_set}\n")

# --- Test des définitions équivalentes de la différence symétrique ---
print("--- Test des définitions équivalentes ---")
# Définition 1: A Delta B = (A \ B) U (B \ A)
sym_diff_def1 = union(difference(A, B), difference(B, A))
print(f"A \\ B = {difference(A, B)}")
print(f"B \\ A = {difference(B, A)}")
print(f"(A \\ B) U (B \\ A) = {sym_diff_def1}")

# Définition 2: A Delta B = (A U B) \ (A I B)
sym_diff_def2 = difference(union(A, B), intersection(A, B))
print(f"A U B = {union(A, B)}")
print(f"A I B = {intersection(A, B)}")
print(f"(A U B) \\ (A I B) = {sym_diff_def2}")

# La différence symétrique calculée par notre fonction principale
sym_diff_func = symmetric_difference(A, B)
print(f"symmetric_difference(A, B) = {sym_diff_func}")

# Assertion: Les deux définitions doivent être équivalentes et correspondre à la fonction implémentée.
assert sym_diff_def1 == sym_diff_def2, "Les deux définitions de la différence symétrique ne sont pas équivalentes."
assert sym_diff_def1 == sym_diff_func, "La fonction symmetric_difference ne correspond pas à la définition 1."
assert sym_diff_def2 == sym_diff_func, "La fonction symmetric_difference ne correspond pas à la définition 2."
print("Assertions des définitions équivalentes passées avec succès.\n")


# --- Test des propriétés algébriques ---
print("--- Test des propriétés algébriques ---")

# 1. Commutativité: A Delta B = B Delta A
sd_ab = symmetric_difference(A, B)
sd_ba = symmetric_difference(B, A)
print(f"A Delta B = {sd_ab}")
print(f"B Delta A = {sd_ba}")
assert sd_ab == sd_ba, "La propriété de commutativité n'est pas respectée."
print("Assertion de commutativité passée avec succès.\n")

# 2. Associativité: (A Delta B) Delta C = A Delta (B Delta C)
sd_ab_c = symmetric_difference(symmetric_difference(A, B), C)
sd_a_bc = symmetric_difference(A, symmetric_difference(B, C))
print(f"(A Delta B) Delta C = {sd_ab_c}")
print(f"A Delta (B Delta C) = {sd_a_bc}")
assert sd_ab_c == sd_a_bc, "La propriété d'associativité n'est pas respectée."
print("Assertion d'associativité passée avec succès.\n")

# 3. Élément neutre: A Delta ∅ = A
sd_a_empty = symmetric_difference(A, empty_set)
print(f"A Delta ∅ = {sd_a_empty}")
assert sd_a_empty == _normalize_set_input(A), "La propriété de l'élément neutre (ensemble vide) n'est pas respectée."
print("Assertion de l'élément neutre passée avec succès.\n")

# 4. Élément inverse: A Delta A = ∅
sd_a_a = symmetric_difference(A, A)
print(f"A Delta A = {sd_a_a}")
assert sd_a_a == empty_set, "La propriété de l'élément inverse (chaque ensemble est son propre inverse) n'est pas respectée."
print("Assertion de l'élément inverse passée avec succès.\n")

# 5. Distributivité de l'intersection sur la différence symétrique: A ∩ (B Δ C) = (A ∩ B) Δ (A ∩ C)
lhs = intersection(A, symmetric_difference(B, C)) # Left Hand Side
rhs = symmetric_difference(intersection(A, B), intersection(A, C)) # Right Hand Side
print(f"B Delta C = {symmetric_difference(B, C)}")
print(f"A ∩ (B Delta C) = {lhs}")
print(f"A ∩ B = {intersection(A, B)}")
print(f"A ∩ C = {intersection(A, C)}")
print(f"(A ∩ B) Delta (A ∩ C) = {rhs}")
assert lhs == rhs, "La propriété de distributivité de l'intersection sur la différence symétrique n'est pas respectée."
print("Assertion de distributivité passée avec succès.\n")

print("\nToutes les assertions mathématiques ont été vérifiées avec succès !")

```

## Analyse de Complexité
L'analyse de complexité de nos fonctions repose sur l'utilisation de listes triées pour représenter les ensembles.

1.  **`_normalize_set_input(s_list)`** :
    *   Conversion en `set()` : En moyenne, $O(N)$ où $N$ est la longueur de `s_list`. Dans le pire des cas (collisions de hachage), cela peut être $O(N^2)$, mais c'est rare pour les types de données standard.
    *   Conversion en `list()` : $O(N)$.
    *   `sorted()` : $O(N \log N)$.
    *   **Complexité temporelle totale** : $O(N \log N)$.
    *   **Complexité spatiale** : $O(N)$ pour stocker le set temporaire et la liste triée.

2.  **`union(A, B)`, `intersection(A, B)`, `difference(A, B)`** :
    *   Chacune de ces fonctions commence par normaliser ses deux entrées `A` et `B`. Si $N = \text{len}(A)$ et $M = \text{len}(B)$, cette étape prend $O(N \log N + M \log M)$.
    *   Les algorithmes de fusion (pour `union`, `intersection`, `difference`) parcourent les deux listes normalisées une seule fois. Cette étape est linéaire par rapport à la somme des longueurs des listes.
    *   **Complexité temporelle de la fusion** : $O(N+M)$.
    *   **Complexité temporelle totale** : $O(N \log N + M \log M)$ (dominée par la normalisation).
    *   **Complexité spatiale** : $O(N+M)$ pour les listes normalisées et la liste résultante.

3.  **`symmetric_difference(A, B)`** :
    *   Cette fonction appelle `difference(A, B)`, `difference(B, A)` et `union(diff_ab, diff_ba)`.
    *   Chaque appel à `difference` ou `union` implique une normalisation des entrées et une opération de fusion.
    *   **Complexité temporelle totale** : Puisque chaque opération est au maximum $O(N \log N + M \log M)$, la complexité globale est également $O(N \log N + M \log M)$.
    *   **Complexité spatiale** : $O(N+M)$ pour les listes intermédiaires et le résultat final.

En résumé, la complexité temporelle de nos opérations ensemblistes est dominée par l'étape de tri (`_normalize_set_input`) si les entrées ne sont pas déjà triées et uniques. Si les entrées sont garanties d'être des listes triées d'éléments uniques, alors les opérations de fusion sont en $O(N+M)$, ce qui est optimal pour des ensembles représentés par des listes triées. La complexité spatiale est linéaire par rapport à la taille des ensembles d'entrée et de sortie.
