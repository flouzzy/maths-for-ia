# TP 01 : Implémentation des opérations ensemblistes de base et de l'ensemble des parties

## Objectif Mathématique

Ce Travail Pratique (TP) a pour objectif d'explorer les fondements de la **Théorie des Ensembles** à travers leur implémentation algorithmique en Python. Nous allons traduire les définitions mathématiques abstraites des opérations ensemblistes en code exécutable, en nous appuyant uniquement sur la bibliothèque standard de Python.

Nous aborderons les concepts suivants :
*   **Ensembles et Éléments** : Comprendre la nature non ordonnée et l'unicité des éléments au sein d'un ensemble.
*   **Opérations Ensemblistes Fondamentales** :
    *   **Union** ($A \cup B$) : L'ensemble de tous les éléments appartenant à $A$ ou à $B$ (ou aux deux).
    *   **Intersection** ($A \cap B$) : L'ensemble de tous les éléments appartenant à la fois à $A$ et à $B$.
    *   **Différence** ($A \setminus B$ ou $A - B$) : L'ensemble de tous les éléments appartenant à $A$ mais pas à $B$.
    *   **Différence Symétrique** ($A \Delta B$) : L'ensemble de tous les éléments appartenant à $A$ ou à $B$, mais pas aux deux simultanément.
*   **Relations Ensemblistes** :
    *   **Sous-ensemble** ($A \subseteq B$) : Tous les éléments de $A$ sont aussi des éléments de $B$.
    *   **Sur-ensemble** ($A \supseteq B$) : Tous les éléments de $B$ sont aussi des éléments de $A$.
*   **Ensemble des Parties** ($\mathcal{P}(E)$ ou $2^E$) : L'ensemble de tous les sous-ensembles possibles d'un ensemble donné $E$, y compris l'ensemble vide et l'ensemble $E$ lui-même.
*   **Produit Cartésien** ($A \times B$) : L'ensemble de tous les couples ordonnés $(a, b)$ où $a \in A$ et $b \in B$.
*   **Indice de Jaccard** : Une mesure de similarité entre deux ensembles, définie comme la taille de leur intersection divisée par la taille de leur union.

L'implémentation "from scratch" de ces opérations nous permettra de saisir les algorithmes sous-jacents et de renforcer notre compréhension des propriétés mathématiques qu'ils modélisent. Nous validerons ces implémentations par des assertions formelles basées sur les axiomes et théorèmes de la théorie des ensembles.

## Implémentation en Python Pur

Nous allons implémenter les fonctions en utilisant des types Python natifs (`set` pour la représentation des ensembles, `tuple` pour les éléments du produit cartésien) et le module `itertools` pour des opérations combinatoires efficaces.

```python
import itertools

def to_set(iterable):
    """
    Convertit un itérable en un ensemble Python.
    Utile pour s'assurer que les entrées sont bien des ensembles.
    """
    return set(iterable)

def my_union(A, B):
    """
    Calcule l'union de deux ensembles A et B.
    Mathématiquement : A U B = {x | x ∈ A ou x ∈ B}
    """
    A = to_set(A)
    B = to_set(B)
    # Implémentation manuelle : combiner tous les éléments et éliminer les doublons
    result = set()
    for x in A:
        result.add(x)
    for x in B:
        result.add(x)
    return result
    # Alternative plus concise et idiomatique avec l'opérateur | ou la méthode .union():
    # return A | B
    # return A.union(B)

def my_intersection(A, B):
    """
    Calcule l'intersection de deux ensembles A et B.
    Mathématiquement : A ∩ B = {x | x ∈ A et x ∈ B}
    """
    A = to_set(A)
    B = to_set(B)
    # Implémentation manuelle : ajouter les éléments présents dans les deux ensembles
    result = set()
    for x in A:
        if x in B:
            result.add(x)
    return result
    # Alternative plus concise et idiomatique avec l'opérateur & ou la méthode .intersection():
    # return A & B
    # return A.intersection(B)

def my_difference(A, B):
    """
    Calcule la différence de deux ensembles A et B (A - B).
    Mathématiquement : A \ B = {x | x ∈ A et x ∉ B}
    """
    A = to_set(A)
    B = to_set(B)
    # Implémentation manuelle : ajouter les éléments de A qui ne sont pas dans B
    result = set()
    for x in A:
        if x not in B:
            result.add(x)
    return result
    # Alternative plus concise et idiomatique avec l'opérateur - ou la méthode .difference():
    # return A - B
    # return A.difference(B)

def my_symmetric_difference(A, B):
    """
    Calcule la différence symétrique de deux ensembles A et B (A Δ B).
    Mathématiquement : A Δ B = (A \ B) U (B \ A) = {x | x ∈ A XOR x ∈ B}
    """
    A = to_set(A)
    B = to_set(B)
    # Implémentation utilisant les fonctions précédentes
    return my_union(my_difference(A, B), my_difference(B, A))
    # Alternative plus concise et idiomatique avec l'opérateur ^ ou la méthode .symmetric_difference():
    # return A ^ B
    # return A.symmetric_difference(B)

def is_subset(A, B):
    """
    Vérifie si A est un sous-ensemble de B (A ⊆ B).
    Mathématiquement : A ⊆ B si et seulement si pour tout x, si x ∈ A alors x ∈ B.
    """
    A = to_set(A)
    B = to_set(B)
    # Implémentation manuelle : tous les éléments de A doivent être dans B
    for x in A:
        if x not in B:
            return False
    return True
    # Alternative plus concise et idiomatique avec l'opérateur <= ou la méthode .issubset():
    # return A <= B
    # return A.issubset(B)

def is_superset(A, B):
    """
    Vérifie si A est un sur-ensemble de B (A ⊇ B).
    Mathématiquement : A ⊇ B si et seulement si B ⊆ A.
    """
    A = to_set(A)
    B = to_set(B)
    # Implémentation utilisant la fonction is_subset
    return is_subset(B, A)
    # Alternative plus concise et idiomatique avec l'opérateur >= ou la méthode .issuperset():
    # return A >= B
    # return A.issuperset(B)

def power_set(S):
    """
    Génère l'ensemble des parties d'un ensemble S (P(S)).
    Mathématiquement : P(S) = {X | X ⊆ S}
    Le nombre d'éléments dans P(S) est 2^|S|.
    """
    S = to_set(S)
    elements = list(S) # Convertir en liste pour permettre l'indexation et l'itération ordonnée
    result = set()
    # Utilisation de itertools.combinations pour générer tous les sous-ensembles de toutes tailles
    for k in range(len(elements) + 1):
        for subset_tuple in itertools.combinations(elements, k):
            result.add(frozenset(subset_tuple)) # frozenset pour pouvoir ajouter des ensembles à un ensemble
    return result

def cartesian_product(A, B):
    """
    Calcule le produit cartésien de deux ensembles A et B (A x B).
    Mathématiquement : A x B = {(a, b) | a ∈ A et b ∈ B}
    Le nombre d'éléments dans A x B est |A| * |B|.
    """
    A = to_set(A)
    B = to_set(B)
    result = set()
    # Utilisation de itertools.product pour générer tous les couples ordonnés
    for pair in itertools.product(A, B):
        result.add(pair)
    return result

def jaccard_index(A, B):
    """
    Calcule l'indice de Jaccard entre deux ensembles A et B.
    Mathématiquement : J(A, B) = |A ∩ B| / |A U B|
    Si A U B est vide, l'indice est défini comme 1 si A et B sont tous deux vides, 0 sinon.
    """
    A = to_set(A)
    B = to_set(B)
    intersection = my_intersection(A, B)
    union = my_union(A, B)

    if not union: # Si l'union est vide
        return 1.0 if not A and not B else 0.0 # 1.0 si les deux sont vides, 0.0 sinon
    return len(intersection) / len(union)

```

## Validation et Assertions

Nous allons maintenant valider l'implémentation de nos fonctions en vérifiant diverses propriétés mathématiques des ensembles à l'aide d'assertions.

```python
# Définition d'ensembles de test
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
C = {2, 4, 6, 8}
D = {1, 2}
E = set() # Ensemble vide
F = {1, 2, 3, 4} # Identique à A

print("--- Tests des opérations ensemblistes de base ---")

# 1. Commutativité de l'Union : A U B = B U A
print(f"Test 1: Commutativité de l'Union (A U B = B U A)")
assert my_union(A, B) == my_union(B, A)
print(f"  A U B = {my_union(A, B)}")
print(f"  B U A = {my_union(B, A)}")
print("  Assertion réussie : A U B = B U A\n")

# 2. Commutativité de l'Intersection : A ∩ B = B ∩ A
print(f"Test 2: Commutativité de l'Intersection (A ∩ B = B ∩ A)")
assert my_intersection(A, B) == my_intersection(B, A)
print(f"  A ∩ B = {my_intersection(A, B)}")
print(f"  B ∩ A = {my_intersection(B, A)}")
print("  Assertion réussie : A ∩ B = B ∩ A\n")

# 3. Idempotence de l'Union : A U A = A
print(f"Test 3: Idempotence de l'Union (A U A = A)")
assert my_union(A, A) == A
print(f"  A U A = {my_union(A, A)}")
print(f"  A     = {A}")
print("  Assertion réussie : A U A = A\n")

# 4. Idempotence de l'Intersection : A ∩ A = A
print(f"Test 4: Idempotence de l'Intersection (A ∩ A = A)")
assert my_intersection(A, A) == A
print(f"  A ∩ A = {my_intersection(A, A)}")
print(f"  A     = {A}")
print("  Assertion réussie : A ∩ A = A\n")

# 5. Distributivité de l'Union sur l'Intersection : A U (B ∩ C) = (A U B) ∩ (A U C)
print(f"Test 5: Distributivité (A U (B ∩ C) = (A U B) ∩ (A U C))")
left_side = my_union(A, my_intersection(B, C))
right_side = my_intersection(my_union(A, B), my_union(A, C))
assert left_side == right_side
print(f"  A U (B ∩ C) = {left_side}")
print(f"  (A U B) ∩ (A U C) = {right_side}")
print("  Assertion réussie : A U (B ∩ C) = (A U B) ∩ (A U C)\n")

# 6. Distributivité de l'Intersection sur l'Union : A ∩ (B U C) = (A ∩ B) U (A ∩ C)
print(f"Test 6: Distributivité (A ∩ (B U C) = (A ∩ B) U (A ∩ C))")
left_side = my_intersection(A, my_union(B, C))
right_side = my_union(my_intersection(A, B), my_intersection(A, C))
assert left_side == right_side
print(f"  A ∩ (B U C) = {left_side}")
print(f"  (A ∩ B) U (A ∩ C) = {right_side}")
print("  Assertion réussie : A ∩ (B U C) = (A ∩ B) U (A ∩ C)\n")

# 7. Propriétés de l'ensemble vide
print(f"Test 7: Propriétés de l'ensemble vide")
# A U ∅ = A
assert my_union(A, E) == A
print(f"  A U ∅ = {my_union(A, E)} (attendu: {A})")
# A ∩ ∅ = ∅
assert my_intersection(A, E) == E
print(f"  A ∩ ∅ = {my_intersection(A, E)} (attendu: {E})")
# A \ ∅ = A
assert my_difference(A, E) == A
print(f"  A \\ ∅ = {my_difference(A, E)} (attendu: {A})")
# ∅ \ A = ∅
assert my_difference(E, A) == E
print(f"  ∅ \\ A = {my_difference(E, A)} (attendu: {E})")
print("  Assertions réussies pour l'ensemble vide.\n")

# 8. Cardinalité de l'Union : |A U B| = |A| + |B| - |A ∩ B|
print(f"Test 8: Cardinalité de l'Union (|A U B| = |A| + |B| - |A ∩ B|)")
card_union = len(my_union(A, B))
card_A_plus_card_B_minus_card_intersection = len(A) + len(B) - len(my_intersection(A, B))
assert card_union == card_A_plus_card_B_minus_card_intersection

print(f"  |A| + |B| - |A ∩ B| = {card_A_plus_card_B_minus_card_intersection}")

# 9. Test des sous-ensembles et sur-ensembles
print(f"Test 9: Sous-ensembles et Sur-ensembles")
# D ⊆ A
assert is_subset(D, A) == True
print(f"  D = {D} est un sous-ensemble de A = {A} : {is_subset(D, A)}")

assert is_superset(A, D) == True

assert is_subset(A, A) == True
print(f"  A est un sous-ensemble de A : {is_subset(A, A)}")
# E ⊆ A (l'ensemble vide est un sous-ensemble de tout ensemble)
assert is_subset(E, A) == True

# A ⊆ E (faux si A n'est pas vide)

print("  Assertions réussies pour les relations de sous-ensemble/sur-ensemble.\n")

print("--- Tests des opérations avancées ---")

# 10. Cardinalité de l'Ensemble des Parties : |P(S)| = 2^|S|
print(f"Test 10: Cardinalité de l'Ensemble des Parties (|P(S)| = 2^|S|)")

print(f"  |P(A)| = {len(S_power_set)} (attendu: 2^{len(A)} = {expected_cardinality})")

# 12. Propriétés de l'Indice de Jaccard
print(f"Test 12: Propriétés de l'Indice de Jaccard")
# J(A, A) = 1
j_AA = jaccard_index(A, A)
assert j_AA == 1.0
print(f"  J(A, A) = {j_AA} (attendu: 1.0)")
# J(A, E) = 0 si A n'est pas vide
j_AE = jaccard_index(A, E)
assert j_AE == 0.0
print(f"  J(A, E) = {j_AE} (attendu: 0.0)")
# J(E, E) = 1
j_EE = jaccard_index(E, E)
assert j_EE == 1.0
print(f"  J(E, E) = {j_EE} (attendu: 1.0)")
# J(A, B) = |A ∩ B| / |A U B|
j_AB = jaccard_index(A, B)
expected_j_AB = len(my_intersection(A, B)) / len(my_union(A, B))
assert j_AB == expected_j_AB
print(f"  J(A, B) = {j_AB} (attendu: {expected_j_AB})")
print("  Assertions réussies pour l'Indice de Jaccard.\n")

print("Toutes les assertions ont été vérifiées avec succès ! L'implémentation respecte les propriétés mathématiques des ensembles.")
```

## Analyse de Complexité

L'efficacité des opérations ensemblistes dépend fortement de la manière dont les ensembles sont représentés et des algorithmes utilisés. En Python, le type `set` est implémenté comme une table de hachage, ce qui offre des performances moyennes très efficaces pour la plupart des opérations.

1.  **`to_set(iterable)`**:
    *   **Temps**: $O(N)$ en moyenne, où $N$ est le nombre d'éléments dans l'itérable. Chaque élément doit être haché et inséré. Dans le pire des cas (collisions de hachage extrêmes), cela peut être $O(N^2)$.
    *   **Espace**: $O(N)$ pour stocker les $N$ éléments.

2.  **`my_union(A, B)`, `my_intersection(A, B)`, `my_difference(A, B)`**:
    *   Ces implémentations manuelles itèrent sur les éléments d'un ou des deux ensembles et effectuent des recherches (`x in B`) et des insertions (`result.add(x)`).
    *   **Temps**: En moyenne, $O(|A| + |B|)$. Les opérations `add` et `in` sur un `set` sont $O(1)$ en moyenne.
    *   **Espace**: $O(|A \cup B|)$ pour stocker le nouvel ensemble résultant.

3.  **`my_symmetric_difference(A, B)`**:
    *   Cette fonction utilise `my_union` et `my_difference`.
    *   **Temps**: $O(|A| + |B|)$ car elle effectue des opérations linéaires.
    *   **Espace**: $O(|A \Delta B|)$.

4.  **`is_subset(A, B)` et `is_superset(A, B)`**:
    *   L'implémentation manuelle itère sur les éléments de $A$ et vérifie leur présence dans $B$.
    *   **Temps**: $O(|A|)$ en moyenne, car chaque élément de $A$ est recherché dans $B$ en $O(1)$ en moyenne.
    *   **Espace**: $O(1)$ (pas de nouvel ensemble créé, juste des comparaisons).

5.  **`power_set(S)`**:
    *   Cette fonction utilise `itertools.combinations`.
    *   **Temps**: La génération de tous les sous-ensembles de taille $k$ à partir d'un ensemble de taille $N$ prend un temps combinatoire. Il y a $\binom{N}{k}$ sous-ensembles de taille $k$. L'ensemble des parties contient $2^N$ sous-ensembles. Pour chaque sous-ensemble, la conversion en `frozenset` prend $O(k)$ temps. Donc, la complexité totale est environ $O(2^N \cdot N)$.
    *   **Espace**: $O(2^N \cdot N)$ pour stocker tous les $2^N$ sous-ensembles, chacun ayant une taille moyenne de $N/2$. Cette croissance exponentielle rend cette opération impraticable pour des ensembles de grande taille (typiquement $|S| > 20-25$).

6.  **`cartesian_product(A, B)`**:
    *   Cette fonction utilise `itertools.product`.
    *   **Temps**: $O(|A| \cdot |B|)$. Chaque paire $(a, b)$ est générée et ajoutée au `set`.
    *   **Espace**: $O(|A| \cdot |B|)$ pour stocker tous les couples du produit cartésien.

7.  **`jaccard_index(A, B)`**:
    *   Cette fonction utilise `my_intersection` et `my_union`.
    *   **Temps**: $O(|A| + |B|)$ en raison des opérations d'union et d'intersection.
    *   **Espace**: $O(|A \cap B| + |A \cup B|)$ pour les ensembles intermédiaires.

En résumé, les opérations ensemblistes de base (`union`, `intersection`, `difference`, `subset`) sont très efficaces avec le type `set` de Python, offrant une complexité temporelle quasi-linéaire. Cependant, les opérations combinatoires comme l'**ensemble des parties** ont une complexité exponentielle ($2^N$), ce qui est une propriété intrinsèque à la combinatoire mathématique et non une limitation de l'implémentation Python. Le **produit cartésien** a une complexité polynomiale ($|A| \cdot |B|$), ce qui peut également devenir très grand si les ensembles sont volumineux.
