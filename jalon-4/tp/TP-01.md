# TP 1 : Implémentation des Opérations Ensemblistes Fondamentales

## Objectif Mathématique
Ce TP vise à comprendre et implémenter les définitions mathématiques des opérations ensemblistes fondamentales (union, intersection, différence) en utilisant des structures de données Python simples (listes) pour représenter les ensembles. L'objectif est de reproduire le comportement des ensembles mathématiques en garantissant l'unicité des éléments et une représentation canonique des résultats (par exemple, des listes triées d'éléments uniques).

Un **ensemble** est une collection d'objets distincts, appelés éléments. L'ordre des éléments n'a pas d'importance, et un élément ne peut apparaître qu'une seule fois dans un ensemble.

*   **Union (A ∪ B)**: L'ensemble de tous les éléments qui appartiennent à A ou à B (ou aux deux).
    *   Formellement : $A \cup B = \{x \mid x \in A \text{ ou } x \in B\}$
*   **Intersection (A ∩ B)**: L'ensemble de tous les éléments qui appartiennent à la fois à A et à B.
    *   Formellement : $A \cap B = \{x \mid x \in A \text{ et } x \in B\}$
*   **Différence (A \ B)**: L'ensemble de tous les éléments qui appartiennent à A mais n'appartiennent pas à B.
    *   Formellement : $A \setminus B = \{x \mid x \in A \text{ et } x \notin B\}$

from typing import List, Any

def _to_set_list(elements: List[Any]) -> List[Any]:
    """
    Convertit une liste en une représentation "ensembliste" :
    tous les doublons sont supprimés et les éléments sont triés
    pour assurer une représentation canonique (indépendante de l'ordre initial).

    Args:
        elements: La liste d'éléments à convertir.

    Returns:
        Une nouvelle liste avec des éléments uniques, triés.
    """
    unique_elements = []
    for item in elements:
        if item not in unique_elements:
            unique_elements.append(item)
    return sorted(unique_elements)

def set_union(set_A: List[Any], set_B: List[Any]) -> List[Any]:
    """
    Calcule l'union de deux ensembles représentés par des listes.
    L'union de deux ensembles A et B est l'ensemble de tous les éléments
    qui appartiennent à A ou à B (ou aux deux).

    Formellement : A ∪ B = {x | x ∈ A ou x ∈ B}

    Les listes d'entrée peuvent contenir des doublons ; la fonction s'assure
    que l'ensemble résultant ne contient que des éléments uniques.

    Args:
        set_A: La première liste représentant un ensemble.
        set_B: La deuxième liste représentant un ensemble.

    Returns:
        Une nouvelle liste représentant l'ensemble union,
        avec des éléments uniques et triés pour une représentation canonique.
    """
    # Combine tous les éléments des deux listes
    combined = set_A + set_B
    # Convertit en une représentation ensembliste (éléments uniques et triés)
    return _to_set_list(combined)

def set_intersection(set_A: List[Any], set_B: List[Any]) -> List[Any]:
    """
    Calcule l'intersection de deux ensembles représentés par des listes.
    L'intersection de deux ensembles A et B est l'ensemble de tous les éléments
    qui appartiennent à la fois à A et à B.

    Formellement : A ∩ B = {x | x ∈ A et x ∈ B}

    Les listes d'entrée peuvent contenir des doublons ; la fonction s'assure
    que l'ensemble résultant ne contient que des éléments uniques.

    Args:
        set_A: La première liste représentant un ensemble.
        set_B: La deuxième liste représentant un ensemble.

    Returns:
        Une nouvelle liste représentant l'ensemble intersection,
        avec des éléments uniques et triés pour une représentation canonique.
    """
    intersection_elements = []
    # Parcourt les éléments du premier ensemble
    for item_a in set_A:
        # Si l'élément est aussi dans le second ensemble, et n'a pas déjà été ajouté
        if item_a in set_B and item_a not in intersection_elements:
            intersection_elements.append(item_a)
    return sorted(intersection_elements)

def set_difference(set_A: List[Any], set_B: List[Any]) -> List[Any]:
    """
    Calcule la différence de deux ensembles représentés par des listes (A \ B).
    La différence de l'ensemble A par l'ensemble B est l'ensemble de tous les éléments
    qui appartiennent à A mais n'appartiennent pas à B.

    Formellement : A \ B = {x | x ∈ A et x ∉ B}

    Les listes d'entrée peuvent contenir des doublons ; la fonction s'assure
    que l'ensemble résultant ne contient que des éléments uniques.

    Args:
        set_A: La première liste représentant un ensemble (le minuende).
        set_B: La deuxième liste représentant un ensemble (le soustracteur).

    Returns:
        Une nouvelle liste représentant l'ensemble différence,
        avec des éléments uniques et triés pour une représentation canonique.
    """
    difference_elements = []
    # Parcourt les éléments du premier ensemble
    for item_a in set_A:
        # Si l'élément est dans A mais pas dans B, et n'a pas déjà été ajouté
        if item_a not in set_B and item_a not in difference_elements:
            difference_elements.append(item_a)
    return sorted(difference_elements)
