# TP 3 : Approximation polynomiale de Bernstein (Théorème de Weierstrass)
**Objectif :** Construire des polynômes de Bernstein pour approximer uniformément la fonction $|x - 0.5|$ sur $[0, 1]$.

**Implémentation :**
```python
import math

def coef_binom(n, k):
    return math.factorial(n) / (math.factorial(k) * math.factorial(n - k))

def polynome_bernstein(f, n, x):
    somme = 0
    for k in range(n + 1):
        poly_base = coef_binom(n, k) * (x**k) * ((1 - x)**(n - k))
        somme += f(k / n) * poly_base
    return somme

f_abs = lambda x: abs(x - 0.5)

grille = [i/50 for i in range(51)]
for n in [5, 20, 50]:
    erreurs = [abs(polynome_bernstein(f_abs, n, x) - f_abs(x)) for x in grille]
    max_err = max(erreurs)
    print(f"Bernstein n={n}, Erreur uniforme: {max_err:.4f}")
```
