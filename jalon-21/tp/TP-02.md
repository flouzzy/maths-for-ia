# TP 2 : Le phénomène de Gibbs
**Objectif :** Analyser le défaut de convergence uniforme des séries de Fourier aux points de discontinuité.

**Implémentation :**
```python
import math

def fourier_creneau(n, x):
    somme = 0
    for k in range(1, n+1, 2):
        somme += (4 / math.pi) * math.sin(k * x) / k
    return somme

grille = [math.pi * i / 1000 for i in range(1001)]
limite = 1 # Valeur du créneau pour x dans ]0, pi[

def erreur_max_fourier(n):
    erreurs = [abs(fourier_creneau(n, x) - limite) for x in grille if 0 < x < math.pi]
    return max(erreurs)

for n in [10, 50, 100]:
    err = erreur_max_fourier(n)
    print(f"Série de Fourier n={n}, Erreur Max: {err:.4f}")
    assert err > 0.17, "Le dépassement de Gibbs (environ 18%) ne s'atténue pas."
```
