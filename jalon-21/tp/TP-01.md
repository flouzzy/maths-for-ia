# TP 1 : Visualisation de la convergence simple

**Objectif :** Implémenter une fonction Python pour évaluer $f_n(x) = x^n$ sur $[0,1]$ et vérifier la convergence simple point par point via des assertions pour différentes valeurs de $x$.

## Implémentation Pure Python (Validation Mathématique)

```python
def f_n(n, x):
    return x ** n

def limite_f(x):
    return 0.0 if x < 1.0 else 1.0

# Validation par assertions
assert abs(f_n(100, 0.5) - limite_f(0.5)) < 1e-5
assert abs(f_n(10, 1.0) - limite_f(1.0)) < 1e-5
print("Convergence simple vérifiée aux points tests.")
```
