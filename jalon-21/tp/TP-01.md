# TP 1 : Illustration numérique de la convergence simple et uniforme
**Objectif :** Implémenter en Python une classe permettant d'évaluer la convergence de suites de fonctions sur une grille, sans bibliothèques externes complexes autres que la syntaxe de base.

**Implémentation :**
```python
import math

class SuiteFonctions:
    def __init__(self, fonction_n_x, limite_x, a, b, n_points=1000):
        self.f_n = fonction_n_x
        self.f = limite_x
        self.a = a
        self.b = b
        self.n_points = n_points
        self.grille = [a + i*(b-a)/n_points for i in range(n_points+1)]

    def erreur_point_par_point(self, n, x):
        return abs(self.f_n(n, x) - self.f(x))

    def norme_infinie(self, n):
        erreurs = [self.erreur_point_par_point(n, x) for x in self.grille]
        return max(erreurs)

# Cas d'étude : x^n sur [0, 1]
f_n = lambda n, x: x**n
f = lambda x: 0 if x < 1 else 1

suite = SuiteFonctions(f_n, f, 0, 1, 10000)

for n in [10, 100, 1000]:
    norme_sup = suite.norme_infinie(n)
    print(f"Norme infinie pour n={n} : {norme_sup:.4f}")
    assert norme_sup > 0.9, "L'erreur reste de l'ordre de 1, prouvant le défaut d'uniformité."
```
