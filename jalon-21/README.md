# Jalon 21 : Suites de fonctions

Ce dossier contient les ressources pédagogiques exhaustives pour le jalon 21 du programme de mathématiques pour l'IA, axé sur les suites de fonctions et la convergence.

## Structure

*   `Jalon-21.md` : Cours théorique approfondi, rigoureux et sans ellipse mathématique.
*   `exos/` : 10 exercices de complexité croissante (sans mention informelle de difficulté) démontrés formellement.
*   `tp/` : 5 travaux pratiques en Python pur pour l'assimilation algorithmique des concepts.
