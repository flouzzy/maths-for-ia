# TP 2 : Simulation numérique du phénomène de divergence

**Objectif :** Observer numériquement qu'une intégrale divergente (comme l'intégrale harmonique $1/t$) croît indéfiniment lorsque la borne de troncature augmente.

**Lien Théorique :** Nous avons prouvé que $\int_1^X \frac{1}{t} dt = \ln(X)$. En fixant différents $X$ croissants dans notre algorithme, nous devons observer que la valeur ne se stabilise pas, confirmant la divergence vers $+\infty$.

```python
import math

def fonction_divergente(t: float) -> float:
    """
    Fonction f(t) = 1 / t.
    L'intégrale de 1 à l'infini diverge (série harmonique continue).
    """
    return 1.0 / t

def integrer_propre(f, a: float, b: float, n_steps: int) -> float:
    """
    Intégration classique par la méthode des trapèzes.
    """
    pas = (b - a) / n_steps
    somme = 0.5 * (f(a) + f(b)) * pas

    for i in range(1, n_steps):
        t_i = a + i * pas
        somme += f(t_i) * pas

    return somme

if __name__ == "__main__":
    # On va calculer l'intégrale pour des bornes de troncature de plus en plus grandes
    bornes_troncature = [10.0, 100.0, 1000.0, 10000.0, 100000.0]
    resultats = []

    for X in bornes_troncature:
        val = integrer_propre(fonction_divergente, 1.0, X, 10000)
        val_theorique = math.log(X)
        resultats.append(val)
        print(f"Intégrale jusqu'à X={X:6.0f} : Numérique = {val:.4f}, Théorique (ln) = {val_theorique:.4f}")

    # Validation mathématique : la suite des résultats doit être strictement croissante
    for i in range(1, len(resultats)):
        assert resultats[i] > resultats[i-1], "L'intégrale ne croît pas, contradiction avec la divergence positive."

    print("Test validé : Le programme met en évidence la croissance logarithmique non bornée (divergence).")
```
