# TP 5 : Intégrale de Dirichlet et Semi-convergence

**Objectif :** Montrer numériquement que l'intégrale $\int_0^{X} \frac{\sin(t)}{t} dt$ converge, tandis que $\int_0^{X} \left|\frac{\sin(t)}{t}\right| dt$ diverge (elle croît sans limite, bien que très lentement).

**Lien Théorique :** C'est l'illustration numérique parfaite de l'Exercice 10 : une intégrale peut converger grâce à des compensations de signes successives (les aires positives annulent les aires négatives), alors que l'intégrale de sa valeur absolue diverge.

```python
import math

def dirichlet_integrande(t: float) -> float:
    if t == 0:
        return 1.0 # Prolongement par continuité
    return math.sin(t) / t

def abs_dirichlet_integrande(t: float) -> float:
    if t == 0:
        return 1.0
    return abs(math.sin(t) / t)

def integrer_simpson(f, a: float, b: float, n_intervals: int) -> float:
    """ Méthode de Simpson pour une meilleure précision sur les fonctions oscillantes. """
    # n_intervals doit être pair
    if n_intervals % 2 != 0:
        n_intervals += 1
    h = (b - a) / n_intervals
    somme = f(a) + f(b)

    for i in range(1, n_intervals, 2):
        somme += 4 * f(a + i * h)
    for i in range(2, n_intervals-1, 2):
        somme += 2 * f(a + i * h)

    return somme * h / 3.0

if __name__ == "__main__":
    # Testons sur des bornes croissantes
    bornes = [10, 50, 100, 500]

    valeurs_classiques = []
    valeurs_absolues = []

    for X in bornes:
        val_classique = integrer_simpson(dirichlet_integrande, 0, X, int(X * 10))
        val_absolue = integrer_simpson(abs_dirichlet_integrande, 0, X, int(X * 10))

        valeurs_classiques.append(val_classique)
        valeurs_absolues.append(val_absolue)

        print(f"X = {X:3d} | Intégrale classique = {val_classique:.4f} | Intégrale absolue = {val_absolue:.4f}")

    # Validation
    # La valeur classique doit se rapprocher de pi/2 (env 1.5708)
    assert abs(valeurs_classiques[-1] - math.pi/2) < 0.05, "L'intégrale classique ne converge pas vers pi/2"

    # La valeur absolue doit croître indéfiniment
    for i in range(1, len(valeurs_absolues)):
        assert valeurs_absolues[i] > valeurs_absolues[i-1], "L'intégrale absolue ne croît pas, contradiction"

    print("Tests validés : L'intégrale classique converge (oscillations compensées), l'absolue diverge.")
```
