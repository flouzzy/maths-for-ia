# TP 3 : Détection de convergence par le critère de Cauchy

**Objectif :** Implémenter un algorithme qui tente de deviner si une intégrale généralisée converge en évaluant si le critère de Cauchy est vérifié numériquement pour $X$ grand.

**Lien Théorique :** L'intégrale $\int_a^{+\infty} f(t)dt$ converge ssi $\forall \epsilon>0, \exists B, \forall X, Y > B, |\int_X^Y f(t)dt| < \epsilon$. Numériquement, on calcule l'intégrale sur des blocs successifs $[X_k, X_{k+1}]$ et on vérifie si ces contributions tendent vers zéro (ou sous un seuil $\epsilon$).

```python
import math

def fonction_cloche(t: float) -> float:
    """ f(t) = e^(-t) """
    return math.exp(-t)

def integrer_bloc(f, a: float, b: float, n_steps: int = 100) -> float:
    pas = (b - a) / n_steps
    somme = sum(f(a + i * pas) for i in range(n_steps)) * pas
    return somme

def test_cauchy_convergence(f, start: float, step: float, epsilon: float, max_iter: int) -> bool:
    """
    Vérifie si l'intégrale sur les blocs [start + k*step, start + (k+1)*step]
    devient inférieure à epsilon.
    """
    for k in range(max_iter):
        a = start + k * step
        b = a + step
        contribution = abs(integrer_bloc(f, a, b))

        if contribution < epsilon:
            # On considère (naïvement) que le critère de Cauchy est respecté
            return True
    return False

if __name__ == "__main__":
    epsilon = 1e-4
    # Test sur une fonction convergente (exponentielle décroissante)
    converge_exp = test_cauchy_convergence(fonction_cloche, 0.0, 1.0, epsilon, 50)
    assert converge_exp is True, "L'exponentielle devrait converger numériquement."

    # Test sur une fonction divergente (1/t)
    def f_div(t): return 1.0/t
    converge_div = test_cauchy_convergence(f_div, 1.0, 1.0, epsilon, 50)
    assert converge_div is False, "1/t ne devrait pas vérifier le critère de Cauchy numériquement si rapidement."

    print("Test validé : Le programme distingue correctement les comportements asymptotiques via le critère de Cauchy.")
```
