# TP 1 : Approximation numérique d'une intégrale convergente

**Objectif :** Implémenter la méthode des rectangles (ou sommes de Riemann) pour approximer une intégrale généralisée sur un intervalle infini, en tronquant l'intervalle d'intégration.

**Lien Théorique :** Mathématiquement, $\int_a^{+\infty} f(t) dt = \lim_{X \to +\infty} \int_a^X f(t) dt$. En machine, on ne peut pas calculer jusqu'à l'infini. On choisit donc un point de troncature $X$ très grand, et on approxime l'intégrale propre $\int_a^X f(t) dt$ par discrétisation.

```python
import math

def fonction_a_integrer(t: float) -> float:
    """
    Fonction f(t) = 1 / t^2.
    L'intégrale de 1 à l'infini vaut 1.
    """
    return 1.0 / (t * t)

def integrer_infinie(f, a: float, b_trunc: float, n_steps: int) -> float:
    """
    Approxime l'intégrale de a à b_trunc par la méthode des rectangles à gauche.
    """
    assert b_trunc > a, "La borne de troncature doit être supérieure à a"
    assert n_steps > 0, "Le nombre de pas doit être strictement positif"

    pas = (b_trunc - a) / n_steps
    somme = 0.0

    for i in range(n_steps):
        t_i = a + i * pas
        somme += f(t_i) * pas

    return somme

if __name__ == "__main__":
    # Test de l'implémentation
    # Vraie valeur : int_1^+inf 1/t^2 dt = 1
    valeur_approx = integrer_infinie(fonction_a_integrer, 1.0, 10000.0, 100000)
    print(f"Approximation: {valeur_approx}")
    # Vérification que l'erreur est petite
    assert abs(valeur_approx - 1.0) < 1e-2, "L'approximation est trop éloignée de la valeur théorique"
    print("Test validé : l'approximation numérique converge vers la valeur théorique 1.")
```
