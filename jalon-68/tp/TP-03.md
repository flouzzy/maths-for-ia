# TP 3 : Calcul empirique de la borne inférieure (Liminf discrète)

Pour bien comprendre la construction de la fonction limite inférieure $g_n = \inf_{k \geq n} f_k$ utilisée dans la preuve du Lemme de Fatou, nous l'implémentons sur un ensemble discret et fini (une approximation).

```python
def compute_g_n(n, K_max, x, f_seq):
    # Calcule l'infimum des f_k(x) pour k entre n et K_max
    # f_seq est une fonction qui prend (k, x)
    min_val = float('inf')
    for k in range(n, K_max + 1):
        val = f_seq(k, x)
        if val < min_val:
            min_val = val
    return min_val

def test_liminf_sequence():
    # Sequence oscillante: f_k(x) = 1 si k pair, 0 si k impair
    def my_seq(k, x):
        return 1.0 if k % 2 == 0 else 0.0

    # L'infimum a partir de n importe quel n (pair ou impair) sur une longue serie
    # contiendra forcement un indice impair, donc l'inf vaut 0.
    for n in range(1, 10):
        g_n_val = compute_g_n(n, n + 5, 0.0, my_seq)
        assert g_n_val == 0.0

    # Sequence decroissante: f_k(x) = 1/k
    def seq_dec(k, x):
        return 1.0 / k

    # L'infimum entre n et K_max d'une fonction decroissante est la valeur en K_max
    g_1_10 = compute_g_n(1, 10, 0.0, seq_dec)
    assert abs(g_1_10 - 0.1) < 1e-6

    print("TP 3 : Calcul de la borne inferieure valide.")

if __name__ == "__main__":
    test_liminf_sequence()
```
