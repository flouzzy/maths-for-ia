# TP 5 : Conservation de la masse par domination

On va montrer empiriquement le Théorème de Convergence Dominée (Corollaire de Fatou) en utilisant une séquence de fonctions de la forme $f_n(x) = (1/n) \mathbf{1}_{[0, n]}(x) * e^{-x}$.
L'exponentielle "tue" la fuite vers l'infini, dominant la fonction, ce qui force la convergence de l'intégrale vers 0 sans perte de masse.

```python
import math

def indicator(x, start, end):
    return 1.0 if start <= x <= end else 0.0

def f_n_dominated(n, x):
    if n == 0:
        return 0.0
    return (1.0 / n) * indicator(x, 0.0, float(n)) * math.exp(-x)

def integral_dominated(n):
    if n == 0:
        return 0.0
    dx = 0.05
    total = 0.0
    x = 0.0
    while x <= float(n):
        total += f_n_dominated(n, x) * dx
        x += dx
    return total

def test_domination():
    # Sans l'exponentielle (TP2), l'integrale valait 1.0 constamment.
    # Ici, grace a l'enveloppe exponentielle decroissante,
    # l'integrale doit tendre vers 0 tout comme la limite ponctuelle.

    val_10 = integral_dominated(10)
    val_50 = integral_dominated(50)
    val_100 = integral_dominated(100)

    assert val_10 < 0.2
    assert val_50 < val_10
    assert val_100 < val_50

    print("TP 5 : Convergence dominee (Fatou sans perte de masse) validee.")

if __name__ == "__main__":
    test_domination()
```
