# TP 2 : Simulation de la perte de masse (Lemme de Fatou)

Nous allons illustrer le cas d'inégalité stricte du Lemme de Fatou.
On simule la suite de fonctions $f_n(x) = (1/n) \mathbf{1}_{[0, n]}(x)$.
L'intégrale (aire sous la courbe) est constante et vaut 1, mais la limite ponctuelle est 0 partout.

```python
def indicator(x, start, end):
    return 1.0 if start <= x <= end else 0.0

def f_n(n, x):
    if n == 0:
        return 0.0
    return (1.0 / n) * indicator(x, 0.0, float(n))

def integral_f_n(n):
    # L'integrale analytique d'un rectangle de hauteur 1/n et largeur n est 1.
    if n == 0:
        return 0.0
    # En Riemann numerique grossier :
    dx = 0.01
    total = 0.0
    x = -1.0
    while x <= float(n) + 1.0:
        total += f_n(n, x) * dx
        x += dx
    return total

def liminf_f_n(x):
    # Pour tout x fixe, a partir d'un certain n > x, fn(x) = 1/n qui tend vers 0.
    # Donc la limite est 0.
    return 0.0

def test_fatou_loss():
    # On teste l'integrale de fn pour n=10, 100, 1000. Elle doit rester proche de 1.
    val_10 = integral_f_n(10)
    val_50 = integral_f_n(50)

    # Tolerances pour le calcul discret
    assert 0.95 <= val_10 <= 1.05
    assert 0.95 <= val_50 <= 1.05

    # Mais l'integrale de la limite (fonction nulle) est 0.
    integral_limit = 0.0

    # Lemme de Fatou: Integrale(lim_inf fn) <= lim_inf(Integrale fn)
    # 0.0 <= 1.0 (inegalite stricte)
    assert integral_limit < val_50

    print("TP 2 : Perte de masse de Fatou validee (Inegalite stricte).")

if __name__ == "__main__":
    test_fatou_loss()
```
