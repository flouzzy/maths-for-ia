# TP 1 : Implémentation de la norme euclidienne

L'objectif de ce TP est d'implémenter de zéro le calcul de la norme euclidienne pour un vecteur de dimension n.
Nous testerons ensuite cette implémentation sur des vecteurs dont la norme est mathématiquement connue.

```python
def euclidean_norm(vector):
    """
    Calcule la norme euclidienne d'un vecteur de dimension n.
    Args:
        vector (list or tuple): Le vecteur d'entree.
    Returns:
        float: La norme euclidienne calculee.
    """
    if not vector:
        return 0.0
    sum_of_squares = 0.0
    for element in vector:
        sum_of_squares += element ** 2
    return sum_of_squares ** 0.5

# Validation mathematique
def test_euclidean_norm():
    # Test 1: Norme d'un vecteur nul en 3D
    assert euclidean_norm([0, 0, 0]) == 0.0, "Echec : La norme du vecteur nul doit etre 0."

    # Test 2: Vecteur normé classique en 2D (Pythagore 3-4-5)
    # 3**2 + 4**2 = 9 + 16 = 25, sqrt(25) = 5
    assert euclidean_norm([3, 4]) == 5.0, "Echec : La norme de [3, 4] doit etre 5.0."

    # Test 3: Vecteur en 3D
    # 1**2 + 2**2 + 2**2 = 1 + 4 + 4 = 9, sqrt(9) = 3
    assert euclidean_norm([1, 2, 2]) == 3.0, "Echec : La norme de [1, 2, 2] doit etre 3.0."

    print("TP 1 valide : L'implementation de la norme euclidienne est correcte.")

if __name__ == "__main__":
    test_euclidean_norm()
```
