# TP 5 : L'algorithme basique de Loss Surface (IA)

Ce TP simule l'évaluation d'une fonction de perte typique d'une régression linéaire (MSE) en fonction de deux paramètres de poids (w1, w2). Bien que nous n'ayons pas encore formellement vu le gradient, nous pouvons explorer numériquement la topologie de cette surface d'erreur en l'évaluant sur une grille (grid search basique) et constater la continuité de l'erreur.

```python
def mse_loss(w1, w2, dataset):
    """
    Calcule l'erreur quadratique moyenne.
    Le modele est y_pred = w1 * x1 + w2 * x2
    Args:
        w1, w2: Les parametres du modele.
        dataset: Une liste de tuples (x1, x2, y_true).
    """
    total_error = 0.0
    for x1, x2, y_true in dataset:
        y_pred = w1 * x1 + w2 * x2
        total_error += (y_pred - y_true) ** 2
    return total_error / len(dataset)

def test_loss_surface():
    # On cree un dataset parfait genere par y = 2*x1 + 3*x2
    dataset = [
        (1.0, 1.0, 5.0),
        (2.0, 0.0, 4.0),
        (0.0, 2.0, 6.0),
        (-1.0, 1.0, 1.0)
    ]

    # 1. Le point optimum doit donner une erreur (loss) nulle.
    optimal_loss = mse_loss(2.0, 3.0, dataset)
    assert optimal_loss == 0.0, f"L'erreur optimale devrait etre 0, obtenue: {optimal_loss}"

    # 2. Continuité (informelle) : Une legere perturbation de w doit entrainer une petite perte.
    perturbed_loss = mse_loss(2.01, 3.01, dataset)
    assert 0.0 < perturbed_loss < 0.1, f"La perte post-perturbation est etrange: {perturbed_loss}"

    # 3. Un mauvais modele doit donner une grosse erreur.
    bad_loss = mse_loss(0.0, 0.0, dataset)
    assert bad_loss > 10.0, f"Le mauvais modele devrait avoir une perte elevee, obtenue: {bad_loss}"

    # 4. Evaluation d'une grid search ultra basique pour s'approcher du minimum
    best_w1, best_w2 = 0.0, 0.0
    min_loss = float('inf')

    # Grid de 0.0 a 4.0 par pas de 1.0
    for w1 in [0.0, 1.0, 2.0, 3.0, 4.0]:
        for w2 in [0.0, 1.0, 2.0, 3.0, 4.0]:
            current_loss = mse_loss(w1, w2, dataset)
            if current_loss < min_loss:
                min_loss = current_loss
                best_w1, best_w2 = w1, w2

    assert best_w1 == 2.0 and best_w2 == 3.0, "La recherche sur grille n'a pas trouve le minimum exact present dans la grille."

    print("TP 5 valide : La fonction de perte multi-variables se comporte continuement et son minimum a ete trouve.")

if __name__ == "__main__":
    test_loss_surface()
```
