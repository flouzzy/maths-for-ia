# TP 02 - Dérivation d'un signal discret (Différence Finie)

**Script Python `tp_02.py` :**
```python
def derivative_discrete(signal, dt):
    # Calcule la dérivée par différence finie avant
    deriv = []
    for i in range(len(signal) - 1):
        deriv.append((signal[i+1] - signal[i]) / dt)
    return deriv

if __name__ == '__main__':
    dt = 0.1
    # Signal créneau (Heaviside discret)
    signal = [0.0]*5 + [1.0]*5

    deriv = derivative_discrete(signal, dt)

    # La dérivée d'un saut de 0 à 1 devrait donner une impulsion de hauteur 1/dt
    print("Signal original :", signal)
    print("Dérivée discrète :", deriv)

    # Vérification de l'impulsion
    assert deriv[4] == 1.0 / dt, "Le saut n'a pas été détecté correctement"
    assert sum(deriv) * dt == 1.0, "L'intégrale de la dérivée discrète doit valoir le saut total (1.0)"

    print("TP 02 Validé.")

```
